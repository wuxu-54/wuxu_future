# 《如何阅读一本书》轻阅读编写组

## 一、读书的3W1H

- 读书四问，这也是本书主要讲的4件事情

    1. why 为什么读书
    2. what 读什么书
        - 主食：职业、生活
        - 美食：思想需求
        - 蔬菜、水果：工具书
        - 甜点、零食：消遣、娱乐
    3. where 在哪里读
    4. how 怎么读

## 二、阅读层次

- 艾德勒：
    1. 基础阅读
    2. 检视阅读
    3. 分析阅读
    4. 主题阅读：可以多本，主题一致即可
- 邹韬奋：分层次阅读
  - 层次划分
    1. 泛读
    2. 略读
    3. 精读
  - 泛读与略读对应检视阅读，精读对应分析阅读
  - 对同一主题类书籍做到分层次阅读对应主题阅读

- 王国维：三重境界  

  - “昨夜西风凋碧树，独上高楼，望尽天涯路” -  基础阅读
  - “衣带渐宽终不悔，为伊消得人憔悴” - 分析阅读
  - “众里寻他千百度，暮然回首，那人却在灯火阑珊处” - 主题阅读

- 本书作者：层次与读书四问
  - 这本书讲了什么？（主题）
  - 作者通过这本书解决了什么问题？（作者主旨）
  - 这本书说的有道理吗？
  - 这本书与我有什么关系？

## 三、阅读方法之速度法

- 注意点
  - 速读不是只图快，而是在保证阅读质量下阅读速度越快越好
  - 速读也要有思考、有理解
  - 速度适合检视阅读/泛读&略读
- 速读方法
  - 视读不声读
  - 拓宽视野：视线从中间扫到两边距离最大。
  - 不`指读`，画弹簧方式扫读：眼睛从左上到右下，从右下到左下，从左下到右上
  - 不`回读`
  - 要做到理解，**心中有其意**，不必纠结一字一词
  - 多做速读练习
  - 提高注意力：阅读时将注意力集中在后脑勺
  - 注意阅读的负面情绪：克服畏惧心、焦虑心，摆脱对作者等负面情绪
- 如何快速理解？
  - 阅读后进行提问（最好的理解方式）
    1. 讲了什么
    2. 作者的主旨
    3. 我的评价
    4. 有什么用
  - 思维导图（结构、主旨，可以参考金字塔原理）
- 如何快速记忆？
  - 明确阅读目标
  - 阅读时，不时停下复述之前的内容
  - 记忆类似电脑硬盘，是存、取的过程
    - 形成存储信息的条件反射：记忆角度越多，越不容易忘记（比如运用多个感官，味觉、嗅觉、触觉、视觉等，加深记忆与印象）
      - 文字图像化
      - 静态形象动态化
      - 抽象概念具体化
      - 单一信息多维护
    - 形成读取信息的条件反射：处理、转化信息的快慢影响读取信息的速度
      - 联想，从大脑中匹配与之相关信息
      - 逆向读取，怎么存储的，就怎么再逆向读取出来。
      - 情景在线

## 四、阅读方法之精读法

- 适用：分析阅读/精读
- 选择精读的书籍
  - 主食类
  - 教会我们知识、技巧、思维的书，即便我们不搞懂其内容（取其内容，也取其形式，获得知识与知识外的感悟）。 例如：《金字塔原理》中，我们可以学习作者的思维方式、研究问题的方法、表达方法等"形式"（也可以说是表面的东西）。
  - 注意：不迷信权威，不迷信自己。一切实事求是。
- 古人精读的方法
  - 四到五用
    - 心到：集中注意力
    - 眼到：认真看
    - 口到：认真背诵
    - 手到：认真做笔记
    - 脑到（鲁迅加的）：认真思考
  - 钩玄提要（韩愈）
    - 提其要（知道书讲了什么）：目录，了解整体结构与联系
    - 钩其玄（知道作者的观点）：看清作者观点，把握重点，形成自己的观点
- 记读书笔记：有助于阅读
  - 摘抄型笔记：摘录书中内容
  - 感悟型笔记：阅读完写出自己的理解感悟，对书中观点的赞成或批评
  - 评注型笔记：与感悟型类似，在阅读过程中表达自己的看法、情况，包括：书头批注、夹住、评注、原文的补充
  - 综合型笔记：兼有以上三种笔记特点，有原文、有感想、有评注。
- 基本要求：识文解义
  - 识文：知道文中说的什么意思。
  - 解义：知道作者表达什么观点
  - 了解汉语句式，可简化语句快速抓住重点，有助于快速识文解义（儿子上小学后，给他讲讲）
    - 短语类型
      - 主谓短语
      - 偏正短语
      - 动宾短语
      - 动补短语
      - 并列短语
      - 介宾短语
    - 句子
      - 主语
      - 谓语
      - 宾语
      - 定语
      - 状语
      - 补语
- 反复阅读：不是反复机械的阅读
  - 有目的
  - 有顺序
  - 有详略
  - 克服心理障碍
    - 障碍一：已读过，感觉无新意
    - 障碍二：已经吃透，随手翻阅 （这种心理要不得，自己所谓的吃透，其实还差的远呢）
      - 解决方法：每次用不重复的方式阅读。比如：第一遍阅读识文解义，第二遍阅读提取重点、深入研读 这样可以保证有新意，阅读不枯燥。
    - 障碍三：重读未尽，半途而废
- 明确书的结构
  - 一本书按内容大体分为：
    - 总分式
    - 并列式
    - 对照式
    - 递进式
    - 或综合上面几种形式
  - 与略读不同，略读目的是获取内容，精读中的结构是按读者自己的理解或需求建立新结构
  - 建立结构时的注意点：
    1. 结构不能脱离主题
    2. 结构要符合材料本身规律
    3. 符合读者自己的习惯，新颖有特点
- 会用书
  - 错误1：尽信书不如无书
  - 错误2：实用主义者不读书不信书
  - 要会用书，择优而用，书与实践相结合，书中理论提供实践的方法，以实践论证理论正确性。
- 阅读效果
  - 分享与传播
    - 能将书中内容（即使晦涩难懂）按自己的理解，通俗易懂的表达出来。
    - 表达时，不依循文章本身结构，但一定调理清晰。
  - 如何评论一本书
    - 必要性：读完、读懂后还需要有自己的观点评论，是对自己阅读结果的检验
    - 不读懂，不妄评；读懂了，必须评。  通过<层次与读书四问>1与2 来判断是否读懂。
    - 有理有据，求同存异。
  - 读书必有疑，无疑不读书
    - 提出问题：
      - “浅”：指问题要清晰明了，浅显易懂
      - “达”：问题直指关键
      - “重要”：不问无关痛痒、自相矛盾的问题，疑问包含自己对书中内容的理解。
    - “疑问-解答-验证-再疑问-再解答-再验证” 螺旋上升的过程
  - 我如何写这本书
    - 明白作者怎么写：理顺作者思路
    - 清楚什么才是自己的：只有创新才是自己的，按自己的理解、吸收的知识去写。
