## 💡 高效使用快捷键的小贴士

除了记住按键，这些技巧能让你用得更顺手：

- **随时查阅内置快捷键列表**：在 Figma 画布界面，按下 `Ctrl + Shift + ?` (Windows) 或 `Cmd + Shift + ?` (Mac)，屏幕底部会显示所有快捷键，你用过的会高亮显示，方便学习和巩固 。
- **巧用测量与复制**：
  - 需要查看元素间距时，选中一个元素，将鼠标悬停在另一个元素上并按住 `Alt` 键，Figma 就会显示它们之间的距离 。
  - 按住 `Alt` 键拖动元素可以快速复制。接着使用 `Ctrl + D` (Windows) 或 `Cmd + D` (Mac) 可以按上一次的移动距离重复复制，非常适合快速创建等间距的列表项 。
- **矢量编辑小技巧**：
  - 使用钢笔工具时，按 `ESC` 键可以结束当前路径的绘制 。
  - 连接两个路径点时，可以使用 `Ctrl + J` (Windows) 或 `Cmd + J` (Mac) 快速连接 。
- **快速调整数值**：在检查器（右侧面板）的数值输入框（如字号、描边粗细）上，**按住 `Alt` 键的同时用鼠标左右拖动**，可以无需输入具体数字就快速调整数值，非常直观 。

## 💎 总结

最好的学习方式就是在实践中应用。建议你先从最常用的工具和操作快捷键开始，比如**移动工具 (`V`)、文本工具 (`T`)、编组 (`Ctrl+G` / `Cmd+G`)、缩放画布（按住空格拖拽）**，熟练后再逐步探索更多功能。

如果你对某个特定操作（比如布尔运算、自动布局）的快捷键有更深入的兴趣，我很乐意为你提供更详细的解答。
