# Figma 快捷键

以下是结合之前所有提及内容整理的**Figma完整快捷键表格**，涵盖基础操作、图层管理、视图控制、设计工具等全场景，确保无遗漏核心功能：

## **一、基础操作与全局控制**

| 操作 | Mac 快捷键 | Windows 快捷键 | 说明 |
|---------------------------|-------------------|-------------------|--------------------------------|
| 撤销 | `Cmd + Z` | `Ctrl + Z` | 撤销上一步操作 |
| 重做 | `Shift + Cmd + Z` | `Shift + Ctrl + Z` | 恢复撤销的操作 |
| 全选 | `Cmd + A` | `Ctrl + A` | 选中画布上所有元素 |
| 取消选择 | `Cmd + Shift + A` | `Ctrl + Shift + A` | 取消当前所有选中状态 |
| 快速搜索（命令面板） | `Cmd + /` | `Ctrl + /` | 搜索功能、插件或历史操作 |
| 复制 | `Cmd + C` | `Ctrl + C` | 复制选中元素 |
| 粘贴 | `Cmd + V` | `Ctrl + V` | 粘贴复制的元素 |
| 粘贴在原位置 | `Shift + Cmd + V` | `Shift + Ctrl + V` | 在相同位置粘贴元素（跨页面有效） |
| 剪切 | `Cmd + X` | `Ctrl + X` | 剪切并删除选中元素 |
| 重复上一个操作 | `Cmd + D` | `Ctrl + D` | 核心功能：重复执行上一次操作（如重复复制、绘制、调整样式等） |
| 保存文件 | `Cmd + S` | `Ctrl + S` | 保存当前文件 |
| 保存版本 | `Cmd + Option + S` | `Ctrl + Alt + S` | 创建文件版本快照 |
| 保存为副本 | `Cmd + Shift + S` | `Ctrl + Shift + S` | 将当前文件另存为副本 |
| 新建文件 | `Cmd + N` | `Ctrl + N` | 创建新文件 |
| 新建页面 | `Cmd + Shift + N` | `Ctrl + Shift + N` | 在当前文件中创建新页面 |
| 关闭文件 | `Cmd + W` | `Ctrl + W` | 关闭当前文件 |
| 关闭所有文件 | `Option + Cmd + W` | `Alt + Ctrl + W` | 关闭当前打开的所有文件 |
| 查找与替换文本 | `Cmd + F` | `Ctrl + F` | 在当前文件中搜索文本并替换 |
| 查找图层/组件 | `Cmd + Option + F` | `Ctrl + Alt + F` | 在图层面板中搜索图层名称或组件 |
| 显示所有快捷键 | `Cmd + Shift + ?` | `Ctrl + Shift + ?` | 打开快捷键总览面板 |

## **高级技巧**

1. **钢笔工具进阶**：
   - 按住 `Ctrl` 拖动锚点可调整曲线手柄。
   - 按住 `Alt` 拖动锚点可打断手柄联动，独立调整单侧曲线。
2. **画布导航**：
   - 按住 `Cmd` + `,` 快速切换语言或设置。
   - 使用 `WASD` 键微调元素位置（需在设置中启用）。
3. **快捷键冲突**：
   - 若快捷键与系统冲突，可通过 `Cmd + ,` > **键盘快捷键** 自定义。

通过掌握这些快捷键，可大幅提升Figma的操作效率，减少鼠标点击次数，尤其适合复杂界面设计和原型制作场景。
