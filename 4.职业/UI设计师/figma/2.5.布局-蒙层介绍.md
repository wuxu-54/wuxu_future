# 蒙层

在Figma中，**蒙版（Mask）** 是一个非常重要的功能，它允许你通过一个形状来控制其下层内容的显示范围，非常适合用于创建圆形头像、特殊形状的图片裁剪等设计效果。下面这个表格汇总了Figma蒙版的核心信息，方便你快速了解：

| 特性维度 | 具体说明 |
| :--- | :--- |
| **核心概念** | 用一个形状（蒙版）控制其下方图层内容的显示与隐藏。 |
| **创建方法** | 1. **工具栏按钮**：选中形状，点击顶部工具栏的 **"Use as Mask"** 图标。<br>2. **右键菜单**：右键点击形状，选择 **"Use as Mask"**。<br>3. **快捷键**：选中形状后，使用 `Ctrl + Alt + M` (Windows) 或 `Cmd + Opt + M` (Mac)。 |
| **图层结构** | 创建后会自动生成一个**蒙版组（Mask Group）**，蒙版图层位于顶部，其下方的所有图层都会受其影响。 |
| **形状限制** | Figma蒙版本质上是**剪贴蒙版**，这意味着蒙版本身是一个矢量路径，不支持直接用图片作为蒙版。但你可以把图片填充到矢量形状里，再用这个形状去做蒙版。 |

## 🛠️ 蒙版使用技巧与场景

掌握蒙版的基础操作后，了解一些实用技巧能让你在设计时更加得心应手。

- **利用矢量工具进行精细抠图**：对于需要抠出非规则形状（如人物、物品）的场景，可以使用**钢笔工具**手动绘制出精确的轮廓路径，然后将这个路径用作蒙版。这种方法虽然对操作要求较高，但能实现最灵活的效果。

- **管理蒙版图层与透明度**：
  - **图层顺序至关重要**：在蒙版组中，确保需要显示的内容图层**位于蒙版图层的下方**。
  - **透明度控制**：蒙版图层的不透明度会影响其下方内容的可见度。**蒙版图层不透明度为0%的区域，其下方的内容将完全不可见**；不透明度为100%的区域，内容完全显示；介于之间的透明度会产生半透明的遮罩效果。

- **结合布尔运算创造复杂形状**：你可以先使用**布尔运算**（如合并、减去、排除等）将多个基本形状组合成一个复杂的图形，然后将这个复合图形用作蒙版，从而创造出独一无二的遮罩形状。

## 🔄 蒙版与填充图像的区别

需要注意的是，Figma中还有一种常见的操作是**直接将图片填充到形状里**。这与使用蒙版在视觉上可能相似，但原理不同：

- **蒙版**：是一个**图层关系**，蒙版形状和被遮罩的内容是独立的图层，可以分别编辑、移动或动画。
- **填充图像**：是形状的一个**属性**，图片被内嵌到形状内部，与形状融为一体。

**如何选择？**

- 如果你需要**独立编辑形状和图片**，或者一个形状要同时遮罩多个图层，请使用**蒙版**。
- 如果只是简单地将一张图片放入一个固定形状中，且不需要分开调整，使用**填充图像**更为便捷。

## 📌 实用建议

- **从源头规划**：在开始设计前，就构思好哪些部分可以使用蒙版，这有助于你更合理地组织图层结构。
- **活用布局网格辅助对齐**：在处理蒙版和内容的位置时，可以开启布局网格来辅助精准对齐。
- **注意嵌套层级**：在复杂的组件嵌套中，蒙版的效果可能会受到父级容器的影响，需要留意图层的绝对位置和相对位置。
