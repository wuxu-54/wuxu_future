# 约束布局

>Androi中xml的约束布局跟Figma的约束布局功能类似

## 1.介绍

Figma 中的 **约束布局** 是控制设计元素在不同屏幕尺寸或容器大小下如何自适应的重要工具，**约束决定了当父框架（Frame）的大小发生变化时，其内部的子元素应该如何响应——是保持与某一边的距离，还是进行缩放**。

| 特性维度 | 描述 |
| :--- | :--- |
| **核心作用** | 定义父 **Frame** 调整大小时，其内部子元素的响应方式。 |
| **约束对象** | 仅适用于 **Frame** 内的子元素，是子元素的属性。 |
| **设置位置** | 选中 Frame 内的子元素后，在右侧属性面板中找到 "Constraints"。 |
| **常见约束方式** | 水平方向：左、中、右、左右拉伸；垂直方向：上、中、下、上下拉伸。 |

## 2.💡 约束布局详解与技巧

主要的约束类型及其表现：

| **约束类型** | **表现（当父框架尺寸变化时）** | **适用场景举例** |
| :--- | :--- | :--- |
| **左/上 (Left/Top)** | 元素保持与父框架左/上边缘的固定距离。 | 需要固定在左上角的Logo或图标。 |
| **右/下 (Right/Bottom)** | 元素保持与父框架右/下边缘的固定距离。 | 需要固定在右下角的“返回顶部”按钮。 |
| **左右/上下 (Left & Right / Top & Bottom)** | 元素两侧被固定，宽度或高度会被拉伸或压缩。 | 需要随宽度自适应的一行输入框或按钮。 |
| **居中 (Center)** | 元素中心点始终与父框架中心点对齐。<br> （即使初始位置偏离父容器中心，缩放时，元素仍是按与中心的距离按比例进行移动。） <br> <br>元素位置计算公式：<br>元素X坐标 = (父框架宽度 - 元素宽度) ÷ 2<br>元素Y坐标 = (父框架高度 - 元素高度) ÷ 2| 页面中央的登录对话框。 |
| **缩放 (Scale)** | 元素与父框架**等比例**缩放（注意：此缩放是基于父框架的缩放，与直接拉伸元素不同）。 | 全屏背景图。 |

### 2.1.🔵 理解约束对象与方向

要使用约束，首先需要一个 **Frame** 作为容器，其内部的子元素（如按钮、文本、图标）才能设置约束。约束分为**水平**和**垂直**两个方向，你可以为子元素在这两个方向上独立设置不同的约束方式。

* **水平约束**：控制子元素在水平方向上如何定位或拉伸。常见选项有 **左 (Left)**、**居中 (Center)**、**右 (Right)** 和**左右拉伸 (Left and right)**。
* **垂直约束**：控制子元素在垂直方向上如何定位或拉伸。常见选项有 **顶 (Top)**、**居中 (Center)**、**底 (Bottom)** 和**上下拉伸 (Top and bottom)**。

通过组合水平和垂直的约束，你可以实现例如**左上固定**、**居中固定**、**水平拉伸垂直居中**等多种效果。

### 2.2.操作

**基本操作步骤**：

1. **创建 Frame** 并放入需要布局的元素。
2. 选中 Frame 内的**子元素**。
3. 在右侧属性面板的 "Constraints" 区域，根据你的布局需求，分别为其选择**水平**和**垂直**方向的约束方式。
4. **设置约束**：
    * 你会看到水平和垂直两个方向的控制器。
    * 点击图标可以选择不同的约束方式，如左、中、右、缩放（水平方向），以及上、中、下、缩放（垂直方向）。
    * 如果需要同时固定左右或上下两边，可以**按住 Shift 键并点击**另一侧的约束图标。

**实用技巧**：

* **测量间距**：在调整布局时，可以按住 `Alt` 键（Windows/Linux）或 `Option` 键 (Mac) 来测量元素间的距离，帮助更精确地设置约束。
* **缩放约束**：除了基本的定位和拉伸，你也可以为子元素设置**缩放 (Scale)** 约束。这样，当父 Frame 尺寸变化时，子元素会按比例进行缩放。

## 3.⚖️ 约束布局与自动布局

在 Figma 中，**约束布局** 和 **自动布局** 是两种不同的布局思路，理解它们的区别对选择合适的布局方式至关重要。

* **约束布局**：更像是给元素制定了相对于父容器某一边或中心的"吸附规则"。父容器变大变小时，元素会根据规则保持与某一边的距离，或者进行拉伸缩放。它更侧重于**元素与父容器边界**之间的关系。
* **自动布局**：则像一个智能的"排列盒子"，定义了内部元素排列的**方向**（水平或垂直）、**间距**和**对齐方式**。当内容增减或变化时，容器会自动调整尺寸并重新排列元素，更侧重于**容器内部元素彼此之间的关系**。

一个重要提示是：**当一个 Frame 应用了自动布局后，其内部子元素的约束设置将失效，布局将完全由自动布局的规则控制**。

### 3.1.💡 约束与自动布局：如何选择？

这是Figma中两个强大的布局工具，它们可以协同工作，但侧重点不同：

| **特性** | **约束 (Constraints)** | **自动布局 (Auto Layout)** |
| :--- | :--- | :--- |
| **核心思想** | **绝对关系**：子元素与父框架**某一边或中心**的位置关系。 | **相对流式**：子元素沿一个方向（水平/垂直）**顺序排列**，具有间距和对齐规则。 |
| **布局自由度** | 较高，子元素可以在父框架内**自由移动**。 | 较低，子元素必须遵循**方向排列**，无法自由定位。 |
| **适用场景** | 处理单个元素在容器内的定位，如将对话框固定在中央，或将角标定位在图标右上角。 | 创建具有内在排列规律的组件，如按钮、列表、导航栏等。 |

**协作技巧**：

* 你可以在一个**自动布局框架内部**的元素上再次使用**约束**，实现更精细的控制。
* 例如，一个水平自动布局的导航栏（自动布局），其内部的某个徽章（子元素）可以使用“右上”约束，使其始终定位在图标右上角，不受自动布局排列影响。

## 注意

1. 编组（Group）没有约束属性，不能作为整体进行约束配置，而是依据其子成员的约束进行处理。编组中的元素依据上一级的Frame进行约束。
2. Frame 有约束属性，可以设定对父Frame的约束。
3. 当一个 Frame 应用了自动布局后，其内部子元素的约束设置将失效，布局将完全由自动布局的规则控制，但Frame本身仍可以设定约束。
