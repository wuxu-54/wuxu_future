# Auto Layout

 **Auto Layout（自动布局）** 功能是 Figma 中最强大、最核心的功能之一，理解它对于创建高效、可维护的现代 UI 设计至关重要。

## 一、什么是 Auto Layout？

简单来说，Auto Layout 是一个可以**自动排列其内部元素的容器**。你只需定义好元素间的方向和间距，当内容（如文字长度、图片大小）发生变化，或当你调整框架本身的大小时，其内部的元素会自动重新排列，无需你手动逐个调整。

**一个生动的比喻：**
把 Auto Layout 想象成一个**智能的磁力盒子**。

- **盒子本身**就是 Auto Layout 框架。
- **盒子里的东西**就是里面的子元素（文本、图标、形状等）。
- **磁力方向**决定了东西是竖着堆叠还是横着排列。
- **磁力强度**决定了东西之间的间距。
- 当你往盒子里**增加或拿走一件东西**，或者**改变盒子大小**时，里面的所有东西都会根据你设定的磁力规则自动重新排好位置。

## 二、Auto Layout 的核心属性

在右侧的「设计」面板中，为选中的框架添加或调整 Auto Layout 时，你会看到以下几个核心控制项：

1. **方向**
    - **水平：** 内部元素从左到右排列。非常适合用于导航栏、按钮、标签列表。
    - **垂直：** 内部元素从上到下排列。非常适合用于列表、卡片内容、表单。

2. **间距**
    - 定义**相邻元素之间**的固定距离。当你增加或删除元素时，它们会保持这个间距。

3. **内边距**
    - 定义了 Auto Layout 框架的**内容区域**与**其边界**之间的空白。它就像是框架内部的“缓冲垫”。

4. **对齐方式**
    - 控制内部元素在**主轴**和**交叉轴**上的对齐方式。
    - **主轴**：与方向一致的轴（水平方向的主轴是水平的，垂直方向的主轴是垂直的）。
    - **交叉轴**：与方向垂直的轴。
    - **对齐选项**：`左上`、`居中`、`右下`、`空间 between`（两端对齐，元素间平均分布空间）。

5. **子元素的调整行为**
    - 这是最需要理解的部分，它决定了当父框架或相邻元素尺寸变化时，子元素如何响应。
    - **固定宽度/高度**：元素尺寸保持不变。
    - **填充容器**：元素在主轴方向上拉伸，填满所有可用空间。
    - **自动调整**：元素根据其内容（如文本长度）自动调整大小。这是文本层的默认行为。

## 三、使用 Auto Layout 的详细步骤与最佳实践

### 1. 创建基础组件（例如一个按钮）

1. 绘制一个圆角矩形，并输入文字 "Button"。
2. **同时选中**矩形和文字层。
3. 使用快捷键 `Shift + A`，或点击右侧面板顶部的 **「+」号 → Auto Layout**。
4. 现在你有了一个 Auto Layout 框架。调整其属性：
    - **方向**：水平（默认）
    - **内边距**：设置一个值（如 24/12），让文字和边框之间有舒适的空间。
    - **对齐**：水平和垂直方向都选择「居中」。
    - **间距**：如果按钮里有图标和文字，就在这里设置它们之间的距离。
5. 现在，尝试改变按钮上的文字，你会发现按钮的宽度会自动适应内容！

### 2. 构建复杂列表（嵌套 Auto Layout）

Auto Layout 的真正威力在于**嵌套使用**。

1. 创建一个**水平**的 Auto Layout 框架，里面放一个头像和一个文本层。这代表列表的一行。
2. 将文本层的宽度设置为 **「填充容器」**，这样它就能占据头像右侧的所有空间。
3. 现在，复制这个行框架 3-4 次。
4. **选中所有这些行框架**，再次应用 Auto Layout（`Shift + A`），但这次选择**垂直**方向。
5. 现在，你得到了一个完整的列表！调整外层垂直框架的宽度，所有行都会统一调整。

## 四、重要注意事项与常见陷阱

1. **过度嵌套与性能**
    - **问题**：为了达到某种布局效果，可能会创建过多层级的 Auto Layout 框架，导致文件变得臃肿，在复杂原型中可能影响性能。
    - **解决**：时刻思考是否有更简单的结构。有时，使用「网格」或简单的「约束」可能比嵌套 Auto Layout 更合适。

2. **「绝对定位」的使用场景**
    - 在 Auto Layout 框架内，你可以将任何一个子元素设置为「绝对定位」。它会被从流式布局中“拎出来”，可以自由放置在框架内的任何位置，不再受间距和对齐的约束。
    - **使用场景**：徽章（Badge）、浮动操作按钮、对话框的关闭按钮等需要脱离文档流的元素。

3. **正确理解「拉伸」与「自动调整」**
    - 当你的 Auto Layout 框架里有多个子元素时，必须清楚地知道哪个元素应该「填充容器」来占据剩余空间，哪个元素应该保持「自动调整」或「固定尺寸」。
    - **常见错误**：希望一个图标和一段文本在卡片中左右对齐，但却忘了将文本层的宽度设置为「填充容器」，导致它无法被推到右边。

4. **文本基线对齐**
    - 在水平 Auto Layout 中，如果包含不同字号的文本或图标，对齐可能会看起来不协调。
    - **解决**：使用「对齐」选项中的「基线对齐」，它会让所有文本元素基于文字基线对齐，而不是它们的容器框，视觉上会更舒适。

5. **与「约束」的混淆**
    - **Auto Layout** 控制的是**框架内部元素之间的关系**。
    - **约束** 控制的是**单个图层与其父级框架（该框架没有 Auto Layout）之间的关系**，当父级框架在不同画板或响应式布局中调整大小时。
    - **关键点**：当一个框架应用了 Auto Layout 后，其内部子元素的「约束」设置将**失效**，因为布局完全由 Auto Layout 规则控制。

6. **裁切内容**
    - 如果启用了「裁切内容」，任何超出 Auto Layout 框架边界的子元素都将被隐藏。这在创建标签页、轮播图等组件时非常有用。

## 总结

Auto Layout 是现代 UI 设计的基石。要掌握它，请记住以下几点：

- **从简单开始**：先从一个按钮或一个列表项练起。
- **理解「方向」和「对齐」**：这是布局的骨架。
- **善用「填充容器」和「自动调整」**：这是实现响应式行为的肌肉。
- **敢于嵌套**：但也要时刻审视是否有更简洁的方案。
- **勤加练习**：多在真实项目中应用，遇到问题就去调试各个属性，这是最快的学习路径。

一旦你熟练掌握了 Auto Layout，你会发现创建一致、灵活且易于维护的 UI 组件（如按钮、导航、列表、卡片）将变得无比高效。
