# Stream

## 一、Stream 核心概念

Java 8 引入的 `Stream` 是处理集合（Collection）的**抽象工具**，它不是数据结构，也不存储数据，而是对数据源（集合、数组、I/O 等）进行一系列**流水线式操作**的管道。

### 核心特点

1. **不存储数据**：仅封装对数据源的操作，数据仍存储在原数据源中。
2. **不可变**：所有中间操作都会返回一个**新的流**，不会修改原流或原数据源。
3. **惰性求值**：中间操作不会立即执行，只有触发**终端操作**时，整个流管道才会执行（延迟执行）。
4. **一次性消费**：流只能被消费一次（执行终端操作后即失效），重复使用会抛出 `IllegalStateException`。
5. **并行友好**：支持串行/并行切换，并行流基于 Fork/Join 框架实现数据分片处理。

### Stream 操作流程

```
数据源 → 中间操作（0或多个） → 终端操作（1个）
```

- 中间操作：筛选、映射、排序等，返回新流（惰性）；
- 终端操作：遍历、聚合、查找等，触发流执行并返回最终结果（非惰性）。

## 二、Stream 的创建

Stream 的数据源可以是集合、数组、文件、甚至无限序列，以下是所有常见的创建方式：

### 1. 从集合创建（最常用）

所有实现 `Collection` 接口的类（List、Set、Queue 等）都有 `stream()`（串行）和 `parallelStream()`（并行）方法：

```java
import java.util.ArrayList;
import java.util.List;
import java.util.stream.Stream;

public class StreamCreateDemo {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        list.add("Java");
        list.add("Python");
        list.add("Go");

        // 串行流
        Stream<String> serialStream = list.stream();
        // 并行流
        Stream<String> parallelStream = list.parallelStream();
    }
}
```

### 2. 从数组创建

通过 `Arrays.stream()` 或 `Stream.of()`（底层也是调用 `Arrays.stream()`）：

```java
import java.util.Arrays;
import java.util.stream.IntStream;
import java.util.stream.Stream;

public class StreamCreateDemo {
    public static void main(String[] args) {
        // 1. 对象数组
        String[] arr = {"a", "b", "c"};
        Stream<String> stream1 = Arrays.stream(arr);
        Stream<String> stream2 = Stream.of(arr); // 等价于上面

        // 2. 基本类型数组（推荐用 IntStream/LongStream/DoubleStream 避免装箱）
        int[] intArr = {1, 2, 3};
        IntStream intStream = Arrays.stream(intArr);
    }
}
```

### 3. 创建空流

避免返回 `null` 导致空指针，推荐用 `Stream.empty()`：

```java
Stream<String> emptyStream = Stream.empty();
```

### 4. 创建无限流

通过 `generate()`（生成无状态的元素）或 `iterate()`（生成有状态的元素），需配合 `limit()` 限制长度：

```java
import java.util.Random;
import java.util.stream.Stream;

public class StreamCreateDemo {
    public static void main(String[] args) {
        // 1. generate()：生成随机数（无状态，每次生成独立）
        Stream<Double> randomStream = Stream.generate(Math::random)
                                           .limit(3); // 限制只生成3个
        randomStream.forEach(System.out::println);

        // 2. iterate()：生成递增序列（有状态，基于前一个元素生成）
        Stream<Integer> numStream = Stream.iterate(0, n -> n + 2)
                                         .limit(5); // 0,2,4,6,8
        numStream.forEach(System.out::println);
    }
}
```

### 5. 从文件/IO 创建

`Files.lines()` 读取文件的每一行作为流元素：

```java
import java.nio.file.Files;
import java.nio.file.Paths;
import java.util.stream.Stream;

public class StreamCreateDemo {
    public static void main(String[] args) {
        try (Stream<String> lines = Files.lines(Paths.get("test.txt"))) {
            lines.forEach(System.out::println); // 打印文件每一行
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

### 6. 基本类型专用流

为避免自动装箱/拆箱的性能损耗，Java 提供了 `IntStream`、`LongStream`、`DoubleStream`（无 `ShortStream`/`ByteStream`，可通过 `mapToInt` 转换）：

```java
import java.util.stream.IntStream;

public class StreamCreateDemo {
    public static void main(String[] args) {
        // 直接创建 1-5 的IntStream
        IntStream rangeStream = IntStream.range(1, 6); // 左闭右开：1,2,3,4,5
        IntStream rangeClosedStream = IntStream.rangeClosed(1, 5); // 左闭右闭：1,2,3,4,5
    }
}
```

## 三、中间操作（Intermediate Operations）

中间操作返回新的流，且**不立即执行**，需等待终端操作触发。分为两类：

- **无状态操作**：处理元素时不依赖其他元素（如 filter、map）；
- **有状态操作**：处理元素时依赖其他元素（如 sorted、distinct、limit）。

### 1. 筛选操作

| 方法 | 作用 | 示例 |
|------|------|------|
| `filter(Predicate)` | 过滤符合条件的元素 | `stream.filter(s -> s.length() > 2)` |
| `distinct()` | 去重（基于 `equals()`） | `stream.distinct()` |
| `limit(long n)` | 截取前 n 个元素 | `stream.limit(3)` |
| `skip(long n)` | 跳过前 n 个元素 | `stream.skip(2)` |

示例代码：

```java
import java.util.Arrays;
import java.util.stream.Stream;

public class StreamIntermediateDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"a", "b", "a", "c", "d", "e"});
        
        stream.filter(s -> s.compareTo("b") > 0) // 筛选大于"b"的元素：c,d,e
              .distinct() // 去重（此处无重复）
              .skip(1)    // 跳过第一个：d,e
              .limit(1)   // 截取第一个：d
              .forEach(System.out::println); // 输出：d
    }
}
```

### 2. 映射操作

将流中的元素转换为另一种类型，核心是 `map` 和 `flatMap`。

| 方法 | 作用 | 示例 |
|------|------|------|
| `map(Function)` | 一对一转换 | `stream.map(String::length)` |
| `flatMap(Function)` | 一对多转换（扁平化） | `stream.flatMap(s -> Arrays.stream(s.split("")))` |
| `mapToInt/Long/Double` | 转换为基本类型流 | `stream.mapToInt(String::length)` |

示例 1：map（一对一转换）

```java
import java.util.Arrays;
import java.util.stream.Stream;

public class StreamIntermediateDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"Java", "Python", "Go"});
        // 将字符串转换为长度
        stream.map(String::length)
              .forEach(System.out::println); // 输出：4,6,2
    }
}
```

示例 2：flatMap（扁平化，解决“流中流”问题）

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Stream;

public class StreamIntermediateDemo {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("a,b,c", "d,e,f");
        // 需求：将每个字符串按逗号分割，最终得到 [a,b,c,d,e,f]
        Stream<String> stream = list.stream()
                                    .flatMap(s -> Arrays.stream(s.split(","))); // 扁平化
        stream.forEach(System.out::println); // 输出：a,b,c,d,e,f
    }
}
```

### 3. 排序操作

| 方法 | 作用 | 示例 |
|------|------|------|
| `sorted()` | 自然排序（元素需实现 `Comparable`） | `stream.sorted()` |
| `sorted(Comparator)` | 定制排序 | `stream.sorted(Comparator.comparing(String::length).reversed())` |

示例：

```java
import java.util.Arrays;
import java.util.Comparator;
import java.util.stream.Stream;

public class StreamIntermediateDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"Java", "Python", "Go"});
        // 按字符串长度降序排序
        stream.sorted(Comparator.comparing(String::length).reversed())
              .forEach(System.out::println); // 输出：Python,Java,Go
    }
}
```

### 4. 调试操作：peek()

`peek(Consumer)` 用于调试，可在中间操作中打印元素（不改变元素），常用来追踪流的处理过程：

```java
import java.util.Arrays;
import java.util.stream.Stream;

public class StreamIntermediateDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"Java", "Python", "Go"});
        stream.peek(s -> System.out.println("原始元素：" + s))
              .map(String::length)
              .peek(len -> System.out.println("转换后长度：" + len))
              .forEach(len -> System.out.println("最终输出：" + len));
    }
}
// 输出：
// 原始元素：Java
// 转换后长度：4
// 最终输出：4
// 原始元素：Python
// 转换后长度：6
// 最终输出：6
// 原始元素：Go
// 转换后长度：2
// 最终输出：2
```

## 四、终端操作（Terminal Operations）

终端操作触发流的执行，并返回最终结果（流执行后失效）。分为两类：

- **非短路操作**：需处理所有元素（如 forEach、collect）；
- **短路操作**：满足条件后立即停止（如 findFirst、anyMatch）。

### 1. 遍历操作

| 方法 | 作用 | 区别 |
|------|------|------|
| `forEach(Consumer)` | 遍历元素（并行流中顺序不确定） | 不保证顺序 |
| `forEachOrdered(Consumer)` | 按数据源顺序遍历（并行流中也保证） | 保证顺序，但牺牲并行性能 |

示例：

```java
import java.util.Arrays;
import java.util.stream.Stream;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"a", "b", "c"}).parallel();
        // 并行流中 forEach 顺序不确定
        stream.forEach(System.out::print); // 可能输出：bca 或 acb 等
        // 并行流中 forEachOrdered 保证顺序
        Stream<String> stream2 = Arrays.stream(new String[]{"a", "b", "c"}).parallel();
        stream2.forEachOrdered(System.out::print); // 必输出：abc
    }
}
```

### 2. 聚合操作（核心）

#### （1）`reduce()`：归约

将流中的元素逐步聚合为一个值，有三个重载版本：

- `reduce(T identity, BinaryOperator<T>)`：带初始值，返回 T；
- `reduce(BinaryOperator<T>)`：无初始值，返回 `Optional<T>`；
- `reduce(U identity, BiFunction<U,T,U>, BinaryOperator<U>)`：并行流专用（合并结果）。

示例：

```java
import java.util.Arrays;
import java.util.Optional;
import java.util.stream.Stream;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        Stream<Integer> stream = Arrays.stream(new Integer[]{1, 2, 3, 4});
        
        // 1. 带初始值（求和：0+1+2+3+4=10）
        Integer sum1 = stream.reduce(0, Integer::sum);
        System.out.println(sum1); // 输出：10
        
        // 2. 无初始值（求最大值）
        Stream<Integer> stream2 = Arrays.stream(new Integer[]{1, 2, 3, 4});
        Optional<Integer> max = stream2.reduce(Integer::max);
        max.ifPresent(System.out::println); // 输出：4
    }
}
```

#### （2）`collect()`：收集（最常用）

将流转换为集合、字符串等，核心是 `Collectors` 工具类，提供了大量预定义收集器。

| 常用 Collectors 方法 | 作用 | 示例 |
|----------------------|------|------|
| `toList()` | 转换为 List | `stream.collect(Collectors.toList())` |
| `toSet()` | 转换为 Set | `stream.collect(Collectors.toSet())` |
| `toMap(Function, Function)` | 转换为 Map | `stream.collect(Collectors.toMap(s -> s, String::length))` |
| `joining()` | 拼接字符串 | `stream.collect(Collectors.joining(","))` |
| `groupingBy(Function)` | 分组 | `stream.collect(Collectors.groupingBy(String::length))` |
| `partitioningBy(Predicate)` | 分区（分为两组：true/false） | `stream.collect(Collectors.partitioningBy(s -> s.length()>2))` |
| `summarizingInt/Long/Double` | 统计（计数、求和、平均、最大、最小） | `stream.collect(Collectors.summarizingInt(String::length))` |

示例 1：转换为集合

```java
import java.util.Arrays;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.stream.Collectors;
import java.util.stream.Stream;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"a", "b", "c", "a"});
        
        // 转换为 List
        List<String> list = stream.collect(Collectors.toList());
        System.out.println(list); // 输出：[a, b, c, a]
        
        // 转换为 Set（去重）
        Stream<String> stream2 = Arrays.stream(new String[]{"a", "b", "c", "a"});
        Set<String> set = stream2.collect(Collectors.toSet());
        System.out.println(set); // 输出：[a, b, c]
        
        // 转换为 Map（键：字符串，值：长度）
        Stream<String> stream3 = Arrays.stream(new String[]{"a", "b", "c"});
        Map<String, Integer> map = stream3.collect(Collectors.toMap(s -> s, String::length));
        System.out.println(map); // 输出：{a=1, b=1, c=1}
    }
}
```

示例 2：分组/分区

```java
import java.util.Arrays;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("Java", "Python", "Go", "C++", "JavaScript");
        
        // 1. 分组：按字符串长度分组
        Map<Integer, List<String>> groupByLen = list.stream()
                .collect(Collectors.groupingBy(String::length));
        System.out.println(groupByLen);
        // 输出：{2=[Go], 3=[C++], 4=[Java], 6=[Python], 10=[JavaScript]}
        
        // 2. 分区：按长度是否大于3分为两组
        Map<Boolean, List<String>> partitionByLen = list.stream()
                .collect(Collectors.partitioningBy(s -> s.length() > 3));
        System.out.println(partitionByLen);
        // 输出：{false=[Go, C++], true=[Java, Python, JavaScript]}
    }
}
```

示例 3：拼接字符串

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("Java", "Python", "Go");
        
        // 直接拼接
        String str1 = list.stream().collect(Collectors.joining());
        System.out.println(str1); // 输出：JavaPythonGo
        
        // 用逗号分隔
        String str2 = list.stream().collect(Collectors.joining(","));
        System.out.println(str2); // 输出：Java,Python,Go
        
        // 带前缀、分隔符、后缀
        String str3 = list.stream().collect(Collectors.joining(", ", "[", "]"));
        System.out.println(str3); // 输出：[Java, Python, Go]
    }
}
```

### 3. 查找与匹配

| 方法 | 作用 | 返回值 | 短路性 |
|------|------|--------|--------|
| `findFirst()` | 找第一个元素 | `Optional<T>` | 是 |
| `findAny()` | 找任意元素（并行流中效率更高） | `Optional<T>` | 是 |
| `anyMatch(Predicate)` | 是否存在符合条件的元素 | `boolean` | 是 |
| `allMatch(Predicate)` | 是否所有元素都符合条件 | `boolean` | 是 |
| `noneMatch(Predicate)` | 是否没有元素符合条件 | `boolean` | 是 |

示例：

```java
import java.util.Arrays;
import java.util.Optional;
import java.util.stream.Stream;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"Java", "Python", "Go"});
        
        // 1. 查找
        Optional<String> first = stream.findFirst();
        first.ifPresent(s -> System.out.println("第一个元素：" + s)); // 输出：Java
        
        // 2. 匹配
        Stream<String> stream2 = Arrays.stream(new String[]{"Java", "Python", "Go"});
        boolean hasLongStr = stream2.anyMatch(s -> s.length() > 5);
        System.out.println("是否有长度>5的元素：" + hasLongStr); // 输出：true
        
        Stream<String> stream3 = Arrays.stream(new String[]{"Java", "Python", "Go"});
        boolean allShortStr = stream3.allMatch(s -> s.length() < 10);
        System.out.println("是否所有元素长度<10：" + allShortStr); // 输出：true
    }
}
```

### 4. 统计操作

基本类型流（IntStream/LongStream/DoubleStream）提供了直接的统计方法，对象流需先转换为基本类型流：

```java
import java.util.Arrays;
import java.util.IntSummaryStatistics;
import java.util.stream.IntStream;

public class StreamTerminalDemo {
    public static void main(String[] args) {
        IntStream stream = Arrays.stream(new int[]{1, 2, 3, 4, 5});
        
        // 单个统计
        long count = stream.count(); // 计数：5
        stream = Arrays.stream(new int[]{1, 2, 3, 4, 5});
        int sum = stream.sum(); // 求和：15
        stream = Arrays.stream(new int[]{1, 2, 3, 4, 5});
        double avg = stream.average().getAsDouble(); // 平均值：3.0
        stream = Arrays.stream(new int[]{1, 2, 3, 4, 5});
        int max = stream.max().getAsInt(); // 最大值：5
        
        // 批量统计（一次获取所有统计信息）
        IntStream stream2 = Arrays.stream(new int[]{1, 2, 3, 4, 5});
        IntSummaryStatistics stats = stream2.summaryStatistics();
        System.out.println("计数：" + stats.getCount()); // 5
        System.out.println("求和：" + stats.getSum()); // 15
        System.out.println("平均值：" + stats.getAverage()); // 3.0
        System.out.println("最大值：" + stats.getMax()); // 5
        System.out.println("最小值：" + stats.getMin()); // 1
    }
}
```

### 5. 转换为数组

`toArray()`：将流转换为数组，有两个重载版本：

## 五、并行流（Parallel Stream）

### 1. 什么是并行流

并行流是将流的操作分配到多个线程执行的流，底层基于 `ForkJoinPool.commonPool()`（默认线程数 = CPU 核心数 - 1）。

### 2. 创建并行流

```java
import java.util.Arrays;
import java.util.List;

public class ParallelStreamDemo {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("a", "b", "c");
        
        // 方式1：直接创建
        list.parallelStream().forEach(System.out::print);
        
        // 方式2：将串行流转为并行流
        list.stream().parallel().forEach(System.out::print);
    }
}
```

### 3. 并行流的注意事项

1. **线程安全**：避免在并行流的 lambda 中操作**共享可变状态**（如全局集合、计数器），否则会导致数据错乱。
   ❌ 错误示例：

   ```java
   import java.util.ArrayList;
   import java.util.Arrays;
   import java.util.List;

   public class ParallelStreamDemo {
       public static void main(String[] args) {
           List<Integer> list = new ArrayList<>();
           // 并行流操作共享集合，会导致数据丢失/重复
           Arrays.stream(new int[]{1,2,3,4,5})
                 .parallel()
                 .forEach(list::add);
           System.out.println(list.size()); // 可能不是5
       }
   }
   ```

   ✅ 正确示例（用 collect 替代）：

   ```java
   List<Integer> list = Arrays.stream(new int[]{1,2,3,4,5})
                             .parallel()
                             .boxed()
                             .collect(Collectors.toList());
   ```

2. **性能考量**：
   - 小数据量：并行流的线程切换开销 > 并行收益，推荐用串行流；
   - 大数据量/计算密集型任务：并行流优势明显；
   - I/O 密集型任务：不推荐（线程会阻塞，浪费资源）。

3. **有序性**：并行流的 `forEach` 不保证顺序，若需顺序，用 `forEachOrdered`（但会牺牲并行性能）。

## 六、Stream 高级用法

### 1. 自定义收集器

实现 `Collector` 接口，自定义收集逻辑（四个核心方法：supplier、accumulator、combiner、finisher）。

示例：自定义收集器，将流转换为不可变 List

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Set;
import java.util.function.BiConsumer;
import java.util.function.BinaryOperator;
import java.util.function.Function;
import java.util.function.Supplier;
import java.util.stream.Collector;
import java.util.stream.Stream;

// 自定义收集器：不可变List收集器
class ImmutableListCollector<T> implements Collector<T, List<T>, List<T>> {
    // 1. 提供容器：创建空List
    @Override
    public Supplier<List<T>> supplier() {
        return ArrayList::new;
    }

    // 2. 累加器：将元素添加到容器
    @Override
    public BiConsumer<List<T>, T> accumulator() {
        return List::add;
    }

    // 3. 组合器：并行流中合并多个容器（必须线程安全）
    @Override
    public BinaryOperator<List<T>> combiner() {
        return (list1, list2) -> {
            list1.addAll(list2);
            return list1;
        };
    }

    // 4. 完成器：将容器转换为最终结果（不可变List）
    @Override
    public Function<List<T>, List<T>> finisher() {
        return Collections::unmodifiableList;
    }

    // 5. 特征：标识收集器的特性
    @Override
    public Set<Characteristics> characteristics() {
        return Set.of(Characteristics.CONCURRENT, Characteristics.UNORDERED);
    }
}

public class CustomCollectorDemo {
    public static void main(String[] args) {
        Stream<String> stream = Stream.of("a", "b", "c");
        List<String> immutableList = stream.collect(new ImmutableListCollector<>());
        // immutableList.add("d"); // 抛出 UnsupportedOperationException
        System.out.println(immutableList); // 输出：[a, b, c]
    }
}
```

### 2. Optional 与 Stream 结合

Stream 的 `findFirst()`、`findAny()`、`max()`、`min()` 等方法返回 `Optional`，避免空指针：

```java
import java.util.Arrays;
import java.util.Optional;
import java.util.stream.Stream;

public class StreamOptionalDemo {
    public static void main(String[] args) {
        Stream<String> stream = Arrays.stream(new String[]{"a", "b", "c"});
        Optional<String> optional = stream.filter(s -> s.equals("d")).findFirst();
        
        // 安全取值方式1：ifPresent
        optional.ifPresent(System.out::println); // 无输出（未找到）
        
        // 安全取值方式2：orElse
        String str = optional.orElse("默认值");
        System.out.println(str); // 输出：默认值
        
        // 安全取值方式3：orElseGet（懒加载，性能更好）
        String str2 = optional.orElseGet(() -> "懒加载默认值");
        System.out.println(str2); // 输出：懒加载默认值
        
        // 安全取值方式4：orElseThrow（抛异常）
        // String str3 = optional.orElseThrow(() -> new RuntimeException("未找到元素"));
    }
}
```

## 七、Stream 注意事项

1. **流只能消费一次**：执行终端操作后，流即失效，重复使用会抛出 `IllegalStateException`；
2. **中间操作惰性**：没有终端操作时，中间操作不会执行（比如只调用 `filter` 不调用 `forEach`，不会有任何效果）；
3. **数据源快照**：流操作的是数据源在终端操作启动时的快照（除了实时数据源如 I/O 流），终端操作执行期间修改数据源，不会影响流的处理；
4. **避免副作用**：尽量不要在 lambda 中修改外部变量（尤其是并行流），遵循“纯函数”原则；
5. **基本类型流优先**：处理 int/long/double 时，用 `IntStream` 等替代 `Stream<Integer>`，避免装箱/拆箱损耗。

---

### 总结

1. **核心特性**：Stream 是处理集合的流水线工具，具有**不存储数据、不可变、惰性求值、一次性消费**的特点；
2. **操作流程**：数据源 → 中间操作（筛选/映射/排序等，惰性） → 终端操作（遍历/聚合/查找等，触发执行）；
3. **关键技巧**：
   - 用 `collect()` 实现流到集合/字符串的转换，`Collectors` 提供丰富的预定义收集器；
   - 并行流适合大数据量/计算密集型任务，需注意线程安全；
   - 基本类型流（IntStream）避免装箱损耗，`Optional` 避免空指针。
