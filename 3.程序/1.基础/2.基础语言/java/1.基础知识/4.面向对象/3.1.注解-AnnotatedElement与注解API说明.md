# Java 注解完整全套详解（元注解+内置注解+反射API+重复注解+面试全集）

## 一、注解本质

注解（Annotation）是 **Java 的标记式元数据**，用于给类、方法、字段、参数等程序元素附加额外信息。

特点：

- 本身**不执行业务逻辑**，仅做标记、存储参数

- 需要 **编译器 / 框架 / 反射** 解析才生效

- 替代繁杂的 XML 配置，实现 **配置即代码**

## 二、四种元注解（用来定义自定义注解的注解）

### 1. @Target（限定注解作用位置）

指定该自定义注解**只能标记在哪些程序元素上**。

常用取值：

- `ElementType.TYPE`：类、接口、枚举

- `ElementType.FIELD`：成员字段

- `ElementType.METHOD`：方法

- `ElementType.PARAMETER`：方法参数

- `ElementType.CONSTRUCTOR`：构造器

### 2. @Retention（限定注解生命周期）

- `RetentionPolicy.SOURCE`：仅源码阶段，编译后丢弃（如 @Override）

- `RetentionPolicy.CLASS`：保留到 class 文件，运行时丢失（默认级别）

- `RetentionPolicy.RUNTIME`：运行时保留，**可通过反射获取**（自定义注解必须这个级别）

### 3. @Inherited（注解继承）

被该元注解标记的注解，**子类可以继承父类上的该注解**。

关键限制：**仅对 Class 有效！方法、字段、参数完全不生效**。

### 4. @Documented（生成文档）

使用该注解的元素，在生成 JavaDoc 文档时会保留注解信息。

### 拓展：Java8 新增两大元注解

#### ① @Repeatable（重复注解）

允许同一个元素上 **多次标注同一个注解**，底层依赖容器注解存储。

#### ② @Native

标记本地方法（native），几乎不用。

## 三、JDK 内置常用注解

- **@Override**：校验方法重写合法性，仅源码有效

- **@Deprecated**：标记过期废弃方法/类

- **@SuppressWarnings**：压制编译器警告

- **@FunctionalInterface**：标记函数式接口

## 四、自定义注解语法

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface MyAnnot {
    String value() default "";
    int num() default 0;
}

```

规则：

- 使用 `@interface` 定义

- 内部定义的是**注解属性**，不是方法

- 带 `value` 属性，使用时可省略属性名

## 五、核心顶层接口：AnnotatedElement（所有注解反射的根基）

**Class、Method、Field、Constructor、Parameter** 全部实现该接口。

所有注解读取、判断，全部依赖下面 **7 个官方完整API**（含源码签名+精准特性）。

### 1. isAnnotationPresent

**完整源码签名**

```java
boolean isAnnotationPresent(Class<? extends Annotation> annotationClass);
```

**作用**：判断当前元素是否存在指定注解。

**特性**：

- 支持读取 `@Inherited` 父类继承注解

- **不支持重复注解**，遇到 @Repeatable 容器注解直接返回 false

### 2. getAnnotation

**完整源码签名**

```java
<T extends Annotation> T getAnnotation(Class<T> annotationClass);
```

**作用**：获取单个指定注解，无则返回 null。

**特性**：

- 支持 `@Inherited` 继承注解

- **不支持重复注解**，无法解析容器，只能获取单个注解

### 3. getAnnotations

**完整源码签名**

```java
Annotation[] getAnnotations();
```

**作用**：获取当前元素**所有有效注解**（自身+继承）。

**特性**：

- 包含自身注解 + 父类继承注解

- 重复注解只会返回**原始容器注解**，不会拆解

### 4. getAnnotationsByType（最强通用API）

**完整源码签名**

```java
<T extends Annotation> T[] getAnnotationsByType(Class<T> annotationClass);
```

**作用**：获取指定类型的**全部注解数组**。

**特性**：

- 支持 `@Inherited` 父类继承

- **完美支持重复注解**，自动拆解容器，返回所有真实注解

- 无注解返回空数组，永不返回 null

---

**以下三个带 Declared：只读取当前元素「自己声明」的注解，完全忽略父类继承**

---

### 5. getDeclaredAnnotation

**完整源码签名**

```java
<T extends Annotation> T getDeclaredAnnotation(Class<T> annotationClass);
```

**作用**：获取当前元素直接声明的指定注解。

**特性**：

- **忽略所有继承注解**

- 不支持重复注解解析

- 无则返回 null

### 6. getDeclaredAnnotationsByType

**完整源码签名**

```java
<T extends Annotation> T[] getDeclaredAnnotationsByType(Class<T> annotationClass);
```

**作用**：获取当前元素直接声明的、指定类型所有注解。

**特性**：

- 忽略父类继承

- 支持重复注解、自动拆容器

### 7. getDeclaredAnnotations

**完整源码签名**

```java
Annotation[] getDeclaredAnnotations();
```

**作用**：获取当前元素直接声明的全部注解。

**特性**：

- 完全忽略继承注解

- 重复注解返回原始容器，不拆解

## 六、注解核心规律（必背，解决所有混淆）

1. **带 Declared**：只看自己，**不继承父类注解**

2. **不带 Declared**：支持 **@Inherited 父类注解继承**

3. **带 ByType**：支持 **Java8 重复注解拆容器**

4. **不带 ByType**：不识别重复注解，重复场景全部失效

## 七、高频面试坑点总结

- **@Inherited 只对类生效**，方法、字段、参数无法继承注解

- **重复注解必须用 XxxByType 读取**，普通 getAnnotation 读不到

- 自定义注解必须 `@Retention(RUNTIME)`，否则反射拿不到

- getAnnotationsByType 是开发首选：兼顾继承 + 重复注解 + 空安全

- Declared 系列用于：**只需要当前元素自身注解**的场景
