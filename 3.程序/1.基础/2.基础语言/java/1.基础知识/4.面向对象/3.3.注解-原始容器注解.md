# 一句话搞懂：**原始容器注解**

Java8 **重复注解**底层不允许直接存多个相同注解，编译器会**自动把多个相同注解打包进一个「容器注解」**，这个打包后的注解 = **原始容器**。

## 1. 完整示例（秒懂）

### 1）定义可重复注解 + 容器注解

```java
// 容器注解（专门用来打包）
@interface MyContainer {
    MyAnnot[] value();
}

// 可重复注解
@Repeatable(MyContainer.class)
@interface MyAnnot {}
```

### 2）使用重复注解

```java
@MyAnnot
@MyAnnot
public class Demo{}
```

### 3）编译后**真实存储形态**（原始容器）

```java
@MyContainer( value = {@MyAnnot, @MyAnnot} )
```

## 2. 关键结论

1. **源码写的是2个MyAnnot**
2. **编译后JVM只存1个MyContainer（原始容器）**
3. 普通API看不到里面的真实注解：

- `getAnnotation()` / `getAnnotations()`：**只能拿到外层 MyContainer 容器**，拿不到内部 MyAnnot
- `getAnnotationsByType()`：**自动拆容器**，返回内部两个真实 `@MyAnnot`

## 3. 对应你之前的笔记坑点

- **getAnnotations() / getDeclaredAnnotations()** 返回的就是**原始容器注解**（没拆包）
- **xxxByType()** 自动拆解原始容器，取出内部真实注解

## 极简背诵
>
> 重复注解编译后**不会并存多个**，只会被打包进**容器注解（原始容器）**；
> 普通API读容器，ByType API拆容器。
