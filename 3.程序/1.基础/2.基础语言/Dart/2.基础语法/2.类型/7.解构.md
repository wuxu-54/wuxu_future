# Dart 解构语法详解

Dart 从 **3.0 版本** 开始，伴随「模式匹配（Patterns）」特性正式支持完整的解构能力。解构的核心作用是：将复合数据结构（记录、列表、Map、类对象等）中的数据，一次性拆分并赋值给多个独立变量，大幅简化数据提取的代码。

---

## 一、核心解构类型

### 1. 记录（Record）解构

Record 是 Dart 3.0 新增的匿名聚合类型，分为**位置记录**和**命名记录**，解构语法对应两种形式。

#### （1）位置记录解构

按位置顺序提取值，变量数量必须与记录字段数完全匹配，数量不匹配会直接触发编译错误。

```dart
// 基础用法：自动推断类型
var (a, b, c) = (1, 'hello', true);
print(a); // 1
print(b); // hello
print(c); // true

// 显式指定每个字段的类型
(int id, String name, bool isActive) = (101, 'Dart', false);

// 配合 final/const 声明常量
final (x, y) = (3.14, 2.718);
const (pi, e) = (3.14159, 2.71828);
```

#### （2）命名记录解构

按字段名提取值，支持「同名简写」和「重命名」两种写法：

```dart
var point = (x: 10, y: 20, label: 'origin');

// 写法1：同名简写（变量名 = 字段名），格式为 :字段名
var (:x, :y, :label) = point;

// 写法2：重命名（自定义变量名），格式为 字段名: 变量名
var (x: px, y: py, label: pointLabel) = point;
print(px);        // 10
print(pointLabel);// origin
```

> 注意：位置记录与命名记录结构不互通，解构形式必须与记录类型严格对应。

---

### 2. 列表（List）解构

按索引顺序提取列表元素，支持忽略元素、剩余元素收集和嵌套解构。

#### （1）基础用法

```dart
var [first, second, third] = [1, 2, 3];
print(first); // 1

// 显式指定元素类型
var [String a, int b] = ['apple', 100];
```

#### （2）忽略元素：下划线 `_`

不需要的位置用 `_` 占位，不会创建实际变量，支持连续忽略多个值：

```dart
var [name, _, age] = ['Alice', 'female', 25];
// 仅创建 name 和 age 变量，第二个元素被丢弃
```

#### （3）剩余元素：Rest 模式 `...`

用 `...变量名` 收集剩余的所有元素到一个新列表。**单个解构中只能有一个 rest**，可放在开头、中间或结尾：

```dart
var nums = [1, 2, 3, 4, 5];

// rest 在结尾
var [first, ...rest] = nums;
print(first); // 1
print(rest);  // [2, 3, 4, 5]

// rest 在开头
var [...head, last] = nums;
print(last); // 5
print(head); // [1, 2, 3, 4]

// rest 在中间
var [a, ...mid, z] = nums;
print(mid); // [2, 3, 4]
```

### 3. Map 解构

按键名提取 Map 中的值，键名必须与 Map 中的键对应。

#### （1）基础用法

```dart
var user = {'name': 'Bob', 'age': 30, 'city': 'Beijing'};

var {'name': userName, 'age': userAge, 'city': userCity} = user;
print(userName); // Bob
print(userAge);  // 30
```

#### （2）默认值：`??`

如果解构的键在 Map 中不存在，默认会抛出运行时错误；可以通过 `??` 设置默认值兜底：

```dart
var {'name': name, 'gender': gender ?? 'unknown'} = {'name': 'Tom'};
print(name);   // Tom
print(gender); // unknown（键不存在，使用默认值）
```

> 注意：Map 解构没有「同名简写」语法，必须明确写出 `'键名': 变量名`。

### 4. 类对象解构（Object Pattern）

对类的实例进行解构，提取其**公开 getter 属性**（普通成员字段、自定义 getter 方法均可）。

#### （1）基础用法

```dart
// 定义类
class Point {
  final double x;
  final double y;
  Point(this.x, this.y);

  // 自定义 getter 也支持解构
  double get distance => x * x + y * y;
}

void main() {
  var p = Point(3, 4);

  // 写法1：重命名变量
  var Point(x: px, y: py) = p;
  print(px); // 3

  // 写法2：同名简写（变量名=属性名）
  var Point(:x, :y, :distance) = p;
  print(y);       // 4
  print(distance);// 25.0
}
```

> 注意：对象解构仅能访问公开 getter，私有属性（下划线开头）无法从外部解构。

## 二、进阶特性

### 1. 嵌套解构

支持任意层级的嵌套解构，可混合记录、列表、Map、对象等多种结构：

```dart
var data = {
  'user': ('Alice', 25),
  'hobbies': ['reading', 'coding', 'running']
};

// 嵌套解构：Map + 记录 + 列表 + rest
var {
  'user': (name, age),
  'hobbies': [firstHobby, ...restHobbies]
} = data;

print(name);        // Alice
print(age);         // 25
print(firstHobby);  // reading
print(restHobbies); // [coding, running]
```

### 2. 解构赋值（重新赋值）

解构不仅可以声明新变量，还可以给**已存在的变量**重新赋值，最经典的场景是「无需临时变量交换两个变量的值」：

```dart
int x = 10;
int y = 20;

// 直接解构赋值，完成变量交换
(x, y) = (y, x);
print(x); // 20
print(y); // 10
```

### 3. 解构中的类型校验

解构模式本身自带类型检查能力，类型不匹配时会抛出运行时错误：

```dart
// 要求第二个元素是 String，实际是 int，运行时抛出类型错误
var [int a, String b] = [1, 2];
```

## 三、常见使用场景

### 1. for 循环遍历解构

遍历包含复合元素的集合时，直接在循环中解构，简化迭代代码：

```dart
// 遍历记录列表
var users = [(1, 'Alice'), (2, 'Bob'), (3, 'Charlie')];
for (var (id, name) in users) {
  print('ID:$id, Name:$name');
}

// 遍历 Map（解构 MapEntry 对象）
var scores = {'math': 95, 'english': 88};
for (var MapEntry(:key, :value) in scores.entries) {
  print('$key: $value');
}
```

### 2. 分支语句中的解构

在 `if-case`、`switch` 语句中，一边匹配结构一边解构出变量使用：

```dart
// if-case 解构
dynamic data = Point(5, 6);
if (data case Point(:x, :y)) {
  print('点坐标：$x, $y');
}

// switch 模式匹配 + 解构
void describe(dynamic obj) {
  switch (obj) {
    case Point(:x, :y) when x > 0 && y > 0:
      print('第一象限点：($x, $y)');
    case [a, b, c]:
      print('三元列表：[$a, $b, $c]');
    case (name, age):
      print('用户：$name，$age 岁');
    default:
      print('未知类型');
  }
}
```

### 3. 函数多返回值接收

Dart 中函数可以返回 Record 实现多返回值，配合解构快速接收结果：

```dart
(int, String) getUserInfo(int id) {
  return (id, 'User_$id');
}

void main() {
  var (id, name) = getUserInfo(1001);
  print('$id - $name'); // 1001 - User_1001
}
```

## 四、注意事项与限制

1. **结构匹配要求**：记录、列表的解构数量必须与右侧结构匹配（rest 模式除外），否则编译期/运行时报错；Map 键不存在且无默认值时运行时报错。
2. **忽略符 `_`**：仅占位不创建变量，可重复使用，适合丢弃不需要的值。
3. **Rest 限制**：`...` 剩余元素模式仅支持列表，不可用于 Record、Map。
4. **函数参数暂不支持解构**：Dart 目前不能直接在函数形参列表中写解构模式，需在函数体内手动解构。
5. **作用域**：switch case、if-case 中解构出的变量，仅在对应分支内有效。
