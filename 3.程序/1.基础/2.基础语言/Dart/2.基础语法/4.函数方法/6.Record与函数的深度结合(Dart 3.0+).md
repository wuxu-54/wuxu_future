# 一、Dart 3.0+ Record 与函数的深度结合

Dart 3.0 正式引入的**记录（Record）** 是一种匿名、不可变的聚合值类型，它最核心的价值就是让函数**原生支持返回多个不同类型的值**，配合解构语法彻底替代了传统的手动封装类、第三方 Tuple 方案，和 Dart 函数体系深度融合。

## 1.1 Record 基础回顾

Record 分为**位置 Record**和**命名 Record**两类，天生支持多值组合，是值类型（字段全部相等则实例相等）：

```
// 位置 Record：按顺序存储，通过 $1、$2 访问（下标从1开始）
(String name, int age) user = ('Tom', 18);
print(user.$1); // Tom
print(user.$2); // 18

// 命名 Record：按键名存储，通过名称访问
({String name, int age}) user2 = (name: 'Jerry', age: 20);
print(user2.name); // Jerry
```

Record 支持泛型、可空、嵌套，可作为变量、参数、返回值自由传递。

---

## 1.2 函数返回多个值（核心用法）

这是 Record 对函数体系最大的增强：无需封装实体类，函数可直接返回多个值，调用方通过解构语法快速提取。

### （1）位置 Record 返回值

适合返回值数量少、语义明确的场景：

```
// 函数返回两个值：计算结果 + 是否溢出
(int result, bool isOverflow) addWithCheck(int a, int b) {
  final sum = a + b;
  return (sum, sum > 100);
}

void main() {
  // 解构接收返回值，变量名可自定义
  final (result, isOverflow) = addWithCheck(50, 60);
  print('结果：$result，是否溢出：$isOverflow');
}
```

### （2）命名 Record 返回值

适合返回值多、语义复杂的场景，可读性更强，调用顺序不影响：

```
// 返回矩形的面积、周长、对角线三个值
({double area, double perimeter, double diagonal}) calcRectangle(double width, double height) {
  return (
    area: width * height,
    perimeter: 2 * (width + height),
    diagonal: sqrt(width * width + height * height),
  );
}

void main() {
  // 解构时名称必须匹配，顺序可以随意
  final (:perimeter, :area, :diagonal) = calcRectangle(3, 4);
  print('面积：$area，周长：$perimeter，对角线：$diagonal');
}
```

### （3）忽略不需要的返回值

解构时用 `_` 占位符跳过不需要的值：

```
// 只关心结果，忽略溢出标记
final (result, _) = addWithCheck(10, 20);
```

## 1.3 函数参数的 Record 解构

Record 不仅可以做返回值，还可以直接在函数参数列表中完成解构，让函数接收 Record 时自动拆分为多个变量。

### （1）参数内直接解构

```
// 入参是一个位置 Record，在参数列表内直接解构为 name 和 age
void printUser((String name, int age) userInfo) {
  print('姓名：${userInfo.$1}，年龄：${userInfo.$2}');
}

// 更简洁的写法：参数声明时直接解构
void printUser((String name, int age) (name, age)) {
  print('姓名：$name，年龄：$age');
}

// 调用
void main() {
  final user = ('Alice', 22);
  printUser(user);
}
```

### （2）回调函数中的解构

这是高频场景，比如集合遍历、事件回调，配合匿名函数非常简洁：

```
final List<(String, int)> users = [('Tom', 18), ('Jerry', 20), ('Alice', 22)];

// 遍历 + 解构，双括号对应 Record 解构
users.forEach(((name, age)) => print('$name - $age'));
```

### （3）嵌套解构

支持多层嵌套的 Record 解构，适配复杂数据结构：

```
// 返回嵌套 Record：用户基础信息 + 地址信息
((String name, int age), (String city, String district)) getUserDetail() {
  return (('Tom', 18), ('Beijing', 'Chaoyang'));
}

void main() {
  // 一次性多层解构
  final ((name, age), (city, district)) = getUserDetail();
  print('$name, $age, $city $district');
}
```

## 1.4 Record 与函数类型、typedef

结合之前讲的函数类型别名，可以定义返回 Record、接收 Record 的函数类型，大幅提升复杂回调的可读性。

```
// 定义验证函数类型：返回 是否通过 + 错误信息
typedef Validator = (bool isValid, String? errorMsg) Function(String input);

// 实现邮箱验证函数
(bool isValid, String? errorMsg) emailValidator(String input) {
  final regex = RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$');
  if (input.isEmpty) return (false, '邮箱不能为空');
  if (!regex.hasMatch(input)) return (false, '邮箱格式错误');
  return (true, null);
}

// 通用校验函数，接收 Validator 类型回调
void runValidate(String value, Validator validator) {
  final (isValid, errorMsg) = validator(value);
  print(isValid ? '验证通过' : '验证失败：$errorMsg');
}
```

---

## 1.5 关键注意点

1. **不可变性**：Record 是值类型，字段不可修改，只能重新创建新的 Record；
2. **类型严格匹配**：位置 Record 的顺序、类型、数量必须完全一致；命名 Record 的字段名、类型必须完全匹配；
3. **单元素 Record**：只有一个元素的位置 Record 必须加尾逗号，如 `(int,)`，否则会被识别为普通括号；
4. **空安全兼容**：字段可单独声明可空，如 `(String, int?)` 表示第二个值允许为空。

## 二、Flutter 实战场景示例

下面结合 Flutter 开发高频场景，演示函数 + Record 的落地用法，覆盖表单、网络、自定义组件、UI 简化等核心场景。

## 场景1：表单验证函数

Flutter 表单开发中，验证函数需要同时返回「是否合法」和「错误提示」，用 Record 可以替代冗余的封装类。

```
import 'package:flutter/material.dart';

class LoginPage extends StatefulWidget {
  const LoginPage({super.key});

  @override
  State<LoginPage> createState() => _LoginPageState();
}

class _LoginPageState extends State<LoginPage> {
  final _formKey = GlobalKey<FormState>();
  String _username = '';
  String _password = '';

  // 用户名验证：返回 (是否合法, 错误信息)
  (bool isValid, String? errorMsg) validateUsername(String value) {
    if (value.isEmpty) return (false, '用户名不能为空');
    if (value.length < 3) return (false, '用户名长度不能少于3位');
    return (true, null);
  }

  // 密码验证
  (bool isValid, String? errorMsg) validatePassword(String value) {
    if (value.isEmpty) return (false, '密码不能为空');
    if (value.length < 6) return (false, '密码长度不能少于6位');
    return (true, null);
  }

  void _submit() {
    if (_formKey.currentState!.validate()) {
      _formKey.currentState!.save();
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('登录成功')),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('登录')),
      body: Form(
        key: _formKey,
        child: Padding(
          padding: const EdgeInsets.all(16),
          child: Column(
            children: [
              TextFormField(
                decoration: const InputDecoration(labelText: '用户名'),
                validator: (value) {
                  final (isValid, errorMsg) = validateUsername(value ?? '');
                  return isValid ? null : errorMsg;
                },
                onSaved: (value) => _username = value ?? '',
              ),
              TextFormField(
                decoration: const InputDecoration(labelText: '密码'),
                obscureText: true,
                validator: (value) {
                  final (isValid, errorMsg) = validatePassword(value ?? '');
                  return isValid ? null : errorMsg;
                },
                onSaved: (value) => _password = value ?? '',
              ),
              const SizedBox(height: 20),
              ElevatedButton(onPressed: _submit, child: const Text('登录')),
            ],
          ),
        ),
      ),
    );
  }
}
```

## 场景2：网络请求结果统一封装

网络层需要返回「成功/失败状态」+「数据/错误信息」，是 Record 最经典的应用场景，替代传统的 `Result` 封装类。

```
import 'dart:convert';
import 'package:http/http.dart' as http;

// 通用网络结果类型，支持泛型数据
typedef ApiResult<T> = ({bool success, T? data, String? errorMsg});

// 通用 GET 请求工具函数
Future<ApiResult<T>> getRequest<T>(
  String url, {
  required T Function(dynamic json) parser,
}) async {
  try {
    final response = await http.get(Uri.parse(url));
    if (response.statusCode == 200) {
      final json = jsonDecode(response.body);
      return (success: true, data: parser(json), errorMsg: null);
    } else {
      return (success: false, data: null, errorMsg: '请求失败：${response.statusCode}');
    }
  } catch (e) {
    return (success: false, data: null, errorMsg: '网络异常：$e');
  }
}

// 业务调用示例
Future<void> fetchUserInfo() async {
  final result = await getRequest<User>(
    '/api/user/1',
    parser: (json) => User.fromJson(json),
  );

  // 解构使用
  final (:success, :data, :errorMsg) = result;
  if (success && data != null) {
    print('用户：${data.name}');
  } else {
    print('错误：$errorMsg');
  }
}

// 示例实体类
class User {
  final String name;
  final int age;
  User({required this.name, required this.age});
  factory User.fromJson(Map<String, dynamic> json) {
    return User(name: json['name'], age: json['age']);
  }
}
```

## 场景3：自定义组件的多值回调

自定义 Widget 的回调经常需要回传多个参数（如选中项的 id、名称、索引），用 Record 可以避免回调参数过长，语义更清晰。

```
import 'package:flutter/material.dart';

// 自定义标签选择组件
class TagSelector extends StatelessWidget {
  final List<(int id, String label)> tags;
  // 回调：返回选中项的 id 和 标签文本
  final void Function(int id, String label) onSelected;

  const TagSelector({
    super.key,
    required this.tags,
    required this.onSelected,
  });

  @override
  Widget build(BuildContext context) {
    return Wrap(
      spacing: 8,
      children: tags.map((tag) {
        final (id, label) = tag; // 解构 Record
        return GestureDetector(
          onTap: () => onSelected(id, label),
          child: Container(
            padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 6),
            decoration: BoxDecoration(
              color: Colors.blue.shade100,
              borderRadius: BorderRadius.circular(16),
            ),
            child: Text(label),
          ),
        );
      }).toList(),
    );
  }
}

// 父组件调用
class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: TagSelector(
          tags: const [(1, 'Dart'), (2, 'Flutter'), (3, 'Android')],
          onSelected: (id, label) {
            print('选中：$id - $label');
          },
        ),
      ),
    );
  }
}
```

## 场景4：扩展方法 + Record 简化 UI 构建

结合扩展方法，用 Record 快速传递样式组合，简化 Flutter 中重复的 Padding、Margin 等 UI 代码。

```
import 'package:flutter/material.dart';

// Widget 样式扩展
extension WidgetStyleExt on Widget {
  // 快速设置水平+垂直边距
  Widget paddingXY(double horizontal, double vertical) {
    return Padding(
      padding: EdgeInsets.symmetric(horizontal: horizontal, vertical: vertical),
      child: this,
    );
  }

  // 通过命名 Record 分别设置四边边距
  Widget padding(({double left, double top, double right, double bottom}) insets) {
    return Padding(
      padding: EdgeInsets.fromLTRB(insets.left, insets.top, insets.right, insets.bottom),
      child: this,
    );
  }
}

// 使用示例
class DemoPage extends StatelessWidget {
  const DemoPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Column(
        children: [
          const Text('Hello Flutter').paddingXY(16, 12),
          const Text('Hello Dart').padding(
            (left: 20, top: 10, right: 20, bottom: 10),
          ),
        ],
      ),
    );
  }
}
```
