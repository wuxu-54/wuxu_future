# Dart 函数方法全面详解

Dart 是一门纯面向对象语言，**函数本身也是 `Function` 类型的对象**（即“一等公民”），支持函数式编程特性，同时拥有完善的参数体系、作用域规则和特殊函数类型。下面从基础语法、参数体系、函数式特性、特殊类型等维度系统讲解。

---

## 一、函数基础定义与语法

### 1.1 标准函数定义

完整语法格式：

```
返回值类型 函数名(参数列表) {
  // 函数体
  return 返回值;
}
```

示例：

```
// 完整定义：接收两个int参数，返回int结果
int add(int a, int b) {
  return a + b;
}
```

- 若省略返回值类型，Dart 会自动做**类型推断**；
- 若函数无返回值，返回类型声明为 `void`，调用方不应使用其返回结果；
- 无显式 `return` 的函数，默认返回 `null`（空安全下需注意可空兼容性）。

### 1.2 箭头函数（=> 语法糖）

当函数体仅包含**一条表达式**时，可使用箭头函数简写，自带 `return` 效果：

```
// 等价于上面的add函数
int add(int a, int b) => a + b;

// 无返回值的箭头函数
void printInfo(String name) => print('Name: $name');
```

>
> 注意：箭头后只能写表达式（如运算、三元表达式、函数调用），不能写语句（如if、for代码块）。

## 二、函数参数体系（核心重点）

Dart 参数分为**位置参数**和**命名参数**两大类，各自又分为“必填”和“可选”，是 Flutter 开发中最常用的语法特性。

### 2.1 必填位置参数

最基础的参数形式，调用时必须**按顺序、按数量**传入，不可省略：

```
void sayHello(String name, int age) {
  print('Hello $name, age: $age');
}

// 调用：顺序、数量必须匹配
sayHello('Tom', 18);
```

### 2.2 可选位置参数

用 `[]` 包裹，必须放在参数列表末尾，调用时可省略，省略后默认值为 `null`（无默认值时）：

```
// age 是可选位置参数，空安全下需声明为可空类型 int?
void sayHello(String name, [int? age]) {
  print('Hello $name, age: ${age ?? "unknown"}');
}

// 调用方式
sayHello('Tom');       // 正确，age 为 null
sayHello('Tom', 20);   // 正确，传入 age
```

### 2.3 可选命名参数

用 `{}` 包裹，调用时通过 `参数名: 值` 的形式传入，**顺序可任意调整**，不传则默认值为 `null`。这是 Flutter Widget 构造函数的标准参数形式：

```
void sayHello(String name, {int? age, String? gender}) {
  print('Hello $name, age: $age, gender: $gender');
}

// 调用方式：命名参数顺序随意，可按需传参
sayHello('Tom');
sayHello('Tom', age: 18);
sayHello('Tom', gender: 'male', age: 20); // 顺序不影响
```

### 2.4 required 命名必填参数

Dart 2.12 空安全引入，用于强制要求命名参数必须传入，不能省略。修饰后的参数无需声明为可空：

```
// age 是必填命名参数，gender 是可选命名参数
void sayHello(String name, {required int age, String? gender}) {
  print('Hello $name, age: $age');
}

// 调用：age 必须传，gender 可选
sayHello('Tom', age: 18);
```

>
> 注意：`required` 仅能修饰命名参数，不能用于位置参数。

### 2.5 参数默认值

所有可选参数（位置/命名）都可设置编译时常量作为默认值，调用未传参时自动使用默认值：

```
// 可选位置参数 + 默认值
void sayHello(String name, [int age = 18]) => print('$name, $age');

// 可选命名参数 + 默认值
void sayHello(String name, {int age = 18, String gender = 'male'}) {
  print('$name, $age, $gender');
}
```

>
> 有默认值的可选参数无需声明为可空，因为永远有有效值。

### 2.6 参数组合规则

1. 可选位置参数 和 可选命名参数 **不能同时存在**，二选一；
2. 可选参数必须全部放在参数列表末尾；
3. 必填位置参数可与任意一种可选参数组合使用。

## 三、一等公民：函数作为值

Dart 中函数是 `Function` 类型的对象，可赋值给变量、作为参数传递、作为返回值，这是函数式编程的基础。

### 3.1 函数赋值给变量

```
// 精确类型声明：接收两个int，返回int的函数
int Function(int, int) add = (a, b) => a + b;

// 也可用动态类型 Function 接收
Function multiply = (int a, int b) => a * b;

print(add(1, 2));    // 3
print(multiply(3,4));// 12
```

### 3.2 函数作为参数（回调函数）

最典型的场景是集合遍历方法（`forEach`、`map` 等），也可自定义接收回调的函数：

```
// 自定义函数：接收一个列表和一个回调函数
void processList(List<int> list, void Function(int) callback) {
  for (final item in list) {
    callback(item);
  }
}

void main() {
  final nums = [1, 2, 3];
  // 传入匿名函数作为回调
  processList(nums, (item) => print(item * 2));
}
```

### 3.3 函数作为返回值

函数可以作为另一个函数的返回结果，通常与闭包配合使用：

```
// 返回一个“加法器”函数
int Function(int) makeAdder(int addBy) {
  return (int i) => i + addBy;
}

void main() {
  final add2 = makeAdder(2);
  print(add2(3));  // 5
  final add5 = makeAdder(5);
  print(add5(3));  // 8
}
```

### 3.4 函数类型别名 typedef

给复杂的函数类型定义别名，大幅提升代码可读性，常用于回调类型声明：

```
// 定义函数类型别名
typedef Calculate = int Function(int a, int b);

int add(int a, int b) => a + b;
int sub(int a, int b) => a - b;

// 使用别名作为参数类型
void calc(int a, int b, Calculate op) {
  print(op(a, b));
}

void main() {
  calc(10, 5, add); // 15
  calc(10, 5, sub); // 5
}
```

## 四、匿名函数与闭包

### 4.1 匿名函数（Lambda）

没有函数名的函数，适合一次性回调场景，语法和普通函数一致，只是省略函数名：

```
final list = ['a', 'b', 'c'];

// 完整匿名函数
list.forEach((item) {
  print(item);
});

// 箭头简写
list.forEach((item) => print(item));
```

### 4.2 闭包（Closure）

**闭包是一个函数对象，它会捕获词法作用域内的变量，即使函数在原始作用域之外被调用，捕获的变量依然存活。**

简单来说：内部函数会“持有”外部函数的局部变量，延长其生命周期。

```
Function createCounter() {
  int count = 0;
  // 返回的匿名函数就是闭包，捕获了 count 变量
  return () {
    count++;
    return count;
  };
}

void main() {
  final counter1 = createCounter();
  print(counter1()); // 1
  print(counter1()); // 2

  final counter2 = createCounter();
  print(counter2()); // 1 （独立闭包，变量互不影响）
}
```

#### 闭包注意点

闭包捕获的是**变量的引用**，而非变量的瞬时值，经典场景：

```
List<Function> funcs = [];
for (int i = 0; i < 3; i++) {
  funcs.add(() => i);
}
// 循环结束后 i 变为3，所有闭包都引用同一个i
funcs.forEach((f) => print(f())); // 输出 3 3 3
```

## 五、特殊函数类型

### 5.1 main() 入口函数

Dart 程序的唯一顶级入口函数，返回值为 `void`，可选参数 `List<String>` 用于接收命令行参数：

```
// 标准入口
void main() {
  print('Hello Dart');
}

// 带命令行参数
void main(List<String> args) {
  print('传入参数：$args');
}
```

Flutter 应用的入口也是 `main` 函数，通常内部执行 `runApp(MyApp())`。

### 5.2 类中的函数（方法）

#### （1）实例方法

定义在类中，依赖类的实例，可访问 `this` 和实例变量：

```
class Person {
  String name;
  Person(this.name);

  // 实例方法
  void sayHi() => print('Hi, I am $name');
}
```

#### （2）静态方法

用 `static` 修饰，属于类本身，不能访问实例变量和 `this`：

```
class MathUtils {
  static int sum(int a, int b) => a + b;
}
// 调用：MathUtils.sum(1, 2);
```

#### （3）抽象方法

定义在抽象类中，无函数体，必须由子类实现：

```
abstract class Animal {
  // 抽象方法
  void makeSound();
}

class Dog extends Animal {
  @override
  void makeSound() => print('汪汪');
}
```

### 5.3 Getter / Setter 访问器

特殊的函数，用于模拟属性的读写行为，调用时和普通属性无差异：

```
class Rectangle {
  double width, height;
  Rectangle(this.width, this.height);

  // getter：计算属性，无参数，有返回值
  double get area => width * height;

  // setter：接收一个参数，无返回值
  set area(double value) {
    width = value / height;
  }
}

void main() {
  final rect = Rectangle(2, 3);
  print(rect.area);   // 调用 getter，输出 6
  rect.area = 12;     // 调用 setter
  print(rect.width);  // 4.0
}
```

### 5.4 生成器函数

用于**懒生成**一系列值，分为同步、异步两类，关键字 `sync*` / `async*`，用 `yield` 产出值。

#### （1）同步生成器 sync\*

返回 `Iterable<T>`，按需生成值，适合大数据量序列：

```
Iterable<int> countTo(int n) sync* {
  for (int i = 1; i <= n; i++) {
    yield i; // 产出一个值
  }
}

void main() {
  final nums = countTo(5);
  print(nums.toList()); // [1, 2, 3, 4, 5]
}
```

#### （2）异步生成器 async\*

返回 `Stream<T>`，异步产出值，配合 `await for` 监听：

```
Stream<int> asyncCountTo(int n) async* {
  for (int i = 1; i <= n; i++) {
    await Future.delayed(const Duration(seconds: 1));
    yield i;
  }
}
```

### 5.5 扩展方法（Extension）

Dart 2.7 引入，无需修改原类或继承，即可给已有类型（如 `String`、`Widget`）添加新方法：

```
// 给 String 类型扩展方法
extension StringExtension on String {
  int toInt() => int.parse(this);
  String capitalize() {
    if (isEmpty) return this;
    return '${this[0].toUpperCase()}${substring(1)}';
  }
}

void main() {
  print('123'.toInt());        // 123
  print('hello'.capitalize()); // Hello
}
```

Flutter 开发中常通过扩展方法简化 UI 代码（如给 Widget 快速添加 padding、margin）。

## 六、其他核心特性

### 6.1 词法作用域

Dart 是**静态词法作用域**，变量的作用域由代码嵌套结构在编译期决定：

- 内层函数可访问外层所有变量（全局、函数内局部）；
- 外层不能访问内层的局部变量。

### 6.2 可调用对象（Callable Classes）

如果类实现了 `call()` 方法，该类的实例可以像函数一样直接调用：

```
class Printer {
  void call(String text) => print('Print: $text');
}

void main() {
  final printer = Printer();
  printer('Hello Dart'); // 等价于 printer.call('Hello Dart')
}
```

### 6.3 函数相等性

- 顶级函数、静态方法：相同引用的函数相等；
- 实例方法：同一实例的同一方法引用相等，不同实例的方法不相等。

## 定义函数

结构：返回值类型 函数名(参数列表){ return 返回值; }

```dart
bool isNoble(int atomicNumber) {
  return _nobleGases[atomicNumber] != null;
}

//可省略返回值类型，编译器会推断类型
isNoble(int atomicNumber) {
  return _nobleGases[atomicNumber] != null;
}

//函数体中 只有一行语句，那么可以简写。 `=>` 
bool isNoble(int atomicNumber) => _nobleGases[atomicNumber] != null;
```

## 调用函数

```dart
// 定义一个可空的函数类型变量
void Function()? nullableFunction;

void main() {
  // 1.调用之前检查是否为 null
  if (nullableFunction != null) {
    nullableFunction();
  }

  // 2.使用空安全调用操作符 ?.
  nullableFunction?.call();

  // 3.1 给可空函数变量赋值
  nullableFunction = () {
    print('Function is called.');
  };

  // 3.2 再次调用
  nullableFunction?.call();
}
```

### 立即执行函数

dart拥有同js一样的功能：立即执行函数。写法如下：

```dart
() {
    print('执行逻辑');
    return 20;
  }();
```

解析:

- `(){}` 这个前一部分是个匿名函数
- `()` 后一部分是对函数的执行。
- 把这两部分结合起来，就构成了一个**立即调用函数表达式（Immediately Invoked Function Expression，IIFE）**。其作用是在代码执行到此处时，马上定义并调用这个匿名函数，获取函数的返回值。
