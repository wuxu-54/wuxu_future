# 函数方法

## 定义函数

结构：返回值类型 函数名(参数列表){ return 返回值; }

```dart
bool isNoble(int atomicNumber) {
  return _nobleGases[atomicNumber] != null;
}

//可省略返回值类型，编译器会推断类型
isNoble(int atomicNumber) {
  return _nobleGases[atomicNumber] != null;
}

//函数体中 只有一行语句，那么可以简写。 `=>` 
bool isNoble(int atomicNumber) => _nobleGases[atomicNumber] != null;
```

## 函数参数

注意！dart不支持参数解构
作为 Dart 专家，我来帮你把函数参数这块儿彻底补全，尤其是你提到的要点之外常被忽略的细节。

### 1. 参数分类总览

Dart 函数参数分为两大类：

- **位置参数（Positional Parameters）**：按调用时传入的顺序对应。
- **命名参数（Named Parameters）**：通过参数名指定，顺序无关。

任何函数参数都必须是这两种之一，且它们**不能混合使用**（即不能既有位置参数又有命名参数？实际上可以混合，但位置参数必须在前，命名参数在后）。

### 2. 位置参数（你已经漏掉了）

位置参数分为**必需位置参数**和**可选位置参数**。

#### 必需位置参数

默认情况下，所有位置参数都是必需的，调用时必须按顺序传入。

```dart
void sayHello(String name, int age) {} // 两个都是必需
sayHello('Alice', 25); // 正确
sayHello('Alice'); // 编译错误
```

#### 可选位置参数

用方括号 `[]` 包裹，表示该参数可传可不传，且可以有默认值。

```dart
void sayHello(String name, [int? age, String? title]) {
  // age 和 title 都是可选的
}
sayHello('Bob');          // 合法
sayHello('Bob', 30);      // 合法
sayHello('Bob', 30, 'Mr.'); // 合法
```

可选位置参数**必须有默认值**（除非类型可空，则默认值为 `null`），推荐显式指定：

```dart
void sayHello(String name, [int age = 18, String title = 'Mr.']) {}
```

---

### 3. 命名参数（你已提到，但有细节补充）

命名参数用 `{}` 包裹，默认是**可选**的，除非用 `required` 标记。

#### 可选命名参数（可空或带默认值）

```dart
void enableFlags({bool bold = false, bool? hidden}) {} 
// bold 有默认值 false，hidden 可空，不传则为 null
```

#### 必传命名参数

使用 `required` 修饰（Dart 2.12+）：

```dart
void enableFlags({required bool bold, bool? hidden}) {}
// bold 必须传入
```

**重要细节**：

- `required` 只能用于命名参数，不能用于位置参数（位置参数默认就是必需的，无需标记）。
- `required` 与可空类型 `?` 可以共存（例如 `required int? value`），表示必须传但可以是 `null`。
- `required` 还常用于构造函数参数（你举的 `Scrollbar` 例子正是）。

### 4. 默认值总结

- **位置参数**（必需位置参数不能有默认值，可选位置参数可设默认值）。
- **命名参数**（可选命名参数可设默认值，必传命名参数不能设默认值，因为已经要求传入）。

默认值必须是编译时常量（例如字面量、`const` 构造等）。

### 5. 关于参数解构（你提到的“不支持”）

你说得对，Dart **不支持** JavaScript 那样的参数解构（例如 `function({a, b}) {}` 自动解构对象）。  
但你可以**手动解构**：

```dart
void process(Map<String, int> data) {
  final a = data['a'];
  final b = data['b'];
  // ...
}
```

或者使用 Dart 3 的**记录（Record）**和**模式匹配（Patterns）**，但那是另一层特性，不是传统的参数解构。

### 6. 函数作为参数（高阶函数）

Dart 中函数也是对象，可以当作参数传递，定义时使用 `Function` 类型或具体函数签名：

```dart
void doSomething(Function callback) {} // 不严谨
void doSomething(void Function(int) callback) {} // 推荐
```

### 7. 参数类型与泛型

泛型函数的类型参数可以在参数列表中使用，例如：

```dart
T identity<T>(T value) => value;
```

### 8. 特殊参数：`super` 参数（构造函数）

在构造函数中，`super.key` 等语法是 Dart 2.17+ 的“超参数”特性，用于简化传递给父类的参数，它本质上还是命名参数的一种用法，但属于构造函数特有的简写。

### 9. 可选参数的位置顺序规则

- **必需位置参数** → **可选位置参数** → **命名参数**  
  即：命名参数必须放在最后，且不能与位置参数混排。

```dart
void example(String requiredPos, [int optionalPos = 0], {bool named = false}) {} // 合法
```

### 10. 空安全与参数默认值

在空安全环境下，如果参数类型不可空且没有默认值，则该参数必须是必需（位置参数默认必需，命名参数必须加 `required`）。  
否则会报编译错误。

### 11.补一个完整例子

```dart
void registerUser(
  String username,                // 必需位置参数
  [int age = 18, String? phone], // 可选位置参数（有默认值/可空）
  {                              // 命名参数
    required String email,       // 必传命名
    bool isActive = true,        // 可选命名（带默认值）
    String? remark,              // 可选命名（可空）
  }
) {
  // ...
}

// 调用方式
registerUser('alice', 25, '123456', email: 'a@b.com', isActive: false);
registerUser('bob', email: 'b@c.com'); // 跳过可选位置，只传必传命名
```

### 常见陷阱

- 忘记给可选位置参数设默认值，又没加 `?`，导致编译错误（空安全要求）。
- 把 `required` 加在位置参数上（不允许）。
- 试图在命名参数前放位置参数（可以，但顺序必须固定）。

### 补充

dart中的函数同java、kotlin一样，也有匿名函数、局部函数等概念，这里不再多讲了。

## 调用函数

```dart
// 定义一个可空的函数类型变量
void Function()? nullableFunction;

void main() {
  // 1.调用之前检查是否为 null
  if (nullableFunction != null) {
    nullableFunction();
  }

  // 2.使用空安全调用操作符 ?.
  nullableFunction?.call();

  // 3.1 给可空函数变量赋值
  nullableFunction = () {
    print('Function is called.');
  };

  // 3.2 再次调用
  nullableFunction?.call();
}
```

## 立即执行函数

dart拥有同js一样的功能：立即执行函数。写法如下：

```dart
() {
    print('执行逻辑');
    return 20;
  }();
```

解析:

- `(){}` 这个前一部分是个匿名函数
- `()` 后一部分是对函数的执行。
- 把这两部分结合起来，就构成了一个**立即调用函数表达式（Immediately Invoked Function Expression，IIFE）**。其作用是在代码执行到此处时，马上定义并调用这个匿名函数，获取函数的返回值。
