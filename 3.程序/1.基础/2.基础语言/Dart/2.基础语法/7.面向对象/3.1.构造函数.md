# 构造函数

Dart 的构造函数极其灵活，远比 Java/C++ 丰富。它没有传统意义的“重载”（多个同名构造函数），而是通过**命名构造函数**来解决多构造场景。

下面是系统性的详解，按实战频率从高到低排列：

---

## 1. 普通生成构造函数（最常用）

这是最标准的构造函数，用来创建类的实例。**重点语法糖：`this.属性`** 可以直接将参数赋值给实例变量。

```dart
class User {
  String name;
  int age;
  
  // 标准写法：参数赋值给 this.name
  // 注意：这里 name 是必传的位置参数（因为没加 [] 或 {}）
  User(this.name, this.age); 
}

void main() {
  var u = User('Alice', 25); // 调用
}
```

---

## 2. 结合命名参数与 `required`（企业级实战标配）

正如你之前学的函数参数，构造函数的参数也完全适用。**现代 Dart 强烈推荐使用命名参数 + `required`**，因为可读性极强，且顺序随意。

```dart
class Product {
  final String id;      // final 要求必须在构造时初始化
  final String name;
  final double? price;  // 可空，不强制传

  // 命名参数 + required
  Product({
    required this.id,
    required this.name,
    this.price,          // 没有 required，且类型可空，默认为 null
  });
}

// 调用：顺序随便，必须带参数名
var p = Product(name: 'Laptop', id: 'p001');
```

---

## 3. 初始化列表（Initializer list）—— 用于 `final` 字段和断言

这是 Dart 独有的特性。在构造函数体**执行之前**，用 `:` 对成员变量进行初始化，或者做参数校验（`assert`）。**对于 `final` 不可变字段，这是唯一能赋值的地方（除了 `this` 简写）。**

```dart
class Circle {
  final double radius; // final 不可变
  final double area;

  // 初始化列表：在 body（{}）执行前运行
  Circle(double r)
      : radius = r,                // 给 final 赋值
        area = 3.14 * r * r,       // 计算派生值
        assert(r > 0, '半径必须大于0'); // 参数校验（开发模式生效）
}
```

---

## 4. 命名构造函数（解决无法重载的问题）

Dart 不支持 `User(String name)` 和 `User(int id)` 这种重载。想要多种构造方式，就用**命名构造函数**。

```dart
class DateTime {
  // 普通构造
  DateTime.now(); 
  
  // 命名构造：从时间戳创建
  DateTime.fromMillisecondsSinceEpoch(int ms);
}

// 自定义例子
class Point {
  double x, y;
  Point(this.x, this.y);
  
  // 命名构造：原点
  Point.origin() : x = 0, y = 0;
  
  // 命名构造：从 JSON
  Point.fromJson(Map<String, double> json) 
      : x = json['x']!,
        y = json['y']!;
}
```

---

## 5. 重定向构造函数（转发给另一个构造）

构造函数体为空，只用 `: this(...)` 将调用转发给本类的其他构造函数。

```dart
class Vector {
  double x, y;
  Vector(this.x, this.y);
  
  // 重定向到主构造，默认值为 0
  Vector.zero() : this(0, 0);
  
  // 重定向到命名构造
  Vector.unitX() : this(1, 0);
}
```

---

## 6. `const` 构造函数（编译时常量）

如果类的所有字段都是 `final` 的，你可以把构造函数设为 `const`。这样创建的对象是**编译期常量**，相同的参数会产生相同的实例（合并优化），性能极高，常用于 Flutter 的 Widget。

```dart
class ImmutableConfig {
  final String host;
  final int port;
  
  // 加上 const
  const ImmutableConfig(this.host, this.port);
}

void main() {
  // 必须用 const 关键字调用才会触发常量池
  const config1 = ImmutableConfig('api.com', 8080);
  const config2 = ImmutableConfig('api.com', 8080);
  print(identical(config1, config2)); // true（同一实例）
}
```

---

## 7. 工厂构造函数（Factory Constructor）—— 不总是创建新对象

它**没有 `this`**，也不自动创建实例。它的作用是：返回一个**已有的实例**（如缓存池、单例）或者返回**子类对象**。**注意：工厂函数不能用 `const`。**

```dart
class Logger {
  final String name;
  static final Map<String, Logger> _cache = {};
  
  // 工厂构造：私有化命名构造，防止外部 new
  factory Logger(String name) {
    return _cache.putIfAbsent(name, () => Logger._internal(name));
  }
  
  // 真正的生成构造是私有的
  Logger._internal(this.name);
}

void main() {
  var a = Logger('UI');
  var b = Logger('UI');
  print(identical(a, b)); // true（单例缓存）
}
```

## 8. 🚀 超级语法糖：超参数（Super Parameters）—— Dart 2.17+

如果你在写继承，子类构造函数往往要写 `super.xxx` 传参。Dart 2.17+ 允许直接在参数列表里用 `super.参数名`，连 `: super(...)` 都省了。

```dart
class Animal {
  final String name;
  Animal(this.name);
}

class Dog extends Animal {
  final String breed;
  
  // 超参数：直接让参数传给父类构造。注意 super 必须在参数列表最后
  Dog(super.name, this.breed); 
  
  // 如果父类是命名参数，也支持
  // Dog({required super.name, required this.breed});
}

void main() {
  var d = Dog('旺财', '金毛');
  print(d.name); // 旺财（直接继承了父类字段）
}
```

---

## 9. 私有构造函数（用于工具类或单例）

把构造函数设为 `_` 开头，外部就无法实例化。

```dart
class Utils {
  // 私有构造，防止被 new
  Utils._(); 
  
  static void printLog(String msg) { print(msg); }
}

// main 中：Utils u = Utils(); // 报错！
Utils.printLog('Hello'); // 只能通过静态方法调用
```

---

## 10. 构造函数的调用顺序（重要）

当涉及继承时，执行顺序非常严格：

1. **初始化列表**（`:` 后面的内容）
2. **父类构造函数**（显式调用 `super()` 或隐式默认无参构造）
3. **当前构造函数体**（`{}` 里面的代码）

```dart
class Parent {
  Parent(int x) { print('Parent'); }
}

class Child extends Parent {
  Child(int x) : assert(x > 0), super(x) { 
    print('Child'); 
  }
}
// 输出顺序：Parent -> Child
```

## 总结：与“函数参数”的关联

你前面学的所有参数规则（命名参数、`required`、可选位置参数 `[]`、默认值）**完全适用于构造函数**。例如：

```dart
class Button {
  final String label;
  final bool isPrimary;
  
  // 混合：位置必传 + 命名参数 + 默认值
  Button(this.label, {this.isPrimary = false});
}
```

**补充提醒：** 如果类中定义了 `final` 字段，且没有在声明时赋值，那么你必须在**初始化列表**或**参数 `this` 简写**中完成赋值，否则编译报错。
