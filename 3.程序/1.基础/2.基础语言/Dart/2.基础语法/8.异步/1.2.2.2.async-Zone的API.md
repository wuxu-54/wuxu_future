# Dart Zone 完整 API 大全

## 一、Zone 类完整 API

### 1.1 静态属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `Zone.current` | `Zone` | 获取当前执行代码所在的 Zone |
| `Zone.root` | `Zone` | 获取根 Zone（最顶层的 Zone） |

```
print(Zone.current);  // 当前 Zone
print(Zone.root);     // 根 Zone
```

---

### 1.2 实例属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `parent` | `Zone?` | 父 Zone，根 Zone 的 parent 为 null |
| `errorZone` | `Zone` | 处理未捕获异常的 Zone（沿 parent 链向上找第一个能处理错误的 Zone） |

```
final zone = Zone.current;
print(zone.parent);     // 父 Zone
print(zone.errorZone);  // 错误处理 Zone
```

---

### 1.3 实例方法：执行代码

#### `run<R>(R action())`

在当前 Zone 中同步执行函数

```
final result = Zone.current.run(() {
  return 42;
});
```

#### `runUnary<R, T>(R action(T argument), T argument)`

在当前 Zone 中执行带一个参数的函数

```
final result = Zone.current.runUnary((int x) {
  return x * 2;
}, 21); // 返回 42
```

#### `runBinary<R, T1, T2>(R action(T1 argument1, T2 argument2), T1 argument1, T2 argument2)`

在当前 Zone 中执行带两个参数的函数

```
final result = Zone.current.runBinary((int a, int b) {
  return a + b;
}, 10, 32); // 返回 42
```

---

### 1.4 实例方法：绑定回调

#### `bindCallback<R>(R callback())`

将回调绑定到当前 Zone，返回一个新函数，调用时会在当前 Zone 中执行

```
final callback = Zone.current.bindCallback(() {
  print('在绑定的 Zone 中执行');
});

// 在其他 Zone 中调用，仍会在原 Zone 执行
otherZone.run(() {
  callback(); // 执行时回到绑定的 Zone
});
```

#### `bindUnaryCallback<R, T>(R callback(T arg))`

绑定单参数回调

```
final callback = Zone.current.bindUnaryCallback((int x) {
  return x * 2;
});

final result = callback(10); // 在绑定的 Zone 中执行
```

#### `bindBinaryCallback<R, T1, T2>(R callback(T1 arg1, T2 arg2))`

绑定双参数回调

```
final callback = Zone.current.bindBinaryCallback((int a, int b) {
  return a + b;
});

final result = callback(1, 2);
```

---

### 1.5 实例方法：绑定回调（Guarded 版本）

#### `bindCallbackGuarded(void callback())`

绑定回调，异常会被 Zone 的错误处理器捕获

```
final callback = Zone.current.bindCallbackGuarded(() {
  throw 'error'; // 异常会被 Zone 的 handleUncaughtError 处理
});
```

#### `bindUnaryCallbackGuarded<T>(void callback(T arg))`

绑定单参数的 guarded 回调

```
final callback = Zone.current.bindUnaryCallbackGuarded((int x) {
  throw 'error in unary';
});
```

#### `bindBinaryCallbackGuarded<T1, T2>(void callback(T1 arg1, T2 arg2))`

绑定双参数的 guarded 回调

```
final callback = Zone.current.bindBinaryCallbackGuarded((int a, int b) {
  throw 'error in binary';
});
```

---

### 1.6 实例方法：注册回调

#### `registerCallback<R>(R callback())`

注册回调（内部方法，一般不直接使用）

```
final registered = Zone.current.registerCallback(() {
  print('callback');
});
```

#### `registerUnaryCallback<R, T>(R callback(T arg))`

注册单参数回调

#### `registerBinaryCallback<R, T1, T2>(R callback(T1 arg1, T2 arg2))`

注册双参数回调

---

### 1.7 实例方法：调度任务

#### `scheduleMicrotask(void callback())`

在当前 Zone 中调度一个微任务

```
Zone.current.scheduleMicrotask(() {
  print('微任务执行');
});
```

#### `createTimer(Duration duration, void callback())`

创建一个 Timer

```
final timer = Zone.current.createTimer(
  Duration(seconds: 1),
  () => print('timer 触发'),
);
```

#### `createPeriodicTimer(Duration period, void callback(Timer timer))`

创建一个周期性 Timer

```
final periodicTimer = Zone.current.createPeriodicTimer(
  Duration(seconds: 1),
  (timer) => print('周期 timer'),
);
```

---

### 1.8 实例方法：fork 新 Zone

#### `fork({ZoneSpecification? specification, Map<Object?, Object?>? zoneValues})`

从当前 Zone 创建一个子 Zone

```
final childZone = Zone.current.fork(
  specification: ZoneSpecification(
    print: (self, parent, zone, line) {
      parent.print(zone, '[Child] $line');
    },
  ),
  zoneValues: {
    #key: 'value',
  },
);

childZone.run(() {
  print('hello'); // 输出: [Child] hello
});
```

---

### 1.9 实例方法：打印

#### `print(String line)`

在当前 Zone 中执行 print

```
Zone.current.print('hello');
```

---

### 1.10 实例方法：错误处理

#### `handleUncaughtError(Object error, StackTrace stackTrace)`

触发 Zone 的未捕获错误处理

```
Zone.current.handleUncaughtError(
  Exception('手动触发错误'),
  StackTrace.current,
);
```

---

### 1.11 实例方法：ZoneValues 访问

#### `operator [](Object? key)`

读取 Zone 中的值（从当前 Zone 向上查找）

```
final value = Zone.current[#myKey];
final value2 = Zone.current['stringKey'];
```

> 
> 注意：ZoneValues 是只读的，只能在 fork 时设置，运行时不能修改

## 二、ZoneSpecification 完整 API

### 2.1 构造函数

```
ZoneSpecification({
  HandleUncaughtErrorHandler? handleUncaughtError,
  RunHandler? run,
  RunUnaryHandler? runUnary,
  RunBinaryHandler? runBinary,
  RegisterCallbackHandler? registerCallback,
  RegisterUnaryCallbackHandler? registerUnaryCallback,
  RegisterBinaryCallbackHandler? registerBinaryCallback,
  ScheduleMicrotaskHandler? scheduleMicrotask,
  CreateTimerHandler? createTimer,
  CreatePeriodicTimerHandler? createPeriodicTimer,
  PrintHandler? print,
  ForkHandler? fork,
})
```

---

### 2.2 所有可拦截的回调

#### 1. `handleUncaughtError`

处理未捕获的异常

```
typedef HandleUncaughtErrorHandler = void Function(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  Object error,
  StackTrace stackTrace,
);
```

#### 2. `run`

拦截同步代码执行

```
typedef RunHandler = R Function<R>(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  R Function() f,
);
```

#### 3. `runUnary`

拦截单参数函数执行

```
typedef RunUnaryHandler = R Function<R, T>(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  R Function(T arg) f,
  T arg,
);
```

#### 4. `runBinary`

拦截双参数函数执行

```
typedef RunBinaryHandler = R Function<R, T1, T2>(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  R Function(T1 arg1, T2 arg2) f,
  T1 arg1,
  T2 arg2,
);
```

#### 5. `registerCallback`

拦截回调注册

```
typedef RegisterCallbackHandler = ZoneCallback<R> Function<R>(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  R Function() f,
);
```

#### 6. `registerUnaryCallback`

拦截单参数回调注册

```
typedef RegisterUnaryCallbackHandler = ZoneUnaryCallback<R, T> Function<R, T>(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  R Function(T arg) f,
);
```

#### 7. `registerBinaryCallback`

拦截双参数回调注册

```
typedef RegisterBinaryCallbackHandler = ZoneBinaryCallback<R, T1, T2> Function<R, T1, T2>(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  R Function(T1 arg1, T2 arg2) f,
);
```

#### 8. `scheduleMicrotask`

拦截微任务调度

```
typedef ScheduleMicrotaskHandler = void Function(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  void Function() f,
);
```

#### 9. `createTimer`

拦截 Timer 创建

```
typedef CreateTimerHandler = Timer Function(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  Duration duration,
  void Function() callback,
);
```

#### 10. `createPeriodicTimer`

拦截周期 Timer 创建

```
typedef CreatePeriodicTimerHandler = Timer Function(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  Duration period,
  void Function(Timer timer) callback,
);
```

#### 11. `print`

拦截 print 调用

```
typedef PrintHandler = void Function(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  String line,
);
```

#### 12. `fork`

拦截 Zone fork

```
typedef ForkHandler = Zone Function(
  Zone self,
  ZoneDelegate parent,
  Zone zone,
  ZoneSpecification? specification,
  Map<Object?, Object?>? zoneValues,
);
```

---

### 2.3 完整示例

```
final spec = ZoneSpecification(
  // 异常处理
  handleUncaughtError: (self, parent, zone, error, stackTrace) {
    print('捕获异常: $error');
    parent.handleUncaughtError(zone, error, stackTrace);
  },

  // 代码执行
  run: <R>(self, parent, zone, f) {
    print('run 开始');
    try {
      return parent.run(zone, f);
    } finally {
      print('run 结束');
    }
  },

  runUnary: <R, T>(self, parent, zone, f, arg) {
    return parent.runUnary(zone, f, arg);
  },

  runBinary: <R, T1, T2>(self, parent, zone, f, arg1, arg2) {
    return parent.runBinary(zone, f, arg1, arg2);
  },

  // 回调注册
  registerCallback: <R>(self, parent, zone, f) {
    return parent.registerCallback(zone, f);
  },

  registerUnaryCallback: <R, T>(self, parent, zone, f) {
    return parent.registerUnaryCallback(zone, f);
  },

  registerBinaryCallback: <R, T1, T2>(self, parent, zone, f) {
    return parent.registerBinaryCallback(zone, f);
  },

  // 任务调度
  scheduleMicrotask: (self, parent, zone, f) {
    print('调度微任务');
    parent.scheduleMicrotask(zone, f);
  },

  createTimer: (self, parent, zone, duration, callback) {
    print('创建 Timer: ${duration.inMilliseconds}ms');
    return parent.createTimer(zone, duration, callback);
  },

  createPeriodicTimer: (self, parent, zone, period, callback) {
    print('创建周期 Timer: ${period.inMilliseconds}ms');
    return parent.createPeriodicTimer(zone, period, callback);
  },

  // 打印
  print: (self, parent, zone, line) {
    parent.print(zone, '[LOG] $line');
  },

  // Fork
  fork: (self, parent, zone, specification, zoneValues) {
    print('fork 新 Zone');
    return parent.fork(zone, specification, zoneValues);
  },
);
```

## 三、ZoneDelegate 完整 API

`ZoneDelegate` 是父 Zone 的委托，用于在 `ZoneSpecification` 的回调中调用父 Zone 的原始行为。

### 3.1 所有方法

| 方法 | 说明 |
| --- | --- |
| `handleUncaughtError(Zone zone, Object error, StackTrace stackTrace)` | 调用父 Zone 的错误处理 |
| `run<R>(Zone zone, R f())` | 调用父 Zone 的 run |
| `runUnary<R, T>(Zone zone, R f(T arg), T arg)` | 调用父 Zone 的 runUnary |
| `runBinary<R, T1, T2>(Zone zone, R f(T1 a, T2 b), T1 a, T2 b)` | 调用父 Zone 的 runBinary |
| `registerCallback<R>(Zone zone, R f())` | 调用父 Zone 的 registerCallback |
| `registerUnaryCallback<R, T>(Zone zone, R f(T arg))` | 调用父 Zone 的 registerUnaryCallback |
| `registerBinaryCallback<R, T1, T2>(Zone zone, R f(T1 a, T2 b))` | 调用父 Zone 的 registerBinaryCallback |
| `scheduleMicrotask(Zone zone, void f())` | 调用父 Zone 的微任务调度 |
| `createTimer(Zone zone, Duration duration, void callback())` | 调用父 Zone 创建 Timer |
| `createPeriodicTimer(Zone zone, Duration period, void callback(Timer))` | 调用父 Zone 创建周期 Timer |
| `print(Zone zone, String line)` | 调用父 Zone 的 print |
| `fork(Zone zone, ZoneSpecification? spec, Map? values)` | 调用父 Zone 的 fork |

### 3.2 使用示例

```
ZoneSpecification(
  print: (Zone self, ZoneDelegate parent, Zone zone, String line) {
    // 在调用父 Zone 之前做一些处理
    final enhancedLine = '[${DateTime.now()}] $line';
    
    // 调用父 Zone 的原始 print 行为
    parent.print(zone, enhancedLine);
  },
)
```

> 
> **注意**：`self` 是当前 Zone 对象，`parent` 是父 Zone 的委托，`zone` 是当前执行代码的 Zone。
> 调用 `parent.xxx(zone, ...)` 时，第一个参数 `zone` 表示"在哪个 Zone 上下文中执行"。

## 四、顶级函数完整 API

### 4.1 `runZoned<R>`

```
R runZoned<R>(
  R body(),
  {
    Map<Object?, Object?>? zoneValues,
    ZoneSpecification? zoneSpecification,
  }
)
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `body` | `R Function()` | 是 | 在新 Zone 中执行的函数 |
| `zoneValues` | `Map<Object?, Object?>?` | 否 | Zone 中共享的数据 |
| `zoneSpecification` | `ZoneSpecification?` | 否 | Zone 行为定制 |

**示例：**

```
runZoned(() {
  print('在新 Zone 中');
}, zoneValues: {
  #key: 'value',
}, zoneSpecification: ZoneSpecification(
  print: (self, parent, zone, line) {
    parent.print(zone, '[PREFIX] $line');
  },
));
```

---

### 4.2 `runZonedGuarded<R>`

```
R? runZonedGuarded<R>(
  R body(),
  void onError(Object error, StackTrace stack),
  {
    Map<Object?, Object?>? zoneValues,
    ZoneSpecification? zoneSpecification,
  }
)
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `body` | `R Function()` | 是 | 在新 Zone 中执行的函数 |
| `onError` | `void Function(Object, StackTrace)` | 是 | 异常回调 |
| `zoneValues` | `Map<Object?, Object?>?` | 否 | Zone 中共享的数据 |
| `zoneSpecification` | `ZoneSpecification?` | 否 | Zone 行为定制 |

**返回值：**

- 正常执行时返回 `body()` 的返回值
- 如果 `body` 同步抛出异常，返回 `null`

**示例：**

```
final result = runZonedGuarded(() {
  return 42;
}, (error, stack) {
  print('错误: $error');
});

print(result); // 42
```

## 七、完整实战示例

### 7.1 全功能 Zone 封装

```
import 'dart:async';

class EnhancedZone {
  static R run<R>(
    R Function() body, {
    String? tag,
    Map<Object?, Object?>? values,
    void Function(Object error, StackTrace stack)? onError,
    void Function(String line)? onLog,
  }) {
    return runZonedGuarded(
      () => body(),
      (error, stack) {
        onError?.call(error, stack);
      },
      zoneValues: {
        if (tag != null) #tag: tag,
        #startTime: DateTime.now(),
        ...?values,
      },
      zoneSpecification: ZoneSpecification(
        print: (self, parent, zone, line) {
          final tag = zone[#tag] ?? 'default';
          final time = DateTime.now().toIso8601String();
          final enhanced = '[$time][$tag] $line';
          onLog?.call(enhanced);
          parent.print(zone, enhanced);
        },
        
        run: <R>(self, parent, zone, f) {
          final sw = Stopwatch()..start();
          try {
            return parent.run(zone, f);
          } finally {
            sw.stop();
            parent.print(zone, '执行耗时: ${sw.elapsedMicroseconds}μs');
          }
        },
        
        scheduleMicrotask: (self, parent, zone, f) {
          parent.print(zone, '调度微任务');
          parent.scheduleMicrotask(zone, f);
        },
        
        createTimer: (self, parent, zone, duration, callback) {
          parent.print(zone, '创建 Timer: ${duration.inMilliseconds}ms');
          return parent.createTimer(zone, duration, callback);
        },
        
        handleUncaughtError: (self, parent, zone, error, stackTrace) {
          parent.print(zone, '❌ 未捕获异常: $error');
          parent.handleUncaughtError(zone, error, stackTrace);
        },
      ),
    )!;
  }
}

// 使用
void main() {
  EnhancedZone.run(() {
    print('开始执行业务逻辑');
    
    Future.delayed(Duration(milliseconds: 100), () {
      print('异步任务完成');
    });
    
    scheduleMicrotask(() {
      print('微任务执行');
    });
  }, tag: 'Business', onError: (error, stack) {
    print('上报错误: $error');
  });
}
```

| Zone 调度方法 | 3 | microtask / timer / periodicTimer |
| Zone 其他方法 | 4 | fork / print / handleUncaughtError / \[\] |
| ZoneSpecification 拦截项 | 12 | 所有可定制的行为 |
| ZoneDelegate 方法 | 12 | 对应 specification 的 12 项 |
| 顶级函数 | 2 | runZoned / runZonedGuarded |
