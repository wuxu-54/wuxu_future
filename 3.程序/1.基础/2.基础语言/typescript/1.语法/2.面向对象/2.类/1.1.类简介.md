# 类

在TypeScript中，类（Class）是面向对象编程的核心概念，用于封装数据和操作数据的方法。TypeScript在ES6类的基础上增加了类型检查、访问修饰符等特性，让类的定义更严谨、功能更丰富。下面从基础到高级特性全面解析TS中的类：

## 一、类的基本定义

类通过`class`关键字声明，包含**属性**（数据）和**方法**（操作），以及用于初始化实例的**构造函数**。

### 基本结构

```typescript
class Person {
  // 属性声明（需指定类型）
  name: string;
  age: number;

  // 构造函数（初始化实例时调用）
  constructor(name: string, age: number) {
    this.name = name; // this指向当前实例
    this.age = age;
  }

  // 方法（实例方法）
  sayHello(): void {
    console.log(`Hello, I'm ${this.name}, ${this.age} years old`);
  }
}

// 创建实例
const person = new Person("Alice", 25);
person.sayHello(); // 输出：Hello, I'm Alice, 25 years old
```

### 注意点：

- 属性必须先声明（指定类型）才能在构造函数中赋值，否则TS会报错。
- 实例通过`new`关键字创建，调用构造函数初始化。

## 二、访问修饰符（Access Modifiers）

TS提供3种访问修饰符，控制类成员（属性/方法）的可访问范围：

| 修饰符   | 含义                                                                 | 访问范围                                     |
|----------|----------------------------------------------------------------------|----------------------------------------------|
| `public` | 公开的（默认值，可省略）                                             | 类内部、子类、类外部（实例）均能访问         |
| `private`| 私有成员                                                             | 仅类内部可访问，子类和外部均不可访问         |
| `protected` | 受保护成员                                                          | 类内部和子类可访问，类外部（实例）不可访问   |

### 1. `public`（默认）

```typescript
class Person {
  public name: string; // 等同于 name: string
  public constructor(name: string) {
    this.name = name;
  }
  public sayName() {
    console.log(this.name);
  }
}

const p = new Person("Bob");
console.log(p.name); // 可访问（外部）
p.sayName(); // 可访问（外部）
```

### 2. `private`（私有）

私有成员仅在当前类内部可见，子类和实例均无法访问：

```typescript
class Person {
  private id: number; // 私有属性
  constructor(id: number) {
    this.id = id; // 类内部可访问
  }
  private getID() { // 私有方法
    return this.id;
  }
}

const p = new Person(1001);
console.log(p.id); // 报错：属性“id”为私有属性，只能在类“Person”中访问
p.getID(); // 报错：方法“getID”为私有方法，只能在类“Person”中访问

// 子类也无法访问父类的private成员
class Student extends Person {
  constructor(id: number) {
    super(id);
    console.log(this.id); // 报错：属性“id”为私有属性，只能在类“Person”中访问
  }
}
```

### 3. `protected`（受保护）

受保护成员可在当前类和子类中访问，但实例无法访问：

```typescript
class Person {
  protected familyName: string; // 受保护属性
  constructor(familyName: string) {
    this.familyName = familyName; // 类内部可访问
  }
  protected getFamilyName() { // 受保护方法
    return this.familyName;
  }
}

class Student extends Person {
  constructor(familyName: string) {
    super(familyName);
    console.log(this.familyName); // 子类可访问父类protected属性
    console.log(this.getFamilyName()); // 子类可访问父类protected方法
  }
}

const s = new Student("Smith");
console.log(s.familyName); // 报错：属性“familyName”为受保护属性，只能在类“Person”及其子类中访问
```

## 三、`readonly` 修饰符

`readonly`用于声明只读属性，只能在**声明时**或**构造函数中**初始化，之后不可修改：

```typescript
class Book {
  readonly isbn: string; // 只读属性
  readonly publishYear: number = 2020; // 声明时初始化

  constructor(isbn: string) {
    this.isbn = isbn; // 构造函数中初始化
  }

  updateIsbn(newIsbn: string) {
    this.isbn = newIsbn; // 报错：无法分配到“isbn”，因为它是只读属性
  }
}

const book = new Book("978-0000000000");
book.isbn = "new-isbn"; // 报错：只读属性不可修改
```

### 注意：

- `readonly`可与访问修饰符结合使用（如`private readonly`、`protected readonly`）。
- 只读属性在实例化后不可变，适合存储固定标识（如ID、ISBN等）。

## 四、继承（Inheritance）

TS通过`extends`关键字支持类的继承（单继承），子类可复用父类的属性和方法，并可扩展或重写父类功能。

### 基本用法

```typescript
// 父类
class Animal {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  move(distance: number = 0) {
    console.log(`${this.name} moved ${distance}m`);
  }
}

// 子类（继承Animal）
class Dog extends Animal {
  // 扩展子类特有属性
  breed: string;

  // 子类构造函数必须调用super()（父类构造函数）
  constructor(name: string, breed: string) {
    super(name); // 调用父类构造函数，必须在this之前
    this.breed = breed;
  }

  // 重写父类方法
  move(distance: number = 5) {
    console.log("Dog moving...");
    super.move(distance); // 调用父类方法
  }

  // 子类特有方法
  bark() {
    console.log(`${this.name} barks: Woof!`);
  }
}

const dog = new Dog("Buddy", "Golden Retriever");
dog.bark(); // 输出：Buddy barks: Woof!
dog.move(10); // 输出：Dog moving... Buddy moved 10m
```

### 关键点：

- 子类构造函数必须通过`super()`调用父类构造函数，且`super()`必须在`this`之前调用。
- 子类可重写父类方法（方法名和参数类型需兼容）。
- 子类可扩展自己的属性和方法。

## 五、抽象类（Abstract Classes）

抽象类是**不能直接实例化**的类，用于定义基类（父类）的结构，强制子类实现特定方法。通过`abstract`关键字声明。

### 特点：

- 抽象类可包含**抽象方法**（无实现体，需子类实现）和**具体方法**（有实现体）。
- 子类必须实现抽象类中的所有抽象方法，否则子类也需声明为抽象类。

```typescript
// 抽象类
abstract class Shape {
  // 抽象方法（无实现，仅定义结构）
  abstract getArea(): number;

  // 具体方法（有实现）
  printArea() {
    console.log(`Area: ${this.getArea()}`);
  }
}

// 子类实现抽象类
class Circle extends Shape {
  radius: number;
  constructor(radius: number) {
    super(); // 抽象类也是类，需调用super()
    this.radius = radius;
  }

  // 必须实现抽象方法getArea()
  getArea(): number {
    return Math.PI * this.radius **2;
  }
}

// 抽象类不能实例化
const shape = new Shape(); // 报错：无法创建抽象类的实例

// 子类实例化
const circle = new Circle(5);
circle.printArea(); // 输出：Area: 78.53981633974483
```

## 六、静态成员（Static Members）

静态成员（属性/方法）属于**类本身**，而非实例，通过`static`关键字声明，可直接通过类名访问。

```typescript
class MathUtil {
  // 静态属性
  static PI: number = 3.14159;

  // 静态方法
  static calculateCircleArea(radius: number): number {
    return this.PI * radius** 2; // 静态方法中用this访问静态属性
  }

  // 实例方法无法直接访问静态成员（需通过类名）
  getPI() {
    return MathUtil.PI; // 正确：通过类名访问
    // return this.PI; // 错误：实例无法访问静态属性
  }
}

// 访问静态成员（无需实例化）
console.log(MathUtil.PI); // 输出：3.14159
console.log(MathUtil.calculateCircleArea(2)); // 输出：12.56636

// 实例化后访问静态成员
const util = new MathUtil();
console.log(util.getPI()); // 输出：3.14159
```

### 应用场景：

- 工具类（如`MathUtil`、`DateUtil`）的工具方法。
- 全局共享的常量或计数器（如`User.count`统计用户数量）。

## 七、存取器（Getters & Setters）

存取器用于控制属性的访问，通过`get`（获取值）和`set`（设置值）方法封装属性操作，可添加验证或额外逻辑。

```typescript
class User {
  private _age: number; // 私有属性，通过存取器访问

  constructor(age: number) {
    this._age = age;
  }

  // Getter：获取属性值
  get age(): number {
    return this._age;
  }

  // Setter：设置属性值（可添加验证）
  set age(newAge: number) {
    if (newAge < 0 || newAge > 150) {
      throw new Error("Invalid age (must be 0-150)");
    }
    this._age = newAge;
  }
}

const user = new User(20);
console.log(user.age); // 调用getter，输出：20

user.age = 30; // 调用setter，设置成功
user.age = 200; // 调用setter，抛出错误：Invalid age (must be 0-150)
```

### 注意：

- 存取器通常配合私有属性使用（如`_age`），避免直接暴露属性。
- 如果只定义`get`而不定义`set`，则属性为只读。

## 八、类实现接口（Implements）

类可以通过`implements`关键字实现接口，强制类遵循接口定义的结构（属性和方法）。

```typescript
// 定义接口
interface Movable {
  speed: number;
  move(): void;
}

// 类实现接口
class Car implements Movable {
  speed: number; // 必须实现接口的属性

  constructor(speed: number) {
    this.speed = speed;
  }

  move(): void { // 必须实现接口的方法
    console.log(`Car moving at ${this.speed}km/h`);
  }
}

// 类可实现多个接口（用逗号分隔）
interface Chargeable {
  charge(): void;
}

class ElectricCar implements Movable, Chargeable {
  speed: number;

  constructor(speed: number) {
    this.speed = speed;
  }

  move(): void {
    console.log(`Electric car moving at ${this.speed}km/h`);
  }

  charge(): void {
    console.log("Charging...");
  }
}
```

### 关键点：

- 类必须实现接口中声明的**所有属性和方法**（包括类型匹配）。
- 接口仅约束结构，不提供实现；抽象类可提供部分实现。

## 九、泛型类（Generic Classes）

泛型类通过泛型参数使类支持多种数据类型，提高复用性。泛型参数在类名后用`<T>`声明。

```typescript
// 泛型类（T为类型参数）
class Container<T> {
  private value: T;

  constructor(value: T) {
    this.value = value;
  }

  getValue(): T {
    return this.value;
  }

  setValue(newValue: T): void {
    this.value = newValue;
  }
}

// 实例化时指定类型参数
const numberContainer = new Container<number>(100);
console.log(numberContainer.getValue()); // 类型：number，值：100

const stringContainer = new Container<string>("hello");
console.log(stringContainer.getValue()); // 类型：string，值：hello

// TS可自动推断类型
const booleanContainer = new Container(true); // 推断为 Container<boolean>
```

### 应用场景：

- 容器类（如`Array`、`Map`）、工具类等需要支持多种类型的场景。

## 十、参数属性（Parameter Properties）

参数属性是简化代码的语法，在构造函数参数前添加访问修饰符（`public`/`private`/`protected`/`readonly`），可直接将参数声明为类属性，无需单独定义。

```typescript
// 普通写法
class Person {
  name: string;
  private age: number;
  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}

// 参数属性简化写法
class Person {
  // 直接在构造函数参数中声明属性
  constructor(public name: string, private age: number) {}
}

// 效果完全相同
const p = new Person("Alice", 25);
console.log(p.name); // 可访问（public）
console.log(p.age); // 报错（private）
```

## 十一、类的`this`类型

类的方法中，`this`默认指向实例，可通过`this`类型约束方法的调用上下文，或实现链式调用。

```typescript
class Calculator {
  value: number;

  constructor(value: number) {
    this.value = value;
  }

  // this作为返回值，实现链式调用
  add(num: number): this {
    this.value += num;
    return this; // 返回当前实例
  }

  multiply(num: number): this {
    this.value *= num;
    return this;
  }
}

const calc = new Calculator(10);
const result = calc.add(5).multiply(2).value; // 链式调用
console.log(result); // 输出：30（(10+5)*2）
```

## 十二、类的合并（Class Merging）

TS支持类与同名命名空间（namespace）合并，用于扩展类的静态成员。

```typescript
// 类定义
class Tool {
  static version: string = "1.0.0";
}

// 命名空间合并（扩展静态成员）
namespace Tool {
  export function getInfo() {
    return `Tool v${Tool.version}`;
  }
}

// 使用合并后的类
console.log(Tool.version); // 输出：1.0.0
console.log(Tool.getInfo()); // 输出：Tool v1.0.0
```

## 总结

TypeScript的类在ES6基础上增强了类型安全和封装性，核心特性包括：

- 访问修饰符（`public`/`private`/`protected`）控制成员访问范围。
- `readonly`确保属性不可修改。
- 继承（`extends`）和抽象类（`abstract`）支持代码复用和约束。
- 静态成员属于类本身，适合工具方法。
- 存取器（`get`/`set`）增强属性访问控制。
- 接口实现（`implements`）和泛型类提升灵活性和规范性。

掌握这些特性可以更高效地使用TypeScript进行面向对象编程，构建可维护、类型安全的应用。
