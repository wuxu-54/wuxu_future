# TypeScript 内置工具类型

你需要的是 TypeScript 内置工具类型的**全量、精细化详解**，涵盖所有官方工具类型的定义、用法、场景和边界规则，以下内容基于 TS 5.5 最新源码（`lib.es5.d.ts`/`lib.typescript.d.ts`），按「核心分类」梳理，每个类型包含**源码定义、通俗解释、基础示例、进阶场景、注意事项**，确保覆盖所有实用场景。

## 一、工具类型核心说明

TypeScript 内置工具类型（Utility Types）是 TS 提供的**泛型类型函数**，本质是「预定义的类型变换逻辑」，仅作用于**编译阶段**（运行时无任何痕迹），核心作用是：

1. 简化重复的类型定义逻辑；
2. 实现类型的动态变换（如可选、只读、筛选、映射等）；
3. 提升类型代码的可读性和可维护性。

所有工具类型均基于 TS 高级类型特性实现：泛型、条件类型、映射类型、索引访问类型、模板字面量类型等。

## 二、核心工具类型全解（按功能分类）

### 1. 基础类型变换（最常用）

#### 1.1 `Partial<T>` - 所有属性变为可选

##### 源码定义

```typescript
type Partial<T> = {
    [P in keyof T]?: T[P];
};
```

##### 解释

遍历类型 `T` 的所有属性 `P`，给每个属性添加 `?` 修饰符，使其变为可选属性。

##### 基础示例

```typescript
interface User {
  name: string;
  age: number;
  gender: string;
}

// 所有属性变为可选
type PartialUser = Partial<User>;
const user: PartialUser = { name: "张三" }; // ✔️ 仅传name即可
```

##### 进阶场景：局部可选（结合 Pick/Omit）

```typescript
// 仅让 name/age 可选，gender 仍必选
type PartialUserPartial = Omit<User, "gender"> & Partial<Pick<User, "name" | "age">>;
const user2: PartialUserPartial = { gender: "男" }; // ✔️
```

##### 注意事项

- `Partial` 仅处理**第一层属性**，嵌套对象的属性不会变为可选（需手动实现深层 Partial，见下文「自定义扩展」）；
- 不会新增/删除属性，仅修改属性的可选性。

#### 1.2 `Required<T>` - 所有属性变为必选

##### 源码定义

```typescript
type Required<T> = {
    [P in keyof T]-?: T[P];
};
```

##### 解释

遍历 `T` 的所有属性，移除 `?` 修饰符（`-?` 表示「移除可选标记」），强制所有属性为必选。

##### 示例

```typescript
interface PartialUser {
  name?: string;
  age?: number;
}

// 所有属性变为必选
type RequiredUser = Required<PartialUser>;
const user: RequiredUser = { name: "张三", age: 25 }; // ✔️ 必须传所有属性
const badUser: RequiredUser = { name: "李四" }; // ❌ 缺少age
```

##### 注意事项

- 仅处理第一层属性的可选性；
- 若原类型有「可选且未定义」的属性（如 `name?: string | undefined`），`Required` 仅移除 `?`，但值仍可传 `undefined`（需结合 `NonNullable` 处理）。

#### 1.3 `Readonly<T>` - 所有属性变为只读

##### 源码定义

```typescript
type Readonly<T> = {
    readonly [P in keyof T]: T[P];
};
```

##### 解释

遍历 `T` 的所有属性，添加 `readonly` 修饰符，使其无法被重新赋值。

##### 示例

```typescript
interface User {
  name: string;
  age: number;
}

type ReadonlyUser = Readonly<User>;
const user: ReadonlyUser = { name: "张三", age: 25 };
user.name = "李四"; // ❌ 只读属性无法修改
```

##### 进阶：深层只读

```typescript
// 自定义深层 Readonly
type DeepReadonly<T> = {
  readonly [P in keyof T]: T[P] extends object ? DeepReadonly<T[P]> : T[P];
};

interface NestedUser {
  name: string;
  info: { age: number };
}

type DeepReadonlyUser = DeepReadonly<NestedUser>;
const user: DeepReadonlyUser = { name: "张三", info: { age: 25 } };
user.info.age = 30; // ❌ 深层属性也只读
```

### 2. 属性筛选与映射

#### 2.1 `Pick<T, K>` - 筛选指定属性

##### 源码定义

```typescript
type Pick<T, K extends keyof T> = {
    [P in K]: T[P];
};
```

##### 解释

从类型 `T` 中**筛选出** `K` 中指定的属性（`K` 必须是 `T` 的属性名子集），生成新类型。

##### 基础示例

```typescript
interface User {
  name: string;
  age: number;
  gender: string;
}

// 仅保留 name 和 age 属性
type PickUser = Pick<User, "name" | "age">;
const user: PickUser = { name: "张三", age: 25 }; // ✔️
const badUser: PickUser = { name: "李四", gender: "男" }; // ❌ 包含未筛选的gender
```

##### 进阶：动态筛选（结合联合类型）

```typescript
type UserKeys = "name" | "age";
type DynamicPickUser = Pick<User, UserKeys>; // 等价于 Pick<User, "name" | "age">
```

##### 注意事项

- `K` 必须是 `keyof T` 的子类型，否则 TS 报错；
- 筛选后的属性保持原有的可选性/只读性。

#### 2.2 `Omit<T, K>` - 排除指定属性

##### 源码定义

```typescript
type Omit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>;
```

##### 解释

从类型 `T` 中**排除** `K` 中指定的属性，本质是 `Pick + Exclude` 的组合（先排除属性名，再筛选剩余属性）。

##### 基础示例

```typescript
interface User {
  name: string;
  age: number;
  gender: string;
}

// 排除 gender 属性
type OmitUser = Omit<User, "gender">;
const user: OmitUser = { name: "张三", age: 25 }; // ✔️
```

##### 进阶：排除多个属性 + 扩展新属性

```typescript
// 排除 age/gender，新增 id 属性
type ExtendedUser = Omit<User, "age" | "gender"> & { id: number };
const user: ExtendedUser = { name: "张三", id: 1001 }; // ✔️
```

##### 注意事项

- `K` 可以是任意合法的属性名（即使不在 `T` 中），TS 会自动忽略不存在的属性；
- 与 `Pick` 互补：`Pick` 是「保留」，`Omit` 是「排除」。

#### 2.3 `Record<K, T>` - 定义键值对类型

##### 源码定义

```typescript
type Record<K extends keyof any, T> = {
    [P in K]: T;
};
```

##### 解释

创建一个对象类型：

- 键的类型为 `K`（K 可以是 string/number/symbol 的任意子类型（如字面量类型、联合类型、枚举、symbol 常量等），但不能是这三类之外的类型（如 boolean/object 等），即合法的对象键类型）；
- 所有键对应的值类型为 `T`。

##### 基础示例

```typescript
// 键为 'zh-CN'/'en-US'，值为 { title: string }
type Translate = Record<"zh-CN" | "en-US", { title: string }>;
const translate: Translate = {
  "zh-CN": { title: "首页" },
  "en-US": { title: "Home" },
};
```

##### 进阶：结合枚举

```typescript
enum OrderStatus {
  PENDING = 0,
  PAID = 1,
  SHIPPED = 2,
}

// 状态码 → 状态名称的映射
type StatusMap = Record<OrderStatus, string>;
const statusMap: StatusMap = {
  [OrderStatus.PENDING]: "待支付",
  [OrderStatus.PAID]: "已支付",
  [OrderStatus.SHIPPED]: "已发货",
};
```

##### 注意事项

- `Record` 要求对象**必须包含所有 `K` 中的键**，不能少也不能多（严格模式下）；
- 与索引签名的区别：`Record` 约束「固定键」，索引签名约束「任意键」。

### 3. 联合类型操作

#### 3.1 `Exclude<T, U>` - 排除联合类型中的指定成员

##### 源码定义

```typescript
type Exclude<T, U> = T extends U ? never : T;
```

##### 解释

遍历联合类型 `T` 的每个成员，若成员可赋值给 `U`，则排除（返回 `never`），否则保留该成员。

##### 基础示例

```typescript
type AllKeys = "name" | "age" | "gender" | "id";
type ExcludeKeys = "gender" | "id";

// 排除 ExcludeKeys 中的成员，结果："name" | "age"
type RemainingKeys = Exclude<AllKeys, ExcludeKeys>;
```

##### 进阶：排除类型中的函数属性

```typescript
interface User {
  name: string;
  age: number;
  sayHello: () => void;
}

// 排除函数类型的属性，结果："name" | "age"
type NonFunctionKeys = Exclude<keyof User, Function>;
type UserWithoutFunctions = Pick<User, NonFunctionKeys>;
```

#### 3.2 `Extract<T, U>` - 提取联合类型中的指定成员

##### 源码定义

```typescript
type Extract<T, U> = T extends U ? T : never;
```

##### 解释

与 `Exclude` 相反：遍历联合类型 `T` 的每个成员，若成员可赋值给 `U`，则保留，否则排除（返回 `never`）。

##### 示例

```typescript
type AllKeys = "name" | "age" | "gender" | "id";
type ExtractKeys = "gender" | "id";

// 提取 ExtractKeys 中的成员，结果："gender" | "id"
type ExtractedKeys = Extract<AllKeys, ExtractKeys>;
```

##### 进阶：提取类型中的数字属性名

```typescript
type MixedKeys = "name" | 100 | "age" | 200 | symbol;
// 提取数字类型的键，结果：100 | 200
type NumberKeys = Extract<MixedKeys, number>;
```

#### 3.3 `NonNullable<T>` - 排除 null/undefined

##### 源码定义

```typescript
type NonNullable<T> = T extends null | undefined ? never : T;
```

##### 解释

从类型 `T` 中排除 `null` 和 `undefined`，仅保留非空类型。

##### 基础示例

```typescript
type NullableString = string | null | undefined;
// 结果：string
type NonNullableString = NonNullable<NullableString>;

type NullableUser = User | null;
// 结果：User
type NonNullableUser = NonNullable<NullableUser>;
```

##### 进阶：处理函数返回值

```typescript
// 函数返回值可能为 null
function getUser(): User | null {
  return Math.random() > 0.5 ? { name: "张三", age: 25 } : null;
}

// 提取非空返回值类型：User
type UserReturnType = NonNullable<ReturnType<typeof getUser>>;
```

### 4. 函数类型操作

#### 4.1 `Parameters<T>` - 提取函数的参数类型

##### 源码定义

```typescript
type Parameters<T extends (...args: any) => any> = T extends (...args: infer P) => any ? P : never;
```

##### 解释

- 约束 `T` 必须是函数类型；
- 用 `infer P` 推断函数的参数数组类型，返回该数组类型（元组）。

##### 基础示例

```typescript
// 定义函数
function getUserInfo(id: number, name: string): User {
  return { name, age: 25, gender: "男" };
}

// 提取参数类型：[id: number, name: string]（元组）
type UserInfoParams = Parameters<typeof getUserInfo>;

// 使用：解构参数类型
const params: UserInfoParams = [1001, "张三"]; // ✔️
```

##### 进阶：提取单个参数类型

```typescript
// 提取第一个参数类型：number
type FirstParam = Parameters<typeof getUserInfo>[0];
// 提取第二个参数类型：string
type SecondParam = Parameters<typeof getUserInfo>[1];
```

#### 4.2 `ReturnType<T>` - 提取函数的返回值类型

##### 源码定义

```typescript
type ReturnType<T extends (...args: any) => any> = T extends (...args: any) => infer R ? R : any;
```

##### 解释

- 约束 `T` 必须是函数类型；
- 用 `infer R` 推断函数的返回值类型，返回该类型。

##### 基础示例

```typescript
function getUserInfo(): User {
  return { name: "张三", age: 25, gender: "男" };
}

// 提取返回值类型：User
type UserInfoReturn = ReturnType<typeof getUserInfo>;
```

##### 进阶：提取异步函数返回值

```typescript
async function fetchUser(): Promise<User> {
  return await Promise.resolve({ name: "张三", age: 25, gender: "男" });
}

// 提取异步函数返回值（需结合 Awaited）：User
type FetchUserReturn = Awaited<ReturnType<typeof fetchUser>>;
```

#### 4.3 `ConstructorParameters<T>` - 提取构造函数的参数类型

##### 源码定义

```typescript
type ConstructorParameters<T extends abstract new (...args: any) => any> = T extends abstract new (...args: infer P) => any ? P : never;
```

##### 解释

与 `Parameters` 类似，但针对**构造函数**（`new` 调用的函数），返回构造函数的参数元组类型。

##### 示例

```typescript
class UserClass {
  constructor(id: number, name: string) {
    // ...
  }
}

// 提取构造函数参数类型：[id: number, name: string]
type UserCtorParams = ConstructorParameters<typeof UserClass>;

// 使用
const ctorParams: UserCtorParams = [1001, "张三"];
const user = new UserClass(...ctorParams); // ✔️
```

#### 4.4 `InstanceType<T>` - 提取构造函数的实例类型

##### 源码定义

```typescript
type InstanceType<T extends abstract new (...args: any) => any> = T extends abstract new (...args: any) => infer R ? R : any;
```

##### 解释

推断构造函数 `T` 实例化后的类型（即 `new T()` 的返回值类型）。

##### 示例

```typescript
class UserClass {
  id: number;
  name: string;
  constructor(id: number, name: string) {
    this.id = id;
    this.name = name;
  }
}

// 提取实例类型：UserClass
type UserInstance = InstanceType<typeof UserClass>;

const user: UserInstance = new UserClass(1001, "张三"); // ✔️
```

### 5. 模板字面量类型（TS 4.1+）

基于模板字符串语法，实现字符串类型的拼接、替换、拆分，常与联合类型结合实现动态字符串类型。

#### 5.1 `Uppercase<T>` - 转为大写

```typescript
type LowercaseStr = "hello";
// 结果："HELLO"
type UppercaseStr = Uppercase<LowercaseStr>;
```

#### 5.2 `Lowercase<T>` - 转为小写

```typescript
type UppercaseStr = "HELLO";
// 结果："hello"
type LowercaseStr = Lowercase<UppercaseStr>;
```

#### 5.3 `Capitalize<T>` - 首字母大写

```typescript
type Str = "hello";
// 结果："Hello"
type CapitalizedStr = Capitalize<Str>;
```

#### 5.4 `Uncapitalize<T>` - 首字母小写

```typescript
type Str = "Hello";
// 结果："hello"
type UncapitalizedStr = Uncapitalize<Str>;
```

##### 进阶：动态生成属性名

```typescript
type Actions = "get" | "set" | "delete";
type Resources = "user" | "order";

// 生成 "getUser" | "getOrder" | "setUser" | "setOrder" | "deleteUser" | "deleteOrder"
type ActionNames = `${Capitalize<Actions>}${Capitalize<Resources>}`;
```

### 6. 其他工具类型（TS 新版本新增）

#### 6.1 `Awaited<T>` - 提取 Promise 解析后的类型（TS 4.5+）

##### 源码定义

```typescript
type Awaited<T> = T extends null | undefined
  ? T // 处理 null/undefined
  : T extends object & { then(onfulfilled: infer F, ...args: infer _): any }
    ? F extends (value: infer V, ...args: infer _) => any
      ? Awaited<V> // 递归解析嵌套 Promise
      : never
    : T;
```

##### 解释

递归解析 `Promise` 的最终返回类型，支持嵌套 Promise。

##### 示例

```typescript
// 单层 Promise
type PromiseUser = Promise<User>;
// 结果：User
type ResolvedUser = Awaited<PromiseUser>;

// 嵌套 Promise
type NestedPromise = Promise<Promise<User>>;
// 结果：User
type ResolvedNestedUser = Awaited<NestedPromise>;

// 联合类型 Promise
type UnionPromise = Promise<User | string>;
// 结果：User | string
type ResolvedUnion = Awaited<UnionPromise>;
```

#### 6.2 `ThisParameterType<T>` - 提取函数的 this 类型（TS 3.7+）

##### 示例

```typescript
function sayHello(this: User, message: string) {
  console.log(`${this.name}: ${message}`);
}

// 提取 this 类型：User
type ThisType = ThisParameterType<typeof sayHello>;
```

#### 6.3 `OmitThisParameter<T>` - 移除函数的 this 参数（TS 3.7+）

##### 示例

```typescript
function sayHello(this: User, message: string) {
  console.log(`${this.name}: ${message}`);
}

// 移除 this 参数后的函数类型：(message: string) => void
type NoThisFunc = OmitThisParameter<typeof sayHello>;
```

## 三、自定义扩展工具类型（实用场景）

官方工具类型仅覆盖基础场景，实际开发中常需扩展以下自定义工具类型：

### 1. `DeepPartial<T>` - 深层可选

```typescript
type DeepPartial<T> = T extends object
  ? {
      [P in keyof T]?: DeepPartial<T[P]>;
    }
  : T;

interface NestedUser {
  name: string;
  info: {
    age: number;
    address: {
      city: string;
    };
  };
}

// 所有层级属性均可选
type DeepPartialUser = DeepPartial<NestedUser>;
const user: DeepPartialUser = {
  name: "张三",
  info: { address: { city: "北京" } },
}; // ✔️
```

### 2. `DeepRequired<T>` - 深层必选

```typescript
type DeepRequired<T> = T extends object
  ? {
      [P in keyof T]-?: DeepRequired<T[P]>;
    }
  : T;
```

### 3. `PickByType<T, U>` - 按值类型筛选属性

```typescript
// 筛选 T 中值类型为 U 的属性
type PickByType<T, U> = {
  [P in keyof T as T[P] extends U ? P : never]: T[P];
};

interface User {
  name: string;
  age: number;
  gender: string;
  isVip: boolean;
}

// 筛选值类型为 string 的属性：{ name: string; gender: string }
type StringProps = PickByType<User, string>;
```

### 4. `Mutable<T>` - 移除只读属性

```typescript
type Mutable<T> = {
  -readonly [P in keyof T]: T[P];
};

type ReadonlyUser = Readonly<User>;
// 移除所有只读属性，可修改
type MutableUser = Mutable<ReadonlyUser>;
```

## 四、核心总结

### 关键要点回顾

1. 工具类型是 TS 编译阶段的「类型函数」，运行时无痕迹，基于泛型/条件类型/映射类型实现；
2. 核心分类：
   - 基础变换：`Partial`/`Required`/`Readonly`（修改属性修饰符）；
   - 属性筛选：`Pick`/`Omit`/`Record`（筛选/定义属性）；
   - 联合操作：`Exclude`/`Extract`/`NonNullable`（处理联合类型）；
   - 函数操作：`Parameters`/`ReturnType`/`ConstructorParameters`（提取函数类型）；
   - 字符串操作：`Uppercase`/`Capitalize`（模板字面量）；
   - 异步操作：`Awaited`（解析 Promise 类型）；
3. 官方工具类型仅处理第一层属性，深层操作需自定义扩展；
4. 最佳实践：
   - 优先使用官方工具类型简化代码；
   - 复杂场景结合多个工具类型（如 `Partial<Record<K, T>>`）；
   - 重复使用的自定义类型封装为通用工具（如 `DeepPartial`）。

### 版本兼容性

- 基础工具类型（`Partial`/`Pick`/`Record` 等）：TS 2.1+ 支持；
- 模板字面量类型（`Uppercase`/`Capitalize`）：TS 4.1+ 支持；
- `Awaited`：TS 4.5+ 支持；
- `ThisParameterType`/`OmitThisParameter`：TS 3.7+ 支持。

这份详解覆盖了 TS 所有内置工具类型的定义、用法和扩展场景，可作为日常开发的「工具类型速查手册」，确保你能高效实现各类类型变换需求。
