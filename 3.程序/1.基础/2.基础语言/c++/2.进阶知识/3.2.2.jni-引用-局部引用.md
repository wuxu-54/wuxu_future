# JNI：默认返回**局部引用(LocalRef)** 的API

一句话：**绝大多数创建/查找Java对象、拿到对象引用的JNI函数，返回出来的 `jobject/jclass/jstring/jarray` 都是局部引用 LocalRef**。

> 前提：只要函数返回 `jobject` 及其子类（`jclass、jstring、jobjectArray、jintArray` 等），基本都是局部引用。

## 一、最常用的默认返回 LocalRef 的API清单

### 1. 查找类 FindClass

```c
jclass FindClass(const char* name);
```

返回 jclass → **局部引用**

```c
jclass cls = env->FindClass("java/lang/String"); // LocalRef
```

> 经典坑：直接把这个cls存到static静态变量，方法返回后变成野句柄！要长期保存必须包一层`NewGlobalRef`。

### 2. 创建对象 NewObject / NewObjectA / NewObjectV

```c
jobject NewObject(jclass clazz, jmethodID methodID, ...);
```

返回新建Java对象 → LocalRef

### 3. 创建数组

```c
jstring NewStringUTF(const char* bytes); // jstring，LocalRef
jintArray NewIntArray(jsize length);
jobjectArray NewObjectArray(jsize length, jclass elementClass, jobject initialElement);
```

`jstring`、各种数组全部属于 jobject 子类，返回局部引用。

### 4. 获取对象字段 GetObjectField

```c
jobject GetObjectField(jobject obj, jfieldID fieldID);
```

拿到Java对象类型的字段，返回LocalRef。
> 基础类型`GetIntField/GetBooleanField`不是引用，是普通值，不存在引用管理。

### 5. 调用返回对象的Java方法 CallObjectMethod

```c
jobject CallObjectMethod(jobject obj, jmethodID methodID, ...);
```

Java方法返回Object/String/List，JNI拿到的返回值是局部引用。

### 6. 数组元素获取 GetObjectArrayElement

```c
jobject GetObjectArrayElement(jobjectArray array, jsize index);
```

拿到对象数组里单个元素，返回LocalRef。

### 7. GetStaticObjectField / CallStaticObjectMethod

静态字段、静态方法返回对象，同样返回**局部引用**。

### 8. 其他

`GetStringChars` 返回的不是引用，是char指针；
`GetArrayElements` 返回的是数组元素的内存指针，**不是jobject引用**，别搞混。

## 二、例外：哪些API**不是返回局部引用**

1. `NewGlobalRef` → 返回**全局引用 GlobalRef**
2. `NewWeakGlobalRef` → 返回**弱全局引用 jweak**
3. 基础类型API：`GetIntField、CallIntMethod`，返回int/boolean等基础类型，**不存在引用**
4. `GetMethodID / GetFieldID`：返回 `jmethodID / jfieldID`
    > ⚠️重点：methodID / fieldID **不是 jobject 引用！不需要DeleteLocalRef**，可以存静态变量长期复用，不用全局引用包装。
5. `NewLocalRef`：专门用来**基于已有引用新建一个局部引用**（它本身是主动创建LocalRef，不是默认返回）

## 三、关键规则

1. **上面这些默认API返回的LocalRef，生命周期绑定当前JNI栈帧**
    native方法return回Java后，JVM自动释放这些局部引用。
2. **默认API不会创建全局引用！**
    哪怕你拿到的对象是Java层的单例，JNI拿到的句柄依旧是局部引用。
3. `NewLocalRef` 平时很少手动调用，因为上面这些API已经直接产出LocalRef。
    `NewLocalRef` 用途：**从一个全局/弱全局引用，临时创建一个局部句柄来使用**。

## 四、举个例子区分

```c
// FindClass 默认返回 LocalRef
jclass local_cls = env->FindClass("android/util/Log"); 

// 如果要长期保存这个类，必须转全局引用
static jclass g_cls = nullptr;
g_cls = (jclass)env->NewGlobalRef(local_cls);

// local_cls 是局部引用，用完可以主动释放
env->DeleteLocalRef(local_cls);
```

## 五、容易踩的误区

❌误区：`jmethodID/jfieldID` 也是局部引用，需要Delete。
✅正确：methodID、fieldID是直接指向类内部的元数据，**不属于jobject引用，不用管理引用计数，可以静态保存**。

❌误区：CallObjectMethod返回的对象，是全局引用，可以存静态变量。
✅错误！返回的一定是局部引用，native函数返回直接失效。

## 六、快速判断口诀
>
> 返回 `jobject / jclass / jstring / jxxxArray` → 默认**局部引用**
> 返回 `jmethodID / jfieldID / int / long / bool` → 不是引用，不用Delete
> NewGlobalRef出来的才是全局引用
