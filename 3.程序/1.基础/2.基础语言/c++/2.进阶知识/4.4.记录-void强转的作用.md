# `(void)config;` 代码解释

```cpp
(void)config;
```

## 一句话作用

**消除编译器警告：变量定义了但是没有使用（unused variable）**。

### 详细拆解

1. `config`：是一个变量（参数/局部变量）
2. `(void)`：强制类型转换，把`config`转成`void`类型
3. 整行是一条**无效果的语句**，不会执行任何逻辑，**不会读取、修改config的值**。

> C/C++编译器默认规则：
> 如果你声明/接收了变量，全程代码里一次都不用，GCC/Clang/MSVC 会报警告：
> `warning: unused parameter 'config'`
>
> 写`(void)config;`就是告诉编译器：**我故意不使用这个变量，别给我报unused警告**。

## 最常见场景：函数参数暂时用不到

```cpp
void func(Config* config)
{
    (void)config; // 暂时不使用config参数，屏蔽未使用变量警告
    // 其他逻辑
}
```

比如：

- 接口规范要求函数必须带这个参数，但是当前版本代码暂时不用；
- 回调函数、虚函数重写，基类定义了参数，子类实现不需要用到它；
- 预留参数，以后扩展功能再使用`config`。

## 等价写法（不同风格）

```cpp
// C++17 推荐属性写法（更现代）
[[maybe_unused]] Config* config;
```

## ❗重点误区

1. **不是把config置空，不会释放内存**，完全不改变变量、不执行任何业务逻辑。
2. 只是**给编译器看的提示**，编译完之后这一行会被直接优化掉，不会生成机器指令。
3. 可以一次性写多个：

```cpp
(void)a;
(void)b;
```

## 举个完整例子

```cpp
void handle_event(int type, void* config)
{
    (void)config; // 暂时不用config，消除警告
    if(type == 1)
    {
        // do something
    }
}
```

如果删掉`(void)config;`，编译时就会出现：`unused parameter ‘config’`警告。

## 笔记精简

1. `(void)变量;`：**仅用来消除「未使用变量」的编译警告，无运行时作用**。
2. 多用于回调、虚函数、预留参数。
3. 不修改变量、不释放资源，运行时这一行直接被编译器优化掉。

> 拓展：CMake或者编译选项如果开了 `-Werror`（警告当作错误），这种unused警告会直接编译失败，`(void)config;` 就非常常用。
