# CMakeLists笔记

CMakeLists 是用于构建的配置文件。本质是构建脚本的配置，最终通过cmake命令执行。

##


## 记录

- `set(CMAKE_CXX_EXTENSIONS OFF)` : 禁用 GNU 扩展（-std=c++17 而非 -std=gnu++17）,目的是使代码更加通用性，有的系统不支持GNU写法导致报错，不过不写GNU会使代码变得复杂。

- `CMAKE_OSX_DEPLOYMENT_TARGET`:

    ```txt
    if(APPLE)
    set(CMAKE_OSX_DEPLOYMENT_TARGET "10.15") # 设定兼容os版本最低为10.15，如果使用大于10.15的新api，编译器会报错
    endif
    ```

- `option(BUILD_SHARED "Build shared library for FFI bindings" OFF)`:
  - option：CMake 内置命令，用于定义一个布尔型缓存变量（可在 GUI 或命令行中修改）。
  - BUILD_JNI：变量名称。在后面的 CMakeLists.txt 中，会通过 if(BUILD_JNI) 来判断是否执行构建 JNI 的代码。
  - "Build JNI binding shared library"：描述信息，在 CMake GUI（如 cmake-gui 或 VS 属性页）中显示给开发者看的说明文字。
  - OFF：默认值。意味着如果用户不主动打开，该选项就是 False，相关代码块会被跳过。 开启：`cmake -DBUILD_JNI=ON ..`
