# `const Object&` 函数入参 vs `int *const`

## 1、`const Object& obj` ：const 引用（函数形参）

```cpp
void func(const Object& obj)
{
    // obj 是引用别名
}
```

**含义：**

- `obj` 是**对象的引用**，是原对象的别名，不产生拷贝；
- **被引用的对象是 const，不能通过 obj 修改原对象**；
- 引用本身天生不可改变（引用一旦绑定一个对象，**不能重新绑定到别的对象**）。

```cpp
Object a;
func(a);

// 在func内部：
obj.modify();   // ❌ 不能调用非const成员函数，因为obj是const限定
obj = Object(); // ❌ 不能赋值，修改原对象
```

> 重点两件事：
>
> 1. **不拷贝对象**，直接引用外部传入对象；
> 2. **只读访问，禁止通过该引用修改源对象**。

> 引用没有“修改绑定目标”这种操作。引用初始化时绑定对象，终生不变。**引用本身不能被const修饰，`Object & const obj` 是非法C++代码！**

```cpp
void func(Object & const obj); // ❌ 编译报错！引用不能加const
// 合法只有 const Object& obj：指【被引用的对象是const】
```

👉 `const Object&` 的 const 修饰的是 **Object 对象本身**，不是引用。

## 2、`int *const p`：指针常量

```cpp
int *const p = &a;
```

`const` 修饰的是**指针变量p本身**。

规则：

1. **指针变量 p 的值（存储的地址）不可修改**，不能让p指向别的变量；
2. **但是可以修改指针指向的内容**。

```cpp
int a = 10;
int b = 20;
int *const p = &a;

*p = 100;   // ✅ ok，可以修改指向的数据
p = &b;     // ❌ 错误，p本身（地址）不能修改
```

### 区分另外一个：`const int *p` 常量指针

```cpp
const int* p = &a;
// const修饰 *p，指向内容只读；指针本身可以改指向
*p = 100; // ❌不能改内容
p = &b;   // ✅可以改指针指向别的地址
```

记忆口诀：

- `int *const p`：**指针本身const（地址不能变）**
- `const int *p`：**指向的内容const（内容不能变）**

# 表格对比：`const Object&` vs `int *const`

|项目|`const Object& obj`|`int *const p`|
|---|---|---|
|const修饰谁|**被引用的对象Object是const**|**指针变量p本身（存储的地址）是const**|
|能不能修改源对象内容|❌不可以，只读|✅可以修改指向的内容 `*p = xxx`|
|能不能重新绑定/指向另一个实体|❌引用天生不能换绑定，初始化定死|❌指针变量p不能存别的地址，不能p=&b|
|是否可为空|nullptr，不可能，引用必须绑定有效对象|✅指针可以存nullptr（初始化给null）|
|函数传参是否拷贝对象|❌不拷贝，别名|❌不拷贝，传递指针值（8字节）|
|语法陷阱|`Object & const obj` 非法，不能给引用加const|语法合法|

### 等价类比（很重要）

`const Object& obj` 等价于：

```cpp
const Object* const p; 
// const对象 + 指针本身不可改。但是引用没有指针语法。
```

- 既不能修改源对象，也不能换目标。
但是引用不会有空值风险。

> 注意，现实不会写 `const Object* const` 作为函数入参，一般直接写 `const Object*`。

## 3、函数参数四种写法对比，彻底理清

```cpp
// 1、值传递，拷贝对象，函数内修改副本，外部不受影响
void f1(Object obj);

// 2、普通引用，可以修改外部原对象，不能传临时对象
void f2(Object& obj);

// 3、const引用，只读原对象，不拷贝，可以接收临时对象！【最常用】
void f3(const Object& obj);

//4、普通指针，可以修改源对象，可以改变指针指向，可以传nullptr
void f4(Object* obj);

//5、const对象指针：对象只读；指针本身可以换指向
void f5(const Object* obj);

//6、Object *const：对象可修改；指针变量不能换指向，极少用作入参
void f6(Object *const obj);
```

### 重点特性：`const Object&` 可以接收临时对象

```cpp
f3(Object{}); // ✅允许，const&可以绑定临时对象
f2(Object{}); // ❌普通左值引用不能绑定临时对象
```

这也是为什么拷贝构造函数的参数是 `T(const T& other)`。

# 高频面试问答

### Q：为什么不能写 `Object & const obj`？
>
> 引用的语义就是：**一旦初始化绑定某个变量，永远不能重新绑定**。它天生就具备“引用本身不可修改”的属性，语言禁止给引用加const。const只能修饰被引用的类型，写在类型前面：`const Object&`。

### Q：`int *const` 为什么很少做函数入参？

函数形参 `void func(int *const p)`：
指针p是形参，只是函数内局部变量。就算加上`*const`，只是保证函数内部你不能写 `p=xxx`，**调用方不受任何限制**。这种限制意义很小，业务代码几乎不用。

> 一般指针入参：
>
> - 不想修改内容：`const int* p`
> - 需要修改内容：`int* p`
> 几乎不会用 `int *const`。

### Q：`const Object&` 日常使用场景

1. 函数入参，避免大对象拷贝，同时保证不会修改外部对象；
2. 拷贝构造函数参数；
3. 可以接收临时对象。

## 极简总结

1. `const Object& obj`：**对象是const只读，引用本身天生不可更换绑定；无拷贝，可以接收临时对象。const修饰的是对象。**
2. `int *const p`：**指针变量本身（存放的地址）const；但指向的数据可修改。const修饰指针变量本身。**

> 核心区分：const修饰的是哪一层。
>
> - 引用：只能修饰被引用的数据。
> - 指针：const可以修饰指针变量，也可以修饰指向的数据。
