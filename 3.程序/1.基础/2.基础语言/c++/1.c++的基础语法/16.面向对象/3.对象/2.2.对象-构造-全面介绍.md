# C++ 构造函数（全面总结）

**构造函数**：是类的一种特殊成员函数，**在创建对象时自动调用**，主要用于对象的初始化，给成员变量赋初值、分配资源等。

隐式（编译器帮我写出来）” ≠ “无参”

- 默认构造：属性是**无参可调用**
- 隐式合成：属性是**编译器自动生成函数体**

这是两套独立维度！

## 一、基本规则

1. 函数名**必须和类名完全相同**，没有返回值，也不能写 `void`。
2. 创建对象时由编译器自动调用，**不能手动显式调用**（ placement‑new 除外）。
3. 如果自己不写，编译器会**隐式生成默认构造函数**。
4. 构造函数可以重载，可以有参数。
5. 构造函数不能是 `virtual`、`const`、`static`。

```
#include <iostream>
using namespace std;

class Person {
public:
    // 构造函数，和类名同名，无返回值
    Person() {
        cout << "调用无参构造函数" << endl;
        age = 0;
    }
    int age;
};

int main() {
    Person p; // 创建对象，自动调用 Person()
    return 0;
}
```

## 二、构造函数的分类

### 1. 默认构造函数

>
> 能**无参数调用**的构造函数，叫默认构造函数。两种情况：

1. 自己写的无参构造函数 `Person()`
2. 编译器自动合成的默认构造函数（用户没有写任何构造函数时）

⚠️重点：只要你手写了任意一个构造函数（带参），编译器就**不再生成默认无参构造**。

```
class Person {
public:
    // 写了带参构造，编译器不会再生成无参默认构造
    Person(int a) { age = a; }
    int age;
};

int main(){
    // Person p; // 编译报错！没有无参构造
    Person p2(18); // 正确
}
```

>
> 编译器合成的默认构造函数行为：
>
>
> - 对于内置类型（int,double,指针）：**不会初始化，值是随机垃圾值**
> - 类类型成员：会调用该成员的默认构造函数。

### 2. 带参构造函数

用来创建对象时直接给成员赋初值：

```
class Person {
public:
    Person(int a, string n) {
        age = a;
        name = n;
    }
    int age;
    string name;
};

int main(){
    Person p(20, "zhangsan"); // 括号初始化
    Person p2{22, "lisi"};    // C++11列表初始化
}
```

### 3. 拷贝构造函数（复制构造函数）

>
> 格式：`类名(const 类名 & 旧对象)`
> 作用：用一个已经存在的同类型对象，去初始化新对象。

#### 触发拷贝构造三种场景

1. 用旧对象初始化新对象 `Person p2 = p1;` / `Person p2(p1);`
2. 函数参数，**值传递**（传对象，不是引用）
3. 函数返回值，**返回对象（值返回）**

```
class Person {
public:
    int age;
    // 拷贝构造函数
    Person(const Person &other) {
        cout << "拷贝构造执行" << endl;
        age = other.age;
    }
    Person(int a):age(a){}
};

int main(){
    Person p1(18);
    Person p2(p1);   // 场景1
    Person p3 = p1;  // 场景1，等价上面，不是赋值！是初始化
    return 0;
}
```

#### 编译器合成拷贝构造

如果你不写，编译器自动生成**浅拷贝拷贝构造**：逐成员拷贝（简单复制每个成员的值）。

>
> ⚠️浅拷贝问题：如果类里面有堆内存指针，浅拷贝会多个对象指向同一块堆内存，析构重复释放内存，程序崩溃。这时需要自己写**深拷贝**。

```
// 浅拷贝灾难示例
class Test{
public:
    int* p;
    Test(int val){
        p = new int(val);
    }
    // 编译器合成拷贝构造：只是 p = other.p; 两个对象p指向同一个堆地址
    ~Test(){ delete p; }
};
```

**深拷贝解决**：拷贝的时候重新new一块内存：

```
Test(const Test &other){
    p = new int(*other.p); // 开辟新堆内存
}
```

### 4. 移动构造函数 C++11

>
> 格式：`类名(类名 && other)`，接收**右值引用**
> 目的：接管临时对象的资源，避免拷贝，提升性能。
> 当用临时对象（右值）初始化新对象，会调用移动构造。

```
#include <iostream>
#include <cstring>
using namespace std;

class Str {
public:
    char* buf;
    Str(const char* s){
        buf = new char[strlen(s)+1];
        strcpy(buf, s);
    }
    // 移动构造
    Str(Str &&other) noexcept {
        cout<<"移动构造"<<endl;
        buf = other.buf;     // 直接抢夺资源，不复制
        other.buf = nullptr; // 原对象置空，析构不会释放
    }
    ~Str(){ delete[] buf; }
};

Str createTemp(){
    return Str("hello");
}

int main(){
    Str s = createTemp(); // 调用移动构造（可能被RVO返回值优化省略）
}
```

>
> 编译器条件生成移动构造：没有用户自定义拷贝构造、拷贝赋值、析构，才会合成默认移动构造。

### 5. 委托构造函数 C++11

一个构造函数，调用本类中另一个构造函数。
⚠️**只能在初始化列表调用，不能在函数体内调用！**

```
class Person{
public:
    Person():Person(0,""){} // 委托给下面的构造
    Person(int a, string n){
        age = a;
        name = n;
    }
    int age;
    string name;
};
```

### 6. 转换构造函数（单参数构造）

只有**一个参数**的构造函数，具备类型转换能力，可以把参数类型隐式转为类对象。

```
class Person{
public:
    Person(int a){ age = a; }
    int age;
};

void func(Person p){}

int main(){
    func(10); // 隐式转换：int -> Person，调用转换构造
}
```

不想允许隐式转换，加上关键字 **`explicit`**

```
explicit Person(int a){ age = a; }
// func(10); // 报错，禁止隐式转换
func(Person(10)); // 必须显式写
```

>
> `explicit` C++11可以用于多参数构造，防止列表初始化隐式转换。

## 三、初始化列表（构造初始化列表）

语法：

```
类名(参数) : 成员1(初值), 成员2(初值)
{
    // 构造函数体
}
```

### 重点特性

1. **初始化列表执行时机早于构造函数体**。
2. **成员变量初始化顺序 = 类中声明顺序，和初始化列表书写顺序无关！**
3. 下面这些成员**必须写在初始化列表初始化，不能在函数体内赋值**
   - `const` 成员变量
   - 引用成员变量
   - 没有默认构造的类类型成员

```
class A {
public:
    A(int x){} // A没有无参构造
};

class B{
public:
    const int c_val;
    int &ref;
    A a_obj;
    // 必须初始化列表
    B(int v, int &r) : c_val(v), ref(r), a_obj(100) {
    }
};
```

>
> 区分：初始化列表是**初始化**；函数体内是**赋值**。初始化只做一次，赋值是修改已经存在的变量。

## 四、编译器合成的五个特殊成员函数（C++98 / C++11）

一个类，如果用户不手写，编译器会在条件满足时自动生成：

1. **默认构造函数** `T()`
2. **拷贝构造函数** `T(const T&)`
3. **拷贝赋值运算符** `T& operator=(const T&)`
4. **析构函数** `~T()`
5. C++11新增：**移动构造 `T(T&&)`、移动赋值 `T& operator=(T&&)`**

>
> 如果你自己写了析构，编译器不会生成移动构造/移动赋值，但仍然生成拷贝构造、拷贝赋值（C++17前）。

### 禁用默认函数 `=delete` C++11

不想编译器生成某个默认函数，可以删除它：

```
class Person{
public:
    Person() = default;  // 显式要求编译器生成默认构造
    Person(const Person&) = delete; // 删除拷贝构造，禁止拷贝对象
};
```

`=default`：强制编译器生成合成版本；`=delete`：删掉这个函数，调用就编译报错。

## 五、继承中的构造函数

1. 子类构造的时候，**会先调用父类构造，再执行子类构造函数体**。
2. 默认调用父类**无参构造**；父类没有无参构造，子类必须在初始化列表显式调用父类带参构造。

```
class Base{
public:
    Base(int x){ cout<<"Base构造"<<endl; }
};

class Derive : public Base{
public:
    // Derive(){} // 报错，Base没有无参构造，子类必须指定父类构造
    Derive(): Base(10) { // 初始化列表显式调用父类构造
        cout<<"Derive构造"<<endl;
    }
};
```

3. 构造顺序：**父类 → 成员对象 → 当前子类构造函数体**

>
> 析构顺序完全相反：子类析构体 → 成员析构 → 父类析构

4. 拷贝构造继承：子类拷贝构造默认调用父类拷贝构造；如果自己手写子类拷贝，默认调用父类无参！要手动写初始化列表调用父类拷贝：

```
Derive(const Derive &d) : Base(d) { ... }
```

## 六、各种对象创建方式与构造调用

```
class Person{
public:
    Person();
    Person(int);
    Person(const Person&);
    Person(Person&&) noexcept;
};

Person p1;            // 无参默认构造
Person p2(10);         // 带参构造
Person p3{20};         // C++11列表初始化
Person p4(p2);         // 拷贝构造
Person p5 = p2;        // 拷贝构造（初始化，不是赋值）
Person p6 = Person(30); // 带参，临时对象，可能优化
Person p7 = std::move(p4); // 移动构造

Person* ptr = new Person;    // new调用无参构造，堆上对象
Person* ptr2 = new Person(5);
delete ptr;
```

>
> 注意：`Person p();` 这不是定义对象！这是一个函数声明，返回Person，名字p，无参数。坑！要写 `Person p;`

## 七、const对象构造

`const Person p;`

- const对象必须在构造完成时初始化；
- 构造函数执行阶段可以修改成员，**构造结束后对象变成const，不能修改成员**。
- 构造函数本身不能加const。

## 八、placement‑new（定位new，显式调用构造）

普通new分配内存+调用构造；placement‑new：**在已经分配好的内存上调用构造函数**。

```
char buf[sizeof(Person)]; // 预先分配一块原始内存
Person* p = new(buf) Person(10); // 在buf地址执行构造函数
// 销毁不能delete，手动调用析构
p->~Person();
```

这是极少数可以**显式调用构造函数**的场景。

## 九、常见易错点总结

1. 写了带参构造，编译器不再提供无参默认构造。
2. `Person p = obj;` 是初始化，调用拷贝构造，不是赋值运算符。
3. 浅拷贝遇到堆指针，会双重释放崩溃，要写深拷贝或者用智能指针。
4. 初始化列表初始化顺序看**声明顺序**，不是书写顺序。
5. 子类继承父类，父类无默认构造，子类初始化列表必须显式调用父类构造。
6. `explicit` 防止单参数构造带来的意外隐式类型转换。
7. `Person p();` 是函数声明，不是对象定义。
8. 拷贝构造参数必须是引用！如果写值传递 `Person(Person other)`，会无限递归。
