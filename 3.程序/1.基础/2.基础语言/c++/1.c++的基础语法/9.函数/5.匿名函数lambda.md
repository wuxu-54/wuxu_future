# C++ Lambda 匿名函数

C++11引入，**可以在代码行内就地定义一个临时函数**，不用写全局函数、不用写仿函数类，最常用于回调、算法、异步。

完整语法模板：

```
[捕获列表](参数列表) mutable ->返回类型
{
    函数体;
};
```

拆解每一部分：

1. `[]`：**捕获列表，最重要**，拿外部作用域变量
2. `()`：形参列表，和普通函数一样
3. `mutable`：可选，允许修改**值捕获**的副本变量
4. `->T`：可选，显式指定返回类型；大部分场景编译器自动推导，可以省略
5. `{}`：函数体

## 1. 捕获列表 []（核心）

>
> lambda本身是独立函数，默认看不见外面局部变量；必须通过`[]`捕获，才能访问外部变量。

| 写法 | 含义 |
| --- | --- |
| `[]` | 不捕获任何外部变量，只能用全局/静态变量 |
| `[x]` | **值捕获**：拷贝一份x到lambda内部，副本，改了不影响外面原变量 |
| `[&x]` | **引用捕获**：拿x的别名，内部修改会直接改动外部原变量 |
| `[=]` | 值捕获**所有用到的外部局部变量**，全部拷贝副本 |
| `[&]` | 引用捕获**所有用到的外部局部变量**，全部是引用 |
| `[=, &a]` | 默认全部值拷贝，唯独a使用引用捕获 |
| `[this]` | 捕获当前类对象指针，可以访问类成员变量、成员函数 |

### 示例

```
int a = 10;
int b = 20;

auto f1 = [a](){        // 值捕获a，拷贝副本
    // a = 100; // ❌ 默认不能修改拷贝进来的a
    std::cout << a;
};

auto f2 = [&a](){       // 引用捕获a
    a = 100; // ✅ 修改外部真实a
};

auto f3 = [=,&b](){
    // a是拷贝，b是引用
};
```

### mutable关键字

>
> 值捕获得到的副本，默认是`const`，不能修改。加`mutable`允许修改副本（**只改lambda里面的拷贝，外部原变量不变**）

```
int x = 10;
auto fun = [x]() mutable {
    x++;   // 修改的是内部拷贝副本，外面x不变
    std::cout << x;
};
fun();
std::cout << x; // 输出仍然是10
```

## 2. 返回类型 `-> Type`

大多数情况编译器自动推导返回值，可以省略`->`

```
// 自动推导返回int
auto add = [](int a,int b){
    return a+b;
};

// 多个return返回类型不一样，必须显式写返回类型
auto fun = [](int flag) -> double {
    if(flag) return 1.5;
    else return 2;
};
```

## 3. 怎么保存lambda？

1. `auto`（最简单）

```
auto my_lambda = [](int v){ return v*2; };
my_lambda(10);
```

2. 存到`std::function`（保存回调，类成员变量常用）
头文件 `<functional>`

```
std::function<void(int)> cb = [](int x){
    // ...
};
cb(100);
```

>
> ⚠️注意：只有**无捕获的lambda**可以转普通函数指针；有捕获的lambda不能转为函数指针，只能用`std::function`。

```
// 无捕获，可以转函数指针
void(*fp)(int) = [](int x){};

// [&x]有捕获，不能赋值给裸函数指针！必须std::function
```

## 4. 三大使用场景

### 场景1：STL算法作为谓词

```
#include <vector>
#include <algorithm>
int main() {
    std::vector<int> vec{1,3,5,7};
    // 过滤大于3的数字
    auto it = std::find_if(vec.begin(),vec.end(),[](int v){
        return v>3;
    });
    return 0;
}
```

### 场景2：异步回调（就是你刚才的promise例子）

```
std::promise<int> pro;
auto fut = pro.get_future();

// lambda作为回调参数传入函数
do_async_work([&pro](int res){
    pro.set_value(res);
});
```

### 场景3：就地执行（C++14，立刻调用）

```
int val = [](int a,int b){
    return a+b;
}(10,20); // 直接调用，val=30
```

## 5. 高频大坑（写业务最容易踩）

### 坑1：异步lambda使用引用捕获局部变量，悬垂引用（头号杀手）

```
std::thread th([&](){
    std::this_thread::sleep_for(std::chrono::seconds(1));
    // 此时局部变量a已经销毁！悬垂引用，UB崩溃
    std::cout << a;
});
// 函数结束，a销毁，线程1秒后才执行lambda
```

>
> 异步回调尽量不要无脑写`[&]`；只捕获必要变量，分清引用还是拷贝；保证捕获对象生命周期长于lambda执行。

### 坑2：`[this]`捕获，异步回调，类对象提前析构

lambda捕获`this`只是拿裸指针；如果类对象已经销毁，回调执行就崩溃。

### 坑3：mutable只修改副本，不修改外部变量

很多人误以为mutable能改外部变量，**mutable只修改值捕获的内部拷贝**。

### 坑4：lambda不能直接放入容器

```
// std::vector< [](int){} > vec; ❶语法不行
// 使用std::function包装
std::vector<std::function<void(int)>> callbacks;
callbacks.push_back([](int x){});
```

## 6. lambda等价于什么？（底层原理）

lambda编译器会**自动生成一个匿名仿函数类**。

```
auto f = [&promise](int v){ promise.set_value(v); };
```

编译器大致生成下面这个类：

```
class __anonymous_lambda
{
private:
    std::promise<NexusResult>& promise; //引用捕获的成员
public:
    void operator()(int v) const{
        promise.set_value(v);
    }
};
```

本质就是重载`operator()`的仿函数，只是不用我们手写类。

>
> 值捕获 → 类里面存成员变量（拷贝）
> 引用捕获 → 类里面存引用/指针

## 快速选型口诀

1. 需要访问外部变量，必须写捕获`[]`
2. 希望修改外面真实变量 → `&变量`引用捕获；注意生命周期
3. 只想拿一份拷贝，修改不影响外部 → 值捕获 `变量`，需要修改副本再加`mutable`
4. 类内lambda要访问成员：写`[this]`
5. 异步回调：拒绝无脑`[&]`，只捕获需要的变量
6. 需要保存回调作为成员变量，用`std::function<签名>`

## 对比普通函数

- lambda：可以捕获上下文，就地写，适合短回调；
- 普通全局函数：不能抓局部上下文，适合通用逻辑。

如果你需要，我给你对比：`lambda`、`std::function`、函数指针三者区别。
