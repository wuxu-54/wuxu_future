# 函数后面跟const

```cpp
NexusMetrics get_metrics() const;
```

这里有两个地方要分清：**返回值没有const**，**成员函数后面的 `const`**。

> `const` 写在函数圆括号后面：修饰**这个成员函数本身**，叫**const成员函数**。

# 1. 函数末尾 const 的作用

```cpp
NexusMetrics get_metrics() const;
```

含义：
> 调用这个成员函数时，**承诺不会修改类对象的任何非mutable成员变量**。
`this` 指针的类型变成：`const 类名* const this`，也就是**常量对象指针**。

简单几条规则：

1. 在这个函数体内，不能修改普通成员变量；
2. 只能调用其它**const成员函数**，不能调用非const成员函数；
3. **const对象 / const引用的对象，只能调用带const后缀的成员函数**。

示例类：

```cpp
struct NexusMetrics {
    int cpu;
    int mem;
};

class Monitor {
private:
    NexusMetrics m_data;
public:
    // ✅ const成员函数
    NexusMetrics get_metrics() const
    {
        // m_data.cpu = 100; // 编译报错！不能修改成员
        return m_data;
    }

    void set_cpu(int v)
    {
        m_data.cpu = v; // 修改成员，不能加const
    }
};
```

## 关键使用场景：const对象只能调用const成员

```cpp
void demo(const Monitor& mon)
{
    auto m = mon.get_metrics();  // ✅可以，get_metrics是const成员

    mon.set_cpu(10); // ❌编译报错！set_cpu不是const成员，mon是const引用
}
```

如果函数声明去掉末尾的`const`：

```cpp
NexusMetrics get_metrics(); // 没有const
```

那么上面 `const Monitor& mon` 调用 `mon.get_metrics()` 直接编译失败。

> 这是最实际的意义：如果你希望**常量对象也能调用这个查询接口**，getter读取接口必须加函数尾const。

# 2. 区分几个容易搞混的const写法

### 写法A（你题目这个）：返回对象，函数const

```cpp
NexusMetrics get_metrics() const;
```

- 函数：不修改对象；
- 返回值是**值拷贝**，返回一个新的NexusMetrics对象；调用方拿到副本可以随便修改。

```cpp
auto met = mon.get_metrics();
met.cpu = 999; // ✅允许，met是副本，和原对象无关
```

### 写法B：返回const对象（很少这么写）

```cpp
const NexusMetrics get_metrics() const;
```

返回的临时对象是const，外部拿到不能修改这个临时。现代C++一般不推荐，意义不大。

### 写法C：返回const引用（高频getter写法，避免拷贝）

```cpp
const NexusMetrics& get_metrics() const;
```

返回**引用**，不拷贝对象；返回const引用，外部不能修改内部成员。
> 如果`NexusMetrics`很大，优先用这个，避免拷贝开销。

### 写法D：返回非const引用（危险，泄露内部状态）

```cpp
NexusMetrics& get_metrics();
```

外部拿到引用可以直接修改类的私有成员，破坏封装；一般getter不要这么干。

# 3. const成员函数内部：mutable例外

如果某个成员标记`mutable`，即使在const成员函数里也可以修改：

```cpp
class Monitor {
private:
    NexusMetrics m_data;
    mutable int m_query_cnt; // mutable，const函数可修改
public:
    NexusMetrics get_metrics() const
    {
        m_query_cnt++; // ✅合法，mutable变量允许修改
        return m_data;
    }
};
```

`mutable`一般用于缓存、统计计数这种不改变对象业务逻辑状态的成员。

# 4. const成员函数的重载（重要）

同一个函数名，可以同时写 const / 非const两个版本：

```cpp
      NexusMetrics& get_metrics();
const NexusMetrics& get_metrics() const;
```

- 普通对象：调用非const版本；
- const对象/const引用：调用const版本。

# 5. 回到你的函数 `NexusMetrics get_metrics() const;` 总结

1. 末尾`const`：这是**只读查询接口**，承诺不修改本对象；
2. `const Monitor&` 这种常量引用也可以调用该接口；
3. 返回值是**值语义**：返回一份拷贝，外部修改返回值不会影响原对象；
4. 适合小结构体；如果NexusMetrics对象很大，优化成返回`const NexusMetrics& get_metrics() const;`减少拷贝。

## 开发规范小经验
>
> 所有**不修改对象状态的成员函数（getter、查询类）都应该加上函数尾const**。这是C++编码最佳实践，既能让const对象可用，编译器也帮你检查有没有不小心修改成员。

### 易错坑

```cpp
class A{
public:
    void foo() const {
        bar(); // ❌编译报错，bar不是const成员函数，const函数内部不能调用非const成员
    }
    void bar(){}
};
```

const成员函数内部，只能调用其他const成员函数。

如果你需要，我可以顺带讲：`const T*` / `T* const` / 成员函数后面`const`三者对比速记。
