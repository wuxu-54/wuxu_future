# 作用域

在 C++ 中，**作用域**（scope）指的是名字（变量、函数、类型等）在程序中的可见范围。同一个名字可以在不同作用域中指向不同实体，编译器通过作用域规则进行名字查找。C++ 的作用域种类繁多，下面按照你给出的结构，完整讲解各类作用域的特点、示例及注意事项。

---

## 1. 局部作用域（Local Scope / 块作用域 Block Scope）

局部作用域也称**块作用域**，是一对花括号 `{}` 界定的区域。它包括函数体这个大“块”，以及函数内部任意由 `{}` 构成的复合语句块。

- **变量声明位置**：在函数体内、或在任意 `{}` 内部声明的变量。
- **可见性**：从声明点开始，直到所在块的结束 `}` 为止。内层块可以访问外层块的变量，但若内层声明同名变量，会**隐藏**外层变量。
- **生命周期**：普通的局部变量（自动存储期）在进入块时创建，离开块时销毁。`static` 局部变量生命周期为整个程序，但作用域仍局限于该块。

```cpp
void func(int x) {        // x 的作用域：整个函数体
    int a = 10;           // a 的作用域：func 函数体
    {
        int b = 20;       // b 的作用域：内层块
        a = b + x;        // 可访问 a, x
    }
    // 此处 b 不可见
    a = 5;                // 仍可访问 a
}
```

>主要作用是：限定局部变量的生命周期，内存回收。

---

## 2. 全局作用域 / 文件作用域（Global Scope / File Scope）

在所有函数、类、命名空间之外声明的变量具有**全局作用域**（也称文件作用域）。它们从声明点开始直到文件结束都是可见的，并且可以通过 **`extern` 声明**被其他编译单元访问（拥有外部链接）。  
`static` 修饰的全局变量则限制为文件内部可见（内部链接），但作用域仍然是整个文件。

- **可见性**：整个文件，以及其他包含声明的文件（若为 `extern`）。
- **生命周期**：静态存储期，程序开始前分配，结束后释放。

```cpp
int global_var = 1;        // 全局作用域，外部链接
static int file_var = 2;   // 文件作用域（全局但内部链接）

void foo() {
    global_var = 10;       // 可以直接访问
}
```

> **注**：C++ 更推荐使用**匿名命名空间**（`namespace { ... }`）代替文件作用域的 `static`，功能相同且更符合 C++ 风格。

---

## 3. 类作用域（Class Scope）

在类定义内部声明的成员（变量、函数、类型别名等）具有**类作用域**。

- **可见性**：在整个类体内有效，类外访问需通过成员访问运算符 `.` 或 `->`，或通过作用域解析运算符 `::`（静态成员、类型名等）。
- **名字查找**：成员函数定义（即使写在类外）也能直接使用类作用域中的名字。
- **声明顺序**：与局部作用域不同，类作用域中的名字在整个类中可见，**声明可先使用后定义**（但类型名等特殊规则有例外）。

```cpp
class Example {
    int x;                  // 类作用域
public:
    void set(int a) { x = a; }
    int get() const;
};

int Example::get() const {  // 在类外定义，仍可直接使用 x
    return x;
}
```

---

## 4. 命名空间作用域（Namespace Scope）

命名空间用于将全局名字分组，避免冲突。命名空间内的变量、函数、类等具有**命名空间作用域**。

- **可见性**：从声明点开始，到命名空间结束。可通过 `using` 声明/指令引入其他作用域，或用 `::` 直接访问。
- **全局命名空间**：没有显式放在任何命名空间中的全局实体，属于全局命名空间，可用 `::name` 访问。

```cpp
namespace MyApp {
    int version = 1;        // 命名空间作用域
    void printVersion();
}

void MyApp::printVersion() {
    std::cout << version;   // 可直接访问同命名空间内的变量
}
```

---

## 5. 函数作用域（Function Scope）—— 仅适用于 goto 标签

在 C++ 中，**标签**（label，用于 `goto`）具有**函数作用域**。这意味着一个函数内，所有标签在整个函数体中都是可见的，**标签名必须在整个函数内唯一**，并且可以出现在定义它之前的 `goto` 语句中。

```cpp
void func() {
    goto my_label;          // 可以跳转到后面定义的标签
    // ...
my_label:
    std::cout << "Jumped";
}
```

> 注意：唯一拥有函数作用域的只有**标签**，普通变量不能有函数作用域。

---

## 6. 函数原型作用域（Function Prototype Scope）

在函数声明（不是定义）的**参数列表**中给出的参数名，其作用域仅限于该原型内部。这些名字只是“占位符”，编译器不要求它们与定义中的参数名一致，甚至可以省略。

- **作用域**：从参数名声明点开始，到原型声明结束为止。
- **用途**：仅用于文档说明，不影响调用或链接。

```cpp
void swap(int a, int b);    // a 和 b 的作用域仅在这条原型中
// 定义时可以叫不同的名字
void swap(int x, int y) { /* ... */ }
```

---

## 7. 语句作用域（Statement Scope）—— 适用于 if / for / while 等

C++ 中，在**`if`、`switch`、`while`、`for`** 等语句的**条件部分**或**初始化部分**声明的变量，其作用域**限定在该语句及其子块**内，这就是**语句作用域**。

- **传统 for 循环**：`for (int i = 0; i < 10; ++i)` 中的 `i` 作用域是整个循环体（包括 `for` 的条件和迭代表达式）。
- **while / if / switch 条件中声明**：如 `while (int x = getValue())`，`x` 的作用域是该 `while` 语句的整个循环体（包括条件检测和循环体）。对于 `if` 和 `switch`，作用域也包含 `else` 分支。
- **C++17 起**：`if` 和 `switch` 支持**初始化语句**，`if (init; condition)` 中 `init` 声明的变量同样属于语句作用域，它贯穿整个 `if-else` 语句。

```cpp
// for 循环初始化声明的变量
for (int i = 0; i < 5; ++i) {
    // i 在此可见
}
// i 不可见

// if (C++17 初始化器)
if (auto p = get_pointer(); p != nullptr) {
    p->doSomething();      // p 在此可见
} else {
    // p 在此也可见（值为 nullptr）
}
// p 不可见
```

---

## 总结

| 作用域类型 | 适用对象 | 可见范围 |
|------------|----------|----------|
| 局部作用域（块作用域） | 函数内或 `{}` 内声明的变量 | 声明点 → 块结尾 |
| 全局作用域 / 文件作用域 | 所有函数之外的变量 | 整个文件（可跨文件） |
| 类作用域 | 类成员 | 整个类，类外通过 `::` / `.` / `->` |
| 命名空间作用域 | 命名空间内实体 | 命名空间内部 |
| 函数作用域 | `goto` 标签 | 整个函数体 |
| 函数原型作用域 | 函数声明中的参数名 | 仅该原型声明 |
| 语句作用域 | `if/switch/while/for` 条件/初始化中声明的变量 | 所在语句及其子块 |

不同作用域决定了一个名字在哪里能用，也与其生命周期密切相关（但生命周期属于存储期范畴，两者相互独立又有关联）。理解这些作用域是写出正确、清晰的 C++ 代码的基础。
