# 命名空间简单使用

## 1. 定义命名空间

```cpp
namespace MyNs {
    int val = 10;
    void func(){}
    class Demo{};
}
```

## 2. 使用方式

1️⃣ **限定访问（推荐，无污染）**

```cpp
MyNs::val;
MyNs::func();
MyNs::Demo d;
```

2️⃣ `using namespace` 全部引入（大工程谨慎，容易名字冲突）

```cpp
using namespace MyNs;
val = 20;
func();
```

3️⃣ `using` 只引入单个名字

```cpp
using MyNs::func;
func();
```

## 3. 嵌套命名空间

```cpp
namespace A::B { // C++17简写，等价 namespace A { namespace B {} }
    void f(){}
}
A::B::f();
```

## 4. 匿名命名空间（本文件内私有，static替代方案）

```cpp
namespace {
    void localFunc(){} //仅当前cpp可用
}
```

## 要点小结

- 作用：防止全局名字冲突。
- 头文件：**namespace包裹声明**，不要写`using namespace`在头文件（会污染所有包含处）。
- 源文件：可以`using namespace xxx`简化代码。
