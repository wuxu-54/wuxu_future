# C++ std::array 全面详解

## 1. std::array 概述

`std::array` 是 C++11 引入的固定大小数组容器，结合了 C 风格数组的性能优势和 STL 容器的便利接口。

### 基本特性

- **固定大小**：编译时确定，运行时不可改变
- **连续内存**：元素在内存中连续存储
- **栈分配**：通常分配在栈上（除非作为类的动态分配成员）
- **零开销抽象**：与 C 风格数组性能相当

## 2. 基本定义和声明

### 头文件

```cpp
#include <array>
```

### 模板声明

```cpp
template<
    class T,
    std::size_t N
> struct array;
```

### 声明示例

```cpp
// 基本声明
std::array<int, 5> arr1;

// 列表初始化
std::array<int, 5> arr2 = {1, 2, 3, 4, 5};
std::array<int, 5> arr3{1, 2, 3, 4, 5};  // C++11 统一初始化

// 推导指引 (C++17)
std::array arr4{1, 2, 3, 4, 5};  // 推导为 std::array<int, 5>

// 部分初始化（剩余元素值初始化）
std::array<int, 5> arr5 = {1, 2};  // arr5 = {1, 2, 0, 0, 0}
```

## 3. 元素访问方法

### 3.1 operator[]

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 读写访问，无边界检查
arr[0] = 10;
int value = arr[1];

// 越界访问是未定义行为
// int bad = arr[10];  // 未定义行为
```

### 3.2 at()

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 带边界检查的访问
try {
    arr.at(0) = 10;
    int value = arr.at(1);
    
    // 越界访问会抛出异常
    int bad = arr.at(10);  // 抛出 std::out_of_range
} catch (const std::out_of_range& e) {
    std::cout << "Out of range: " << e.what() << std::endl;
}
```

### 3.3 front() 和 back()

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 访问首元素
int& first = arr.front();  // 1
first = 10;                // arr = {10, 2, 3, 4, 5}

// 访问尾元素
int& last = arr.back();    // 5
last = 50;                 // arr = {10, 2, 3, 4, 50}
```

### 3.4 data()

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 获取指向底层数组的指针
int* ptr = arr.data();

// 可用于 C 风格接口
std::memcpy(ptr, some_other_array, 5 * sizeof(int));

// 遍历
for (size_t i = 0; i < arr.size(); ++i) {
    std::cout << ptr[i] << " ";
}
```

## 4. 容量相关操作

### 4.1 size() 和 max_size()

```cpp
std::array<int, 10> arr;

std::cout << "size: " << arr.size() << std::endl;        // 10
std::cout << "max_size: " << arr.max_size() << std::endl; // 10

// 编译时获取大小
constexpr size_t arr_size = std::tuple_size<decltype(arr)>::value;
// 或 C++17
constexpr size_t arr_size2 = std::size(arr);
```

### 4.2 empty()

```cpp
std::array<int, 0> empty_arr;
std::array<int, 5> non_empty_arr;

std::cout << std::boolalpha;
std::cout << "empty_arr empty: " << empty_arr.empty() << std::endl;    // true
std::cout << "non_empty_arr empty: " << non_empty_arr.empty() << std::endl; // false
```

## 5. 迭代器操作

### 5.1 正向迭代器

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 传统迭代器遍历
for (auto it = arr.begin(); it != arr.end(); ++it) {
    std::cout << *it << " ";
}

// 常量迭代器
for (auto it = arr.cbegin(); it != arr.cend(); ++it) {
    // *it = 10;  // 错误：不能修改常量迭代器指向的值
    std::cout << *it << " ";
}
```

### 5.2 反向迭代器

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 反向遍历
for (auto rit = arr.rbegin(); rit != arr.rend(); ++rit) {
    std::cout << *rit << " ";  // 输出: 5 4 3 2 1
}

// 常量反向迭代器
for (auto rit = arr.crbegin(); rit != arr.crend(); ++rit) {
    std::cout << *rit << " ";
}
```

### 5.3 基于范围的 for 循环

```cpp
std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 值拷贝
for (int val : arr) {
    std::cout << val << " ";
    val = 10;  // 不影响原数组
}

// 引用修改
for (int& val : arr) {
    val *= 2;  // 修改原数组元素
}

// 常量引用（只读）
for (const int& val : arr) {
    std::cout << val << " ";
    // val = 10;  // 错误：不能修改常量引用
}
```

## 6. 元素操作

### 6.1 fill()

```cpp
std::array<int, 5> arr;

// 填充相同值
arr.fill(42);  // arr = {42, 42, 42, 42, 42}

// 可用于清零
std::array<int, 100> large_arr;
large_arr.fill(0);
```

### 6.2 swap()

```cpp
std::array<int, 3> arr1 = {1, 2, 3};
std::array<int, 3> arr2 = {4, 5, 6};

// 交换两个数组内容
arr1.swap(arr2);  // arr1 = {4, 5, 6}, arr2 = {1, 2, 3}

// 全局 swap 函数
std::swap(arr1, arr2);  // 交换回来
```

## 7. 比较操作

std::array 支持所有比较运算符（==, !=, <, <=, >, >=），按字典序比较：

```cpp
std::array<int, 3> arr1 = {1, 2, 3};
std::array<int, 3> arr2 = {1, 2, 4};
std::array<int, 3> arr3 = {1, 2, 3};

std::cout << std::boolalpha;
std::cout << "arr1 == arr3: " << (arr1 == arr3) << std::endl;  // true
std::cout << "arr1 < arr2: " << (arr1 < arr2) << std::endl;    // true
std::cout << "arr1 > arr2: " << (arr1 > arr2) << std::endl;    // false
```

## 8. 结构化绑定 (C++17)

```cpp
std::array<int, 3> arr = {1, 2, 3};

// 解包数组元素
auto [a, b, c] = arr;
std::cout << a << " " << b << " " << c << std::endl;  // 1 2 3

// 引用绑定可修改原数组
auto& [x, y, z] = arr;
x = 10;  // 修改 arr[0]
```

## 9. 与 C 风格数组的互操作

### 9.1 传递给 C 风格函数

```cpp
void c_style_function(int* arr, size_t size) {
    for (size_t i = 0; i < size; ++i) {
        std::cout << arr[i] << " ";
    }
}

std::array<int, 5> arr = {1, 2, 3, 4, 5};

// 使用 data() 成员函数
c_style_function(arr.data(), arr.size());

// 或者使用地址运算符（需要确保不为空）
if (!arr.empty()) {
    c_style_function(&arr[0], arr.size());
}
```

### 9.2 从 C 风格数组构造

```cpp
int c_array[] = {1, 2, 3, 4, 5};

// 手动复制
std::array<int, 5> std_arr;
std::copy(std::begin(c_array), std::end(c_array), std_arr.begin());

// 或者使用构造函数（C++20 起有 std::to_array）
auto std_arr2 = std::to_array(c_array);
```

## 10. 编译时特性

### 10.1 constexpr 支持

```cpp
// constexpr 数组
constexpr std::array<int, 3> const_arr = {1, 2, 3};

// 编译时计算
constexpr int first_element = const_arr[0];  // 编译期已知

// constexpr 函数中使用
constexpr size_t get_size() {
    std::array<int, 5> arr{};
    return arr.size();  // 编译期计算
}

static_assert(get_size() == 5);  // 编译期断言
```

### 10.2 类型特征

```cpp
std::array<int, 5> arr;

// 获取元素类型
using value_type = decltype(arr)::value_type;  // int

// 获取大小类型
using size_type = decltype(arr)::size_type;    // std::size_t

// 编译时获取大小
constexpr size_t arr_size = std::tuple_size<decltype(arr)>::value;
```

## 11. 高级用法和技巧

### 11.1 自定义类型数组

```cpp
struct Point {
    int x, y;
    
    // 需要默认构造函数用于值初始化
    Point() : x(0), y(0) {}
    Point(int x, int y) : x(x), y(y) {}
};

std::array<Point, 3> points = {
    Point(1, 2),
    Point(3, 4),
    Point(5, 6)
};

// 或者使用统一初始化
std::array<Point, 3> points2{{
    {1, 2},
    {3, 4},
    {5, 6}
}};
```

### 11.2 多维数组

```cpp
// 2D 数组
std::array<std::array<int, 3>, 2> matrix = {{
    {1, 2, 3},
    {4, 5, 6}
}};

// 访问元素
int value = matrix[0][1];  // 2

// 使用 structured binding 遍历
for (const auto& row : matrix) {
    for (int val : row) {
        std::cout << val << " ";
    }
    std::cout << std::endl;
}
```

### 11.3 作为函数参数和返回值

```cpp
// 按值传递（小数组推荐）
void process_array(std::array<int, 5> arr) {
    for (auto& val : arr) {
        val *= 2;
    }
}

// 按引用传递（避免拷贝）
void modify_array(std::array<int, 5>& arr) {
    for (auto& val : arr) {
        val += 1;
    }
}

// 常量引用（只读访问）
void read_array(const std::array<int, 5>& arr) {
    for (const auto& val : arr) {
        std::cout << val << " ";
    }
}

// 返回数组
std::array<int, 3> create_array() {
    return {1, 2, 3};  // 返回值优化 (RVO)
}
```

### 11.4 算法应用

```cpp
#include <algorithm>
#include <numeric>

std::array<int, 5> arr = {5, 2, 8, 1, 9};

// 排序
std::sort(arr.begin(), arr.end());  // {1, 2, 5, 8, 9}

// 查找
auto it = std::find(arr.begin(), arr.end(), 5);
if (it != arr.end()) {
    std::cout << "Found at position: " << std::distance(arr.begin(), it) << std::endl;
}

// 累加
int sum = std::accumulate(arr.begin(), arr.end(), 0);
std::cout << "Sum: " << sum << std::endl;

// 变换
std::array<int, 5> squared;
std::transform(arr.begin(), arr.end(), squared.begin(),
               [](int x) { return x * x; });
```

## 12. 性能考虑和最佳实践

### 12.1 性能优势

- **零开销抽象**：与 C 风格数组性能相同
- **栈分配**：避免堆分配开销
- **内联优化**：编译器可充分优化

### 12.2 使用建议

```cpp
// 推荐：小尺寸固定数组
std::array<int, 16> small_buffer;

// 不推荐：大尺寸数组（可能导致栈溢出）
// std::array<int, 1000000> large_array;  // 可能在栈上分配失败

// 替代方案：使用 std::vector 对于大尺寸或动态大小
std::vector<int> dynamic_array(1000000);  // 在堆上分配
```

### 12.3 异常安全

```cpp
void safe_array_operations() {
    std::array<int, 5> arr = {1, 2, 3, 4, 5};
    
    try {
        // at() 提供强异常保证
        int value = arr.at(10);  // 抛出 std::out_of_range
    } catch (const std::out_of_range&) {
        // 数组状态保持不变
        std::cout << "Caught out_of_range exception" << std::endl;
    }
    
    // operator[] 不提供异常保证，但通常不会抛出
    // 只在调试模式下可能有边界检查
}
```

## 13. 完整示例

```cpp
#include <iostream>
#include <array>
#include <algorithm>
#include <numeric>

int main() {
    // 创建和初始化
    std::array<int, 6> numbers = {3, 1, 4, 1, 5, 9};
    
    // 基本操作
    std::cout << "Original array: ";
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    
    // 排序
    std::sort(numbers.begin(), numbers.end());
    std::cout << "Sorted array: ";
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
    
    // 数学运算
    int sum = std::accumulate(numbers.begin(), numbers.end(), 0);
    double avg = static_cast<double>(sum) / numbers.size();
    std::cout << "Sum: " << sum << ", Average: " << avg << std::endl;
    
    // 查找
    auto it = std::find(numbers.begin(), numbers.end(), 5);
    if (it != numbers.end()) {
        std::cout << "Found 5 at position: " 
                  << std::distance(numbers.begin(), it) << std::endl;
    }
    
    // 安全访问
    try {
        std::cout << "Element at index 2: " << numbers.at(2) << std::endl;
        std::cout << "Element at index 10: " << numbers.at(10) << std::endl;
    } catch (const std::out_of_range& e) {
        std::cout << "Out of range error: " << e.what() << std::endl;
    }
    
    return 0;
}
```

std::array 提供了现代 C++ 中处理固定大小数组的最佳方式，结合了性能、安全性和便利性。在需要固定大小容器的场景中，它应该是首选 over C 风格数组。
