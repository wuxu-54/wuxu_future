# 指针 `T*` vs 引用 `T&`
>
> 底层原理：**引用本质上大多编译器实现就是指针常量（`T* const`），但是语法层面做了包装，对外表现不一样**。
> 注意语法写法：参数里是 `T& p`（引用），不是 `p&`；`T* p`（指针）。

## 基础对比总表

|项目|指针 `T*`|引用 `T&`|
|---|---|---|
|定义含义|存储对象的内存地址变量|**对象的别名**，给已有对象再起一个名字|
|是否可以为空|可以 `nullptr`，可以不指向有效对象|**不能为空，必须绑定一个有效对象**，没有空引用|
|能否重新绑定|可以，随时改变指向另一个对象|**一旦绑定，永远不能改绑到别的对象**；只能修改指向对象的值|
|使用语法|要用 `*` 解引用拿值；`->`访问成员|直接当原对象用，不需要解引用；`.`访问成员|
|本身有独立内存|指针变量自己占内存（64位8字节，存地址）|编译器大多实现为指针常量，但是语法上视为别名；不允许取“引用本身”的地址，`&ref`拿到的是原对象地址|
|初始化|可以先定义，后面再赋值|**定义时必须立刻初始化绑定对象**，不能先声明后赋值|
|const修饰|`T* const` 指针本身不可改；`const T*` 指向内容不可改|只有 `const T&`（常量引用），没有“引用本身const”，引用天生不可改绑|

## 1. 代码直观例子

### 指针

```cpp
int a = 10;
int b = 20;

int* p = &a;   // p保存a的地址
*p = 100;      // 修改a的值 a=100
p = &b;        // ✅ p可以重新指向b
p = nullptr;   // ✅可以置空
```

### 引用

```cpp
int a = 10;
int b = 20;

int& r = a;    // r是a的别名，定义立刻绑定a
r = 100;       // 修改a的值 a=100
r = b;         // ⚠️！！不是改绑定！等价 a = b；把b的值赋值给a，r依旧绑定a，不会绑定b
// int& r2;    // ❌编译报错，引用必须初始化，不能悬空
```

> 重点坑：`r = b` **不是让r引用b**，是赋值操作，把b的值拷贝到r绑定的a里面。引用绑定关系终生不变。

## 2. 函数参数场景（你重点问的：`T&` 和 `T*` 参数）

### ① 指针参数 `void func(T* p)`

```cpp
void func(int* p)
{
    if(p == nullptr) return; // 必须判空！p可以是空
    *p += 1;
}

//调用
int x = 10;
func(&x);
func(nullptr); //合法，可以传空
```

特点：

1. 需要手动传地址 `&x`；
2. 参数**允许传入nullptr**，函数内部必须考虑空指针，有悬空风险；
3. 函数内可以修改p本身，让p指向别的对象（不会影响外部实参，p是局部指针变量）；
4. 语义：“可能为空，可选传入一个对象地址”。

### ② 引用参数 `void func(T& r)`

```cpp
void func(int& r)
{
    r += 1; // 直接操作原对象，不需要*解引用
}

//调用
int x =10;
func(x); // 直接传对象，不用取地址&
// func(nullptr); ❌非法，不能传空
```

特点：

1. 直接传对象，不用写`&`；
2. **绝对不能接收空值，调用时必须传入一个真实存在对象**；不需要判空；
3. r不能改绑定，只能修改绑定对象里面的值；
4. 语义：**必须传入一个有效对象**。

> `const T&` 常量引用：最常用，接收左值也接收临时右值，避免拷贝，只读。

```cpp
void func(const int& r){}
func(100); // ✅可以接收临时右值
```

### 关键区别：传参语义总结

- `T* p`：**参数可以为空**；调用方显式取地址；函数要处理nullptr；适合可选参数、可以为空的场景。
- `T& r`：**参数一定有效不能为空**；调用直接传变量；不需要判空；适合必须传入对象。

> 注意：C++没有 `p&`，写法是类型在前：`int& r`，不是 `int r&`。

## 3. 底层原理（编译器实现层面）
>
> 绝大多数编译器，引用底层就是 `T* const`（常量指针，指针本身不能修改指向）

```cpp
int a = 10;
int& r = a;
//编译器内部等价转换伪代码：
int* const r = &a;
```

- 所以引用变量本身也会占用栈内存，存地址；
- **但是C++语法层屏蔽你，不让你操作这个指针本身**：你不能让r指向别的对象；`&r`拿到的是原对象a的地址，不是这个内部指针的地址。

> ⚠️：这是**编译器实现细节，C++标准并没有强制规定引用必须用指针实现**，只是现实所有编译器都这么做。写业务代码不要依赖底层实现，遵循语法规则。

## 4. 什么时候选指针，什么时候选引用

✅优先用引用：

1. 参数**一定不为空**，需要修改传入对象；`T&`
2. 只读接收参数，希望避免拷贝：`const T&`（可以接收临时对象）

✅优先用指针：

1. 对象**有可能为空**、可选传入；
2. 需要在函数内改变指向（切换指向不同对象）；
3. 和C语言交互、JNI、void*，旧C接口。

## 5. 经典坑

1. **返回局部变量的引用/指针 → 悬垂，未定义行为，崩溃**

```cpp
int& bad(){
    int x=10;
    return x; // ❌局部函数结束销毁，返回引用指向已经销毁的栈内存
}
```

指针同样不能返回局部栈对象地址。

2. 引用不能为nullptr，但是你可以恶意强制转换制造悬空引用，属于UB，业务不要干。

## 极简一句话面试背诵版
>
> 指针是保存对象地址的独立变量，可以为空，可以改变指向；引用是对象别名，初始化必须绑定有效对象，不能为空，绑定后不能改指向。
> 函数参数：`T*`允许nullptr，调用要传地址；`T&`必须传入有效对象，直接传变量，不需要判空。底层编译器引用大多实现为 `T* const`。

### 补充：`T*&` 指针的引用（进阶）

```cpp
void change_ptr(int*& p){
    p = nullptr; // 可以修改外部实参指针本身的值
}
```

`int*& p`：p是**指针的引用**，不要和普通引用`int&`搞混。
