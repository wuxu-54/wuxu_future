# 结构体

C++结构体与C相同，可查看 **c的基础语法[结构体](/3.程序/1.基础/2.基础语言/c/1.c的基础语法/14.结构体/1.结构体是啥.md)** 章节。

## 语法

struct 结构体名{结构体成员列表;}结构体声明(这个可不写);

```cpp
struct Test{
    int a;
    int b;
    float c;
} test;
```

## 结构体C、C++区别

1. C中`结构体内的变量`在声明时不能直接初始化,会报错，但是C++中可以初始化；
2. c++空结构体有1字节占用；c中空结构体无字节占用；
