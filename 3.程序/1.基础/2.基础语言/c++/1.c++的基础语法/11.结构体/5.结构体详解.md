# C++ struct（结构体）完整详解

一句话核心：

>
> **C++ 的 `struct` 本质就是 `class`，唯一差别：struct 默认成员是 `public`；class 默认成员是 `private`。**
> C语言struct只能放成员变量；C++的struct可以：成员变量、成员函数、构造/析构、继承、多态、访问控制、静态成员、友元。

## 一、基础语法

```
#include <iostream>
using namespace std;

struct Student
{
    // 默认 public
    int id;
    string name;

    // 成员函数
    void show()
    {
        cout << id << " " << name << endl;
    }
};

int main()
{
    Student s;
    s.id = 1001;
    s.name = "Zhang";
    s.show();
    return 0;
}
```

直接访问 `s.id`，因为默认public。
换成 `class Student`，上面代码编译报错，成员默认private，不能直接访问。

## 二、访问控制（public / protected / private）

struct 只是**默认权限不同**，你可以手动写权限修饰符，和class完全一样：

```
struct Demo
{
public:
    int a;      // 外部可访问
protected:
    int b;      // 仅本类 + 子类可访问
private:
    int c;      // 仅本类内部访问
    void func(){}
};
```

## 三、构造函数、析构函数（你刚才关心的重点）

struct 支持**构造、拷贝构造、移动构造、析构**，规则和class一模一样。

- 构造函数：名字和结构体同名，无返回值，可以带参数，可以重载
- 析构函数：`~结构体名()`，无参数无返回值，**不能重载**，对象销毁自动调用

```
struct MnnContext
{
    int* buffer;

    // 默认构造
    MnnContext()
    {
        cout << "构造 MnnContext" << endl;
        buffer = new int[128];
    }

    // 带参构造
    MnnContext(int size)
    {
        buffer = new int[size];
    }

    // 析构函数
    ~MnnContext()
    {
        cout << "析构 ~MnnContext，释放内存" << endl;
        delete[] buffer;
    }
};

int main()
{
    MnnContext ctx;       // 栈对象，离开作用域自动调用 ~MnnContext
    MnnContext* p = new MnnContext(256);
    delete p;             // delete时调用析构
    return 0;
}
```

### 特殊：默认生成的函数

如果你**不手写**，编译器会隐式生成：

1. 默认构造函数
2. 拷贝构造函数
3. 拷贝赋值运算符 `operator=`
4. 析构函数
5. 移动构造 / 移动赋值（C++11以后）

可以显式指定 `=default`（使用编译器默认实现）、`=delete`（禁用）

```
struct Test
{
    Test() = default;        // 使用默认构造
    ~Test() = default;      // 默认析构
    Test(const Test&) = delete; // 禁用拷贝构造，不能拷贝
};
```

## 四、继承（struct可以继承！）

struct 继承默认是 **public继承**；class继承默认是 private继承。

```
struct Base
{
    virtual ~Base() = default; // 虚析构，多态必备
    void hello() { cout << "base\n"; }
};

// struct默认 public 继承
struct Derive : Base
{
    void hello() { cout << "derive\n"; }
};
```

>
> 重点：如果基类通过基类指针delete子类对象，基类析构必须加 `virtual`，否则只会调用基类析构，子类资源泄漏。MNN源码里大量这种写法。

## 五、多态（虚函数 virtual）

struct完全支持虚函数、虚表，和class没有任何区别

```
struct Base
{
    virtual void print()
    {
        cout << "Base" << endl;
    }
    virtual ~Base() = default;
};

struct Sub : Base
{
    void print() override
    {
        cout << "Sub" << endl;
    }
};
```

## 六、静态成员、友元

```
struct A
{
    static int count; // 静态成员变量，属于结构体本身，不属于单个对象
    static void showCount(){}

    friend void func(A& a); // 友元函数
};
int A::count = 0;
```

## 七、和C语言struct兼容写法

C++结构体**依然支持C风格初始化**，兼容老代码：

```
struct Point
{
    int x;
    int y;
};

Point p1 = {10,20}; // C风格聚合初始化
```

>
> 注意：一旦你写了自定义构造函数，就不再是「聚合类型」，这种`{}`初始化会受限制。

## 八、struct vs class 完整对比表

| 特性 | struct | class |
| --- | --- | --- |
| 默认成员访问权限 | public | private |
| 默认继承方式 | public继承 | private继承 |
| 构造、析构 | ✅支持 | ✅支持 |
| 虚函数、多态 | ✅支持 | ✅支持 |
| 静态成员、友元 | ✅支持 | ✅支持 |
| 模板 | ✅支持 `template<...> struct` | ✅支持 |

>
> 工程习惯：
>
>
> 1. **struct**：一般用来存简单数据（POCO，plain old data），成员默认public，少量简单函数
> 2. **class**：复杂业务逻辑，封装，成员默认private，对外暴露接口
> MNN这类底层框架经常用struct写类，只是代码风格选择，不是语法限制。

## 九、POD类型（简单结构体，重要概念）

POD（Plain Old Data）：像C结构体一样，**没有自定义构造/析构、没有虚函数**。
POD对象可以直接memcpy、序列化；一旦写了析构、虚函数，就不再是POD。

```
// POD类型，可以memcpy
struct PodPoint{
    int x,y;
};

// 不是POD，有自定义析构，不能随便memcpy
struct NotPod{
    int* p;
    ~NotPod(){delete p;}
};
```

## 十、常见坑

1. **struct有虚函数时，对象会带虚指针，内存布局变化，不能当成C结构体直接二进制拷贝**（MNN里面要特别留意）
2. 继承多态，基类析构不加virtual，delete基类指针造成内存泄漏
3. 自定义析构后，编译器生成的拷贝构造不会做深拷贝，容易**浅拷贝double free**

```
struct BadCase
{
    char* buf;
    BadCase(){ buf = new char[10]; }
    ~BadCase(){ delete[] buf; }
    // 编译器默认拷贝构造是浅拷贝，两个对象共用同一块buf，析构两次崩溃
};
```

解决：手动写拷贝构造、拷贝赋值（深拷贝），或者禁用拷贝 `BadCase(const BadCase&)=delete;`

## 十一、什么时候用struct / class？

- 只保存数据，对外直接访问成员 → struct
- 需要封装，隐藏内部成员，只提供接口 → class
- 底层库（MNN、OpenCV）很多用struct写类，属于编码风格，语法等价
