# 推导式

Python 推导式是一种独特的数据处理方式，可以从一个数据序列构建另一个新的数据序列的结构体。

## 什么是推导式？

推导式（Comprehensions）是Python提供的一种**简洁、高效**的语法结构，用于从一个或多个可迭代对象中创建新的序列（列表、字典、集合等）。它将循环和条件逻辑压缩到一行代码中，使代码更加Pythonic（符合Python风格）。

### 推导式的核心优势

✅ **代码简洁**：用一行代码替代多行循环  
✅ **执行高效**：C语言级别优化，比普通循环更快  
✅ **可读性强**：表达意图清晰，符合数学集合表示法  
✅ **内存友好**：生成器表达式支持惰性求值，节省内存

Python 支持各种数据结构的推导式：

- 列表(list)推导式
- 字典(dict)推导式  
- 集合(set)推导式
- 元组(tuple)推导式（实际为生成器表达式）

## 列表推导式

格式：

```txt
[表达式 for 变量 in 列表] 
[out_exp_res for out_exp in input_list]

或者 

[表达式 for 变量 in 列表 if 条件]
[out_exp_res for out_exp in input_list if condition]
```

- out_exp_res：列表生成元素表达式，可以是有返回值的函数。
- for out_exp in input_list：迭代 input_list 将 out_exp 传入到 out_exp_res 表达式中。
- if condition：条件语句，可以过滤列表中不符合条件的值。

示例：过滤掉长度小于或等于3的字符串列表，并将剩下的转换成大写字母

```python
>>> names = ['Bob', 'Tom', 'alice', 'Jerry', 'Wendy', 'Smith']
>>> new_names = [name.upper() for name in names if len(name) > 3]
>>> print(new_names)
['ALICE', 'JERRY', 'WENDY', 'SMITH']
```

>补充说明：推导式中的out_exp_res 必须是个已声明的值。如上面示例，必须`[name.upper() for name in names if len(name)>3]` name.upper()中的`name`是前面声明的变量

## 字典推导式

格式：

```txt
{ key_expr: value_expr for value in collection }

或

{ key_expr: value_expr for value in collection if condition }
```

示例：使用字符串及其长度创建字典

```python
listdemo = ['Google','Runoob', 'Taobao']
# 将列表中各字符串值为键，各字符串的长度为值，组成键值对
>>> newdict = {key:len(key) for key in listdemo}
>>> newdict
{'Google': 6, 'Runoob': 6, 'Taobao': 6}
```

## 集合推导式

格式：

```txt
{ expression for item in Sequence }
或
{ expression for item in Sequence if conditional }
```

示例：计算数字 1,2,3 的平方数

```python
>>> setnew = {i**2 for i in (1,2,3)}
>>> setnew
{1, 4, 9}
```

## 元组推导式(又称：生成器表达式)

元组推导式可以利用 range 区间、元组、列表、字典和集合等数据类型，快速生成一个满足指定需求的元组。

格式：

```txt
(expression for item in Sequence )
或
(expression for item in Sequence if conditional )
```

元组推导式和列表推导式的用法也完全相同，只是元组推导式是用 `()` 圆括号将各部分括起来，而列表推导式用的是中括号 `[]`，另外元组推导式返回的结果是一个**生成器对象**。

示例：生成一个包含数字 1~9 的元组

```python
>>> a = (x for x in range(1,10))
>>> a
<generator object <genexpr> at 0x7faf6ee20a50>  # 返回的是生成器对象

>>> tuple(a)       # 使用 tuple() 函数，可以直接将生成器对象转换成元组
(1, 2, 3, 4, 5, 6, 7, 8, 9)
```

## 高级用法与嵌套推导式

### 嵌套循环推导式

```python
# 相当于嵌套for循环
>>> matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
>>> flattened = [num for row in matrix for num in row]
>>> flattened
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

### 多条件推导式

```python
# 多个if条件（相当于and）
>>> numbers = [x for x in range(20) if x % 2 == 0 if x % 3 == 0]
>>> numbers
[0, 6, 12, 18]
```

## 使用注意事项

`_dict = {i: _dict[i]+1 if i in _dict else 0 for i in data} 不能工作` 问题解析：

- 推导式不能引用未定义的变量或者未定义自身，比如：如果_dict未定义，那这个语法执行中会有触发`_dict[1]`,明显是错误的。
- 推导式如果_dict有定义，但这个语法也是错误的，因为在运行中使用旧字典，旧字典本身的值是一直没有变化的，需要注意

    ```txt
    推导式右边的 _dict 引用的是外部作用域中已经存在的那个旧字典（在循环开始前就固定了），而不是正在逐步构建的新字典。

    所以上面的例子中：

    对于 "a"：旧字典中 _dict["a"]=1 → 新 _dict["a"] = 1+1 = 2

    对于 "b"：旧字典中 _dict["b"]=2 → 新 _dict["b"] = 2+1 = 3

    对于 "c"："c" not in 旧字典 → 新 _dict["c"] = 1

    第二个 "a"：再次遇到 "a" 时，旧字典中 _dict["a"] 还是 1（旧字典未变），所以仍然计算为 1+1=2，覆盖之前的 2。

    也就是说，无法累积统计频率，因为每次判断 i in _dict 和取值 _dict[i] 都只看旧字典，而非新字典中已经计数过的值。遇到重复元素时，只会反复基于旧字典的初始值计算，最终值只会是 旧值+1，而不是累加多次。
    ```

⚠️ **性能考虑**：

- 对于简单操作，推导式通常比循环更快
- 对于复杂逻辑，优先考虑代码可读性，避免过度复杂的推导式

⚠️ **内存使用**：

- 列表、字典、集合推导式会立即创建完整数据结构，占用内存
- 生成器表达式（元组推导式）是惰性求值，内存友好，适合大数据处理

⚠️ **可读性原则**：

- 单行推导式不应超过80个字符
- 过于复杂的逻辑建议使用传统循环，保持代码清晰

## 总结对比表

| 推导式类型 | 语法符号 | 返回类型 | 内存特性 | 适用场景 |
|-----------|---------|---------|---------|---------|
| 列表推导式 | `[...]` | list | 立即求值 | 需要完整列表数据 |
| 字典推导式 | `{...}` | dict | 立即求值 | 创建键值对映射 |
| 集合推导式 | `{...}` | set | 立即求值 | 去重、集合运算 |
| 生成器表达式 | `(...)` | generator | 惰性求值 | 大数据流处理 |

💡 **最佳实践**：当你的代码中出现简单的`for`循环配合`append()`、`update()`等方法时，优先考虑使用推导式来简化代码！
