
# 字典类型怎么遍历？

Python 字典提供了多种遍历方式：

## ① 遍历所有键（默认）

```python
d = {'a': 1, 'b': 2, 'c': 3}
for key in d:          # 等价于 for key in d.keys():
    print(key, d[key])
```

## ② 遍历所有值

```python
for value in d.values():
    print(value)
```

## ③ 遍历键值对（最常用）

```python
for key, value in d.items():
    print(key, value)
```

## ④ 同时获取索引和键值对（使用 `enumerate`）

```python
for idx, (key, value) in enumerate(d.items()):
    print(idx, key, value)
```
