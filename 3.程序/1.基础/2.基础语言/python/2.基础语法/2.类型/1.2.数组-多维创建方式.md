# Python 多维数组（列表）创建 + 含义 超详细讲解

Python 里**没有真正的数组**，我们用**嵌套列表**模拟多维数组，比如：

- 一维：`[1,2,3]`
- 二维：`[[1,2],[3,4]]`（表格）
- 三维：`[[[1],[2]],[[3],[4]]]`（立方体）

我只讲**最常用、最安全、面试必背**的写法，一次性讲透。

---

## 一、一维数组（最基础）

```python
arr = [0] * 5    # [0,0,0,0,0]
```

含义：创建**长度为5**的列表，每个元素都是0。

---

## 二、二维数组（重点！90% 人错在这里）

### ✅ 正确写法（唯一安全写法）

```python
# 创建 m 行 n 列
dp = [[0] * n for _ in range(m)]
```

#### 逐字拆解含义

```python
[[0] * n    for _ in range(m)]
  ↑ 一行有n个      ↑ 总共生成 m 行
```

例子：创建 **3行4列** 的二维数组

```python
dp = [[0]*4 for _ in range(3)]
```

结果：

```
[
 [0,0,0,0],  # 第0行
 [0,0,0,0],  # 第1行
 [0,0,0,0]   # 第2行
]
```

访问：`dp[行][列]` → `dp[0][1]` 第0行第1列

---

### ❌ 绝对不能用的错误写法（坑死人）

```python
dp = [[0]*n] * m   # 大错特错！
```

#### 为什么错？

**所有行指向同一个列表！**
改一行，所有行跟着变！

例子：

```python
dp = [[0]*2]*2
dp[0][0] = 1
print(dp)
# 输出 [[1,0],[1,0]]  两行都变了！
```

---

## 三、三维数组（了解即可）

### 正确写法

```python
# 3 × 4 × 5 三维数组
dp = [[[0]*5 for _ in range(4)] for __ in range(3)]
```

含义：

- 最内层：`[0]*5` → 一维
- 中间：`[...] for _ in range(4)` → 二维
- 最外层：`[...] for __ in range(3)` → 三维

---

## 四、核心规律（背会这一条，永远不写错）

### Python 创建多维列表公式：

**从右往左 ← 维度从外到内**

```
二维：[[0] * 列 for _ in range(行)]
三维：[[[0]*z for _ in range(y)] for __ in range(x)]
```

规则：

1. **最右边是最内层**（最后一维）
2. **`for` 循环个数 = 维度数**
3. **绝对不要用 `*` 复制外层列表**

---

## 五、你之前的错误回顾

你写的：

```python
dp = [[0]*rowCount for n in columnCount ]
```

错误：

1. `columnCount` 是数字，不能 `for n in 数字`
2. 行列写反了
3. 循环变量用 `n` 没必要，应该用 `_`

正确：

```python
dp = [[0] * columnCount for _ in range(rowCount)]
```

---

## 六、超简记忆口诀

```
[0] * 列数
for _ in range(行数)
```

---

## 总结

1. **二维数组正确写法**：`[[0]*列 for _ in range(行)]`
2. **`[[0]*n]*m` 绝对禁用**
3. **for 循环次数 = 维度数**
4. Python 列表支持负索引，但**DP 必须从 1 开始循环**
