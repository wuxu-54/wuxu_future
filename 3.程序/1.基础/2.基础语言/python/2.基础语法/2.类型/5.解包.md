# Python解包（Unpacking）

Python的解包功能允许将序列（列表、元组）或字典中的元素"展开"并分配给多个变量，这在函数调用和数据处理中非常有用。

## 1. 基本序列解包

### 元组和列表解包

```python
# 元组解包
a, b, c = (1, 2, 3)
print(a, b, c)  # 输出: 1 2 3

# 列表解包  
x, y, z = [4, 5, 6]
print(x, y, z)  # 输出: 4 5 6

# 字符串解包
first, second, third = "abc"
print(first, second, third)  # 输出: a b c
```

### 实际应用场景

```python
# 交换变量值
a, b = 10, 20
a, b = b, a  # 交换值
print(a, b)  # 20 10

# 函数返回多个值
def get_coordinates():
    return 100, 200

x, y = get_coordinates()  # 自动解包
print(f"Coordinates: ({x}, {y})")
```

## 2. 扩展解包（Extended Unpacking）- Python 3+

使用 `*` 捕获剩余元素：

```python
# 捕获中间的元素
first, *middle, last = [1, 2, 3, 4, 5]
print(first)   # 1
print(middle)  # [2, 3, 4]
print(last)    # 5

# 捕获末尾的元素
head, *tail = [10, 20, 30, 40]
print(head)    # 10
print(tail)    # [20, 30, 40]

# 捕获开头的元素
*start, end = [100, 200, 300, 400]
print(start)   # [100, 200, 300]
print(end)     # 400

# 只捕获部分元素
a, b, *rest = [1, 2]  # rest 会是空列表 []
print(a, b, rest)     # 1 2 []
```

### 嵌套解包

```python
# 解包嵌套结构
data = [(1, 2), (3, 4), (5, 6)]
for x, y in data:
    print(f"x={x}, y={y}")

# 更复杂的嵌套解包
nested = [1, [2, 3], {'name': 'John'}]
a, (b, c), d = nested
print(a, b, c, d['name'])  # 1 2 3 John
```

## 3. 函数参数解包

### 使用 `*` 解包序列作为位置参数

```python
def greet(name, age, city):
    print(f"Hello {name}, you are {age} years old and live in {city}")

# 使用列表解包调用函数
person_info = ["Alice", 25, "New York"]
greet(*person_info)  # 等价于 greet("Alice", 25, "New York")

# 使用元组解包
person_tuple = ("Bob", 30, "London")
greet(*person_tuple)

# 处理不确定长度的数据
def process_data(header, *items):
    print(f"Header: {header}")
    for item in items:
        print(f"Item: {item}")

data = ["Title", "item1", "item2", "item3"]
process_data(*data)  # 解包整个列表
```

### 使用 `**` 解包字典作为关键字参数

```python
def create_profile(name, email, age=None):
    print(f"Name: {name}, Email: {email}, Age: {age}")

# 使用字典解包调用函数
user_data = {"name": "Charlie", "email": "charlie@example.com", "age": 28}
create_profile(**user_data)

# 也可以只传递部分参数
basic_data = {"name": "David", "email": "david@example.com"}
create_profile(**basic_data)  # age使用默认值None

# 结合不定长参数使用
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

info = {"name": "Eve", "job": "Engineer", "company": "TechCorp"}
print_info(**info)
```

## 4. 在函数定义中的解包应用

结合不定长参数的高级用法：

```python
# 接收任意数量的位置参数并进行计算
def sum_all(*numbers):
    return sum(numbers)

# 调用时可以解包列表
nums = [1, 2, 3, 4, 5]
result = sum_all(*nums)  # 等价于 sum_all(1, 2, 3, 4, 5)
print(result)  # 15

# 混合使用位置参数和关键字参数解包
def complex_function(a, b, *args, **kwargs):
    print(f"Required: a={a}, b={b}")
    print(f"Extra args: {args}")
    print(f"Keyword args: {kwargs}")

# 同时解包序列和字典
positional_args = [10, 20, 30, 40]
keyword_args = {"x": 100, "y": 200}

complex_function(*positional_args, **keyword_args)
# 输出:
# Required: a=10, b=20
# Extra args: (30, 40)
# Keyword args: {'x': 100, 'y': 200}
```

## 5. 集合和生成器解包

```python
# 集合解包（注意：集合是无序的）
my_set = {1, 2, 3}
a, b, c = my_set  # 顺序不确定

# 生成器解包
def number_generator():
    yield 1
    yield 2
    yield 3

x, y, z = number_generator()
print(x, y, z)  # 1 2 3

# 在函数调用中直接解包生成器
def process_numbers(*numbers):
    return sum(numbers)

result = process_numbers(*number_generator())
print(result)  # 6
```

## 6. 注意事项和常见错误

### 元素数量不匹配

```python
# 错误：元素数量不匹配
# a, b = [1, 2, 3]  # ValueError: too many values to unpack

# 正确：使用扩展解包
a, b, *rest = [1, 2, 3, 4, 5]
print(a, b, rest)  # 1 2 [3, 4, 5]

# 或者明确指定所有变量
a, b, c = [1, 2, 3]  # 正确
```

### 字典解包的键名匹配

```python
def func(a, b):
    return a + b

# 错误：键名不匹配函数参数
# func(**{'a': 1, 'c': 2})  # TypeError: got an unexpected keyword argument 'c'

# 正确：键名必须与函数参数名一致
result = func(**{'a': 1, 'b': 2})  # 正确
print(result)  # 3
```

### 空序列解包

```python
# 空列表解包到空变量列表
*empty, = []  # empty 是空列表 []
print(empty)   # []

# 但不能解包到固定数量的变量
# a, b = []  # ValueError: not enough values to unpack
```

## 7. 高级技巧和最佳实践

### 在列表/字典字面量中使用解包

```python
# 列表拼接
list1 = [1, 2, 3]
list2 = [4, 5, 6]
combined = [*list1, *list2]  # [1, 2, 3, 4, 5, 6]

# 字典合并（Python 3.5+）
dict1 = {'a': 1, 'b': 2}
dict2 = {'c': 3, 'd': 4}
merged = {**dict1, **dict2}  # {'a': 1, 'b': 2, 'c': 3, 'd': 4}

# 函数参数中的混合使用
def setup_config(database, cache, **extra_settings):
    config = {
        'database': database,
        'cache': cache,
        **extra_settings  # 合并额外配置
    }
    return config

config = setup_config('mysql', 'redis', timeout=30, retries=3)
print(config)
# {'database': 'mysql', 'cache': 'redis', 'timeout': 30, 'retries': 3}
```

### 解包与默认值结合

```python
def safe_unpack(data, default_values):
    """安全解包，提供默认值"""
    # 确保数据长度足够
    extended_data = list(data) + list(default_values[len(data):])
    return extended_data[:len(default_values)]

# 使用示例
data = [1, 2]
defaults = [0, 0, 0]
a, b, c = safe_unpack(data, defaults)
print(a, b, c)  # 1 2 0
```

## 总结

Python解包是一个强大而灵活的特性，主要用途包括：

- **变量赋值**：同时给多个变量赋值
- **函数调用**：将序列或字典作为参数传递给函数
- **数据处理**：处理不确定长度的数据结构
- **代码简洁性**：减少冗余代码，提高可读性

掌握解包技术能让你的Python代码更加简洁、高效和Pythonic！
