# 类型注解

Python 类型注解（Type Annotations）是一种用于指定变量、函数参数以及返回值类型的语法。它们在 Python 3.5 中引入，旨在帮助开发者指定期望的数据类型，从而提高代码的可读性和可维护性。类型注解不会对 Python 运行时的行为产生影响，因为 Python 是一种动态类型语言，但它们可以被第三方工具如类型检查器（例如 `mypy`）用来进行静态类型检查。
>简单理解：明确类型，达到像如Java等强类型语言效果。

## 基本语法

```python
def greet(name: str, age: int) -> str:
    return f"Hello, {name}! You are {age} years old."
```

在这个例子中：

- `name: str` 表示 `name` 参数应该是一个字符串。
- `age: int` 表示 `age` 参数应该是一个整数。
- `-> str` 表示这个函数应该返回一个字符串。

## 类型注解的使用

### 变量注解

```python
# 基本类型注解
age: int = 25
name: str = "Alice"
height: float = 175.5
is_student: bool = True

# 延迟赋值（先声明后赋值）
score: float
if passed_exam:
    score = 95.0
else:
    score = 0.0
```

### 函数注解

基本语法：

```python
def function_name(param1: Type1, param2: Type2) -> ReturnType:
    pass
```

- param1, param2, ...：函数的参数名称。
- Type1, Type2, ...：参数的注解类型。
- ReturnType：函数返回值的注解类型。

示例：

```python
def add_numbers(a: int, b: int) -> int:
    return a + b

# 无返回值的函数
def log_message(message: str) -> None:
    print(f"[LOG] {message}")

# 返回多个值（使用元组）
def get_coordinates() -> tuple[float, float]:
    return (10.5, 20.3)
```

### 类注解

```python
from typing import Optional

class BankAccount:
    balance: float
    owner: str
    account_number: Optional[str]  # 可能为None

    def __init__(self, initial_balance: float, owner: str):
        self.balance = initial_balance
        self.owner = owner
        self.account_number = None

    def deposit(self, amount: float) -> None:
        self.balance += amount

    def withdraw(self, amount: float) -> bool:
        if amount <= self.balance:
            self.balance -= amount
            return True
        return False
```

### 使用 `typing` 模块

Python 的 `typing` 模块提供了更复杂的类型注解。不同Python版本有不同的最佳实践：

#### Python 3.5-3.8 传统方式

```python
from typing import List, Dict, Set, Tuple, Union, Optional, Callable, Any

# 容器类型注解
def process_items(items: List[str]) -> Dict[str, int]:
    return {item: len(item) for item in items}

def analyze_data(numbers: List[Union[int, float]]) -> Tuple[float, float]:
    return (min(numbers), max(numbers))

# 可选类型
def find_user(user_id: int) -> Optional[Dict[str, Any]]:
    # 可能返回用户字典或None
    pass

# 回调函数类型
def execute_callback(callback: Callable[[str], bool], data: str) -> bool:
    return callback(data)
```

#### Python 3.9+ 内置泛型类型

从Python 3.9开始，可以直接使用内置类型进行泛型注解，无需导入`typing`模块：

```python
# Python 3.9+
def process_items(items: list[str]) -> dict[str, int]:
    return {item: len(item) for item in items}

def get_unique_tags(tags: set[str]) -> set[str]:
    return set(tag.lower() for tag in tags)

def get_point() -> tuple[float, float]:
    return (0.0, 0.0)
```

#### Python 3.10+ 联合类型操作符

从Python 3.10开始，可以使用`|`操作符替代`Union`：

```python
# Python 3.10+
def handle_input(value: str | int | float) -> str:
    return str(value)

def find_item(items: list[str], target: str) -> str | None:
    return target if target in items else None

# 等价于传统的 Union 写法
# def handle_input(value: Union[str, int, float]) -> str:
# def find_item(items: List[str], target: str) -> Optional[str]:
```

### 常用 typing 类型详解

| 类型 | 用途 | 示例 | 说明 |
|------|------|------|------|
| `List[T]` / `list[T]` | 列表，所有元素为类型T | `List[int]` | Python 3.9+推荐使用`list[T]` |
| `Dict[K, V]` / `dict[K, V]` | 字典，键类型K，值类型V | `Dict[str, int]` | Python 3.9+推荐使用`dict[K, V]` |
| `Set[T]` / `set[T]` | 集合，所有元素为类型T | `Set[str]` | Python 3.9+推荐使用`set[T]` |
| `Tuple[T, ...]` / `tuple[T, ...]` | 元组 | `Tuple[str, int]` | 固定长度或可变长度 |
| `Union[A, B]` / `A \| B` | 联合类型，可以是A或B | `Union[str, int]` | Python 3.10+推荐使用`\|` |
| `Optional[T]` | 可选类型，等价于`Union[T, None]` | `Optional[str]` | 表示可能为None |
| `Callable[[ArgTypes], ReturnType]` | 可调用对象（函数） | `Callable[[int], str]` | 函数签名类型 |
| `Any` | 任意类型 | `Any` | 绕过类型检查，谨慎使用 |
| `Type[T]` | 类型本身 | `Type[Exception]` | 表示类而不是实例 |
| `Literal[value]` | 字面量类型 | `Literal["red", "blue"]` | 限制为特定值 |
| `Final` | 常量 | `MAX_SIZE: Final[int] = 100` | 表示不可重新赋值 |

### 高级类型注解示例

```python
from typing import (
    List, Dict, Set, Tuple, Union, Optional, 
    Callable, Any, Literal, Final, TypeVar, Generic
)

# TypeVar - 泛型类型变量
T = TypeVar('T')

def first_element(items: List[T]) -> T:
    """返回列表的第一个元素，保持原始类型"""
    return items[0]

# Generic - 创建泛型类
class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: List[T] = []
    
    def push(self, item: T) -> None:
        self._items.append(item)
    
    def pop(self) -> T:
        return self._items.pop()

# Literal - 字面量类型
def set_color(color: Literal["red", "green", "blue"]) -> None:
    print(f"Setting color to {color}")

# Final - 常量
API_VERSION: Final[str] = "v1.0"
MAX_RETRIES: Final[int] = 3

# 复杂嵌套类型
UserPreferences = Dict[str, Union[List[str], Dict[str, bool]]]
def process_preferences(prefs: UserPreferences) -> None:
    pass
```

## 类型注解的好处

1. **提高代码可读性**：类型注解提供了清晰的信息，表明了函数和变量应该具有的类型。
2. **静态类型检查**：可以使用 `mypy` 等工具在代码运行之前检查类型错误。
3. **IDE 支持**：现代 IDE 可以利用类型注解提供更好的自动完成、代码导航和错误检测。
4. **文档目的**：类型注解作为文档的一部分，有助于其他开发者或维护者理解代码的预期行为。
5. **重构安全**：在大型项目中修改代码时，类型检查可以帮助发现潜在的错误。
6. **团队协作**：明确的类型契约减少了沟通成本。

## 最佳实践

### 1. 渐进式添加类型注解

- 从公共API开始（函数参数和返回值）
- 逐步添加内部变量的类型注解
- 使用 `# type: ignore` 临时忽略复杂情况

### 2. 选择合适的类型粒度

```python
# 推荐：具体类型
def calculate_area(length: float, width: float) -> float:
    return length * width

# 避免：过于宽泛的类型
def calculate_area(length: Any, width: Any) -> Any:
    return length * width
```

### 3. 处理可选值

```python
# 推荐：明确使用 Optional
def find_user(user_id: int) -> Optional[User]:
    # 实现逻辑
    pass

# 在使用时进行类型检查
user = find_user(123)
if user is not None:
    print(user.name)  # mypy 知道这里 user 不是 None
```

### 4. 避免过度使用 Any

```python
# 不推荐
def process_data(data: Any) -> Any:
    return data

# 推荐：使用 Union 或泛型
def process_data(data: Union[str, int, float]) -> str:
    return str(data)
```

### 5. 使用类型别名提高可读性

```python
from typing import Dict, List, Union

# 复杂类型别名
JSONValue = Union[str, int, float, bool, None, 'JSONDict', 'JSONList']
JSONDict = Dict[str, JSONValue]
JSONList = List[JSONValue]

def parse_json(data: str) -> JSONValue:
    # 解析逻辑
    pass
```

## 常见陷阱和解决方案

### 1. 循环导入问题

```python
# 使用字符串字面量注解
class Node:
    def __init__(self, value: int, next_node: 'Node' = None):
        self.value = value
        self.next_node = next_node
```

### 2. 前向引用

```python
from __future__ import annotations  # Python 3.7+

class Tree:
    def __init__(self, value: int, children: list['Tree'] = None):
        self.value = value
        self.children = children or []
```

### 3. 动态属性问题

```python
class DynamicClass:
    def __init__(self):
        self.dynamic_attr: str = "initialized"  # 提前声明
    
    def add_attribute(self):
        setattr(self, 'new_attr', 42)  # mypy 会报错
        # 解决方案：使用 __dict__ 或在 __init__ 中预先声明
```

### 4. 第三方库无类型提示

```python
# 方案1：使用 # type: ignore
import some_library  # type: ignore

# 方案2：创建 stub 文件 (.pyi)
# 方案3：使用 Any 作为临时解决方案
from typing import Any
some_function: Any = some_library.some_function
```

## 性能考虑

- **运行时开销**：类型注解在运行时几乎无开销（仅存储在 `__annotations__` 属性中）
- **内存使用**：注解会占用少量内存，但通常可以忽略
- **启动时间**：不影响Python解释器启动时间
- **类型检查时间**：静态类型检查工具（如mypy）会增加开发时的检查时间，但不影响运行时性能

## 注意事项

- 类型注解不会强制类型检查，它们仅作为提示存在。
- 你可以为任何变量、参数或返回值添加注解。
- 可以使用 `typing` 模块中的类型来注解更复杂的数据结构。
- 在Python 3.7+中，可以使用 `from __future__ import annotations` 启用延迟注解评估，解决前向引用问题。
- 对于大型项目，建议制定团队的类型注解规范，保持一致性。

类型注解是一种有用的工具，可以帮助你编写更清晰、更可维护的代码，尤其是在大型项目或团队协作中。虽然它们不改变 Python 的动态类型特性，但它们为代码的静态分析提供了基础。合理使用类型注解可以显著提高代码质量和开发效率。
