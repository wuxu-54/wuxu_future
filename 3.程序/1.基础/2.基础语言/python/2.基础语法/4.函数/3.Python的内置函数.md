# Python 内置函数全解（分类+作用+用法+示例）

Python **内置函数**是解释器自带的核心函数，**无需导入任何模块**，直接调用即可使用，是编程中最基础、最高频的工具。

Python 3.10+ 共有**70+内置函数**，本文按**功能分类**讲解**高频核心内置函数**（含作用、语法、代码示例），冷门函数仅简要标注，兼顾实用性和完整性。

---

## 一、数值与数学运算函数

专门处理数字计算、数值转换，适用于 `int/float/complex` 类型。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `abs(x)` | 返回数字的**绝对值** | `abs(-10) → 10` |
| `round(x, n)` | 四舍五入，`n`=保留小数位数（默认0） | `round(3.1415, 2) → 3.14` |
| `max(*args)` | 返回可迭代对象/多个参数的**最大值** | `max(1,3,5) → 5`；`max([2,4,6]) →6` |
| `min(*args)` | 返回可迭代对象/多个参数的**最小值** | 用法同 `max` |
| `sum(iterable, start=0)` | 对可迭代对象求和，`start`=初始值 | `sum([1,2,3]) →6`；`sum([1,2], 10) →13` |
| `pow(x, y, z=None)` | 计算 `x^y`，带`z`则取模 `x^y % z` | `pow(2,3) →8`；`pow(2,3,5) →3` |
| `divmod(a, b)` | 返回元组 `(商, 余数)` | `divmod(10,3) →(3,1)` |
| `bool(x)` | 转换为布尔值（空/0为False，其余True） | `bool(0)→False`；`bool("abc")→True` |

## 二、序列/可迭代对象操作函数

适用于**列表、元组、字符串、range、生成器**等所有可迭代对象，是Python最常用的一类函数。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `len(obj)` | 返回对象的**长度**（元素个数） | `len("python")→6`；`len([1,2,3])→3` |
| `sorted(iterable, key=None, reverse=False)` | **排序**，返回**新列表**（原对象不变） | `sorted([3,1,2])→[1,2,3]`；`sorted([3,1], reverse=True)→[3,1]` |
| `reversed(seq)` | 反转序列，返回**迭代器**（不修改原对象） | `list(reversed([1,2,3]))→[3,2,1]` |
| `enumerate(iterable, start=0)` | 同时返回**索引+元素** | `for i, v in enumerate(["a","b"]): print(i,v)` → 0 a /1 b |
| `zip(*iterables)` | 打包多个可迭代对象，返回元组迭代器 | `list(zip([1,2],["a","b"]))→[(1,"a"),(2,"b")]` |
| `filter(func, iterable)` | 按条件**过滤**元素（func返回True保留） | `list(filter(lambda x:x>2, [1,3,5]))→[3,5]` |
| `map(func, iterable)` | 对每个元素**映射转换** | `list(map(str, [1,2,3]))→["1","2","3"]` |
| `all(iterable)` | 所有元素为True，返回True | `all([1,True,"a"])→True`；`all([0,1])→False` |
| `any(iterable)` | 任一元素为True，返回True | `any([0,False,1])→True` |

## 三、容器构造函数

用于创建**列表、元组、字典、集合**等容器对象，可将可迭代对象转换为对应容器。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `list(iterable)` | 创建/转换为**列表** | `list("abc")→["a","b","c"]` |
| `tuple(iterable)` | 创建/转换为**元组**（不可变） | `tuple([1,2])→(1,2)` |
| `dict(**kwargs)` | 创建/转换为**字典** | `dict(name="Tom", age=18)→{"name":"Tom","age":18}` |
| `set(iterable)` | 创建**集合**（无序、自动去重） | `set([1,2,2,3])→{1,2,3}` |
| `frozenset(iterable)` | 创建**不可变集合** | 用法同`set`，无法增删元素 |

## 四、类型转换与类型判断

用于数据类型转换、判断对象类型，是编程必备的基础函数。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `int(x)` | 转换为整数 | `int("123")→123`；`int(3.9)→3` |
| `float(x)` | 转换为浮点数 | `float("3.14")→3.14` |
| `str(x)` | 转换为字符串 | `str(123)→"123"` |
| `type(obj)` | 返回对象的**原始类型** | `type([1,2])→list` |
| `isinstance(obj, class)` | **推荐**：判断对象是否为指定类/子类实例 | `isinstance([1,2], list)→True` |
| `issubclass(sub, sup)` | 判断一个类是否是另一个类的子类 | `issubclass(bool, int)→True` |

## 五、输入输出与文件操作

仅3个核心函数，负责控制台交互和文件读写。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `print(*objects, sep=" ", end="\n")` | 控制台输出 | `print("hello", "python", sep="-")→hello-python` |
| `input(prompt=None)` | 控制台输入，**返回字符串** | `name = input("请输入名字：")` |
| `open(file, mode="r")` | 打开文件，返回文件对象 | `f = open("test.txt", "w"); f.write("hello"); f.close()` |

## 六、迭代器与范围生成

用于生成整数序列、操作迭代器，循环/遍历必备。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `range(start, stop, step)` | 生成**左闭右开**整数序列 | `range(1,5)→1,2,3,4`；`range(0,10,2)→0,2,4,6,8` |
| `iter(iterable)` | 将可迭代对象转为**迭代器** | `it = iter([1,2])` |
| `next(iterator)` | 获取迭代器的**下一个元素** | `next(it)→1`；`next(it)→2` |

## 七、字符与编码转换

处理字符、ASCII/Unicode编码、进制转换。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `chr(i)` | Unicode编码 → 对应字符 | `chr(65)→"A"` |
| `ord(c)` | 字符 → 对应Unicode编码 | `ord("A")→65` |
| `bin(x)` | 转换为**二进制字符串** | `bin(10)→"0b1010"` |
| `oct(x)` | 转换为**八进制字符串** | `oct(10)→"0o12"` |
| `hex(x)` | 转换为**十六进制字符串** | `hex(10)→"0xa"` |
| `format(value, format_spec)` | 格式化字符串 | `format(10, "x")→"a"` |

## 八、对象属性与标识

用于查看/操作对象的属性、内存标识。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `id(obj)` | 返回对象的**唯一内存地址** | `id([1,2])→1407...` |
| `hash(obj)` | 返回对象的哈希值（可哈希对象） | `hash("python")` |
| `dir(obj)` | 返回对象的**所有属性/方法列表** | `dir("abc")` → 查看字符串所有方法 |
| `hasattr(obj, name)` | 判断对象是否有指定属性 | `hasattr(str, "upper")→True` |

## 九、作用域与代码执行

用于操作作用域、执行字符串形式的代码（谨慎使用）。

| 函数 | 作用 | 语法 & 示例 |
|------|------|-------------|
| `globals()` | 返回**全局作用域**字典 | 查看所有全局变量 |
| `locals()` | 返回**局部作用域**字典 | 查看函数内局部变量 |
| `eval(s)` | 执行**字符串表达式**，返回结果 | `eval("1+2")→3` |
| `exec(s)` | 执行**字符串代码块**，无返回值 | `exec("a=1; print(a)")→1` |

## 十一、冷门内置函数（简要了解）

以下函数日常开发使用率极低，仅作了解：

- `compile()`：编译代码为字节码
- `repr()`：返回对象的官方字符串表示
- `slice()`：创建切片对象
- `memoryview()`：返回对象的内存视图
- `bytearray()`：可变字节数组
- `__import__()`：动态导入模块

---

## 核心总结

1. **内置函数无需导入**，直接调用，是Python的基础工具；
2. **高频必背**：`len/max/min/sum/sorted/zip/enumerate/map/filter/print/input`；
3. **关键区别**：`sorted()`返回新对象，`list.sort()`是列表方法（修改原对象）；`isinstance()` 比 `type()` 更适合类型判断。
