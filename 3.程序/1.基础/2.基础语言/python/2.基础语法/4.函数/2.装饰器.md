# 装饰器

Python 装饰允许在不修改原有函数代码的基础上，动态地增加或修改函数的功能，装饰器本质上是一个接收函数作为输入并返回一个新的包装过后的函数的对象。（也有类装饰器，即类作为装饰器）
>TS也有同种语法，其本质是在调用被装饰的函数过程中调用装饰器函数，进行某些功能修改。

格式：**@decorator_name**

Python 还提供了一些内置的装饰器，比如 `@staticmethod` 和 `@classmethod`，用于定义静态方法和类方法。

## 装饰器的应用场景

- 日志记录: 装饰器可用于记录函数的调用信息、参数和返回值。
- 性能分析: 可以使用装饰器来测量函数的执行时间。
- 权限控制: 装饰器可用于限制对某些函数的访问权限。
- 缓存: 装饰器可用于实现函数结果的缓存，以提高性能。

## 基本语法

装饰器修饰函数。

```python
@time_logger
def target_function():
    pass
```

等同于：

```python
def target_function():
    pass
target_function = time_logger(target_function)
```

## 示例

```python
def decorator_function(original_function):
    def wrapper(*args, **kwargs):
        # 这里是在调用原始函数前添加的新功能
        before_call_code()
        
        result = original_function(*args, **kwargs)
        
        # 这里是在调用原始函数后添加的新功能
        after_call_code()
        
        return result
    return wrapper

# 使用装饰器
@decorator_function
def target_function(arg1, arg2):
    pass  # 原始函数的实现
```

解析：decorator 是一个装饰器函数，它接受一个函数 func 作为参数，并返回一个内部函数 wrapper，在 wrapper 函数内部，你可以执行一些额外的操作，然后调用原始函数 func，并返回其结果。

- decorator_function 是装饰器，它接收一个函数 original_function 作为参数。
- wrapper 是内部函数，它是实际会被调用的新函数，它包裹了原始函数的调用，并在其前后增加了额外的行为。
- 当我们使用 @decorator_function 前缀在 target_function 定义前，Python会自动将 target_function 作为参数传递给 decorator_function，然后将返回的 wrapper 函数替换掉原来的 target_function。

## 类装饰器

类装饰器是包含 `__call__` 方法的类，它接受一个函数作为参数，并返回一个新的函数。

```python
class DecoratorClass:
    def __init__(self, func):
        self.func = func
    
    def __call__(self, *args, **kwargs):
        # 在调用原始函数之前/之后执行的代码
        result = self.func(*args, **kwargs)
        # 在调用原始函数之后执行的代码
        return result

@DecoratorClass
def my_function():
    pass
```

## Python 装饰器详解

装饰器是 Python 中一种非常强大且优雅的设计模式，它允许你在不修改函数或类原有定义的情况下，为其动态添加额外功能。本质上，装饰器是一个接受可调用对象（函数、方法或类）作为参数并返回另一个可调用对象的高阶函数。理解装饰器需要先掌握**闭包**和**函数对象**的概念。

### 1. 从基础开始：函数是一等公民

在 Python 中，函数可以像普通变量一样被赋值、作为参数传递、作为返回值返回。这正是装饰器得以实现的基础。

```python
def hello():
    return "Hello"

# 将函数赋值给变量
greet = hello
print(greet())  # 输出: Hello

# 函数作为参数
def call_func(func):
    return func()

print(call_func(hello))  # 输出: Hello

# 函数作为返回值
def make_greeting():
    def inner():
        return "Hi"
    return inner

f = make_greeting()
print(f())  # 输出: Hi
```

### 2. 什么是闭包？

闭包是指一个函数（内层函数）捕获了其外部作用域（外层函数）中的变量，并且即使外层函数已经执行完毕，这些变量仍然被内层函数所引用。

```python
def outer(x):
    def inner(y):
        return x + y
    return inner

add5 = outer(5)
print(add5(3))  # 输出: 8
```

这里的 `inner` 记住了外层作用域的 `x=5`，这就是闭包。装饰器就是利用闭包在运行时动态包装函数。

### 3. 最简单的装饰器

一个装饰器就是一个接受函数并返回新函数的函数。下面是一个记录函数调用时间的装饰器：

```python
def timer(func):
    import time
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 执行耗时: {end - start:.4f} 秒")
        return result
    return wrapper

# 使用手动包装
def slow_func():
    import time
    time.sleep(1)
    return "done"

slow_func = timer(slow_func)

# 使用 @ 语法糖（等效写法）
@timer
def fast_func():
    return "fast"

slow_func()
fast_func()
```

`@timer` 放在函数定义前等价于 `fast_func = timer(fast_func)`。

### 4. `@wraps` 的重要性

装饰后的函数会丢失原函数的元信息（如 `__name__`、`__doc__`、`__annotations__` 等）。`functools.wraps` 可以解决这个问题，它将原函数的属性复制到包装函数上。

```python
from functools import wraps

def logger(func):
    @wraps(func)          # 必须加在内层函数上
    def wrapper(*args, **kwargs):
        """包装函数的文档"""
        print(f"调用 {func.__name__} 参数: {args} {kwargs}")
        return func(*args, **kwargs)
    return wrapper

@logger
def add(a, b):
    """计算两数之和"""
    return a + b

print(add.__name__)   # 输出: add （如果不加 wraps 会输出 wrapper）
print(add.__doc__)    # 输出: 计算两数之和
```

**最佳实践**：编写任何装饰器时都应加上 `@wraps`，否则会破坏调试和自省能力。

### 5. 带参数的装饰器

有时装饰器本身需要接受参数（如日志级别、重复次数等）。这需要在最外层再嵌套一层函数来接收这些参数，并返回一个“真正的装饰器”。

```python
def repeat(times):
    """装饰器工厂：接受重复次数"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def say_hello():
    print("Hello")

say_hello()   # 会打印三次 Hello

# 等价于： say_hello = repeat(3)(say_hello)
```

调用链：`repeat(3)` 返回 `decorator`，然后 `decorator(say_hello)` 返回 `wrapper`。

### 6. 多个装饰器的执行顺序

当多个装饰器叠加时，执行顺序是**从下往上**（靠近函数的先装饰），但最终调用时顺序是**从上往下**（先装饰的后执行？需要区分“装饰”和“调用”）。

```python
@deco1
@deco2
@deco3
def func():
    pass

# 等价于
func = deco1(deco2(deco3(func)))
```

调用 `func()` 时，实际调用顺序：`deco1` 的包装函数先执行，其内部再调用 `deco2` 的包装函数，依此类推。示例：

```python
def deco1(f):
    @wraps(f)
    def wrapper(*a, **kw):
        print("deco1 进入")
        res = f(*a, **kw)
        print("deco1 退出")
        return res
    return wrapper

def deco2(f):
    @wraps(f)
    def wrapper(*a, **kw):
        print("deco2 进入")
        res = f(*a, **kw)
        print("deco2 退出")
        return res
    return wrapper

@deco1
@deco2
def target():
    print("target 执行")

# 执行输出:
# deco1 进入
# deco2 进入
# target 执行
# deco2 退出
# deco1 退出
```

可见外层装饰器 `deco1` 包围了内层装饰器 `deco2` 及其内部的原始函数。

### 7. 类作为装饰器

除了函数，类也可以实现装饰器，需要实现 `__call__` 方法。这样实例可以像函数一样被调用。

```python
class CountCalls:
    def __init__(self, func):
        self.func = func
        self.count = 0
        self._wrapped = func   # 可选保留原函数引用

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"调用 {self.func.__name__} 第 {self.count} 次")
        return self.func(*args, **kwargs)

@CountCalls
def greet(name):
    print(f"Hello {name}")

greet("Alice")
greet("Bob")   # count 会累积
```

类装饰器常用于需要维护状态的场景（如计数、缓存）。但注意此时原函数的元信息（`__name__` 等）会变成类的属性，可以手动通过 `functools.update_wrapper` 修复。

### 8. 装饰器装饰类

装饰器也可以作用于类，通常用于添加类属性、方法或修改类的行为（类似元类的轻量级替代）。

```python
def add_str(cls):
    def __str__(self):
        return f"{self.__class__.__name__}({self.__dict__})"
    cls.__str__ = __str__
    return cls

@add_str
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(2, 3)
print(p)   # 输出: Point({'x': 2, 'y': 3})
```

### 9. 内置的常用装饰器

Python 标准库提供了几个非常实用的装饰器：

- **`@staticmethod`**：将方法变为静态方法，不传递 self/cls 参数。
- **`@classmethod`**：将方法变为类方法，第一个参数是类本身（通常命名为 `cls`）。
- **`@property`**：将方法变成属性调用，实现 getter。
- **`@functools.lru_cache`**：为函数添加记忆化缓存（递归斐波那契常见）。
- **`@dataclass`**（Python 3.7+）：自动生成 `__init__`、`__repr__` 等特殊方法。

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)
```

### 10. 带实例状态的装饰器（使用类实例包装）

有时我们需要装饰器记住每个被装饰函数的独立状态，而非共享状态。上面的 `CountCalls` 类装饰器已经做到了每个函数有自己的计数器。如果使用函数装饰器加闭包，需要小心可变对象。

```python
def counter(func):
    cnt = 0
    @wraps(func)
    def wrapper(*args, **kwargs):
        nonlocal cnt
        cnt += 1
        print(f"{func.__name__} 已调用 {cnt} 次")
        return func(*args, **kwargs)
    return wrapper
```

### 11. 装饰器与参数传递：保留签名

即使使用 `@wraps`，包装函数的签名（参数名称、默认值）仍然不是原始函数的签名（Python 3.4+ 中 `@wraps` 会尝试复制签名，但部分工具如 `inspect.signature` 仍可工作）。如果需要完全保留签名，可以使用 `inspect` 模块动态构建，或使用第三方库 `decorator`。

```python
from decorator import decorator

@decorator
def my_decorator(func, *args, **kwargs):
    print("before")
    result = func(*args, **kwargs)
    print("after")
    return result

@my_decorator
def add(a, b):
    return a + b

import inspect
print(inspect.signature(add))  # 正确显示 (a, b)
```

### 12. 实际应用场景

- **日志与监控**：自动记录函数调用参数、返回值、耗时。
- **权限校验**：Web框架中检查用户是否登录或具有特定角色（如 Flask 的 `@login_required`）。
- **缓存**：`@lru_cache` 或自定义 Redis 缓存。
- **重试机制**：网络请求失败时自动重试指定次数。
- **输入验证/类型检查**：使用 `@validate` 装饰器校验参数类型。
- **事务管理**：数据库操作自动提交或回滚。
- **同步锁**：多线程环境中给函数加锁。

### 13. 常见陷阱与注意事项

- **忘记 `@wraps`**：导致元信息丢失，IDE 提示异常。
- **装饰器内部修改可变默认参数**：如果原函数有默认参数为列表或字典，装饰器多次调用可能意外共享状态。
- **对类方法使用装饰器时注意 `self`**：如果装饰器内部直接调用 `func(*args, **kwargs)`，类方法的第一个参数会自动传入 `self`，这没问题。但如果你想在装饰器中访问实例属性，需要解析 `args[0]`。
- **异步函数装饰**：对于 `async def` 函数，装饰器应返回 `async def wrapper`，并使用 `await func(*args, **kwargs)`。
- **性能开销**：每个被装饰的函数调用都会多一层函数调用开销，但通常可以忽略。

### 14. 完整示例：带可选参数的通用装饰器

有时候我们希望装饰器既可以不带参数使用（如 `@deco`），也可以带参数使用（如 `@deco(arg=value)`）。这需要判断传入的第一个参数是否为可调用对象。

```python
from functools import wraps
import inspect

def optional_decorator(func=None, *, times=1):
    def decorator(f):
        @wraps(f)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = f(*args, **kwargs)
            return result
        return wrapper

    if func is None:
        # 带参数调用：@optional_decorator(times=3)
        return decorator
    else:
        # 不带参数调用：@optional_decorator
        return decorator(func)

# 两种用法
@optional_decorator
def foo(): print("foo")

@optional_decorator(times=3)
def bar(): print("bar")
```

### 总结

装饰器是 Python 中非侵入式扩展函数行为的利器，理解它需要掌握闭包、高阶函数和 `@` 语法糖。合理使用装饰器可以极大提升代码的复用性和可读性，但也要警惕过度装饰导致逻辑隐藏。编写装饰器时始终加上 `functools.wraps`，并考虑其是否应该接受参数、是否适用于类方法或异步函数。掌握装饰器是进阶 Python 编程的重要里程碑。
