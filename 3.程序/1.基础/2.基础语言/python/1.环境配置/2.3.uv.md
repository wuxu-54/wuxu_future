# uv 完全详解：超高速 Python 包与环境管理器

**uv** 是由 Astral 公司（开发了 Ruff 代码检查器）用 **Rust 语言** 编写的下一代 Python 包管理器和虚拟环境管理器。它的目标是**全面替代 pip、pipenv、poetry、virtualenv、tox** 等工具，提供**10-100倍**的速度提升，同时保持完全的兼容性和更强大的功能。

对于你之前使用的 Jupyter Notebook（.ipynb 文件），uv 提供了**原生支持**，可以极大简化环境配置和 Notebook 运行流程。

## 一、核心优势：为什么选择 uv？

### 1. 碾压级的速度

这是 uv 最显著的优势。与传统工具相比：

- 依赖解析速度：比 poetry 快 **100-1000倍**
- 包安装速度：比 pip 快 **10-100倍**
- 虚拟环境创建：几乎瞬时完成（<100ms）

**速度对比示例**（安装 pandas + numpy + matplotlib + seaborn + scikit-learn）：

| 工具 | 耗时 |
|------|------|
| pip | ~45秒 |
| poetry | ~90秒 |
| uv | ~2秒 |

### 2. 功能全面整合

uv 一个工具就包含了：

- 虚拟环境管理（替代 virtualenv/venv）
- 包安装与卸载（替代 pip）
- 依赖解析与锁定（替代 poetry/pipenv）
- 项目管理（替代 poetry）
- 脚本运行（替代 pipx）
- 多版本 Python 管理（替代 pyenv）
- ✅ **原生支持运行 .ipynb 文件**（新功能）

### 3. 完美兼容性

- 完全兼容 pip 的命令行接口和 `requirements.txt` 格式
- 支持 `pyproject.toml` 标准（PEP 621）
- 可以无缝导入 poetry 和 pipenv 的项目
- 支持所有主流 Python 版本（3.7+）和操作系统

### 4. 其他亮点

- 全局缓存：跨项目共享下载的包，节省磁盘空间
- 离线工作：缓存的包无需重新下载
- 严格的依赖解析：避免版本冲突
- 自动清理：自动删除未使用的包
- 内置 pipx 功能：全局安装命令行工具

## 二、安装 uv

### 1. 一键安装（推荐）

```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 2. 用 pip 安装（不推荐，但可用）

```bash
pip install uv
```

### 3. 验证安装

```bash
uv --version
# 输出类似：uv 0.4.18 (a1b2c3d 2025-05-15)
```

## 三、核心功能与常用命令

### 1. 虚拟环境管理

uv 会自动在项目目录下创建 `.venv` 虚拟环境，无需手动激活。

```bash
# 创建虚拟环境（自动检测系统Python版本）
uv venv

# 创建指定Python版本的虚拟环境
uv venv --python 3.11
uv venv --python 3.12.3

# 激活虚拟环境（传统方式，uv run 更推荐）
# macOS/Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate

# 退出虚拟环境
deactivate
```

### 2. 包管理

```bash
# 安装包（自动创建虚拟环境如果不存在）
uv add pandas numpy matplotlib

# 安装指定版本
uv add pandas==2.2.0
uv add "pandas>=2.0,<3.0"

# 安装开发依赖
uv add --dev pytest black ruff

# 卸载包
uv remove pandas

# 更新所有包到最新版本
uv update

# 更新指定包
uv update pandas

# 安装项目所有依赖（从 pyproject.toml 和 uv.lock）
uv sync
```

### 3. 运行命令与脚本

uv 最强大的功能之一是**无需手动激活虚拟环境**，直接运行命令：

```bash
# 在虚拟环境中运行任意命令
uv run python --version
uv run pip list

# 运行Python脚本
uv run script.py

# 运行项目中定义的脚本（在 pyproject.toml 的 [tool.uv.scripts] 中）
uv run start
uv run test
```

### 4. 项目管理

```bash
# 初始化一个新项目
uv init my_project
cd my_project

# 初始化一个现有项目
uv init

# 生成依赖锁定文件 uv.lock
uv lock

# 导出 requirements.txt
uv export --format requirements.txt > requirements.txt

# 从 requirements.txt 导入依赖
uv add -r requirements.txt
```

## 四、重点：uv 与 Jupyter Notebook 完美结合

这是对你最有用的部分！uv 极大简化了 Jupyter 环境的配置和 .ipynb 文件的运行。

### 1. 一键创建 Jupyter 环境

```bash
# 创建新项目并安装 JupyterLab
uv init my_data_project
cd my_data_project
uv add jupyterlab pandas numpy seaborn scikit-learn
```

### 2. 启动 JupyterLab/Notebook

**无需激活虚拟环境**，直接运行：

```bash
# 启动 JupyterLab（推荐）
uv run jupyter lab

# 启动经典 Jupyter Notebook
uv run jupyter notebook
```

### 3. ✅ 直接运行 .ipynb 文件（uv 0.4+ 新功能）

这是 uv 最惊艳的功能之一！你可以**不用启动 Jupyter 服务器**，直接在命令行运行整个 .ipynb 文件：

```bash
# 运行你之前的鸢尾花分析示例
uv run iris_analysis.ipynb
```

**这个命令会自动：**

1. 检测当前目录的虚拟环境（如果没有则自动创建）
2. 安装 Notebook 中所需的所有依赖（如果未安装）
3. 按顺序执行所有单元格
4. 将运行结果保存回原 .ipynb 文件

### 4. 为单个 Notebook 创建临时环境

如果你只想运行一个别人的 .ipynb 文件，不想污染全局环境：

```bash
# 创建临时环境，运行 Notebook，然后删除环境
uv run --with pandas,numpy,matplotlib iris_analysis.ipynb
```

### 5. 管理 Jupyter 内核

```bash
# 将当前虚拟环境注册为 Jupyter 内核
uv run python -m ipykernel install --user --name=my_project_env

# 查看已安装的内核
uv run jupyter kernelspec list

# 删除内核
uv run jupyter kernelspec remove my_project_env
```

## 五、完整工作流示例：用 uv 运行你的鸢尾花分析

1. **下载你的示例文件**：保存 `iris_analysis.ipynb` 到一个新文件夹

2. **一键运行所有内容**：

   ```bash
   uv run --with pandas,numpy,matplotlib,seaborn,scikit-learn iris_analysis.ipynb
   ```

   就是这么简单！uv 会自动：
   - 创建一个临时虚拟环境
   - 安装所有 5 个依赖包（只需几秒钟）
   - 执行 Notebook 中的所有代码单元格
   - 将运行结果（表格、图表）保存回原文件

3. **如果想交互式编辑**：

   ```bash
   # 安装 JupyterLab 并启动
   uv add jupyterlab
   uv run jupyter lab iris_analysis.ipynb
   ```

## 七、常见问题与最佳实践

### 1. 从 pip/poetry 迁移到 uv

```bash
# 从 requirements.txt 迁移
uv add -r requirements.txt

# 从 poetry 迁移
uv import pyproject.toml
uv sync
```

### 2. 配置镜像源

创建 `~/.config/uv/uv.toml` 文件（Windows: `%APPDATA%\uv\uv.toml`）：

```toml
[index-url]
default = "https://pypi.tuna.tsinghua.edu.cn/simple"
```

### 3. 最佳实践

- 每个项目使用独立的虚拟环境（uv 会自动创建）
- 提交 `uv.lock` 文件到版本控制，确保团队环境一致
- 使用 `uv run` 代替手动激活虚拟环境
- 对于 Jupyter 项目，在 `pyproject.toml` 中声明所有依赖
- 使用 `uv run notebook.ipynb` 快速运行和验证 Notebook

### 4. 常见问题

- **Q: uv 会破坏我现有的 Python 环境吗？**  
  A: 不会。uv 默认在项目目录创建独立的 `.venv` 环境，不会影响全局 Python。

- **Q: 我可以同时使用 uv 和 pip 吗？**  
  A: 可以，但不推荐。uv 完全兼容 pip 的命令，建议统一使用 uv。

- **Q: uv 支持 Conda 吗？**  
  A: 目前不支持 Conda 包，但可以在 Conda 环境中使用 uv 来管理 pip 包。
