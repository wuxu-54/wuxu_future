
# NumPy 超详细入门：语法 + API + 作用（看完直接用）

<https://numpy.com.cn/>

**NumPy = Python 里做数值计算的核心库**，所有机器学习、深度学习、RAG、向量检索都离不开它。
它专门用来处理**数组（矩阵）**，比 Python 原生列表快 10~100 倍！

---

## 一、NumPy 到底干嘛用？（一句话）

- 用来创建**多维数组（向量、矩阵）**
- 快速做**数学运算、加减乘除、统计、矩阵运算**
- **所有 AI 库的底层基础**：sklearn、PyTorch、TensorFlow、LangChain 都依赖它

## 三、核心数据结构：np.array（数组）

### 1. 从列表创建数组

```python
import numpy as np

## 一维数组（向量）
a = np.array([1, 2, 3, 4])

## 二维数组（矩阵）
b = np.array([[1,2], [3,4], [5,6]])
```

### 2. 数组常用属性

```python
a.shape    ## 形状 (4,) → 4个元素
b.shape    ## (3,2) → 3行2列
a.ndim     ## 维度 1
b.ndim     ## 维度 2
a.dtype    ## 数据类型 int64
a.size     ## 总元素数量
```

---

## 四、最常用创建数组 API（必须会）

### 1. `np.array()` → 列表转数组

```python
np.array([1,2,3])
```

### 2. `np.zeros(shape)` → 全 0 数组

```python
np.zeros((2,3))  ## 2行3列 全0
```

### 3. `np.ones(shape)` → 全 1 数组

```python
np.ones((3,3))
```

### 4. `np.arange(start, end, step)` → 数字序列

```python
np.arange(0, 10, 2)  ## [0,2,4,6,8]
```

### 5. `np.random.rand(shape)` → 随机数（0~1）

```python
np.random.rand(3,2)
```

### 6. `np.linspace(start, stop, num)` → 均分数字

```python
np.linspace(0, 10, 5)
```

---

## 五、数组索引 & 切片（读取数据）

### 1. 一维

```python
a = np.array([10,20,30,40])
a[0]    ## 10
a[1:3]  ## [20,30]
```

### 2. 二维（行，列）

```python
b = np.array([[1,2],[3,4],[5,6]])
b[0, 1]   ## 第0行第1列 → 2
b[:, 0]   ## 所有行，第0列 → [1,3,5]
b[1, :]   ## 第1行，所有列 → [3,4]
```

---

## 六、数学运算（超级重要）

### 1. 加减乘除（直接算）

```python
a = np.array([1,2])
b = np.array([3,4])

a + b   ## [4,6]
a - b
a * b
a / b
```

### 2. 常用统计函数

```python
a.sum()    ## 总和
a.mean()   ## 平均值
a.max()    ## 最大值
a.min()    ## 最小值
a.argmax() ## 最大值索引
np.sqrt(a) ## 开方
np.exp(a)  ## 指数
```

### 3. 矩阵乘法（AI 必用）

```python
np.dot(a, b)   ## 点积（向量相似度用这个！）
a @ b          ## 矩阵乘法
```

## 七、形状操作

### 1. reshape 改变形状

```python
a = np.arange(6)
a.reshape(2,3)  ## 变成 2行3列
```

### 2. flatten 展平

```python
a.flatten()   ## 变成一维
```

### 3. 转置

```python
a.T
```

## 八、与 sklearn 的关系（你马上会用到）

**TF-IDF 输出的向量就是 numpy 数组！**

```python
from sklearn.feature_extraction.text import TfidfVectorizer
vec = TfidfVectorizer()
X = vec.fit_transform(["我 爱 机器学习"])

## X 是 numpy 数组
print(X.toarray())
```

你之后做**余弦相似度、向量检索、RAG 匹配**，全是 numpy 运算！

## 九、你必须记住的 10 个 API（高频）

1. `np.array()` → 创建数组
2. `np.zeros()` / `np.ones()` → 创建空数组
3. `arr.shape` → 看形状
4. `arr.reshape()` → 改形状
5. `arr.sum()` / `.mean()` / `.max()`
6. `np.dot()` → 点积（相似度）
7. `arr[:,0]` → 取列
8. `arr[0,:]` → 取行
9. `np.arange()` → 生成序列
10. `arr.toarray()` → 稀疏矩阵转numpy（TF-IDF常用）
