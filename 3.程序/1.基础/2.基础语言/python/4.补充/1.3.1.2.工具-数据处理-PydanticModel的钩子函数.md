# Pydantic Model 完整钩子函数指南

> 注：以下内容基于**Pydantic v2（当前主流版本，2.12+）** 编写，同时包含v1的钩子信息以便迁移参考。

Pydantic的钩子系统允许您在模型的**验证、初始化、序列化**等生命周期阶段插入自定义逻辑。根据使用方式，可分为**可直接重写的生命周期方法**和**装饰器注册的钩子**两大类。

## 一、Pydantic v2 核心钩子（推荐使用）

### 1. 可直接重写的生命周期方法

这些是`BaseModel`类中预定义的特殊方法，您可以直接在子类中重写它们来插入逻辑。

| 钩子方法 | 版本要求 | 签名 | 调用时机 | 主要用途 | 注意事项 |
|---------|---------|------|---------|---------|---------|
| `model_post_init` | v2.0+ | `def model_post_init(self, __context: Any) -> None` | 所有验证完成后，模型实例已基本构建 | 初始化非验证逻辑、设置私有属性、建立连接、注册事件等 | `__context`是验证时传入的上下文对象；可以修改模型实例 |
| `__pydantic_on_complete__` | v2.12.0+ | `def __pydantic_on_complete__(self) -> None` | `model_post_init`执行完毕后 | 标志模型**完全准备好使用**，适合执行依赖于模型完全初始化的逻辑 | 是v2.12新增的最终初始化钩子 |
| `__init__` | 所有版本 | `def __init__(self, **data: Any) -> None` | 构造函数调用时 | 自定义初始化流程 | **强烈不推荐重写**，会丢失所有验证参数（如`strict`、`context`、`extra`等）；如需初始化逻辑请使用`model_post_init` |

### 2. 装饰器注册的钩子

这些是通过装饰器注册的函数，Pydantic会在对应的生命周期阶段自动调用它们。

#### 2.1 验证类钩子

用于自定义数据验证逻辑，支持模型级和字段级。

##### 模型级验证器：`@model_validator`

```python
from typing import Any
from typing_extensions import Self
from pydantic import BaseModel, model_validator, ModelWrapValidatorHandler

class User(BaseModel):
    username: str
    password1: str
    password2: str

    # 模式1：before - 在所有字段验证之前执行，接收原始输入数据
    @model_validator(mode='before')
    @classmethod
    def pre_process_data(cls, data: Any) -> Any:
        if isinstance(data, dict):
            # 数据预处理：统一用户名小写
            data['username'] = data.get('username', '').lower()
        return data

    # 模式2：after - 在所有字段验证之后执行，接收已验证的模型实例
    @model_validator(mode='after')
    def check_passwords_match(self) -> Self:
        if self.password1 != self.password2:
            raise ValueError('两次输入的密码不一致')
        return self

    # 模式3：wrap - 包装整个验证过程，完全控制验证流程
    @model_validator(mode='wrap')
    @classmethod
    def wrap_validation(cls, data: Any, handler: ModelWrapValidatorHandler[Self]) -> Self:
        try:
            return handler(data)
        except ValueError as e:
            # 自定义错误处理
            raise ValueError(f"用户验证失败: {e}") from e
```

##### 字段级验证器：`@field_validator`

```python
from pydantic import BaseModel, field_validator, ValidationInfo

class Product(BaseModel):
    name: str
    price: float
    stock: int

    # 验证单个字段，after模式（默认）：在类型转换后执行
    @field_validator('price')
    @classmethod
    def check_price_positive(cls, v: float) -> float:
        if v <= 0:
            raise ValueError('价格必须大于0')
        return v

    # 验证多个字段，before模式：在类型转换前执行
    @field_validator('name', 'stock', mode='before')
    @classmethod
    def pre_process_fields(cls, v: Any, info: ValidationInfo) -> Any:
        if info.field_name == 'name':
            return v.strip()  # 去除名称前后空格
        if info.field_name == 'stock':
            return int(v) if v is not None else 0  # 强制转换为整数
        return v
```

#### 2.2 序列化类钩子

用于自定义数据序列化逻辑，支持模型级和字段级。

##### 模型级序列化器：`@model_serializer`

```python
from pydantic import BaseModel, model_serializer, SerializerFunctionWrapHandler

class Order(BaseModel):
    id: int
    total: float
    status: str

    # 模式1：plain - 直接返回序列化结果，替代默认序列化
    @model_serializer(mode='plain')
    def serialize_order(self) -> dict[str, Any]:
        return {
            'order_id': self.id,
            'order_total': f"${self.total:.2f}",
            'order_status': self.status.upper()
        }

    # 模式2：wrap - 调用默认序列化器，在其前后添加逻辑
    @model_serializer(mode='wrap')
    def wrap_serialize(self, handler: SerializerFunctionWrapHandler) -> dict[str, Any]:
        result = handler(self)
        # 添加额外字段
        result['serialized_at'] = datetime.now().isoformat()
        return result
```

##### 字段级序列化器：`@field_serializer`

```python
from datetime import datetime
from pydantic import BaseModel, field_serializer

class Event(BaseModel):
    name: str
    start_time: datetime
    end_time: datetime

    # 序列化单个字段
    @field_serializer('start_time', 'end_time')
    def format_datetime(self, v: datetime) -> str:
        return v.strftime('%Y-%m-%d %H:%M:%S')

    # 仅在JSON模式下生效
    @field_serializer('name', when_used='json')
    def format_name_json(self, v: str) -> str:
        return f"【{v}】"
```

#### 2.3 计算字段：`@computed_field`

用于定义依赖于其他字段的动态字段，在序列化时自动计算。

```python
from pydantic import BaseModel, computed_field

class Rectangle(BaseModel):
    width: float
    height: float

    @computed_field
    @property
    def area(self) -> float:
        return self.width * self.height

    @computed_field(alias='perimeter_cm')
    @property
    def perimeter(self) -> float:
        return 2 * (self.width + self.height)
```

## 二、Pydantic v1 钩子（已废弃，仅用于迁移）

Pydantic v1的钩子系统在v2中已被重构，以下是v1的主要钩子及其v2替代方案：

| Pydantic v1 钩子 | Pydantic v2 替代方案 |
|-----------------|---------------------|
| `__post_init__` | `model_post_init` |
| `__post_init_post_parse__` | 已移除，逻辑可合并到`model_post_init` |
| `@validator` | `@field_validator` |
| `@root_validator` | `@model_validator` |
| `json_encoders` 配置 | `@field_serializer` / `@model_serializer` |

## 三、完整生命周期调用顺序

### 验证与初始化流程（v2.12+）

1. 调用构造函数（`User(**data)`）或验证方法（`User.model_validate(data)` / `User.model_validate_json(json_str)`）
2. 执行所有`@model_validator(mode='before')`
3. 执行所有`@field_validator(mode='before')`
4. Pydantic内部执行类型转换和基础验证
5. 执行所有`@field_validator(mode='after')`
6. 执行所有`@model_validator(mode='after')`
7. 执行`model_post_init(__context)`
8. 执行`__pydantic_on_complete__()`
9. 模型实例完全可用

### 序列化流程

1. 调用序列化方法（`model.model_dump()` / `model.model_dump_json()`）
2. 计算所有`@computed_field`的值
3. 执行所有`@field_serializer`
4. 执行`@model_serializer`（如果定义）
5. 返回最终序列化结果

## 四、重要注意事项

1. **避免重写`__init__`**：除非您完全了解其影响，否则请使用`model_post_init`进行初始化逻辑。
2. **验证器返回值**：`before`模式验证器必须返回处理后的数据；`after`模式模型验证器必须返回`self`。
3. **序列化器限制**：每个字段/模型只能定义一个序列化器，无法组合多个。
4. **版本兼容性**：`__pydantic_on_complete__`仅在v2.12.0及以上版本可用，低版本会报错。
5. **与Pydantic AI钩子区分**：Pydantic AI的钩子（如`before_model_request`）是用于Agent生命周期的，与`BaseModel`的钩子无关。

## Pydantic v2 钩子速查表 + 完整可运行示例

### 一、常用钩子使用场景速查表

| 钩子类型 | 具体钩子 | 最常用场景 | 代码片段 |
|---------|---------|-----------|---------|
| **初始化钩子** | `model_post_init` | 初始化非验证属性、建立数据库连接、注册事件、计算缓存值 | `def model_post_init(self, __context): self._cache = {}` |
| | `__pydantic_on_complete__` | 执行依赖于模型完全初始化的逻辑、发送初始化完成通知 | `def __pydantic_on_complete__(self): self._start_heartbeat()` |
| **验证钩子** | `@field_validator(mode='before')` | 数据清洗：去除空格、统一大小写、类型强制转换 | `@field_validator('email') def normalize_email(cls, v): return v.strip().lower()` |
| | `@field_validator(mode='after')` | 业务规则验证：范围检查、格式验证、枚举检查 | `@field_validator('age') def check_age(cls, v): if v < 18: raise ValueError('必须成年')` |
| | `@model_validator(mode='before')` | 全局数据预处理：添加默认值、字段重命名、数据转换 | `@model_validator(mode='before') def rename_fields(cls, data): data['user_id'] = data.pop('id')` |
| | `@model_validator(mode='after')` | 跨字段验证：密码确认、日期范围、逻辑依赖关系 | `@model_validator(mode='after') def check_dates(self): if self.end < self.start: raise ValueError()` |
| | `@model_validator(mode='wrap')` | 自定义错误处理、验证日志记录、权限检查 | `@model_validator(mode='wrap') def wrap_validation(cls, data, handler): try: return handler(data) except: raise CustomError()` |
| **序列化钩子** | `@field_serializer` | 格式化输出：日期格式化、金额格式化、敏感信息脱敏 | `@field_serializer('password') def mask_password(self, v): return '*' * 8` |
| | `@model_serializer(mode='plain')` | 完全自定义序列化结构：字段重命名、嵌套结构转换 | `@model_serializer(mode='plain') def serialize(self): return {'id': self.id, 'name': self.name}` |
| | `@model_serializer(mode='wrap')` | 扩展默认序列化：添加额外字段、修改现有字段 | `@model_serializer(mode='wrap') def wrap_serialize(self, handler): result = handler(self); result['timestamp'] = datetime.now()` |
| **计算字段** | `@computed_field` | 动态计算属性：总价、年龄、状态派生值 | `@computed_field @property def total(self): return self.price * self.quantity` |

### 二、包含所有核心钩子的完整示例代码

```python
from datetime import datetime
from typing import Any, Optional
from typing_extensions import Self
from pydantic import (
    BaseModel,
    field_validator,
    model_validator,
    field_serializer,
    model_serializer,
    computed_field,
    ValidationInfo,
    ModelWrapValidatorHandler,
    SerializerFunctionWrapHandler,
)

class User(BaseModel):
    """用户模型，展示Pydantic v2所有核心钩子的用法"""
    user_id: int
    username: str
    email: str
    password: str
    confirm_password: str
    birth_date: Optional[datetime] = None
    is_active: bool = True
    created_at: datetime = datetime.now()

    # ------------------------------
    # 1. 字段级验证器 - before模式
    # ------------------------------
    @field_validator('username', 'email', mode='before')
    @classmethod
    def pre_process_strings(cls, v: Any, info: ValidationInfo) -> Any:
        """在类型转换前处理字符串：去除空格、统一大小写"""
        if not isinstance(v, str):
            return v
        
        if info.field_name == 'email':
            return v.strip().lower()
        return v.strip()

    # ------------------------------
    # 2. 字段级验证器 - after模式
    # ------------------------------
    @field_validator('password')
    @classmethod
    def validate_password_strength(cls, v: str) -> str:
        """验证密码强度：至少8位，包含字母和数字"""
        if len(v) < 8:
            raise ValueError('密码长度不能少于8位')
        if not any(c.isalpha() for c in v):
            raise ValueError('密码必须包含至少一个字母')
        if not any(c.isdigit() for c in v):
            raise ValueError('密码必须包含至少一个数字')
        return v

    # ------------------------------
    # 3. 模型级验证器 - before模式
    # ------------------------------
    @model_validator(mode='before')
    @classmethod
    def pre_process_model_data(cls, data: Any) -> Any:
        """全局数据预处理：添加默认值、字段重命名"""
        if isinstance(data, dict):
            # 兼容旧API的字段名
            if 'id' in data and 'user_id' not in data:
                data['user_id'] = data.pop('id')
            
            # 设置默认创建时间
            if 'created_at' not in data:
                data['created_at'] = datetime.now()
        
        return data

    # ------------------------------
    # 4. 模型级验证器 - after模式
    # ------------------------------
    @model_validator(mode='after')
    def check_passwords_match(self) -> Self:
        """跨字段验证：确认两次密码输入一致"""
        if self.password != self.confirm_password:
            raise ValueError('两次输入的密码不一致')
        return self

    # ------------------------------
    # 5. 模型级验证器 - wrap模式
    # ------------------------------
    @model_validator(mode='wrap')
    @classmethod
    def wrap_validation_with_logging(
        cls, 
        data: Any, 
        handler: ModelWrapValidatorHandler[Self]
    ) -> Self:
        """包装整个验证过程，添加日志记录和自定义错误处理"""
        print(f"开始验证用户数据: {data}")
        try:
            result = handler(data)
            print(f"用户数据验证成功: user_id={result.user_id}")
            return result
        except Exception as e:
            print(f"用户数据验证失败: {str(e)}")
            raise ValueError(f"用户注册失败: {str(e)}") from e

    # ------------------------------
    # 6. 初始化钩子 - model_post_init
    # ------------------------------
    def model_post_init(self, __context: Any) -> None:
        """验证完成后执行初始化逻辑"""
        print(f"执行model_post_init: 初始化用户 {self.username}")
        
        # 初始化私有属性
        self._session_token: Optional[str] = None
        self._last_login: Optional[datetime] = None
        
        # 模拟建立数据库连接
        self._db_connection = f"db_connection_{self.user_id}"

    # ------------------------------
    # 7. 最终初始化钩子 - __pydantic_on_complete__
    # ------------------------------
    def __pydantic_on_complete__(self) -> None:
        """模型完全初始化后执行"""
        print(f"执行__pydantic_on_complete__: 用户 {self.username} 已准备就绪")
        
        # 模拟发送用户注册成功通知
        self._send_welcome_email()

    # ------------------------------
    # 8. 计算字段
    # ------------------------------
    @computed_field
    @property
    def age(self) -> Optional[int]:
        """根据出生日期计算年龄"""
        if not self.birth_date:
            return None
        
        today = datetime.today()
        age = today.year - self.birth_date.year
        if (today.month, today.day) < (self.birth_date.month, self.birth_date.day):
            age -= 1
        return age

    @computed_field(alias='full_name')
    @property
    def display_name(self) -> str:
        """用户显示名称"""
        return f"{self.username} ({self.email.split('@')[0]})"

    # ------------------------------
    # 9. 字段级序列化器
    # ------------------------------
    @field_serializer('password', 'confirm_password')
    def mask_sensitive_fields(self, v: str) -> str:
        """敏感信息脱敏：密码显示为星号"""
        return '*' * 8

    @field_serializer('birth_date', 'created_at')
    def format_datetime(self, v: Optional[datetime]) -> Optional[str]:
        """日期格式化"""
        if not v:
            return None
        return v.strftime('%Y-%m-%d %H:%M:%S')

    # ------------------------------
    # 10. 模型级序列化器 - wrap模式
    # ------------------------------
    @model_serializer(mode='wrap')
    def wrap_serialize(self, handler: SerializerFunctionWrapHandler) -> dict[str, Any]:
        """扩展默认序列化，添加额外信息"""
        result = handler(self)
        
        # 添加序列化时间戳
        result['serialized_at'] = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        
        # 移除不需要的字段
        result.pop('confirm_password', None)
        
        return result

    # ------------------------------
    # 私有辅助方法
    # ------------------------------
    def _send_welcome_email(self) -> None:
        """模拟发送欢迎邮件"""
        print(f"发送欢迎邮件到 {self.email}")

    def login(self, password: str) -> bool:
        """用户登录方法"""
        if password == self.password:
            self._last_login = datetime.now()
            self._session_token = f"token_{self.user_id}_{int(datetime.now().timestamp())}"
            print(f"用户 {self.username} 登录成功")
            return True
        print(f"用户 {self.username} 登录失败")
        return False

# ------------------------------
# 测试代码
# ------------------------------
if __name__ == "__main__":
    print("=== 创建用户实例 ===")
    try:
        user = User(
            id=1001,  # 测试字段重命名
            username="  JohnDoe  ",  # 测试空格去除
            email="JOHNDOE@EXAMPLE.COM  ",  # 测试大小写转换和空格去除
            password="Password123",
            confirm_password="Password123",
            birth_date=datetime(1990, 5, 15)
        )
    except ValueError as e:
        print(f"创建用户失败: {e}")
        exit(1)

    print("\n=== 用户实例信息 ===")
    print(f"用户ID: {user.user_id}")
    print(f"用户名: {user.username}")
    print(f"邮箱: {user.email}")
    print(f"年龄: {user.age}")
    print(f"显示名称: {user.display_name}")
    print(f"是否激活: {user.is_active}")
    print(f"创建时间: {user.created_at}")

    print("\n=== 测试登录 ===")
    user.login("Password123")

    print("\n=== 序列化结果 ===")
    serialized_user = user.model_dump()
    for key, value in serialized_user.items():
        print(f"{key}: {value}")

    print("\n=== JSON序列化结果 ===")
    print(user.model_dump_json(indent=2, by_alias=True))
```

### 三、运行输出说明

运行上述代码，你会看到清晰的钩子调用顺序：

1. 先执行`wrap_validation_with_logging`（wrap模式验证器）
2. 然后执行`pre_process_model_data`（before模式模型验证器）
3. 接着执行`pre_process_strings`（before模式字段验证器）
4. 然后执行`validate_password_strength`（after模式字段验证器）
5. 接着执行`check_passwords_match`（after模式模型验证器）
6. 然后执行`model_post_init`
7. 最后执行`__pydantic_on_complete__`

序列化时会先计算所有`@computed_field`，然后执行`@field_serializer`，最后执行`@model_serializer`。

### 四、最佳实践补充

1. **优先使用装饰器钩子**：装饰器钩子比直接重写方法更灵活，支持多个验证器按顺序执行
2. **保持验证器纯粹**：验证器应该只做数据验证和转换，不要有副作用
3. **使用`mode='before'`做数据清洗**：在类型转换前处理原始数据可以避免很多类型错误
4. **使用`mode='after'`做业务验证**：在类型转换后验证业务规则，代码更简洁
5. **敏感信息处理**：永远使用`@field_serializer`脱敏敏感字段，不要在模型中存储明文密码
6. **版本兼容**：如果需要兼容v2.12以下版本，不要使用`__pydantic_on_complete__`，将逻辑合并到`model_post_init`
