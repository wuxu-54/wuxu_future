## 一、一句话说清：jieba 是啥？

**jieba = Python 里最流行、最简单、最好用的中文分词工具**
专门把**连续中文句子切成一个个词语**。

例子：

```
我喜欢机器学习
→ 我 / 喜欢 / 机器学习
```

为什么必须分词？
因为**中文不像英文有天然空格**，计算机无法直接识别词语，必须先分词，才能做：

- TF-IDF
- 词向量
- RAG 检索
- 文本分类
- 关键词提取

---

## 二、jieba 三大核心功能（必须掌握）

### 1）精确模式（最常用）

把句子**最准确、无冗余**地切开。

```
我爱北京天安门
→ 我 / 爱 / 北京 / 天安门
```

### 2）全模式

把句子里**所有可能的词都切出来**，速度快，但有冗余。

```
我爱北京天安门
→ 我 / 爱 / 北京 / 天安 / 天安门
```

### 3）搜索引擎模式

在精确模式基础上，**对长词再切分**，适合搜索引擎、检索。

```
机器学习深度学习
→ 机器 / 学习 / 深度 / 深度学 / 学习 / 深度学习
```

## 三、3 行代码学会使用 jieba

### 安装

```bash
pip install jieba
```

### 最简单分词

```python
import jieba

text = "我喜欢使用jieba进行中文分词"

## 精确模式（默认）
words = jieba.cut(text)  
print(list(words))
```

输出：

```
['我', '喜欢', '使用', 'jieba', '进行', '中文', '分词']
```

### 三种模式写法

```python
## 1. 精确模式
jieba.cut(text, cut_all=False)

## 2. 全模式
jieba.cut(text, cut_all=True)

## 3. 搜索引擎模式
jieba.cut_for_search(text)
```

## 四、jieba 为什么这么强？（原理）

jieba 基于 **前缀词典 + 动态规划（DP）** 找最大概率分词路径。

简单说：

1. 内置词典包含几十万个词语
2. 计算哪种切分方式最通顺、最常见
3. 输出最优切分

所以它**切词准、速度快、支持自定义词**。

## 五、超级重要功能：自定义词典（必学）

jieba 自带词典不一定包含你的专业词，比如：

- 大模型
- 提示词
- RAG
- LangChain
- 脑机接口

你可以**强制让它不切开**！

### 方法 1：临时添加词

```python
jieba.add_word("大模型")
jieba.add_word("LangChain")
jieba.add_word("RAG系统")
```

### 方法 2：加载自定义词典文件（推荐）

user_dict.txt

```
大模型
LangChain
RAG系统
提示工程
```

使用：

```python
jieba.load_userdict("user_dict.txt")
```

效果：

```
我正在学习LangChain的RAG系统
→ 我 / 正在 / 学习 / LangChain / 的 / RAG系统
```

## 六、关键词提取（做 RAG 必备）

jieba 自带 **TF-IDF 关键词抽取**，不用自己写！

```python
from jieba import analyse

text = "我喜欢使用机器学习和深度学习构建AI大模型系统"

## 提取关键词
keywords = analyse.extract_tags(text, topK=3)
print(keywords)
```

输出：

```
['机器学习', '深度学习', '大模型']
```

## 七、词性标注（知道词语是什么类型）

你可以知道：名词、动词、形容词…

```python
import jieba.posseg as pseg

words = pseg.cut("我爱中国")
for w, f in words:
    print(w, f)
```

输出：

```
我 r
爱 v
中国 ns
```

常见词性：

- n 名词
- v 动词
- a 形容词
- ns 地名
- r 代词

## 九、jieba 在 LangChain / RAG 里怎么用？

**RAG 检索、文本分块、关键词匹配都必须先分词**

典型流程：

1. 文档 → jieba 分词
2. 分词 → TF-IDF 向量
3. 向量存入检索库
4. 用户提问 → 分词 → 检索 → 回答

你在 LangChain 做中文 RAG 时，**100% 会用到 jieba**。
