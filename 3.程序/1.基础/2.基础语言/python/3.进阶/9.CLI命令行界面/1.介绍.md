# Python CLI 完整指南：从入门到企业级实战

**CLI（Command-Line Interface，命令行界面）** 是Python最强大的应用形态之一。与图形界面相比，CLI工具具有**轻量、快速、可脚本化、易自动化、资源消耗低**等优势，是开发者工具、系统管理、数据处理和CI/CD流水线的首选。

## 一、Python CLI 基础

### 什么是Python CLI？

Python CLI是通过命令行终端与用户交互的Python程序。它接收用户输入的命令和参数，执行相应的逻辑，并将结果输出到终端。

### Python CLI的核心优势

- **零依赖部署**：纯Python编写，只需Python环境即可运行
- **跨平台兼容**：在Windows、macOS和Linux上表现一致
- **易于集成**：可以轻松被其他脚本或程序调用
- **开发速度快**：相比GUI开发，CLI工具开发周期短得多
- **可组合性**：可以通过管道`|`和重定向`>`与其他命令组合使用

## 二、Python CLI的实现方式

Python提供了多种实现CLI的方式，从最基础的原生方法到功能强大的第三方库：

| 实现方式 | 难度 | 功能 | 适用场景 |
|----------|------|------|----------|
| `sys.argv` | 极低 | 基础 | 简单脚本、快速原型 |
| `argparse` | 中 | 丰富 | 标准库、无需额外依赖 |
| `click` | 中 | 非常丰富 | 复杂CLI、企业级工具 |
| `typer` | 低 | 非常丰富 | 现代Python、基于类型提示 |
| `fire` | 极低 | 自动生成 | 快速将Python代码转为CLI |

## 三、主流CLI库详解与示例

### 1. `sys.argv`：最基础的方法

`sys.argv`是Python内置的列表，包含了命令行传入的所有参数。

**示例：简单的加法器**

```python
import sys

def main():
    # sys.argv[0] 是脚本本身的名称
    if len(sys.argv) != 3:
        print("用法: python add.py <数字1> <数字2>")
        sys.exit(1)
    
    try:
        num1 = float(sys.argv[1])
        num2 = float(sys.argv[2])
        print(f"结果: {num1 + num2}")
    except ValueError:
        print("错误: 请输入有效的数字")
        sys.exit(1)

if __name__ == "__main__":
    main()
```

**运行方式**：

```bash
python add.py 3 5
# 输出: 结果: 8.0
```

**缺点**：

- 没有自动生成帮助文档
- 没有参数类型检查
- 不支持可选参数和标志
- 不支持子命令

### 2. `argparse`：Python标准库

`argparse`是Python标准库中推荐的CLI解析器，功能强大且无需安装额外依赖。

**示例：功能完善的文件处理工具**

```python
import argparse
import os

def main():
    # 创建解析器
    parser = argparse.ArgumentParser(
        description="文件处理工具 - 统计文件行数、单词数和字符数",
        epilog="示例: python file_tool.py -lwc example.txt"
    )
    
    # 添加位置参数
    parser.add_argument("filename", help="要处理的文件路径")
    
    # 添加可选参数（标志）
    parser.add_argument("-l", "--lines", action="store_true", help="统计行数")
    parser.add_argument("-w", "--words", action="store_true", help="统计单词数")
    parser.add_argument("-c", "--chars", action="store_true", help="统计字符数")
    
    # 添加带值的可选参数
    parser.add_argument("-o", "--output", help="将结果保存到指定文件")
    
    # 解析参数
    args = parser.parse_args()
    
    # 检查文件是否存在
    if not os.path.exists(args.filename):
        parser.error(f"文件 '{args.filename}' 不存在")
    
    # 读取文件内容
    with open(args.filename, "r", encoding="utf-8") as f:
        content = f.read()
    
    # 计算统计数据
    lines = len(content.splitlines())
    words = len(content.split())
    chars = len(content)
    
    # 准备输出结果
    result = []
    if args.lines:
        result.append(f"行数: {lines}")
    if args.words:
        result.append(f"单词数: {words}")
    if args.chars:
        result.append(f"字符数: {chars}")
    
    # 如果没有指定任何统计选项，默认显示所有
    if not result:
        result = [f"行数: {lines}", f"单词数: {words}", f"字符数: {chars}"]
    
    output_text = "\n".join(result)
    
    # 输出结果
    if args.output:
        with open(args.output, "w", encoding="utf-8") as f:
            f.write(output_text)
        print(f"结果已保存到 {args.output}")
    else:
        print(output_text)

if __name__ == "__main__":
    main()
```

**运行方式**：

```bash
# 查看帮助
python file_tool.py -h

# 统计所有信息
python file_tool.py example.txt

# 只统计行数和单词数
python file_tool.py -lw example.txt

# 将结果保存到文件
python file_tool.py -c example.txt -o result.txt
```

### 3. `click`：最流行的第三方CLI库

`click`是由Pallets团队（Flask的开发者）开发的CLI库，以其简洁的装饰器语法和强大的功能著称。

**安装**：

```bash
pip install click
```

**示例：待办事项管理工具**

```python
import click
import json
import os

TODO_FILE = "todos.json"

def load_todos():
    if not os.path.exists(TODO_FILE):
        return []
    with open(TODO_FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def save_todos(todos):
    with open(TODO_FILE, "w", encoding="utf-8") as f:
        json.dump(todos, f, indent=2)

@click.group()
def cli():
    """待办事项管理工具"""
    pass

@cli.command()
@click.argument("task")
def add(task):
    """添加新的待办事项"""
    todos = load_todos()
    todos.append({"task": task, "done": False})
    save_todos(todos)
    click.echo(f"已添加待办事项: {task}")

@cli.command()
def list():
    """列出所有待办事项"""
    todos = load_todos()
    if not todos:
        click.echo("没有待办事项")
        return
    
    for i, todo in enumerate(todos, 1):
        status = "✓" if todo["done"] else "✗"
        click.echo(f"{i}. [{status}] {todo['task']}")

@cli.command()
@click.argument("index", type=int)
def done(index):
    """将指定的待办事项标记为已完成"""
    todos = load_todos()
    if index < 1 or index > len(todos):
        click.echo(f"错误: 无效的索引 {index}")
        return
    
    todos[index-1]["done"] = True
    save_todos(todos)
    click.echo(f"已将待办事项 {index} 标记为已完成")

@cli.command()
@click.argument("index", type=int)
def delete(index):
    """删除指定的待办事项"""
    todos = load_todos()
    if index < 1 or index > len(todos):
        click.echo(f"错误: 无效的索引 {index}")
        return
    
    deleted = todos.pop(index-1)
    save_todos(todos)
    click.echo(f"已删除待办事项: {deleted['task']}")

if __name__ == "__main__":
    cli()
```

**运行方式**：

```bash
# 查看帮助
python todo.py --help

# 添加待办事项
python todo.py add "学习Python CLI"

# 列出所有待办事项
python todo.py list

# 标记为已完成
python todo.py done 1

# 删除待办事项
python todo.py delete 1
```

### 4. `typer`：现代Python CLI库

`typer`是基于`click`开发的现代CLI库，它利用Python 3.6+的类型提示功能，让CLI开发变得更加简单和直观。

**安装**：

```bash
pip install typer[all]
```

**示例：与上面相同的待办事项管理工具**

```python
import typer
import json
import os
from typing import Optional

TODO_FILE = "todos.json"

app = typer.Typer(help="待办事项管理工具")

def load_todos():

def list():

    if not todos:

    for i, todo in enumerate(todos, 1):
        status = "✓" if todo["done"] else "✗"

        typer.echo(f"错误: 无效的索引 {index}")
        raise typer.Exit(code=1)
    
    todos[index-1]["done"] = True
    save_todos(todos)
    typer.echo(f"已将待办事项 {index} 标记为已完成")

@app.command()

if __name__ == "__main__":

```

**`typer`的优势**：

- 基于类型提示，自动推断参数类型
- 自动生成美观的帮助文档
- 完全兼容`click`的所有功能
- 支持自动补全
- 代码更加简洁易读

## 四、Python CLI高级功能

### 1. 子命令

子命令是复杂CLI工具的核心功能，它允许你将不同的功能组织成独立的命令。

**`typer`子命令示例**：

```python
import typer

app = typer.Typer()
user_app = typer.Typer()
app.add_typer(user_app, name="user", help="用户管理命令")
product_app = typer.Typer()
app.add_typer(product_app, name="product", help="产品管理命令")

@user_app.command()
def create(name: str, email: str):
    """创建新用户"""
    typer.echo(f"创建用户: {name} <{email}>")

@user_app.command()
def delete(user_id: int):
    """删除用户"""
    typer.echo(f"删除用户: {user_id}")

@product_app.command()
def list():
    """列出所有产品"""
    typer.echo("产品列表: 产品1, 产品2, 产品3")

if __name__ == "__main__":
    app()
```

**运行方式**：

```bash
python cli.py user create "张三" zhangsan@example.com
python cli.py product list
```

### 2. 参数类型与验证

`typer`和`click`都支持丰富的参数类型和自定义验证。

**示例：参数验证**

```python
import typer
from typing_extensions import Annotated

def validate_age(age: int) -> int:
    if age < 18:
        raise typer.BadParameter("年龄必须大于等于18岁")
    return age

@app.command()
def register(
    name: str,
    age: Annotated[int, typer.Argument(callback=validate_age)],
    email: Annotated[str, typer.Option(prompt=True, help="用户邮箱")],
    password: Annotated[str, typer.Option(prompt=True, hide_input=True, confirmation_prompt=True)],
):
    """用户注册"""
    typer.echo(f"注册成功: {name}, {age}岁, {email}")
```

### 3. 自动补全

`typer`内置支持自动补全功能，可以极大提升用户体验。

**安装自动补全**：

```bash
# 为当前shell安装自动补全
python your_cli.py --install-completion

# 生成补全脚本
python your_cli.py --show-completion
```

### 4. 进度条与彩色输出

`typer`和`click`都提供了进度条和彩色输出功能，让CLI工具更加专业。

**示例：进度条**

```python
import typer
import time

@app.command()
def process(count: int = 100):
    """处理任务并显示进度条"""
    with typer.progressbar(range(count), label="处理中") as progress:
        for i in progress:
            time.sleep(0.01)
    typer.echo(typer.style("处理完成!", fg=typer.colors.GREEN, bold=True))
```

## 五、CLI工具打包与分发

### 使用`setuptools`打包

创建`setup.py`文件：

```python
from setuptools import setup, find_packages

setup(
    name="todo-cli",
    version="0.1.0",
    packages=find_packages(),
    install_requires=[
        "typer[all]>=0.9.0",
    ],
    entry_points={
        "console_scripts": [
            "todo = todo:app",
        ],
    },
    author="你的名字",
    description="一个简单的待办事项管理CLI工具",
    classifiers=[
        "Programming Language :: Python :: 3",
        "Programming Language :: Python :: 3.8",
        "Programming Language :: Python :: 3.9",
        "Programming Language :: Python :: 3.10",
    ],
)
```

**安装本地版本**：

```bash
pip install -e .
```

现在你可以直接使用`todo`命令：

```bash
todo add "学习打包CLI工具"
todo list
```

### 使用`PyInstaller`打包为可执行文件

`PyInstaller`可以将Python脚本打包为独立的可执行文件，无需用户安装Python环境。

**安装**：

```bash
pip install pyinstaller
```

**打包**：

```bash
pyinstaller --onefile --name todo todo.py
```

打包完成后，可执行文件会生成在`dist`目录中。

## 六、最佳实践

1. **遵循Unix哲学**：每个工具只做一件事，并把它做好
2. **提供清晰的帮助文档**：每个命令和参数都应该有详细的说明
3. **使用有意义的退出码**：0表示成功，非0表示失败
4. **支持管道和重定向**：输出应该是机器可读的
5. **处理错误优雅**：提供清晰的错误信息，而不是堆栈跟踪
6. **使用配置文件**：对于复杂的工具，支持从配置文件读取参数
7. **添加版本信息**：提供`--version`选项
8. **编写测试**：CLI工具也需要单元测试和集成测试

## 七、总结

Python CLI是构建开发者工具和自动化脚本的最佳选择。对于大多数项目，我推荐使用：

- **`typer`**：现代、简洁、基于类型提示，是新的行业标准
- **`argparse`**：标准库，无需额外依赖，适合简单工具
- **`click`**：功能强大，生态丰富，适合复杂的企业级工具

通过掌握这些技术，你可以快速构建出专业、易用、可维护的CLI工具，极大提升你的开发效率。
