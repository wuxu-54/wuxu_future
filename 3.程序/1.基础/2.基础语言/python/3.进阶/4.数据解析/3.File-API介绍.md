# Python 文件操作 API 介绍

Python 提供了丰富的文件操作 API，主要通过内置的 `open()` 函数和文件对象来实现。

## open() 函数

```python
open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None, closefd=True, opener=None)
```

### 模式参数 (mode)

| 模式 | 描述 | 说明 |
|------|------|------|
| `'r'` | 只读（默认） | 文件必须存在 |
| `'w'` | 只写 | 覆盖现有文件，不存在则创建 |
| `'a'` | 追加 | 在文件末尾追加，不存在则创建 |
| `'x'` | 独占创建 | 文件已存在则失败 |
| `'b'` | 二进制模式 | 与上述模式组合使用 |
| `'t'` | 文本模式（默认） | 与上述模式组合使用 |
| `'+'` | 读写模式 | 与上述模式组合使用 |

**常用模式组合：**
- `'r'` 或 `'rt'`: 文本只读
- `'rb'`: 二进制只读  
- `'w'` 或 `'wt'`: 文本只写
- `'wb'`: 二进制只写
- `'a'` 或 `'at'`: 文本追加
- `'ab'`: 二进制追加
- `'r+'`: 文本读写
- `'rb+'`: 二进制读写

## 文件对象属性

| 属性 | 描述 |
|------|------|
| `name` | 文件名 |
| `mode` | 打开模式 |
| `closed` | 文件是否已关闭 |
| `encoding` | 文件编码（文本模式） |
| `newlines` | 换行符类型（文本模式） |

## 文件对象方法

### 读取方法

| 方法 | 返回值 | 描述 |
|------|--------|------|
| `read([size])` | str/bytes | 读取指定字节数，不指定则读取全部 |
| `readline([size])` | str/bytes | 读取一行 |
| `readlines([hint])` | list | 读取所有行，返回列表 |
| `__next__()` | str/bytes | 迭代器协议，逐行读取 |

### 写入方法

| 方法 | 参数 | 描述 |
|------|------|------|
| `write(string)` | str/bytes | 写入字符串或字节 |
| `writelines(lines)` | iterable | 写入多行（不自动添加换行符） |
| `truncate([size])` | int | 截断文件到指定大小 |

### 文件指针操作

| 方法 | 返回值 | 描述 |
|------|--------|------|
| `seek(offset[, whence])` | None | 移动文件指针 |
| `tell()` | int | 获取当前文件指针位置 |
| `flush()` | None | 强制刷新缓冲区 |

### 其他方法

| 方法 | 返回值 | 描述 |
|------|--------|------|
| `close()` | None | 关闭文件 |
| `fileno()` | int | 获取文件描述符 |
| `isatty()` | bool | 是否为终端设备 |
| `readable()` | bool | 是否可读 |
| `writable()` | bool | 是否可写 |
| `seekable()` | bool | 是否可seek |

## 上下文管理器 (with 语句)

推荐使用 `with` 语句自动管理文件资源：

```python
# 自动关闭文件，即使发生异常
with open('file.txt', 'r') as f:
    content = f.read()
    # 文件在此处自动关闭
```

## 常用操作示例

### 1. 基本文件读写

```python
# 读取文本文件
with open('example.txt', 'r', encoding='utf-8') as f:
    content = f.read()

# 写入文本文件
with open('output.txt', 'w', encoding='utf-8') as f:
    f.write('Hello, World!')

# 追加内容
with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('New log entry\n')
```

### 2. 逐行处理大文件

```python
# 内存友好的方式处理大文件
with open('large_file.txt', 'r', encoding='utf-8') as f:
    for line in f:
        process_line(line.strip())
```

### 3. 二进制文件操作

```python
# 读取二进制文件（如图片）
with open('image.jpg', 'rb') as f:
    data = f.read()

# 写入二进制数据
with open('copy.jpg', 'wb') as f:
    f.write(data)
```

### 4. 文件指针操作

```python
with open('file.txt', 'r+') as f:
    # 读取前10个字符
    first_part = f.read(10)
    
    # 移动到文件开头
    f.seek(0)
    
    # 获取当前位置
    pos = f.tell()
    
    # 移动到文件末尾
    f.seek(0, 2)  # 0:开头, 1:当前位置, 2:末尾
```

### 5. 错误处理

```python
try:
    with open('nonexistent.txt', 'r') as f:
        content = f.read()
except FileNotFoundError:
    print("文件不存在")
except PermissionError:
    print("没有权限访问文件")
except UnicodeDecodeError:
    print("文件编码错误")
```

## 高级文件操作模块

除了内置的文件操作，Python 还提供了其他有用的文件相关模块：

### os 模块
```python
import os

# 文件路径操作
os.path.exists('file.txt')
os.path.getsize('file.txt')
os.path.getmtime('file.txt')  # 最后修改时间

# 文件系统操作
os.remove('file.txt')  # 删除文件
os.rename('old.txt', 'new.txt')  # 重命名
```

### pathlib 模块 (Python 3.4+)
```python
from pathlib import Path

# 面向对象的路径操作
p = Path('file.txt')
if p.exists():
    content = p.read_text(encoding='utf-8')
    size = p.stat().st_size
```

### tempfile 模块
```python
import tempfile

# 创建临时文件
with tempfile.NamedTemporaryFile(mode='w', delete=False) as f:
    f.write('temporary data')
    temp_name = f.name

# 使用后记得清理
os.unlink(temp_name)
```

## 性能优化建议

1. **使用缓冲**: 默认缓冲通常足够，大文件可调整 `buffering` 参数
2. **批量读写**: 避免频繁的小量读写操作
3. **适当编码**: 明确指定文件编码避免猜测
4. **资源管理**: 始终使用 `with` 语句确保文件正确关闭
5. **异常处理**: 处理常见的文件操作异常

## 常见陷阱

1. **忘记关闭文件**: 导致资源泄漏
2. **编码问题**: 不指定编码可能导致跨平台问题
3. **路径分隔符**: 使用 `os.path.join()` 或 `pathlib` 处理路径
4. **权限问题**: 确保有足够的文件访问权限
5. **大文件内存**: 避免一次性读取超大文件到内存

Python 的文件操作 API 设计简洁而强大，合理使用这些功能可以高效地处理各种文件操作需求。
