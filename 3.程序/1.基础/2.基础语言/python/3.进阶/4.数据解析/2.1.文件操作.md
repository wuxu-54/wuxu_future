# Python文件操作详解

Python提供了强大且简洁的文件操作能力，是处理数据、配置文件、日志等任务的基础。文件操作主要分为**内置函数基础操作**和**os/shutil模块高级操作**两大类。

## 一、文件操作基础：打开与关闭

### 1. 核心函数：`open()`

`open()`是Python内置的文件打开函数，返回一个**文件对象**（也叫文件句柄）。

**基本语法**：

```python
file_object = open(file_path, mode='r', encoding=None, buffering=None, errors=None, newline=None, closefd=True, opener=None)
```

**关键参数**：

- `file_path`：文件路径（相对路径或绝对路径）
- `mode`：文件打开模式（默认`'r'`只读）
- `encoding`：文件编码（推荐使用`'utf-8'`）
- `errors`：编码错误处理方式（如`'ignore'`忽略错误）

### 2. 必须关闭文件：`close()`

文件打开后会占用系统资源，操作完成后**必须关闭**。

```python
# 基础方式（不推荐，容易忘记关闭）
f = open('test.txt', 'r', encoding='utf-8')
content = f.read()
f.close()  # 关键步骤
```

### 3. 推荐方式：上下文管理器`with`语句

`with`语句会在代码块执行完毕后**自动关闭文件**，即使发生异常也能保证文件正确关闭。

```python
# 最佳实践
with open('test.txt', 'r', encoding='utf-8') as f:
    content = f.read()
# 离开with块后，文件自动关闭
```

## 二、文件打开模式详解

`mode`参数决定了文件的打开方式，由多个字符组合而成：

| 模式 | 含义 | 特点 | 文件不存在时 | 文件存在时 |
|------|------|------|--------------|------------|
| `'r'` | 只读模式 | 只能读取，不能写入 | 抛出`FileNotFoundError` | 正常打开，指针在开头 |
| `'w'` | 只写模式 | 只能写入，不能读取 | 创建新文件 | **清空原有内容**，指针在开头 |
| `'a'` | 追加模式 | 只能在末尾写入 | 创建新文件 | 保留原有内容，指针在末尾 |
| `'r+'` | 读写模式 | 可读可写 | 抛出`FileNotFoundError` | 正常打开，指针在开头 |
| `'w+'` | 读写模式 | 可读可写 | 创建新文件 | **清空原有内容**，指针在开头 |
| `'a+'` | 读写模式 | 可读可写 | 创建新文件 | 保留原有内容，指针在末尾 |
| `'b'` | 二进制模式 | 与上述模式组合使用（如`'rb'`, `'wb'`） | - | 以字节流方式处理，不进行编码转换 |
| `'t'` | 文本模式 | 默认模式，与上述模式组合使用（如`'rt'`） | - | 以字符串方式处理，自动进行编码转换 |

**重要提示**：

- `'w'`和`'w+'`模式会**永久删除**文件原有内容，使用时务必小心
- 二进制模式用于处理非文本文件（图片、视频、音频、exe等）
- 文本模式会自动处理换行符（Windows的`\r\n`和Unix的`\n`）

## 三、读取文件内容

### 1. 一次性读取全部内容：`read()`

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    # 读取整个文件内容为一个字符串
    content = f.read()
    print(content)
    
    # 读取指定字节数（文本模式下是字符数）
    f.seek(0)  # 移动文件指针到开头
    partial_content = f.read(10)  # 读取前10个字符
    print(partial_content)
```

### 2. 逐行读取：`readline()`

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    # 读取第一行
    line1 = f.readline()
    print(line1, end='')  # end=''避免重复换行
    
    # 读取第二行
    line2 = f.readline()
    print(line2, end='')
```

### 3. 读取所有行到列表：`readlines()`

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    # 所有行组成的列表，每个元素是一行字符串（包含换行符）
    lines = f.readlines()
    print(f"共有{len(lines)}行")
    
    for line in lines:
        print(line.strip())  # strip()去除首尾空白字符和换行符
```

### 4. 迭代读取（推荐大文件使用）

对于大文件（GB级别），一次性读取会占用大量内存，推荐使用迭代方式逐行处理：

```python
with open('large_file.txt', 'r', encoding='utf-8') as f:
    for line in f:  # 文件对象本身就是可迭代对象
        process_line(line.strip())  # 处理每一行
```

## 四、写入文件内容

### 1. 写入字符串：`write()`

```python
# 覆盖写入
with open('output.txt', 'w', encoding='utf-8') as f:
    f.write("第一行内容\n")
    f.write("第二行内容\n")
    f.write("第三行内容")

# 追加写入
with open('output.txt', 'a', encoding='utf-8') as f:
    f.write("\n第四行内容（追加）")
```

### 2. 写入字符串列表：`writelines()`

```python
lines = ["第一行\n", "第二行\n", "第三行\n"]

with open('output.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)  # 不会自动添加换行符，需要手动在字符串末尾加'\n'
```

**注意**：`writelines()`只是将列表中的字符串依次写入，不会自动添加换行符。

## 五、文件指针操作

文件指针标记了当前读写的位置，类似于文本编辑器中的光标。

### 1. 获取当前指针位置：`tell()`

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    print(f.tell())  # 初始位置0
    f.read(5)
    print(f.tell())  # 读取5个字符后，指针位置5
```

### 2. 移动指针位置：`seek()`

```python
with open('test.txt', 'r', encoding='utf-8') as f:
    # 移动到文件开头
    f.seek(0)
    
    # 从当前位置向后移动10个字节
    f.seek(10, 1)  # 第二个参数：0=开头，1=当前位置，2=文件末尾
    
    # 移动到文件末尾
    f.seek(0, 2)
```

**注意**：在文本模式下，`seek()`的偏移量只能是0或`tell()`返回的值，否则会出现错误。二进制模式下可以任意偏移。

## 六、二进制文件操作

处理图片、视频、音频等非文本文件时，必须使用二进制模式（`'b'`）。

```python
# 复制图片文件
with open('input.jpg', 'rb') as src_file:
    with open('output.jpg', 'wb') as dest_file:
        # 逐块读取，避免大文件占用过多内存
        chunk_size = 1024 * 1024  # 1MB
        while True:
            chunk = src_file.read(chunk_size)
            if not chunk:  # 读取完毕
                break
            dest_file.write(chunk)
```

## 七、常见错误处理

文件操作容易出现各种异常，建议使用`try-except`进行错误处理：

```python
file_path = 'test.txt'

try:
    with open(file_path, 'r', encoding='utf-8') as f:
        content = f.read()
except FileNotFoundError:
    print(f"错误：文件'{file_path}'不存在")
except PermissionError:
    print(f"错误：没有权限读取文件'{file_path}'")
except UnicodeDecodeError:
    print(f"错误：文件'{file_path}'编码不是utf-8")
except Exception as e:
    print(f"未知错误：{e}")
else:
    print("文件读取成功")
    print(content)
```

## 八、os模块：文件系统操作

`os`模块提供了与操作系统交互的功能，用于处理文件和目录。

### 1. 路径操作

```python
import os

# 获取当前工作目录
current_dir = os.getcwd()
print(f"当前工作目录：{current_dir}")

# 改变当前工作目录
os.chdir('/path/to/directory')

# 拼接路径（跨平台兼容）
file_path = os.path.join('folder', 'subfolder', 'file.txt')
print(f"拼接后的路径：{file_path}")

# 获取绝对路径
abs_path = os.path.abspath('test.txt')
print(f"绝对路径：{abs_path}")

# 分离文件名和扩展名
file_name, file_ext = os.path.splitext('test.txt')
print(f"文件名：{file_name}，扩展名：{file_ext}")

# 分离目录和文件名
dir_name, base_name = os.path.split('/path/to/test.txt')
print(f"目录：{dir_name}，文件名：{base_name}")
```

### 2. 文件和目录操作

```python
import os

# 检查路径是否存在
if os.path.exists('test.txt'):
    print("文件存在")

# 检查是否是文件
if os.path.isfile('test.txt'):
    print("这是一个文件")

# 检查是否是目录
if os.path.isdir('folder'):
    print("这是一个目录")

# 创建目录
os.mkdir('new_folder')  # 创建单个目录
os.makedirs('parent/child/grandchild')  # 递归创建多级目录

# 删除文件
os.remove('test.txt')

# 删除空目录
os.rmdir('empty_folder')

# 重命名文件或目录
os.rename('old_name.txt', 'new_name.txt')

# 列出目录内容
files = os.listdir('.')  # 列出当前目录下的所有文件和目录
for file in files:
    print(file)
```

## 九、shutil模块：高级文件操作

`shutil`模块提供了更高级的文件操作功能，如复制、移动、删除非空目录等。

```python
import shutil

# 复制文件
shutil.copy('source.txt', 'destination.txt')
shutil.copy2('source.txt', 'destination.txt')  # 保留元数据（创建时间、修改时间等）

# 复制目录
shutil.copytree('source_dir', 'destination_dir')

# 移动文件或目录
shutil.move('source.txt', 'destination.txt')

# 删除非空目录
shutil.rmtree('non_empty_dir')  # 谨慎使用！会永久删除目录及其所有内容
```

## 十、最佳实践和注意事项

1. **始终使用`with`语句**：自动管理文件资源，避免资源泄漏
2. **明确指定编码**：使用`encoding='utf-8'`确保跨平台兼容性
3. **大文件分块处理**：避免一次性读取整个大文件占用过多内存
4. **谨慎使用`'w'`模式**：会清空文件原有内容，建议先备份
5. **处理异常**：文件操作容易出错，使用`try-except`捕获异常
6. **使用os.path处理路径**：确保代码在不同操作系统上都能运行
7. **关闭文件前刷新缓冲区**：`f.flush()`可以强制将缓冲区内容写入磁盘

## 十一、Python 3.4+ 新特性：pathlib模块

`pathlib`是Python 3.4引入的面向对象的路径操作模块，比`os.path`更简洁直观：

```python
from pathlib import Path

# 创建Path对象
p = Path('test.txt')

# 读取文件内容
content = p.read_text(encoding='utf-8')

# 写入文件内容
p.write_text('Hello, World!', encoding='utf-8')

# 路径操作
print(p.exists())  # 检查是否存在
print(p.is_file())  # 检查是否是文件
print(p.absolute())  # 获取绝对路径
print(p.name)  # 文件名
print(p.suffix)  # 文件扩展名
print(p.parent)  # 父目录

# 遍历目录
for file in Path('.').glob('*.txt'):
    print(file)
```

## 总结

Python的文件操作体系非常完善：

- 基础操作使用`open()`函数和文件对象的方法
- 上下文管理器`with`是最佳实践
- `os`和`shutil`模块提供了文件系统操作能力
- `pathlib`模块提供了更现代的面向对象路径操作方式
