# Python glob 模块与 pathlib.glob 全面总结

`glob` 是 Python 中**文件路径模式匹配**的标准解决方案，它用简单的通配符语法快速查找符合规则的文件和目录，是批量处理文件的必备工具。Python 提供了两种主流写法：**传统函数式 `glob.glob()`** 和 **现代面向对象 `pathlib.Path.glob()`**，后者是 Python 3.4+ 官方推荐的最佳实践。

## 一、核心概念与通配符语法

两种写法共享完全相同的通配符规则，支持 4 种基本模式：

| 通配符 | 含义 | 示例 | 匹配结果 |
|--------|------|------|----------|
| `*` | 匹配任意长度任意字符（含空） | `*.py` | 所有 .py 文件 |
| `?` | 匹配任意单个字符 | `file?.txt` | file1.txt、fileA.txt |
| `[]` | 匹配括号内任意一个字符 | `file[0-9a-z].txt` | 数字/小写字母结尾的文件 |
| `**` | 递归匹配所有子目录 | `**/*.txt` | 当前及所有子目录下的 .txt 文件 |

**关键说明**：

- `**` 必须配合递归参数使用（`glob.glob()` 需 `recursive=True`，`pathlib` 有专用 `rglob()` 方法）
- 文件名本身包含通配符时，必须用 `glob.escape()` 转义
- Windows 不区分大小写，Unix/Linux/Mac 区分大小写
- 默认不匹配以 `.` 开头的隐藏文件

## 二、传统写法：glob 模块（函数式）

### 核心函数

```python
import glob

# 1. 返回匹配路径的字符串列表
txt_files = glob.glob('*.txt')  # ['test.txt', 'data.txt']

# 2. 返回迭代器（大文件场景节省内存）
for log_file in glob.iglob('logs/*.log'):
    process(log_file)

# 3. 转义特殊字符
special_file = 'file[123].txt'
matches = glob.glob(glob.escape(special_file))

# 4. 递归匹配
all_py_files = glob.glob('**/*.py', recursive=True)
```

### 特点

- 优点：简单直接，兼容所有 Python 版本
- 缺点：返回字符串，需手动拼接路径和转换类型；递归写法繁琐；不支持链式调用

## 三、现代写法：pathlib.Path.glob（面向对象）

### 核心方法

```python
from pathlib import Path

# 创建 Path 对象（代表某个目录）
current_dir = Path('.')
data_dir = Path('./data')

# 1. 基本匹配（返回 Path 对象生成器）
txt_files = list(current_dir.glob('*.txt'))  # [PosixPath('test.txt')]

# 2. 递归匹配（专用 rglob() 方法，推荐）
all_py_files = list(current_dir.rglob('*.py'))
# 等价于 current_dir.glob('**/*.py')

# 3. 直接操作匹配结果（最大优势）
for txt_file in current_dir.glob('*.txt'):
    content = txt_file.read_text(encoding='utf-8')  # 直接读取
    print(txt_file.name)  # 获取文件名
    print(txt_file.suffix)  # 获取扩展名
    print(txt_file.parent)  # 获取父目录

# 4. 链式调用
large_py_files = [
    f for f in current_dir.rglob('*.py')
    if f.stat().st_size > 1024  # 筛选大于 1KB 的文件
]
```

### 特点

- 优点：返回 Path 对象，可直接进行文件操作；递归写法简洁；支持链式调用；自动跨平台兼容；内存效率更高
- 缺点：仅支持 Python 3.4+

## 四、两种写法详细对比

| 特性 | `glob.glob()`（函数式） | `path.glob()`（面向对象） |
|------|--------------------------|---------------------------|
| 返回值类型 | 字符串列表 | Path 对象生成器 |
| 递归写法 | `glob('**/*.py', recursive=True)` | `path.rglob('*.py')` |
| 文件操作 | 需手动拼接路径和调用 os 模块 | 直接调用 Path 对象方法 |
| 链式调用 | 不支持 | 支持 |
| 跨平台兼容性 | 一般，需手动处理分隔符 | 完美，自动适配 |
| 内存效率 | 一次性返回所有结果 | 迭代器方式，按需生成 |
| 推荐程度 | 兼容旧版本时使用 | Python 3.4+ 优先使用 |

## 五、常见使用场景

1. **批量处理文件**

   ```python
   # 批量读取 CSV 并合并
   import pandas as pd
   df = pd.concat([pd.read_csv(f) for f in Path('data').glob('*.csv')])
   ```

2. **清理临时文件**

   ```python
   # 递归删除所有 .log 文件
   for log_file in Path('.').rglob('*.log'):
       log_file.unlink()
   ```

3. **按规则查找文件**

   ```python
   # 查找 2023 年 10 月的日志文件
   oct_logs = list(Path('logs').glob('2023-10-*.log'))
   ```

4. **筛选特定文件**

   ```python
   # 查找所有图片文件
   image_exts = ['*.jpg', '*.jpeg', '*.png', '*.gif']
   images = [f for ext in image_exts for f in Path('.').rglob(ext)]
   ```

## 六、最佳实践与避坑指南

1. **优先使用 pathlib.glob**：Python 3.4+ 项目一律推荐使用面向对象写法，代码更优雅易维护
2. **大文件用迭代器**：不要将生成器转成列表（`list()`），直接迭代处理以节省内存
3. **处理空结果**：匹配不到文件时返回空列表/生成器，使用前先检查

   ```python
   files = list(Path('.').glob('*.txt'))
   if not files:
       print("未找到任何 txt 文件")
   ```

4. **转义特殊字符**：文件名包含 `*`、`?`、`[`、`]` 时，必须用 `glob.escape()` 转义
5. **避免无限制递归**：在非常深的目录结构中慎用 `rglob()`，可能导致性能问题
6. **区分文件和目录**：匹配结果可能包含目录，如需仅文件，添加 `if f.is_file()` 过滤

## 七、总结

- `glob` 是 Python 文件路径匹配的标准工具，通配符语法简单强大
- 传统 `glob.glob()` 适合兼容旧版本 Python，现代 `pathlib.Path.glob()` 功能更全面
- `pathlib.glob()` 的最大优势是返回 Path 对象，可直接进行文件操作，无需额外调用 os 模块
- 递归匹配优先使用 `rglob()` 方法，代码更简洁直观

掌握这两种写法，你就能高效处理各种批量文件查找和处理任务。
