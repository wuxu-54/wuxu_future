## 获取字典最大值对应的key键

1. 使用`max()`函数

    ```python
    print(max(dic, key=dic.get)) # 必须要写key，这样对比的是value大小，否则默认按key大小对比选出最大的
    print(max(dic, key=lambda k: dic[k]))
    ```

2. 方式2：使用`Counter`,一行代码解决

    ```python
    """
    c(data)：统计 data 列表中每个元素出现的次数，返回一个类似字典的 Counter 对象。
    most_common(1)：返回出现次数最多的 前 1 个 元素列表(most_common 已经按频率降序排好)，每个元素是一个 (元素, 次数) 元组，例如 [('c', 4)]。
    [0]：取出列表中的第一个元组 → ('c', 4)。
    [0]：再取元组的第一个元素 → 'c'。
    """
    print(Counter(dic).most_common(1)[0][0]) 
    ```
