# mac-多jdk配置

1. 在".bash_profile"添加：

```txt
export JAVA_8_HOME=/Users/admin/Library/Java/JavaVirtualMachines/corretto-1.8.0_372/Contents/Home
export JAVA_11_HOME=/Users/admin/Library/Java/JavaVirtualMachines/corretto-11.0.19/Contents/Home
export JAVA_17_HOME=/usr/local/Cellar/openjdk@17/17.0.17
export JAVA_22_HOME=/Users/admin/Library/Java/JavaVirtualMachines/openjdk-22.0.1/Contents/Home

export JAVA_HOME=$JAVA_17_HOME && export PATH=$JAVA_HOME/bin:$PATH

#alias命令动态切换jdk版本
alias jdk8='export JAVA_HOME=$JAVA_8_HOME && export PATH=$JAVA_HOME/bin:$PATH && echo "已成功切换至 JDK 8"'
alias jdk11='export JAVA_HOME=$JAVA_11_HOME && export PATH=$JAVA_HOME/bin:$PATH && echo "已成功切换至 JDK 11"'
alias jdk17='export JAVA_HOME=$JAVA_17_HOME && export PATH=$JAVA_HOME/bin:$PATH && echo "已成功切换至 JDK 17"'
alias jdk22='export JAVA_HOME=$JAVA_22_HOME && export PATH=$JAVA_HOME/bin:$PATH && echo "已成功切换至 JDK 22"'
```

2. 执行：`source .bash_profile`

3. 使用命令：`jdk8`、`jdk11` 等直接可以切换jdk版本
