# 整除运算符

在编程语言中，`//` 通常表示**整除（地板除法，向下取整）** 运算符，但并非所有语言都支持这一用法。以下是明确支持 `//` 作为整除运算符的主流语言：

## 1. Python

`//` 是 Python 中专门的**地板除法**运算符，无论操作数是正数还是负数，结果都会向下取整（取不大于商的最大整数）。
>python 章节有写

示例：

```python
print(7 // 3)   # 输出 2（7÷3=2.333...，向下取整为2）
print(-7 // 3)  # 输出 -3（-7÷3≈-2.333...，向下取整为-3）
```

## 2. Ruby

Ruby 中 `//` 同样表示**整除（向下取整）**，行为与 Python 类似。  
示例：

```ruby
puts 7 // 3    # 输出 2
puts -7 // 3   # 输出 -3
```

## 3. Lua

Lua 中的 `//` 是整数除法运算符，结果会截断小数部分（对于正数等价于向下取整，对于负数则向零取整，与 Python 略有不同）。  
示例：

```lua
print(7 // 3)   -- 输出 2
print(-7 // 3)  -- 输出 -2（Lua 中向零取整）
```

## 注意：其他语言的 `//` 多为注释

多数语言中，`//` 是**单行注释符号**（而非运算符），例如：  

- C、C++、Java、C#、JavaScript、PHP、Go、Swift、Kotlin 等。  
这些语言中若要实现整除，通常使用普通除法 `/` 结合类型转换（如 `(int)(7/3)`）或取整函数（如 `Math.floor()`）。

总结：`//` 作为整除运算符主要存在于 Python、Ruby、Lua 等语言中，其他多数语言中 `//` 仅用于注释。
