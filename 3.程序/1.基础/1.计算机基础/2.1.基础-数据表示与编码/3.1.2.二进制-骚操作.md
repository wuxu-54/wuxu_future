# 骚操作

二进制位运算在编程中有着极高的效率和灵活性，掌握一些"骚操作"能大幅优化代码性能（尤其在底层开发、算法题中）。以下是整理的二进制操作技巧，涵盖基础、进阶及实战场景：

## 一、基础位运算特性

先明确6种基本位运算的核心特性（以32位整数为例）：

- **与（&）**：同1则1，否则0（可保留指定位）
- **或（|）**：有1则1，否则0（可设置指定位为1）
- **异或（^）**：不同则1，相同则0（可翻转指定位，a^a=0，a^0=a）
- **取反（~）**：0变1，1变0（等价于 `-x-1`，如 `~3 = -4`）
- **左移（<<）**：x << n = x * 2ⁿ（溢出截断）
- **右移（>>）**：x >> n = x // 2ⁿ（正数补0，负数补1，即算术右移）

## 二、数值判断技巧

1. **判断奇偶性**  
   原理：二进制末位为1则是奇数，0则是偶数。  

   ```c
   bool is_odd(int x) { return x & 1; }  // 1:奇数，0:偶数
   ```

2. **判断是否为2的幂**  
   原理：2的幂的二进制只有1个"1"（如8=1000），`x & (x-1)`会消除最后一个1，结果为0。  

   ```c
   bool is_power_of_two(int x) { 
       return x > 0 && (x & (x - 1)) == 0; 
   }
   ```

3. **判断是否为4的幂**  
   原理：4的幂是2的幂，且唯一的"1"在奇数位（如4=100，16=10000），与`0x55555555`（二进制奇数位为1）相与不为0。  

   ```c
   bool is_power_of_four(int x) { 
       return x > 0 && (x & (x - 1)) == 0 && (x & 0x55555555) != 0; 
   }
   ```

4. **判断两个数符号是否相同**  
   原理：符号位（最高位）相同则异或为0，否则为1。  

   ```c
   bool same_sign(int a, int b) { return (a ^ b) >= 0; }  // 非负则同号
   ```

## 三、数值计算技巧

1. **快速乘/除2ⁿ**  
   替代 `x * 2ⁿ` 或 `x / 2ⁿ`（无溢出时等价，效率更高）：  

   ```c
   int multiply_by_8(int x) { return x << 3; }   // x * 8
   int divide_by_2(int x) { return x >> 1; }     // x / 2（向下取整）
   ```

2. **求两个数的平均数（避免溢出）**  
   常规 `(a + b) / 2` 可能溢出，改用位运算：  

   ```c
   int average(int a, int b) { 
       return (a & b) + ((a ^ b) >> 1);  // 等价于 (a + b) / 2
   }
   ```

   原理：`a + b = (a & b) * 2 + (a ^ b)`，除以2后拆分即可。

3. **求绝对值（不借助判断）**  
   原理：符号位 `sign = x >> 31`（正数为0，负数为-1），负数时用 `~x + 1` 取反加1（补码）：  

   ```c
   int abs(int x) {
       int sign = x >> 31;
       return (x ^ sign) - sign;  // 正数：x^0 - 0 = x；负数：x^(-1) - (-1) = ~x + 1
   }
   ```

4. **快速计算模2ⁿ**  
   当除数是2的幂时，`x % 2ⁿ = x & (2ⁿ - 1)`（如模8等价于 `x & 7`）：  

   ```c
   int mod_8(int x) { return x & 7; }  // x % 8
   ```

5. **位运算实现加法**  
   用异或算无进位和，与运算+左移1位算进位，循环直到无进位：  

   ```c
   int add(int a, int b) {
       while (b != 0) {
           int carry = (a & b) << 1;  // 计算进位
           a ^= b;                    // 计算无进位和
           b = carry;                 // 迭代处理进位
       }
       return a;
   }
   ```

## 四、位操作技巧

1. **交换两个数（无临时变量）**  
   利用异或的自反性（`a ^ a = 0`，`a ^ 0 = a`）：  

   ```c
   void swap(int *a, int *b) {
       *a ^= *b;  // a = a ^ b
       *b ^= *a;  // b = b ^ (a ^ b) = a
       *a ^= *b;  // a = (a ^ b) ^ a = b
   }
   ```

2. **统计二进制中1的个数（汉明重量）**  
   - **Brian Kernighan算法**：每次消除最后一个1，循环次数=1的个数：  

     ```c
     int count_ones(int x) {
         int cnt = 0;
         while (x) {
             x &= x - 1;  // 消除最后一个1（如1010 & 1001 = 1000）
             cnt++;
         }
         return cnt;
     }
     ```

   - **查表法**：预存0~255的1的个数，按字节拆分计算（适合高频场景）。

3. **将第n位设置为1**  
   用 `1 << n` 生成掩码，再与原数或运算：  

   ```c
   int set_bit(int x, int n) { return x | (1 << n); }  // 第n位（0开始）设为1
   ```

4. **将第n位清零**  
   用 `~(1 << n)` 生成掩码，再与原数与运算：  

   ```c
   int clear_bit(int x, int n) { return x & ~(1 << n); }  // 第n位清0
   ```

5. **翻转第n位（0变1，1变0）**  
   用 `1 << n` 生成掩码，与原数异或：  

   ```c
   int flip_bit(int x, int n) { return x ^ (1 << n); }
   ```

6. **获取第n位的值**  
   右移n位后与1：  

   ```c
   int get_bit(int x, int n) { return (x >> n) & 1; }  // 0或1
   ```

7. **反转二进制位（如32位整数）**  
   逐步交换高低位：  

   ```c
   uint32_t reverse_bits(uint32_t x) {
       x = (x << 16) | (x >> 16);                 // 高低16位交换
       x = ((x & 0xff00ff00) >> 8) | ((x & 0x00ff00ff) << 8);  // 每8位交换
       x = ((x & 0xf0f0f0f0) >> 4) | ((x & 0x0f0f0f0f) << 4);  // 每4位交换
       x = ((x & 0xcccccccc) >> 2) | ((x & 0x33333333) << 2);  // 每2位交换
       x = ((x & 0xaaaaaaaa) >> 1) | ((x & 0x55555555) << 1);  // 每1位交换
       return x;
   }
   ```

8. **提取二进制中最后一个1**  
   如 `x=1010`（10），结果为 `0010`（2）：  

   ```c
   int last_one(int x) { return x & -x; }  // 利用补码特性，-x = ~x + 1
   ```

9. **消除二进制中最后一个1及其右边的位**  
   如 `x=10110`（22），结果为 `10000`（16）：  

   ```c
   int clear_last_one(int x) { return x & (x + 1); }
   ```

## 五、实战场景技巧

1. **状态压缩（用二进制表示集合）**  
   例如用一个整数表示多个开关状态：  
   - `mask | (1 << i)`：开启第i个状态  
   - `mask & ~(1 << i)`：关闭第i个状态  
   - `mask & (1 << i)`：判断第i个状态是否开启  
   常用于DFS/BFS中的状态记录（如子集问题、N皇后的列/对角线标记）。

2. **求最大公约数（GCD，二进制优化版）**  
   比辗转相除法更快，利用偶数/奇数特性：  

   ```c
   int gcd(int a, int b) {
       if (a == 0) return b;
       if (b == 0) return a;
       // 移除所有因子2
       int a_zeros = __builtin_ctz(a);  // 末尾0的个数（GCC内置函数）
       int b_zeros = __builtin_ctz(b);
       a >>= a_zeros;
       b >>= b_zeros;
       while (a != b) {
           if (a > b) {
               a -= b;
               a >>= __builtin_ctz(a);  // 移除新产生的因子2
           } else {
               b -= a;
               b >>= __builtin_ctz(b);
           }
       }
       return a << min(a_zeros, b_zeros);  // 还原因子2
   }
   ```

3. **判断一个数是否为3的幂（不循环/递归）**  
   利用3的幂在二进制中无规律，但在特定范围内最大值是`3^19=1162261467`，它的约数只有3的幂：  

   ```c
   bool is_power_of_three(int n) {
       return n > 0 && 1162261467 % n == 0;
   }
   ```

4. **二进制枚举子集**  
   枚举一个数的所有子集（如`mask=101`的子集为`101,100,001,000`）：  

   ```c
   void enum_subsets(int mask) {
       int submask = mask;
       do {
           printf("%d ", submask);
           submask = (submask - 1) & mask;  // 下一个子集
       } while (submask != mask);  // 直到回到原mask（循环结束条件）
   }
   ```

## 总结

二进制技巧的核心是利用位运算的特性（快速、无分支），在算法优化、嵌入式开发、密码学等领域应用广泛。实际编程中，需注意数据类型的位数（32/64位）和符号位的影响，优先保证可读性，再考虑用位运算优化性能瓶颈。
