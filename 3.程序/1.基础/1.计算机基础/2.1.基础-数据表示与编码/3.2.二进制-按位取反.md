# 按位取反

按位取反（Bitwise NOT）是编程语言中一种基础的位运算，作用是对整数的**每一个二进制位进行反转**（0变1，1变0）。它的行为与整数的存储方式（原码、反码、补码）、位数（8位、32位、64位）以及符号性（有符号/无符号）密切相关，理解起来需要结合二进制表示的细节。以下从原理到应用进行全面解析。

## 一、按位取反的基本定义

- **运算符**：几乎所有编程语言（C++、Java、JavaScript、Go等）都使用 `~`（波浪号）作为按位取反运算符。
- **操作对象**：整数（二进制形式），对浮点数无效（会先转换为整数再操作，但结果无意义）。
- **核心逻辑**：将整数的二进制表示中每一位的 `0` 变为 `1`，`1` 变为 `0`（包括符号位，若为有符号整数）。

例如，8位二进制数 `00000101`（十进制5）按位取反后为 `11111010`，32位二进制数 `00000000 00000000 00000000 00000101` 取反后为 `11111111 11111111 11111111 11111010`。

## 二、二进制表示的前置知识

按位取反的结果依赖于整数的二进制存储方式，需先明确以下概念：

### 1. 整数的位数

计算机中整数以固定位数存储（如8位、16位、32位、64位），位数决定了二进制的长度。例如：

- `char` 通常为8位，`int` 通常为32位，`long long` 通常为64位。
- 位数不足时会在高位补0（无符号整数）或补符号位（有符号整数）。

### 2. 无符号整数 vs 有符号整数

- **无符号整数（unsigned）**：所有位均为数值位，范围是 `0 ~ 2^n - 1`（n为位数），无负数。
- **有符号整数（signed）**：最高位为符号位（0表示正数，1表示负数），其余为数值位。  
  计算机中**有符号整数用补码存储**（而非原码），这是理解取反结果的关键。

### 3. 原码、反码、补码（针对有符号整数）

- **原码**：符号位+数值的二进制（如+5的8位原码为 `00000101`，-5的8位原码为 `10000101`）。
- **反码**：正数反码=原码；负数反码=符号位不变，数值位取反（如-5的8位反码为 `11111010`）。
- **补码**：正数补码=原码；负数补码=反码+1（如-5的8位补码为 `11111011`）。  

**补码的作用**：统一正负整数的运算规则（减法可转化为加法），避免“正负零”问题（原码中+0和-0是两个不同值，补码中只有一个0）。

## 三、无符号整数的按位取反

无符号整数的所有位都是数值位，取反逻辑最简单：**每一位0变1、1变0，结果可直接通过公式计算**。

### 规律公式

若 `x` 是 `n` 位无符号整数，则：  
`~x = (2^n - 1) - x`  

（原理：`2^n - 1` 是 `n` 位全1的二进制数，减去 `x` 等价于对 `x` 的每一位取反）

### 示例（8位无符号整数）

8位无符号整数的范围是 `0 ~ 255`（`2^8 - 1 = 255`，二进制 `11111111`）。

| 原数 x（十进制） | x 的8位二进制 | ~x 的8位二进制 | ~x（十进制） | 验证公式：255 - x |
|------------------|---------------|----------------|--------------|-------------------|
| 0                | 00000000      | 11111111       | 255          | 255 - 0 = 255     |
| 5                | 00000101      | 11111010       | 250          | 255 - 5 = 250     |
| 100              | 01100100      | 10011011       | 155          | 255 - 100 = 155   |
| 255              | 11111111      | 00000000       | 0            | 255 - 255 = 0     |

### 代码验证（C++）

```cpp
#include <iostream>
using namespace std;

int main() {
    unsigned char x = 5; // 8位无符号整数
    unsigned char res = ~x;
    cout << (int)res << endl; // 输出 250（符合 255 - 5 = 250）
    return 0;
}
```

## 四、有符号整数的按位取反

有符号整数的最高位是符号位（0为正，1为负），且以补码存储，取反结果需结合补码规则推导，核心规律是：**`~x = -x - 1`**。

### 推导过程（以32位有符号整数为例）

1. 正数 `x` 的补码 = 原码（符号位0，数值位为x的二进制）。  
2. 按位取反后，符号位变为1（负数），数值位全反转，得到的是“新数的补码”。  
3. 负数的补码转换为原码的规则是：补码取反（除符号位）+1（即补码的补码=原码）。  
4. 最终推导得出：`~x = -x - 1`（对所有有符号整数成立）。

### 示例1：正整数的取反

以 `x = 5`（32位有符号整数）为例：

- `x` 的补码（原码）：`00000000 00000000 00000000 00000101`  
- `~x` 的补码（每一位取反）：`11111111 11111111 11111111 11111010`  
- 这是一个负数的补码，转换为原码：  
  补码取反（除符号位）：`10000000 00000000 00000000 00000101`  
  加1：`10000000 00000000 00000000 00000110`（即 `-6`）  
- 符合公式：`~5 = -5 - 1 = -6`  

### 示例2：负整数的取反

以 `x = -3`（32位有符号整数）为例：

- `x` 的原码：`10000000 00000000 00000000 00000011`  
- `x` 的补码（反码+1）：`11111111 11111111 11111111 11111101`  
- `~x` 的补码（每一位取反）：`00000000 00000000 00000000 00000010`（正数，补码=原码）  
- 结果为 `2`，符合公式：`~(-3) = -(-3) - 1 = 3 - 1 = 2`  

### 特殊值验证

| 有符号整数 x | ~x 的结果 | 公式验证：~x = -x - 1 |
|--------------|-----------|-----------------------|
| 0            | -1        | -0 - 1 = -1           |
| 1            | -2        | -1 - 1 = -2           |
| -1           | 0         | -(-1) - 1 = 1 - 1 = 0 |
| 100          | -101      | -100 - 1 = -101       |
| -255         | 254       | -(-255) - 1 = 255 - 1 = 254 |

### 代码验证（Java）

Java 中 `int` 是32位有符号整数，直接验证公式：

```java
public class Main {
    public static void main(String[] args) {
        int x = 5;
        System.out.println(~x); // 输出 -6（符合 ~5 = -5-1）
        
        int y = -3;
        System.out.println(~y); // 输出 2（符合 ~(-3) = 3-1）
    }
}
```

## 五、不同编程语言中的差异

按位取反的核心逻辑一致，但不同语言对整数的位数和符号性处理略有差异：

| 语言       | 整数默认类型       | 特殊处理                                                                 |
|------------|--------------------|--------------------------------------------------------------------------|
| C++        | 可指定 signed/unsigned | `unsigned int` 按无符号规则，`int` 按有符号规则（依赖补码）。             |
| Java       | 所有整数均为有符号 | `byte`(8位)、`short`(16位)、`int`(32位)、`long`(64位)，均遵循 `~x = -x-1`。 |
| JavaScript | 所有数字均为64位浮点数 | 按位取反前会先将数字转换为32位有符号整数，结果再转回64位浮点数，遵循32位有符号规则。 |
| Python     | 无限精度整数       | 无固定位数，按位取反 `~x` 等价于 `-x - 1`（与有符号整数规则一致）。         |

### Python 示例

```python
x = 5
print(~x)  # 输出 -6（符合 ~x = -x-1）

y = -3
print(~y)  # 输出 2（符合 ~x = -x-1）
```

## 六、按位取反的应用场景

按位取反看似简单，实则在底层编程和性能优化中非常实用：

### 1. 掩码操作（清除特定位）

结合与运算（`&`）可清除整数的某些位。例如，清除32位整数的低8位（保留高24位）：

```cpp
int x = 0x12345678; // 二进制：00010010 00110100 01010110 01111000
int mask = ~0xFF;   // 0xFF是低8位全1，~0xFF是低8位全0，高24位全1 → 0xFFFFFF00
int res = x & mask; // 结果：0x12345600（低8位被清除）
```

### 2. 交换变量（不使用临时变量）

利用按位取反的特性，结合异或（`^`）可交换两个变量的值（无需临时变量）：

```cpp
void swap(int& a, int& b) {
    if (a != b) { // 避免自身交换出错
        a ^= b;   // a = a ^ b
        b ^= a;   // b = b ^ (a ^ b) = a
        a ^= b;   // a = (a ^ b) ^ a = b
    }
}
```

原理：`x ^ x = 0`，`x ^ 0 = x`，而 `x ^ ~x = -1`（全1）。

### 3. 判断奇偶（替代模运算）

偶数的二进制末位是0，奇数是1。按位取反后，末位会反转，结合与运算（`&1`）可判断奇偶：

```java
// 等价于 (x % 2 == 1)，但位运算更快
boolean isOdd(int x) {
    return (x & 1) == 1; 
    // 或用 ~x：(~x & 1) == 0 → 奇数的~x末位是0
}
```

### 4. 计算负数的绝对值（部分场景）

对负数 `x`（`x < 0`），`~x + 1` 等价于 `-x`（绝对值）：

```cpp
int abs(int x) {
    if (x < 0) {
        return ~x + 1; // 对负数x，~x + 1 = -x（绝对值）
    }
    return x;
}
```

原理：负数的补码是 `~原码数值位 + 1`，取反后加1即还原为原码数值位。

## 七、常见误区与注意事项

1. **混淆逻辑取反（`!`）与按位取反（`~`）**：  
   - `!x` 是对布尔值取反（非0值→false，0→true），结果是布尔值。  
   - `~x` 是对二进制位取反，结果是整数。  
   例如：`!5` 结果为 `false`（0），`~5` 结果为 `-6`。

2. **忽略整数位数的影响**：  
   同样的数在不同位数下取反结果不同。例如 `x=5`：  
   - 8位无符号：`~5 = 250`  
   - 32位有符号：`~5 = -6`  

3. **误解负数取反的结果**：  
   负数取反后不一定是正数（如 `-1` 取反是 `0`），需严格按公式 `~x = -x - 1` 计算。

4. **浮点数按位取反无意义**：  
   浮点数的二进制存储格式（如IEEE 754）与整数不同，对其按位取反会得到无意义的结果。

## 八、总结

按位取反（`~`）的核心是对二进制位逐位反转，其结果受整数的**位数**和**符号性**影响：

- 无符号整数：`~x = (2^n - 1) - x`（n为位数）。
- 有符号整数（补码存储）：`~x = -x - 1`（通用公式，无需关注二进制细节）。

理解按位取反需要掌握二进制补码规则，而实际应用中可直接利用公式快速计算结果。它在掩码操作、变量交换、性能优化等场景中具有不可替代的作用，是底层编程的基础工具。
