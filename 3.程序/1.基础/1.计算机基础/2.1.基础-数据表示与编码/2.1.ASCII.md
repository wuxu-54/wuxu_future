# ASCII 码对照表与多语言字符转换操作指南

ASCII（American Standard Code for Information Interchange，美国信息交换标准代码）是基于拉丁字母的字符编码，共定义 128 个字符（十进制 0-127），包括控制字符、可打印字符（数字、字母、符号等）。扩展 ASCII（128-255）无统一标准，不同系统可能存在差异，本文主要聚焦标准 ASCII（0-127）。

## 二、多语言字符与 ASCII 码的转换操作

不同语言对字符的存储方式不同（如 Java 的 `char` 是 16 位 UTF-16，C++ 的 `char` 是 8 位整数，JS 无单独 `char` 类型），但 ASCII 范围内（0-127）的转换逻辑一致，以下分场景详解。

### 2.1 Java 字符转换操作

Java 中 `char` 本质是 **16 位无符号整数**，ASCII 码（0-127）可直接通过强转与 `char` 互转，扩展 ASCII（128-255）需注意编码兼容（需用 `byte` 处理）。

#### 场景 1：单个字符 ↔ ASCII 码

```java
// 1. 字符转 ASCII 码（char → int）
char charA = 'A';
int asciiA = (int) charA; // 结果：65（对应大写A的ASCII）

char charSpace = ' ';
int asciiSpace = (int) charSpace; // 结果：32（空格的ASCII）

char charNewline = '\n';
int asciiNewline = (int) charNewline; // 结果：10（换行符的ASCII）

// 2. ASCII 码转字符（int → char）
int asciiB = 66;
char charB = (char) asciiB; // 结果：'B'

int ascii0 = 48;
char char0 = (char) ascii0; // 结果：'0'（注意：不是数字0，是字符'0'）
```

#### 场景 2：字符串 ↔ ASCII 码数组

```java
// 1. 字符串转 ASCII 码数组
String str = "Ab1!";
int[] asciiArr = new int[str.length()];
for (int i = 0; i < str.length(); i++) {
    asciiArr[i] = (int) str.charAt(i); // 逐个字符转ASCII
}
// 结果：asciiArr = [65, 98, 49, 33]（A→65，b→98，1→49，!→33）

// 2. ASCII 码数组转字符串
int[] asciiArr2 = {104, 101, 108, 108, 111}; // h(104)、e(101)、l(108)、l(108)、o(111)
StringBuilder sb = new StringBuilder();
for (int ascii : asciiArr2) {
    sb.append((char) ascii); // 逐个ASCII转字符拼接
}
String result = sb.toString(); // 结果："hello"
```

#### 场景 3：扩展 ASCII（128-255）处理

Java 中 `char` 是 16 位，扩展 ASCII 需用 `byte`（8 位）存储，避免乱码：

```java
// 扩展 ASCII 示例：十进制 169 对应版权符号 ©（需确认系统编码支持）
byte extAscii = (byte) 169; // 扩展ASCII用byte存储（signed byte 范围-128~127，169需强转）
// 转换为字符（需指定编码，如ISO-8859-1，该编码支持扩展ASCII）
String extChar = new String(new byte[]{extAscii}, StandardCharsets.ISO_8859_1);
System.out.println(extChar); // 输出：©（需终端支持该编码）
```

#### 注意事项

- Java 字符串默认编码是 **UTF-16**，ASCII 字符会被压缩为 1 个 `char`， Unicode 字符（如中文）占 2 个 `char`；
- 控制字符（如 `\r`、`\t`）转 ASCII 时，直接强转即可，无需额外处理。

### 2.2 C++ 字符转换操作

C++ 中 `char` 本质是 **8 位整数**（默认 `signed char`，范围-128~127；`unsigned char` 范围0~255），ASCII 转换依赖整数与字符的直接赋值。

#### 场景 1：单个字符 ↔ ASCII 码

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 字符转 ASCII 码（char → int）
    char charA = 'A';
    int asciiA = charA; // 结果：65（signed char 可直接赋值给int）
    
    char charTab = '\t'; // 水平制表符
    int asciiTab = (unsigned char) charTab; // 强制转为unsigned，避免负数（若char是signed）
    cout << asciiTab << endl; // 结果：9

    // 2. ASCII 码转字符（int → char）
    int asciiC = 67;
    char charC = (char) asciiC; // 结果：'C'
    
    int asciiDot = 46;
    char charDot = static_cast<char>(asciiDot); // 推荐用static_cast强转，更安全
    cout << charDot << endl; // 结果：'.'
    
    return 0;
}
```

#### 场景 2：字符串（`string`/字符数组） ↔ ASCII 码数组

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. string 转 ASCII 码数组
    string str = "Test123";
    int asciiArr[100] = {0}; // 初始化ASCII数组
    for (int i = 0; i < str.size(); i++) {
        asciiArr[i] = static_cast<unsigned char>(str[i]); // 用unsigned避免扩展ASCII为负数
    }
    // 结果：asciiArr = [84, 101, 115, 116, 49, 50, 51]（T→84，e→101，...）

    // 2. ASCII 码数组转 string
    int asciiArr2[] = {119, 111, 114, 108, 100}; // w(119)、o(111)、r(114)、l(108)、d(100)
    string result;
    int arrLen = sizeof(asciiArr2) / sizeof(asciiArr2[0]); // 计算数组长度
    for (int i = 0; i < arrLen; i++) {
        result += static_cast<char>(asciiArr2[i]); // 逐个ASCII转字符拼接
    }
    cout << result << endl; // 结果："world"

    return 0;
}
```

#### 场景 3：扩展 ASCII（128-255）处理

C++ 中 `signed char` 会将 128-255 视为负数，需用 `unsigned char` 处理：

```cpp
// 扩展 ASCII 172 对应乘号 ×（需系统编码支持）
unsigned char extChar = 172; // 用unsigned char存储，避免负数
cout << "扩展ASCII字符：" << extChar << endl; // 输出：×（需终端编码支持）

// 字符数组形式处理扩展ASCII
unsigned char extAsciiArr[] = {169, 174}; // ©（169）、®（174）
string extStr(reinterpret_cast<char*>(extAsciiArr), sizeof(extAsciiArr));
cout << extStr << endl; // 输出：©®
```

#### 注意事项

- C++ 字符串（`string`）本质是字符数组，末尾隐含 `\0`（字符串结束符，ASCII 0），遍历需避免越界；
- 不同编译器默认 `char` 是 `signed` 或 `unsigned`，处理扩展 ASCII 时建议显式指定 `unsigned char`。

### 2.3 JavaScript（JS）字符转换操作

JS 无单独 `char` 类型，字符以 **UTF-16 编码** 存储在字符串中，通过内置方法实现 ASCII 转换。

#### 场景 1：单个字符 ↔ ASCII 码

```javascript
// 1. 字符转 ASCII 码：用 charCodeAt(0)（返回字符的UTF-16编码，ASCII范围内与ASCII一致）
const charA = 'A';
const asciiA = charA.charCodeAt(0); // 结果：65

const charDel = '\x7F'; // 直接用十六进制表示DEL字符（ASCII 127）
const asciiDel = charDel.charCodeAt(0); // 结果：127

// 注：codePointAt(0) 与 charCodeAt(0) 在ASCII范围内效果一致，前者支持Unicode补充平面
const asciiB = 'B'.codePointAt(0); // 结果：66

// 2. ASCII 码转字符：用 String.fromCharCode()
const asciiSpace = 32;
const charSpace = String.fromCharCode(asciiSpace); // 结果：' '（空格）

const asciiExcl = 33;
const charExcl = String.fromCharCode(asciiExcl); // 结果：'!'
```

#### 场景 2：字符串 ↔ ASCII 码数组

```javascript
// 1. 字符串转 ASCII 码数组：split('') 分割为字符数组，再 map 转ASCII
const str = "Hi!";
const asciiArr = str.split('').map(char => char.charCodeAt(0));
console.log(asciiArr); // 结果：[72, 105, 33]（H→72，i→105，!→33）

// 2. ASCII 码数组转字符串：用 String.fromCharCode(...数组)（扩展运算符解构）
const asciiArr2 = [97, 98, 99]; // a(97)、b(98)、c(99)
const result = String.fromCharCode(...asciiArr2);
console.log(result); // 结果："abc"
```

#### 场景 3：扩展 ASCII（128-255）处理

JS 默认用 UTF-16 编码，扩展 ASCII 需通过 `TextEncoder` 转为 `Uint8Array`（8 位无符号数组）处理：

```javascript
// 扩展 ASCII 169（©）、174（®）
const extAsciiArr = [169, 174];
// 用 TextEncoder 转换为 UTF-8 字节（需指定编码为 windows-1252 或 ISO-8859-1，支持扩展ASCII）
const encoder = new TextEncoder('windows-1252'); // 或 'iso-8859-1'
const uint8Arr = encoder.encode(String.fromCharCode(...extAsciiArr));
// 再解码为可见字符（需确保终端支持该编码）
const decoder = new TextDecoder('windows-1252');
const extStr = decoder.decode(uint8Arr);
console.log(extStr); // 输出：©®
```

#### 注意事项

- JS 中 `\xhh` 表示十六进制 ASCII 字符（如 `\x41` 即 'A'），`\uhhhh` 表示 UTF-16 字符（如 `\u0041` 即 'A'）；
- 扩展 ASCII 无统一标准，不同浏览器/终端对 128-255 的解析可能不同，建议优先用 Unicode 字符（如 `©` 直接写为 `'©'`）。

## 三、通用注意事项

1. **ASCII 与扩展 ASCII 边界**：标准 ASCII 仅 0-127，扩展 ASCII（128-255）依赖系统/编码（如 ISO-8859-1、Windows-1252），跨平台需统一编码；
2. **控制字符的实际效果**：不同系统对换行符处理不同（Windows：`\r\n`，Linux：`\n`，Mac：`\r`），转换时需注意场景；
3. **编码兼容**：Java/C++/JS 均支持 UTF-8/UTF-16，ASCII 字符在所有编码中均兼容，无需额外处理；
4. **字符类型范围**：Java `char`（0-65535）、C++ `unsigned char`（0-255）、JS 字符串（UTF-16 编码），超出范围需特殊处理（如 Java 用 `int` 存 Unicode 码点）。
