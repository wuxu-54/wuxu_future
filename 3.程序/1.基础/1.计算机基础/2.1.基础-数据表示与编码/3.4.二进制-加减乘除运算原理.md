# 运算原理

二进制的加减乘除运算逻辑与十进制类似，但由于每位只能是0或1，规则更简单。下面分别详解计算过程，结合实例说明：

## 一、二进制加法（+）

**核心规则**：同十进制加法，从最低位（右）开始计算，遇“1+1”产生进位（向高位进1）。  
具体位运算：  

- 0 + 0 = 0（无进位）  
- 0 + 1 = 1（无进位）  
- 1 + 0 = 1（无进位）  
- 1 + 1 = 0（向高位进1）  

**示例**：计算 `1010（10） + 0111（7）`  
步骤：  

```txt
  1010  
+ 0111  
--------  
从右往左逐位算：  
第0位（最右）：0 + 1 = 1 → 本位1，无进位  
第1位：1 + 1 = 0 → 本位0，向高位进1  
第2位：0 + 1 + 进位1 = 0 → 本位0，向高位进1（因为1+1=0再进1）  
第3位：1 + 0 + 进位1 = 0 → 本位0，向高位进1  
最高位（进位）：1 → 本位1  
结果：10001（17），即10 + 7 = 17  
```

## 二、二进制减法（-）

**核心规则**：从最低位开始，遇“0-1”时需要向高位借位（借1当2，因为二进制是逢2进1）。  
具体位运算：  

- 0 - 0 = 0（无借位）  
- 1 - 0 = 1（无借位）  
- 1 - 1 = 0（无借位）  
- 0 - 1 = 1（需向高位借1，借位后本位为2-1=1，高位减1）  

**示例**：计算 `1010（10） - 0111（7）`  
步骤：  

```txt
  1010  
- 0111  
--------  
从右往左逐位算：  
第0位：0 - 1 → 不够减，向高位借1（借后本位为2），2-1=1 → 本位1  
第1位：被借位后原1变0，0 - 1 → 不够减，向高位借1（借后本位为2），2-1=1 → 本位1  
第2位：被借位后原0变-1（实际是高位借1后，这里变成2-1=1），1 - 1 = 0 → 本位0  
第3位：原1被借位后变0，0 - 0 = 0 → 本位0  
结果：0011（3），即10 - 7 = 3  
```

## 三、二进制乘法（×）

**核心规则**：与十进制乘法逻辑一致——用乘数的每一位分别乘被乘数，再将结果错位相加（乘数第n位的结果向左移n位）。  
具体步骤：  

1. 乘数的某一位是1，则结果为被乘数本身；是0，则结果为0；  
2. 按乘数的位数错位（左移）后，将所有中间结果相加。  

**示例**：计算 `101（5） × 11（3）`  
步骤：  

```txt
  101  
×  11  
-------  
第一步：用乘数第0位（1）乘被乘数 → 101（左移0位）  
第二步：用乘数第1位（1）乘被乘数 → 101（左移1位，即1010）  
第三步：将中间结果相加：  
  101  
+1010  
-------  
 1111（15），即5 × 3 = 15  
```

## 四、二进制除法（÷）

**核心规则**：与十进制除法类似，是乘法的逆运算——通过“试商”判断被除数中包含多少个除数，逐步减去除数并累加商。  
具体步骤：  

1. 从被除数最高位开始，取与除数位数相同的部分，判断是否大于等于除数；  
2. 若够除，商的对应位记1，减去除数得到余数；若不够除，商记0；  
3. 将被除数的下一位移到余数后，重复步骤2，直到被除数所有位处理完。  

**示例**：计算 `1111（15） ÷ 101（5）`  
步骤：  

```txt
除数：101（5），被除数：1111（15）  
第一步：取被除数前3位111，与101比较 → 111 ≥ 101，商第1位记1，余数：111 - 101 = 010  
第二步：将被除数第4位1移到余数后 → 0101，与101比较 → 0101 = 101，商第0位记1，余数：0101 - 101 = 000  
结果：商为11（3），余数0，即15 ÷ 5 = 3  
```

## 总结

二进制运算的本质是“逢2进1”（加法）和“借1当2”（减法），乘除则是加减的多次叠加。由于每位只有0和1，运算规则比十进制更简单，且非常适合计算机硬件实现（通过逻辑门电路直接处理位运算）。
