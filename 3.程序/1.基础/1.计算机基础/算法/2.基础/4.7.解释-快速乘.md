# 快速乘（Fast Multiplication）详解

## 一、快速乘的核心概念

快速乘是一种**高效计算两个整数乘积**的算法，核心思想是通过「二进制分解」将乘法转化为「左移（等价于乘2的幂）」和「加法」，从而将时间复杂度从朴素乘法的 **O(b)**（若用循环累加模拟）优化到 **O(log b)**（b 为其中一个乘数的绝对值）。

其核心价值在于：

1. **避免大整数直接乘法溢出**：当两个数较大（如超过32位/64位整数范围）时，直接相乘可能触发溢出，而快速乘通过分步加法+左移，可配合「边计算边取模」进一步控制中间结果范围。
2. **模拟乘法运算**：在某些场景下（如编程题明确禁止使用乘法运算符 `*`），可通过快速乘间接实现乘法。

## 二、快速乘的原理（二进制分解）

任何整数都可表示为二进制形式，例如 `b = 13` 的二进制是 `1101`，可分解为：  
`b = 13 = 8 + 4 + 0 + 1 = 2³ + 2² + 2⁰`  

因此，`a * b` 可转化为：  
`a * 13 = a*(2³ + 2² + 2⁰) = a<<3 + a<<2 + a<<0`（左移 `k` 位等价于乘 `2ᵏ`）  

快速乘的本质就是「遍历 `b` 的二进制每一位，若当前位为1，则将 `a` 左移对应位数后加入结果，最终累加得到乘积」。

## 三、快速乘的关键步骤（以计算 `a * b` 为例）

以迭代版快速乘为例，核心步骤如下：

1. **初始化结果**：`res = 0`（存储最终乘积，初始为0）。
2. **遍历 `b` 的二进制每一位**：循环判断 `b` 是否为0，直到 `b` 被右移至0：
   - 若 `b` 的当前最低位为1（`b & 1 == 1`），则将当前的 `a` 加入 `res`（因为当前 `a` 已左移至对应二进制位的权重）。
   - 将 `a` 左移1位（`a <<= 1`），等价于 `a *= 2`，对应二进制的下一位权重。
   - 将 `b` 右移1位（`b >>= 1`），等价于 `b // 2`，用于判断下一位是否为1。
3. **返回结果 `res`**。

## 四、边界情况处理

快速乘需处理「负数乘数」和「0乘数」，具体规则如下：

1. **乘数为0**：若 `a` 或 `b` 为0，直接返回0（无需后续计算）。
2. **负数乘数**：先记录结果的符号（若 `a` 和 `b` 异号，结果为负；同号为正），再将 `a` 和 `b` 转为绝对值计算，最后根据符号调整结果。

## 五、实例演示（以 `a=5，b=7` 为例）

`b=7` 的二进制为 `111`，分解为 `2² + 2¹ + 2⁰`，计算过程如下：

| 步骤 | b（二进制） | b&1（最低位） | a（当前值） | res（累加结果） | 操作（a左移/ b右移） |
|------|-------------|---------------|-------------|-----------------|----------------------|
| 初始 | 111（7）    | -             | 5           | 0               | -                    |
| 1    | 111         | 1（最低位为1） | 5           | 0 + 5 = 5       | a<<1→10，b>>1→11（3） |
| 2    | 11（3）     | 1（最低位为1） | 10          | 5 + 10 = 15     | a<<1→20，b>>1→1（1）  |
| 3    | 1（1）      | 1（最低位为1） | 20          | 15 + 20 = 35    | a<<1→40，b>>1→0（0）  |
| 结束 | 0           | -             | -           | 35（最终结果）  | 循环终止             |

最终 `5*7=35`，与预期一致。

## 六、常见实现方式（代码示例）

### 1. 基础迭代版（处理非负整数）

适用于 `a` 和 `b` 均为非负整数的场景：

```java
public int fastMultiply(int a, int b) {
    int res = 0;
    while (b > 0) {
        // 若b的最低位为1，累加当前a
        if ((b & 1) == 1) {
            res += a;
        }
        // a左移1位（a *= 2），b右移1位（b /= 2）
        a <<= 1;
        b >>= 1;
    }
    return res;
}
```

### 2. 支持负数的迭代版

通过「符号预处理」支持正负整数：

```java
public int fastMultiplyWithNegative(int a, int b) {
    // 步骤1：处理0的情况
    if (a == 0 || b == 0) {
        return 0;
    }
    // 步骤2：记录结果符号（异号为负，同号为正）
    boolean isNegative = (a < 0) ^ (b < 0);
    // 步骤3：转为绝对值计算
    long aAbs = Math.abs((long) a); // 用long避免绝对值溢出（如a=-2^31）
    long bAbs = Math.abs((long) b);
    long res = 0;
    
    while (bAbs > 0) {
        if ((bAbs & 1) == 1) {
            res += aAbs;
        }
        aAbs <<= 1; // aAbs *= 2
        bAbs >>= 1; // bAbs /= 2
    }
    // 步骤4：根据符号调整结果，转为int（需确保结果在int范围内）
    return isNegative ? (int) -res : (int) res;
}
```

### 3. 带取模的快速乘（解决大整数溢出）

当计算 `(a * b) mod mod` 时（如密码学、数论问题），可通过「边计算边取模」避免中间结果溢出，核心是利用模运算的性质：`(x + y) mod m = [(x mod m) + (y mod m)] mod m`。

代码实现：

```java
// 计算 (a * b) mod mod 的快速乘（a、b可为负数，mod为正整数）
public long fastMultiplyMod(long a, long b, long mod) {
    // 步骤1：处理负数（确保a、b在[0, mod)范围内）
    a = (a % mod + mod) % mod;
    b = (b % mod + mod) % mod;
    long res = 0;
    
    while (b > 0) {
        if ((b & 1) == 1) {
            res = (res + a) % mod; // 累加后立即取模
        }
        a = (a << 1) % mod; // a *= 2后取模（避免a过大）
        b >>= 1;
    }
    return res;
}
```

### 4. 递归版快速乘（理解思路，实际少用）

递归版逻辑与迭代一致，但需注意递归深度（若 `b` 为 `2^30`，递归深度为30，无栈溢出风险，但效率略低于迭代版）：

```java
public int fastMultiplyRecursive(int a, int b) {
    if (b == 0) return 0;
    // 若b为奇数：a*b = a + a*(b-1)；若为偶数：a*b = a*2*(b/2) = (a<<1)*(b>>1)
    return (b & 1) == 1 ? a + fastMultiplyRecursive(a << 1, b >> 1) : fastMultiplyRecursive(a << 1, b >> 1);
}
```

## 七、快速乘的应用场景

1. **大整数乘法防溢出**：如计算 `(1e18 * 1e18) mod 1e9+7`，直接相乘会溢出64位整数，需用带取模的快速乘。
2. **快速幂配合使用**：快速幂（计算 `a^b mod mod`）中，每次迭代的“乘当前结果”步骤，若 `a` 和结果较大，需用快速乘避免溢出（即「快速幂+快速乘」组合，合称“快速幂乘”）。
   - 示例：快速幂中计算 `res = res * a mod mod`，可替换为 `res = fastMultiplyMod(res, a, mod)`。
3. **禁止使用乘法运算符的场景**：如编程题要求“仅用 `+`、`-`、`<<`、`>>`、`&` 等运算符实现乘法”，快速乘是唯一可行方案（如 LeetCode 371. 两整数之和的变种问题）。

## 八、常见误区与注意事项

1. **负数绝对值溢出**：在32位整数中，`-2^31` 的绝对值是 `2^31`，超出 `int` 范围（`int` 最大值为 `2^31-1`），因此处理负数时需用 `long` 存储中间结果（如上述「支持负数的迭代版」中用 `long aAbs`）。
2. **左移的边界**：左移时需确保中间结果不超出存储类型范围（如 `int` 左移31位会溢出，需用 `long` 过渡）。
3. **取模的顺序**：带取模的快速乘中，**必须在每次累加和左移后立即取模**，否则中间结果仍可能溢出。

## 九、LeetCode 相关题目

- **371. 两整数之和**：虽为加法，但核心思路（二进制分解+位运算）与快速乘一致，可作为铺垫。
- **50. Pow(x, n)**：快速幂的基础题，若将 `x` 改为整数且需取模，需配合快速乘。
- **149. 直线上最多的点数**：计算两点斜率时，需用快速乘避免浮点数精度误差（判断 `(y2-y1)*(x3-x1) == (y3-y1)*(x2-x1)`，可用快速乘计算两边乘积）。

## 总结

快速乘的核心是「二进制分解+位运算转化」，其价值不仅在于效率优化，更在于解决“大整数乘法溢出”这一关键问题。掌握其迭代实现（尤其是带取模的版本）和与快速幂的配合使用，是处理数论、密码学相关算法题的必备技能。
