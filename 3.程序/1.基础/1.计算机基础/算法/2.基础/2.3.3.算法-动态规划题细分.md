# 动态规划（DP）完整分类体系+详细解释+经典例题+状态转移方程模板

动态规划的核心是「状态定义+转移方程+边界条件」，其分类本质是按**问题模型、状态结构、应用场景**划分，不同分类的核心差异在于状态的组织形式和递推逻辑。以下是整合后的完整体系，每个分类均包含「详细解释+经典例题+核心模板」，兼顾理论理解与刷题落地。

## 一、核心基础DP（入门必学，搭建DP思维框架）

### （一）线性DP

#### 分类详细解释

线性DP是最基础的DP类型，核心特征是**状态按线性顺序递推**（无分支、无环、无嵌套结构）。状态通常依赖于前一个或前几个相邻状态，适用于处理单序列、双序列、一维/二维线性结构的问题（如子序列、子数组、路径等）。其本质是将复杂问题拆解为「线性排列的子问题」，按顺序逐步求解每个子问题的最优解。

#### 入门题：最长上升子序列（LIS）- LeetCode 300

- 核心考点：单序列递推、状态记录最长长度
- 状态定义：dp[i] 表示以第i个元素结尾的最长上升子序列长度
- 转移方程：dp[i] = max(dp[j] + 1)，其中 j < i 且 nums[j] < nums[i]
- 思路提示：遍历每个元素，对比前面所有更小元素的dp值，更新当前最大值；边界条件为dp[i] = 1（每个元素自身可构成长度为1的子序列）

#### 进阶题：编辑距离 - LeetCode 72

- 核心考点：双序列匹配、多状态转移选择
- 状态定义：dp[i][j] 表示将word1前i个字符转为word2前j个字符的最少操作数
- 转移方程：
  - 若word1[i-1] == word2[j-1]：dp[i][j] = dp[i-1][j-1]（无需操作）
  - 否则：dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1（分别对应删除、插入、替换操作）
- 思路提示：初始化边界（空字符串转目标字符串的操作数，如dp[0][j] = j、dp[i][0] = i），再逐字符递推

### （二）背包DP

#### 分类详细解释

背包DP的核心矛盾是「物品选择与资源约束的平衡」，所有子问题均围绕「给定有限资源（如容量、重量、次数），选择若干物品（按特定规则），最大化价值或满足目标」展开。其本质是「选择类问题」，核心差异在于**物品的选取规则**（选1次、选多次、选有限次等）和「资源约束的维度」（单约束、双约束等）。

#### 子分类及核心差异

- 01背包：物品仅能选择1次（选或不选），核心是逆序遍历资源避免重复选取
- 完全背包：物品可选择无限次，核心是顺序遍历资源允许重复选取
- 多重背包：物品可选择有限次（给定数量），核心是拆分物品（二进制拆分/单调队列优化）
- 分组背包：物品分为若干组，每组仅能选1个，核心是按组遍历+组内逆序遍历
- 二维费用背包：资源约束为2个维度（如容量+重量、时间+金钱），核心是多维度逆序遍历
- 依赖背包：物品间存在依赖关系（如选A才能选B），核心是按依赖关系构建树形/链式结构递推
- 混合背包：结合多种背包规则（如部分物品选1次、部分选多次），核心是分类型处理物品

#### 入门题：01背包（模板题）

- 核心考点：物品仅选1次、单容量约束
- 状态定义：dp[j] 表示容量为j的背包能装的最大价值
- 转移方程：dp[j] = max(dp[j], dp[j - weight[i]] + value[i])（逆序遍历容量j，从大到小）
- 思路提示：逆序遍历避免物品重复选取，边界条件为dp[0] = 0（容量为0时价值为0）

#### 进阶题：二维费用背包 - LeetCode 474

- 核心考点：双重约束（0的数量+1的数量）、计数类背包（最大化字符串个数）
- 核心考点：双重约束（0的数量+1的数量）、计数类背包（最大化字符串个数）
- 状态定义：dp[j][k] 表示用j个0和k个1能组成的最大字符串数（省略物品维度，用滚动数组优化）
- 转移方程：dp[j][k] = max(dp[j][k], dp[j - cnt0][k - cnt1] + 1)（cnt0为当前字符串0的数量，cnt1为1的数量）
- 思路提示：先统计每个字符串的0和1数量，按二维容量逆序遍历（避免重复选取），边界条件为dp[0][0] = 0

## 二、区间DP（处理区间相关问题）

### 分类详细解释

区间DP的核心特征是**状态定义在「区间[i,j]」上**，即dp[i][j]表示处理区间从索引i到j的子问题的最优解。其核心思想是「分治+合并」：将大区间[i,j]拆分为子区间[i,k]和[k+1,j]（i≤k<j），通过子区间的最优解合并得到大区间的最优解。适用于需要处理子串、子数组、区间合并、环形结构（破环成链）等问题。

#### 入门题：石子合并（普通版）- 洛谷 P1776

- 核心考点：区间合并、子区间推导、前缀和优化
- 状态定义：dp[i][j] 表示合并区间[i,j]的石子所需最小代价（代价为每次合并的石子总数）
- 转移方程：dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum(i,j)（i ≤ k < j，sum(i,j)为区间[i,j]的石子和）
- 思路提示：先预处理前缀和数组（快速计算sum(i,j)），再按「区间长度」枚举（从2到n），最后枚举区间起点i，计算终点j = i + len - 1；边界条件为dp[i][i] = 0（单个石子无需合并，代价为0）

#### 进阶题：环形石子合并 - 洛谷 P1880

- 核心考点：环形问题转化、区间DP扩展（求最小/最大代价）
- 状态定义：dp[i][j] 表示合并环形中「从i开始、长度为j」的区间的最小/最大代价
- 转移方程：与普通版一致，需将环形拆分为线性（将原数组复制拼接为长度2n的数组，如原数组[1,2,3]变为[1,2,3,1,2,3]）
- 思路提示：破环成链后，按普通区间DP求解，最终答案为所有长度为n的区间（i到i+n-1，i从1到n）的最小/最大值；边界条件为dp[i][1] = 0

## 三、树形DP（基于树结构的DP）

### 分类详细解释

树形DP的核心是「状态定义在树的节点上」，利用树的递归结构（根-子树）递推。由于树无环且具有明确的父子关系，状态通常分为「选当前节点」和「不选当前节点」两类，递推顺序为「后序遍历」（先求解子树的状态，再合并得到当前节点的状态）。适用于处理树的路径、节点选择、子树约束等问题（如树的直径、最大独立集、树上背包等）。

#### 入门题：树的最大独立集 - 洛谷 P1352

- 核心考点：树形递归、选与不选状态划分
- 状态定义：
  - dp[u][0] 表示不选节点u时，以u为根的子树的最大独立集大小（独立集为互不相邻的节点集合）
  - dp[u][1] 表示选节点u时，以u为根的子树的最大独立集大小
- 转移方程：
  - dp[u][1] += dp[v][0]（v为u的子节点，选u则子节点不能选）
  - dp[u][0] += max(dp[v][0], dp[v][1])（不选u则子节点可选可不选，取最大值）
- 思路提示：从叶子节点向上递归（后序遍历），根节点的答案为max(dp[root][0], dp[root][1])；边界条件为叶子节点dp[leaf][0] = 0，dp[leaf][1] = leaf的权值

#### 进阶题：树上背包 - 洛谷 P2014

- 核心考点：树形结构+背包约束、子树容量分配
- 状态定义：dp[u][j] 表示以u为根的子树中，选择j个节点的最大价值（节点带权，需满足父子节点选择约束）
- 转移方程：dp[u][j] = max(dp[u][j - k] + dp[v][k])（v为u的子节点，k为子树v中选择的节点数，j为当前子树总选择数）
- 思路提示：先遍历子节点，再用「分组背包」的思路合并子树状态（每个子树为一组，组内选择k个节点）；容量遍历需逆序（避免重复选择），边界条件为dp[u][0] = 0，dp[u][1] = u的权值

## 四、数位DP（处理数字计数/约束问题）

### 分类详细解释

数位DP专门用于解决「区间内符合特定约束的数字计数」问题（如含数字1的数的个数、无重复数字的数的个数、数字和为k的数的个数等）。核心思想是「逐位递推」：将数字按位拆分为数组（如123拆分为[1,2,3]），状态记录「当前遍历到的位数、已满足的约束条件（如是否达到上限、是否含前导零、已选数字掩码等）」，通过枚举当前位的可能取值，累加合法方案数。其本质是「状态压缩+记忆化搜索」，避免暴力枚举所有数字。

#### 入门题：数字1的个数 - LeetCode 233

- 核心考点：逐位统计、上限约束处理
- 状态定义：dp[pos][cnt][limit] 表示遍历到第pos位（从高位到低位），已统计cnt个1，是否受上限限制（limit=1表示当前位最大为原数字的pos位，0表示可到9）的方案数
- 转移方程：
  - 确定当前位的最大取值max_d：若limit=1则max_d = num[pos]，否则max_d=9
  - 枚举当前位取值d（0到max_d）：
    - 新cnt = cnt + (1 if d == 1 else 0)
    - 新limit = limit & (d == max_d)（若当前位取max_d，后续仍受上限约束）
    - 累加dp[pos+1][new_cnt][new_limit]到当前状态
- 思路提示：将数字转为数组，用记忆化搜索（递归+缓存）实现，边界条件为pos遍历完所有位时，返回cnt（统计1的总个数）

#### 进阶题：不含重复数字的个数 - LeetCode 357

- 核心考点：数位约束+去重、掩码状态记录
- 状态定义：dp[pos][mask][limit] 表示遍历到第pos位，已用数字的掩码为mask（二进制表示，如mask=0b101表示已用数字0和2），是否受上限限制的方案数
- 转移方程：
  - max_d = num[pos] if limit else 9
  - 枚举d（0到max_d）：
    - 若d已在mask中（(mask & (1 << d)) != 0），跳过（重复数字）
    - 新mask：若前导零未消除（mask=0且d=0）则仍为0，否则mask | (1 << d)
    - 新limit = limit & (d == max_d)
    - 累加dp[pos+1][new_mask][new_limit]
- 思路提示：前导零需单独处理（mask=0时d=0不算已用数字），记忆化搜索缓存状态，边界条件为pos遍历完返回1（合法方案）

## 五、状态压缩DP（状态用二进制表示）

### 分类详细解释

状态压缩DP适用于「状态维度高但取值有限」的问题（通常n≤20），核心是用「二进制数（掩码）」表示状态（如n=3时，mask=0b101表示选择了第0和第2个元素），将原本需要多维数组表示的状态压缩为单个整数，降低空间复杂度。其本质是「枚举子集+递推」，适用于子集选择、旅行商问题（TSP）、铺砖问题等。

#### 入门题：蒙德里安的梦想 - 洛谷 P1171

- 核心考点：二进制状态表示、合法状态判断、列间兼容
- 状态定义：dp[i][j] 表示第i列的状态为j（j的二进制位表示该行是否被横向瓷砖覆盖，1表示覆盖，0表示未覆盖）时的铺砖方案数
- 转移方程：
  - 先预处理所有合法状态：状态j中无连续奇数个0（否则纵向瓷砖无法填充）
  - 枚举第i-1列的状态k，若k和j兼容（k & j == 0，无重叠覆盖；(k | j)中无连续奇数个0，确保纵向瓷砖可填充），则dp[i][j] += dp[i-1][k]
- 思路提示：初始化dp[0][0] = 1（第0列无瓷砖覆盖，方案数1），按列递推，最终答案为dp[m][0]（m为列数，最后一列无横向瓷砖覆盖）

#### 进阶题：旅行商问题（TSP）- 洛谷 P1433

- 核心考点：全排列优化、状态压缩记录访问节点
- 状态定义：dp[mask][u] 表示访问过mask中的所有节点（mask的二进制位1表示已访问），当前位于节点u的最小路径长度
- 转移方程：
  - 枚举所有未访问的节点v（(mask & (1 << v)) == 0）：
    - 新mask = mask | (1 << v)
    - dp[new_mask][v] = min(dp[new_mask][v], dp[mask][u] + w[u][v])（w[u][v]为u到v的路径长度）
- 思路提示：初始化dp[1 << u][u] = 0（仅访问节点u，路径长度0），枚举所有mask，再枚举当前节点u，最终答案为dp[(1 << n) - 1][u]（访问所有节点，当前在u）的最小值

## 六、计数与优化类DP

### （一）计数DP

#### 分类详细解释

计数DP的核心目标是「统计满足特定条件的方案数」（如不同路径数、整数拆分方案数、合法括号序列数等）。其转移方程的核心是「累加子方案数」：当前状态的方案数等于所有能转移到当前状态的子状态的方案数之和。适用于无明确“最大化/最小化”目标，仅需统计合法方案总数的问题。

#### 入门题：整数拆分 - LeetCode 343

- 核心考点：拆分方案计数、无顺序约束（如3=2+1与3=1+2视为同一方案）
- 状态定义：dp[i] 表示将i拆分为若干正整数的最大乘积（本题虽为求最大乘积，但本质是计数类思路的延伸，枚举拆分方式）
- 转移方程：dp[i] = max(dp[i], max(j *(i - j), j* dp[i - j]))（1 ≤ j < i，j为拆分出的第一个数）
- 思路提示：枚举所有可能的拆分方式，对比“直接拆为j和i-j”与“拆为j和i-j的最优拆分”的乘积，取最大值；边界条件为dp[1] = 1

#### 进阶题：不同路径II - LeetCode 63

- 核心考点：网格路径计数、障碍处理
- 状态定义：dp[i][j] 表示从(0,0)到(i,j)的不同路径数（只能向右或向下移动）
- 转移方程：
  - 若obstacleGrid[i][j] == 1（障碍点），则dp[i][j] = 0（无路径可达）
  - 否则，dp[i][j] = (dp[i-1][j] if i > 0 else 0) + (dp[i][j-1] if j > 0 else 0)（从上方或左方转移）
- 思路提示：初始化边界（第一行：若遇障碍，后续所有点路径数为0；第一列同理），再逐格递推；边界条件为dp[0][0] = 1（起点无障碍时）

### （二）优化类DP

#### 分类详细解释

优化类DP并非独立的DP类型，而是对基础DP（如线性DP、背包DP）的「时间/空间复杂度优化」。核心是通过数学推导、数据结构（单调队列、堆）或状态简化，消除冗余状态和重复计算，将原O(n²)、O(nm)的复杂度优化为O(n)、O(n log n)等。常见优化方式有：滚动数组（空间优化）、前缀和优化、单调队列优化、斜率优化、二分优化等。

#### 入门题：最大子数组和（前缀和优化）- LeetCode 53

- 核心考点：线性DP的时间优化、冗余状态消除
- 状态定义：dp[i] 表示以i结尾的最大子数组和
- 转移方程：dp[i] = max(nums[i], dp[i-1] + nums[i])（优化后可省略dp数组，用变量current_max记录当前最大值）
- 思路提示：无需遍历所有前序节点，仅需跟踪前一个状态的最大值，实时更新；空间优化后，用current_max和global_max两个变量即可，时间复杂度O(n)，空间O(1)

#### 进阶题：斜率优化DP（烽火传递）- 洛谷 P2900

- 核心考点：单调队列优化、线性DP的时间复杂度优化
- 状态定义：dp[i] 表示前i个烽火台满足“连续m个中至少有1个点燃”的最小代价（点燃第i个烽火台的代价为a[i]）
- 转移方程：dp[i] = min(dp[j] + a[i])（i - m ≤ j ≤ i - 1，即前m个烽火台中至少有1个点燃）
- 思路提示：原转移方程为O(nm)，用单调队列维护区间[i-m, i-1]内的dp[j]最小值，每次取队首即可，将时间复杂度优化为O(n)；队列需保持单调递增，移除过期（j < i - m）和比当前dp[i]大的元素

## 七、概率与期望DP

### 分类详细解释

概率与期望DP用于解决「随机事件的概率计算」或「随机变量的期望计算」问题。核心思想是「基于概率/期望的线性性质，递推状态转移」：

- 概率DP：状态表示“事件发生的概率”，转移方程基于概率加法公式（互斥事件）和乘法公式（独立事件）
- 期望DP：状态表示“随机变量的期望”，转移方程基于期望的线性性质（E[X+Y] = E[X] + E[Y]），常采用“逆向递推”（从结果向初始状态递推）

适用于掷骰子、抽奖、迷宫逃脱、随机游走等问题。

#### 入门题：掷骰子的N种方法 - LeetCode 1155

- 核心考点：概率计数、多步递推
- 状态定义：dp[i][j] 表示掷i次骰子，点数和为j的方案数（概率=方案数/6^i）
- 转移方程：dp[i][j] = sum(dp[i-1][j - k])（1 ≤ k ≤ 6，且j - k ≥ i - 1（掷i-1次的最小点数和为i-1））
- 思路提示：初始化dp[1][k] = 1（k=1到6，掷1次每个点数的方案数为1），递推i从2到n，j从i到6i；最终概率为dp[n][target] / (6 ** n)

#### 进阶题：逃离大迷宫 - LeetCode 1036（简化版：期望逃脱步数）

- 核心考点：期望DP、逆向递推
- 状态定义：dp[x][y] 表示从坐标(x,y)出发，逃离迷宫（到达边界）的期望步数
- 转移方程：
  - 若(x,y)为边界（已逃离），dp[x][y] = 0
  - 否则，枚举(x,y)的相邻可达格子（nx, ny），共k个，则dp[x][y] = (sum(dp[nx][ny]) + k) / k（每步选择一个方向，步数+1，期望为平均步数）
- 思路提示：逆向递推（从边界向内部），用记忆化搜索避免重复计算；若存在不可达边界的格子（如封闭环），则期望为无穷大

## 八、博弈DP（处理对抗性决策问题）

### 分类详细解释

博弈DP用于解决「两人对抗性游戏」的胜负判断问题，核心假设是「双方都采取最优策略」。状态分为「必胜状态」（当前玩家可通过某种操作让对手陷入必败状态）和「必败状态」（当前玩家无论如何操作，对手都能进入必胜状态）。核心工具是「SG函数（Grundy数）」：将复杂游戏拆解为多个子游戏，总SG值为各子游戏SG值的异或，非零则必胜，零则必败。

适用于尼姆游戏、巴什游戏、威佐夫游戏、取石子游戏等。

#### 入门题：尼姆游戏 - LeetCode 292

- 核心考点：异或运算、必胜状态判断
- 状态定义：无需显式DP数组，通过所有堆石子数的异或和判断
- 核心结论：设所有堆石子数为a1, a2, ..., an，计算xor_sum = a1 ^ a2 ^ ... ^ an
  - 若xor_sum != 0：当前玩家必胜（可通过操作使xor_sum变为0，让对手陷入必败）
  - 若xor_sum == 0：当前玩家必败
- 思路提示：直接计算异或和，无需递推，本质是博弈DP的简化结论

#### 进阶题：SG函数（取石子游戏）- 洛谷 P2148

- 核心考点：Grundy数、游戏状态分解
- 状态定义：sg[x] 表示石子数为x时的SG值（SG值为所有可达状态SG值的mex，mex为最小的非负整数）
- 转移方程：sg[x] = mex{ sg[x - k] | 1 ≤ k ≤ x，k为合法取法（如每次可取1~3个）}
- 思路提示：预处理每个石子数的SG值（从0开始，x=0时sg[0]=0），多个堆的游戏总SG值为各堆SG值异或；非零则必胜，零则必败；合法取法可扩展为任意集合（如每次取2或5个）

## 九、其他高频DP类型

### （一）多维DP

#### 分类详细解释

多维DP的状态包含「2个及以上维度」（如三维、四维），适用于处理多约束、多维度决策的问题。其核心是「将复杂问题的约束条件转化为状态的维度」，转移方程需遍历所有维度的子状态。常见于三维背包、多维路径计数、多序列匹配等问题，可通过滚动数组优化空间复杂度。

#### 入门题：最长公共子序列（LCS）- LeetCode 1143

- 核心考点：二维状态、双序列匹配
- 状态定义：dp[i][j] 表示word1前i个字符和word2前j个字符的最长公共子序列长度
- 转移方程：
  - 若word1[i-1] == word2[j-1]：dp[i][j] = dp[i-1][j-1] + 1（公共字符+1）
  - 否则：dp[i][j] = max(dp[i-1][j], dp[i][j-1])（取其中一个序列的前序最优解）
- 思路提示：初始化dp[0][*] = 0、dp[*][0] = 0（空序列的LCS长度为0），逐字符递推

#### 进阶题：三维背包 - 洛谷 P1833

- 核心考点：三重约束、空间优化
- 状态定义：dp[i][j][k] 表示用i时间、j金钱、k容量获得的最大价值（三重约束）
- 转移方程：dp[i][j][k] = max(dp[i][j][k], dp[i - t][j - m][k - v] + w)（t为物品时间，m为金钱，v为容量，w为价值）
- 思路提示：采用滚动数组优化空间，将三维压缩为二维（逆序遍历时间、金钱、容量维度），避免重复选取物品

### （二）分组DP

#### 分类详细解释

分组DP的核心是「将问题拆解为若干组，组内或组间按特定规则转移」。常见场景有：

- 组内选择：每组仅能选1个或多个元素（如分组背包）
- 组间约束：前一组的选择影响后一组的决策（如任务分组、阶段划分）
其本质是「分阶段DP」，将复杂问题按组拆分，逐步求解每组的最优解。

#### 示例题：分组背包（分组DP核心应用）

- 核心考点：组内选择约束、多组物品递推
- 状态定义：dp[j] 表示容量为j的背包，选择前i组物品的最大价值
- 转移方程：对于第i组的每个物品（重量w，价值v），dp[j] = max(dp[j], dp[j - w] + v)（逆序遍历容量，组内物品仅选1个）
- 思路提示：按组遍历，每组内部按01背包的逆序遍历容量，确保每组仅选1个物品

### （三）混合DP

#### 分类详细解释

混合DP是「多种DP模型的结合」，适用于复杂问题（如树形结构+背包约束、区间DP+计数、状态压缩+概率DP等）。核心是「识别问题中的多个核心模型」，将其拆解为子问题，分别用对应DP模型求解，再合并结果。

#### 示例题：树上区间DP（树形DP+区间DP）

- 核心考点：树形结构+区间合并
- 状态定义：dp[u][l][r] 表示以u为根的子树中，处理区间[l][r]的子问题的最优解（如子树中节点权值构成的子数组[l][r]的最大和）
- 转移方程：结合树形DP的父子递推和区间DP的子区间合并，dp[u][l][r] = max(dp[v][l][k] + dp[u][k+1][r])（v为u的子节点，k为区间拆分点）
- 思路提示：先处理子树的区间DP，再合并到父节点的区间状态中
