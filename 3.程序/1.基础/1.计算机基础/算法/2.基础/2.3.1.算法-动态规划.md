# 动态规划

动态规划（Dynamic Programming，简称DP）是解决多阶段决策最优化问题的经典思想，其核心是通过**“分解问题、存储中间结果、复用子问题解”** 来高效求解复杂问题。理解动态规划的核心概念，需要抓住以下几个关键要素：

## 一、核心思想：避免重复计算，复用子问题解

动态规划的本质是**“以空间换时间”**。对于一个复杂问题，若它可以拆解为多个**重叠的子问题**（即不同的大问题会用到相同的小问题结果），则可以通过存储这些子问题的解（避免重复计算），快速推导全局最优解。

例如：计算斐波那契数列 `f(n) = f(n-1) + f(n-2)` 时，递归解法会重复计算 `f(n-2)`、`f(n-3)` 等子问题（时间复杂度 O(2ⁿ)）；而动态规划通过缓存子问题结果（如用数组存储 `f(0)` 到 `f(n)`），将时间复杂度降至 O(n)。

## 二、三大核心要素

动态规划能解决问题的前提是满足三个核心要素：**重叠子问题**、**最优子结构**，以及基于这两者推导的**状态转移方程**。

### 1. 重叠子问题（Overlapping Subproblems）

**定义**：在求解问题的过程中，多个不同的“大问题”会依赖同一个“小问题”的解，即子问题的计算会被重复触发。  
这是动态规划适用的**前提之一**（否则无需存储子问题解，用分治法即可）。  

**示例**：  
在“爬楼梯”问题中（每次可爬1或2阶，求爬到n阶的方法数）：  

- 爬到第 `n` 阶的方法数 = 爬到第 `n-1` 阶的方法数 + 爬到第 `n-2` 阶的方法数（即 `f(n) = f(n-1) + f(n-2)`）。  
- 计算 `f(5)` 时需要 `f(4)` 和 `f(3)`；计算 `f(4)` 时需要 `f(3)` 和 `f(2)`——其中 `f(3)` 被重复计算，属于重叠子问题。  

### 2. 最优子结构（Optimal Substructure）

**定义**：问题的**全局最优解**必然包含**子问题的最优解**。即可以通过求解子问题的最优解，“拼凑”出全局最优解。  
这是动态规划能通过子问题推导全局解的**核心依据**。  

**示例**：  

- 最短路径问题：从 A 到 C 的最短路径若经过 B，则 A 到 B 的路径和 B 到 C 的路径也必须是各自的最短路径（否则 A 到 C 的路径就不是最优的）。  
- 0-1 背包问题：前 `i` 个物品在容量 `j` 下的最大价值，要么是“不选第 `i` 个物品时前 `i-1` 个物品在容量 `j` 下的最大价值”，要么是“选第 `i` 个物品时前 `i-1` 个物品在容量 `j-重量[i]` 下的最大价值 + 价值[i]”——两种情况均依赖子问题的最优解。  

### 3. 状态转移方程（State Transition Equation）

**定义**：用数学公式描述“当前问题的状态”与“子问题的状态”之间的关系，是动态规划的**灵魂**。  
它需要明确两个关键：  

- **状态（State）**：描述问题在某一阶段的特征（通常用变量表示，如 `dp[i]`、`dp[i][j]`）。  
- **转移**：如何从子问题的状态推导出当前状态的解。  

**构建状态转移方程的步骤**：  

1. **定义状态**：明确 `dp[i]`（或 `dp[i][j]`）代表什么（如 `dp[i]` 表示“爬到第 `i` 阶的方法数”）。  
2. **确定边界条件**：最基础的子问题（无需再分解的问题）的解（如 `dp[0] = 1`，`dp[1] = 1`，表示爬到0阶和1阶的方法数）。  
3. **推导转移关系**：基于最优子结构，写出 `dp[i]` 与 `dp[i-1]`、`dp[i-2]` 等的关系（如 `dp[i] = dp[i-1] + dp[i-2]`）。  

**示例**：  

- 爬楼梯问题：  
  - 状态定义：`dp[i]` = 爬到第 `i` 阶的方法数。  
  - 边界条件：`dp[0] = 1`（初始状态），`dp[1] = 1`（1阶只有1种方法）。  
  - 转移方程：`dp[i] = dp[i-1] + dp[i-2]`（从 `i-1` 阶爬1步，或从 `i-2` 阶爬2步）。  

## 三、两种典型实现方式

动态规划的实现围绕“存储子问题解”展开，根据计算顺序可分为两类：  

### 1. 自顶向下（Top-Down）：备忘录法（Memoization）

- **思路**：从原问题（大问题）出发，递归分解为子问题，用**缓存（如哈希表、数组）** 存储已计算的子问题解，避免重复计算。  
- **特点**：直观（符合递归思维），但可能有递归调用的额外开销。  

**示例（斐波那契数列）**：  

```java
// 缓存子问题解
private Map<Integer, Integer> memo = new HashMap<>();

public int fib(int n) {
    // 边界条件
    if (n <= 1) return n;
    // 若子问题已计算，直接返回缓存
    if (memo.containsKey(n)) return memo.get(n);
    // 递归计算子问题，并缓存结果
    int res = fib(n-1) + fib(n-2);
    memo.put(n, res);
    return res;
}
```

### 2. 自底向上（Bottom-Up）：DP表法

- **思路**：从最基础的子问题（边界条件）出发，按顺序计算出所有子问题的解（填充DP表），最终得到原问题的解。  
- **特点**：迭代实现，无递归开销，空间可进一步优化（如滚动数组）。  

**示例（爬楼梯）**：  

```java
public int climbStairs(int n) {
    if (n <= 1) return 1;
    // DP表存储子问题解
    int[] dp = new int[n+1];
    // 边界条件
    dp[0] = 1;
    dp[1] = 1;
    // 从子问题逐步计算到原问题
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2]; // 状态转移方程
    }
    return dp[n];
}
```

## 四、总结

动态规划的核心概念可概括为：  

1. **通过分解问题**，将复杂问题转化为重叠的子问题；  
2. **利用最优子结构**，确保子问题的最优解能推导出全局最优解；  
3. **定义状态和状态转移方程**，明确子问题之间的关系；  
4. **存储子问题解**（备忘录或DP表），避免重复计算，实现高效求解。  

能否正确定义“状态”和“状态转移方程”，是动态规划解题的关键——这需要对问题本质的深刻理解和大量实践。
