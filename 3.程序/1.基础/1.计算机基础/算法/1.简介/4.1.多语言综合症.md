# 做leetcode时， 我学的语言太多了，导致很多api弄混或忘记了，怎么办

这是一个非常典型且普遍的“多语言切换综合症”。你掌握的语言越多（C, C++, Java, Python, JS/TS, Rust, Kotlin, Swift, Dart等），在 LeetCode 这种需要快速调用 API 的场景下，大脑的“上下文切换”成本就越高。

针对你的情况，结合你提供的笔记目录，我为你整理了一套**“降维打击 + 肌肉记忆”**的解决方案：

## 1. 核心策略：确立“主战语言” (The Main Weapon)

不要试图在 LeetCode 上同时精通所有语言。**刷题的目的是锻炼算法思维，而不是测试 API 记忆力。**

* **建议**：从你熟悉的语言中选出 **1-2 门**作为刷题专用语言。
  * **首选推荐**：**Python** 或 **Java**。
    * **Python**：API 极其简洁（如 `len()`, `sorted()`, `set()`），伪代码即代码，最适合专注算法逻辑。
    * **Java**：生态标准，`HashMap`, `ArrayList`, `PriorityQueue` 等数据结构实现严谨，适合面试中大厂后端岗位。
  * **次选**：**C++** (如果你追求极致性能或参加 ACM 竞赛) 或 **JavaScript/TypeScript** (如果你主攻前端)。
  * **避坑**：尽量避免使用 **Rust** 或 **C** 刷题，除非题目特意考察内存管理。因为它们的样板代码（Boilerplate）和所有权/指针处理会分散你对算法本身的注意力。

## 2. 建立“通用 API 映射表” (The Rosetta Stone)

## 4. 针对性复习你的笔记 (Knowledge Consolidation)

根据你的目录，重点复习以下容易混淆的点：

1. **字符串操作**：
    * **Java/Kotlin/Swift**: 字符串通常是**不可变**的。修改字符串需要创建新对象或使用 `StringBuilder` (Java/Kotlin) / `StringBuffer`。
    * **C++**: `std::string` 是可变的。
    * **Rust**: `String` (拥有所有权，可变) vs `&str` (借用，不可变切片)。刷题时尽量用 `String` 或 `chars().collect::<Vec<char>>()` 来处理复杂逻辑。
    * **Python/JS**: 虽然不可变，但语法上像可变一样方便（切片、拼接）。

2. **数组与列表**：
    * **C/C++**: 注意指针越界和内存泄漏。刷题建议直接用 `std::vector`。
    * **Rust**: 注意 `Vec` 的索引访问 `vec[i]` 会 panic，推荐使用 `get(i)` 返回 `Option`，或者确保逻辑绝对安全。
    * **Java**: `ArrayList` 是动态数组，`LinkedList` 是链表。随机访问多用 `ArrayList`。

3. **空值处理**：
    * **Java/Kotlin/Swift**: 警惕 `NullPointerException`。Kotlin 的 `?.` 和 `?:` 很有用。
    * **Rust**: 没有 null，只有 `Option<T>`。刷题时可以用 `.unwrap()` 偷懒，但面试时要展示对 `Some/None` 的处理。
    * **JS/TS**: 警惕 [undefined](file:///Users/admin/AndroidStudioProjects/wx/wuxu/github/wuxu_future/4.职业/远程工作/大牛给的建议/2025年，应该如何寻找远程工作？_files/undefined) 和 `null` 的区别。使用可选链 `obj?.prop`。

## 5. 实战训练法：刻意练习 API

1. **“盲打”简单题**：
    选择 Easy 级别的题目（如 Two Sum, Reverse String），强制自己**不查阅文档**完成。如果卡住，记下是哪个 API 忘了，事后加入错题本。
2. **一题多解（限语言）**：
    用同一门语言，分别用暴力解法和最优解法写一遍。这能帮你熟悉该语言的标准库（如 Java 的 `Stream` API，Python 的 `itertools`，C++ 的 `<algorithm>`）。
3. **阅读官方文档的 "Cheat Sheet"**：
    * [Python Docs](https://docs.python.org/3/library/stdtypes.html)
    * [Java Collections Framework](https://docs.oracle.com/javase/tutorial/collections/interfaces/index.html)
    * [C++ Reference](https://en.cppreference.com/w/cpp/container)
    * [Rust By Example](https://doc.rust-lang.org/rust-by-example/)

## 6. 心理建设

* **忘记是正常的**：即使是资深工程师，也经常需要查文档确认 `substring` 的参数是 `(start, end)` 还是 `(start, length)`。
* **IDE 是你的朋友**：在实际工作中，IntelliJ IDEA, VS Code, Rust Analyzer 等工具会自动补全 API。LeetCode 的编辑器较弱，所以你需要记忆的是**最核心的那 20% 的 API**，它们覆盖了 80% 的题目。

**总结行动清单：**

1. **选定主语言**（推荐 Python 或 Java）。
2. **打印/保存上面的“通用 API 映射表”**。
3. **配置代码模板**，减少重复打字。
4. **遇到遗忘的 API，记录到专门的“API 备忘录”笔记中**，定期回顾。

通过这种方式，你将把“记忆负担”转化为“模式识别”，刷题效率会显著提升。
