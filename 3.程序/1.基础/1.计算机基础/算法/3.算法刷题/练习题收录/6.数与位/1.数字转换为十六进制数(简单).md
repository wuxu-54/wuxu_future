# 405. 数字转换为十六进制数

<https://leetcode.cn/problems/convert-a-number-to-hexadecimal>

```txt
给定一个整数，编写一个算法将这个数转换为十六进制数。对于负整数，我们通常使用 补码运算 方法。

答案字符串中的所有字母都应该是小写字符，并且除了 0 本身之外，答案中不应该有任何前置零。

注意: 不允许使用任何由库提供的将数字直接转换或格式化为十六进制的方法来解决这个问题。


示例 1：

输入：num = 26
输出："1a"
示例 2：

输入：num = -1
输出："ffffffff"
 

提示：

-231 <= num <= 231 - 1
```

## 题解

```cpp
class Solution {
public:
    string toHex(int num) {
        if(num==0){
            return "0";
        }
        string ret;
        //核心原理：( num >> 4 *i ) & 0xf
        //这个公式作用：num 取低四位数。  作用等同于 %16 （但%16的方法只能正整数） 且能包括负整数
        for(int i = 7;i>=0;i--){ // 因为num 是int类型，32位，换算16进制则每4位表示16进制的一位，所以最终16进制的数只有8个.  从7到0  是从高位开始取，按顺序写入ret中。
            int val = ( num >> 4* i ) & 0xf;
            if(ret.length()>0|| val > 0){//这一步是num如果是负数，val最终会<0,此时需要判断ret.length()>0 让符号位进入
                char t = val < 10 ? (char)(48+val):(char)(97+val-10);
                ret.push_back(t);
            }
        }
        return ret;
    }
};
```
