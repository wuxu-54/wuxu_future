# 项目架构层次：表现层-业务逻辑层-数据层

从我知道的移动端（android、鸿蒙）来说大致分为三大层：表现层/UI层、业务逻辑层、数据层。  我想其他前端如【react、vue、小程序】大体架构类似，所以在本章节列出架构层次的简要说明，在具体如Android等领域章节我也有写。

## 架构层次

下面描述的是各层次常见、通用的元素，真正项目需要依据项目大小进行灵活运用。

### 表现层/UI层

只关注 “如何展示”，不处理业务逻辑.

包括：

1. Page：具体页面，是路由跳转的节点（如首页、详情页），由多个业务UI / 基础UI组合而成。
2. 业务UI（Business UI）：业务相关UI，比如Android中的 业务View、react/鸿蒙/vue/小程序 中的业务组件
3. 基础UI（Basic UI）：通用UI元素

### 业务逻辑层

处理业务逻辑，隔离 UI 与数据，是连接表现层和数据层的桥梁。

包括：

1. ViewModel：为页面组件提供数据和交互方法，内部调用 UseCase（因为ViewModel与UI高度关联，谷歌Android官方架构将其放在UI层）
2. UseCase：封装单一业务场景（如 “登录流程”“商品筛选”），可组合多个 Repository 的方法，避免 ViewModel 臃肿。

#### useCase

核心作用：

- 业务逻辑与 UI 层的彻底隔离；
- 复杂业务的拆分与复用；
- 低成本的单元测试（无需依赖 UI 和真实数据源）。

一些说明：

1. 命名：以 “动作 + 业务场景” 命名
2. UseCase 重点强调，在小型项目里是可以省略的，封装过渡没有必要，ViewModel可以直接调用数据层如 Repository对象。
3. 在业务模块中，可以放置在单独设置的`usecase`命名的文件夹里。

### 数据层

负责数据的 “获取、存储、转换”，对外提供统一数据接口。

包括：

1. 数据调度（Repository）：整合本地数据、远程数据，向外提供的方法。
2. 本地数据：Local DataSource  如本地数据库、本地文件数据等。
3. 远程服务器数据：Remote DataSource  如 Http请求
4. 数据转换（Mapper）：数据转换处理，有些数据是无法直接给上层使用的，所以需要进行转换，这一步放在数据层中即Mapper。

## 项目架构中的单元测试

通过数据层进行mock数据的配置，可以对**业务逻辑层**进行单元测试。

例如登录模块模拟测试时，ViewModel调用LoginUseCase，LoginUseCase通过数据层MockLoginRepository 返回模拟数据。

```ts
// LoginUseCase.test.ets（单元测试文件）
import { LoginUseCase } from '../usecase/LoginUseCase';
import { UserRepositoryInterface } from '../../../data/ets/repository/UserRepository';

// Mock Repository：模拟登录成功/失败的场景
class MockUserRepository implements UserRepositoryInterface {
  async login(username: string, password: string) {
    if (username === 'test' && password === '123456') {
      return { success: true, token: 'mock_token' };
    } else {
      return { success: false, message: '账号或密码错误' };
    }
  }

  async saveToken(token: string) {
    // 模拟保存Token（实际测试中可验证是否调用）
    console.log('Mock保存Token：', token);
  }
}

// 测试用例
describe('LoginUseCase', () => {
  const useCase = new LoginUseCase(new MockUserRepository());

  it('参数为空时，登录应失败', async () => {
    const result = await useCase.execute({ username: '', password: '' });
    expect(result.success).toBe(false);
    expect(result.message).toContain('不能为空');
  });

  it('账号密码正确时，登录应成功并返回Token', async () => {
    const result = await useCase.execute({
      username: 'test',
      password: '123456',
      remember: true
    });
    expect(result.success).toBe(true);
    expect(result.token).toBe('mock_token');
  });
});
```
