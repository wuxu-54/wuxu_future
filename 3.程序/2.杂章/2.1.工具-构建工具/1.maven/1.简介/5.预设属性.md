# 预设属性

Maven `pom.xml` 中所有**内置预设属性（Predefined Properties）**（也叫内置属性/预定义属性），并详细说明每个属性的含义、用途和示例值。这些属性无需在 `<properties>` 中定义，Maven 会自动生成并可直接通过 `${属性名}` 引用，我会按**功能分类**梳理，确保覆盖所有核心预设属性：

## 一、核心项目属性（Project Core Properties）

这类属性直接映射 `pom.xml` 中的核心配置，是最常用的预设属性，部分属性有简写形式。

| 预设属性名                | 简写形式       | 含义                                                                 | 示例值                          |
|---------------------------|----------------|----------------------------------------------------------------------|---------------------------------|
| `${project.groupId}`      | `${groupId}`   | 项目的 Group ID（对应 `<groupId>` 标签）                             | `com.example`                   |
| `${project.artifactId}`   | `${artifactId}`| 项目的 Artifact ID（对应 `<artifactId>` 标签）                       | `e-commerce-core`               |
| `${project.version}`      | `${version}`   | 项目的版本号（对应 `<version>` 标签）                                 | `1.0.0` / `2.0.0-SNAPSHOT`      |
| `${project.packaging}`    | `${packaging}` | 项目的打包类型（对应 `<packaging>` 标签，默认 `jar`）                 | `jar` / `war` / `pom`           |
| `${project.name}`         | -              | 项目名称（对应 `<name>` 标签）                                       | `电商核心模块`                  |
| `${project.description}`  | -              | 项目描述（对应 `<description>` 标签）                                | `包含通用工具类和数据模型`      |
| `${project.url}`          | -              | 项目官网/仓库地址（对应 `<url>` 标签）                               | `https://github.com/example/demo`|
| `${project.basedir}`      | `${basedir}`   | 项目根目录（包含 `pom.xml` 的目录，核心常用）                         | `/Users/xxx/projects/e-commerce`|
| `${project.version}`      | `${pom.version}`| 等同于 `${project.version}`（兼容写法）                             | `1.0.0`                         |
| `${project.build.finalName}` | -            | 项目打包后的最终文件名（默认 `${artifactId}-${version}`）            | `e-commerce-core-1.0.0`        |

## 二、构建输出相关属性（Build Output Properties）

这类属性指向构建过程中生成的文件/目录路径，核心与 `target` 目录相关。

| 预设属性名                          | 含义                                                                 | 示例值                                  |
|-------------------------------------|----------------------------------------------------------------------|-----------------------------------------|
| `${project.build.directory}`        | 构建输出根目录（默认 `${basedir}/target`）                           | `/Users/xxx/projects/e-commerce/target` |
| `${project.build.outputDirectory}`  | 主代码编译后的类文件输出目录（默认 `${project.build.directory}/classes`） | `target/classes`                        |
| `${project.build.testOutputDirectory}` | 测试代码编译后的类文件输出目录（默认 `${project.build.directory}/test-classes`） | `target/test-classes`          |
| `${project.build.sourceDirectory}`  | 主源码目录（默认 `${basedir}/src/main/java`）                        | `src/main/java`                         |
| `${project.build.testSourceDirectory}` | 测试源码目录（默认 `${basedir}/src/test/java`）                    | `src/test/java`                         |
| `${project.build.resourceDirectory}` | 主资源文件目录（默认 `${basedir}/src/main/resources`）              | `src/main/resources`                    |
| `${project.build.testResourceDirectory}` | 测试资源文件目录（默认 `${basedir}/src/test/resources`）          | `src/test/resources`                    |
| `${project.build.scriptSourceDirectory}` | 脚本源码目录（默认 `${basedir}/src/main/scripts`）                | `src/main/scripts`                      |
| `${project.reporting.outputDirectory}` | 项目报告输出目录（默认 `${project.build.directory}/site`）         | `target/site`                           |

## 三、环境与系统属性（Environment & System Properties）

这类属性映射操作系统、JDK、用户环境等信息，与Maven运行环境强相关。

| 预设属性名                | 含义                                                                 | 示例值                                  |
|---------------------------|----------------------------------------------------------------------|-----------------------------------------|
| `${user.home}`            | 当前操作系统用户的主目录                                             | Windows: `C:\Users\张三` / Linux: `/home/zhangsan` |
| `${user.dir}`             | Maven 命令执行的当前工作目录（不一定是项目根目录）                   | `/Users/xxx/projects/e-commerce`        |
| `${java.home}`            | JDK/JRE 的安装目录                                                   | `/Library/Java/JavaVirtualMachines/jdk1.8.0_301.jdk/Contents/Home` |
| `${java.version}`         | JDK 版本号                                                           | `1.8.0_301` / `17.0.5`                  |
| `${java.vendor}`          | JDK 供应商                                                           | `Oracle Corporation` / `Eclipse Adoptium` |
| `${os.name}`              | 操作系统名称                                                         | `Mac OS X` / `Windows 10` / `Linux`     |
| `${os.arch}`              | 操作系统架构                                                         | `x86_64` / `aarch64`（M1/M2芯片）       |
| `${os.version}`           | 操作系统版本                                                         | `13.4`（macOS） / `10.0.19045`（Windows）|
| `${file.separator}`       | 系统文件分隔符                                                       | Linux/Mac: `/` / Windows: `\`           |
| `${path.separator}`       | 系统路径分隔符                                                       | Linux/Mac: `:` / Windows: `;`           |
| `${line.separator}`       | 系统换行符                                                           | Linux/Mac: `\n` / Windows: `\r\n`       |
| `${user.name}`            | 当前操作系统登录用户名                                               | `zhangsan` / `admin`                    |

## 四、Maven 自身属性（Maven Runtime Properties）

这类属性描述 Maven 运行时的自身信息（版本、安装目录等）。

| 预设属性名                | 含义                                                                 | 示例值                                  |
|---------------------------|----------------------------------------------------------------------|-----------------------------------------|
| `${maven.version}`        | 当前使用的 Maven 版本号                                             | `3.8.8` / `3.9.5`                       |
| `${maven.home}`           | Maven 安装目录（M2_HOME）                                            | `/usr/local/apache-maven-3.8.8`         |
| `${maven.conf}`           | Maven 配置文件目录（默认 `${maven.home}/conf`）                      | `/usr/local/apache-maven-3.8.8/conf`    |
| `${maven.repo.local}`     | 本地仓库目录（默认 `${user.home}/.m2/repository`）                   | `/Users/zhangsan/.m2/repository`        |
| `${maven.build.timestamp}` | Maven 构建的时间戳（默认格式：`yyyyMMdd-HHmm`）                     | `20260113-1530`                         |
| `${maven.build.timestamp.format}` | 自定义构建时间戳格式（需手动定义，如 `yyyy-MM-dd HH:mm:ss`）       | `2026-01-13 15:30:25`                   |

## 五、仓库相关属性（Repository Properties）

这类属性指向 Maven 仓库的核心配置，部分需结合 `settings.xml`。

| 预设属性名                | 含义                                                                 | 示例值                                  |
|---------------------------|----------------------------------------------------------------------|-----------------------------------------|
| `${settings.localRepository}` | 本地仓库目录（等同于 `${maven.repo.local}`）                       | `/Users/zhangsan/.m2/repository`        |
| `${project.distributionManagement.repository.url}` | 项目部署的正式版本仓库地址（对应 `<distributionManagement>`）       | `http://localhost:8081/repository/maven-releases/` |
| `${project.distributionManagement.snapshotRepository.url}` | 项目部署的快照版本仓库地址 | `http://localhost:8081/repository/maven-snapshots/` |

## 六、其他常用预设属性

| 预设属性名                | 含义                                                                 | 示例值                                  |
|---------------------------|----------------------------------------------------------------------|-----------------------------------------|
| `${project.version}`      | 项目版本（含 `-SNAPSHOT` 后缀）                                     | `2.0.0-SNAPSHOT`                        |
| `${project.baseUri}`      | 项目根目录的 URI 形式                                               | `file:///Users/xxx/projects/e-commerce/` |
| `${project.parent.groupId}` | 父项目的 Group ID（多模块项目）                                     | `com.example`                           |
| `${project.parent.artifactId}` | 父项目的 Artifact ID（多模块项目）                                 | `e-commerce-parent`                    |
| `${project.parent.version}` | 父项目的版本号（多模块项目）                                         | `1.0.0`                                 |

## 补充说明：如何验证/查看所有生效的预设属性

如果想确认当前项目中所有可用的预设属性（包括系统属性、Maven内置属性），可执行以下命令：

```bash
# 打印所有系统属性和Maven内置属性
mvn help:system

# 仅查看Maven核心预设属性（结合有效POM）
mvn help:effective-pom -Doutput=effective-pom.xml
```

## 总结

Maven 预设属性的核心要点：

1. **无需定义即可使用**：所有预设属性由 Maven 自动生成，直接通过 `${属性名}` 引用（如 `${basedir}` 指向项目根目录）；
2. **简写与全写等价**：如 `${groupId}` 等同于 `${project.groupId}`，推荐使用全写以提高可读性；
3. **环境相关性**：`${os.name}`、`${java.version}` 等属性值随运行环境变化，可用于跨平台配置；
4. **核心常用属性**：`${basedir}`、`${project.version}`、`${maven.repo.local}`、`${project.build.directory}` 是日常开发中最常使用的预设属性。

掌握这些预设属性可以大幅简化 `pom.xml` 配置（如避免硬编码路径、版本），提升配置的灵活性和跨环境兼容性。
