# VChart图表

<https://www.visactor.com/vchart/guide/tutorial_docs/Chart_Concepts/Legend>

## 介绍

VChart 是字节跳动 VisActor 开源的**多端可视化图表库**，支持 Web、HarmonyOS、小程序等场景，以 `spec`（配置对象）为核心，兼具易用性、高性能和跨端适配能力。以下是 **VChart 从入门到进阶的完整用法详解**（覆盖 Web/HarmonyOS 双端）。

## 一、VChart 核心认知

### 1. 是什么？

VChart 是基于可视化渲染引擎 `VisActor` 开发的图表库，提供 **50+ 图表类型**（柱状图、折线图、饼图、地图等），支持动态交互、大数据渲染、自定义扩展，同时适配多端环境。

### 2. 核心特点

- **跨端适配**：一套配置支持 Web/HarmonyOS/小程序；
- **高性能**：支持百万级数据渲染、局部更新；
- **低代码**：通过 `spec` 配置快速生成图表，无需复杂编码；
- **高自定义**：从样式到交互均可深度定制。

## 二、环境准备

### 1. Web 端（HTML/JS/Vue/React）

#### 方式1：CDN 引入（快速测试）

```html
<!-- 引入 VChart -->
<script src="https://unpkg.com/@visactor/vchart/build/index.min.js"></script>
```

#### 方式2：npm 安装（项目开发）

```bash
# 安装 VChart
npm install @visactor/vchart --save
```

### 2. HarmonyOS 端（ArkTS）

在鸿蒙工程中安装依赖：

```bash
npm install @visactor/vchart --save
```

并在 `package.json` 中声明依赖（鸿蒙工程要求）：

```json
"dependencies": {
  "@visactor/vchart": "^1.10.0"
}
```

## 三、快速入门：第一个 VChart 图表

### 场景：基础柱状图

#### 1. Web 端示例（HTML+JS）

```html
<!DOCTYPE html>
<html>
<head>
  <script src="https://unpkg.com/@visactor/vchart/build/index.min.js"></script>
</head>
<body>
  <div id="chart" style="width: 600px; height: 400px;"></div>
  <script>
    // 1. 定义数据
    const data = [
      { category: '2022', value: 30 },
      { category: '2023', value: 50 },
      { category: '2024', value: 40 }
    ];

    // 2. 定义 spec 配置（VChart 核心）
    const spec = {
      type: 'bar', // 图表类型：柱状图
      data: [{ id: 'barData', values: data }], // 数据源
      xField: 'category', // X轴绑定「分类」字段
      yField: 'value', // Y轴绑定「数值」字段
      legend: { visible: false }, // 隐藏图例
      bar: { itemStyle: { color: '#4ECDC4' } } // 柱子样式
    };

    // 3. 渲染图表
    const vchart = new VChart(spec, { dom: 'chart' });
    vchart.renderAsync();
  </script>
</body>
</html>
```

#### 2. HarmonyOS 端示例（ArkTS）

```typescript
import { VChart } from '@visactor/vchart';
import { Component, Entry, Column, ComponentContainer } from '@ohos/ui';

@Entry
@Component
struct VChartBarDemo {
  build() {
    Column() {
      // 鸿蒙容器：通过 ComponentContainer 挂载图表
      ComponentContainer({
        id: 'chart',
        onContainerAttached: (container) => {
          // 1. 数据
          const data = [
            { category: '2022', value: 30 },
            { category: '2023', value: 50 },
            { category: '2024', value: 40 }
          ];

          // 2. spec 配置
          const spec = {
            type: 'bar',
            data: [{ id: 'barData', values: data }],
            xField: 'category',
            yField: 'value',
            legend: { visible: false },
            bar: { itemStyle: { color: '#4ECDC4' } }
          };

          // 3. 渲染图表
          const vchart = new VChart(spec, { dom: container });
          vchart.renderAsync();
        }
      })
      .width('100%') // 鸿蒙自适应单位
      .height('400vp');
    }
  }
}
```

## 四、VChart 核心概念

VChart 的所有功能都围绕 **`spec` 配置对象** 展开，核心概念包括：

| 概念       | 作用                                                                 |
|------------|----------------------------------------------------------------------|
| `type`     | 图表类型（如 `'bar'`/`'line'`/`'pie'`），决定图表基础形态。           |
| `data`     | 数据源，格式为 `[{id: '数据ID', values: [数据项数组]}]`，支持多数据源。 |
| `xField/yField` | 轴字段映射：将数据字段绑定到 X/Y 轴（适用于直角坐标系图表）。         |
| `seriesField` | 多系列区分字段：将数据按指定字段分组为多个系列（如多系列柱状图）。    |
| `series`   | 系列配置：针对多系列图表，可单独配置每个系列的样式/逻辑。             |
| 组件（`legend`/`tooltip`/`axes`） | 辅助元素：图例、提示框、坐标轴等，控制图表的辅助交互/展示。           |

## 五、基础配置详解

### 1. 数据源配置（`data`）

支持**静态数据**、**数据转换**（过滤/映射）：

```javascript
const spec = {
  data: [
    {
      id: 'barData',
      values: [
        { category: 'A', value: 30, type: '系列1' },
        { category: 'B', value: 50, type: '系列2' }
      ],
      // 数据转换：过滤 value > 30 的数据
      transform: [
        { type: 'filter', config: { field: 'value', operator: '>', value: 30 } }
      ]
    }
  ]
};
```

### 2. 多系列配置（`seriesField`）

通过 `seriesField` 按字段分组为多系列：

```javascript
const spec = {
  type: 'bar',
  data: [{ id: 'barData', values: data }],
  xField: 'category',
  yField: 'value',
  seriesField: 'type', // 按 type 字段分系列
  color: ['#FF6B6B', '#4ECDC4'] // 多系列颜色
};
```

### 3. 组件配置

#### （1）图例（`legend`）

控制图例的显隐、位置、样式：

```javascript
const spec = {
  legend: {
    visible: true, // 显示图例
    position: 'bottom', // 位置：top/bottom/left/right
    item: { size: 12 }, // 图例项大小
    text: { style: { fontSize: 14 } } // 图例文字样式
  }
};
```

#### （2）提示框（`tooltip`）

自定义提示框内容/样式：

```javascript
const spec = {
  tooltip: {
    visible: true,
    formatter: (datum) => {
      // 自定义提示文案：显示分类+数值
      return `${datum.category}：${datum.value}`;
    },
    style: { backgroundColor: 'rgba(0,0,0,0.7)' } // 背景样式
  }
};
```

#### （3）坐标轴（`axes`）

定制坐标轴的显隐、样式：

```javascript
const spec = {
  axes: [
    {
      orient: 'x', // X轴
      visible: true,
      label: { style: { fontSize: 12, rotate: 45 } } // X轴标签旋转45度
    },
    {
      orient: 'y', // Y轴
      visible: true,
      grid: { style: { lineDash: [2, 2] } } // Y轴网格线为虚线
    }
  ]
};
```

## 六、样式定制

VChart 支持从**全局到数据项**的精细化样式控制：

### 1. 全局系列样式

```javascript
const spec = {
  bar: { // 针对柱状图系列
    width: 20, // 柱子宽度
    itemStyle: {
      color: '#FF6B6B', // 全局柱子颜色
      cornerRadius: [4, 4, 0, 0] // 柱子圆角（左上/右上/右下/左下）
    }
  }
};
```

### 2. 数据项级样式（回调函数）

根据数据值/字段自定义样式：

```javascript
const spec = {
  bar: {
    itemStyle: {
      color: (datum) => {
        // 按 value 数值区分颜色：>50 为红色，否则为绿色
        return datum.value > 50 ? '#FF6B6B' : '#4ECDC4';
      }
    }
  }
};
```

### 3. 视觉映射（`visualMap`）

按数值范围自动渐变颜色：

```javascript
const spec = {
  visualMap: [
    {
      type: 'continuous', // 连续映射
      field: 'value', // 基于 value 字段
      min: 0,
      max: 100,
      inRange: { color: ['#E8F4FD', '#409EFF'] } // 浅蓝→深蓝渐变
    }
  ]
};
```

## 七、交互功能

### 1. 事件监听

监听图表的点击、 hover 等事件：

```javascript
const vchart = new VChart(spec, { dom: 'chart' });
vchart.renderAsync().then(() => {
  // 监听数据项点击事件
  vchart.on('bar:click', (event) => {
    console.log('点击了数据项：', event.datum); // event.datum 是当前数据项
  });

  // 监听图例点击事件
  vchart.on('legend:click', (event) => {
    console.log('点击了图例：', event.seriesName);
  });
});
```

### 2. 交互行为

配置缩放、拖拽等交互：

```javascript
const spec = {
  // 开启X轴缩放
  zoom: { enabled: true, orient: 'x' },
  // 开启拖拽平移
  pan: { enabled: true, orient: 'x' },
  // 开启数据项选中
  select: { enabled: true, mode: 'single' } // 单选模式
};
```

## 八、多端适配要点

### 1. Web vs HarmonyOS 差异

| 维度          | Web 端                          | HarmonyOS 端                    |
|---------------|---------------------------------|---------------------------------|
| 容器挂载      | 绑定 DOM 元素（`dom: 'chart'`） | 绑定 `ComponentContainer` 实例 |
| 尺寸单位      | 用 `px`/`%`                    | 用鸿蒙自适应单位 `vp`           |
| 生命周期管理  | 页面卸载时调用 `vchart.destroy()` | 鸿蒙页面生命周期（如 `onPageHide`）中销毁 |

### 2. 鸿蒙端性能优化

- 禁用非必要动画：`animation: { enabled: false }`；
- 大数据量时开启数据采样：`data: [{ values: data, sample: { enabled: true, count: 1000 } }]`；
- 页面隐藏时销毁图表：

  ```typescript
  onPageHide(() => {
    vchart?.destroy();
  });
  ```

## 九、进阶用法

### 1. 组合图表（多系列混合）

在一个 spec 中配置多个系列（如柱状图+折线图）：

```javascript
const spec = {
  type: 'common', // 通用图表类型（支持多系列）
  data: [{ id: 'mixData', values: data }],
  xField: 'category',
  series: [
    { type: 'bar', yField: 'value1', name: '销量' }, // 柱状图系列
    { type: 'line', yField: 'value2', name: '增长率' } // 折线图系列
  ],
  color: ['#FF6B6B', '#4ECDC4']
};
```

### 2. 自定义组件

通过 `annotation` 添加自定义图形/文字：

```javascript
const spec = {
  annotation: [
    {
      type: 'text', // 文本标注
      position: ['2023', 50], // 标注位置（X=2023，Y=50）
      content: '峰值', // 标注内容
      style: { fontSize: 14, fill: 'red' }
    }
  ]
};
```

## 十、常见问题

1. **图表不渲染？**
   - 检查容器是否有宽高；
   - 检查 `spec` 配置是否正确（如 `type`/`xField` 是否存在）。

2. **鸿蒙端依赖报错？**
   - 确保 `@visactor/vchart` 版本适配鸿蒙；
   - 执行 `npm install` 后重启 DevEco Studio。

3. **大数据卡顿？**
   - 开启数据采样；
   - 禁用动画、简化样式。
