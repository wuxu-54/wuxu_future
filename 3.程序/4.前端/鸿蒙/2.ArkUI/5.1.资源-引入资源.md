# 资源管理

在HarmonyOS中，资源（如图片、字符串、颜色、布局等）的管理遵循统一的规范，通过结构化目录和配置文件实现多设备适配、资源复用和动态切换（如深色/浅色模式、多语言）。以下是详细的资源配置说明，重点讲解图片等资源的管理方式。

## 一、资源目录结构

HarmonyOS的资源目录位于模块的`src/main/resources`下，采用“基础目录+限定词目录”的结构，方便系统根据设备环境（如屏幕尺寸、语言、主题）自动匹配最合适的资源。

核心目录结构如下：

```txt
resources/
├── base/                 # 基础资源目录（默认使用的资源）
│   ├── media/            # 媒体资源（图片、音频等，重点）
│   ├── string.json       # 字符串资源
│   ├── color.json        # 颜色资源
│   ├── float.json        # 浮点数值资源（如尺寸、间距）
│   ├── int.json          # 整数资源
│   ├── bool.json         # 布尔值资源
│   ├── style.json        # 样式资源
│   └── layout/           # 布局资源（XML布局，较少用于ArkUI）
├── en_US/                # 限定词目录（英文环境资源）
│   └── string.json       # 英文对应的字符串
├── zh_CN/                # 中文环境资源
│   └── string.json       # 中文对应的字符串
├── dark/                 # 深色模式资源
│   ├── color.json        # 深色模式下的颜色
│   └── media/            # 深色模式下的图片
├── hdpi/                 # 高分辨率屏幕资源（图片适配）
│   └── media/
└── rawfile/              # 原始文件（不经过编译处理，如特殊格式文件）
```

## 二、图片资源配置（重点）

图片是最常用的资源类型，HarmonyOS对图片的管理支持多分辨率适配、主题适配等，核心配置如下：

### 1. 图片存放目录

图片资源默认放在`base/media`目录下，支持的格式包括：

- 位图：`png`、`jpg`、`jpeg`（推荐`png`，支持透明通道）
- 矢量图：`svg`（推荐，可无损缩放，适配不同尺寸屏幕）
- 动图：`gif`（仅支持简单动效）

示例：

```txt
resources/
└── base/
    └── media/
        ├── icon.png       # 应用图标
        ├── background.jpg # 背景图
        └── logo.svg       # 矢量图Logo
```

### 2. 多分辨率适配

不同设备屏幕密度不同，可通过“限定词目录”存放不同分辨率的图片，系统会根据设备自动选择：

- `ldpi`：低分辨率（120dpi）
- `mdpi`：中分辨率（160dpi）
- `hdpi`：高分辨率（240dpi）
- `xhdpi`：超高分辨率（320dpi）
- `xxhdpi`：超超高分辨率（480dpi）

示例（同一张图片的不同分辨率版本）：

```txt
resources/
├── base/media/icon.png       # 默认分辨率（若设备无匹配的限定词目录，使用此图）
├── hdpi/media/icon.png       # 高分辨率设备使用
└── xxhdpi/media/icon.png     # 超超高分辨率设备使用
```

### 3. 主题/模式适配

针对深色模式、浅色模式等场景，可通过`dark`/`light`限定词目录存放不同主题的图片：

```txt
resources/
├── base/media/button_bg.png       # 浅色模式下的按钮背景
└── dark/media/button_bg.png       # 深色模式下的按钮背景（颜色更深）
```

### 4. 图片资源的引用方式

在ArkUI组件（如`Image`）中引用图片资源，需使用**资源标识符**，格式有两种：

#### （1）使用`$r`引用（推荐，支持资源索引和适配）

`$r('app.media.资源名')`：`app`表示应用内资源，`media`表示媒体类型，`资源名`为图片文件名（不含后缀）。

示例：

```tsx
// 引用base/media/icon.png
Image($r('app.media.icon'))
  .width(100)
  .height(100)
```

系统会自动根据设备环境（分辨率、主题等）选择对应的图片版本。

#### （2）使用`$rawfile`引用原始图片（不推荐，无适配能力）

若图片放在`rawfile`目录（不经过编译处理），通过`$rawfile('文件名')`引用：

```tsx
// 引用rawfile/banner.png
Image($rawfile('banner.png'))
  .width(300)
```

**注意**：`rawfile`目录下的资源不会被系统优化，也不支持多版本适配，仅用于特殊场景（如第三方SDK依赖的固定格式文件）。

## 三、其他常用资源配置

除图片外，其他资源的配置和引用方式类似：

### 1. 字符串资源（string.json）

用于统一管理文本，方便多语言适配。  
`base/string.json`内容：

```json
{
  "string": [
    {
      "name": "app_name",
      "value": "我的应用"
    },
    {
      "name": "welcome_msg",
      "value": "欢迎使用"
    }
  ]
}
```

引用方式：

```tsx
Text($r('app.string.welcome_msg'))
  .fontSize(16)
```

### 2. 颜色资源（color.json）

统一管理颜色值，方便主题切换。  
`base/color.json`内容：

```json
{
  "color": [
    {
      "name": "text_primary",
      "value": "#FF000000"  // 黑色文本
    },
    {
      "name": "bg_primary",
      "value": "#FFFFFFFF"  // 白色背景
    }
  ]
}
```

引用方式：

```tsx
Text('示例文本')
  .color($r('app.color.text_primary'))
  .backgroundColor($r('app.color.bg_primary'))
```

### 3. 尺寸资源（float.json）

管理间距、字体大小等数值，适配不同屏幕。  
`base/float.json`内容：

```json
{
  "float": [
    {
      "name": "font_size_small",
      "value": 14
    },
    {
      "name": "spacing",
      "value": 20
    }
  ]
}
```

引用方式：

```tsx
Text('小字体文本')
  .fontSize($r('app.float.font_size_small'))
  .margin($r('app.float.spacing'))
```

## 四、资源适配原理

HarmonyOS通过“限定词优先级”自动匹配资源：当设备环境（如语言、分辨率、主题）变化时，系统会从对应的限定词目录中查找资源；若未找到，则回退到`base`目录。

例如：中文（zh_CN）+ 深色模式（dark）的设备，会优先查找：
`zh_CN/dark/media/icon.png` → 若不存在，查找`zh_CN/media/icon.png` → 若不存在，查找`dark/media/icon.png` → 最后使用`base/media/icon.png`。

## 五、注意事项

1. **资源命名规范**：资源名只能包含字母、数字、下划线（`_`），且不能以数字开头（如`icon123`合法，`123icon`不合法）。
2. **矢量图优先**：`svg`格式图片可自适应不同屏幕尺寸，减少多分辨率图片的维护成本，推荐优先使用。
3. **避免资源冗余**：非必要不使用`rawfile`，尽量通过`base`和限定词目录管理资源，利用系统自动适配能力。
4. **资源编译**：`resources`目录下的资源会被编译为二进制格式，提升访问效率；`rawfile`目录下的资源保持原始格式。

通过以上配置，可高效管理鸿蒙应用的各类资源，实现灵活的多设备适配和主题切换，尤其图片资源的多版本管理能显著提升应用在不同设备上的显示效果。
