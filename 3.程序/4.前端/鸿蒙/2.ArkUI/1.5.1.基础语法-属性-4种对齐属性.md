# 4种对齐属性

布局对齐相关的概念。这些属性主要用在**ArkUI框架**的Flex、Column、Row等容器布局中。

## 1. align (在鸿蒙中更多指 Alignment)

**定义**：用于设置组件在父容器中的对齐方式

```typescript
// 在容器中设置所有子组件的整体对齐方式
Column() {
  Text('Hello')
}
.width('100%')
.height('100%')
.align(Alignment.Center) // 子组件在Column中居中对齐

// 或单个组件的对齐
Text('Hello')
  .align(Alignment.TopStart) // 文本在自身空间内左上对齐
```

**常用值**：

- `Alignment.TopStart`、`Alignment.Center`、`Alignment.BottomEnd`等
- 适用于Stack等绝对定位容器

## 2. alignRules (相对布局中的对齐规则)

**定义**：用于**RelativeContainer**相对布局容器，定义组件相对于其他组件或父容器的对齐规则

```typescript
RelativeContainer() {
  Text('Text1')
    .id('t1')
    .alignRules({
      top: { anchor: '__container__', align: VerticalAlign.Top },
      left: { anchor: '__container__', align: HorizontalAlign.Start }
    })
    
  Text('Text2')
    .id('t2')
    .alignRules({
      top: { anchor: 't1', align: VerticalAlign.Bottom },
      center: { anchor: '__container__', align: HorizontalAlign.Center }
    })
}
```

**特点**：

- 只适用于RelativeContainer
- 可以相对于父容器(`__container__`)或其他组件ID
- 支持top、bottom、left、right、center、middle等多个方向的约束

## 3. alignSelf (覆盖容器的默认对齐)

**定义**：允许单个子组件**覆盖**其父容器设置的`alignItems`规则

```typescript
Column({ space: 10 }) {
  Text('Item 1')
    .width('90%')
    .height(50)
    .backgroundColor(Color.Red)
    
  Text('Item 2')
    .width('90%')
    .height(50)
    .backgroundColor(Color.Green)
    .alignSelf(ItemAlign.Start) // 覆盖父容器的Center对齐
    
  Text('Item 3')
    .width('90%')
    .height(50)
    .backgroundColor(Color.Blue)
}
.width('100%')
.height('100%')
.alignItems(HorizontalAlign.Center) // 所有子组件水平居中
```

**常用值**：

- `ItemAlign.Auto` (默认，继承父容器)
- `ItemAlign.Start`
- `ItemAlign.Center`
- `ItemAlign.End`
- `ItemAlign.Stretch` (拉伸)

## 4. alignItems (容器的交叉轴对齐)

**定义**：设置在Flex、Column、Row等容器中**所有子组件**在**交叉轴**上的对齐方式

```typescript
// Column示例：交叉轴是水平轴
Column() {
  Text('Item 1').width('60%').height(50)
  Text('Item 2').width('80%').height(50)
  Text('Item 3').width('40%').height(50)
}
.width('100%')
.alignItems(HorizontalAlign.Start) // 所有子组件在水平方向左对齐

// Row示例：交叉轴是垂直轴
Row() {
  Text('Item 1').width(100).height(30)
  Text('Item 2').width(100).height(50)
  Text('Item 3').width(100).height(70)
}
.height(200)
.alignItems(VerticalAlign.Center) // 所有子组件在垂直方向居中对齐
```

## 核心区别对比

| 属性 | 作用对象 | 适用容器 | 功能描述 |
|------|---------|---------|---------|
| **align** | 单个组件或容器 | 多种容器 | 设置组件在父容器中的对齐位置 |
| **alignRules** | RelativeContainer的子组件 | RelativeContainer | 定义相对于其他组件/父容器的约束规则 |
| **alignSelf** | 容器的单个子组件 | Flex, Column, Row | 覆盖父容器的alignItems设置 |
| **alignItems** | 整个容器 | Flex, Column, Row | 设置所有子组件在交叉轴的对齐方式 |

## 实际应用示例

```typescript
// 综合示例
@Entry
@Component
struct AlignExample {
  build() {
    Column({ space: 20 }) {
      // 1. alignSelf 覆盖示例
      Flex({ direction: FlexDirection.Row, alignItems: ItemAlign.Center }) {
        Text('Left')
          .alignSelf(ItemAlign.Start) // 覆盖为顶部对齐
        
        Text('Center')
          // 使用父容器的Center对齐
        
        Text('Right')
          .alignSelf(ItemAlign.End) // 覆盖为底部对齐
      }
      .height(100)
      .width('100%')
      .backgroundColor(0xF5F5F5)

      // 2. alignItems 容器对齐示例
      Row() {
        Text('A').width(80).height(40)
        Text('B').width(80).height(60)
        Text('C').width(80).height(80)
      }
      .height(200)
      .width('100%')
      .alignItems(VerticalAlign.Center) // 垂直居中
      .backgroundColor(0xE8F4FD)

      // 3. alignRules 相对布局
      RelativeContainer() {
        Text('基准')
          .id('base')
          .alignRules({
            center: { anchor: '__container__', align: HorizontalAlign.Center },
            middle: { anchor: '__container__', align: VerticalAlign.Center }
          })
          
        Text('右上角')
          .id('topRight')
          .alignRules({
            top: { anchor: 'base', align: VerticalAlign.Top },
            right: { anchor: 'base', align: HorizontalAlign.End }
          })
      }
      .width('100%')
      .height(200)
      .backgroundColor(0xFFF0F0)
    }
    .width('100%')
    .height('100%')
    .align(Alignment.Top) // Column在父容器中顶部对齐
  }
}
```

## 记忆技巧

1. **align** - "对齐"：最基础的对齐属性
2. **alignItems** - "项目对齐"：容器内**所有项目**的对齐方式
3. **alignSelf** - "自我对齐"：**自己**决定如何对齐（覆盖父规则）
4. **alignRules** - "对齐规则"：在相对布局中的**约束规则**

## 使用建议

1. 优先使用 **alignItems** 设置容器整体对齐
2. 有特殊需求时使用 **alignSelf** 进行个别调整
3. 复杂相对定位时使用 **alignRules**
4. 简单绝对定位时使用 **align**

掌握这些对齐属性，可以让你在鸿蒙应用开发中实现各种复杂的布局需求！
