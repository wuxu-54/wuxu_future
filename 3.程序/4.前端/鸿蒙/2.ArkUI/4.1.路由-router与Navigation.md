# Router模块和Navigation组件

在鸿蒙（HarmonyOS）应用开发中，ArkUI提供了两种主流的页面路由方案：**Router模块**和**Navigation组件**。为了帮助你快速了解它们的区别，我准备了一个对比表格：

| 特性维度 | Router 模块 | Navigation 组件 |
| :--- | :--- | :--- |
| **核心思想** | **API驱动**，通过方法调用跳转 | **组件声明式**，在UI结构中描述导航 |
| **页面栈管理** | 系统管理，最大32个页面 | 开发者可通过`NavPathStack`更精细控制 |
| **页面配置** | 在 `main_pages.json` 中声明 | 在 `route_map.json` 中配置路由表 |
| **传参方式** | `params` 对象，通过 `router.getParams()` 获取 | `params` 对象，通过 `NavDestinationContext` 获取 |
| **转场动效** | 支持，但动画类型受限 | **强大支持**，可全局或单页面自定义 |
| **一多能力** | 不支持 | **支持**，自适应单栏/双栏显示 |
| **路由拦截** | 不支持 | **支持**，通过 `setInterception` 实现 |
| **推荐场景** | 模块间页面跳转，简单场景 | **模块内页面跳转**，复杂动效和高级路由场景 |

>我的理解：router是从window跳转到另一个window 即对Ability处理，类似Android中的Activity，Navigation是 一个page内，类似Android的Frgment

## 🛠️ Router 模块基础用法

Router通过URL进行页面跳转，适用于简单的页面导航。

1. **导入模块与页面跳转**
    通过 `router.pushUrl()` 或 `router.replaceUrl()` 实现跳转，并可选择实例模式（Standard 或 Single）。

    ```typescript
    import router from '@ohos.router';
    
    // 跳转到详情页，保留当前页
    router.pushUrl({
      url: 'pages/Detail',
      params: { productId: 123, productName: '鸿蒙手机' } // 传递参数
    }, router.RouterMode.Standard, (err) => {
      if (err) {
        console.error(`跳转失败: ${err.code}, ${err.message}`);
        return;
      }
      console.info('跳转成功');
    });
    
    // 替换当前页为登录页，销毁当前页
    router.replaceUrl({
      url: 'pages/Login'
    });
    ```

2. **目标页面接收参数**
    在目标页面的生命周期函数中，使用 `router.getParams()` 获取参数。

    ```typescript
    import router from '@ohos.router';
    
    @Entry
    @Component
    struct Detail {
      // 注意：根据SDK版本，取值方式可能是 router.getParams()['key']
      private productId: number = router.getParams()['productId'];
      private productName: string = router.getParams()['productName'];
    
      onPageShow() {
        // 也可以在onPageShow中获取和处理参数
        const params = router.getParams();
        console.info(`接收到的产品ID: ${params['productId']}`);
      }
    
      build() {
        // ... 页面布局
      }
    }
    ```

3. **页面返回**
    使用 `router.back()` 返回，并可传递参数给上一个页面。

    ```typescript
    // 返回上一页
    router.back();
    
    // 返回到指定页面，并传递参数
    router.back({
      url: 'pages/Home',
      params: { refresh: true }
    });
    ```

## 🧭 Navigation 组件进阶指南

Navigation是ArkUI声明式开发范式中**推荐使用的路由组件**，尤其适用于模块内页面切换，能提供更自然的转场体验。

1. **基本结构与路由配置**
    Navigation的基本结构包含一个导航页（承载`Navigation`组件）和若干子页（`NavDestination`）。首先需要在 `src/main/resources/base/profile/route_map.json` 配置路由表。

    ```json
    // route_map.json
    {
      "routerMap": [
        {
          "name": "DetailPage", // 路由名称
          "pageSourceFile": "src/main/ets/pages/DetailPage.ets", // 页面文件路径
          "buildFunction": "DetailPageBuilder" // 页面构建函数名
        }
      ]
    }
    ```

    同时，在 `module.json5` 文件中关联此路由配置：

    ```json
    {
      "module": {
        "routerMap": "$profile:route_map"
      }
    }
    ```

2. **导航页实现**
    导航页是页面的根容器，需要创建 `NavPathStack` 对象来管理页面栈。

    ```typescript
    import { NavPathStack } from '@ohos.router';
    
    @Entry
    @Component
    struct MainPage {
      private pathStack: NavPathStack = new NavPathStack();
    
      build() {
        Navigation(this.pathStack) {
          // 这里是首页的内容
          Column() {
            Text('首页')
            Button('查看详情')
              .onClick(() => {
                // 跳转到详情页
                this.pathStack.pushPathByName('DetailPage', { productId: 123 });
              })
          }
          .width('100%')
          .height('100%')
        }
        .title('我的应用')
      }
    }
    ```

3. **子页实现**
    子页由 `NavDestination` 组件包裹，通过 `NavDestinationContext` 可以获取传递的参数和操作页面栈。

    ```typescript
    @Builder
    export function DetailPageBuilder() {
      DetailPage()
    }
    
    @Component
    export struct DetailPage {
      private pathStack: NavPathStack = new NavPathStack();
      @State productId: number = 0;
    
      build() {
        NavDestination() {
          Column() {
            Text(`产品ID: ${this.productId}`)
            Button('返回')
              .onClick(() => {
                this.pathStack.pop();
              })
          }
          .width('100%')
          .height('100%')
        }
        .title('详情页')
        .onReady((context: NavDestinationContext) => {
          this.pathStack = context.pathStack;
          // 接收参数
          this.productId = context.params?.['productId'] || 0;
        })
      }
    }
    ```

4. **常见路由操作**
    `NavPathStack` 提供了丰富的方法来操作路由栈：

    ```typescript
    // 跳转
    this.pathStack.pushPathByName('PageName', params);
    // 返回
    this.pathStack.pop();
    // 返回到指定页面
    this.pathStack.popToName('HomePage');
    // 替换当前页
    this.pathStack.replacePath({ name: 'NewPage' });
    // 清空页面栈
    this.pathStack.clear();
    ```

## 💡 选型与迁移建议

- **如何选择**：对于新项目或模块内跳转，**强烈推荐使用Navigation组件**，它能带来更好的用户体验和开发灵活性。如果只是简单的模块间跳转，或者需要保持与旧版本兼容，则可以使用Router模块。

- **从Router迁移到Navigation**：主要变化在于：
  - 页面结构：从多个`@Entry`页面变为一个`@Entry`导航页 + 多个`NavDestination`子页。
  - 配置方式：从 `main_pages.json` 变为 `route_map.json`。
  - 跳转方法：从 `router.pushUrl()` 变为 `pathStack.pushPathByName()`。
