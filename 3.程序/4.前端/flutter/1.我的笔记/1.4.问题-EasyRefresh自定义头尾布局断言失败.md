# 错题 ：EasyRefresh 自定义 Header/Footer 时断言失败（Cannot scroll indefinitely when clamping）

- **报错现象**：

  ```
  Cannot scroll indefinitely when clamping.
  'package:easy_refresh/src/indicator/indicator.dart':
  Failed assertion: line 405 pos 16: 'infiniteOffset == null || !clamping'
  ```

- **错误代码**：

  ```dart
  class MyCustomHeader extends Header {
    const MyCustomHeader({
      super.triggerOffset = 70.0,
      super.clamping = true,          // 钳制边界
      super.infiniteOffset = 100.0,   // ❌ 又设置了无限偏移（冲突！）
    });
  }
  ```

- **根本原因**：
  - `clamping`（边界钳制）和 `infiniteOffset`（无限偏移）是**互斥属性**，不能同时启用。
  - `clamping: true` 表示列表滚动到边界后**无法继续拖拽**（无弹性效果）。
  - `infiniteOffset` 表示允许列表**无限滚动**（即使未加载完也能持续触发加载）。
  - 两者语义矛盾：既然边界被钳制了，就不存在“无限滚动”的可能。框架通过断言 `infiniteOffset == null || !clamping` 强制约束这一逻辑。

- **正确写法**：
  - **方案 A**：保留 `clamping: true`，移除 `infiniteOffset`（保持 null）

    ```dart
    class MyCustomHeader extends Header {
      const MyCustomHeader({
        super.triggerOffset = 70.0,
        super.clamping = true,   // 保留钳制
        // 不传 infiniteOffset，保持 null
      });
    }
    ```

  - **方案 B**：保留 `infiniteOffset`，将 `clamping` 改为 `false`

    ```dart
    class MyCustomHeader extends Header {
      const MyCustomHeader({
        super.triggerOffset = 70.0,
        super.clamping = false,        // 允许弹性
        super.infiniteOffset = 100.0,  // 允许无限偏移
      });
    }
    ```

  - **方案 C（最推荐）**：使用默认值，什么都不传（默认 `clamping: false`，`infiniteOffset: null`）

    ```dart
    class MyCustomHeader extends Header {
      const MyCustomHeader({
        super.triggerOffset = 70.0,
        // clamping 默认 false
        // infiniteOffset 默认 null
      });
    }
    ```
