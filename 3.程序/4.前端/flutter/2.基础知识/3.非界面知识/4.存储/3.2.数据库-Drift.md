# Drift

Drift（原Moor）是一个建立在SQLite之上的**响应式、类型安全**的持久化库。它的核心API主要分为三个层次，由高到低提供了不同的灵活性和控制力。

## 🏗️ 三层 API 架构

### 1. Manager API（最高层，最易用）

这是Drift中最**符合直觉、代码最简洁**的API。使用前，需要先通过`db.managers`获取Manager对象。

* **Create (创建)**：
  * `create()`: 插入单条记录，返回生成ID。
  * `createReturning()`: 插入并返回完整记录。
  * `bulkCreate()`: 批量插入多条记录。
* **Read (读取)**：
  * `get()`: 获取所有匹配记录列表。
  * `getSingle()` / `getSingleOrNull()`: 获取单条记录。
  * `watch()`: 创建**响应式Stream**，数据变更时自动更新。
  * `count()` / `exists()`: 计数或检查记录是否存在。
* **Update (更新)**：
  * `update()`: 更新所有匹配的记录。
  * `replace()`: 根据主键替换整个记录。
* **Delete (删除)**：
  * `delete()`: 删除所有匹配的记录。

### 2. Statement-Based API（中间层，最常用）

这是Drift**最核心、最常用**的API，通过生成的DAO（数据访问对象）类进行操作，在类型安全和灵活性之间取得了很好的平衡。

* **Insert (插入)**：通过 `into(table).insert()` 系列方法操作。
  * `insert()`: 插入数据。
  * `insertReturning()`: 插入并返回记录。
  * `insertOnConflictUpdate()`: 插入时处理冲突。
* **Update (更新)**：通过 `update(table)` 方法链式操作。
  * `write()`: 更新匹配的记录。
  * `replace()`: 替换整个记录。
  * `where()`: 添加过滤条件。
* **Select (查询)**：这是Drift**响应式能力的核心**。
  * `get()`: 执行查询，返回当前结果列表。
  * `watch()`: 执行查询并返回一个**Stream**，当表数据变化时，Stream会自动发出新结果。
  * `where()` / `orderBy()` / `limit()`: 添加查询条件、排序和限制。
* **Delete (删除)**：通过 `delete(table)` 方法链操作。
  * `go()`: 执行删除操作。
  * `where()`: 指定删除条件。

### 3. Low-Level API（最底层，最灵活）

当需要执行复杂SQL或Drift未覆盖的操作时，可以使用底层API直接执行SQL语句。

* `customInsert()`: 执行自定义`INSERT`语句。
* `customUpdate()`: 执行自定义`UPDATE`或`DELETE`语句。
* `customSelect()`: 执行自定义`SELECT`查询。
* `customStatement()`: 执行任何SQL语句。
* `batch()`: 批量执行多个操作，确保原子性并提升性能。

## 🚀 如何使用 Drift (核心流程)

### 第一步：添加依赖

在你的 `pubspec.yaml` 文件中添加以下依赖:

```yaml
dependencies:
  drift: ^2.30.0
  drift_flutter: ^0.2.8
  path_provider: ^2.1.5

dev_dependencies:
  drift_dev: ^2.30.0
  build_runner: ^2.10.4
```

### 第二步：定义表结构

创建一个类继承 `Table`，定义你的数据模型。

```dart
import 'package:drift/drift.dart';

// 1. 定义表
class Todos extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get title => text()();
  TextColumn get content => text().nullable()();
  BoolColumn get isCompleted => boolean().withDefault(const Constant(false))();
}
```

### 第三步：创建数据库

创建一个继承 `_$AppDatabase` 的类，并注解 `@DriftDatabase`。

```dart
import 'package:drift/drift.dart';
import 'package:drift_flutter/drift_flutter.dart';

// 2. 创建数据库类
@DriftDatabase(tables: [Todos])
class AppDatabase extends _$AppDatabase {
  // 用于单元测试的构造方法
  AppDatabase(QueryExecutor e) : super(e);

  // 生产环境使用的默认构造方法
  AppDatabase.defaults()
      : super(driftDatabase(
          name: 'app_db', // 数据库文件名
        ));

  @override
  int get schemaVersion => 1; // 数据库版本号，用于迁移
}
```

### 第四步：运行代码生成器

在终端执行以下命令，生成必要的代码:

```bash
dart run build_runner build
```

### 第五步：执行 CRUD 操作

现在你可以在代码中使用生成的 API 了。

```dart
// 获取数据库实例
final db = AppDatabase.defaults();

// 1. 插入数据
Future<int> addTodo(String title, String content) async {
  return await db.into(db.todos).insert(
    TodosCompanion(
      title: Value(title),
      content: Value(content),
    ),
  );
}

// 2. 查询并响应式监听数据
Stream<List<Todo>> watchAllTodos() {
  return db.select(db.todos).watch();
}

// 3. 更新数据（使用 where 条件）
Future<int> markAsCompleted(int id) async {
  return await (db.update(db.todos)..where((t) => t.id.equals(id)))
      .write(TodosCompanion(isCompleted: Value(true)));
}

// 4. 删除数据
Future<int> deleteTodo(int id) async {
  return await (db.delete(db.todos)..where((t) => t.id.equals(id))).go();
}
```

### 第六步：在 Flutter UI 中使用

结合 `StreamBuilder` 和 `watch()` 方法，可以轻松实现响应式 UI。

```dart
StreamBuilder<List<Todo>>(
  stream: db.watchAllTodos(),
  builder: (context, snapshot) {
    final todos = snapshot.data ?? [];
    return ListView.builder(
      itemCount: todos.length,
      itemBuilder: (context, index) {
        final todo = todos[index];
        return ListTile(
          title: Text(todo.title),
          trailing: Checkbox(
            value: todo.isCompleted,
            onChanged: (_) => db.markAsCompleted(todo.id),
          ),
        );
      },
    );
  },
);
```

## 💎 总结

| API 层级 | 核心方法 | 适用场景 |
| :--- | :--- | :--- |
| **Manager API** | `create`, `get`, `update`, `delete` | 简单的CRUD，追求最简洁的代码 |
| **Statement-Based API** | `insert`, `select`, `update`, `delete` | **日常开发中最常用**，平衡了类型安全和灵活性 |
| **Low-Level API** | `customSelect`, `customUpdate`, `batch` | 执行复杂SQL、批量操作等高级需求 |

## ⚠️ 特别提醒

在使用`update`或`delete`操作时，**如果没有明确指定`where`条件，该语句将影响表中的所有行**。务必谨慎操作，避免数据意外丢失。

总的来说，Drift通过这三层API设计，让你可以从易用的高级API开始，在需要时平滑地下沉到更灵活的底层API，既保证了开发效率，也提供了强大的能力。

建议你查阅官方的[Drift文档](https://drift.simonbinder.eu/)以获取更详细的信息。
