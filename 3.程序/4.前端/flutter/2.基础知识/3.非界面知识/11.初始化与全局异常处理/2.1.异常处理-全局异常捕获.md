# Flutter 全局异常捕获处理完全指南

## 一、Flutter 异常分类

Flutter 中的异常按来源可分为以下几类：

| 异常类型 | 来源 | 捕获方式 |
| --- | --- | --- |
| **Dart 同步异常** | 业务代码中 throw | `try-catch` / `runZonedGuarded` |
| **Dart 异步异常** | Future/Stream/Timer 等 | `runZonedGuarded` |
| **Flutter 框架异常** | build/layout/render 阶段 | `FlutterError.onError` |
| **平台层异常** | 原生代码(Android/iOS) | 原生侧捕获 |
| **Isolate 异常** | 其他 Isolate | `Isolate.addErrorListener` |

---

## 二、各层异常捕获详解

### 2.1 Dart 层面：`runZonedGuarded`

捕获 Dart 代码中的同步和异步异常。

```
import 'dart:async';

void main() {
  runZonedGuarded(() {
    WidgetsFlutterBinding.ensureInitialized();
    runApp(const MyApp());
  }, (Object error, StackTrace stackTrace) {
    // 捕获所有未处理的同步 + 异步异常
    _handleError('ZoneError', error, stackTrace);
  });
}
```

**能捕获：**

- ✅ `throw 'error'`（同步异常）
- ✅ `Future.error(...)`（未 catch 的 Future）
- ✅ `Timer` 回调中的异常
- ✅ `Stream` 中的异常
- ✅ `async` 函数中的异常

**不能捕获：**

- ❌ Flutter 框架构建异常
- ❌ 其他 Isolate 的异常
- ❌ 原生平台的崩溃

---

### 2.2 Flutter 框架层面：`FlutterError.onError`

捕获 Flutter 框架在构建、布局、渲染过程中产生的错误。

```
FlutterError.onError = (FlutterErrorDetails details) {
  // 开发环境：打印详细信息到控制台
  if (kDebugMode) {
    FlutterError.dumpErrorToConsole(details);
  }
  
  // 统一上报
  _handleError('FlutterError', details.exception, details.stack);
};
```

**常见触发场景：**

- Widget `build` 方法抛出异常
- 布局约束错误（如 overflow）
- 渲染错误
- 断言失败（debug 模式）
- 图片加载失败

**`FlutterErrorDetails` 关键属性：**

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `exception` | `Object` | 异常对象 |
| `stack` | `StackTrace?` | 堆栈信息 |
| `context` | `DiagnosticsNode?` | 错误上下文（哪个组件出错） |
| `library` | `String` | 出错的库 |
| `informationCollector` | `InformationCollector?` | 额外信息收集器 |
| `silent` | `bool` | 是否为静默错误（不打印） |

---

### 2.3 平台调度器：`PlatformDispatcher.instance.onError`

Flutter 3.3+ 新增，捕获平台层面的错误（如原生回调、插件回调等）。

```
import 'dart:ui';

PlatformDispatcher.instance.onError = (Object error, StackTrace stack) {
  _handleError('PlatformError', error, stack);
  return true; // 返回 true 表示已处理
};
```

>
> **注意**：返回 `true` 表示错误已被处理，不会再向上传播；返回 `false` 则会继续传播。

### 2.5 Isolate 异常捕获

其他 Isolate 中的异常不会被主 Isolate 的 Zone 捕获，需要单独处理。

```
// 方式1：使用 Isolate.addErrorListener
Isolate.spawn(worker, message).then((isolate) {
  isolate.addErrorListener(RawReceivePort((error) {
    final errorMessage = error[0] as String;
    final stackTrace = error[1] as String;
    _handleError('IsolateError', errorMessage, StackTrace.fromString(stackTrace));
  }).sendPort);
});

// 方式2：使用 compute 时包裹 try-catch
Future<T> safeCompute<T>(ComputeCallback<T> callback, message) async {
  try {
    return await compute(callback, message);
  } catch (e, stack) {
    _handleError('ComputeError', e, stack);
    rethrow;
  }
}
```

### 2.7 异步异常的其他捕获方式

#### Future 的 catchError

```
fetchData()
    .then((data) => process(data))
    .catchError((error, stack) {
      print('捕获异常: $error');
      return defaultValue;
    });
```

#### Stream 的 handleError

```
stream.listen(
  (data) => print(data),
  onError: (error, stack) {
    print('Stream 错误: $error');
  },
  onDone: () => print('完成'),
);
```

#### async/await 的 try-catch

```
Future<void> loadData() async {
  try {
    final data = await fetchData();
    await process(data);
  } catch (e, stack) {
    print('捕获异常: $e');
  }
}
```

## 四、错误分级与策略

### 4.1 错误分级

| 级别 | 类型 | 处理策略 |
| --- | --- | --- |
| **致命错误** | 崩溃、白屏 | 上报 + 提示用户 + 重启/降级 |
| **严重错误** | 页面崩溃、功能不可用 | 上报 + 错误页 + 重试 |
| **一般错误** | 接口失败、数据异常 | 上报 + Toast 提示 |
| **轻微错误** | 图片加载失败、非核心功能 | 静默上报 + 降级显示 |

### 4.2 分级处理实现

```
class ErrorLevelHandler {
  static void handleError(ErrorInfo info) {
    switch (info.type) {
      case ErrorType.flutter:
        _handleFlutterError(info);
        break;
      case ErrorType.zone:
        _handleZoneError(info);
        break;
      case ErrorType.platform:
        _handlePlatformError(info);
        break;
      default:
        _handleGeneralError(info);
    }
  }

  /// Flutter 框架错误（页面级别）
  static void _handleFlutterError(ErrorInfo info) {
    // 上报
    _report(info);
    
    // 如果是 build 错误，ErrorWidget.builder 已经处理了 UI
    // 这里可以做额外的处理
  }

  /// Zone 异步错误（业务级别）
  static void _handleZoneError(ErrorInfo info) {
    _report(info);
    
    // 根据错误类型做不同处理
    if (info.error is NetworkError) {
      _showToast('网络异常，请检查网络连接');
    } else if (info.error is AuthError) {
      _redirectToLogin();
    }
  }

  /// 平台错误（严重级别）
  static void _handlePlatformError(ErrorInfo info) {
    _report(info);
    // 可能需要重启 App
  }

  /// 通用错误处理
  static void _handleGeneralError(ErrorInfo info) {
    _report(info);
  }

  static void _report(ErrorInfo info) {
    // 统一上报
  }

  static void _showToast(String msg) {
    // 显示 Toast
  }

  static void _redirectToLogin() {
    // 跳转到登录页
  }
}
```

```
  // 手机号脱敏
  errorMsg = errorMsg.replaceAllMapped(
    RegExp(r'1[3-9]\d{9}'),
    (m) => '${m.group(0)!.substring(0, 3)}****${m.group(0)!.substring(7)}',

  // 身份证脱敏

  );
  
  return errorMsg;
}
```

### 6.3 错误去重与限流

避免同一错误频繁上报：

```
class ErrorDeduplicator {
  static final Map<String, DateTime> _recentErrors = {};
  static const _minInterval = Duration(minutes: 5);

  static bool shouldReport(String errorKey) {
    final now = DateTime.now();
    final lastTime = _recentErrors[errorKey];
    
    if (lastTime != null && now.difference(lastTime) < _minInterval) {
      return false; // 太频繁，跳过
    }
    
    _recentErrors[errorKey] = now;
    
    // 清理过期记录
    _recentErrors.removeWhere((_, time) => 
      now.difference(time) > const Duration(hours: 1)
    );
    
    return true;
  }
}
```

## 八、总结

| 捕获方式 | 捕获范围 | 优先级 |
| --- | --- | --- |
| `runZonedGuarded` | Dart 同步 + 异步异常 | ⭐⭐⭐⭐⭐ 必须 |
| `FlutterError.onError` | Flutter 框架构建/布局/渲染错误 | ⭐⭐⭐⭐⭐ 必须 |
| `PlatformDispatcher.instance.onError` | 平台调度器错误 | ⭐⭐⭐⭐ 推荐 |
| `ErrorWidget.builder` | 自定义错误页面 | ⭐⭐⭐⭐ 推荐 |
| `Isolate.addErrorListener` | 其他 Isolate 错误 | ⭐⭐⭐ 按需 |
| `Image.errorBuilder` | 图片加载失败 | ⭐⭐⭐ 按需 |
| `try-catch` / `catchError` | 局部异常处理 | ⭐⭐⭐⭐⭐ 必须 |

**核心原则：**
