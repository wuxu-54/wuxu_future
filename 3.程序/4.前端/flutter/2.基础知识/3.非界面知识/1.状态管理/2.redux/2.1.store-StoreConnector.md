# StoreConnector

在 Flutter 中，`StoreConnector` 是 `flutter_redux` 库提供的核心组件，用于将 Redux 的全局状态（Store）与 UI 组件高效连接。

>**StoreConnector ≈ Redux 版的 Selector**。

---

## **核心作用**

1. **状态与UI解耦**  
   将 Redux Store 中的状态转换为 UI 所需的 ViewModel，并自动响应状态变化，触发 UI 更新。

2. **性能优化**  
   通过 `distinct` 参数避免不必要的重建，仅在 ViewModel 变化时更新组件。

---

## **主要参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| `converter` | `Store<State> → ViewModel` | 将 Store 转换为 ViewModel（含数据和方法） |
| `builder` | `(BuildContext, ViewModel) → Widget` | 根据 ViewModel 构建 UI |
| `distinct` | `bool` (默认 `true`) | 是否仅在 ViewModel 变化时重建 |

它是一个双泛型组件：

- 第一个泛型 `S`：全局 Store 的完整状态类型（如 `AppState`）
- 第二个泛型 `ViewModel`：UI 实际需要的数据模型

两个核心回调：

- `converter`：转换函数，输入完整 Store，输出 UI 需要的 ViewModel（等价于 Selector 的 `selector` 参数）
- `builder`：构建函数，输入上下文和 ViewModel，输出 Widget（等价于 Selector 的 `builder` 参数）

### 基础示例

```
// 全局状态（Redux 仓库）
class AppState {
  final int count;
  final String userName;
  AppState(this.count, this.userName);
}

// 纯展示组件：完全不知道 Redux 的存在，只接收参数
class CounterText extends StatelessWidget {
  final int count;
  const CounterText({super.key, required this.count});

  @override
  Widget build(BuildContext context) {
    Text('计数：$count', style: const TextStyle(fontSize: 32));
  }
}

// 连接器：把全局状态和纯UI组件连接起来
StoreConnector<AppState, int>(
  // 从完整仓库中筛选出组件只需要的 count
  converter: (Store<AppState> store) => store.state.count,
  
  // 只有 count 发生变化时，builder 才会重新执行
  builder: (BuildContext context, int count) {
    return CounterText(count: count);
  },
)
```

### 标准 ViewModel 写法

工程中通常会封装独立的 ViewModel 类，同时承载数据和操作回调：

```
// ViewModel：UI 层需要的所有数据和交互方法
class _CounterViewModel {
  final int count;
  final VoidCallback onIncrement;
  _CounterViewModel({required this.count, required this.onIncrement});
}

StoreConnector<AppState, _CounterViewModel>(
  converter: (Store<AppState> store) {
    return _CounterViewModel(
      count: store.state.count,
      // 把 dispatch 动作封装成回调，UI 层不用感知 Action
      onIncrement: () => store.dispatch(IncrementAction()),
    );
  },
  builder: (context, viewModel) {
    return Column(
      children: [
        Text('计数：${viewModel.count}'),
        ElevatedButton(
          onPressed: viewModel.onIncrement,
          child: const Text('+1'),
        ),
      ],
    );
  },
)
```

## 底层工作原理

1. 内部通过 `StoreProvider.of(context)` 向上查找 Widget 树中顶层注入的 Redux Store。
2. 初始化时执行 `converter` 得到初始 ViewModel。
3. 订阅 Store 的状态变更事件，每次全局状态更新时，重新执行 `converter` 生成新的 ViewModel。
4. 对比新旧 ViewModel 是否相等（可通过 `distinct: true` 开启严格判等优化），不相等则触发 `builder` 重建子组件。
5. 整个过程和 Provider 的 Selector 完全同源：全量状态通知 → 筛选转换 → 判等过滤 → 局部刷新。

## **代码示例**

```dart
import 'package:flutter/material.dart';
import 'package:flutter_redux/flutter_redux.dart';
import 'package:redux/redux.dart';

// 状态类
class AppState {
  final int count;
  AppState({required this.count});
}

// Action
class IncrementAction {}

// Reducer
AppState reducer(AppState state, dynamic action) {
  if (action is IncrementAction) {
    return AppState(count: state.count + 1);
  }
  return state;
}

// ViewModel
class CounterViewModel {
  final int count;
  final Function() onIncrement;

  CounterViewModel({
    required this.count,
    required this.onIncrement,
  });

  // 实现相等性比较（或用 equatable 简化）
  @override
  bool operator ==(Object other) =>
      identical(this, other) ||
      other is CounterViewModel &&
          runtimeType == other.runtimeType &&
          count == other.count;

  @override
  int get hashCode => count.hashCode;
}

void main() {
  final store = Store<AppState>(
    reducer,
    initialState: AppState(count: 0),
  );

  runApp(StoreProvider<AppState>(
    store: store,
    child: MaterialApp(
      home: CounterScreen(),
    ),
  ));
}

class CounterScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Redux Counter')),
      body: StoreConnector<AppState, CounterViewModel>(
        converter: (store) => CounterViewModel(
          count: store.state.count,
          onIncrement: () => store.dispatch(IncrementAction()),
        ),
        builder: (context, viewModel) => Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Text('Count: ${viewModel.count}'),
              ElevatedButton(
                onPressed: viewModel.onIncrement,
                child: Text('Increment'),
              ),
            ],
          ),
        ),
        distinct: true, // 仅当 count 变化时重建
      ),
    );
  }
}
```

## **最佳实践**

1. **保持 ViewModel 轻量**  
   仅包含 UI 所需的数据和方法，避免冗余数据触发重建。

2. **不可变状态**  
   使用不可变对象（如 `equatable`）简化相等性比较，确保 `distinct` 正确判断。

3. **选择性重建**  
   将大组件拆分为多个 `StoreConnector`，仅关键部分响应状态变化，提升性能。

---

通过 `StoreConnector`，你可以高效管理 Flutter 应用的状态，确保 UI 与数据层清晰分离，同时保持流畅的性能表现。
