# Flutter EasyRefresh 完整用法（3.x 新版）

`easy_refresh` 是 Flutter 生态中成熟的下拉刷新、上拉加载更多框架，支持几乎所有可滚动组件（`ListView`、`GridView`、`CustomScrollView` 等），内置多套风格指示器，支持高度自定义交互与动画。

>
> 注意：目前主流维护版本为 **3.x 系列**（包名 `easy_refresh`），旧版 `flutter_easyrefresh` 已停止更新，下文均基于新版 `easy_refresh` 讲解。

## 一、引入依赖

### 1. pubspec.yaml 中添加依赖

```
dependencies:
  flutter:
    sdk: flutter
  # 下拉刷新上拉加载，可去 pub.dev 查看最新稳定版
  easy_refresh: ^3.4.0
```

执行 `flutter pub get` 完成安装。

### 2. 导包

```
import 'package:easy_refresh/easy_refresh.dart';
```

## 二、基础用法

### 2.1 最简下拉刷新

仅需包裹可滚动组件，实现 `onRefresh` 回调即可，回调执行完成后自动收起指示器：

```
EasyRefresh(
  onRefresh: () async {
    // 执行刷新逻辑，如网络请求、数据重置
    await Future.delayed(const Duration(seconds: 1));
  },
  child: ListView.builder(
    itemCount: 20,
    itemBuilder: (context, index) => ListTile(title: Text("列表项 $index")),
  ),
)
```

### 2.2 下拉刷新 + 上拉加载更多（标准业务写法）

通过回调返回 `IndicatorResult` 控制状态，无需手动控制器，是最简洁的业务实现方式：

```
class ListPage extends StatefulWidget {
  const ListPage({super.key});

  @override
  State<ListPage> createState() => _ListPageState();
}

class _ListPageState extends State<ListPage> {
  List<String> dataList = [];
  int currentPage = 1;
  static const int pageSize = 10;

  @override
  void initState() {
    super.initState();
    // 进入页面首次加载数据
    _loadData(isRefresh: true);
  }

  /// 加载数据
  Future<void> _loadData({required bool isRefresh}) async {
    if (isRefresh) currentPage = 1;
    // 模拟网络请求
    await Future.delayed(const Duration(seconds: 1));
    // 生成分页模拟数据
    List<String> newData = List.generate(
      pageSize,
      (index) => "数据 ${(currentPage - 1) * pageSize + index + 1}",
    );

    setState(() {
      if (isRefresh) {
        dataList = newData;
      } else {
        dataList.addAll(newData);
      }
      currentPage++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("列表刷新")),
      body: EasyRefresh(
        // 下拉刷新回调
        onRefresh: () async {
          await _loadData(isRefresh: true);
          return IndicatorResult.success;
        },
        // 上拉加载回调
        onLoad: () async {
          await _loadData(isRefresh: false);
          // 模拟：第3页后没有更多数据
          if (currentPage > 3) {
            return IndicatorResult.noMore;
          }
          return IndicatorResult.success;
        },
        child: ListView.builder(
          itemCount: dataList.length,
          itemBuilder: (context, index) => ListTile(title: Text(dataList[index])),
        ),
      ),
    );
  }
}
```

`IndicatorResult` 常用状态：

- `success`：加载成功
- `fail`：加载失败
- `noMore`：无更多数据（加载更多功能禁用）
- `none`：无状态变更

## 三、控制器 EasyRefreshController

如果需要**手动触发刷新/加载**、**精细化控制结束状态**，使用 `EasyRefreshController`。

### 3.1 初始化与核心方法

```
// 初始化控制器
final EasyRefreshController _controller = EasyRefreshController(
  // 开启手动控制刷新结束：需主动调用 finishRefresh 才会收起
  controlFinishRefresh: true,
  // 开启手动控制加载结束：需主动调用 finishLoad 才会收起
  controlFinishLoad: true,
);

// 核心 API
_controller.callRefresh();       // 手动触发下拉刷新
_controller.callLoad();          // 手动触发上拉加载
_controller.finishRefresh();     // 结束刷新（controlFinishRefresh=true 时生效）
_controller.finishLoad(IndicatorResult.success); // 结束加载并指定结果
_controller.resetFooter();       // 重置加载更多状态（刷新后调用，解除 noMore）
_controller.dispose();           // 页面销毁时释放资源
```

### 3.2 完整示例（手动控制结束）

```
class ControllerDemo extends StatefulWidget {
  const ControllerDemo({super.key});

  @override
  State<ControllerDemo> createState() => _ControllerDemoState();
}

class _ControllerDemoState extends State<ControllerDemo> {
  final EasyRefreshController _controller = EasyRefreshController(
    controlFinishRefresh: true,
    controlFinishLoad: true,
  );
  int _itemCount = 10;

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text("控制器用法"),
        actions: [
          IconButton(
            icon: const Icon(Icons.refresh),
            onPressed: () => _controller.callRefresh(), // 点击按钮触发刷新
          ),
        ],
      ),
      body: EasyRefresh(
        controller: _controller,
        onRefresh: () async {
          await Future.delayed(const Duration(seconds: 1));
          if (!mounted) return;
          setState(() => _itemCount = 10);
          // 手动结束刷新
          _controller.finishRefresh();
          // 重置加载更多状态，恢复可加载
          _controller.resetFooter();
        },
        onLoad: () async {
          await Future.delayed(const Duration(seconds: 1));
          if (!mounted) return;
          setState(() => _itemCount += 5);
          // 手动结束加载，超过20条标记无更多
          _controller.finishLoad(
            _itemCount >= 20 ? IndicatorResult.noMore : IndicatorResult.success,
          );
        },
        child: ListView.builder(
          itemCount: _itemCount,
          itemBuilder: (context, index) => ListTile(title: Text("条目 $index")),
        ),
      ),
    );
  }
}
```

## 四、内置指示器样式

`easy_refresh` 内置了多种风格的头部/尾部指示器，直接替换 `header` / `footer` 参数即可切换：

| 指示器组件 | 风格说明 |
| --- | --- |
| `ClassicHeader` / `ClassicFooter` | 默认经典样式，带下拉提示、刷新状态文字 |
| `MaterialHeader` / `MaterialFooter` | Material Design 风格，接近安卓原生刷新效果 |
| `CupertinoHeader` / `CupertinoFooter` | iOS 系统风格，仿原生下拉刷新 |
| `BezierHeader` / `BezierFooter` | 贝塞尔曲线回弹动效样式 |

使用示例：

```
EasyRefresh(
  header: const MaterialHeader(), // 安卓风格刷新头
  footer: const ClassicFooter(),  // 经典加载更多尾部
  // ... 其他参数
)
```

## 五、常用配置参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `enableRefresh` | `bool` | 是否启用下拉刷新，默认 `true` |
| `enableLoad` | `bool` | 是否启用上拉加载，默认 `true` |
| `refreshOnStart` | `bool` | 页面初始化时自动触发一次刷新，默认 `false` |
| `header` / `footer` | `Header` / `Footer` | 刷新/加载指示器组件 |
| `onRefresh` / `onLoad` | `Future<IndicatorResult> Function()` | 刷新/加载回调 |
| `controller` | `EasyRefreshController` | 交互控制器 |
| `clipBehavior` | `Clip` | 边缘裁剪行为，默认 `Clip.hardEdge` |

## 六、自定义指示器

如果内置样式不满足需求，官方推荐使用 `BuilderHeader` / `BuilderFooter` 快速自定义，无需继承复杂基类，直接通过 builder 构建 UI。

### 示例：自定义下拉刷新头

```
EasyRefresh(
  header: BuilderHeader(
    triggerOffset: 70, // 触发刷新的最小下拉距离
    clamping: true,
    position: IndicatorPosition.above,
    builder: (context, state) {
      return Container(
        height: state.offset,
        alignment: Alignment.center,
        child: state.mode == IndicatorMode.processing
            ? const CircularProgressIndicator(strokeWidth: 2)
            : const Icon(Icons.arrow_downward, color: Colors.grey),
      );
    },
  ),
  // ... 其他配置
)
```

- `state.offset`：当前下拉偏移量，可用于做跟手动画
- `state.mode`：指示器当前状态（拖拽中、刷新中、完成等）

## 七、配合 CustomScrollView 使用

针对 `Sliver` 布局，使用 `EasyRefresh.custom` 构造，配合 `HeaderLocator.sliver()` / `FooterLocator.sliver()` 嵌入 Sliver 树：

```
EasyRefresh.custom(
  onRefresh: () async { ... },
  onLoad: () async { ... },
  slivers: [
    const SliverAppBar(title: Text("Sliver 列表刷新")),
    const HeaderLocator.sliver(), // 刷新头占位
    SliverList.builder(
      itemCount: 20,
      itemBuilder: (context, index) => ListTile(title: Text("Sliver 项 $index")),
    ),
    const FooterLocator.sliver(), // 加载尾占位
  ],
)
```

## 八、常见问题与踩坑

1. **上拉加载不触发？**
   - 子组件必须是可滚动 Widget（`ListView`、`GridView` 等），普通容器无法触发滚动加载。
   - 列表内容必须超出屏幕高度，内容不足一屏时默认不会触发上拉加载。
2. **刷新后“没有更多”状态不恢复？**
下拉刷新成功后，必须调用 `_controller.resetFooter()` 重置加载更多状态，否则会一直保持 `noMore` 禁用状态。
3. **进入页面自动执行刷新？**
直接设置 `refreshOnStart: true` 即可，无需在 `initState` 中手动调用。
4. **列表滚动物理效果冲突？**
使用 `EasyRefresh.builder` 构造，通过 `childBuilder` 将框架内部的 `physics` 传递给子列表：

```
EasyRefresh.builder(
  onRefresh: () async { ... },
  childBuilder: (context, physics) {
    return ListView(physics: physics, ...);
  },
)
```

5. **内存泄漏风险**
页面销毁时必须调用 `_controller.dispose()` 释放控制器资源。
