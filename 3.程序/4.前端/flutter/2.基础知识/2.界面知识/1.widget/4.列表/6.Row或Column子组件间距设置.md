# Row / Column 设置子组件间距的完整方案

## 一、方式总览

| 方式 | 适用场景 | 推荐度 |
| --- | --- | --- |
| `SizedBox` | 固定间距，精确控制 | ⭐⭐⭐⭐⭐ 最常用 |
| `Spacer` | 自动填充剩余空间 | ⭐⭐⭐⭐ |
| `Padding` | 单个组件周围留白 | ⭐⭐⭐⭐ |
| `MainAxisAlignment` | 均匀分布 | ⭐⭐⭐ |
| `Wrap` + `spacing` | 自动换行 + 间距 | ⭐⭐⭐ |
| 自定义扩展 | 批量设置间距 | ⭐⭐⭐ |

---

## 二、SizedBox（最推荐）

### 2.1 基本用法

在两个子组件之间插入 `SizedBox`：

```
// Row 水平间距
Row(
  children: [
    Text('左边'),
    SizedBox(width: 16),  // 水平间距
    Text('右边'),
  ],
)

// Column 垂直间距
Column(
  children: [
    Text('上面'),
    SizedBox(height: 16),  // 垂直间距
    Text('下面'),
  ],
)
```

### 2.2 多个子组件

```
Column(
  children: [
    Text('第一项'),
    SizedBox(height: 12),
    Text('第二项'),
    SizedBox(height: 12),
    Text('第三项'),
    SizedBox(height: 12),
    Text('第四项'),
  ],
)
```

### 2.3 优点

- ✅ **精确控制**：想设多少就设多少
- ✅ **灵活**：不同位置可以有不同间距
- ✅ **直观**：一眼就能看到间距在哪里
- ✅ **零开销**：SizedBox 是最轻量的组件

## 三、Spacer（自动填充）

### 3.1 基本用法

`Spacer` 会自动填充剩余空间，适合做弹性布局：

```
Row(
  children: [
    Text('左对齐'),
    Spacer(),  // 填充中间所有空间
    Text('右对齐'),
  ],
)
```

### 3.2 按比例分配

```
Row(
  children: [
    Text('左'),
    Spacer(flex: 1),  // 占 1 份
    Text('中'),
    Spacer(flex: 2),  // 占 2 份
    Text('右'),
  ],
)
// 左 和 中 之间的间距是 1 份
// 中 和 右 之间的间距是 2 份
```

### 3.3 适用场景

```
// 场景：左右两端对齐
Row(
  children: [
    Text('标题'),
    Spacer(),
    TextButton(onPressed: () {}, child: Text('更多')),
  ],
)

// 场景：底部按钮，一个左一个右
Row(
  children: [
    OutlinedButton(onPressed: () {}, child: Text('取消')),
    Spacer(),
    ElevatedButton(onPressed: () {}, child: Text('确定')),
  ],
)
```

## 四、Padding（单个组件留白）

### 4.1 基本用法

给某个子组件单独设置 padding：

```
Row(
  children: [
    Text('左边'),
    Padding(
      padding: EdgeInsets.symmetric(horizontal: 16),
      child: Text('中间'),  // 左右各 16px
    ),
    Text('右边'),
  ],
)
```

### 4.2 只给一侧加间距

```
Column(
  children: [
    Text('第一项'),
    Padding(
      padding: EdgeInsets.only(top: 24),  // 只在顶部加间距
      child: Text('第二项（距离上面更远）'),
    ),
    Text('第三项'),
  ],
)
```

## 五、MainAxisAlignment（均匀分布）

### 5.1 六种对齐方式

```
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Icon(Icons.home),
    Icon(Icons.search),
    Icon(Icons.settings),
  ],
)
```

| 对齐方式 | 效果 |
| --- | --- |
| `start` | 从起点开始排列（默认） |
| `end` | 从终点开始排列 |
| `center` | 居中排列 |
| `spaceBetween` | 两端对齐，中间均匀分布 |
| `spaceAround` | 每个组件左右间距相等 |
| `spaceEvenly` | 所有间距都相等（包括两端） |

### 5.2 效果对比

```
spaceBetween:
  [item]      [item]      [item]

spaceAround:
    [item]    [item]    [item]    

spaceEvenly:
    [item]    [item]    [item]    ← 注意两端也有
```

### 5.3 示例

```
// 底部导航栏图标均匀分布
Row(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [
    IconButton(icon: Icon(Icons.home), onPressed: () {}),
    IconButton(icon: Icon(Icons.search), onPressed: () {}),
    IconButton(icon: Icon(Icons.favorite), onPressed: () {}),
    IconButton(icon: Icon(Icons.person), onPressed: () {}),
  ],
)
```

## 六、Wrap + spacing（自动换行）

### 6.1 基本用法

当子组件太多会换行时，用 `Wrap` 代替 `Row`/`Column`：

```
Wrap(
  spacing: 12,        // 主轴方向间距（水平）
  runSpacing: 8,      // 交叉轴方向间距（垂直，行与行之间）
  children: [
    Chip(label: Text('标签1')),
    Chip(label: Text('标签2')),
    Chip(label: Text('标签3')),
    Chip(label: Text('标签4')),
    Chip(label: Text('标签5')),
    Chip(label: Text('标签6')),
  ],
)
```

### 6.2 适用场景

- 标签云
- 搜索历史
- 图片网格
- 按钮组

## 七、自定义扩展（批量设置）

### 7.1 扩展方法

给 `List<Widget>` 加一个扩展方法，批量插入间距：

```
extension WidgetListExtension on List<Widget> {
  /// 水平方向添加间距
  List<Widget> withSpacing(double spacing) {
    if (isEmpty) return this;
    return [
      first,
      for (int i = 1; i < length; i++) ...[
        SizedBox(width: spacing),
        this[i],
      ],
    ];
  }

  /// 垂直方向添加间距
  List<Widget> withHeightSpacing(double spacing) {
    if (isEmpty) return this;
    return [
      first,
      for (int i = 1; i < length; i++) ...[
        SizedBox(height: spacing),
        this[i],
      ],
    ];
  }
}
```

**使用：**

```
Row(
  children: [
    Text('A'),
    Text('B'),
    Text('C'),
  ].withSpacing(16),  // 每个之间 16px 间距
)

Column(
  children: [
    Text('第一项'),
    Text('第二项'),
    Text('第三项'),
  ].withHeightSpacing(12),
)
```

### 7.2 封装 Gap 组件

```
// 水平间距
class HGap extends SizedBox {
  const HGap(double width, {Key? key}) 
      : super(key: key, width: width);
}

// 垂直间距
class VGap extends SizedBox {
  const VGap(double height, {Key? key}) 
      : super(key: key, height: height);
}

// 使用
Row(
  children: [
    Text('左边'),
    HGap(16),
    Text('右边'),
  ],
)

Column(
  children: [
    Text('上面'),
    VGap(16),
    Text('下面'),
  ],
)
```

## 八、间距设计规范

### 8.1 常用间距值

```
class AppSpacing {
  static const double xs = 4.0;   // 极小间距
  static const double sm = 8.0;   // 小间距
  static const double md = 12.0;  // 中间距
  static const double lg = 16.0;  // 大间距
  static const double xl = 24.0;  // 超大间距
  static const double xxl = 32.0; // 特大间距
}
```

### 8.2 使用规范

```
Column(
  children: [
    // 标题和正文之间：大间距
    Text('标题', style: TextStyle(fontSize: 20, fontWeight: FontWeight.bold)),
    VGap(AppSpacing.lg),
    
    // 正文之间：中间距
    Text('正文内容1'),
    VGap(AppSpacing.md),
    Text('正文内容2'),
    VGap(AppSpacing.md),
    Text('正文内容3'),
    
    // 段落之间：超大间距
    VGap(AppSpacing.xl),
    
    // 按钮之间：大间距
    Row(
      children: [
        Expanded(child: OutlinedButton(onPressed: () {}, child: Text('取消'))),
        HGap(AppSpacing.lg),
        Expanded(child: ElevatedButton(onPressed: () {}, child: Text('确定'))),
      ],
    ),
  ],
)
```

## 九、各种场景的最佳方案

### 场景1：固定间距的列表

**用 `SizedBox`**

```
Column(
  children: [
    Text('A'),
    SizedBox(height: 12),
    Text('B'),
    SizedBox(height: 12),
    Text('C'),
  ],
)
```

### 场景2：两端对齐

**用 `Spacer` 或 `spaceBetween`**

```
// 方式1：Spacer（更灵活）
Row(
  children: [
    Text('标题'),
    Spacer(),
    Text('更多 >'),
  ],
)

// 方式2：spaceBetween
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Text('标题'),
    Text('更多 >'),
  ],
)
```

### 场景3：均匀分布的图标

**用 `spaceEvenly`**

```
Row(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  children: [
    Icon(Icons.home),
    Icon(Icons.search),
    Icon(Icons.favorite),
    Icon(Icons.person),
  ],
)
```

### 场景4：标签云（自动换行）

**用 `Wrap` + `spacing`**

```
Wrap(
  spacing: 8,
  runSpacing: 8,
  children: tags.map((tag) => Chip(label: Text(tag))).toList(),
)
```

### 场景5：列表项（大量重复）

**用 `ListView.separated`**

```
ListView.separated(
  itemCount: 100,
  separatorBuilder: (context, index) => Divider(height: 1),
  itemBuilder: (context, index) => ListTile(title: Text('Item $index')),
)
```

## 十、常见问题

### Q1：SizedBox 和 Container 哪个好？

**SizedBox 更好**，更轻量，语义更明确。

```
// ❌ 不推荐：用 Container 只为了间距
Container(width: 16)

// ✅ 推荐：SizedBox 专门干这个
SizedBox(width: 16)
```

### Q2：间距应该写在父组件还是子组件？

- **固定列表**：写在子组件之间（SizedBox）
- **单个组件**：写在子组件上（Padding）
- **整体布局**：写在父组件上（mainAxisAlignment）

### Q3：Column 内容溢出怎么办？

用 `SingleChildScrollView` 包裹，或者用 `ListView`：

```
SingleChildScrollView(
  child: Column(
    children: [...],
  ),
)
```

### Q4：怎么让间距自适应？

用 `MediaQuery` 或 `LayoutBuilder`：

```
LayoutBuilder(
  builder: (context, constraints) {
    final spacing = constraints.maxWidth > 600 ? 24.0 : 12.0;
    return Row(
      children: [
        Text('A'),
        SizedBox(width: spacing),
        Text('B'),
      ],
    );
  },
)
```

## 十一、总结

| 方式 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- |
| `SizedBox` | 精确、灵活、轻量 | 每个间距都要写 | 固定间距、精确控制 |
| `Spacer` | 自动填充、弹性 | 必须有剩余空间 | 两端对齐、比例分配 |
| `Padding` | 单个组件控制 | 只影响一个组件 | 单个组件周围留白 |
| `MainAxisAlignment` | 一行代码搞定 | 间距不可控 | 均匀分布 |
| `Wrap + spacing` | 自动换行 | 只能均匀间距 | 标签云、流式布局 |
| `ListView.separated` | 列表专用 | 只能用于列表 | 长列表 |

**推荐优先级：**

1. 首选 `SizedBox`（最灵活、最直观）
2. 弹性布局用 `Spacer`
3. 均匀分布用 `MainAxisAlignment`
4. 自动换行行用 `Wrap`
5. 长列表用 `ListView.separated`
