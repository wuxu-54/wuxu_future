# Flutter TextField 完整详解

TextField 是 Flutter 最核心的文本输入组件，用于输入账号、密码、搜索、备注等，底层基于 RenderEditable，支持光标、输入法、样式、校验、焦点、键盘类型、多行输入等全套能力。

## 一、最简基础用法

```
TextField()
```

默认：单行、无边框、可输入文字，最基础示例：

```
class TextFieldDemo extends StatelessWidget {
  const TextFieldDemo({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Padding(
        padding: EdgeInsets.all(20),
        child: TextField(),
      ),
    );
  }
}
```

## 二、核心必备控制器：TextEditingController

想要获取输入内容、主动赋值、清空文字，必须用控制器。

### 基础使用步骤

1. 定义控制器；
2. 绑定给 TextField；
3. 用完销毁（防止内存泄漏）。

```
class _DemoState extends State<Demo> {
  // 创建控制器
  final TextEditingController _controller = TextEditingController();

  @override
  void dispose() {
    // 页面销毁必须释放
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        TextField(controller: _controller),
        ElevatedButton(
          onPressed: () {
            // 获取输入内容
            String text = _controller.text;
            print("输入内容：$text");
            // 清空输入框
            _controller.clear();
            // 主动赋值
            // _controller.text = "预设文字";
          },
          child: Text("获取内容"),
        )
      ],
    );
  }
}
```

监听输入实时变化两种方式：

1. controller 监听

```
@override
void initState() {
  super.initState();
  _controller.addListener(() {
    print("实时输入：${_controller.text}");
  });
}
```

2. onChanged 回调（更常用）

```
TextField(
  onChanged: (value) {
    // value 就是当前输入的全部文字
    print(value);
  },
)
```

## 三、外观样式：decoration InputDecoration（最重要）

绝大多数样式都写在 `decoration` 里，包括边框、占位文字、图标、标签、提示、错误文案等。

### 常用参数一览

| 参数 | 作用 |
| --- | --- |
| hintText | 灰色占位提示文字（输入前显示） |
| hintStyle | 占位文字样式 |
| labelText | 悬浮标签，输入框获得焦点会上浮到左上角 |
| labelStyle | 标签文字样式 |
| prefixIcon | 左侧图标 |
| suffixIcon | 右侧图标（常用：清除按钮、眼睛显隐密码） |
| border | 默认边框样式 |
| enabledBorder | 未获焦点边框 |
| focusedBorder | 获取焦点边框 |
| errorText | 校验错误提示文案 |
| filled | 是否开启背景填充 |
| fillColor | 填充背景色 |
| contentPadding | 内边距，控制文字上下左右距离 |

### 完整美化示例

```
TextField(
  controller: _controller,
  decoration: InputDecoration(
    hintText: "请输入手机号",
    hintStyle: TextStyle(color: Colors.grey),
    labelText: "手机号",
    prefixIcon: Icon(Icons.phone),
    filled: true,
    fillColor: Color(0xfff5f5f5),
    contentPadding: EdgeInsets.symmetric(horizontal: 12, vertical: 14),
    // 常规圆角边框
    border: OutlineInputBorder(borderRadius: BorderRadius.circular(8)),
    enabledBorder: OutlineInputBorder(
      borderRadius: BorderRadius.circular(8),
      borderSide: BorderSide(color: Colors.grey.shade300),
    ),
    focusedBorder: OutlineInputBorder(
      borderRadius: BorderRadius.circular(8),
      borderSide: BorderSide(color: Colors.blue, width: 1.5),
    ),
  ),
)
```

无边框样式（聊天框常用）：

```
border: InputBorder.none,
enabledBorder: InputBorder.none,
focusedBorder: InputBorder.none,
```

## 四、输入行为控制参数

### 1. 单行/多行

- `maxLines`：最大行数；
- `minLines`：最小行数；
- 不设置：默认单行；
- 设置 `minLines=1,maxLines=5`：自动换行，最多5行；
- 密码框必须强制单行。

```
// 多行备注框
TextField(
  minLines: 2,
  maxLines: 4,
  maxLength: 100, // 最多输入100个字
  decoration: InputDecoration(hintText: "请输入备注"),
)
```

### 2. 输入长度限制

`maxLength`：限制总字符；右下角会自带计数。
隐藏右下角字数计数：

```
buildCounter: (ctx, current, max, isFocus) => SizedBox()
```

### 3. 键盘类型 keyboardType

适配不同场景唤起对应输入法：

```
keyboardType: TextInputType.number, // 纯数字键盘
// 可选枚举：
// TextInputType.text 默认全键盘
// TextInputType.phone 手机号键盘
// TextInputType.emailAddress 邮箱键盘
// TextInputType.url 网址键盘
// TextInputType.multiline 多行回车换行
```

### 4. 密码框 obscureText

隐藏文字为圆点，搭配 suffixIcon 实现显示/隐藏密码：

```
bool _obscure = true;

TextField(
  obscureText: _obscure,
  decoration: InputDecoration(
    hintText: "请输入密码",
    suffixIcon: IconButton(
      icon: Icon(_obscure ? Icons.visibility_off : Icons.visibility),
      onPressed: () => setState(() => _obscure = !_obscure),
    ),
  ),
)
```

### 5. 大小写、自动大写 textCapitalization

```
textCapitalization: TextCapitalization.words,
// none：不自动大写
// words：每个单词首字母大写
// sentences：句子首字母大写
// characters：全部大写
```

### 6. 禁止编辑

- `enabled: false` 不可输入，置灰；
- `readOnly: true` 只读，可点击、可复制，但不能输入。

只读常用场景：点击唤起选择弹窗，不能手动打字：

```
TextField(
  readOnly: true,
  onTap: (){
    // 点击弹出日期选择、地址选择
  },
  decoration: InputDecoration(hintText: "请选择日期"),
)
```

TextField(

## 六、焦点管理 FocusNode

控制手动获取焦点、失去焦点，关闭键盘。
使用流程：创建FocusNode → 绑定 → 销毁。

```
final FocusNode _focusNode = FocusNode();

// 唤起键盘
_focusNode.requestFocus();
// 收起键盘
FocusScope.of(context).unfocus();

TextField(
  focusNode: _focusNode,
)

// dispose销毁
@override
void dispose() {
  _focusNode.dispose();
  _controller.dispose();
  super.dispose();
}
```

常用：点击空白处收起键盘

```
GestureDetector(
  onTap: () => FocusScope.of(context).unfocus(),
  child: Scaffold(
    body: TextField(focusNode: _focusNode),
  ),
)
```

监听焦点变化：

```
_focusNode.addListener(() {
  if (_focusNode.hasFocus) {
    print("输入框已聚焦");
  } else {
    print("失去焦点");
  }
});
```

## 七、回车键盘操作：textInputAction

控制键盘右下角按钮文案与行为

```
textInputAction: TextInputAction.search,
```

常用枚举：

- done：完成，点击收起键盘
- search：搜索
- go：前往
- next：下一项（表单连续跳转）
- send：发送

搭配 onSubmitted 监听回车点击：

```
TextField(
  textInputAction: TextInputAction.search,
  onSubmitted: (value) {
    print("回车搜索：$value");
  },
)
```

表单多输入框联动：用 `next` + FocusNode 切焦点

```
// 第一个框回车跳到第二个
TextField(
  textInputAction: TextInputAction.next,
  onSubmitted: (_) => _focus2.requestFocus(),
)
```

## 八、输入格式过滤：inputFormatters

限制只能输入数字、手机号、正则过滤，依赖 `flutter/services.dart`。

```
import 'package:flutter/services.dart';

TextField(
  // 只允许输入数字
  inputFormatters: [
    FilteringTextInputFormatter.digitsOnly,
  ],
)
```

常用格式化器：

1. `FilteringTextInputFormatter.digitsOnly` 仅数字
2. `FilteringTextInputFormatter.allow(RegExp(r'[0-9a-zA-Z]'))` 只允许数字字母
3. `FilteringTextInputFormatter.deny(RegExp('[^.]'))` 禁止某些字符

自定义手机号格式化（344分段 138 0000 1111）需要手写 TextInputFormatter。

## 九、常用回调全量汇总

1. `onChanged(String value)`：每输入一个字符实时回调
2. `onSubmitted(String value)`：按下回车触发
3. `onTap()`：点击输入框触发（只读框高频使用）
4. `onEditingComplete`：回车/完成键触发，早于 onSubmitted

## 十、高频踩坑解决方案

### 1. 输入框被键盘遮挡

外层包裹 SingleChildScrollView 让页面整体滚动；
或使用 `resizeToAvoidBottomInset: true`（Scaffold默认开启）。

### 2. 横向ListView内TextField无法点击

大概率手势冲突，给TextField包裹 IgnorePointer 不行，优先检查：
横向滚动与输入手势争抢，可包裹 GestureDetector 区分滑动和点击。

### 3. 中文粘贴乱码、超长文字布局溢出

配合 maxLength + TextOverflow.visible，固定高度。

### 4. 初始化带默认文字

不要直接写在build里赋值controller.text，放在initState：

```
@override
void initState() {
  super.initState();
  _controller.text = "初始内容";
}
```

### 5. 多行输入回车不换行

确认 keyboardType 是 TextInputType.multiline，且 textInputAction 不要强制 done。

## 十一、完整表单综合示例（账号+密码）

```
class LoginPage extends StatefulWidget {
  const LoginPage({super.key});

  @override
  State<LoginPage> createState() => _LoginPageState();
}

class _LoginPageState extends State<LoginPage> {
  final TextEditingController _accCtrl = TextEditingController();
  final TextEditingController _pwdCtrl = TextEditingController();
  final FocusNode _accFocus = FocusNode();
  final FocusNode _pwdFocus = FocusNode();
  bool obscure = true;

  @override
  void dispose() {
    _accCtrl.dispose();
    _pwdCtrl.dispose();
    _accFocus.dispose();
    _pwdFocus.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: () => FocusScope.of(context).unfocus(),
      child: Scaffold(
        body: Padding(
          padding: EdgeInsets.all(24),
          child: Column(
            children: [
              TextField(
                controller: _accCtrl,
                focusNode: _accFocus,
                keyboardType: TextInputType.phone,
                textInputAction: TextInputAction.next,
                onSubmitted: (_) => _pwdFocus.requestFocus(),
                decoration: InputDecoration(
                  hintText: "请输入手机号",
                  prefixIcon: Icon(Icons.account_circle),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(12)),
                ),
              ),
              SizedBox(height: 16),
              TextField(
                controller: _pwdCtrl,
                focusNode: _pwdFocus,
                obscureText: obscure,
                textInputAction: TextInputAction.done,
                decoration: InputDecoration(
                  hintText: "请输入密码",
                  prefixIcon: Icon(Icons.lock),
                  suffixIcon: IconButton(
                    icon: Icon(obscure ? Icons.visibility_off : Icons.visibility),
                    onPressed: () => setState(() => obscure = !obscure),
                  ),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(12)),
                ),
                onSubmitted: (val) {
                  print("登录账号：${_accCtrl.text}，密码：$val");
                },
              ),
              SizedBox(height: 30),
              SizedBox(
                width: double.infinity,
                child: ElevatedButton(
                  onPressed: () {
                    String acc = _accCtrl.text.trim();
                    String pwd = _pwdCtrl.text.trim();
                    print("提交：$acc / $pwd");
                  },
                  child: Text("登录"),
                ),
              )
            ],
          ),
        ),
      ),
    );
  }
}
```

## 十二、补充进阶拓展

1. **表单校验**：配合 Form + GlobalKey，在 TextField 加 validator 统一校验；
2. 第三方增强：`flutter_mask_textfield` 做银行卡、手机号格式化；
3. 富文本输入：使用第三方编辑器，原生 TextField 仅支持纯文本；
4. 禁用自动填充：`autofillHints: []` 关闭系统账号密码自动填充。
