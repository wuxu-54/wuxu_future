# Flutter 状态栏设置与验收指南

## 一、状态栏设置的核心方式

### 1.1 `SystemChrome.setSystemUIOverlayStyle`

最常用的方式，设置系统 UI 覆盖层（状态栏 + 导航栏）的样式。

```
import 'package:flutter/services.dart';

// 设置状态栏样式
SystemChrome.setSystemUIOverlayStyle(
  SystemUiOverlayStyle(
    // 状态栏颜色（Android）
    statusBarColor: Colors.transparent,
    // 状态栏图标亮度（Android）
    statusBarIconBrightness: Brightness.dark,
    // 状态栏亮度（iOS）
    statusBarBrightness: Brightness.light,
    // 导航栏颜色（Android）
    systemNavigationBarColor: Colors.white,
    // 导航栏图标亮度（Android）
    systemNavigationBarIconBrightness: Brightness.dark,
  ),
);
```

## 二、常用设置场景

### 2.1 全局设置（main 函数中）

```
void main() {
  WidgetsFlutterBinding.ensureInitialized();
  
  // 全局设置状态栏
  SystemChrome.setSystemUIOverlayStyle(
    const SystemUiOverlayStyle(
      statusBarColor: Colors.transparent,
      statusBarIconBrightness: Brightness.dark,
      statusBarBrightness: Brightness.light, // iOS
    ),
  );
  
  runApp(const MyApp());
}
```

### 2.2 单页面设置（`AnnotatedRegion`）

推荐方式，每个页面可以独立设置，页面切换时自动切换样式。

```
import 'package:flutter/services.dart';

class MyPage extends StatelessWidget {
  const MyPage({super.key});

  @override
  Widget build(BuildContext context) {
    return AnnotatedRegion<SystemUiOverlayStyle>(
      value: SystemUiOverlayStyle.dark.copyWith(
        statusBarColor: Colors.blue,
      ),
      child: Scaffold(
        appBar: AppBar(title: const Text('页面标题')),
        body: const Center(child: Text('内容')),
      ),
    );
  }
}
```

### 2.3 AppBar 自动设置

`AppBar` 会根据 `systemOverlayStyle` 属性自动设置状态栏：

```
AppBar(
  title: const Text('标题'),
  backgroundColor: Colors.blue,
  // 状态栏样式
  systemOverlayStyle: SystemUiOverlayStyle.light,
)
```

### 2.4 隐藏状态栏

```
// 隐藏状态栏和导航栏（全屏）
SystemChrome.setEnabledSystemUIMode(SystemUiMode.immersiveSticky);

// 只隐藏状态栏
SystemChrome.setEnabledSystemUIMode(
  SystemUiMode.manual,
  overlays: [SystemUiOverlay.bottom], // 只保留底部导航栏
);

// 恢复显示
SystemChrome.setEnabledSystemUIMode(SystemUiMode.edgeToEdge);
```

### 2.5 沉浸式状态栏

```
// 透明状态栏 + 内容延伸到状态栏下方
Scaffold(
  extendBodyBehindAppBar: true, // 内容延伸到 AppBar 后面
  appBar: AppBar(
    backgroundColor: Colors.transparent,
    elevation: 0,
    systemOverlayStyle: SystemUiOverlayStyle.dark,
  ),
  body: Container(
    decoration: const BoxDecoration(
      image: DecorationImage(
        image: AssetImage('assets/bg.jpg'),
        fit: BoxFit.cover,
      ),
    ),
    child: const SafeArea(child: Text('内容')),
  ),
)
```

## 四、iOS vs Android 差异

| 属性 | Android | iOS | 说明 |
| --- | --- | --- | --- |
| `statusBarColor` | ✅ 支持 | ❌ 不支持 | 状态栏背景色 |
| `statusBarIconBrightness` | ✅ 支持 | ❌ 不支持 | 图标/文字颜色 |
| `statusBarBrightness` | ❌ 不支持 | ✅ 支持 | 状态栏亮度（间接控制文字） |
| `systemNavigationBarColor` | ✅ 支持 | ❌ 不支持 | 底部导航栏颜色 |

**双平台兼容写法：**

```
SystemUiOverlayStyle getStatusBarStyle({
  required Color bgColor,
  required Brightness iconBrightness,
}) {
  return SystemUiOverlayStyle(
    // Android
    statusBarColor: bgColor,
    statusBarIconBrightness: iconBrightness,
    // iOS
    statusBarBrightness: iconBrightness == Brightness.dark 
        ? Brightness.light 
        : Brightness.dark,
  );
}
```

## 五、状态栏设置验收清单

### 5.1 基础功能验收

| 验收项 | 检查要点 | 通过标准 |
| --- | --- | --- |
| **状态栏颜色** | 状态栏背景色是否与设计一致 | 颜色值完全匹配设计稿 |
| **状态栏文字颜色** | 时间、电量、信号等文字颜色 | 深色背景配白色文字，浅色背景配黑色文字 |
| **透明度** | 半透明/透明状态栏效果 | 内容正确延伸到状态栏下方 |
| **沉浸式效果** | 图片/渐变背景延伸到状态栏 | 无白色/黑色条带，背景连续 |

### 5.2 页面切换验收

| 验收项 | 检查要点 | 通过标准 |
| --- | --- | --- |
| **页面切换样式** | 不同页面状态栏样式不同时，切换是否正确更新 | 进入新页面后状态栏样式立即更新 |
| **返回恢复** | 返回上一页时状态栏样式是否恢复 | 样式正确恢复为上一页的设置 |
| **弹窗/抽屉** | 打开 Dialog / BottomSheet / Drawer 时状态栏是否正确 | 状态栏样式保持不变或按预期变化 |

### 5.3 系统交互验收

| 验收项 | 检查要点 | 通过标准 |
| --- | --- | --- |
| **下拉通知栏** | 下拉通知栏后再收起，状态栏是否正常 | 样式保持不变，无异常闪烁 |
| **控制中心** | 上滑/下拉打开控制中心后 | 样式正确恢复 |
| **横竖屏切换** | 旋转屏幕后状态栏是否正确 | 横屏时状态栏隐藏或样式正确 |
| **刘海屏/挖孔屏** | 异形屏适配是否正确 | 内容不被刘海遮挡，SafeArea 生效 |

### 5.4 特殊场景验收

| 验收项 | 检查要点 | 通过标准 |
| --- | --- | --- |
| **启动页** | App 启动瞬间状态栏颜色 | 与启动页背景一致，无闪烁 |
| **Splash 页** | 闪屏页状态栏 | 透明或与闪屏背景一致 |
| **WebView 页面** | 内嵌网页的状态栏 | 样式与 App 整体风格一致 |
| **视频全屏** | 视频播放全屏时 | 状态栏正确隐藏 |
| **深色模式** | 系统深色模式切换时 | 状态栏样式正确适配 |

### 5.5 兼容性验收

| 验收项 | 检查要点 | 通过标准 |
| --- | --- | --- |
| **Android 低版本** | Android 6.0 以下状态栏文字颜色 | 低版本不支持深色图标时的降级方案 |
| **iOS 不同版本** | iOS 14/15/16/17 表现一致 | 各版本样式统一 |
| **不同机型** | 刘海屏、挖孔屏、普通屏 | 都能正确适配 |
| **平板/折叠屏** | 大屏设备 | 状态栏样式正确 |

## 六、常见问题与解决方案

### 问题1：状态栏颜色设置不生效

**原因：**

- 使用了 `AppBar`，它会覆盖全局设置
- `AnnotatedRegion` 没有正确包裹 `Scaffold`

**解决方案：**

```
// 方式1：通过 AppBar 设置
AppBar(
  systemOverlayStyle: SystemUiOverlayStyle.dark,
)

// 方式2：使用 AnnotatedRegion 包裹
AnnotatedRegion<SystemUiOverlayStyle>(
  value: SystemUiOverlayStyle.dark,
  child: Scaffold(...),
)
```

### 问题2：iOS 状态栏文字颜色不生效

**原因：** iOS 使用 `statusBarBrightness` 而非 `statusBarIconBrightness`

**解决方案：**

```
SystemUiOverlayStyle(
  // Android 用这个控制图标颜色
  statusBarIconBrightness: Brightness.dark,
  // iOS 用这个控制文字颜色（dark = 白色文字）
  statusBarBrightness: Brightness.light,
)
```

### 问题3：页面返回后状态栏样式错乱

**原因：** 上一个页面没有设置 `AnnotatedRegion`

**解决方案：** 每个页面都用 `AnnotatedRegion` 包裹，确保页面切换时样式正确切换。

### 问题4：沉浸式状态栏内容被遮挡

**原因：** 内容延伸到状态栏下方但没有加 `SafeArea`

**解决方案：**

```
Scaffold(
  extendBodyBehindAppBar: true,
  body: SafeArea(
    child: Column(...),
  ),
)
```

### 问题5：Android 状态栏半透明效果不对

**原因：** Android 状态栏默认有半透明遮罩

**解决方案：**

```
// 在 Android 的 styles.xml 中设置
<item name="android:statusBarColor">@android:color/transparent</item>

// 或者在 Flutter 中设置
SystemChrome.setSystemUIOverlayStyle(
  SystemUiOverlayStyle(
    statusBarColor: Colors.transparent,
  ),
);
```

## 七、封装一个状态栏工具类

```
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

class StatusBarUtil {
  /// 设置深色状态栏（黑色文字）
  static void setDark() {
    SystemChrome.setSystemUIOverlayStyle(
      const SystemUiOverlayStyle(
        statusBarColor: Colors.transparent,
        statusBarIconBrightness: Brightness.dark, // Android
        statusBarBrightness: Brightness.light,    // iOS
      ),
    );
  }

  /// 设置浅色状态栏（白色文字）
  static void setLight() {
    SystemChrome.setSystemUIOverlayStyle(
      const SystemUiOverlayStyle(
        statusBarColor: Colors.transparent,
        statusBarIconBrightness: Brightness.light, // Android
        statusBarBrightness: Brightness.dark,      // iOS
      ),
    );
  }

  /// 自定义状态栏颜色
  static void setCustom({
    Color? statusBarColor,
    Brightness? iconBrightness,
    Color? navBarColor,
    Brightness? navIconBrightness,
  }) {
    SystemChrome.setSystemUIOverlayStyle(
      SystemUiOverlayStyle(
        statusBarColor: statusBarColor ?? Colors.transparent,
        statusBarIconBrightness: iconBrightness ?? Brightness.dark,
        statusBarBrightness: 
            (iconBrightness ?? Brightness.dark) == Brightness.dark 
                ? Brightness.light 
                : Brightness.dark,
        systemNavigationBarColor: navBarColor ?? Colors.white,
        systemNavigationBarIconBrightness: 
            navIconBrightness ?? Brightness.dark,
      ),
    );
  }

  /// 隐藏状态栏（全屏）
  static void hide() {
    SystemChrome.setEnabledSystemUIMode(SystemUiMode.immersiveSticky);
  }

  /// 显示状态栏
  static void show() {
    SystemChrome.setEnabledSystemUIMode(SystemUiMode.edgeToEdge);
  }

  /// 获取状态栏高度
  static double getHeight(BuildContext context) {
    return MediaQuery.of(context).padding.top;
  }
}

// 使用示例：
// StatusBarUtil.setDark();
// StatusBarUtil.setLight();
// StatusBarUtil.setCustom(statusBarColor: Colors.blue, iconBrightness: Brightness.light);
```

## 九、总结

| 要点 | 说明 |
| --- | --- |
| **设置方式** | `SystemChrome.setSystemUIOverlayStyle` / `AnnotatedRegion` / `AppBar.systemOverlayStyle` |
| **推荐方式** | 单页面用 `AnnotatedRegion`，全局用 `SystemChrome` |
| **平台差异** | Android 用 `statusBarIconBrightness`，iOS 用 `statusBarBrightness` |
| **沉浸式** | `extendBodyBehindAppBar: true` + `SafeArea` |
| **验收重点** | 颜色、文字颜色、页面切换、异形屏、双平台一致性 |
| **常见坑** | AppBar 覆盖全局设置、iOS 属性用错、沉浸式内容遮挡 |
