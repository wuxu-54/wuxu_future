# Flutter Scaffold 完全详解

## 一、Scaffold 是什么

`Scaffold` 是 Flutter Material 组件库中最核心的页面骨架组件，它实现了 Material Design 的基本视觉布局结构，为你提供了一个"标准页面模板"，包含了常见的页面元素位置预设。

简单说：**Scaffold 就是一个帮你快速搭建页面基本框架的脚手架**。

---

## 二、核心属性一览

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `appBar` | PreferredSizeWidget? | 顶部导航栏 |
| `body` | Widget? | 页面主体内容 |
| `floatingActionButton` | Widget? | 悬浮按钮（FAB） |
| `floatingActionButtonLocation` | FloatingActionButtonLocation? | FAB 的位置 |
| `drawer` | Widget? | 左侧抽屉菜单 |
| `endDrawer` | Widget? | 右侧抽屉菜单 |
| `bottomNavigationBar` | Widget? | 底部导航栏 |
| `bottomSheet` | Widget? | 底部持久化面板 |
| `snackBar` | — | 通过 ScaffoldMessenger 显示 |
| `backgroundColor` | Color? | 页面背景色 |
| `resizeToAvoidBottomInset` | bool | 键盘弹出时是否调整布局（默认 true） |
| `extendBody` | bool | body 是否延伸到底部导航栏下方 |
| `extendBodyBehindAppBar` | bool | body 是否延伸到 AppBar 后方 |

---

## 三、各属性详解

### 1. appBar — 顶部导航栏

最常用的属性，显示在页面顶部。

```
Scaffold(
  appBar: AppBar(
    title: Text('首页'),
    centerTitle: true,            // 标题居中
    elevation: 0,                 // 阴影高度
    backgroundColor: Colors.blue, // 背景色
    leading: Icon(Icons.menu),    // 左侧按钮
    actions: [                    // 右侧按钮组
      IconButton(
        icon: Icon(Icons.search),
        onPressed: () {},
      ),
      IconButton(
        icon: Icon(Icons.more_vert),
        onPressed: () {},
      ),
    ],
    bottom: PreferredSize(        // AppBar 底部区域（如 TabBar）
      preferredSize: Size.fromHeight(48),
      child: TabBar(
        tabs: [Tab(text: '推荐'), Tab(text: '热门')],
      ),
    ),
  ),
  body: ...
)
```

**常用技巧：**

- `automaticallyImplyLeading: false` 可禁止自动返回按钮
- `flexibleSpace` 可实现渐变/图片背景的 AppBar
- 配合 `PreferredSize` 可以自定义 AppBar 高度

---

### 2. body — 页面主体

页面的主要内容区域，占据 AppBar 下方的所有空间。

```
Scaffold(
  body: Center(
    child: Text('Hello Flutter'),
  ),
)
```

**注意：** body 默认不会延伸到 AppBar 和底部导航栏区域。如果需要沉浸式效果，使用 `extendBodyBehindAppBar: true`。

---

### 3. floatingActionButton — 悬浮按钮

Material Design 标志性组件，通常用于页面的主要操作。

```
Scaffold(
  floatingActionButton: FloatingActionButton(
    onPressed: () {},
    child: Icon(Icons.add),
    backgroundColor: Colors.blue,
  ),
  // FAB 位置
  floatingActionButtonLocation: FloatingActionButtonLocation.centerFloat,
)
```

**位置枚举：**

- `endFloat` — 右下角（默认）
- `centerFloat` — 底部居中
- `endDocked` — 右下角嵌入底部栏
- `centerDocked` — 底部居中嵌入底部栏（凹槽效果）

---

### 4. drawer / endDrawer — 抽屉菜单

左侧/右侧滑出的侧边栏菜单。

```
Scaffold(
  drawer: Drawer(
    child: ListView(
      padding: EdgeInsets.zero,
      children: [
        UserAccountsDrawerHeader(
          accountName: Text('张三'),
          accountEmail: Text('zhangsan@example.com'),
          currentAccountPicture: CircleAvatar(
            backgroundImage: NetworkImage('...'),
          ),
        ),
        ListTile(
          leading: Icon(Icons.home),
          title: Text('首页'),
          onTap: () {},
        ),
        ListTile(
          leading: Icon(Icons.settings),
          title: Text('设置'),
          onTap: () {},
        ),
      ],
    ),
  ),
)
```

**控制抽屉开关：**

```
// 打开左侧抽屉
Scaffold.of(context).openDrawer();
// 打开右侧抽屉
Scaffold.of(context).openEndDrawer();
// 关闭抽屉
Navigator.pop(context);
```

---

### 5. bottomNavigationBar — 底部导航栏

用于多页面切换的底部 Tab。

```
Scaffold(
  bottomNavigationBar: BottomNavigationBar(
    currentIndex: _currentIndex,
    onTap: (index) {
      setState(() => _currentIndex = index);
    },
    items: [
      BottomNavigationBarItem(icon: Icon(Icons.home), label: '首页'),
      BottomNavigationBarItem(icon: Icon(Icons.search), label: '发现'),
      BottomNavigationBarItem(icon: Icon(Icons.person), label: '我的'),
    ],
    selectedItemColor: Colors.blue,
    unselectedItemColor: Colors.grey,
    type: BottomNavigationBarType.fixed, // 超过3个时保持固定
  ),
)
```

**底部导航的其他选择：**

- `BottomAppBar` — 配合 FAB 实现凹槽效果
- `NavigationBar`（M3 风格）— Material 3 新版底部导航
- `CupertinoTabBar` — iOS 风格底部栏

---

### 6. bottomSheet — 底部持久化面板

常驻底部的面板，与 bottomSheet 弹窗不同，它是一直显示的。

```
Scaffold(
  bottomSheet: Container(
    height: 60,
    color: Colors.orange,
    child: Center(child: Text('底部常驻面板')),
  ),
)
```

> 
> 💡 如果需要弹出式底部面板，使用 `showModalBottomSheet()` 方法。

---

### 7. SnackBar — 轻量提示

通过 `ScaffoldMessenger` 显示底部短暂提示条。

```
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(
    content: Text('操作成功'),
    duration: Duration(seconds: 2),
    action: SnackBarAction(
      label: '撤销',
      onPressed: () {},
    ),
  ),
);
```

---

### 8. backgroundColor — 背景色

设置整个 Scaffold 的背景颜色。

```
Scaffold(
  backgroundColor: Colors.grey[100],
  body: ...
)
```

---

### 9. resizeToAvoidBottomInset — 键盘避让

控制键盘弹出时页面是否自动上推，避免输入框被遮挡。

```
Scaffold(
  resizeToAvoidBottomInset: true, // 默认 true
  body: ...
)
```

> 
> 设为 `false` 时，键盘弹出会覆盖页面内容，适合全屏沉浸式场景。

---

### 10. extendBody / extendBodyBehindAppBar — 延伸效果

```
Scaffold(
  extendBodyBehindAppBar: true,  // body 延伸到 AppBar 下方
  extendBody: true,              // body 延伸到底部导航栏下方
  appBar: AppBar(
    backgroundColor: Colors.transparent,
    elevation: 0,
  ),
  body: Image.network('...', fit: BoxFit.cover),
)
```

常用于实现**沉浸式页面**，如图片详情页、个人主页等。

## 四、完整示例

```
class HomePage extends StatefulWidget {
  @override
  _HomePageState createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  int _currentIndex = 0;

  final List<Widget> _pages = [
    Center(child: Text('首页')),
    Center(child: Text('发现')),
    Center(child: Text('我的')),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('Scaffold 示例'),
        centerTitle: true,
        actions: [
          IconButton(
            icon: Icon(Icons.search),
            onPressed: () {
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('点击了搜索')),
              );
            },
          ),
        ],
      ),
      drawer: Drawer(
        child: ListView(
          children: [
            DrawerHeader(
              child: Text('菜单'),
              decoration: BoxDecoration(color: Colors.blue),
            ),
            ListTile(title: Text('选项1'), onTap: () {}),
            ListTile(title: Text('选项2'), onTap: () {}),
          ],
        ),
      ),
      body: _pages[_currentIndex],
      floatingActionButton: FloatingActionButton(
        onPressed: () {},
        child: Icon(Icons.add),
      ),
      floatingActionButtonLocation: FloatingActionButtonLocation.endFloat,
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _currentIndex,
        onTap: (index) => setState(() => _currentIndex = index),
        items: [
          BottomNavigationBarItem(icon: Icon(Icons.home), label: '首页'),
          BottomNavigationBarItem(icon: Icon(Icons.search), label: '发现'),
          BottomNavigationBarItem(icon: Icon(Icons.person), label: '我的'),
        ],
      ),
    );
  }
}
```

## 五、常见问题与注意事项

### ❓ Scaffold.of(context) 找不到 Scaffold？

确保 `context` 在 Scaffold 的**子树**中。如果在 Scaffold 同一层级调用会报错，解决方案：

- 使用 `Builder` 包裹
- 使用 `GlobalKey<ScaffoldState>`

```
final _scaffoldKey = GlobalKey<ScaffoldState>();

Scaffold(
  key: _scaffoldKey,
  ...
)

// 调用
_scaffoldKey.currentState?.openDrawer();
```

### ❓ AppBar 高度怎么自定义？

```
appBar: PreferredSize(
  preferredSize: Size.fromHeight(80),
  child: AppBar(...),
)
```

### ❓ 如何去掉 AppBar 底部的阴影？

```
AppBar(
  elevation: 0,
  scrolledUnderElevation: 0, // Material 3 滚动时的阴影
)
```

### ❓ Scaffold 必须用吗？

不是必须的。但如果你需要 AppBar、抽屉、FAB、底部导航、SnackBar 等 Material Design 标准元素，Scaffold 是最高效的方式。纯自定义页面可以直接用 `Scaffold` 的 body 部分（即一个普通 Widget）。

## 六、与 Scaffold 配合的常用组件

| 组件 | 用途 |
| --- | --- |
| `AppBar` | 顶部栏 |
| `Drawer` | 侧边抽屉 |
| `BottomNavigationBar` | 底部导航 |
| `FloatingActionButton` | 悬浮按钮 |
| `SnackBar` | 底部提示 |
| `TabBar` + `TabBarView` | 顶部 Tab 切换 |
| `BottomSheet` | 底部面板 |
| `SafeArea` | 安全区域适配 |

---

**总结：** Scaffold 是 Flutter 页面开发的"标配骨架"，掌握它的核心属性就能快速搭建 90% 以上的标准页面结构。建议重点掌握 `appBar`、`body`、`drawer`、`bottomNavigationBar` 和 `floatingActionButton` 这五个最常用属性。
