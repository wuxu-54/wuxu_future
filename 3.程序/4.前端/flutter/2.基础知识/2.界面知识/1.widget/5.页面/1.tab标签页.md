# Flutter Tab 组件详解：TabBar、TabBarView 与 TabController

在 Flutter 中，Tab 导航是最常用的页面结构之一，由三个核心组件配合完成：

| 组件 | 职责 |
| --- | --- |
| `TabController` | **控制器** — 管理 Tab 的选中状态、监听切换、驱动动画 |
| `TabBar` | **标签栏** — 展示一排可点击的 Tab 标签 |
| `TabBarView` | **内容区** — 展示每个 Tab 对应的页面内容，支持左右滑动切换 |

三者通过同一个 `TabController` 关联起来，实现"点标签 → 切页面"和"滑页面 → 切标签"的双向联动。

---

## 一、最常用方式：DefaultTabController（最简写法）

大多数场景下，你不需要手动创建 `TabController`，用 `DefaultTabController` 即可，它会自动向子树注入控制器：

```
class MyTabPage extends StatelessWidget {
  const MyTabPage({super.key});

  @override
  Widget build(BuildContext context) {
    return DefaultTabController(
      length: 3,          // Tab 的数量，必须和 TabBar/TabBarView 的数量一致
      initialIndex: 0,   // 默认选中第几个，从 0 开始
      child: Scaffold(
        appBar: AppBar(
          title: const Text('Tab 示例'),
          bottom: const TabBar(          // ① 标签栏，放在 AppBar 的 bottom
            tabs: [
              Tab(text: '首页', icon: Icon(Icons.home)),
              Tab(text: '消息', icon: Icon(Icons.message)),
              Tab(text: '我的', icon: Icon(Icons.person)),
            ],
          ),
        ),
        body: const TabBarView(          // ② 内容区
          children: [
            Center(child: Text('首页内容')),
            Center(child: Text('消息内容')),
            Center(child: Text('我的内容')),
          ],
        ),
      ),
    );
  }
}
```

**关键点：**

- `length` 必须等于 `TabBar.tabs` 的数量，也必须等于 `TabBarView.children` 的数量，否则会报错。
- `TabBar` 和 `TabBarView` 会自动从父级 `DefaultTabController` 中找到控制器，无需手动传递。

## 二、手动管理：TabController（需要监听/控制时用）

当你需要**监听切换事件**、**主动跳转到某个 Tab**、或者在 `StatefulWidget` 中精细控制时，就需要手动创建 `TabController`。

### 基本用法

```
class MyTabPage extends StatefulWidget {
  const MyTabPage({super.key});

  @override
  State<MyTabPage> createState() => _MyTabPageState();
}

// ① 必须 with TickerProviderStateMixin（或 SingleTickerProviderStateMixin）
class _MyTabPageState extends State<MyTabPage> with TickerProviderStateMixin {
  late TabController _tabController;

  @override
  void initState() {
    super.initState();
    // ② 创建控制器
    _tabController = TabController(
      length: 3,
      vsync: this,        // 传入 TickerProvider，用于动画驱动
      initialIndex: 0,
    );

    // ③ 监听切换
    _tabController.addListener(() {
      // index 是当前选中的 tab 索引
      // indexIsChanging 表示是否正在切换动画中
      if (_tabController.indexIsChanging) {
        print('切换到第 ${_tabController.index} 个 Tab');
      }
    });
  }

  @override
  void dispose() {
    _tabController.dispose();  // ④ 必须释放，否则内存泄漏
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('手动 Controller'),
        bottom: TabBar(
          controller: _tabController,  // ⑤ 传入控制器
          tabs: const [
            Tab(text: 'Tab A'),
            Tab(text: 'Tab B'),
            Tab(text: 'Tab C'),
          ],
        ),
      ),
      body: TabBarView(
        controller: _tabController,  // ⑥ 传入同一个控制器
        children: const [ // 这里const 表示 在编译时就将此数组数据放在常量内存块里，运行时不会被修改
          Center(child: Text('页面 A')),
          Center(child: Text('页面 B')),
          Center(child: Text('页面 C')),
        ],
      ),
    );
  }
}
```

`vsync` 是 **vertical synchronization**（垂直同步）的缩写，在 Flutter 里它的类型是 `TickerProvider`，就是告诉 Flutter：" 用 `this`（当前 State）作为动画的 ' 心跳起搏器 '，让动画和屏幕的刷新节奏同步，并且在页面不可见时自动暂停，节省性能。"。简单来说，它的作用是：**给动画提供一个 "节拍器"**—— 屏幕每刷新一帧，动画就往前推进一点。

### TabController 常用 API

```
// 跳转到指定 Tab（带动画）
_tabController.animateTo(1);

// 直接设置索引（不带动画）
_tabController.index = 2;

// 获取当前索引
int current = _tabController.index;

// 上一个 / 下一个
_tabController.previousIndex;

// 动画对象（可用于自定义联动效果）
_tabController.animation;
```

## 三、TabBar 的常用样式定制

`TabBar` 有非常多的样式参数，下面是最常用的几个：

```
TabBar(
  // 标签列表
  tabs: const [
    Tab(text: '推荐'),
    Tab(text: '热门'),
    Tab(text: '关注'),
  ],

  // ① 指示器（下划线）样式
  indicatorColor: Colors.red,           // 指示器颜色
  indicatorWeight: 3,                   // 指示器高度（粗细）
  indicatorPadding: EdgeInsets.zero,    // 指示器左右内边距
  indicatorSize: TabBarIndicatorSize.label,  // 指示器宽度 = 文字宽度
  // indicatorSize: TabBarIndicatorSize.tab,  // 指示器宽度 = 整个 tab 宽度

  // 自定义指示器（比如圆角矩形）
  indicator: BoxDecoration(
    color: Colors.blue.withOpacity(0.2),
    borderRadius: BorderRadius.circular(20),
  ),

  // ② 文字样式
  labelColor: Colors.black,             // 选中文字颜色
  unselectedLabelColor: Colors.grey,    // 未选中文字颜色
  labelStyle: TextStyle(fontSize: 16, fontWeight: FontWeight.bold),
  unselectedLabelStyle: TextStyle(fontSize: 14),

  // ③ 布局
  isScrollable: true,                   // 标签过多时可横向滚动
  labelPadding: EdgeInsets.symmetric(horizontal: 20),  // 每个标签的内边距

  // ④ 交互
  onTap: (index) {
    print('点击了第 $index 个');
  },
)
```

### 常用小技巧

- **标签很多时**：设置 `isScrollable: true`，否则所有 Tab 会被挤在一行，文字变小。
- **指示器是个小方块**：用 `indicator` 自定义 `BoxDecoration`，可以做出"选中背景色"的效果。
- **Tab 不仅是文字**：`Tab` 组件支持 `text` + `icon`，也可以直接传 `child` 放任意 Widget。

```
Tab(
  child: Row(
    children: [
      Icon(Icons.star),
      SizedBox(width: 4),
      Text('收藏'),
    ],
  ),
)
```

## 四、TabBarView 的常用特性

```
TabBarView(
  controller: _tabController,
  physics: BouncingScrollPhysics(),   // 滑动到边界的回弹效果
  // physics: NeverScrollableScrollPhysics(), // 禁止滑动切换，只能点标签

  children: [
    Page1(),
    Page2(),
    Page3(),
  ],
)
```

### 重要：页面状态保持（AutomaticKeepAliveClientMixin）

默认情况下，`TabBarView` 切换时会**销毁**不可见的页面，切回来会重新 build。如果想保持页面状态（比如列表滚动位置、表单输入），需要在子页面的 State 中混入 `AutomaticKeepAliveClientMixin`：

```
class _PageAState extends State<PageA> with AutomaticKeepAliveClientMixin {
  @override
  bool get wantKeepAlive => true;  // 返回 true 表示保持状态

  @override
  Widget build(BuildContext context) {
    super.build(context);  // 必须调用 super
    return ListView.builder(
      itemCount: 50,
      itemBuilder: (_, i) => ListTile(title: Text('第 $i 条')),
    );
  }
}
```

## 五、底部 Tab 导航栏（BottomNavigationBar vs TabBar）

很多人会混淆 `TabBar` 和 `BottomNavigationBar`，这里做个区分：

|  | TabBar + TabBarView | BottomNavigationBar |
| --- | --- | --- |
| 位置 | 通常在顶部（AppBar.bottom） | 底部 Scaffold.bottomNavigationBar |
| 滑动切换 | 支持左右滑动切换 | 不支持，只能点击 |
| 适用场景 | 同层级内容切换（分类、频道） | App 主导航（首页/发现/我的） |
| 页面数量 | 可以很多（可滚动） | 通常 3~5 个 |

如果想做**底部的 Tab 且支持滑动**，可以把 `TabBar` 放到 `Scaffold.bottomNavigationBar` 里，配合 `TabBarView` 使用。

## 六、完整示例：可滚动的分类 Tab

```
class CategoryPage extends StatefulWidget {
  const CategoryPage({super.key});

  @override
  State<CategoryPage> createState() => _CategoryPageState();
}

class _CategoryPageState extends State<CategoryPage>
    with SingleTickerProviderStateMixin {
  late TabController _controller;

  final List<String> _categories = const [
    '推荐', '热门', '科技', '财经', '体育', '娱乐', '汽车', '游戏', '美食', '旅游'
  ];

  @override
  void initState() {
    super.initState();
    _controller = TabController(length: _categories.length, vsync: this);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('新闻分类'),
        bottom: TabBar(
          controller: _controller,
          isScrollable: true,
          labelColor: Colors.red,
          unselectedLabelColor: Colors.black54,
          indicatorColor: Colors.red,
          indicatorSize: TabBarIndicatorSize.label,
          tabs: _categories.map((c) => Tab(text: c)).toList(),
        ),
      ),
      body: TabBarView(
        controller: _controller,
        children: _categories.map((c) {
          return KeepAlivePage(
            child: ListView.builder(
              itemCount: 20,
              itemBuilder: (_, i) => ListTile(
                leading: CircleAvatar(child: Text('${i + 1}')),
                title: Text('$c - 新闻标题 ${i + 1}'),
                subtitle: Text('这是一条来自「$c」分类的新闻内容'),
              ),
            ),
          );
        }).toList(),
      ),
    );
  }
}

// 封装一个通用的保持状态组件
class KeepAlivePage extends StatefulWidget {
  final Widget child;
  const KeepAlivePage({super.key, required this.child});

  @override
  State<KeepAlivePage> createState() => _KeepAlivePageState();
}

class _KeepAlivePageState extends State<KeepAlivePage>
    with AutomaticKeepAliveClientMixin {
  @override
  bool get wantKeepAlive => true;

  @override
  Widget build(BuildContext context) {
    super.build(context);
    return widget.child;
  }
}
```

## 七、常见问题与踩坑

**1. 报错 "Controller's length property does not match"**

- 原因：`TabController.length` ≠ `TabBar.tabs` 数量 ≠ `TabBarView.children` 数量。
- 解决：确保三者数量完全一致。

**2. TabBar 放在 AppBar 外不显示/样式不对**

- 原因：`TabBar` 需要 `Material` 祖先组件提供主题。
- 解决：外面包一层 `Material`，或者放到 `AppBar.bottom` 里。

**3. 切换 Tab 后页面状态丢失、列表回到顶部**

- 原因：`TabBarView` 默认会销毁不可见页面。
- 解决：用 `AutomaticKeepAliveClientMixin` 或 `PageStorageKey`。

**4. 想监听滑动进度做联动动画**

- 用 `_tabController.animation`（一个 `Animation<double>`），值从 0 到 length-1，滑动时连续变化，可以用来驱动自定义动画。

```
AnimatedBuilder(
  animation: _tabController.animation!,
  builder: (_, __) {
    double value = _tabController.animation!.value;
    // 根据 value 做自定义联动
    return ...;
  },
)
```

**5. Tab 数量动态变化怎么办？**

- 动态改变 `length` 后，需要 `dispose` 旧 controller 并重新创建，或者用 `TabController(length: newLength, vsync: this)` 重建后赋值。

## 总结

三者的关系可以一句话概括：

> 
> **`TabController` 是"大脑"，`TabBar` 是"按钮"，`TabBarView` 是"内容"——三者共享同一个控制器，实现标签和页面的双向联动。**

- **简单场景** → 用 `DefaultTabController`，几行代码搞定。
- **需要监听/控制** → 手动创建 `TabController`，记得 `dispose`。
- **标签多** → `isScrollable: true`。
- **保持页面状态** → `AutomaticKeepAliveClientMixin`。
- **自定义样式** → `indicator`、`labelStyle` 等参数灵活定制。
