# Flutter BottomNavigationBar 详细介绍

`BottomNavigationBar` 是 Flutter 提供的**底部导航栏**组件，用于在 App 底部展示 3~5 个导航项，点击切换不同的主页面。它是移动端 App 最经典的导航模式之一（首页/发现/我的 这种结构）。

---

## 一、基本用法

```
class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  int _currentIndex = 0;  // 当前选中的索引

  // 对应的页面列表
  final List<Widget> _pages = const [
    HomeTab(),
    DiscoverTab(),
    ProfileTab(),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: _pages[_currentIndex],  // 根据索引显示对应页面
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _currentIndex,  // 当前选中项
        onTap: (index) {              // 点击切换
          setState(() {
            _currentIndex = index;
          });
        },
        items: const [
          BottomNavigationBarItem(
            icon: Icon(Icons.home),
            label: '首页',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.explore),
            label: '发现',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.person),
            label: '我的',
          ),
        ],
      ),
    );
  }
}
```

**核心要素：**

- `items`：导航项列表，类型是 `List<BottomNavigationBarItem>`
- `currentIndex`：当前选中的索引（从 0 开始）
- `onTap`：点击回调，参数是被点击项的索引

---

## 二、BottomNavigationBarItem 详解

每个导航项的配置：

```
BottomNavigationBarItem(
  icon: Icon(Icons.home_outlined),       // 未选中时的图标
  activeIcon: Icon(Icons.home),          // 选中时的图标（可选）
  label: '首页',                          // 文字标签
  backgroundColor: Colors.blue,          // 背景色（仅 shifting 模式下生效）
  tooltip: '首页',                        // 长按时的提示文字
)
```

**常用技巧：**

- 用 `activeIcon` 可以实现"选中/未选中"不同图标样式（比如 outline → filled）
- `label` 是必须的（Flutter 3.x 之后，`title` 参数已废弃，改用 `label`）

---

## 三、两种类型：fixed vs shifting

`BottomNavigationBar` 有两种显示类型，由 `type` 参数控制：

### 1. fixed（默认，≤3 项时自动使用）

所有项均匀分布，宽度相等，选中项略微放大：

```
BottomNavigationBar(
  type: BottomNavigationBarType.fixed,
  // ...
)
```

特点：

- 所有图标和文字始终可见
- 选中项颜色高亮，大小略大
- 适合 3~4 个导航项

### 2. shifting（≥4 项时自动使用）

选中项展开显示文字，未选中项只显示图标，有横向位移动画：

```
BottomNavigationBar(
  type: BottomNavigationBarType.shifting,
  // 注意：shifting 模式下，每个 item 的 backgroundColor 才会生效
  items: [
    BottomNavigationBarItem(
      icon: Icon(Icons.home),
      label: '首页',
      backgroundColor: Colors.blue,  // 整个导航栏的背景色会随选中项变化
    ),
    // ...
  ],
)
```

特点：

- 选中项显示图标+文字，未选中项只显示图标
- 导航栏背景色跟随选中项的 `backgroundColor` 变化
- 适合 4~5 个导航项，视觉更有层次

> 
> **注意：** 当 `items` 数量 ≤ 3 时，默认是 `fixed`；≥ 4 时，默认是 `shifting`。可以通过 `type` 参数强制指定。

## 四、样式定制大全

```
BottomNavigationBar(
  currentIndex: _currentIndex,
  onTap: (index) => setState(() => _currentIndex = index),

  // ① 颜色
  selectedItemColor: Colors.blue,        // 选中项颜色
  unselectedItemColor: Colors.grey,      // 未选中项颜色
  backgroundColor: Colors.white,         // 背景色（fixed 模式用这个）
  // fixed 模式下 backgroundColor 直接设置
  // shifting 模式下背景色由每个 item 的 backgroundColor 控制

  // ② 文字样式
  selectedFontSize: 14,                  // 选中文字大小
  unselectedFontSize: 12,                // 未选中文字大小
  selectedLabelStyle: TextStyle(         // 选中文字样式
    fontWeight: FontWeight.bold,
  ),
  unselectedLabelStyle: TextStyle(),     // 未选中文字样式
  showSelectedLabels: true,              // 是否显示选中项的文字
  showUnselectedLabels: true,            // 是否显示未选中项的文字

  // ③ 图标
  selectedIconTheme: IconThemeData(      // 选中图标主题
    size: 28,
    color: Colors.blue,
  ),
  unselectedIconTheme: IconThemeData(    // 未选中图标主题
    size: 24,
    color: Colors.grey,
  ),

  // ④ 布局与间距
  iconSize: 24,                          // 图标大小（统一设置）
  mouseCursor: SystemMouseCursors.click, // 鼠标悬停光标（桌面端）

  // ⑤ 其他
  elevation: 8,                          // 阴影高度
  enableFeedback: true,                  // 点击是否有触觉反馈（震动）
  landscapeLayout: BottomNavigationBarLandscapeLayout.centered, // 横屏布局

  items: const [
    BottomNavigationBarItem(icon: Icon(Icons.home), label: '首页'),
    BottomNavigationBarItem(icon: Icon(Icons.explore), label: '发现'),
    BottomNavigationBarItem(icon: Icon(Icons.person), label: '我的'),
  ],
)
```

## 五、页面状态保持：IndexedStack（重要）

直接用 `_pages[_currentIndex]` 切换页面有个问题：**每次切换都会重新 build 页面**，列表滚动位置、表单数据等都会丢失。

### 解决方案：IndexedStack

`IndexedStack` 会**同时构建所有子页面**，通过 `index` 控制显示哪一个，其他的只是隐藏（不销毁），状态完全保留：

```
Scaffold(
  body: IndexedStack(
    index: _currentIndex,
    children: _pages,  // 所有页面同时存在，切换不销毁
  ),
  bottomNavigationBar: BottomNavigationBar(
    // ...
  ),
)
```

**优点：**

- 页面状态完全保留（滚动位置、输入内容等）
- 切换瞬间完成，无加载延迟

**缺点：**

- 所有页面一次性初始化，启动时开销略大
- 页面多且复杂时，内存占用较高

> 
> **最佳实践：** 3~5 个主 Tab 用 `IndexedStack` 完全没问题；如果页面非常复杂或数量多，可以考虑 `PageView` + `AutomaticKeepAliveClientMixin` 的懒加载方案。

## 六、配合 PageView 实现滑动切换

如果想让底部导航**同时支持左右滑动切换**（类似 TabBarView 的效果），可以用 `PageView`：

```
class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage> {
  int _currentIndex = 0;
  final PageController _pageController = PageController();

  final List<Widget> _pages = const [
    HomeTab(),
    DiscoverTab(),
    ProfileTab(),
  ];

  @override
  void dispose() {
    _pageController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: PageView(
        controller: _pageController,
        onPageChanged: (index) {
          // 滑动页面时同步更新底部导航选中状态
          setState(() {
            _currentIndex = index;
          });
        },
        children: _pages,
      ),
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _currentIndex,
        onTap: (index) {
          // 点击底部导航时跳转到对应页面
          _pageController.animateToPage(
            index,
            duration: const Duration(milliseconds: 300),
            curve: Curves.easeInOut,
          );
        },
        items: const [
          BottomNavigationBarItem(icon: Icon(Icons.home), label: '首页'),
          BottomNavigationBarItem(icon: Icon(Icons.explore), label: '发现'),
          BottomNavigationBarItem(icon: Icon(Icons.person), label: '我的'),
        ],
      ),
    );
  }
}
```

**双向联动：**

- 点底部导航 → `animateToPage` 滑动到对应页面
- 左右滑动页面 → `onPageChanged` 更新底部选中项

> 
> **注意：** 底部导航通常不建议支持滑动切换，因为底部 Tab 一般是 App 的主导航层级，滑动容易和页面内的横向滚动冲突。是否支持滑动，取决于你的产品设计。

## 七、自定义底部导航栏

系统的 `BottomNavigationBar` 样式有限，想做更炫酷的效果（如凸起的中间按钮、渐变背景、动画图标等），可以完全自定义：

### 示例：带凸起按钮的底部导航

```
Scaffold(
  body: _pages[_currentIndex],
  floatingActionButton: FloatingActionButton(
    onPressed: () {},
    child: Icon(Icons.add),
  ),
  floatingActionButtonLocation: FloatingActionButtonLocation.centerDocked,
  bottomNavigationBar: BottomAppBar(
    shape: const CircularNotchedRectangle(),  // 中间凹陷
    notchMargin: 8,
    child: Row(
      mainAxisAlignment: MainAxisAlignment.spaceAround,
      children: [
        IconButton(
          icon: Icon(Icons.home, color: _currentIndex == 0 ? Colors.blue : Colors.grey),
          onPressed: () => setState(() => _currentIndex = 0),
        ),
        IconButton(
          icon: Icon(Icons.explore, color: _currentIndex == 1 ? Colors.blue : Colors.grey),
          onPressed: () => setState(() => _currentIndex = 1),
        ),
        const SizedBox(width: 40),  // 给中间凸起按钮留位置
        IconButton(
          icon: Icon(Icons.favorite, color: _currentIndex == 2 ? Colors.blue : Colors.grey),
          onPressed: () => setState(() => _currentIndex = 2),
        ),
        IconButton(
          icon: Icon(Icons.person, color: _currentIndex == 3 ? Colors.blue : Colors.grey),
          onPressed: () => setState(() => _currentIndex = 3),
        ),
      ],
    ),
  ),
)
```

这种 `BottomAppBar` + `FloatingActionButton` 的组合是经典的"中间凸起发布按钮"设计。

## 八、常见问题与踩坑

### 1. label 不显示 / 只显示图标

**原因：** `shifting` 模式下，未选中项默认不显示文字。

**解决：**

```
BottomNavigationBar(
  type: BottomNavigationBarType.fixed,  // 强制 fixed 模式
  showUnselectedLabels: true,           // 或者显式开启
)
```

### 2. 切换页面后状态丢失

**原因：** 直接用 `_pages[index]` 切换，页面会被销毁重建。

**解决：** 用 `IndexedStack` 或 `PageView` + `AutomaticKeepAliveClientMixin`。

### 3. 底部导航栏上方有一条白线 / 阴影

**原因：** `elevation` 默认有阴影。

**解决：**

```
BottomNavigationBar(
  elevation: 0,  // 去掉阴影
)
```

### 4. 键盘弹出时底部导航被顶上去

**原因：** `Scaffold` 默认会让 body 适应键盘高度。

**解决：**

```
Scaffold(
  resizeToAvoidBottomInset: false,  // 页面不随键盘上移
  // ...
)
```

> 
> 注意：这样设置后，输入框可能会被键盘遮挡，需要自行处理键盘弹起时的滚动。

### 5. 想给导航项加红点 / 消息角标

用 `Badge` 组件（Flutter 3.7+ 内置）或 `Stack` 自定义：

```
BottomNavigationBarItem(
  icon: Badge(
    label: Text('99+'),
    child: Icon(Icons.message),
  ),
  label: '消息',
)
```

### 6. 页面多了怎么办？

底部导航**不建议超过 5 个**。如果确实有更多入口，考虑：

- "我的"页面里放二级入口
- 用侧边抽屉（`Drawer`）
- 用顶部 `TabBar` 做分类

## 九、BottomNavigationBar vs TabBar 对比

| 对比项 | BottomNavigationBar | TabBar + TabBarView |
| --- | --- | --- |
| 位置 | 底部 | 通常在顶部 |
| 滑动切换 | 默认不支持（需配合 PageView） | 原生支持 |
| 适用场景 | App 主导航（首页/发现/我的） | 同级内容分类（推荐/热门/关注） |
| 数量 | 建议 3~5 个 | 可以很多（可滚动） |
| 状态保持 | 用 IndexedStack | 用 AutomaticKeepAliveClientMixin |
| 动画效果 | 简单的大小/颜色变化 | 滑动过渡动画 |

**选择建议：**

- **App 级主导航** → `BottomNavigationBar` + `IndexedStack`
- **同一页面内的内容分类** → `TabBar` + `TabBarView`

## 十、完整示例：标准三 Tab 结构

```
class MainPage extends StatefulWidget {
  const MainPage({super.key});

  @override
  State<MainPage> createState() => _MainPageState();
}

class _MainPageState extends State<MainPage> {
  int _currentIndex = 0;

  final List<Widget> _pages = const [
    HomePage(),
    DiscoverPage(),
    MessagePage(),
    ProfilePage(),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: IndexedStack(
        index: _currentIndex,
        children: _pages,
      ),
      bottomNavigationBar: BottomNavigationBar(
        type: BottomNavigationBarType.fixed,
        currentIndex: _currentIndex,
        onTap: (index) => setState(() => _currentIndex = index),
        selectedItemColor: Colors.blue,
        unselectedItemColor: Colors.grey,
        selectedFontSize: 12,
        unselectedFontSize: 12,
        items: const [
          BottomNavigationBarItem(
            icon: Icon(Icons.home_outlined),
            activeIcon: Icon(Icons.home),
            label: '首页',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.explore_outlined),
            activeIcon: Icon(Icons.explore),
            label: '发现',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.message_outlined),
            activeIcon: Icon(Icons.message),
            label: '消息',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.person_outline),
            activeIcon: Icon(Icons.person),
            label: '我的',
          ),
        ],
      ),
    );
  }
}
```

## 总结

- **`BottomNavigationBar`** 是底部导航栏，用于 App 主导航，建议 3~5 个项。
- **两种类型**：`fixed`（均匀分布）和 `shifting`（选中展开，背景色跟随）。
- **状态保持**：用 `IndexedStack` 最简单直接。
- **滑动切换**：配合 `PageView` 可以实现左右滑动。
- **自定义**：`BottomAppBar` + `FloatingActionButton` 可以做出中间凸起等复杂样式。
- **和 TabBar 的区别**：底部导航是 App 层级，Tab 是页面内的内容分类。
