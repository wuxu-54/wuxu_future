# Flutter 底部Tab + 多页面下拉刷新/上拉加载 完整落地方案

这是一套可直接复制运行、符合真实业务规范的完整实现方案，采用**底部Tab导航 + 通用刷新列表组件**的架构，3个页面独立维护数据与状态，支持下拉刷新、上拉分页加载、首次加载、错误重试、空状态等完整业务场景。

## 一、前置依赖

在 `pubspec.yaml` 中添加下拉刷新库，执行 `flutter pub get` 安装：

```
dependencies:
  flutter:
    sdk: flutter
  easy_refresh: ^3.4.0 # 可替换为 pub.dev 最新稳定版
```

## 二、整体架构设计

1. **主框架层**：`MainTabPage` 负责底部Tab导航与页面切换，使用 `IndexedStack` 实现页面保活，切换不丢失滚动位置与数据状态
2. **通用组件层**：`BaseRefreshPage` 封装通用的刷新、分页、状态处理逻辑，所有业务页面复用，避免重复代码
3. **业务页面层**：3个独立业务页面，仅需配置数据请求逻辑与列表项UI，无需重复实现刷新机制

// ===================== 通用刷新列表组件（核心复用层） =====================
/// 通用可刷新分页列表，泛型T支持自定义数据模型
class BaseRefreshPage<T> extends StatefulWidget {
  /// 数据请求回调：传入页码，返回对应页数据列表
  final Future<List<T>> Function(int page) fetchData;

  /// 列表项构建器：传入数据项和索引，返回Item Widget
  final Widget Function(T item, int index) itemBuilder;

  /// 每页数据量，默认10条
  final int pageSize;

  /// 空状态自定义Widget
  final Widget? emptyWidget;

  /// 错误状态自定义Widget
  final Widget? errorWidget;

  const BaseRefreshPage({
    super.key,
    required this.fetchData,
    required this.itemBuilder,
    this.pageSize = 10,
    this.emptyWidget,
    this.errorWidget,
  });

  @override
  State<BaseRefreshPage<T>> createState() => _BaseRefreshPageState<T>();
}

class _BaseRefreshPageState<T> extends State<BaseRefreshPage<T>> {
  late final EasyRefreshController _controller;
  final List<T> _dataList = [];
  int _currentPage = 1;
  bool _isFirstLoading = true; // 首次进入页面加载状态
  bool _hasError = false;

  @override
  void initState() {
    super.initState();
    _controller = EasyRefreshController(
      controlFinishRefresh: true,
      controlFinishLoad: true,
    );
    // 页面初始化自动加载数据
    _loadData(isRefresh: true);
  }

  @override
  void dispose() {
    _controller.dispose(); // 释放控制器，避免内存泄漏
    super.dispose();
  }

  /// 统一加载数据逻辑
  Future<void> _loadData({required bool isRefresh}) async {
    try {
      if (isRefresh) _currentPage = 1;

      // 执行数据请求（可替换为真实网络请求）
      final List<T> newData = await widget.fetchData(_currentPage);

      if (!mounted) return;
      setState(() {
        _hasError = false;
        _isFirstLoading = false;
        if (isRefresh) _dataList.clear();
        _dataList.addAll(newData);
        _currentPage++;
      });

      // 控制刷新/加载结束状态
      if (isRefresh) {
        _controller.finishRefresh();
        _controller.resetFooter(); // 刷新后重置加载更多状态，解除noMore
      } else {
        // 返回数据小于页大小，判定为无更多数据
        final bool noMore = newData.length < widget.pageSize;
        _controller.finishLoad(
          noMore ? IndicatorResult.noMore : IndicatorResult.success,
        );
      }
    } catch (e) {
      if (!mounted) return;
      setState(() {
        _hasError = true;
        _isFirstLoading = false;
      });
      // 结束加载并标记失败
      if (isRefresh) {
        _controller.finishRefresh();
      } else {
        _controller.finishLoad(IndicatorResult.fail);
      }
    }
  }

  @override
  Widget build(BuildContext context) {
    // 1. 首次加载中
    if (_isFirstLoading) {
      return const Center(child: CircularProgressIndicator(strokeWidth: 2));
    }

    // 2. 加载失败且无数据：显示错误重试页
    if (_hasError && _dataList.isEmpty) {
      return Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            const Icon(Icons.error_outline, size: 48, color: Colors.grey),
            const SizedBox(height: 12),
            const Text('加载失败，请检查网络', style: TextStyle(color: Colors.grey)),
            const SizedBox(height: 16),
            ElevatedButton(
              onPressed: () {
                setState(() => _isFirstLoading = true);
                _loadData(isRefresh: true);
              },
              child: const Text('重新加载'),
            ),
          ],
        ),
      );
    }

    // 3. 空数据状态
    if (_dataList.isEmpty) {
      return widget.emptyWidget ??
          const Center(child: Text('暂无数据', style: TextStyle(color: Colors.grey)));
    }

    // 4. 正常列表 + 刷新控件
    return EasyRefresh(
      controller: _controller,
      onRefresh: () => _loadData(isRefresh: true),
      onLoad: () => _loadData(isRefresh: false),
      // 可自定义刷新/加载指示器样式
      header: const ClassicHeader(),
      footer: const ClassicFooter(),
      child: ListView.builder(
        padding: const EdgeInsets.symmetric(vertical: 8),
        itemCount: _dataList.length,
        itemBuilder: (context, index) => widget.itemBuilder(_dataList[index], index),
      ),
    );
  }
}

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  /// 模拟首页数据请求，替换为真实接口即可
  Future<List<String>> _fetchData(int page) async {
    await Future.delayed(const Duration(seconds: 1));
    // 模拟3页后无更多数据
    if (page > 3) return [];
    return List.generate(10, (index) => '首页资讯 ${(page - 1) * 10 + index + 1}');
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('首页')),
      body: BaseRefreshPage<String>(
        fetchData: _fetchData,
        itemBuilder: (item, index) {
          return Card(
            margin: const EdgeInsets.symmetric(horizontal: 16, vertical: 6),
            elevation: 2,
            child: ListTile(
              leading: const CircleAvatar(child: Icon(Icons.article, size: 18)),
              title: Text(item),
              subtitle: Text('发布时间：2024-01-${index + 1}'),
              trailing: const Icon(Icons.chevron_right),
            ),
          );
        },
      ),
    );
  }
}

## 四、方案核心特性

1. **页面完全保活**：采用 `IndexedStack` 承载页面，切换Tab时页面不销毁，滚动位置、加载状态、输入内容完全保留，体验与原生App一致。
2. **逻辑高度复用**：所有刷新、分页、异常处理逻辑封装在 `BaseRefreshPage` 中，新增业务页面仅需20行左右代码，无需重复造轮子。
3. **完整业务状态**：覆盖首次加载中、加载失败重试、空数据、无更多数据四种核心业务场景，直接对接真实后端接口即可上线。
4. **类型安全**：支持泛型数据模型，可替换为自定义的业务实体类，避免类型转换错误。

## 五、业务落地改造指南

### 1. 替换真实网络请求

将每个页面 `_fetchData` 方法中的模拟逻辑，替换为真实的网络请求（如Dio），示例：

```
Future<List<OrderModel>> _fetchData(int page) async {
  // 真实接口请求
  final response = await Dio().get('/api/order/list', queryParameters: {
    'page': page,
    'pageSize': 10,
  });
  // 解析数据模型并返回
  return (response.data['list'] as List).map((e) => OrderModel.fromJson(e)).toList();
}
```

### 2. 自定义刷新样式

修改 `BaseRefreshPage` 中 `EasyRefresh` 的 `header` / `footer` 参数，可切换为官方内置样式：

- `MaterialHeader()`：安卓原生风格
- `CupertinoHeader()`：iOS原生风格
- `BezierHeader()`：贝塞尔动效风格

### 3. 支持左右滑动切换Tab

如果需要手势滑动切换页面，将 `IndexedStack` 替换为 `PageView`，并给子页面添加保活：

1. 主框架替换为 `PageView + PageController`
2. `BaseRefreshPage` 状态类混入 `AutomaticKeepAliveClientMixin`
3. 重写 `wantKeepAlive = true`，并在 `build` 中调用 `super.build(context)`

## 六、常见问题与优化

1. **列表卡顿优化**：复杂列表项提取为独立 `Widget`，尽量使用 `const` 构造，避免在 `itemBuilder` 中做耗时计算。
2. **Tab数量过多**：如果Tab超过5个，建议改用 `PageView` 懒加载方案，避免首屏一次性构建所有页面导致启动慢。
3. **刷新不触发**：确保子组件是可滚动Widget（ListView/GridView/CustomScrollView）；列表内容不足一屏时，可设置 `overScroll` 开启强制下拉。
4. **内存泄漏**：控制器已在 `dispose` 中释放，无需额外处理；请勿在全局单例中持有页面上下文。
