# Flutter 样式设定完全指南

## 一、样式设定的层级体系

Flutter 中的样式设定遵循**就近原则**，越具体的样式优先级越高：

```
全局主题 (ThemeData)
    │
    ▼
  组件主题 (TextTheme / ButtonTheme 等)
    │
    ▼
  父组件样式 (继承自父级)
    │
    ▼
  组件自身样式 (直接设置)
    │
    ▼
  局部覆盖 (copyWith / merge)
```

  theme: ThemeData(

## 四、主题的使用与覆盖

### 4.1 获取主题

```
// 获取当前主题
final theme = Theme.of(context);

// 获取颜色方案
final colorScheme = Theme.of(context).colorScheme;

// 获取文本主题
final textTheme = Theme.of(context).textTheme;

// 使用文本主题样式
Text(
  '标题',
  style: Theme.of(context).textTheme.headlineMedium,
)
```

### 4.2 局部覆盖主题

```
// 方式1：Theme 组件包裹
Theme(
  data: Theme.of(context).copyWith(
    primaryColor: Colors.green,
  ),
  child: MyWidget(),
)

// 方式2：局部覆盖特定组件主题
Theme(
  data: Theme.of(context).copyWith(
    elevatedButtonTheme: ElevatedButtonThemeData(
      style: ElevatedButton.styleFrom(
        backgroundColor: Colors.green,
      ),
    ),
  ),
  child: Column(
    children: [
      ElevatedButton(onPressed: () {}, child: Text('绿色按钮')),
    ],
  ),
)
```

### 4.3 样式合并 `merge` / `copyWith`

```
// TextStyle 合并
Text(
  'Hello',
  style: Theme.of(context).textTheme.titleLarge?.copyWith(
    color: Colors.red,
    fontSize: 20,
  ),
)

// ThemeData 合并
final myTheme = ThemeData.light().copyWith(
  primaryColor: Colors.purple,
  textTheme: ThemeData.light().textTheme.apply(
    bodyColor: Colors.black87,
    displayColor: Colors.black,
  ),
)
```

## 六、响应式样式

### 6.1 屏幕尺寸适配

```
class ResponsiveUtils {
  static double screenWidth(BuildContext context) => 
      MediaQuery.of(context).size.width;
  
  static double screenHeight(BuildContext context) => 
      MediaQuery.of(context).size.height;
  
  static bool isMobile(BuildContext context) => 
      screenWidth(context) < 600;
  
  static bool isTablet(BuildContext context) => 
      screenWidth(context) >= 600 && screenWidth(context) < 1200;
  
  static bool isDesktop(BuildContext context) => 
      screenWidth(context) >= 1200;
  
  // 根据屏幕宽度返回不同值
  static T responsiveValue<T>(
    BuildContext context, {
    required T mobile,
    T? tablet,
    T? desktop,
  }) {
    if (isDesktop(context) && desktop != null) return desktop;
    if (isTablet(context) && tablet != null) return tablet;
    return mobile;
  }
}

// 使用
Container(
  width: ResponsiveUtils.responsiveValue(
    context,
    mobile: 200,
    tablet: 300,
    desktop: 400,
  ),
)
```

### 6.2 文字大小适配

```
extension TextStyleExtension on TextStyle {
  TextStyle responsive(BuildContext context) {
    final width = MediaQuery.of(context).size.width;
    final scale = width / 375; // 以 375 为基准
    return copyWith(fontSize: (fontSize ?? 14) * scale.clamp(0.8, 1.2));
  }
}

// 使用
Text(
  '响应式文字',
  style: TextStyle(fontSize: 16).responsive(context),
)
```

## 八、样式最佳实践

### 8.1 设计规范

| 原则 | 说明 |
| --- | --- |
| **统一设计令牌** | 颜色、字体、间距、圆角等统一管理，不硬编码 |
| **语义化命名** | `primary` / `success` / `warning` 而非 `red` / `blue` |
| **层级清晰** | 全局主题 → 组件主题 → 局部覆盖 |
| **响应式** | 适配不同屏幕尺寸 |
| **暗色模式** | 同时支持亮色/暗色主题 |

### 8.2 性能优化

```
// ❌ 避免：每次 build 都创建新的样式
Widget build(BuildContext context) {
  return Text(
    'Hello',
    style: TextStyle(fontSize: 16, color: Colors.blue), // 每次都新建
  );
}

// ✅ 推荐：提取为常量或使用主题
static const _textStyle = TextStyle(fontSize: 16, color: Colors.blue);

Widget build(BuildContext context) {
  return Text('Hello', style: _textStyle);
}

// ✅ 推荐：使用主题
Text('Hello', style: Theme.of(context).textTheme.bodyMedium)
```

## 十、总结

| 层级 | 方式 | 适用场景 |
| --- | --- | --- |
| **全局** | `ThemeData` + `MaterialApp` | App 整体风格统一 |
| **页面/区域** | `Theme` 组件 + `copyWith` | 某个模块/页面特殊风格 |
| **组件** | 组件 `style` / `decoration` 属性 | 单个组件样式 |
| **文本** | `TextStyle` | 文字样式 |
| **自定义** | 设计系统类（Colors/Spacing/TextStyles） | 设计规范统一管理 |

**核心原则：**

1. 能用主题就不用硬编码
2. 能用常量就不用每次创建
3. 样式统一管理，便于维护和修改
4. 支持暗色模式和响应式
