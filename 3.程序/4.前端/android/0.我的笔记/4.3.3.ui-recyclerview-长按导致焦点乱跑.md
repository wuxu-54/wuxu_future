# 长按导致焦点乱跑

问题：TV开发，Recyclerview是3列的。  遥控器长按上下键时，比如长按下键，本来焦点在第一列，结果到底部时可能会聚焦到第二列的位置，非长按时逻辑正常。我猜测跟快速滚动有关。

## 解决方案

介绍Recyclerview两个方法的作用：

- requestChildFocus（焦点获取时的基础操作）- 与本问题无关，只是了解下作用。
    1. 核心作用, 当 RecyclerView 的某个 Item 拿到焦点时，会触发这个方法，主要做 2 件事：
      - 通知 RecyclerView：「这个 Item 是焦点项了」；
      - 计算焦点项需要的居中偏移量（比如 3 列布局中，让焦点项在列内居中），给后续滚动校准定规矩。
    2. 对你的问题的价值：长按上下键时，每次焦点切换都会走这个方法，提前算好「只能在当前列垂直居中」的偏移量，避免焦点一开始就跑偏到其他列。
- requestChildRectangleOnScreen（焦点滚动的精准控制）
    1. 核心作用，焦点项不在屏幕可视区域（或位置不对）时，RecyclerView 会调用这个方法，强制把焦点项滚动到屏幕内，核心是「算准滚动的方向和距离」。
    2. 对你的问题的价值，它被重写后，只允许垂直方向滚动（上下键），完全禁止水平滚动（左右），哪怕长按快速滚动，焦点也只能在当前列的垂直方向动，根本跨不到第二列。

解决方法：重新crequestChildRectangleOnScreen，手动设置滚动距离，避免快速滚动。

代码示例：

```java
public boolean requestChildRectangleOnScreen(View child, Rect rect, boolean immediate) {
    // 1. 计算父容器的有效区域（排除 padding）
    int parentLeft = this.getPaddingLeft();
    int parentTop = this.getPaddingTop();
    int parentRight = this.getWidth() - this.getPaddingRight();
    int parentBottom = this.getHeight() - this.getPaddingBottom();
    
    // 2. 计算子View（焦点项）的绝对位置
    int childLeft = child.getLeft() + rect.left;
    int childTop = child.getTop() + rect.top;
    int childRight = childLeft + rect.width();
    int childBottom = childTop + rect.height();
    
    // 3. 核心：计算焦点项的滚动偏移量（强制居中）
    // mSelectedItemOffsetStart/End 是居中偏移量（在requestChildFocus中计算）
    int offScreenLeft = Math.min(0, childLeft - parentLeft - this.mSelectedItemOffsetStart);
    int offScreenTop = Math.min(0, childTop - parentTop - this.mSelectedItemOffsetStart);
    int offScreenRight = Math.max(0, childRight - parentRight + this.mSelectedItemOffsetEnd);
    int offScreenBottom = Math.max(0, childBottom - parentBottom + this.mSelectedItemOffsetEnd);
    
    // 4. 区分横竖布局，只计算对应方向的滚动偏移
    boolean canScrollHorizontal = this.getLayoutManager().canScrollHorizontally();
    boolean canScrollVertical = this.getLayoutManager().canScrollVertically();
    int dx = canScrollHorizontal ? (ViewCompat.getLayoutDirection(this) == 1 ? offScreenRight : offScreenLeft) : 0;
    int dy = canScrollVertical ? offScreenTop : 0;
    
    // 5. 关键：只滚动必要的偏移量，且禁止过度滚动
    if (dx != 0 || dy != 0) {
        this.scrollBy(dx, dy);
        return true;
    }
    
    this.postInvalidate();
    return false;
}
```
