# 混淆

## 1. 组件包混淆必须要增加前缀

混淆时，如果使用组件包，则必须增加包名前缀，否则会出现与其他包的包名冲突问题。

原因：混淆后，完整包名、类名是：a.a  b.b c.c  这样的，假如其他组件混淆时也没有注意添加包名前缀，则其他组件的包名会冲突，导致无法打包成功。

解决办法: 强制让其中一个 SDK 的所有类，在编译时自动加上自定义包前缀 a.a → my.umessage.a.a

```txt
# 强制重命名 uMessageSDK 所有类，添加前缀：com.haier.umessage.
-repackageclasses 'com.haier.umessage'
-keep class com.haier.umessage.** { *; }

# 如果你只想对某个包生效：解释：-repackageclasses '前缀' included in 依赖包名
-repackageclasses 'com.haier.umessage' included in com.haier.uhome.uMessageSDK
```
