# 移除Item出现的焦点乱跑

问题 ： 实际TV项目有这样一个需求，焦点在底部item，按返回键滚动并且焦点聚焦第一个条目，这时GridlayoutManager多个列的列表在滚动时原底部item被移除，此时Recyclerview会触发自动寻焦，导致焦点乱跑，同时也会影响到滚动事件被异常终止。

## 解决方案

问题代码：

```kotlin
 override fun onBackPressed() {
    (pBinding.recyclerView.layoutManager as GridLayoutManager).scrollToPositionWithOffset(
        0,
        0
    )
    // 等待滚动完成后请求焦点
    pBinding.recyclerView.post {
        for (i in 0 until pBinding.recyclerView.childCount) {
            val itemType = mConEquAdapter.getItemViewType(i)
            if (itemType == EquipmentMaintenanceAdapter.ITEM_TYPE_CLEAN || itemType == EquipmentMaintenanceAdapter.ITEM_TYPE_CONSUMABLES) {
                pBinding.recyclerView.getChildAt(i)?.customRequestFocus()
                return@post
            }
        }
    }
}
```

解法：先让Recyclerview获取焦点，等滚动完成再让条目view获取焦点

```kotlin
 override fun onBackPressed() {
    pBinding.recyclerView.isFocusable=true
    pBinding.recyclerView.descendantFocusability=ViewGroup.FOCUS_BEFORE_DESCENDANTS
    pBinding.recyclerView.customRequestFocus()

    (pBinding.recyclerView.layoutManager as GridLayoutManager).scrollToPositionWithOffset(
        0,
        0
    )
    // 等待滚动完成后请求焦点
    pBinding.recyclerView.post {
        for (i in 0 until pBinding.recyclerView.childCount) {
            val itemType = mConEquAdapter.getItemViewType(i)
            if (itemType == EquipmentMaintenanceAdapter.ITEM_TYPE_CLEAN || itemType == EquipmentMaintenanceAdapter.ITEM_TYPE_CONSUMABLES) {
                pBinding.recyclerView.getChildAt(i)?.customRequestFocus()
                return@post
            }
        }

        pBinding.recyclerView.isFocusable=false
        pBinding.recyclerView.isFocusableInTouchMode=false
        pBinding.recyclerView.descendantFocusability=ViewGroup.FOCUS_AFTER_DESCENDANTS
    }
}
```
