# 逐行带注释：`ZygoteConnection.java handleChildProc`
>
> 调用时机：fork完成后，**只有子进程会进入这个函数**，父进程不会走到这里。
> 返回值：`Runnable`，这个Runnable就是回到`runSelectLoop`执行`command.run()`，最终触发`ActivityThread.main`

```java
// 子进程处理逻辑，forkAndSpecialize之后，子进程进入此方法
private Runnable handleChildProc(ZygoteArguments parsedArgs,
        FileDescriptor pipeFd, boolean isZygote) {
/*
 * By the time we get here, the native code has closed the two actual Zygote
 * socket connections, and substituted /dev/null in their place.  The LocalSocket
 * objects still need to be closed properly.
 */
/*
 * 注释翻译：执行到这里的时候，native层代码已经关闭了真实的Zygote socket连接，
 * 并且把socket fd替换成/dev/null。但Java层LocalSocket对象，仍然需要手动做关闭清理。
 * 【重点】子进程不再需要Zygote服务socket，必须全部关掉，防止子进程意外复用Zygote监听fd
 */

    closeSocket();
    // Java层关闭当前和AMS通信的LocalSocket对象，释放资源

    Zygote.setAppProcessName(parsedArgs, TAG);
    // 设置当前App进程名（ps看到的进程名称），从AMS传递过来的参数解析得到

    // End of the postFork event.
    Trace.traceEnd(Trace.TRACE_TAG_ACTIVITY_MANAGER);
    // 结束Trace埋点，性能追踪标记，用于systrace抓取fork阶段耗时

    if (parsedArgs.mInvokeWith != null) {
        // 分支：mInvokeWith不为null，代表使用wrapper包装器启动（比如app调试、profiling、性能分析场景）
        WrapperInit.execApplication(parsedArgs.mInvokeWith,
                parsedArgs.mNiceName, parsedArgs.mTargetSdkVersion,
                VMRuntime.getCurrentInstructionSet(),
                pipeFd, parsedArgs.mRemainingArgs);

        // Should not get here.
        // 注释：正常情况下execApplication会调用exec系统调用，替换整个进程镜像，永远不会return回来。
        // 如果代码跑到这里说明exec失败，抛出异常
        throw new IllegalStateException("WrapperInit.execApplication unexpectedly returned");
    } else {
        // 普通App启动场景，不走wrapper
        if (!isZygote) {
            // 普通应用进程（不是子Zygote），进入 ZygoteInit.zygoteInit
            return ZygoteInit.zygoteInit(parsedArgs.mTargetSdkVersion,
                    parsedArgs.mDisabledCompatChanges,
                    parsedArgs.mEnabledCompatChanges,
                    parsedArgs.mRemainingArgs, null /* classLoader */);
        } else {
            // isZygote=true：子Zygote场景（极少用，多Zygote架构）
            return ZygoteInit.childZygoteInit(
                    parsedArgs.mRemainingArgs /* classLoader */);
        }
    }
}
```

## 核心执行链路（普通App，走`ZygoteInit.zygoteInit`）

```
handleChildProc
    ↓ ZygoteInit.zygoteInit()
        ↓ RuntimeInit.applicationInit()
            ↓ RuntimeInit.findStaticMain()
                → 反射找到 ActivityThread.main，封装成Runnable返回
    ← 返回这个Runnable给 processCommand()
    ← 继续return，一层层回到 ZygoteServer.runSelectLoop
        runSelectLoop 执行 command.run()
            → Runnable内部反射调用 ActivityThread.main()
```

## 关键分支说明

### 1. `parsedArgs.mInvokeWith != null`（Wrapper模式）

`WrapperInit.execApplication()` 底层会调用linux `exec()`系统调用。
`exec`的特性：**直接替换当前进程的可执行镜像**，原来Zygote的代码全部被替换，**不会return回来**。
> 多用于：debug调试app、gprof性能分析、内存分析。
> 如果exec成功，下面的throw永远执行不到；exec失败才抛异常。

### 2. `!isZygote`（绝大多数普通App，你重点关心）

调用`ZygoteInit.zygoteInit`，最终返回**Runnable任务对象**。
这个Runnable就是用来启动`ActivityThread.main`的载体。

### 3. `isZygote = true` 子Zygote（了解即可）

多Zygote场景，会fork一个**子Zygote进程**，子Zygote继续维护socket循环，继续孵化app。
普通手机默认不走这个分支。

## 两个重点知识点

1. **closeSocket()**
    native层已经把底层fd关闭，Java层还要调用`closeSocket()`销毁LocalSocket对象。
    目的：**子进程绝对不能持有Zygote监听socket的句柄**。如果不关闭，子进程也会监听zygote socket，引发严重错乱。

2. 返回Runnable的意义
`handleChildProc` 把Runnable return出去，一路回到`runSelectLoop`，在`runSelectLoop`执行`command.run()`。

> 这就是Android12+USAP版本，**抛弃老版本抛MethodAndArgsCaller异常跳栈**的新方案。

## 配套：ZygoteInit.zygoteInit 内部简化代码

```java
public static Runnable zygoteInit(int targetSdkVersion, long[] disabledCompatChanges,
        long[] enabledCompatChanges, String[] argv, ClassLoader classLoader) {
    RuntimeInit.commonInit();          // 初始化异常处理器、时区、Binder基础环境
    ZygoteInit.nativeZygoteInit();     // native初始化binder线程池
    return RuntimeInit.applicationInit(targetSdkVersion, disabledCompatChanges, argv, classLoader);
}
```

`RuntimeInit.applicationInit` 调用`findStaticMain`生成目标Runnable。

## 整条链路汇总（接上你前面runSelectLoop）

```
runSelectLoop
    → processCommand()
        → Zygote.forkAndSpecialize()
            子进程 → handleChildProc()
                → ZygoteInit.zygoteInit()
                    → RuntimeInit.applicationInit()
                        → findStaticMain() 生成 Runnable（ActivityThread.main）
                return Runnable
        return Runnable command
    runSelectLoop 执行 command.run()
        → invoke ActivityThread.main()
```
