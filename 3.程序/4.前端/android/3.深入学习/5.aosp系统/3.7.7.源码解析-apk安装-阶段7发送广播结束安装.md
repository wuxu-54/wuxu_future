# 阶段7：发送系统广播、通知Launcher更新图标，结束安装会话
> 前置：阶段6完成，PMS内存缓存、packages.xml持久化成功；APK文件、data目录、oat编译产物全部部署完毕。
> 执行主体：**PMS（system_server）**

## 7.1 关闭安装Session，结束PackageInstaller会话
1. PMS通知`PackageInstallerService`，标记本次安装会话成功完成。
2. 清理 `/data/app-staging` 下残留临时文件（staging目录不再需要）。
3. 向前端PackageInstaller页面返回**安装成功**，弹窗提示安装完成。
> 如果是adb install，adb命令收到返回码0，打印Success。

## 7.2 发送应用安装广播（核心）
PMS发送对应的Intent系统广播：
- **全新安装**：`Intent.ACTION_PACKAGE_ADDED`
- **覆盖升级**：`Intent.ACTION_PACKAGE_REPLACED`

### 广播关键特点
1. 广播携带data Uri：`package:com.xxx.app`，携带包名；
2. 广播是**有序广播**；
3. 广播权限限制：普通App不能随意接收，需要声明对应权限；
4. 不会主动拉起所有App，只是发给已经注册该广播的接收器。

> 注意：Android高版本对系统广播有限制，静态注册广播会有后台限制，但Launcher、系统应用可以正常接收。

### 额外广播（升级场景）
升级时还会发送 `ACTION_PACKAGE_REMOVED` 先通知旧包移除（但`/data/data`目录保留），再发送`ACTION_PACKAGE_REPLACED`。

## 7.3 Launcher（桌面）接收广播，更新图标
Launcher提前静态注册了`PACKAGE_ADDED` / `PACKAGE_REPLACED`广播：
1. Launcher收到广播，拿到包名；
2. Launcher调用`PackageManager`（Binder跨进程），向PMS查询这个应用信息：label应用名称、icon图标、是否有LAUNCHER类型的Activity；
3. 解析Intent-filter，查找带有`android.intent.category.LAUNCHER`的Activity；
4. 如果找到，在桌面数据库插入/更新应用图标条目，桌面UI刷新，出现应用图标。

> 关键点：
> - 图标**不是广播直接携带**，广播只通知“包变化了”；图标、名称由Launcher主动从PMS查询；
> - 如果应用没有LAUNCHER入口Activity，桌面不会显示图标（比如纯SDK、后台服务App）。

## 7.4 其他系统组件接收广播，做各自业务
除Launcher外，其他系统服务/应用收到广播做处理：
1. 权限管理模块：刷新权限列表；
2. 电池、流量统计服务：新增应用统计项；
3. 应用管理页面：刷新已安装应用列表；
4. 备份服务：识别新增应用，纳入备份候选。

## 7.5 安装全流程收尾
1. PMS完成本次安装全部流程，所有状态落定；
2. 此时用户可以：点击桌面图标启动App；通过PackageManager查询包信息。

# 完整安装全链路复盘（汇总）
1. 创建安装Session，APK写入 `/data/app-staging` 临时目录
2. PackageParser解析APK、读取AndroidManifest，构建Package对象
3. PMS执行APK完整性 + V2/V3签名校验，覆盖安装校验签名公钥一致性
4. PMS预校验、分配/复用UID、权限预处理（危险权限仅登记）
5. PMS Binder调用installd，移动APK、创建data目录、提取so、dex2oat编译
6. PMS更新mPackages内存缓存，持久化写入packages.xml / packages.list；升级异步删除旧APK目录
7. 关闭安装会话、清理staging目录；发送PACKAGE_ADDED / REPLACED广播；Launcher刷新桌面图标

# 面试考点
1. 广播**只做通知**，不携带图标、应用名称；Launcher收到广播后主动通过PackageManager查询PMS获取信息。
2. 全新：`ACTION_PACKAGE_ADDED`；覆盖升级：`ACTION_PACKAGE_REPLACED`。
3. staging临时目录在本阶段清理。
4. 桌面是否显示图标，取决于应用是否存在带`LAUNCHER` category的Activity。
5. 广播是系统通知，**不是App启动**，此时App进程没有被创建。

# 时序简图
```
阶段6持久化完成
    ↓
关闭PackageInstaller安装session，清理/data/app-staging临时文件
    ↓
PMS发送广播：PACKAGE_ADDED / PACKAGE_REPLACED
    ↓
Launcher接收广播 → 调用PackageManager查询应用label、icon、Launcher Activity
    ↓
更新桌面数据库，刷新桌面图标
    ↓
其他系统服务同步刷新应用相关信息
    ↓
✅ APK安装流程全部结束
```
