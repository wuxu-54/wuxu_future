# Android 性能分析工具 Perfetto 全面详解

## 一、概述与定位

**Perfetto** 是 Google 开发的开源高性能系统追踪框架，自 Android 10 (API 29) 起成为 Android 平台的默认性能分析工具，全面替代了已停止维护的 Systrace 。它是一个完整的工具套件，包含 SDK、守护进程和分析工具，用于帮助开发者理解复杂系统的行为，定位功能和性能问题 。

### 核心设计目标

- **低开销**：典型追踪场景下 CPU 占用率 < 5%，支持生产环境使用
- **高精度**：纳秒级时间戳精度
- **长时追踪**：支持数小时的持续数据采集，不受内存限制
- **全栈覆盖**：从 Linux 内核到应用层的完整数据采集能力
- **强大分析**：内置 SQL 查询引擎，支持复杂的程序化分析

## 二、Perfetto 与 Systrace 详细对比

| 特性 | Perfetto | Systrace |
|------|----------|----------|
| 引入版本 | Android 9 (实验性)，Android 10+ 正式支持 | Android 4.1 |
| 维护状态 | 持续活跃开发 | 已停止开发，仅保留兼容性 |
| 数据格式 | Protobuf 二进制格式，体积小 | JSON 格式，体积大 |
| 最大追踪时长 | 数小时（流式写入文件） | 通常 1-5 分钟（内存限制） |
| 分析能力 | 内置 SQLite 数据库，支持 SQL 查询 | 仅基于浏览器的简单可视化 |
| 可视化体验 | 流畅的 Web 界面，支持 GB 级文件 | 大文件下操作严重卡顿 |
| Native 层支持 | 完整支持锁竞争、函数调用、堆内存 | 仅能捕捉 Java 层锁等待 |
| Binder 通信分析 | 全链路追踪，显示源/目标进程和事务 | 仅显示简单时间轴 |
| 内存分析 | 支持 Native 堆和 Java 堆详细分析 | 无原生支持 |
| 电量分析 | 集成系统电量计数器 | 无原生支持 |
| 自动化支持 | 完善的 CLI 和 API，适合 CI/CD | 有限的脚本支持 |

**选择建议**：

- Android 10 及以上设备：**强烈推荐使用 Perfetto**
- Android 9 及以下设备：使用 Systrace 或升级设备
- 需要深度分析、自动化或长时追踪：必须使用 Perfetto

## 三、整体架构与核心组件

Perfetto 采用生产者-消费者架构，由三个核心部分组成：

### 1. 追踪服务 (traced)

- 系统级守护进程，运行在 `/system/bin/traced`
- 作为整个追踪系统的协调中心
- 管理所有数据源的生命周期和配置
- 分配和管理共享内存缓冲区
- 将数据序列化并写入 trace 文件

### 2. 系统探针 (traced_probes)

- 运行在 `/system/bin/traced_probes`
- 负责采集内核层和系统层数据
- 集成 Linux ftrace、procfs、sysfs 等接口
- 提供 heapprofd、java_hprof 等专用分析器

### 3. 消费者 (Consumers)

- 向 traced 发送追踪配置请求
- 接收和处理追踪数据
- 主要包括：
  - `adb shell perfetto` 命令行工具
  - Android Studio Profiler
  - Perfetto Web UI (ui.perfetto.dev)
  - 应用内集成的 SDK

### 数据传输机制

Perfetto 使用**共享内存缓冲区 (Shared Memory Buffer, SMB)** 实现数据零拷贝传输：

- Producer 进程与 traced 进程通过 mmap 共享同一块内存
- 数据以 4KB 为单位的 Chunk 进行管理
- Producer 写满一个 Chunk 后通知 traced 读取
- traced 将数据序列化为 Protobuf 格式写入文件

## 四、主要数据源与性能指标

Perfetto 支持数十种数据源，覆盖 Android 系统的各个层面：

### 1. 内核层数据源

- **sched**：CPU 调度事件（线程切换、进程创建/销毁）
- **freq**：CPU 频率和电压变化
- **idle**：CPU 空闲状态
- **irq**：中断处理
- **block**：块设备 I/O 操作
- **binder_driver**：Binder 跨进程通信
- **syscalls**：系统调用

### 2. 系统服务数据源

- **am** (ActivityManager)：Activity 生命周期、进程管理
- **wm** (WindowManager)：窗口管理、动画
- **gfx** (Graphics)：图形渲染、SurfaceFlinger
- **view**：View 系统绘制
- **input**：输入事件处理
- **hal**：硬件抽象层事件
- **dalvik**：ART 虚拟机事件（GC、类加载）

### 3. 专用分析数据源

- **android.heapprofd**：Native 堆内存分析
- **android.java_hprof**：Java 堆转储
- **android.power**：电量和功耗数据
- **android.gpu.memory**：GPU 内存使用
- **android.log**：Logcat 日志
- **process_stats**：进程统计信息（CPU、内存）

## 五、使用方法

### 1. Perfetto Web UI 方式（推荐）

这是最简单直观的使用方式：

1. 打开浏览器访问 <https://ui.perfetto.dev>
2. 点击左侧 "Record new trace"
3. 确保 Android 设备已连接并开启 USB 调试
4. 在 "Recording page" 中配置：
   - 选择目标设备
   - 设置追踪时长
   - 勾选需要的数据源
5. 点击 "Start Recording" 开始采集
6. 操作设备复现性能问题
7. 采集完成后自动在 UI 中显示分析结果

### 2. 命令行方式

#### 基础命令

```bash
# 采集 20 秒系统追踪
adb shell perfetto \
  -o /data/misc/perfetto-traces/trace.perfetto-trace \
  -t 20s \
  sched freq idle am wm gfx view binder_driver hal dalvik input

# 拉取 trace 文件到本地
adb pull /data/misc/perfetto-traces/trace.perfetto-trace
```

#### 使用配置文件（推荐复杂场景）

```bash
# 生成配置文件（可从 UI 中复制）
cat > config.pbtx << EOF
buffers: {
  size_kb: 63488
  fill_policy: RING_BUFFER
}
data_sources: {
  config {
    name: "linux.ftrace"
    ftrace_config {
      ftrace_events: "sched/sched_switch"
      ftrace_events: "power/cpu_frequency"
    }
  }
}
duration_ms: 10000
EOF

# 使用配置文件采集
cat config.pbtx | adb shell perfetto -c - --txt -o /data/misc/perfetto-traces/trace.perfetto-trace
```

#### 使用官方辅助脚本

```bash
# 下载脚本
curl -LO https://raw.githubusercontent.com/google/perfetto/master/tools/record_android_trace

# 简单采集（自动拉取并打开浏览器）
python3 record_android_trace -o trace.perfetto-trace -t 10s
```

### 3. Android Studio 集成

- Android Studio Arctic Fox (2020.3.1) 及以上版本内置 Perfetto 支持
- 打开 "Profiler" 窗口
- 选择 "System Trace" 选项卡
- 点击 "Record" 开始采集

## 六、数据分析与可视化

### 1. 时间轴视图

Perfetto UI 的核心是交互式时间轴，主要包含以下轨道：

- **CPU 轨道**：显示每个 CPU 核心上运行的线程
- **进程轨道**：显示每个进程的线程和事件
- **帧轨道**：显示应用渲染的每一帧及其耗时
- **VSync 轨道**：显示系统 VSync 信号
- **内存轨道**：显示系统和应用内存使用情况
- **电量轨道**：显示电量消耗和唤醒锁

### 2. 基本操作

- **缩放**：鼠标滚轮或触摸板双指缩放
- **平移**：鼠标拖动或触摸板双指平移
- **选择**：点击事件查看详细信息
- **搜索**：使用顶部搜索框查找特定事件
- **命令面板**：`Ctrl+Shift+P` (Windows/Linux) 或 `Cmd+Shift+P` (Mac)

### 3. SQL 查询分析

这是 Perfetto 最强大的功能之一，允许你对 trace 数据进行复杂查询：

1. 在 UI 中点击左侧 "Query (SQL)"
2. 输入 SQL 查询语句
3. 点击 "Run" 执行查询

**常用查询示例**：

```sql
-- 统计主线程所有切片的耗时
SELECT name, SUM(dur)/1e6 AS total_ms, COUNT(*) AS count
FROM slice
WHERE track_id IN (
  SELECT id FROM thread_track
  WHERE utid IN (
    SELECT utid FROM thread
    WHERE name = 'main' AND upid IN (
      SELECT upid FROM process WHERE name = 'com.example.myapp'
    )
  )
)
GROUP BY name
ORDER BY total_ms DESC
LIMIT 20;

-- 查找耗时超过 16ms 的帧
SELECT ts, dur/1e6 AS frame_ms
FROM slice
WHERE name = 'Choreographer#doFrame' AND dur > 16e6
ORDER BY dur DESC;
```

## 七、高级功能

### 1. CPU Profiling

Perfetto 支持基于采样的 CPU 分析，基于 Linux `perf_event_open` 系统调用：

**工作原理**：

1. 配置采样事件（时间或硬件计数器）
2. CPU 周期性触发采样中断
3. 记录当前进程的调用栈
4. 离线解析符号信息
5. 生成火焰图展示

**使用方法**：

```bash
# 下载 CPU Profiling 脚本
curl -LO https://raw.githubusercontent.com/google/perfetto/master/tools/cpu_profile

# 对指定应用进行 CPU 分析（100Hz 采样）
python3 cpu_profile -n com.example.myapp -f 100

# 采集完成后生成：
# - raw-trace: 完整 trace 文件
# - profile.*.pb: pprof 格式文件，可用于生成火焰图
```

### 2. Native 堆内存分析 (heapprofd)

heapprofd 是 Perfetto 内置的低开销 Native 堆分析器：

- 通过挂钩 malloc/free/new/delete 函数
- 记录每次内存分配的调用栈和大小
- 支持采样以降低开销
- 可检测内存泄漏和内存碎片

### 3. Java 堆分析 (java_hprof)

- 支持采集 Java 堆转储
- 与 Android Studio 的 Heap Dump 功能兼容
- 可在 Perfetto UI 中查看对象分布和引用链

### 4. 长时追踪

Perfetto 支持持续数小时的追踪，特别适合分析间歇性性能问题：

- 使用环形缓冲区模式
- 数据流式写入文件，不占用大量内存
- 可配置触发条件，只在问题发生时保存数据

## 八、最佳实践与注意事项

### 1. 采集配置最佳实践

- **缓冲区大小**：建议 32-64MB，长时间采集可适当增大
- **采样频率**：CPU 采样推荐 50-200Hz，过高会增加开销
- **数据源选择**：只开启需要的数据源，减少噪音和开销
- **采集时机**：在问题发生前 1-2 秒开始采集
- **设备选择**：优先使用真机，模拟器 CPU 调度与真机差异大

### 2. 应用配置要求

- 应用必须是 **debuggable** 或 **profileable**
- 在 AndroidManifest.xml 中添加：

  ```xml
  <application android:profileable="true" android:debuggable="true">
  ```

- 生产环境建议只开启 profileable，避免 debuggable 带来的安全风险

### 3. 性能开销控制

- 避免同时开启过多数据源
- 长时间追踪时使用较低的采样频率
- 对于 Native 堆分析，使用采样模式（如每 1024 字节采样一次）
- 避免在性能测试环境中同时运行其他分析工具

## 九、总结

Perfetto 是 Android 性能分析领域的革命性工具，它解决了传统 Systrace 在追踪时长、分析能力和扩展性方面的诸多限制。通过其低开销的采集机制、强大的 SQL 查询引擎和现代化的可视化界面，开发者能够深入理解系统和应用的行为，精准定位性能瓶颈。

随着 Google 持续投入开发，Perfetto 正在不断增加新功能，如网络分析、电量分析和更强大的自动化能力。对于所有 Android 开发者来说，掌握 Perfetto 已经成为进行专业性能优化的必备技能。
