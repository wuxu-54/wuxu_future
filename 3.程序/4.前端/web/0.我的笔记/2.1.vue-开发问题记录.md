# vue 开发问题记录

## 1. 引入组件导致的UI渲染问题

正常父子view同一个页面嵌套使用正常，flex 布局按直接父子关系正常生效；但拆分为子组件并引入后，flex 失效、布局表现异常。

**原因：**
Vue 子组件**自带一个根元素**，会在 DOM 中**多插入一层节点**，导致 flex 布局关系被隔断。
flex 布局**只对直接子元素生效**，孙子/重孙元素上写 `flex:1` 一律无效。

**示例：**

```Vue
<!-- 父组件 -->
<template>
  <view style="display:flex;flex-direction:column;">
    <!-- 问题写法：
         渲染后结构：
         parent(flex)
           ↓
           子组件根节点（无 flex:1）
             ↓
             内部 div(flex:1) → 无效
    -->
    <Child></Child>

    <!-- 正确写法：
         给【子组件根节点】设置 flex:1，
         让它成为父 flex 容器的直接弹性子项
    -->
    <Child style="flex:1; display:flex; flex-direction:column;"></Child>
  </view>
</template>

<!-- Child 子组件 -->
<template>
  <!-- 这里 flex:1 无效，因为它不是父 flex 的直接子元素 -->
  <view style="flex:1;"></view>
</template>
```
