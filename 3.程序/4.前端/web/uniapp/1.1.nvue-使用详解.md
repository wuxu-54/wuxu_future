# nvue

>我在实际开发中遇到了很多样式的坑，nvue不支持很多布局样式！

- [官方文档](https://uniapp.dcloud.net.cn/tutorial/nvue-css.html)

nvue 是 uni-app 面向 App 端的**原生渲染页面**格式，基于 Weex 引擎改造，主打高性能渲染（尤其长列表、复杂交互）。但它与普通 Vue 差异巨大，核心限制集中在**布局与样式**，本文从基础到进阶，手把手带你避坑。

---

## 一、nvue 核心定位与适用场景

### 1. 是什么

nvue（native Vue）是 uni-app 为 App 端提供的**原生渲染页面**，与普通 Vue（WebView 渲染）并列。

- **App 端**：优先使用 nvue（同名文件下 nvue 优先级更高），性能更接近原生。
- **H5/小程序**：自动降级为 Web 渲染，需注意样式兼容。

### 2. 为什么用（适用场景）

- 长列表/瀑布流（`list`/`recycle-list`/`waterfall`）滚动流畅，远超 `scroll-view`。
- 复杂自定义下拉刷新、左右拖动长列表。
- 原生组件层级问题（`map`/`video`/`live-pusher`）覆盖。
- 极致启动优化（首页用 nvue 可将启动时间压至 1 秒内）。

### 3. 不适用场景

- 动态横竖屏（不支持媒体查询）。
- 复杂 Canvas 动画（性能差，建议用 Vue 页面+renderjs）。
- 重度依赖 Web 特性（如 DOM、BOM、CSS 预编译）。

## 二、快速上手：基础结构与配置

### 1. 创建与注册

1. 新建文件：后缀为 `.nvue`（HBuilderX 可直接选择模板）。
2. 注册路由：在 `pages.json` 中注册，无需后缀（同名 Vue 文件在 App 端会被忽略）。

```json
// pages.json
{
  "pages": [
    {
      "path": "pages/index/index", // 对应 pages/index/index.nvue
      "style": { "navigationBarTitleText": "nvue 首页" }
    }
  ]
}
```

### 2. 基础模板结构

与 Vue 一致，由 `<template>`/`<script>`/`<style>` 组成，但有严格规则：

```vue
<template>
  <!-- 根节点建议用 view，所有文字必须放在 text 组件内 -->
  <view class="container">
    <text class="title">Hello nvue</text>
  </view>
</template>

<script>
export default {
  data() { return { msg: "nvue 布局核心：Flex" } }
}
</script>

<style scoped>
/* 仅支持 class 选择器，默认 flex 布局，无需写 display:flex */
.container {
  flex: 1; /* 占满全屏 */
  justify-content: center;
  align-items: center;
  background-color: #f5f5f5;
}
.title { font-size: 32px; color: #333; }
</style>
```

## 三、核心差异：nvue vs 普通 Vue（聚焦布局与样式）

| 维度 | 普通 Vue（WebView） | nvue（原生渲染） | 影响与建议 |
| :--- | :--- | :--- | :--- |
| **渲染引擎** | WebView | 原生（Weex 改造） | nvue 性能更强，但样式限制多 |
| **布局模型** | 全支持（Flex/Grid/Float/Position） | **仅支持 Flex**，默认 `flex-direction: column` | 放弃 Grid/Float，用 Flex 重构布局 |
| **滚动机制** | 页面自动滚动 | 页面不自动滚动，需用 `list`/`scroll-view` 等组件 | 长内容必须套可滚动组件，否则内容溢出不可见 |
| **显隐控制** | 支持 `v-if`/`v-show` | **仅支持 `v-if`**，`v-show` 无效 | 用 `v-if` 控制显隐，避免 `v-show` 踩坑 |
| **样式选择器** | 全支持（ID/标签/类/后代/通配） | **仅支持 class 选择器** | 所有样式必须写 class，避免 ID/标签选择器 |
| **单位** | 支持 px/rpx/rem/em/% | 仅支持 **px**（H5/小程序编译时自动对齐 rpx） | 布局用 rpx 适配，编译时自动转换；避免 % 布局 |
| **背景图** | 支持 `background-image` | **不支持**，需用 `image` 组件+层级模拟 | 背景图用 `<image class="bg" src="xxx.png">` 实现 |
| **文字规则** | 可直接写在 view 内 | **文字必须在 `<text>` 组件内**，view 内直接写文字无效 | 所有文本节点必须包裹 `<text>`，且不换行写（避免空白） |
| **定位** | 支持 `relative`/`absolute`/`fixed`/`sticky` | 支持 `relative`/`absolute`/`sticky`，**不支持 `fixed`** | 吸顶用 `sticky`（仅部分组件支持），或监听滚动动态调整 |
| **全局样式** | App.vue 全局样式生效 | App.vue 全局样式生效，但不支持的属性会报警 | 不兼容样式用 `<!-- #ifdef APP-PLUS-NVUE -->` 条件编译隔离 |
| **CSS 特性** | 支持预编译（Sass/Less）、媒体查询、复杂动画 | **不支持预编译**、媒体查询、简写属性（部分版本支持） | 用原生 CSS，避免预编译和媒体查询；样式拆分为独立属性 |
| **组件** | 全量 uni-app 组件 | 部分组件优化（如 `map`/`video` 更完善），无 `canvas` | 优先用 nvue 专属组件（`list`/`refresh`），避免复杂组件嵌套 |

## 四、布局核心：Flex 布局详解（nvue 唯一布局）

nvue 强制使用 Flex 布局，**无需手动添加 `display: flex`**，默认所有容器为 Flex 容器，主轴默认垂直（`column`）。

### 1. 核心属性与支持情况

| 属性 | 支持值 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `flex-direction` | `column`/`column-reverse`/`row`/`row-reverse` | 主轴方向，默认 `column` | `flex-direction: row;`（横向布局） |
| `flex-wrap` | `nowrap`/`wrap`/`wrap-reverse` | 是否换行，默认 `nowrap` | `flex-wrap: wrap;`（自动换行） |
| `justify-content` | `flex-start`/`center`/`flex-end`/`space-between`/`space-around` | 主轴对齐方式 | `justify-content: space-between;`（两端对齐） |
| `align-items` | `stretch`/`flex-start`/`center`/`flex-end` | 交叉轴对齐方式 | `align-items: center;`（垂直居中） |
| `flex` | 数字（如 1/2） | 子项占剩余空间比例，**不支持简写**（如 `flex: 1 1 auto`） | `flex: 1;`（平均分配剩余空间） |
| `align-self` | 同 `align-items` | 单个子项覆盖父项 `align-items` | 仅部分版本支持，慎用 |

### 2. 常用布局示例

#### （1）垂直居中布局（默认）

```vue
<template>
  <view class="container">
    <text class="text">垂直居中</text>
  </view>
</template>

<style scoped>
.container {
  flex: 1; /* 占满屏幕 */
  justify-content: center; /* 主轴（垂直）居中 */
  align-items: center; /* 交叉轴（水平）居中 */
  background-color: #fff;
}
.text { font-size: 28px; }
</style>
```

#### （2）横向列表布局

```vue
<template>
  <view class="list">
    <view class="item" v-for="(item, index) in list" :key="index">
      <text class="item-text">{{ item }}</text>
    </view>
  </view>
</template>

<style scoped>
.list {
  flex-direction: row; /* 横向布局 */
  flex-wrap: wrap; /* 自动换行 */
  padding: 10px;
}
.item {
  width: 100px; /* 固定宽度 */
  height: 60px;
  margin: 10px;
  background-color: #007aff;
  border-radius: 8px;
  justify-content: center;
  align-items: center;
}
.item-text { color: #fff; font-size: 24px; }
</style>
```

#### （3）自适应左右布局

```vue
<template>
  <view class="container">
    <view class="sidebar">
      <text>侧边栏</text>
    </view>
    <view class="content">
      <text>内容区（自适应）</text>
    </view>
  </view>
</template>

<style scoped>
.container { flex-direction: row; height: 100px; }
.sidebar {
  width: 80px; /* 固定宽度 */
  background-color: #f0f0f0;
  justify-content: center;
  align-items: center;
}
.content {
  flex: 1; /* 占满剩余空间 */
  background-color: #fff;
  justify-content: center;
  align-items: center;
}
</style>
```

## 五、样式限制与避坑指南

### 1. 样式核心限制

1. **选择器限制**：仅支持 class 选择器，不支持 ID、标签、后代、通配选择器。
   ❌ 错误：`#id { ... }` / `view { ... }` / `.container .item { ... }`
   ✅ 正确：`.container { ... }` / `.item { ... }`

2. **单位限制**：仅支持 px（H5/小程序编译时自动将 rpx 转换为对应 px），不支持 %/rem/em/vw/vh。
   ❌ 错误：`width: 100%;` / `font-size: 1rem;`
   ✅ 正确：`width: 750rpx;`（编译后为屏幕宽度） / `width: 375px;`

3. **背景图限制**：不支持 `background-image`，需用 `image` 组件实现。

   ```vue
   <template>
     <view class="bg-container">
       <!-- 背景图组件，绝对定位覆盖整个容器 -->
       <image class="bg-img" src="/static/bg.png" mode="aspectFill"></image>
       <text class="text">背景图内容</text>
     </view>
   </template>

   <style scoped>
   .bg-container {
     flex: 1;
     position: relative; /* 作为定位参考系 */
   }
   .bg-img {
     position: absolute;
     top: 0;
     left: 0;
     width: 750rpx;
     height: 100%;
     z-index: -1; /* 置于底层 */
   }
   .text { font-size: 32px; color: #fff; }
   </style>
   ```

4. **文字样式限制**：仅 `text` 组件支持 `font-size`/`color`/`text-align` 等文本样式，view 内文字无效。
   ❌ 错误：`<view class="text">文字</view>`
   ✅ 正确：`<view><text class="text">文字</text></view>`

5. **定位限制**：不支持 `position: fixed`，吸顶需用 `sticky`（仅 `list`/`cell` 等组件支持）或监听滚动动态调整。

   ```vue
   <!-- 吸顶导航（list 组件内） -->
   <list class="list">
     <cell class="sticky-header" position="sticky">
       <text class="header-text">吸顶导航</text>
     </cell>
     <cell v-for="(item, index) in list" :key="index">
       <text>{{ item }}</text>
     </cell>
   </list>

   <style scoped>
   .sticky-header {
     height: 44px;
     background-color: #007aff;
     justify-content: center;
     align-items: center;
   }
   .header-text { color: #fff; font-size: 28px; }
   </style>
   ```

6. **盒模型**：默认 `box-sizing: border-box`（宽高包含 padding/border），与 Web 一致，但 Android 端大量圆角会导致性能问题，建议减少圆角使用。

7. **其他限制**：
   - 不支持 CSS 预编译（Sass/Less），仅用原生 CSS。
   - 不支持媒体查询，动态适配横竖屏困难。
   - 不支持 `@font-face` 引入自定义字体。
   - 安卓端组件默认透明，未设置 `background-color` 可能出现重影。

### 2. 样式编写规范

1. 样式拆分：避免简写属性，如 `border` 需拆分为 `border-width`/`border-style`/`border-color`（HBuilderX 3.1.0+ 部分支持简写）。
   ❌ 错误：`border: 1px solid #333;`
   ✅ 正确：

   ```css
   border-width: 1px;
   border-style: solid;
   border-color: #333;
   ```

2. 类名简洁：nvue 样式解析效率依赖类名，避免过长或重复类名。

3. 条件编译：全局样式中不兼容 nvue 的属性，用 `APP-PLUS-NVUE` 隔离。

   ```css
   /* App.vue */
   .common {
     color: #333;
     /* #ifdef APP-PLUS-NVUE */
     font-size: 28px;
     /* #endif */
   }
   ```

## 六、滚动与回弹：nvue 特有机制

### 1. 滚动机制

nvue 页面**默认不自动滚动**，内容超过屏幕高度时，需将内容放入以下可滚动组件：

- `list`：高性能长列表，支持吸顶、下拉刷新。
- `waterfall`：瀑布流组件，适合多列不规则布局。
- `scroll-view`：通用滚动组件，支持横向/纵向滚动。
- `recycle-list`：虚拟列表，适合千级以上长列表，性能最优。

**自动滚动优化**：nvue 编译为 uni-app 模式时，会自动给页面外层套 `scroller`，实现页面自动滚动；但如果页面包含 `recycle-list`，则不会自动套 `scroller`，需手动添加。
关闭自动滚动：在 `pages.json` 中配置 `disableScroll: true`。

```json
{
  "path": "pages/index/index",
  "style": { "disableScroll": true }
}
```

### 2. 回弹效果（bounce）

nvue 页面默认无回弹效果，仅以下组件支持：`list`/`recycle-list`/`waterfall`。
开启回弹：在组件上添加 `bounce="true"`（默认 false）。

```vue
<list class="list" bounce="true">
  <!-- 列表内容 -->
</list>
```

## 七、进阶技巧：性能优化与兼容

### 1. 性能优化要点

1. 长列表用 `recycle-list` 替代 `scroll-view`/`list`，减少 DOM 节点渲染。
2. 避免在 `text` 组件外设置文本样式，仅 `text` 支持字体相关样式。
3. 减少圆角和阴影
