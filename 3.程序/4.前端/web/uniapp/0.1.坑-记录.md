# 记录

## 1. canvas 绘制，字体大小不对，怎么可以等同于style上的rpx呢？

答：手机app上需要关注两个点，1是屏幕分辨率，包括物理像素和逻辑像素 2是注意普通px与rpx的转换

示例：

```vue

const systemInfo = uni.getSystemInfoSync()

const ratio = systemInfo.windowWidth / 750;
const dpr = systemInfo.pixelRatio
const fontSize = 28 * ratio * dpr;      // 28rpx → px
const padding = 10 * ratio * dpr;       // 10rpx → px
const lineHeight = fontSize + 8 * ratio* dpr;

```

实际开发是，我没有`*dpr`这个操作，也就是我只关注了物理像素与逻辑像素的处理，没有注意到第二条，这里我加上后，尺寸就正常了。

## 2. nvue层级覆盖问题

因为我需要实现实时摄像功能，必须使用nvue。

1. 要使用absolute布局脱离文档流
2. index不好使，得用`cover-view` ，图片用`cover-image`
3. 文本必须用<text>
4. v-if不好使，当从true变为false时，不会销毁，而是卡死在那（这就是渲染机制导致，极其ex）
5. 最终，很多复杂的层级布局还是不能实现，最好新开一个页面，或是使用subNVue（这个也是.nvue，也不咋好用，最起码能解决v-if 组件卡死问题）
