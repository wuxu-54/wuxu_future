# nvue-层叠布局

在 nvue 中实现类似 Flutter `Stack` 的**叠加层叠布局**，核心是依靠 **`position: absolute` 绝对定位** + **DOM 节点顺序（后写覆盖先写）**，并配合 nvue 支持的 **`z-index`**（注意写法）来精确控制层级。下面是完整、可直接复制的实现方案与细节。

## 一、核心原理（nvue 特有规则）

1. **必须用绝对定位**
   - nvue 不支持 Web 式的默认流叠加，所有层叠元素必须设为 `position: absolute`
   - 父容器必须设为 `position: relative`（作为定位基准）
2. **层级规则**
   - **默认层级**：代码靠后的组件，覆盖前面的组件
   - **`z-index`**：nvue 支持 `z-index`（数字），**值越大越在上层**
   - 不支持 `position: fixed`（页面内叠加用 absolute 即可）
3. **单位**：只支持 `px` / `rpx`（**不支持 %**）

---

## 二、基础实现：全屏/区域叠加（最常用）

### 1. 全屏 Stack 效果（底层图 + 上层文字/按钮）

```nvue
<template>
  <!-- 父容器：relative 作为定位基准 -->
  <view class="stack-container">
    <!-- 底层：背景图（最先写，层级最低） -->
    <image class="bg-img" src="/static/demo.jpg" mode="aspectFill"></image>

    <!-- 中层：半透明遮罩 -->
    <view class="mask"></view>

    <!-- 上层：文字与按钮（最后写，层级最高） -->
    <view class="content">
      <text class="title">Stack 叠加层</text>
      <button class="btn">点击操作</button>
    </view>
  </view>
</template>

<style scoped>
/* 父容器：占满全屏 + relative */
.stack-container {
  flex: 1;
  position: relative;
}

/* 底层图：全屏 */
.bg-img {
  position: absolute;
  top: 0;
  left: 0;
  width: 750rpx; /* 全屏宽 */
  height: 100%;
}

/* 中层遮罩 */
.mask {
  position: absolute;
  top: 0;
  left: 0;
  width: 750rpx;
  height: 100%;
  background-color: rgba(0, 0, 0, 0.4);
  z-index: 10; /* 显式提升层级 */
}

/* 上层内容：居中 */
.content {
  position: absolute;
  top: 0;
  left: 0;
  width: 750rpx;
  height: 100%;
  z-index: 20; /* 最高层 */
  justify-content: center;
  align-items: center;
}

.title {
  font-size: 36rpx;
  color: #fff;
  margin-bottom: 30rpx;
}
.btn {
  padding: 20rpx 40rpx;
  background-color: #007aff;
  border-radius: 8rpx;
  color: #fff;
}
</style>
```

### 2. 局部区域叠加（卡片内叠层）

```nvue
<template>
  <view class="card">
    <!-- 叠加容器 -->
    <view class="stack-box">
      <image class="card-img" src="/static/item.jpg"></image>
      <!-- 右上角标签 -->
      <view class="tag">
        <text class="tag-text">热销</text>
      </view>
    </view>
    <text class="card-title">商品标题</text>
  </view>
</template>

<style scoped>
.card {
  width: 340rpx;
  margin: 20rpx;
}
.stack-box {
  position: relative; /* 关键点 */
  width: 340rpx;
  height: 340rpx;
}
.card-img {
  width: 100%;
  height: 100%;
}
/* 右上角叠加标签 */
.tag {
  position: absolute;
  top: 20rpx;
  right: 20rpx;
  background-color: #ff3000;
  padding: 10rpx 16rpx;
  border-radius: 6rpx;
  z-index: 9;
}
.tag-text {
  color: #fff;
  font-size: 24rpx;
}
.card-title {
  margin-top: 20rpx;
  font-size: 28rpx;
}
</style>
```

## 四、nvue 叠加布局必知坑点

1. **不支持 `background-image` 背景叠加**
   - ❌ 禁止：`.box { background-image: url(xxx); }`
   - ✅ 必须用 `<image>` 组件 + absolute 模拟
2. **`z-index` 只在同一父级有效**
   - 不同父容器的元素，`z-index` 不互通
3. **文字必须放 `<text>`**
   - 叠加层里的文字，不能直接写在 view 里
4. **不支持百分比宽高（`width:100%` 无效）**
   - 全屏用 `width:750rpx; height:100%;`
5. **原生组件（video/map）层级**
   - nvue 所有组件都是原生，可正常用 absolute 覆盖 video/map
   - 复杂覆盖可用 `subNVue` 子窗体
