# nvue-QA记录

## 1. 不支持百分比，子view如何宽度全屏、高度自定义

- 普通布局：父垂直flex，子**不写width**，自动满屏宽，直接写height即可
- 绝对定位/叠加布局：写 **width:750rpx** 满屏，height自定义

## 2. 高度如何根据子view总高自动变化

- 父容器**不写height、不写flex:1**
- 子元素用正常流布局，即可自动撑开父高度
- 绝对定位子元素不占高度，不能撑开父容器

## 3. height:auto 可以吗

- **nvue不支持height:auto**，写了无效
- 高度自适应直接**不写height**就行
