## 一、CSS 字体属性总览

字体属性分两大类：

1. **字体本身**（font-family、font-size、font-weight、font-style...）
2. **文本排版**（line-height、letter-spacing、text-align...）

## 二、**字体核心属性（最常用）**

### 1. **font-family**（字体族）

作用：设置**使用什么字体**。

#### 格式

```css
font-family: "字体1", "字体2", 通用字体族;
```

#### 规则

- 优先使用前面的字体，找不到就往后找
- 字体名有空格必须加引号：`"Microsoft YaHei"`
- 最后必须加 **通用字体族**（保证跨平台）

#### 5 大通用字体族（必须记住）

- `serif`：衬线字体（有笔锋，如宋体）
- `sans-serif`：**无衬线字体**（最常用，清晰，如黑体、苹方、Roboto）
- `monospace`：等宽字体
- `cursive`：手写体
- `fantasy`：艺术字体

#### 最推荐的通用写法

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

**这是行业标准字体栈**。

---

### 2. **font-size**（字体大小）

作用：控制文字大小

#### 常用单位

- `px`：固定像素（最常用）
- `em`：相对于父元素
- `rem`：相对于根元素（项目首选）
- `%`：百分比
- `vw`：视窗宽度

#### 标准示例

```css
font-size: 14px; /* 正文 */
font-size: 16px; /* 大正文 */
font-size: 12px; /* 辅助文字、备注 */
```

---

### 3. **font-weight**（字体粗细）

作用：控制文字粗细

#### 可选值

- `normal` = 400（默认）
- `bold` = 700（粗体）
- `lighter`：更细
- `bolder`：更粗
- **100 ~ 900** 数值（最常用、最标准）

#### 常用值含义

- 100：细体
- 400：常规
- 500：中等
- 700：粗体
- 900：特粗

⚠️ 注意：
**不是所有字体都支持 100~900**，很多字体只支持 400 和 700。

---

### 4. **font-style**（字体样式）

作用：斜体 / 正常

#### 值

- `normal`：正常（默认）
- `italic`：**斜体**（使用字体自带斜体）
- `oblique`：倾斜（强制倾斜，不推荐）

---

### 5. **line-height**（行高）

**最重要的排版属性**
控制：行间距、文字垂直居中

#### 用法

```css
line-height: 1.5;  /* 推荐！无单位 = 字体大小的倍数 */
line-height: 24px;
line-height: 150%;
```

#### 最佳实践

- 正文：`1.4 ~ 1.6`
- 标题：`1.2 ~ 1.3`

#### 垂直居中技巧

```css
height: 40px;
line-height: 40px; /* 文字垂直居中 */
```

---

### 6. **font**（字体简写属性）

**必须按顺序写！**

格式：

```css
font: font-style font-weight font-size/line-height font-family;
```

示例：

```css
font: normal 400 14px/1.5 "Microsoft YaHei", sans-serif;
```

⚠️ 规则：

- **必须包含 font-size 和 font-family**
- 顺序不能乱

## 三、**文本外观属性（非常常用）**

### 7. **color**（颜色）

```css
color: ##333;
color: rgb(51, 51, 51);
color: rgba(0,0,0,0.5); /* 半透明 */
```

---

### 8. **text-align**（水平对齐）

- `left`：左对齐（默认）
- `center`：居中
- `right`：右对齐
- `justify`：两端对齐

---

### 9. **text-decoration**（文本装饰）

- `none`：无（清除 a 标签下划线常用）
- `underline`：下划线
- `line-through`：删除线
- `overline`：上划线

```css
text-decoration: none; /* 最常用 */
```

---

### 10. **text-indent**（首行缩进）

```css
text-indent: 2em; /* 缩进2字符 */
```

---

### 11. **letter-spacing**（字间距）

```css
letter-spacing: 1px;
```

---

### 12. **word-spacing**（词间距，英文用）

---

### 13. **white-space**（空白处理）

- `normal`：自动换行
- `nowrap`：**不换行**
- `pre`：保留格式
- `pre-wrap`：保留换行+自动换行

---

### 14. **text-overflow**（文字溢出）

配合 `overflow: hidden` 和 `white-space: nowrap` 使用

```css
text-overflow: ellipsis; /* 显示... */
```

## 四、**高级字体属性（进阶）**

### 15. **font-variant**

小型大写字母

```css
font-variant: small-caps;
```

---

### 16. **text-shadow**（文字阴影）

```css
text-shadow: 1px 1px 2px rgba(0,0,0,0.3);
```

---

### 17. **text-transform**（大小写转换）

- `none`
- `capitalize`：首字母大写
- `uppercase`：全部大写
- `lowercase`：全部小写

## 五、**最常用的 5 个 CSS 文本组合（直接复制用）**

### 1. 标准正文（最常用）

```css
font-size: 14px;
font-weight: 400;
line-height: 1.5;
color: ##333;
font-family: "Microsoft YaHei", sans-serif;
```

### 2. 标题

```css
font-size: 18px;
font-weight: 500;
line-height: 1.3;
color: ##000;
```

### 3. 单行溢出显示省略号

```css
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
```

### 4. 清除下划线

```css
text-decoration: none;
```

### 5. 文字垂直居中

```css
line-height: 盒子高度;
```
