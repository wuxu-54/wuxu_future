
# Flex 高频坑

## 一、flex 容器（父元素）相关坑与注意

### 1. 必须设置 `display: flex / inline-flex`

- 不设置，子元素完全不受 flex 控制
- `flex` 块级；`inline-flex` 行内块级

### 2. `flex-direction` 改变主轴与交叉轴

- `row`（默认）：主轴水平 → `justify` 管左右，`align` 管上下
- `column`：主轴垂直 → `justify` 管上下，`align` 管左右
**坑**：方向一改，所有对齐属性逻辑全反转，极易写错。

### 3. 不设置 `flex-wrap: wrap` 会强制不换行

- 默认 `nowrap`
- 子元素总宽度 > 父宽度时会**被压缩**，不会自动换行
- 想换行必须显式写 `wrap`

### 4. `align-content` 只有多行才生效

- 只对**换行后的多行**起作用
- 只有一行时完全无效
- 常和 `align-items` 混淆

### 5. 容器不设高度，纵向 flex 布局失效

- `flex-direction:column` 时，父容器必须有明确高度
  否则 `flex:1` 不知道“占满多少”
- 常见：页面布局必须 `100vh` / `100%` 逐层传递

### 6. `gap` 与 `margin` 混用可能重复间距

- `gap` 是 flex 专用间距，不会折叠、不影响最后一项
- 子元素再写 `margin` 会叠加

### 7. 容器设置 `overflow:hidden` 会影响子元素绝对定位

- 子绝父相是常规，但 flex 容器同样会成为定位包含块

### 8. `justify-content: space-between` 最后一行对齐问题

- 项目不足一行时，最后一行会被强行拉开，很难看
- 解决：用 grid / 伪元素 / 动态计算 margin

### 9. flex 容器默认不会让子元素超出自己

- 但子元素内容过长仍可能溢出，需要 `overflow:hidden`

### 10. `inline-flex` 会受文字、空格影响

- 像行内块一样出现意外间距
- 解决：父级 `font-size:0` 或不用 inline-flex

## 二、flex 子元素（项目）常见坑

### 11. `flex:1` 不等于自适应高度/宽度

- 必须父是 `flex` + 正确方向
- 纵向必须父有高度

### 12. `flex:1` 会覆盖 `width`/`height`

- flex 弹性权重 > 明确宽高
- 想固定尺寸不要写 `flex:1`

### 13. 子元素默认 `min-width/min-height: auto`

- 导致内容过长时**不会收缩，只会撑破父容器**
- 必须设置：
  - 横向滚动：`min-width:0`
  - 纵向滚动：`min-height:0`
**这是你最开始遇到问题的核心坑**

### 14. 百分比宽高在 flex 里经常失效

- `width:100%` 一般正常
- `height:100%` 经常无效，因为父高度是弹性计算
- 充满优先用 `flex:1`，不要依赖 `height:100%`

### 15. 子元素设置 `float`/`clear` 完全无效

- flex 子元素脱离常规流规则，float 失效

### 16. `vertical-align` 对 flex 子元素无效

- 想垂直对齐必须用 `align-items/align-self`

### 17. 子元素 `position:absolute` 会脱离 flex 流

- 不再参与 flex 排列、拉伸、对齐
- 但仍可被父容器相对定位

### 18. 多个子元素都设 `flex:1` 会均分空间

- 想不等分：`flex:2`、`flex:3`

### 19. `flex-shrink:0` 非常重要

- 默认 `flex-shrink:1` → 空间不足会被压缩
- 不想被压缩：`flex-shrink:0`
  常用于侧边栏、tab、按钮

### 20. `flex-basis` 优先级高于 width/height

- `flex-basis` 是主轴基础尺寸
- 主轴水平 → 影响宽度
- 主轴垂直 → 影响高度

### 21. `flex` 简写容易写错

完整含义：

```
flex: flex-grow  flex-shrink  flex-basis
```

- `flex:1` → `1 1 0%`
- `flex:auto` → `1 1 auto`
- `flex:none` → `0 0 auto`（固定尺寸，不伸缩）

### 22. 子元素 margin 不会坍塌

- flex 中子元素上下 margin 不会合并
- 布局更可控，但要注意间距叠加

### 23. `margin:auto` 在 flex 里超级强大

- 单个子元素居中：`margin:auto`
- 右侧对齐：`margin-left:auto`
- 底部对齐：`margin-top:auto`
很多布局不用复杂对齐，靠它解决

### 24. 子元素设置 `overflow:auto` 必须配合 min-height:0

否则无法出现滚动条，只会被内容撑高

### 25. 图片作为 flex 子元素会被拉伸

- 默认 `align-items:stretch`
- 解决：`align-self:center` 或给图片设置宽高

## 三、纵向 flex 布局（column）专属大坑

### 26. 父容器必须有高度，否则 flex:1=0

- 页面布局必须从根节点开始逐层 `100%`/`100vh`

### 27. 纵向 `align-items` 默认是拉伸宽度

- 子元素默认撑满父宽度
- 想让子元素由内容决定宽度：`align-items:flex-start`

### 28. 纵向滚动必须三层结构

```
父：flex:1; overflow:hidden
子：flex:1; min-height:0; overflow:auto
```

少一个都无法正常滚动

### 29. 纵向 `space-between` 在内容少时也会分开

- 可能导致底部留白异常

## 四、对齐相关混淆点（最容易错）

### 30. `align-items` 单行交叉轴对齐

### 31. `align-content` 多行交叉轴对齐

### 32. `justify-content` 主轴对齐

### 33. `align-self` 子项单独覆盖对齐

### 34. `place-items` = `align-items` + `justify-items`

### 35. flex 没有 `justify-items`

- 只有 grid 才有
- flex 想单个项目靠右只能用 `margin-left:auto`

## 五、兼容性与怪异行为

### 36. 旧浏览器对 flex 支持不完整

- 如 iOS 9、旧 Chrome 需加前缀，但现在基本不用

### 37. 某些浏览器对 `flex-basis:100%` 解析异常

### 38. 表单元素（button/input）作为 flex 子元素样式怪异

- 需重置外观、设置宽高、`flex-shrink:0`

### 39. 嵌套 flex 层级过深可能导致性能略降

- 一般可忽略，极复杂列表才会出现

### 40. flex 与 `transform`/`fixed` 组合偶尔出现层级错乱

- 属于渲染层问题，加 `z-index` 或 `will-change:transform`

---

## 六、与其他布局冲突

### 41. flex + 文本自动折行异常

- 长英文/链接不换行：加 `word-break:break-all`

### 42. flex + 表格混用布局混乱

### 43. flex + 浮动混用无意义

### 44. flex + 网格(grid)混用非常正常，现代标准布局方式

---

## 七、你最开始的问题，放在这里就是：

45. **flex 纵向布局中，子元素写 height:100% 经常无效**
46. **flex:1 子元素不设置 min-height:0 会被内容撑大，无法滚动、无法收缩**
47. **多层 flex 嵌套必须每一层都正确传递 flex:1**

---

## 八、最实用万能规则（背会几乎不踩坑）

1. 想充满父容器 → `flex:1`，不要依赖 `height:100%`
2. 想滚动 → `flex:1 + min-height:0 + overflow:auto`
3. 不想被压缩 → `flex-shrink:0`
4. 想不被内容撑破 → `min-width:0 / min-height:0`
5. 纵向布局 → 父必须有高度
6. 对齐分不清 → 记住：**主轴 justify，交叉轴 align**
7. 单个项目要特殊对齐 → `margin:auto` 最强
8. 换行 → `flex-wrap:wrap`
9. 间距优先 `gap`
10. 固定宽度侧边栏 + 自适应内容 = 经典 `flex-shrink:0 + flex:1`
