# 组件概览

## 一、组件核心概念

自定义组件是**可复用的Vue实例**，拥有和Vue根实例一致的核心选项（`data`、`methods`、`computed`、生命周期等），但有2个关键区别：

1. 组件的 `data` 必须是**函数**（返回对象），避免多个组件实例共享同一数据导致污染；
2. 组件没有 `el` 选项（根实例的挂载选项），组件的挂载由使用它的父组件/根实例决定。

## 二、组件的定义与注册

Vue2中组件注册分**全局注册**和**局部注册**，两者适用场景不同，先从最基础的结构讲起。

### 1. 全局注册（Vue.component）

全局注册的组件可在**任何Vue实例/组件**中直接使用，适合通用型组件（如按钮、输入框）。

#### 基础语法：

```javascript
// 全局注册组件
Vue.component('组件名', {
  // 组件选项（data、template、props等）
  data() { // 必须是函数
    return {
      组件内部数据: 值
    }
  },
  template: '组件的HTML结构'
});
```

#### 完整示例（全局组件）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2 全局组件</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
</head>
<body>
  <div id="app">
    <!-- 使用全局组件 -->
    <my-button></my-button>
    <my-button></my-button> <!-- 可复用 -->
  </div>

  <script>
    // 1. 全局注册组件（组件名建议用短横线命名，符合W3C规范）
    Vue.component('my-button', {
      // data必须是函数，返回独立的数据源
      data() {
        return {
          count: 0 // 每个组件实例的count都是独立的
        }
      },
      // template：组件的HTML结构（根节点必须唯一）
      template: `
        <button @click="count++">
          点击了 {{ count }} 次（全局组件）
        </button>
      `
    });

    // 2. 创建根实例
    new Vue({
      el: '#app'
    });
  </script>
</body>
</html>
```

#### 全局注册注意事项：

- 组件名推荐用**短横线命名**（如`my-button`），符合HTML标签规范，也可使用PascalCase（如`MyButton`，在模板中两种写法都可）；
- `template` 根节点**必须唯一**（Vue2不支持多根节点）；
- 全局组件需在**创建Vue根实例前**注册，否则无法使用；
- 全局组件会增加Vue实例体积，即使未使用也会打包，适合高频复用的组件。

### 2. 局部注册（components选项）

局部注册的组件仅在**当前注册的作用域内**可用，适合业务专属组件（如订单组件、个人中心组件），更节省资源。

#### 完整示例（局部组件）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2 局部组件</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
</head>
<body>
  <div id="app">
    <!-- 使用局部组件 -->
    <my-card></my-card>
    <!-- 这里无法使用<my-button>，因为是另一个局部组件 -->
  </div>

  <script>
    // 1. 定义局部组件（本质是一个配置对象）
    const MyCard = {
      data() {
        return {
          title: '局部组件卡片'
        }
      },
      template: `
        <div style="border: 1px solid #ccc; padding: 20px; margin: 10px;">
          <h3>{{ title }}</h3>
          <p>仅在当前根实例中可用</p>
        </div>
      `
    };

    // 2. 定义另一个局部组件（仅作示例）
    const MyButton = {
      template: '<button>仅在其他作用域可用</button>'
    };

    // 3. 创建根实例，局部注册组件
    new Vue({
      el: '#app',
      components: {
        // 注册局部组件：键是组件名，值是组件配置对象
        'my-card': MyCard // 短横线命名
        // MyButton: MyButton // PascalCase命名（模板中可写<MyButton>或<my-button>）
      }
    });
  </script>
</body>
</html>
```

#### 局部注册注意事项：

- 局部组件仅在注册它的父组件/根实例中可用，子组件不会继承；
- 若要在子组件中使用另一个局部组件，需在子组件的`components`选项中单独注册；
- 推荐使用ES6对象简写：`components: { MyCard }`（组件名和变量名一致时）。

## 三、父子组件通信（核心）

组件复用的关键是组件间数据传递，Vue2中父子组件通信是最常用的场景：

### 1. 父传子：通过 `props` 传递数据

`props` 是组件的**输入属性**，父组件通过属性向子组件传值，子组件通过`props`接收并使用。

#### 步骤拆解：

1. 父组件：在使用子组件时，通过`属性名=值`传递数据；
2. 子组件：通过`props`选项声明接收的属性（支持类型校验、默认值、必传校验）；
3. 子组件：直接使用`props`中的属性（只读，不能直接修改）。

#### 完整示例（父传子）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2 父传子 props</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
</head>
<body>
  <div id="app">
    <!-- 父组件：向子组件传值（静态值/动态值） -->
    <my-product 
      title="Vue2实战教程" 
      :price="99"  <!-- 动态值加: -->
      :stock="100"
    ></my-product>

    <!-- 传不同的值，复用组件 -->
    <my-product 
      title="JavaScript高级编程" 
      :price="89"
      :stock="50"
    ></my-product>
  </div>

  <script>
    // 子组件：接收并使用父组件传递的props
    Vue.component('my-product', {
      // 声明props（支持三种写法：数组/对象（带校验））
      props: {
        // 基础类型校验
        title: String,
        // 带默认值 + 类型校验
        price: {
          type: Number,
          default: 0 // 默认值
        },
        // 必传 + 类型校验
        stock: {
          type: Number,
          required: true, // 必传
          validator(value) { // 自定义校验
            return value >= 0; // 库存不能为负数
          }
        }
      },
      template: `
        <div style="border: 1px solid #eee; padding: 10px; margin: 10px;">
          <h4>商品：{{ title }}</h4>
          <p>价格：¥{{ price }}</p>
          <p>库存：{{ stock }}件</p>
          <!-- 错误：不能直接修改props（只读） -->
          <!-- <button @click="stock--">减库存</button> -->
        </div>
      `
    });

    new Vue({
      el: '#app'
    });
  </script>
</body>
</html>
```

#### props关键注意事项：

- `props` 是**只读的**，子组件不能直接修改（修改会触发警告），若需修改，应在子组件内部定义`data`接收props值后再修改；
- props命名：父组件传值时，若props是驼峰命名（如`productTitle`），模板中需用短横线（`product-title`）；
- 类型校验支持：String/Number/Boolean/Array/Object/Function/Symbol，也可自定义构造函数；
- 默认值：对象/数组的默认值需用函数返回（避免共享引用），如`default: () => ({ name: '默认' })`。

### 2. 子传父：通过 `$emit` 触发自定义事件

子组件不能直接修改父组件数据，需通过**自定义事件**向父组件传递数据，父组件监听事件并处理。

#### 步骤拆解：

1. 子组件：通过`this.$emit('事件名', 传递的数据)`触发自定义事件；
2. 父组件：在使用子组件时，通过`@事件名=处理函数`监听事件；
3. 父组件：在处理函数中接收子组件传递的数据，并修改自身数据。

#### 完整示例（子传父）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2 子传父 $emit</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
</head>
<body>
  <div id="app">
    <h3>父组件：总数量 = {{ totalCount }}</h3>
    <!-- 父组件：监听子组件的自定义事件 -->
    <my-counter 
      @add="handleAdd"  <!-- 监听add事件，执行handleAdd -->
      @minus="handleMinus"
    ></my-counter>
  </div>

  <script>
    // 子组件：触发自定义事件传递数据
    Vue.component('my-counter', {
      data() {
        return {
          count: 0 // 子组件内部数据
        }
      },
      template: `
        <div style="padding: 20px;">
          <button @click="handleClickAdd">+1</button>
          <span>{{ count }}</span>
          <button @click="handleClickMinus">-1</button>
        </div>
      `,
      methods: {
        handleClickAdd() {
          this.count++;
          // 触发自定义事件，传递当前count值给父组件
          this.$emit('add', this.count);
        },
        handleClickMinus() {
          if (this.count > 0) {
            this.count--;
            // 触发自定义事件
            this.$emit('minus', this.count);
          }
        }
      }
    });

    // 父组件：处理子组件的事件
    new Vue({
      el: '#app',
      data: {
        totalCount: 0
      },
      methods: {
        handleAdd(val) {
          this.totalCount = val; // 接收子组件传递的数据
        },
        handleMinus(val) {
          this.totalCount = val;
        }
      }
    });
  </script>
</body>
</html>
```

### 3. 父调用子组件方法/获取子组件数据：`$refs`

若父组件需要直接操作子组件（如调用子组件方法、获取子组件数据），可通过`ref`属性标记子组件，再通过`this.$refs.xxx`访问。

#### 示例：

```html
<div id="app">
  <button @click="callChildMethod">调用子组件方法</button>
  <!-- 给子组件加ref标记 -->
  <my-child ref="childRef"></my-child>
</div>

<script>
  Vue.component('my-child', {
    data() {
      return {
        childMsg: '子组件数据'
      }
    },
    methods: {
      childMethod() {
        alert('子组件方法被调用：' + this.childMsg);
      }
    },
    template: '<div>子组件</div>'
  });

  new Vue({
    el: '#app',
    methods: {
      callChildMethod() {
        // 通过$refs访问子组件
        this.$refs.childRef.childMethod(); // 调用子组件方法
        console.log(this.$refs.childRef.childMsg); // 获取子组件数据
      }
    }
  });
</script>
```

#### 注意：

- `$refs` 仅在组件**挂载完成后**可用；
- 尽量避免过度使用`$refs`（违背组件封装原则），优先用props/$emit通信。

## 四、插槽（Slot）：组件内容自定义

插槽用于让父组件向子组件传递**HTML结构**，解决组件内容灵活定制的问题，Vue2支持三种插槽：默认插槽、具名插槽、作用域插槽。

### 1. 默认插槽（匿名插槽）

子组件预留一个默认位置，父组件可自定义填充内容。

```html
<div id="app">
  <!-- 父组件：填充插槽内容 -->
  <my-dialog>
    <p>这是自定义的弹窗内容</p>
    <button>确认按钮</button>
  </my-dialog>
</div>

<script>
  Vue.component('my-dialog', {
    template: `
      <div style="border: 2px solid #333; padding: 20px;">
        <h3>弹窗标题</h3>
        <!-- 插槽：父组件的内容会填充到这里 -->
        <slot>默认内容（父组件没传内容时显示）</slot>
      </div>
    `
  });

  new Vue({ el: '#app' });
</script>
```

### 2. 具名插槽

子组件预留多个命名位置，父组件可精准填充对应位置的内容（Vue2中用`slot`属性，Vue3用`v-slot`）。

```html
<div id="app">
  <my-layout>
    <!-- 填充header插槽 -->
    <div slot="header">自定义头部</div>
    <!-- 填充main插槽 -->
    <div slot="main">自定义主体内容</div>
    <!-- 填充footer插槽 -->
    <div slot="footer">自定义底部</div>
  </my-layout>
</div>

<script>
  Vue.component('my-layout', {
    template: `
      <div>
        <!-- 具名插槽：name指定名称 -->
        <header><slot name="header">默认头部</slot></header>
        <main><slot name="main">默认主体</slot></main>
        <footer><slot name="footer">默认底部</slot></footer>
      </div>
    `
  });

  new Vue({ el: '#app' });
</script>
```

### 3. 作用域插槽

子组件向插槽传递数据，父组件在填充插槽时可使用这些数据（解决“子传父”的插槽内容定制）。

```html
<div id="app">
  <my-list :list="userList">
    <!-- 作用域插槽：通过slot-scope接收子组件传递的数据 -->
    <div slot-scope="slotProps">
      <!-- 使用子组件传递的item数据 -->
      <p>姓名：{{ slotProps.item.name }}，年龄：{{ slotProps.item.age }}</p>
    </div>
  </my-list>
</div>

<script>
  Vue.component('my-list', {
    props: { list: Array },
    template: `
      <ul>
        <li v-for="item in list" :key="item.id">
          <!-- 子组件：通过slot传递数据（:item="item"） -->
          <slot :item="item"></slot>
        </li>
      </ul>
    `
  });

  new Vue({
    el: '#app',
    data: {
      userList: [
        { id: 1, name: '张三', age: 20 },
        { id: 2, name: '李四', age: 25 }
      ]
    }
  });
</script>
```

## 五、非父子组件通信（补充）

对于兄弟组件、跨层级组件通信，Vue2常用两种方式：

### 1. EventBus（事件总线）

创建一个空的Vue实例作为总线，所有组件通过它触发/监听事件：

```javascript
// 1. 创建EventBus
const Bus = new Vue();

// 2. 组件A：触发事件
Bus.$emit('send-data', { msg: 'Hello' });

// 3. 组件B：监听事件（在created/mounted中监听）
Bus.$on('send-data', (data) => {
  console.log('接收数据：', data); // { msg: 'Hello' }
});

// 4. 销毁事件（避免内存泄漏）
Bus.$off('send-data');
```

### 2. Vuex（推荐复杂场景）

对于中大型项目，推荐使用Vuex管理全局状态（专门的状态管理库），后续可单独学习，核心是`state`（存储数据）、`mutations`（修改数据）、`actions`（异步操作）、`getters`（计算属性）。

## 六、组件生命周期（补充）

组件拥有和根实例一致的生命周期钩子，但注意：

- 组件的`beforeCreate`/`created`阶段：`$el`（DOM元素）未生成，无法操作DOM；
- 组件的`beforeMount`/`mounted`阶段：`$el`生成，可操作DOM；
- 组件的`beforeDestroy`阶段：可清理定时器、解绑事件（避免内存泄漏）。

## 七、完整综合示例（自定义组件核心用法）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2 自定义组件综合示例</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
  <style>
    .card { border: 1px solid #ccc; padding: 15px; margin: 10px; border-radius: 4px; }
    .btn { padding: 5px 10px; cursor: pointer; }
  </style>
</head>
<body>
  <div id="app">
    <h2>父组件：购物车总数 = {{ cartTotal }}</h2>
    <!-- 父传子 + 监听子组件事件 + 插槽 -->
    <product-card 
      v-for="product in products"
      :key="product.id"
      :product="product"
      @add-to-cart="addToCart"
    >
      <!-- 具名插槽 -->
      <div slot="action">
        <button class="btn" @click="handleViewDetail(product.id)">查看详情</button>
      </div>
    </product-card>
  </div>

  <script>
    // 1. 局部注册子组件
    const ProductCard = {
      props: {
        product: {
          type: Object,
          required: true
        }
      },
      data() {
        return {
          count: 1
        }
      },
      template: `
        <div class="card">
          <h4>{{ product.name }}</h4>
          <p>价格：¥{{ product.price }}</p>
          <p>库存：{{ product.stock }}件</p>
          <div>
            <button class="btn" @click="count > 1 ? count-- : 1">-</button>
            <span>{{ count }}</span>
            <button class="btn" @click="count < product.stock ? count++ : product.stock">+</button>
          </div>
          <!-- 子传父：触发自定义事件 -->
          <button class="btn" style="margin-top: 10px;" @click="handleAdd">加入购物车</button>
          <!-- 具名插槽 -->
          <slot name="action"></slot>
        </div>
      `,
      methods: {
        handleAdd() {
          // 触发自定义事件，传递商品和数量
          this.$emit('add-to-cart', {
            id: this.product.id,
            name: this.product.name,
            count: this.count
          });
        }
      }
    };

    // 2. 根实例
    new Vue({
      el: '#app',
      components: {
        ProductCard // 局部注册
      },
      data: {
        cartTotal: 0,
        products: [
          { id: 1, name: 'Vue2教程', price: 99, stock: 50 },
          { id: 2, name: 'React教程', price: 89, stock: 30 }
        ]
      },
      methods: {
        addToCart(data) {
          this.cartTotal += data.count;
          alert(`已加入${data.count}件【${data.name}】到购物车`);
        },
        handleViewDetail(id) {
          alert(`查看商品ID为${id}的详情`);
        }
      }
    });
  </script>
</body>
</html>
```

## 总结

### 关键点回顾

1. **组件注册**：全局注册（`Vue.component`）适用于通用组件，局部注册（`components`选项）适用于业务专属组件，组件`data`必须是函数；
2. **父子通信**：父传子用`props`（只读，支持校验），子传父用`$emit`触发自定义事件，父调用子方法用`$refs`；
3. **插槽**：默认插槽（匿名）用于简单内容定制，具名插槽用于多位置定制，作用域插槽用于子向父传递插槽数据。

### 核心原则

- 组件遵循“单向数据流”：父数据变 → 子props变，子不能直接改props；
- 组件封装原则：高内聚（内部逻辑封闭）、低耦合（通过props/$emit通信）；
- 复杂场景优先用Vuex管理全局状态，避免EventBus滥用导致维护困难。
