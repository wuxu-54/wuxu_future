
# vue2 概括

## 一、Vue2 基础准备

首先要确保你能正确引入Vue2，新手推荐先使用CDN方式（无需配置环境），后续再学习npm安装：

```html
<!-- 引入Vue2 CDN -->
<script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
<!-- 生产环境可用压缩版：https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.min.js -->
```

Vue2的核心是**创建Vue实例**，所有功能都围绕实例展开，基础结构：

```html
<div id="app"></div>

<script>
// 创建Vue实例
const vm = new Vue({
  // 配置项（挂载、数据、方法等都在这里）
}).$mount('#app'); // 挂载方式1：手动挂载
</script>
```

## 二、核心知识点详解

### 1. 实例挂载（Vue实例与DOM关联）

挂载是将Vue实例和页面中的DOM元素“绑定”，让Vue接管该元素内部的所有内容，有两种核心方式：

#### 方式1：通过 `el` 选项直接挂载（最常用）

`el`（element的缩写）指定Vue实例要挂载的DOM元素选择器（ID、类、标签等，推荐ID）。

```html
<div id="app">{{ message }}</div>

<script>
const vm = new Vue({
  el: '#app', // 挂载到id为app的DOM元素上
  data: {
    message: 'Vue2挂载成功！'
  }
});
</script>
```

#### 方式2：通过 `$mount()` 方法手动挂载（更灵活）

适合需要先配置实例，再延迟挂载的场景（比如异步操作后挂载）。

```html
<div id="app">{{ message }}</div>

<script>
// 先创建实例，不指定el
const vm = new Vue({
  data: {
    message: '手动挂载成功！'
  }
});

// 手动挂载（可延迟执行）
setTimeout(() => {
  vm.$mount('#app'); // 挂载到#app
}, 1000);

// 也可以挂载到任意DOM元素，比如：vm.$mount('.container')
</script>
```

#### 挂载的关键注意事项：

- 挂载元素（如`#app`）是Vue的**根容器**，Vue只会管理该元素内部的DOM；
- 挂载元素本身不会被替换，只是接管其内部内容；
- 一个Vue实例只能挂载到一个DOM元素上，重复挂载会报错；
- 推荐使用ID选择器（唯一），避免类/标签选择器导致的歧义。

### 2. 数据绑定（数据与视图关联）

Vue2的核心是“数据驱动视图”，数据绑定是将`data`中的数据渲染到页面，分三类核心方式：

#### 2.1 文本插值（最基础，{{ }} 双大括号）

用于渲染**文本内容**，支持简单表达式，但不支持语句（如if/for）。

```html
<div id="app">
  <!-- 基础文本绑定 -->
  <p>基础文本：{{ message }}</p>
  <!-- 支持简单表达式 -->
  <p>数值计算：{{ num + 10 }}</p>
  <p>三元表达式：{{ isShow ? '显示' : '隐藏' }}</p>
  <!-- 不支持：{{ if (num > 0) { return '正数' } }} -->
</div>

<script>
new Vue({
  el: '#app',
  data: {
    message: 'Hello Vue2!',
    num: 5,
    isShow: true
  }
});
</script>
```

**注意**：`{{ }}` 会将数据解析为纯文本，无法渲染HTML（防止XSS攻击），如果要渲染HTML需用`v-html`指令。

#### 2.2 指令绑定（v-bind，绑定HTML属性）

`v-bind` 用于绑定HTML元素的**属性**（如`src`、`href`、`class`、`style`、自定义属性等），简写为 `:`。

```html
<div id="app">
  <!-- 绑定href属性 -->
  <a v-bind:href="url">Vue官网</a>
  <!-- 简写：:href -->
  <a :href="url">Vue官网（简写）</a>

  <!-- 绑定class属性（对象语法：键是类名，值是布尔值） -->
  <div :class="{ active: isActive, 'text-red': hasError }">样式绑定</div>

  <!-- 绑定style属性（对象语法） -->
  <div :style="{ fontSize: size + 'px', color: 'blue' }">内联样式</div>

  <!-- 绑定自定义属性 -->
  <div :data-id="id">自定义属性</div>
</div>

<script>
new Vue({
  el: '#app',
  data: {
    url: 'https://v2.cn.vuejs.org/',
    isActive: true,
    hasError: false,
    size: 16,
    id: 1001
  }
});
</script>
```

#### 2.3 双向数据绑定（v-model，仅用于表单元素）

`v-model` 实现“数据 ↔ 视图”双向同步：视图修改会同步到数据，数据修改会同步到视图，仅支持表单元素（input、select、textarea等）。

```html
<div id="app">
  <!-- 输入框双向绑定 -->
  <input v-model="username" placeholder="请输入用户名">
  <p>你输入的用户名：{{ username }}</p>

  <!-- 修饰符：.trim（去除首尾空格） -->
  <input v-model.trim="content" placeholder="输入内容（自动去空格）">

  <!-- 修饰符：.number（转为数字） -->
  <input v-model.number="age" type="number" placeholder="请输入年龄">

  <!-- 修饰符：.lazy（失去焦点后同步） -->
  <input v-model.lazy="email" placeholder="懒加载同步">
</div>

<script>
new Vue({
  el: '#app',
  data: {
    username: '',
    content: '',
    age: 0,
    email: ''
  }
});
</script>
```

### 3. 元素绑定（事件/样式/条件/循环绑定）

你提到的“元素绑定”核心是**事件绑定**（v-on）和**样式绑定**（已在v-bind中提过），补充核心的事件绑定：

#### 3.1 事件绑定（v-on，绑定DOM事件）

`v-on` 用于给DOM元素绑定事件（如click、input、mouseover等），简写为 `@`。

```html
<div id="app">
  <!-- 基础事件绑定 -->
  <button v-on:click="sayHello">点击打招呼</button>
  <!-- 简写：@click -->
  <button @click="sayHello">点击打招呼（简写）</button>

  <!-- 传参 + 事件对象 -->
  <button @click="handleClick(100, $event)">传参+事件对象</button>

  <!-- 事件修饰符：.stop（阻止冒泡）、.prevent（阻止默认行为） -->
  <a @click.stop.prevent="handleLink" href="https://vuejs.org/">阻止跳转+冒泡</a>
</div>

<script>
new Vue({
  el: '#app',
  methods: { // 事件处理函数写在methods中
    sayHello() {
      alert('Hello Vue2!');
    },
    handleClick(num, e) {
      console.log('参数：', num);
      console.log('事件对象：', e.target);
    },
    handleLink() {
      alert('链接被点击，但不会跳转');
    }
  }
});
</script>
```

#### 3.2 补充：条件/循环绑定（常用元素操作）

这是元素绑定的延伸，新手也需要掌握：

```html
<div id="app">
  <!-- 条件绑定：v-if/v-else -->
  <div v-if="isLogin">欢迎回来！</div>
  <div v-else>请先登录</div>

  <!-- 循环绑定：v-for（遍历数组） -->
  <ul>
    <li v-for="(item, index) in list" :key="index">
      {{ index + 1 }} - {{ item }}
    </li>
  </ul>
</div>

<script>
new Vue({
  el: '#app',
  data: {
    isLogin: false,
    list: ['Vue2', '数据绑定', '挂载', '事件绑定']
  }
});
</script>
```

## 三、完整示例（整合所有核心知识点）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2 核心用法示例</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
  <style>
    .active { color: red; font-weight: bold; }
    .text-blue { color: blue; }
  </style>
</head>
<body>
  <div id="app">
    <!-- 挂载 + 文本插值 -->
    <h1>{{ title }}</h1>

    <!-- 双向数据绑定（表单） -->
    <input v-model="inputValue" placeholder="输入内容">
    <p>你输入的内容：{{ inputValue }}</p>

    <!-- 事件绑定 + 样式绑定 -->
    <button @click="toggleActive" :class="{ active: isActive }">
      点击切换样式
    </button>

    <!-- 指令绑定（属性） -->
    <img :src="imgUrl" :alt="title" style="width: 100px;">

    <!-- 循环绑定 -->
    <ul>
      <li v-for="(item, i) in list" :key="i" @click="deleteItem(i)">
        {{ item }}（点击删除）
      </li>
    </ul>
  </div>

  <script>
    // 创建Vue实例 + 手动挂载
    const vm = new Vue({
      data: {
        title: 'Vue2 核心用法',
        inputValue: '',
        isActive: false,
        imgUrl: 'https://v2.cn.vuejs.org/images/logo.png',
        list: ['挂载', '数据绑定', '事件绑定', '样式绑定']
      },
      methods: {
        toggleActive() {
          this.isActive = !this.isActive; // 修改data中的数据，视图自动更新
        },
        deleteItem(index) {
          this.list.splice(index, 1); // 删除数组元素，视图自动更新
        }
      }
    }).$mount('#app'); // 手动挂载
  </script>
</body>
</html>
```

## 四、总结

### 关键点回顾

1. **挂载**：Vue2实例通过 `el` 选项（直接）或 `$mount()` 方法（手动）关联DOM，一个实例仅挂载一个元素；
2. **数据绑定**：核心分三类——`{{ }}` 文本插值、`v-bind/:` 绑定HTML属性、`v-model` 表单双向绑定；
3. **元素绑定**：事件用 `v-on/@` 绑定（支持传参/修饰符），样式用 `v-bind` 的对象/数组语法，循环用 `v-for`（必须加key）、条件用 `v-if`。

### 核心思想

Vue2的核心是“数据驱动视图”：你只需要修改`data`中的数据，Vue会自动更新对应的视图，无需手动操作DOM，这也是Vue对比原生JS的最大优势。
