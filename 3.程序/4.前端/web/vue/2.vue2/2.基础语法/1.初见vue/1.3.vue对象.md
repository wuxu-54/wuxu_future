# vue2 对象

## 一、核心概念区分

首先明确两个易混淆的概念，这是理解Vue对象的前提：

| 类型                | 定义                                                                 | 示例                          |
|---------------------|----------------------------------------------------------------------|-------------------------------|
| Vue构造函数（全局） | Vue2的核心入口，是一个全局构造函数，挂载了静态属性/方法，用于全局配置、注册、创建实例 | `Vue`、`Vue.component()`、`Vue.mixin()` |
| Vue实例（局部）     | 通过`new Vue()`创建的对象，是Vue应用的最小运行单元，对应具体的DOM挂载点 | `const vm = new Vue({ el: '#app' })` |

简单来说：`Vue` 是“工厂”，负责生产实例；`vm`（Vue实例）是“产品”，负责具体的页面渲染和交互。

## 二、Vue构造函数（全局Vue对象）

`Vue` 作为全局构造函数，本身挂载了大量**静态属性**和**静态方法**，用于全局层面的配置、注册、扩展，是Vue2的“全局工具箱”。

### 1. 静态属性（Vue.xxx）

静态属性用于全局配置或获取Vue的基础信息，核心常用的有：

#### （1）Vue.version

获取当前Vue2的版本号，常用于版本兼容判断：

```javascript
console.log(Vue.version); // 输出如：2.7.16
if (Vue.version < '2.6.0') {
  console.log('当前Vue版本低于2.6.0，不支持某些特性');
}
```

#### （2）Vue.config

Vue的全局配置对象，用于设置全局的行为规则，核心配置项：

```javascript
// 1. 关闭生产环境的提示
Vue.config.productionTip = false;

// 2. 自定义错误处理函数（全局捕获Vue的报错）
Vue.config.errorHandler = (err, vm, info) => {
  console.error('Vue全局错误：', err, '报错位置：', info);
};

// 3. 自定义警告处理（开发环境有效）
Vue.config.warnHandler = (msg, vm, trace) => {
  console.warn('Vue全局警告：', msg, '调用栈：', trace);
};

// 4. 自定义指令/组件的前缀（避免冲突）
Vue.config.optionMergeStrategies.myOption = (parent, child) => {
  // 自定义自定义选项的合并规则（比如之前讲的myOption）
  return child || parent;
};
```

#### （3）Vue.options

存储Vue的全局默认选项，包括全局注册的组件、指令、过滤器、混入等：

```javascript
// 查看全局注册的组件
console.log(Vue.options.components); // 包含Vue内置组件（如<keep-alive>）和全局注册的组件

// 查看全局注册的指令
console.log(Vue.options.directives); // 包含v-model、v-show等内置指令

// 查看全局混入
console.log(Vue.options.mixins); // 包含通过Vue.mixin()注册的全局混入
```

### 2. 静态方法（Vue.xxx()）

静态方法是Vue构造函数提供的全局工具方法，用于扩展Vue的能力，核心常用的有：

#### （1）Vue.extend()：创建组件构造器（组件的底层实现）

用于基于Vue构造函数创建“子类”（组件构造器），是自定义组件的底层原理（`Vue.component()` 内部就是调用它）：

```javascript
// 1. 创建组件构造器
const MyComponent = Vue.extend({
  template: '<div>{{ msg }}</div>',
  data() {
    return { msg: '通过Vue.extend创建的组件' };
  }
});

// 2. 创建组件实例并挂载
new MyComponent().$mount('#app');
```

#### （2）Vue.component()：全局注册组件

之前讲过的全局组件注册，底层依赖`Vue.extend()`：

```javascript
// 简写形式（内部自动调用Vue.extend）
Vue.component('my-button', {
  template: '<button>全局按钮</button>'
});
```

#### （3）Vue.mixin()：全局混入

全局注入配置到所有Vue实例，慎用（会污染所有实例）：

```javascript
Vue.mixin({
  created() {
    console.log('全局混入的created钩子');
  }
});
```

#### （4）Vue.directive()：全局注册自定义指令

注册全局指令（如v-focus、v-copy）：

```javascript
// 注册全局指令v-focus：自动聚焦输入框
Vue.directive('focus', {
  inserted(el) { // 指令绑定的元素插入DOM时执行
    el.focus();
  }
});

// 使用：<input v-focus>
```

#### （5）Vue.filter()：全局注册过滤器

用于格式化数据（如日期、金额）：

```javascript
// 注册全局过滤器：格式化金额
Vue.filter('formatPrice', (value) => {
  return '¥' + Number(value).toFixed(2);
});

// 使用：<p>{{ 99 | formatPrice }}</p> → 输出¥99.00
```

#### （6）Vue.use()：安装Vue插件

用于加载Vue插件（如VueRouter、Vuex、ElementUI）：

```javascript
// 示例：安装VueRouter插件
import VueRouter from 'vue-router';
Vue.use(VueRouter); // 插件必须在new Vue()之前安装
```

#### （7）Vue.nextTick()：异步更新DOM

等待Vue的DOM更新循环结束后执行回调（解决“修改数据后立即操作DOM无效”的问题）：

```javascript
const vm = new Vue({
  el: '#app',
  data: { msg: 'hello' }
});

vm.msg = 'world';
console.log(vm.$el.textContent); // 输出：hello（DOM未更新）

Vue.nextTick(() => {
  console.log(vm.$el.textContent); // 输出：world（DOM已更新）
});
```

#### （8）Vue.set() / Vue.delete()：响应式修改数据

解决Vue2无法检测数组下标修改、对象新增属性的响应式问题：

```javascript
const vm = new Vue({
  data: {
    obj: { name: '张三' },
    arr: [1, 2, 3]
  }
});

// 给对象新增响应式属性
Vue.set(vm.obj, 'age', 20);

// 删除对象的响应式属性
Vue.delete(vm.obj, 'name');

// 修改数组指定下标的响应式值
Vue.set(vm.arr, 0, 100);
```

## 三、Vue实例（new Vue() 创建的对象）

通过`new Vue(options)`创建的实例（通常命名为`vm`，View Model的缩写）是Vue应用的核心运行单元，每个实例对应一个DOM挂载点，封装了数据、方法、生命周期等核心能力。

### 1. 实例的创建

基本语法：

```javascript
// 完整的实例创建示例
const vm = new Vue({
  // 核心配置选项
  el: '#app', // 挂载DOM元素（等价于vm.$mount('#app')）
  data: { msg: 'Vue实例' }, // 实例的响应式数据
  methods: { // 实例方法（可通过vm.xxx调用）
    sayHi() { console.log('hi'); }
  },
  computed: { // 计算属性
    reversedMsg() { return this.msg.split('').reverse().join(''); }
  },
  watch: { // 监听数据变化
    msg(newVal) { console.log('msg变了：', newVal); }
  },
  created() { // 生命周期钩子
    console.log('实例已创建');
  }
});
```

### 2. 实例的内置属性（vm.$xxx）

实例的内置属性以`$`开头（区分自定义属性），是访问实例内部状态的核心入口：

| 内置属性 | 作用                                                                 | 示例                          |
|----------|----------------------------------------------------------------------|-------------------------------|
| $el      | 实例挂载的DOM元素（只读）                                            | `vm.$el` → 对应<div id="app"></div> |
| $data    | 实例的响应式数据对象（等同于vm.xxx，但$data是原始引用）              | `vm.$data.msg` → 等价于vm.msg |
| $options | 实例的配置选项（包含内置选项+自定义选项）                            | `vm.$options.el` → '#app'     |
| $refs    | 引用模板中通过ref标记的DOM元素/组件实例                              | `vm.$refs.input` → 获取<input ref="input"> |
| $parent  | 父实例（仅子组件实例有）                                            | `vm.$parent` → 父组件实例     |
| $children| 子组件实例列表（仅父组件实例有，非响应式）                          | `vm.$children[0]` → 第一个子组件 |
| $root    | 根实例（所有组件实例都能通过$root访问根实例）                        | `vm.$root` → 根Vue实例        |
| $attrs   | 父组件传递的非props属性（用于透传属性）                              | `vm.$attrs` → { id: 'test' }  |
| $listeners | 父组件传递的事件监听器（用于透传事件）                              | `vm.$listeners` → { click: fn } |

#### 示例：实例内置属性的使用

```html
<div id="app">
  <input ref="input" type="text">
  <my-child></my-child>
</div>

<script>
Vue.component('my-child', {
  template: '<div>子组件</div>',
  created() {
    console.log(this.$parent); // 指向根实例vm
    console.log(this.$root); // 也指向根实例vm
  }
});

const vm = new Vue({ el: '#app' });
console.log(vm.$el); // <div id="app">...</div>
console.log(vm.$refs.input); // <input type="text">
console.log(vm.$data.msg); // 等价于vm.msg
</script>
```

### 3. 实例的内置方法（vm.$xxx()）

实例的内置方法以`$`开头，用于操作实例的状态、DOM、事件等：

#### （1）vm.$mount()：手动挂载实例

替代`el`选项，用于延迟挂载（比如异步获取数据后挂载）：

```javascript
const vm = new Vue({
  data: { msg: '手动挂载' }
});
// 手动挂载到#app
vm.$mount('#app');
```

#### （2）vm.$destroy()：销毁实例

销毁实例后，实例的所有生命周期钩子、事件监听、响应式系统都会失效：

```javascript
// 销毁实例（比如页面卸载时）
vm.$destroy();
```

#### （3）vm.$emit() / vm.$on() / vm.$off()：实例事件系统

用于组件通信（子传父、事件总线）：

```javascript
// 监听事件
vm.$on('my-event', (data) => {
  console.log('收到事件：', data);
});

// 触发事件
vm.$emit('my-event', { msg: 'hello' });

// 解绑事件
vm.$off('my-event');
```

#### （4）vm.$watch()：动态监听数据

替代配置项中的`watch`，支持动态添加/移除监听：

```javascript
// 监听msg的变化
const unwatch = vm.$watch('msg', (newVal, oldVal) => {
  console.log('msg从', oldVal, '变到', newVal);
});

// 停止监听
unwatch();
```

#### （5）vm.$nextTick()：实例级的DOM异步更新

和`Vue.nextTick()`功能一致，但回调中的`this`默认指向当前实例：

```javascript
vm.msg = 'new msg';
vm.$nextTick(function() {
  console.log(this.$el.textContent); // 输出new msg（this指向vm）
});
```

#### （6）vm.$set() / vm.$delete()：实例级的响应式修改

和`Vue.set()`/`Vue.delete()`功能一致，只是无需传递实例参数：

```javascript
// 等价于Vue.set(vm.obj, 'age', 20)
vm.$set(vm.obj, 'age', 20);
```

### 4. 实例的生命周期

每个Vue实例都有完整的生命周期，通过**生命周期钩子**（如created、mounted、updated、destroyed）可以在不同阶段执行自定义逻辑，这是控制实例行为的核心方式：

```javascript
new Vue({
  created() { // 实例创建完成（DOM未挂载）
    console.log('实例已创建，$el还未生成：', this.$el); // undefined
  },
  mounted() { // 实例挂载完成（DOM已生成）
    console.log('实例已挂载，$el：', this.$el); // <div id="app">...</div>
  },
  updated() { // 数据更新导致DOM更新后
    console.log('实例已更新');
  },
  destroyed() { // 实例销毁后
    console.log('实例已销毁');
  }
});
```

## 四、核心综合示例（Vue对象全场景使用）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue对象综合示例</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
</head>
<body>
  <div id="app">
    <p>{{ msg }}</p>
    <p>{{ msg | formatMsg }}</p>
    <input ref="input" v-focus type="text">
    <button @click="changeMsg">修改数据</button>
    <my-component></my-component>
  </div>

  <script>
    // 1. Vue构造函数的静态方法：注册全局过滤器
    Vue.filter('formatMsg', (value) => {
      return '格式化：' + value.toUpperCase();
    });

    // 2. Vue构造函数的静态方法：注册全局指令
    Vue.directive('focus', {
      inserted(el) { el.focus(); }
    });

    // 3. Vue构造函数的静态方法：注册全局组件
    Vue.component('my-component', {
      template: '<div>全局组件</div>',
      created() {
        // 组件实例访问根实例
        console.log('组件的根实例：', this.$root.msg);
      }
    });

    // 4. 创建Vue实例（核心）
    const vm = new Vue({
      el: '#app',
      data: {
        msg: 'Hello Vue对象'
      },
      methods: {
        changeMsg() {
          // 实例方法修改数据
          this.msg = 'Vue构造函数 & 实例';
          // 实例内置方法：异步更新DOM
          this.$nextTick(() => {
            console.log('DOM更新后：', this.$el.querySelector('p').textContent);
          });
        }
      },
      created() {
        // 实例内置属性：访问配置选项
        console.log('实例的el配置：', this.$options.el);
        // 实例内置方法：监听数据
        this.$watch('msg', (newVal) => {
          console.log('msg更新：', newVal);
        });
      }
    });

    // 5. Vue构造函数的静态属性：查看版本
    console.log('Vue版本：', Vue.version);

    // 6. Vue构造函数的静态方法：响应式修改数据
    Vue.set(vm.$data, 'newProp', '新增响应式属性');
    console.log(vm.newProp); // 新增响应式属性
  </script>
</body>
</html>
```

## 总结

### 关键点回顾

1. **Vue构造函数（全局）**：是Vue的核心入口，挂载静态属性（`Vue.config`/`Vue.version`）和静态方法（`Vue.component`/`Vue.set`/`Vue.nextTick`），用于全局配置、注册、扩展；
2. **Vue实例（局部）**：是应用的运行单元，通过`new Vue()`创建，内置属性（`$el`/`$data`/`$refs`）用于访问内部状态，内置方法（`$emit`/`$mount`/`$nextTick`）用于操作实例行为；
3. **核心区别**：Vue构造函数是“全局工具”，作用于所有实例；Vue实例是“具体产品”，作用于单个挂载点，且实例的内置API（`$set`/`$nextTick`）是全局API的实例化封装。

### 核心原则

- 全局Vue对象（构造函数）负责“全局层面”的扩展和配置，实例负责“具体业务”的渲染和交互；
- 实例的内置属性/方法以`$`开头，是Vue内置的，避免和自定义属性/方法重名；
- Vue2的核心是“数据驱动视图”，无论是构造函数还是实例，最终都是为了让实例的响应式数据和DOM联动。
