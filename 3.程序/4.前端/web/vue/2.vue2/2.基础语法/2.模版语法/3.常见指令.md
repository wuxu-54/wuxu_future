# 常见的指令

## Vue2 全量内置指令（按功能分类）

### 一、内容渲染指令（控制元素内容展示）

这类指令用于将数据渲染到页面的 DOM 元素中，是最基础的指令。

| 指令       | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-text`   | 更新元素的 `textContent`（纯文本），会覆盖元素原有内容               | ```html <div v-text="message"></div>```<br>数据：`message: 'Hello Vue'` | 等同于 `{{ message }}`，但不会出现插值闪烁；优先级高于元素内默认文本     |
| `v-html`   | 更新元素的 `innerHTML`，可渲染 HTML 结构，会覆盖元素原有内容         | ```html <div v-html="htmlStr"></div>```<br>数据：`htmlStr: '<h1>标题</h1>'` | 🔥 安全风险：仅渲染可信内容，禁止渲染用户输入的 HTML（防止 XSS 攻击）    |
| `v-cloak`  | 解决插值表达式 `{{ }}` 渲染前的“闪烁问题”（显示原始 {{}} 符号）       | ```css [v-cloak] { display: none; }```<br>```html <div v-cloak>{{ msg }}</div>``` | 需配合 CSS 使用；Vue 实例挂载完成后，会自动移除该指令，元素恢复显示      |

### 二、条件渲染指令（控制元素是否渲染/显示）

这类指令根据条件动态控制 DOM 元素的创建/销毁或显示/隐藏。

| 指令           | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|----------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-if`         | 条件渲染：满足条件则创建元素，不满足则销毁（惰性渲染）                 | ```html <div v-if="isShow">显示内容</div>```<br>数据：`isShow: true`     | 初始条件不满足时，元素不会被渲染；可单独使用，也可搭配 `v-else-if`/`v-else` |
| `v-else-if`    | `v-if` 的“else if”分支，需紧跟 `v-if` 或 `v-else-if` 之后             | ```html <div v-if="type === 'A'">A</div> <div v-else-if="type === 'B'">B</div>``` | 不能单独使用；多个 `v-else-if` 可连续使用                                |
| `v-else`       | `v-if` 的“else”分支，需紧跟 `v-if` 或 `v-else-if` 之后                | ```html <div v-if="isShow">显示</div> <div v-else>隐藏</div>```          | 不能单独使用；前后元素不能有“中断”（如 `v-for` 或其他元素隔开）           |
| `v-show`       | 条件显示：通过 `display: none` 控制元素隐藏/显示，元素始终存在于 DOM  | ```html <div v-show="isShow">一直存在的元素</div>```                     | 初始渲染会创建元素；切换开销小，适合频繁切换的场景（对比 `v-if` 惰性渲染） |

#### ✅ `v-if` vs `v-show` 核心区别

| 维度         | `v-if`                          | `v-show`                        |
|--------------|---------------------------------|---------------------------------|
| 渲染机制     | 动态创建/销毁 DOM 元素          | 仅切换 `display` 样式，DOM 始终存在 |
| 初始渲染开销 | 条件不满足时无开销（惰性）      | 无论条件如何，都有初始渲染开销  |
| 切换开销     | 高（重建/销毁元素）             | 低（仅改样式）                  |
| 适用场景     | 不频繁切换的条件渲染            | 频繁切换的条件显示              |

### 三、列表渲染指令（循环渲染列表数据）

核心指令 `v-for`，用于遍历数组、对象、数字、字符串等，生成重复的 DOM 元素。

| 指令       | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-for`    | 遍历数据生成列表，支持数组、对象、数字、字符串                       | 1. 遍历数组：<br>```html <li v-for="(item, index) in list" :key="index">{{ item }}</li>```<br>数据：`list: ['A', 'B', 'C']`<br>2. 遍历对象：<br>```html <li v-for="(value, key, index) in obj" :key="key">{{ key }}: {{ value }}</li>```<br>数据：`obj: { name: 'Vue', version: '2.x' }` | 🔥 必须加 `key`：优先使用唯一 ID（如后端返回的 id），避免用 index（列表重排时会导致性能问题/错误）；<br>不能在 `v-for` 同级使用 `v-if`（Vue2 会警告，可将 `v-if` 移到子元素） |

### 四、事件绑定指令（绑定 DOM 事件）

核心指令 `v-on`，用于给元素绑定事件监听器，支持事件修饰符和按键修饰符。

| 指令       | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-on`     | 绑定事件监听器，缩写 `@`；支持传参、事件对象 `$event`                 | 1. 基础用法：<br>```html <button v-on:click="handleClick">点击</button>```<br>2. 缩写：<br>```html <button @click="handleClick">点击</button>```<br>3. 传参+事件对象：<br>```html <button @click="handleClick(10, $event)">点击</button>```<br>方法：<br>```js handleClick(num, e) { console.log(num, e); }``` | 事件名无需加 `on`（如 `click` 而非 `onclick`）；<br>原生事件（如 `click`/`mouseover`）和自定义事件都支持 |

#### ✅ `v-on` 核心修饰符（Vue2 全量）

| 修饰符         | 作用                                                                 | 示例                          |
|----------------|----------------------------------------------------------------------|-------------------------------|
| `.stop`        | 阻止事件冒泡（等同于 `e.stopPropagation()`）                         | `@click.stop="handleClick"`   |
| `.prevent`     | 阻止默认行为（等同于 `e.preventDefault()`）                         | `@submit.prevent="handleSubmit"` |
| `.capture`     | 事件捕获模式（从外到内触发）                                         | `@click.capture="handleClick"` |
| `.self`        | 仅当事件触发在元素本身（而非子元素）时才执行                         | `@click.self="handleClick"`   |
| `.once`        | 事件仅触发一次                                                       | `@click.once="handleClick"`   |
| `.passive`     | 优化移动端滚动性能（告知浏览器无需阻止默认行为）                     | `@touchmove.passive="handleMove"` |
| `.native`      | 给组件绑定原生事件（组件需触发原生事件）                             | `<my-component @click.native="handleClick"></my-component>` |
| 按键修饰符     | 仅当按下指定按键时触发事件                                           | `@keyup.enter="handleEnter"`（回车）、`@keyup.esc="handleEsc"`（ESC）、`@keyup.tab`（Tab）、`@keyup.delete`（删除/退格）、`@keyup.space`（空格）、`@keyup.up/down/left/right`（方向键） |
| 自定义按键修饰符 | 通过 `Vue.config.keyCodes` 自定义（Vue2 专属，Vue3 已移除）          | ```js Vue.config.keyCodes.f1 = 112;```<br>使用：`@keyup.f1="handleF1"` |

### 五、属性绑定指令（绑定 HTML 属性/组件 Props）

核心指令 `v-bind`，用于动态绑定 HTML 元素的属性、组件的 Props，支持对象/数组语法。

| 指令       | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-bind`   | 动态绑定属性，缩写 `:`；支持单个属性、多个属性、样式/类名绑定         | 1. 单个属性：<br>```html <img v-bind:src="imgUrl" alt="图片">```<br>缩写：<br>```html <img :src="imgUrl" alt="图片">```<br>2. 多个属性：<br>```html <div v-bind="attrs"></div>```<br>数据：`attrs: { id: 'box', class: 'container' }` | 可绑定任意 HTML 属性（如 `src`/`href`/`class`/`style`/`disabled` 等）；<br>绑定布尔属性（如 `disabled`）时，值为 `false` 会移除该属性 |

#### ✅ `v-bind` 核心修饰符（仅 2 个）

| 修饰符         | 作用                                                                 | 示例                          |
|----------------|----------------------------------------------------------------------|-------------------------------|
| `.sync`        | 实现 Props 双向绑定（语法糖，Vue2.3+），替代 `v-model` 用于组件       | 父组件：`<my-component :title.sync="title"></my-component>`<br>子组件：`this.$emit('update:title', '新标题')` | 本质是 `@update:title` 事件的语法糖；不能和表达式一起使用（如 `:title.sync="title + '123'"` 无效） |
| `.prop`        | 将绑定的属性设为 DOM 元素的“property”而非“attribute”                 | `<input :value.prop="inputValue">` | 少数场景使用（如 DOM 元素的 `value` property 和 attribute 不一致时）     |

### 六、表单双向绑定指令（`v-model`）

专门用于表单元素的双向数据绑定，自动同步视图和数据，支持多种表单类型和修饰符。

| 指令       | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-model`  | 表单元素双向绑定，支持 input/textarea/select/checkbox/radio 等       | 1. 输入框：<br>```html <input v-model="username" type="text">```<br>2. 复选框（单个）：<br>```html <input v-model="isAgree" type="checkbox">```<br>3. 复选框（多个）：<br>```html <input v-model="hobbies" type="checkbox" value="game">```<br>数据：`hobbies: []` | 本质是 `v-bind:value` + `v-on:input` 的语法糖；<br>组件中使用需手动实现 `value` Props 和 `input` 事件 |

#### ✅ `v-model` 核心修饰符（Vue2 全量）

| 修饰符         | 作用                                                                 | 示例                          |
|----------------|----------------------------------------------------------------------|-------------------------------|
| `.lazy`        | 从“input”事件触发改为“change”事件触发（失去焦点/回车时同步数据）      | `<input v-model.lazy="username">` | 减少数据同步频率，适合无需实时同步的场景                                 |
| `.number`      | 自动将输入值转为数字类型（非数字则返回原始字符串）                   | `<input v-model.number="age" type="text">` | 适合数字输入框（如年龄、手机号），避免手动转换类型                       |
| `.trim`        | 自动过滤输入值的首尾空格                                             | `<input v-model.trim="username">` | 适合用户名、密码等需要去除首尾空格的场景                                 |

### 七、特殊指令（编译优化/特殊场景）

这类指令用于控制 Vue 的编译过程，或实现特殊的渲染逻辑。

| 指令       | 作用                                                                 | 语法/示例                                                                 | 注意事项                                                                 |
|------------|----------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------|
| `v-pre`    | 跳过元素及其子元素的编译过程，直接显示原始内容（包括 `{{ }}`）        | ```html <div v-pre>{{ message }}</div>```<br>页面显示：`{{ message }}` | 用于静态内容（无需编译），提升渲染性能                                   |
| `v-once`   | 元素/组件仅渲染一次，后续数据变化不再更新（静态渲染）                 | ```html <div v-once>{{ message }}</div>```<br>数据更新后，该元素内容不变 | 适合永不变化的静态内容，减少响应式开销                                   |
| `v-slot`   | 定义插槽（Vue2.6+ 新增，替代废弃的 `slot`/`slot-scope` 指令），缩写 `#` | 1. 默认插槽：<br>```html <my-component v-slot:default>默认内容</my-component>```<br>缩写：<br>```html <my-component #default>默认内容</my-component>```<br>2. 具名插槽：<br>```html <my-component #header>头部内容</my-component>```<br>3. 作用域插槽：<br>```html <my-component #item="scope"><div>{{ scope.data }}</div></my-component>``` | 🔥 仅能用于 `<template>` 标签或组件标签本身；<br>Vue2.6 前的 `slot`/`slot-scope` 已废弃，建议使用 `v-slot` |

## 总结

1. Vue2 核心指令分为 7 大类：内容渲染、条件渲染、列表渲染、事件绑定、属性绑定、表单绑定、特殊指令，覆盖了数据渲染、交互、编译优化等核心场景。
2. 高频指令需重点掌握：`v-if`/`v-show`（条件）、`v-for`（列表，必加 `key`）、`v-on`（@，事件修饰符）、`v-bind`（:，属性绑定）、`v-model`（双向绑定，修饰符）。
3. 注意版本差异：`v-slot` 是 Vue2.6+ 标准，替代废弃的 `slot`/`slot-scope`；`v-bind.sync` 是 Vue2 专属的双向绑定语法糖。
