# vue2 路由

## 一、路由核心基础

### 1. 核心概念

- **SPA（单页面应用）**：整个应用只有一个HTML页面，页面切换通过JS动态替换DOM内容实现，路由是SPA的核心实现方式；
- **vue-router**：Vue2官方的路由插件，专门用于管理SPA的页面跳转，核心作用是**建立“路径”与“组件”的映射关系**；
- **版本匹配**：Vue2必须使用`vue-router 3.x`（Vue3对应`vue-router 4.x`），版本不匹配会导致报错。

### 2. 安装方式

#### （1）CDN方式（新手推荐，无需配置环境）

```html
<!-- 先引入Vue2，再引入vue-router 3.x -->
<script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
<script src="https://cdn.jsdelivr.net/npm/vue-router@3.6.5/dist/vue-router.js"></script>
```

#### （2）npm方式（项目开发常用）

```bash
# 安装指定版本（Vue2专用）
npm install vue-router@3 --save
# 或 yarn add vue-router@3
```

## 二、路由基础配置与使用

### 1. 最小化完整示例（CDN版）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2路由基础</title>
  <!-- 引入Vue2和vue-router 3.x -->
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/vue-router@3.6.5/dist/vue-router.js"></script>
</head>
<body>
  <div id="app">
    <!-- 2. 路由导航链接：替代a标签，不会刷新页面 -->
    <router-link to="/home">首页</router-link>
    <router-link to="/about">关于</router-link>

    <!-- 3. 路由出口：匹配的组件会渲染到这里 -->
    <router-view></router-view>
  </div>

  <script>
    // 1. 定义路由组件（普通Vue组件）
    const Home = { template: '<div>首页内容</div>' };
    const About = { template: '<div>关于我们</div>' };

    // 2. 定义路由规则：路径 → 组件的映射
    const routes = [
      { path: '/home', component: Home }, // 首页路由
      { path: '/about', component: About }, // 关于路由
      { path: '/', redirect: '/home' } // 重定向：默认跳首页
    ];

    // 3. 创建路由实例
    const router = new VueRouter({
      routes // 简写，等价于 routes: routes
    });

    // 4. 挂载路由到Vue根实例
    new Vue({
      el: '#app',
      router // 注入路由，所有子组件可通过this.$router/this.$route访问
    });
  </script>
</body>
</html>
```

### 2. 核心组件/API解释

| 核心元素          | 作用                                                                 |
|-------------------|----------------------------------------------------------------------|
| `router-link`     | 路由导航组件，替代`<a>`标签，点击不会刷新页面，`to`属性指定目标路径 |
| `router-view`     | 路由出口，匹配的路由组件会渲染到这个位置                             |
| `VueRouter`       | 路由构造函数，用于创建路由实例                                       |
| `routes`          | 路由规则数组，每个规则是`{ path: 路径, component: 组件 }`的对象      |
| `redirect`        | 路由重定向，比如根路径`/`重定向到`/home`                             |
| `this.$router`    | 路由实例（全局唯一），用于编程式导航（如`this.$router.push`）        |
| `this.$route`     | 当前路由信息对象，包含路径、参数、查询等信息（如`this.$route.path`）  |

### 3. 路由模式（hash/history）

`vue-router`支持两种路由模式，在创建路由实例时通过`mode`配置：

```javascript
const router = new VueRouter({
  mode: 'history', // 可选：hash（默认）/ history
  routes
});
```

| 模式   | 特点                                                                 | 注意事项                                   |
|--------|----------------------------------------------------------------------|--------------------------------------------|
| hash   | URL带`#`（如`http://localhost/#/home`），基于锚点实现，无需后端配置   | 兼容性好，所有浏览器支持                   |
| history| URL无`#`（如`http://localhost/home`），基于HTML5 History API         | 需后端配置（刷新404问题），仅支持现代浏览器 |

## 三、路由参数传递

实际开发中常需要在路由跳转时传递数据，Vue2路由支持两种核心传参方式：

### 1. Query参数（查询字符串，?key=value）

- **特点**：参数拼接在URL后，刷新页面不丢失，适合非敏感、可选参数；
- **配置**：无需修改路由规则，直接在跳转时拼接；
- **示例**：

```html
<div id="app">
  <!-- 1. 声明式导航传query参数 -->
  <router-link to="/user?id=1001&name=张三">用户1001</router-link>
  <!-- 动态拼接query参数（模板中） -->
  <router-link :to="{ path: '/user', query: { id: 1002, name: '李四' } }">用户1002</router-link>

  <router-view></router-view>
</div>

<script>
  const User = {
    template: `
      <div>
        <!-- 3. 获取query参数 -->
        <p>用户ID：{{ $route.query.id }}</p>
        <p>用户名：{{ $route.query.name }}</p>
      </div>
    `
  };

  const routes = [{ path: '/user', component: User }];
  const router = new VueRouter({ routes });
  new Vue({ el: '#app', router });
</script>
```

### 2. Params参数（动态路由，/path/:param）

- **特点**：参数嵌入URL路径中，刷新页面不丢失，适合必填、核心参数；
- **配置**：需先定义动态路由规则（`:参数名`）；
- **示例**：

```html
<div id="app">
  <!-- 1. 声明式导航传params参数 -->
  <router-link to="/user/1001/张三">用户1001</router-link>
  <!-- 动态拼接params参数（模板中，需用name匹配路由） -->
  <router-link :to="{ name: 'User', params: { id: 1002, name: '李四' } }">用户1002</router-link>

  <router-view></router-view>
</div>

<script>
  const User = {
    template: `
      <div>
        <!-- 3. 获取params参数 -->
        <p>用户ID：{{ $route.params.id }}</p>
        <p>用户名：{{ $route.params.name }}</p>
      </div>
    `
  };

  // 2. 定义动态路由规则（name用于params动态跳转）
  const routes = [{ 
    path: '/user/:id/:name', // 动态参数：id和name
    name: 'User', // 路由命名
    component: User 
  }];

  const router = new VueRouter({ routes });
  new Vue({ el: '#app', router });
</script>
```

### 3. 传参注意事项

- `params`参数必须配合**命名路由**（`name`）或直接拼接路径使用，不能用`path`+`params`（会失效）；
- 动态路由参数可设置可选：`/user/:id?`（`?`表示id可选）；
- 获取参数时，若参数不存在，`$route.params.xxx`会返回`undefined`，可添加默认值（如`$route.params.id || '默认ID'`）。

## 四、编程式导航（JS控制路由跳转）

除了`router-link`（声明式导航），还可以通过`this.$router`的方法实现JS控制跳转（编程式导航），核心方法：

| 方法                | 作用                                                                 | 示例                                      |
|---------------------|----------------------------------------------------------------------|-------------------------------------------|
| `$router.push()`    | 跳转到指定路由，新增历史记录（可返回上一页）                         | `this.$router.push('/home')`              |
| `$router.replace()` | 跳转到指定路由，替换当前历史记录（不可返回上一页）                   | `this.$router.replace('/about')`          |
| `$router.go(n)`     | 历史记录前进/后退n步（n为正数前进，负数后退）                        | `this.$router.go(-1)`（返回上一页）       |

### 示例：编程式导航+传参

```html
<div id="app">
  <button @click="toHome">跳首页</button>
  <button @click="toUserQuery">用户（query）</button>
  <button @click="toUserParams">用户（params）</button>
  <router-view></router-view>
</div>

<script>
  const Home = { template: '<div>首页</div>' };
  const User = {
    template: `
      <div>
        <p>Query ID：{{ $route.query.id }}</p>
        <p>Params ID：{{ $route.params.id }}</p>
      </div>
    `
  };

  const routes = [
    { path: '/home', component: Home },
    { path: '/user', component: User }, // query路由
    { path: '/user/:id', name: 'User', component: User } // params路由
  ];

  const router = new VueRouter({ routes });
  new Vue({
    el: '#app',
    router,
    methods: {
      toHome() {
        this.$router.push('/home'); // 简单跳转
      },
      toUserQuery() {
        // push传query参数
        this.$router.push({ path: '/user', query: { id: 1001 } });
      },
      toUserParams() {
        // push传params参数（必须用name）
        this.$router.push({ name: 'User', params: { id: 1002 } });
      }
    }
  });
</script>
```

## 五、嵌套路由（多级路由）

实际项目中（如后台管理系统），页面通常有“布局+子页面”的结构，嵌套路由用于实现多级路由匹配：

### 示例：嵌套路由

```html
<div id="app">
  <router-view></router-view>
</div>

<script>
  // 1. 父组件（布局组件）
  const Layout = {
    template: `
      <div>
        <h2>后台管理系统</h2>
        <!-- 子路由导航 -->
        <router-link to="/layout/home">首页</router-link>
        <router-link to="/layout/user">用户管理</router-link>
        
        <!-- 子路由出口：子组件渲染到这里 -->
        <router-view></router-view>
      </div>
    `
  };

  // 2. 子组件
  const LayoutHome = { template: '<div>首页内容</div>' };
  const LayoutUser = { template: '<div>用户管理内容</div>' };

  // 3. 嵌套路由规则（children数组）
  const routes = [
    {
      path: '/layout',
      component: Layout,
      // 子路由规则：路径相对父路由（不加/）
      children: [
        { path: 'home', component: LayoutHome }, // 匹配 /layout/home
        { path: 'user', component: LayoutUser }, // 匹配 /layout/user
        { path: '', redirect: 'home' } // 父路由默认跳子路由
      ]
    },
    { path: '/', redirect: '/layout' } // 根路径跳布局
  ];

  const router = new VueRouter({ routes });
  new Vue({ el: '#app', router });
</script>
```

### 嵌套路由核心规则

- 父路由组件必须包含`<router-view>`，用于渲染子路由组件；
- 子路由的`path`不加`/`，表示相对父路由的路径（加`/`表示绝对路径）；
- 可给父路由设置`redirect`，指定默认显示的子路由。

## 六、导航守卫（路由拦截）

导航守卫用于拦截路由跳转，实现**登录验证、权限控制、页面离开提示**等功能，Vue2路由提供了3类守卫：

### 1. 全局守卫（作用于所有路由）

#### （1）`router.beforeEach`（全局前置守卫）

跳转前触发，核心用于登录验证：

```javascript
// 模拟登录状态
const isLogin = false;

const router = new VueRouter({ routes });

// 全局前置守卫
router.beforeEach((to, from, next) => {
  // to：目标路由信息对象
  // from：当前路由信息对象
  // next：放行函数（必须调用）
  
  // 需求：访问/user需登录，否则跳登录页
  if (to.path === '/user' && !isLogin) {
    next('/login'); // 跳登录页
  } else {
    next(); // 正常放行
  }
});
```

#### （2）`router.afterEach`（全局后置守卫）

跳转完成后触发，无`next`参数，用于页面埋点、标题修改：

```javascript
router.afterEach((to, from) => {
  // 修改页面标题
  document.title = to.meta.title || '默认标题';
});
```

### 2. 路由独享守卫（作用于单个路由）

在路由规则中定义，仅拦截当前路由：

```javascript
const routes = [
  {
    path: '/user',
    component: User,
    // 路由独享守卫
    beforeEnter: (to, from, next) => {
      if (!isLogin) {
        next('/login');
      } else {
        next();
      }
    },
    meta: { title: '用户中心' } // 路由元信息：存储自定义数据
  }
];
```

### 3. 组件内守卫（作用于组件内）

在组件内部定义，拦截组件的路由跳转：

```javascript
const User = {
  template: '<div>用户中心</div>',
  // 进入组件前触发（组件未创建，this为undefined）
  beforeRouteEnter(to, from, next) {
    next(vm => {
      // vm是组件实例，可访问this
      console.log('进入用户组件', vm);
    });
  },
  // 组件路由更新时触发（如参数变化）
  beforeRouteUpdate(to, from, next) {
    console.log('用户组件参数变化', to.params.id);
    next();
  },
  // 离开组件前触发（如返回上一页）
  beforeRouteLeave(to, from, next) {
    const confirm = window.confirm('确定离开吗？');
    if (confirm) {
      next();
    } else {
      next(false); // 阻止跳转
    }
  }
};
```

### 导航守卫核心注意事项

- `next()`：必须调用，否则路由跳转会卡住；
- `next(false)`：阻止跳转；
- `next('/path')`：跳转到指定路径；
- `beforeRouteEnter`中`this`为`undefined`，需通过`next(vm => {})`访问组件实例。

## 七、路由懒加载（性能优化）

默认情况下，所有路由组件会在首屏加载时一起打包，导致首屏加载慢。路由懒加载可实现“按需加载”（访问路由时才加载组件代码）：

### 示例：路由懒加载（CDN版无需打包，仅演示语法）

```javascript
// 普通方式：同步加载
// const Home = { template: '<div>首页</div>' };

// 懒加载方式：异步加载（Vue2推荐写法）
const Home = () => import('./Home.vue'); // 项目中使用
// CDN版模拟懒加载（仅演示）
const About = () => Promise.resolve({ template: '<div>关于我们</div>' });

const routes = [
  { path: '/home', component: Home },
  { path: '/about', component: About }
];

const router = new VueRouter({ routes });
```

### 懒加载核心优势

- 减小首屏打包体积，提升首屏加载速度；
- 访问对应路由时才加载组件代码，按需加载资源。

## 八、完整综合示例（带登录验证的路由）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue2路由综合示例</title>
  <script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/vue-router@3.6.5/dist/vue-router.js"></script>
</head>
<body>
  <div id="app">
    <router-view></router-view>
  </div>

  <script>
    // 1. 定义组件
    const Login = {
      template: `
        <div>
          <h2>登录页</h2>
          <button @click="login">模拟登录</button>
        </div>
      `,
      methods: {
        login() {
          // 模拟登录：修改全局登录状态
          window.isLogin = true;
          // 跳转到首页
          this.$router.push('/home');
        }
      }
    };

    const Home = {
      template: `
        <div>
          <h2>首页（需登录）</h2>
          <router-link :to="{ name: 'User', params: { id: 1001 } }">用户1001</router-link>
          <router-view></router-view>
        </div>
      `
    };

    const User = {
      template: `<div>用户ID：{{ $route.params.id }}</div>`,
      beforeRouteLeave(to, from, next) {
        const confirm = window.confirm('确定离开用户页吗？');
        confirm ? next() : next(false);
      }
    };

    // 2. 路由规则
    const routes = [
      { path: '/login', component: Login },
      {
        path: '/home',
        component: Home,
        meta: { requiresAuth: true }, // 标记需要登录
        children: [
          { path: 'user/:id', name: 'User', component: User }
        ]
      },
      { path: '/', redirect: '/home' }
    ];

    // 3. 创建路由实例
    const router = new VueRouter({ mode: 'hash', routes });

    // 4. 全局前置守卫：登录验证
    router.beforeEach((to, from, next) => {
      // 检查目标路由是否需要登录
      if (to.meta.requiresAuth && !window.isLogin) {
        next('/login'); // 未登录跳登录页
      } else {
        next(); // 已登录放行
      }
    });

    // 5. 全局后置守卫：修改标题
    router.afterEach((to) => {
      document.title = to.meta.title || 'Vue2路由示例';
    });

    // 6. 挂载到Vue实例
    new Vue({ el: '#app', router });
  </script>
</body>
</html>
```

## 总结

### 关键点回顾

1. **核心配置**：Vue2路由需用`vue-router 3.x`，核心是创建`VueRouter`实例，定义`routes`规则，挂载到Vue根实例；
2. **路由跳转**：声明式（`router-link`）和编程式（`$router.push/replace/go`），传参分`query`（URL拼接）和`params`（动态路由）；
3. **进阶功能**：嵌套路由用`children`数组实现多级页面，导航守卫用于登录验证/权限控制，路由懒加载优化首屏性能；
4. **核心对象**：`$router`是路由实例（控制跳转），`$route`是当前路由信息（获取参数/路径）。

### 核心原则

- 路由的本质是“路径→组件”的映射，实现SPA页面无刷新跳转；
- 导航守卫的核心是`next()`函数，必须调用才能完成路由跳转；
- 动态路由参数（`params`）需配合命名路由使用，`query`参数更灵活（无需修改路由规则）。
