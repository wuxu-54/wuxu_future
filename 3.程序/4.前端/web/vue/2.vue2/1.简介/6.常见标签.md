# vue常见标签

Vue 提供了一批无渲染的内置特殊标签（也叫「内置组件」），用于处理特定的组件逻辑、DOM 渲染或性能优化，以下是所有核心特殊标签的详细解析，确保内容准确且覆盖完整：

---

## 1. `<template>` - 模板容器

### 核心作用

作为**不可见的包裹容器**，仅用于分组元素/承载指令逻辑，渲染时不会生成任何 DOM 节点。

### 关键用法

等同于vue对象中的`template`属性

#### 场景 1：分组元素（避免多余 DOM 嵌套）

```vue
<template>
  <!-- 用 template 包裹多个元素，最终仅渲染 h1 + p，无 template 节点 -->
  <template>
    <h1>标题</h1>
    <p>内容</p>
  </template>
```

#### 场景 2：配合条件/列表指令（无额外容器）

- 配合 `v-if`：批量控制元素显示，无需外层 div

  ```vue
  <template v-if="showContent">
    <h2>子标题</h2>
    <ul>
      <li>列表项1</li>
      <li>列表项2</li>
    </ul>
  </template>
  ```

- 配合 `v-for`：循环多个元素，无外层容器

  ```vue
  <template v-for="item in list" :key="item.id">
    <div>{{ item.title }}</div>
    <p>{{ item.desc }}</p>
  </template>
  ```

### 注意事项

- `<template>` 仅支持 `v-if`/`v-for`/`v-slot` 指令，不支持 `v-show`（因无 DOM 节点，无法切换 display）；
- 单独使用 `<template>`（无指令）会被 Vue 忽略，不会渲染任何内容。

## 2. `<slot>` - 插槽容器

### 核心作用

定义组件的「内容分发插槽」，允许父组件向子组件注入自定义内容，是 Vue 组件内容复用的核心标签。

### 基础语法

```vue
<!-- 子组件 MyComponent.vue -->
<template>
  <div class="container">
    <!-- 匿名插槽：默认插槽 -->
    <slot></slot>
    <!-- 具名插槽：指定名称 -->
    <slot name="footer"></slot>
    <!-- 作用域插槽：向父组件传递数据 -->
    <slot name="item" :data="listItem"></slot>
  </div>
</template>
```

### 详细用法

#### （1）匿名插槽（默认插槽）

父组件无需指定名称，内容默认注入到子组件的 `<slot>` 位置：

```vue
<!-- 父组件使用 -->
<MyComponent>
  <p>这是注入到默认插槽的内容</p>
</MyComponent>
```

#### （2）具名插槽

父组件通过 `v-slot:名称`（简写 `#名称`）指定注入的插槽：

```vue
<!-- 父组件使用 -->
<MyComponent>
  <template #footer>
    <button>底部按钮</button>
  </template>
</MyComponent>
```

#### （3）作用域插槽

子组件通过 `slot` 的属性向父组件传值，父组件接收后自定义渲染逻辑：

```vue
<!-- 子组件 -->
<template>
  <div>
    <slot name="item" :id="123" :name="'张三'"></slot>
  </div>
</template>

<!-- 父组件使用 -->
<MyComponent>
  <template #item="slotProps">
    <!-- slotProps 接收子组件传递的所有数据 -->
    <p>ID：{{ slotProps.id }}，名称：{{ slotProps.name }}</p>
  </template>
</MyComponent>
```

#### （4）默认内容

插槽未注入内容时，显示 `<slot>` 内部的默认内容：

```vue
<!-- 子组件 -->
<slot>
  <p>这是默认内容（父组件未传内容时显示）</p>
</slot>
```

### 注意事项

- `v-slot` 只能用在 `<template>` 上（除非是默认插槽的缩写形式）；
- Vue 2.6+ 统一使用 `v-slot` 替代旧的 `slot`/`slot-scope` 属性（旧属性已废弃）；
- 作用域插槽的参数可解构：`#item="{ id, name }"`，简化代码。

## 3. `<component>` - 动态组件

### 核心作用

根据绑定的 `is` 属性，动态渲染不同的组件，实现「组件切换」功能。

### 基础语法

```vue
<template>
  <!-- is 属性绑定组件名（字符串） -->
  <component :is="currentComponent"></component>
  
  <button @click="currentComponent = 'ComponentA'">显示A</button>
  <button @click="currentComponent = 'ComponentB'">显示B</button>
</template>

<script>
import ComponentA from './ComponentA.vue'
import ComponentB from './ComponentB.vue'

export default {
  components: { ComponentA, ComponentB },
  data() {
    return {
      currentComponent: 'ComponentA' // 初始渲染 ComponentA
    }
  }
}
</script>
```

### 高级用法

#### （1）缓存动态组件（配合 `<keep-alive>`）

避免组件切换时销毁/重建，保留组件状态：

```vue
<keep-alive>
  <component :is="currentComponent"></component>
</keep-alive>
```

#### （2）直接绑定组件对象（而非字符串）

```vue
<script>
import ComponentA from './ComponentA.vue'

export default {
  data() {
    return {
      currentComponent: ComponentA // 直接绑定组件对象
    }
  }
}
</script>
```

### 注意事项

- `is` 属性的值可以是：已注册的组件名（字符串）、组件对象、HTML 标签名（如 `'div'`，渲染原生元素）；
- 动态组件切换时，未缓存的组件会触发 `beforeDestroy`/`destroyed` 生命周期，缓存的组件触发 `deactivated`/`activated`。

---

## 4. `<keep-alive>` - 组件缓存

### 核心作用

缓存包裹的组件实例，避免重复创建/销毁，保留组件的状态（如表单输入内容、滚动位置），是**无渲染标签**（仅包裹组件，不生成 DOM）。

### 基础语法

```vue
<keep-alive>
  <!-- 缓存动态组件 -->
  <component :is="currentComponent"></component>
</keep-alive>
```

### 核心属性（精准控制缓存范围）

| 属性 | 类型 | 作用 | 示例 |
|------|------|------|------|
| `include` | 字符串/正则/数组 | 仅缓存匹配的组件（匹配组件的 `name` 选项） | `include="ComponentA,ComponentB"` 或 `:include="['ComponentA']"` |
| `exclude` | 字符串/正则/数组 | 不缓存匹配的组件 | `exclude="/^Comp/"`（正则匹配以 Comp 开头的组件） |
| `max` | 数字 | 缓存组件的最大数量（超出则按 LRU 策略移除最久未使用的） | `max="5"` |

### 示例（带筛选的缓存）

```vue
<keep-alive include="ComponentA,ComponentB" max="3">
  <component :is="currentComponent"></component>
</keep-alive>
```

### 生命周期钩子（缓存组件特有）

- `activated`：缓存组件**激活**时触发（首次渲染也会触发）；
- `deactivated`：缓存组件**失活**时触发（切换走但未销毁）。

### 注意事项

- `<keep-alive>` 仅作用于「有状态的组件」或「动态组件」，不作用于函数式组件；
- 不会缓存 `<keep-alive>` 内部的非组件元素（如 div）；
- Vue 3 中，`<keep-alive>` 只能包裹一个根组件（Vue 2 可包裹多个），多个组件需用 `<component>` 或 `<template>` 包裹。

## 5. `<transition>` - 过渡动画

### 核心作用

为单个元素/组件的「插入/更新/移除」添加过渡动画，基于 CSS 过渡/动画或 JavaScript 钩子实现。

### 基础语法

```vue
<template>
  <button @click="show = !show">切换</button>
  
  <!-- 包裹需要动画的元素 -->
  <transition name="fade">
    <div v-if="show" class="box">过渡动画示例</div>
  </transition>
</template>

<style>
/* 定义过渡类名（name 为 fade，类名前缀为 fade-） */
/* 进入/离开的起始状态 */
.fade-enter-from, .fade-leave-to {
  opacity: 0;
  transform: translateX(20px);
}
/* 进入/离开的过程 */
.fade-enter-active, .fade-leave-active {
  transition: all 0.5s ease;
}
/* 进入完成/离开起始状态 */
.fade-enter-to, .fade-leave-from {
  opacity: 1;
  transform: translateX(0);
}
</style>

<script>
export default {
  data() {
    return { show: false }
  }
}
</script>
```

### 核心属性

| 属性 | 作用 | 示例 |
|------|------|------|
| `name` | 过渡类名前缀（默认 `v-`） | `name="fade"` → 类名 `fade-enter-from` |
| `appear` | 初始渲染时触发过渡 | `appear` → 页面加载时就执行动画 |
| `mode` | 控制进入/离开的顺序（仅单个元素） | `mode="out-in"`（先离开再进入）/ `mode="in-out"`（先进入再离开） |
| `duration` | 过渡时长（毫秒） | `:duration="500"` 或 `:duration="{ enter: 300, leave: 500 }"` |

### 高级用法（JavaScript 钩子）

```vue
<transition
  @before-enter="beforeEnter"
  @enter="enter"
  @after-enter="afterEnter"
  @leave="leave"
>
  <div v-if="show">JS 动画</div>
</transition>

<script>
export default {
  methods: {
    beforeEnter(el) {
      // 进入前：初始化样式
      el.style.opacity = 0;
    },
    enter(el, done) {
      // 进入中：执行动画，done 是回调（必须调用）
      setTimeout(() => {
        el.style.opacity = 1;
        done(); // 通知 Vue 动画完成
      }, 300);
    },
    afterEnter(el) {
      // 进入完成
    },
    leave(el, done) {
      // 离开中
      el.style.opacity = 0;
      done();
    }
  }
}
</script>
```

### 注意事项

- `<transition>` 仅包裹**单个元素/组件**，多个元素需用 `<transition-group>`；
- 配合 `v-if`/`v-show`/`动态组件`/`路由` 使用，触发过渡；
- CSS 过渡类名在 Vue 3 中调整：`v-enter` → `v-enter-from`，`v-leave` → `v-leave-from`（更语义化）。

## 6. `<transition-group>` - 列表过渡

### 核心作用

为**列表元素**的「插入/删除/排序」添加过渡动画，是 `<transition>` 的列表版本，会生成真实 DOM 节点（默认 `<span>`，可通过 `tag` 指定）。

### 基础语法

```vue
<template>
  <button @click="addItem">添加项</button>
  
  <transition-group name="list" tag="ul">
    <li v-for="item in list" :key="item.id">{{ item.text }}</li>
  </transition-group>
</template>

<style>
/* 列表项进入/离开动画 */
.list-enter-from, .list-leave-to {
  opacity: 0;
  transform: translateY(10px);
}
.list-enter-active, .list-leave-active {
  transition: all 0.3s ease;
}
/* 列表排序动画（需配合 key） */
.list-move {
  transition: transform 0.3s ease;
}
</style>

<script>
export default {
  data() {
    return {
      list: [{ id: 1, text: '项1' }, { id: 2, text: '项2' }],
      nextId: 3
    }
  },
  methods: {
    addItem() {
      this.list.push({ id: this.nextId++, text: `项${this.nextId - 1}` });
    }
  }
}
</script>
```

### 核心属性

- 继承 `<transition>` 的所有属性；
- `tag`：指定渲染的根标签（默认 `<span>`），如 `tag="ul"`；
- `move-class`：自定义排序动画的类名（默认 `${name}-move`）。

### 注意事项

- 必须为列表项添加唯一 `key`（否则排序动画失效）；
- `list-leave-active` 需设置 `position: absolute` 或 `display: inline-block`，避免布局抖动；
- 排序动画依赖 `transform` 属性，需定义 `move` 类。

## 7. `<Teleport>`（Vue 3 特有）- 传送门

### 核心作用

将组件的 DOM 结构「传送」到页面的指定位置（如 `<body>`、自定义容器），保持组件的逻辑归属不变，仅改变 DOM 渲染位置。

### 基础语法

```vue
<template>
  <button @click="showModal = true">打开弹窗</button>
  
  <!-- 传送至 body 标签下 -->
  <Teleport to="body">
    <div v-if="showModal" class="modal">
      <p>弹窗内容</p>
      <button @click="showModal = false">关闭</button>
    </div>
  </Teleport>
</template>

<script>
export default {
  data() {
    return { showModal: false }
  }
}
</script>
```

### 核心属性

| 属性 | 作用 | 示例 |
|------|------|------|
| `to` | 目标容器（CSS 选择器/元素对象） | `to="body"` / `to="#modal-container"` |
| `disabled` | 是否禁用传送（DOM 留在原位置） | `:disabled="!isTeleport"` |

### 注意事项

- `to` 指向的目标元素必须**提前存在**于 DOM 中（不能是 Vue 渲染的元素）；
- 传送后的组件仍能访问父组件的 props、方法、响应式数据（逻辑归属不变）；
- 配合 `<transition>` 实现弹窗动画：

  ```vue
  <Teleport to="body">
    <transition name="modal">
      <div v-if="showModal" class="modal"></div>
    </transition>
  </Teleport>
  ```

## 8. `<Suspense>`（Vue 3 特有，实验性→稳定）- 加载占位

### 核心作用

等待异步组件加载完成，并显示「加载中」的占位内容，解决异步组件加载时的空白问题。

### 基础语法

```vue
<template>
  <Suspense>
    <!-- 异步组件（需要等待的内容） -->
    <template #default>
      <AsyncComponent />
    </template>
    
    <!-- 加载中占位内容 -->
    <template #fallback>
      <div>加载中...</div>
    </template>
  </Suspense>
</template>

<script setup>
// 定义异步组件
const AsyncComponent = defineAsyncComponent(() => import('./AsyncComponent.vue'));
</script>
```

### 核心特性

- 支持等待 `async/await` 语法的组件（如 `<script setup>` 中使用 `await`）；
- `fallback` 插槽是必填的（加载过程中显示）；
- 可配合路由懒加载使用，实现页面级加载占位。

### 注意事项

- `<Suspense>` 目前不支持配合 `v-if`/`v-for` 等指令在同一层级使用；
- 异步组件加载失败时，需自行处理错误（如配合 `errorCaptured` 钩子）。

---

### 总结

1. **核心特殊标签分类**：
   - 容器类：`<template>`（分组/指令载体）；
   - 组件控制类：`<component>`（动态组件）、`<keep-alive>`（组件缓存）；
   - 内容分发类：`<slot>`（插槽）；
   - 动画类：`<transition>`（单元素过渡）、`<transition-group>`（列表过渡）；
   - Vue 3 特有：`<Teleport>`（DOM 传送）、`<Suspense>`（异步加载占位）。
2. **关键注意事项**：
   - `<keep-alive>` 仅缓存组件，需配合动态组件使用，Vue 3 仅包裹单个根组件；
   - `<transition-group>` 必须加 `key`，且会生成真实 DOM 节点；
   - Vue 3 的 `<Teleport>`/`<Suspense>` 是新增能力，解决 DOM 位置和异步加载问题；
   - `<slot>` 在 Vue 2.6+ 统一使用 `v-slot` 语法，替代旧的 `slot` 属性。
3. **使用原则**：所有特殊标签均为「无渲染/辅助性」，仅处理逻辑/动画/缓存，不影响最终业务 DOM 结构（除 `<transition-group>` 指定 `tag` 外）。
