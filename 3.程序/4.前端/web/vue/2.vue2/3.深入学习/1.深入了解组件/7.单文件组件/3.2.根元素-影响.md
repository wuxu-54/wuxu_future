# 组件根元素隔离带来的**全部影响（超全·超细·实战版）**

完全按照你要的深度，把**根元素这一层 DOM 隔断**会破坏、影响、失效的所有场景全部列出来，覆盖 flex、布局、继承、样式、事件、滚动、选择器等 99% 实战坑点。

---

## 一、对 Flex 布局的全部影响（最核心）

1. **直接隔断 flex 父子关系**
   - flex 只作用于**直接子元素**
   - 根元素插入一层 → 内部元素变成孙子 → `flex:1` 失效
2. **纵向 flex 必须给根元素写 flex:1，否则高度为 0**
3. **横向 flex 子组件不写 flex 相关值，会被默认压缩/撑开**
4. **align-items、justify-content 只对根元素生效，不对内部生效**
5. **子组件内部写 flex:1 永远无效，因为父级不是 flex 容器**
6. **滚动布局失效**
   - 父：flex:1 overflow:hidden
   - 子组件根元素：必须写 flex:1 min-height:0，否则无法滚动
7. **多子组件均分布局失效**
   - 必须给每个子组件根元素设置 flex:1

---

## 二、对 CSS 样式继承的影响（大面积失效）

8. **非继承样式完全穿不透根元素**
   - 如：width、height、border、padding、background、overflow
9. **只有 CSS 继承属性能穿透**
   - 如：color、font-size、line-height、text-align、visibility
10. **父级设置的 overflow 无法作用到子组件内部**
    - 必须给根元素设置 overflow
11. **父级 position 布局无法控制子组件内部**
    - 必须给根元素写 position
12. **父级设置的 gap 不生效**
    - 因为 gap 作用于 flex 直接子元素（根元素），不作用于内部
13. **父级 :hover 无法直接控制子组件内部样式**
    - 除非子组件根元素也写 :hover 或使用深层选择器
14. **父级设置的 white-space、text-overflow 不生效**
    - 必须给根元素/内部元素重写
15. **z-index 形成独立层叠上下文**
    - 子组件内部 z-index 只在根元素内部比较，无法突破根元素层级
16. **transform、filter 会创建独立层叠上下文**
    - 根元素设置后，内部 fixed 定位会失效

---

## 三、对 CSS 选择器的影响

17. **父组件写子组件内部元素样式 → 完全不生效**

    ```css
    /* 父组件 */
    .parent .child-inner {
      /* 无效！被根元素隔离，选择器穿不透 */
    }
    ```

18. **必须使用深度选择器才能穿透**
    - :deep() / ::v-deep / /deep/
19. **scoped 样式完全被根元素隔离**
    - vue scoped 只作用于当前组件 DOM
    - 子组件内部 DOM 不在父组件作用域内
20. **类名、属性选择器无法跨组件根元素匹配**
21. **相邻兄弟选择器 +、~ 无法跨根元素使用**
    - 只对根元素有效，不对内部元素有效

---

## 四、对高度/宽度/尺寸计算的影响

22. **子组件高度无法继承父级高度**
    - 父 height:100% → 根元素不写 → 子组件内部 height:100% 失效
23. **子组件宽度无法继承父级宽度**
    - 除非根元素是 block / flex
24. **min-height、max-height 不穿透根元素**
    - 必须写在根元素上
25. **box-sizing 不继承？不，会继承，但大部分布局属性不继承**
26. **aspect-ratio 无法跨根元素生效**
27. **calc(100% - xx) 必须写在根元素才有效**

---

## 五、对定位（position）的影响

28. **子组件内部 absolute 无法相对于父组件定位**
    - 只能相对于**子组件根元素**定位
    - 根元素没写 relative → 相对于页面/最近非 static 定位
29. **fixed 定位在根元素设置 transform 后失效**
30. **sticky 定位必须写在根元素或直接子元素才有效**
31. **top/left/right/bottom 无法穿透根元素**

---

## 六、对滚动布局的影响（超级多坑）

32. **父级 overflow:auto 无法让子组件内容滚动**
    - 必须给根元素设置 overflow + height/flex:1
33. **滚动穿透问题由根元素隔离导致**
34. **scroll-behavior 不穿透根元素**
35. **-webkit-overflow-scrolling 必须写在根元素**
36. **滚动高度 offsetHeight、scrollHeight 获取错误**
    - 因为根元素是实际滚动层

---

## 七、对事件的影响

37. **事件冒泡不受影响（可以穿透）**
38. **事件捕获不受影响**
39. **但父级设置的 pointer-events 不穿透根元素**
40. **父级阻止滚动 touchmove 不生效**
    - 必须给根元素加 @touchmove.prevent
41. **click outside 外部点击判断失效**
    - 因为根元素是独立 DOM 节点，会被判定为外部

---

## 八、对 JavaScript 获取 DOM 的影响

42. **父组件 document.querySelector 找不到子组件内部元素**
    - 跨组件 DOM 隔离
43. **ref 无法跨根元素获取内部 DOM**
    - 父组件只能获取到**根元素的 ref**
44. **getBoundingClientRect() 获取的是根元素尺寸，不是内部**
45. **offsetParent、closest() 无法跨根元素向上查找**

---

## 九、对动画/过渡的影响

46. **父级 transition 不穿透根元素**
47. **父级 animation 不作用于子组件内部**
48. **transform-origin 必须写在对应元素上，无法继承**
49. **will-change 不穿透根元素**

---

## 十、对表单/控件/原生标签的影响

50. **label for 无法跨根元素关联 input**
51. **fieldset disabled 不穿透子组件根元素**
52. **autofocus、tabindex 继承但行为异常**
53. **表单元素样式无法从父级继承**

---

## 十一、对 UI 框架组件的影响（如 uview、vant、uni-app 组件）

54. **UI 组件内部布局被根元素隔断**
55. **自定义样式必须 deep 才能生效**
56. **flex 配合 UI 组件必须给 UI 组件根元素加 flex:1**
57. **弹窗、抽屉、absoulte 定位经常因为根元素层级错位**
58. **滚动加载、下拉刷新因为根元素隔断失效**

---

## 十二、一句话终极总结（最精髓）

### **组件根元素 = 一道 DOM 墙

所有布局、尺寸、定位、样式、选择器、overflow、flex、滚动 都穿不过去
只有 事件、文字继承样式 能穿过去**

---

## 最实用结论（你开发必背）

1. **flex 布局 → 必须给子组件根元素写 flex:1**
2. **高度继承 → 必须给根元素写 height:100%**
3. **滚动 → 必须给根元素写 overflow + flex:1 + min-height:0**
4. **父样式改子组件内部 → 必须用 :deep()**
5. **定位 → 子组件内部绝对定位 = 相对于根元素**
6. **获取高度 → 获取的是根元素高度**
