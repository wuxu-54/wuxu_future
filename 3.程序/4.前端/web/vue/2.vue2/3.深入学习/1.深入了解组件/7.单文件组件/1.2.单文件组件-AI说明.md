# 单文件组件`.vue`

`.vue` 文件是 Vue 特有的**单文件组件（Single-File Component，简称 SFC）** 格式，核心作用是将组件的「模板（HTML）」「逻辑（JavaScript）」「样式（CSS）」封装在单个文件中，实现组件的模块化、可维护性和复用性。以下从基础结构到高级特性，逐一拆解所有细节：

---

## 一、核心定义与优势

### 1. 定义

`.vue` 文件是一个符合 Vue 规范的文本文件，通过特定的标签（`<template>`/`<script>`/`<style>`）划分组件的不同部分，最终通过 Vue 编译器（vue-loader/vite）编译为浏览器可识别的 JavaScript、HTML 和 CSS。

### 2. 核心优势

- **模块化封装**：一个文件对应一个组件，逻辑、视图、样式高度内聚；
- **语法高亮**：主流编辑器（VS Code + Vetur/Volar）支持完整的语法高亮；
- **作用域样式**：内置 CSS 作用域能力，避免样式污染；
- **编译优化**：Vue 编译器可对模板做静态分析和优化，提升运行时性能；
- **生态兼容**：支持 TypeScript、CSS 预处理器（Sass/Less）、PostCSS 等。

---

## 二、基础结构（必含核心标签）

一个完整的 `.vue` 文件由 3 个核心标签组成（部分标签可省略），结构如下：

```vue
<!-- 1. 模板部分：组件的视图结构（HTML） -->
<template>
  <div class="component-container">
    {{ message }}
    <button @click="handleClick">点击</button>
  </div>
</template>

<!-- 2. 逻辑部分：组件的行为（JavaScript/TypeScript） -->
<script>
export default {
  // 组件选项
  name: 'MyComponent',
  data() {
    return {
      message: 'Hello Vue SFC'
    }
  },
  methods: {
    handleClick() {
      console.log('点击了按钮');
    }
  }
}
</script>

<!-- 3. 样式部分：组件的样式（CSS） -->
<style scoped>
.component-container {
  padding: 20px;
  background: #f5f5f5;
}
button {
  padding: 8px 16px;
  border: none;
  background: #42b983;
  color: white;
}
</style>
```

### 各部分核心规则

| 标签         | 必要性 | 核心规则                                                                 |
|--------------|--------|--------------------------------------------------------------------------|
| `<template>` | 可选   | ① 只能有**一个根节点**（Vue 3 支持多根节点）；② 支持所有 Vue 指令/插值；③ 无渲染开销 |
| `<script>`   | 可选   | ① 必须导出一个 Vue 组件选项对象（或 `setup` 函数）；② 支持 ES6+ 语法；③ 可写多个（需加 `lang`/`setup` 区分） |
| `<style>`    | 可选   | ① 可写多个（不同作用域/预处理器）；② 支持 `scoped`/`module` 等属性；③ 支持预处理器 |

---

## 三、各部分深度解析

### 1. `<template>` 模板部分

#### 核心特性

- **根节点规则**：
  - Vue 2：必须有且仅有一个根节点（如 `<div>`/`<template>`）；
  - Vue 3：支持多根节点（无需外层包裹）：

    ```vue
    <template>
      <h1>标题</h1>
      <p>内容</p>
      <button>按钮</button>
    </template>
    ```

- **语法支持**：
  - 所有 Vue 指令（`v-if`/`v-for`/`v-bind`/`v-model` 等）；
  - 插值表达式（`{{ }}`）、指令缩写（`:`/`@`）；
  - 插槽（`<slot>`）、动态组件（`<component>`）等特殊标签；
- **模板编译优化**：
  Vue 编译器会对模板做静态分析，将静态内容（如 `<h1>固定标题</h1>`）提取为常量，动态内容做响应式绑定，提升渲染性能。

#### 高级用法：模板导入

可通过 `import` 导入外部模板片段（需配合 `vue-loader`/Vite）：

```vue
<!-- 导入外部模板 -->
<template src="./template-part.html"></template>

<!-- 内部模板（优先级高于 src） -->
<template>
  <div>内部模板会覆盖 src 导入的模板</div>
</template>
```

### 2. `<script>` 逻辑部分

#### （1）Vue 2 选项式 API 写法（经典）

```vue
<script>
// 导入依赖
import ChildComponent from './ChildComponent.vue'

// 导出组件选项对象
export default {
  // 组件名（必填：用于调试/keep-alive 缓存/递归组件）
  name: 'ParentComponent',
  
  // 组件注册
  components: {
    ChildComponent // 注册子组件
  },
  
  // 接收父组件 props
  props: {
    title: {
      type: String,
      required: true,
      default: '默认标题'
    }
  },
  
  // 响应式数据
  data() {
    return {
      count: 0
    }
  },
  
  // 计算属性
  computed: {
    doubleCount() {
      return this.count * 2
    }
  },
  
  // 方法
  methods: {
    increment() {
      this.count++
    }
  },
  
  // 生命周期钩子
  mounted() {
    console.log('组件挂载完成');
  }
}
</script>
```

#### （2）Vue 3 组合式 API 写法（推荐）

##### 写法 1：`<script setup>`（语法糖，最常用）

```vue
<script setup>
// 1. 导入依赖（自动注册组件）
import ChildComponent from './ChildComponent.vue'
import { ref, computed, onMounted } from 'vue'

// 2. 接收 props（需用 defineProps）
const props = defineProps({
  title: {
    type: String,
    required: true,
    default: '默认标题'
  }
})

// 3. 定义响应式数据
const count = ref(0)

// 4. 计算属性
const doubleCount = computed(() => count.value * 2)

// 5. 方法
const increment = () => {
  count.value++
}

// 6. 生命周期钩子
onMounted(() => {
  console.log('组件挂载完成');
})

// 7. 定义自定义事件（需用 defineEmits）
const emit = defineEmits(['change', 'delete'])
const handleEmit = () => {
  emit('change', count.value)
}
</script>
```

- **核心特性**：
  - 无需导出：代码直接在组件作用域内执行；
  - 自动注册组件：导入的组件无需手动注册；
  - 编译优化：比选项式 API 更高效，减少运行时开销；
  - 内置宏函数：`defineProps`/`defineEmits`/`defineExpose` 等（无需导入）。

##### 写法 2：普通 `<script>` + `setup` 函数（兼容场景）

```vue
<script>
import { ref } from 'vue'

export default {
  setup(props, ctx) {
    const count = ref(0)
    const increment = () => count.value++
    
    // 返回值暴露给模板
    return {
      count,
      increment
    }
  }
}
</script>
```

#### （3）TypeScript 支持

通过 `lang="ts"` 指定脚本语言，结合 `<script setup>` 实现类型校验：

```vue
<script setup lang="ts">
// 定义 props 类型
interface Props {
  title: string
  count?: number
}

// 带类型的 props
const props = defineProps<Props>()

// 带默认值的 props（Vue 3.3+）
const props = withDefaults(defineProps<Props>(), {
  count: 0
})

// 响应式数据类型
const num = ref<number>(0)
</script>
```

#### （4）多 `<script>` 标签

可同时存在多个 `<script>` 标签（如区分普通脚本和 setup 脚本）：

```vue
<!-- 普通脚本：定义组件名/全局逻辑 -->
<script>
export default {
  name: 'MyComponent'
}
</script>

<!-- setup 脚本：核心逻辑 -->
<script setup lang="ts">
// 组合式 API 代码
</script>
```

### 3. `<style>` 样式部分

#### （1）核心属性

| 属性       | 作用                                                                 | 示例                          |
|------------|----------------------------------------------------------------------|-------------------------------|
| `scoped`   | 样式仅作用于当前组件（通过添加唯一属性选择器实现）                   | `<style scoped>`              |
| `module`   | 将样式导出为模块，通过 `$style` 访问（避免样式冲突）                 | `<style module>`              |
| `lang`     | 指定 CSS 预处理器（Sass/Less/Stylus）                               | `<style lang="scss">`         |
| `src`      | 导入外部样式文件                                                     | `<style src="./style.scss">`  |

#### （2）`scoped` 样式（最常用）

- **原理**：Vue 会为组件的 DOM 节点添加唯一属性（如 `data-v-123456`），并为样式添加该属性选择器，实现样式隔离；
- **示例**：

  ```vue
  <template>
    <div class="box">带作用域的样式</div>
  </template>

  <style scoped>
  .box {
    color: red;
  }
  </style>
  ```

  编译后样式：

  ```css
  .box[data-v-123456] {
    color: red;
  }
  ```

- **穿透 scoped 样式**：
  如需修改子组件的样式，可使用 `::v-deep`（Vue 2）/ `:deep()`（Vue 3）：

  ```vue
  <style scoped>
  /* Vue 3 */
  :deep(.child-class) {
    color: blue;
  }
  
  /* Vue 2 */
  ::v-deep .child-class {
    color: blue;
  }
  </style>
  ```

#### （3）`module` 样式（高级隔离）

将样式作为模块导出，通过 `$style` 绑定到元素，避免类名冲突：

```vue
<template>
  <!-- 通过 $style 访问样式类 -->
  <div :class="$style.box">模块样式</div>
</template>

<style module>
.box {
  background: #f5f5f5;
  padding: 20px;
}
</style>
```

#### （4）CSS 预处理器支持

通过 `lang` 指定预处理器（需安装对应依赖，如 `sass`/`less`）：

```vue
<!-- Sass 示例 -->
<style lang="scss" scoped>
$primary-color: #42b983;

.box {
  color: $primary-color;
  .inner {
    padding: 10px;
  }
}
</style>
```

#### （5）多 `<style>` 标签

可拆分样式（如全局样式 + 作用域样式）：

```vue
<!-- 全局样式（无 scoped） -->
<style>
body {
  margin: 0;
  padding: 0;
}
</style>

<!-- 组件作用域样式 -->
<style scoped lang="scss">
// 组件专属样式
</style>
```

## 四、高级特性

### 1. 自定义块（Custom Blocks）

除了核心的 3 个标签，`.vue` 文件还支持自定义块（如 `<docs>`/`<i18n>`），用于扩展组件功能，需配合插件解析：

```vue
<!-- 示例：i18n 国际化块（需 vue-i18n 插件） -->
<i18n>
{
  "en": {
    "hello": "Hello"
  },
  "zh-CN": {
    "hello": "你好"
  }
}
</i18n>

<template>
  <div>{{ $t('hello') }}</div>
</template>
```

### 2. 组件继承/混合

通过 `extends`/`mixins` 复用逻辑（Vue 2 常用，Vue 3 推荐组合式 API）：

```vue
<script>
import mixin from './mixin.js'

export default {
  // 继承另一个组件
  extends: BaseComponent,
  // 混入多个 mixin
  mixins: [mixin]
}
</script>
```

### 3. 异步组件

通过 `defineAsyncComponent` 定义异步组件，实现懒加载：

```vue
<script setup>
import { defineAsyncComponent } from 'vue'

// 异步加载组件
const AsyncComponent = defineAsyncComponent(() => import('./AsyncComponent.vue'))
</script>

<template>
  <AsyncComponent />
</template>
```

## 五、编译与运行原理

### 1. 编译流程

`.vue` 文件无法直接被浏览器识别，需通过构建工具编译：

```mermaid
graph TD
    A[.vue 文件] --> B[Vue 编译器（vue-loader/Vite）]
    B --> C1[解析 <template> → 渲染函数（render）]
    B --> C2[解析 <script> → 组件逻辑（JS/TS）]
    B --> C3[解析 <style> → 样式（CSS，处理 scoped/module）]
    C1 + C2 + C3 --> D[浏览器可执行的 JS/CSS]
```

### 2. 关键编译产物

- `<template>` 编译为 `render` 函数（虚拟 DOM 描述）；
- `<script>` 编译为组件选项对象（或 setup 函数）；
- `<style>` 编译为普通 CSS（添加 scoped 属性选择器/模块导出）。

## 六、最佳实践

### 1. 命名规范

- 组件文件：使用 PascalCase（大驼峰）或 kebab-case（短横线），如 `MyComponent.vue`/`my-component.vue`；
- 组件名：与文件名一致，且避免和 HTML 原生标签冲突（如不命名为 `div.vue`）；
- 样式类名：使用 BEM 规范（如 `component__header--active`），提升可读性。

### 2. 性能优化

- 模板中避免复杂表达式（如 `{{ list.filter(item => item.age > 18).length }}`），抽为计算属性；
- 合理使用 `v-once`/`v-memo` 缓存静态内容；
- 样式尽量使用 `scoped`，避免全局污染；
- 大型组件拆分为多个子组件，提升复用性和维护性。

### 3. 可维护性

- 一个组件只做一件事，代码行数控制在 300 行以内；
- 逻辑部分按「导入 → props → 响应式数据 → 计算属性 → 方法 → 生命周期」排序；
- 样式部分按「布局 → 样式 → 状态 → 子组件样式」排序；
- 复杂逻辑抽离为 composables（Vue 3）或 mixins（Vue 2）。

---

### 总结

1. **核心结构**：`.vue` 文件由 `<template>`（视图）、`<script>`（逻辑）、`<style>`（样式）组成，Vue 3 支持多根节点和 `<script setup>` 语法糖；
2. **关键特性**：
   - `<template>`：Vue 3 支持多根节点，支持所有 Vue 指令/插槽；
   - `<script>`：Vue 3 推荐 `<script setup>`，支持 TypeScript，内置 `defineProps`/`defineEmits` 等宏；
   - `<style>`：`scoped` 实现样式隔离，`lang` 支持预处理器，`:deep()` 穿透子组件样式；
3. **最佳实践**：遵循命名规范，拆分大型组件，模板避免复杂表达式，样式使用 `scoped`，提升可维护性和性能。
