## Vue2 / Vue3 组件根元素导致失效 · 修复对照表

### 一、Flex 布局类

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 子组件内 `flex:1` 不生效、高度为 0 | 根元素隔断 flex 父子关系，flex 只认直接子元素 | 给**组件根元素**加 `flex:1` |
| 纵向 flex 布局撑不满父容器 | 根元素无高度、无 flex:1 | 根元素：`flex:1; min-height:0` |
| 子组件被压缩变形 | 根元素默认 `flex-shrink:1` | 根元素：`flex-shrink:0` |
| 子组件不拉伸占满 | 根元素无 `align-self:stretch` | 根元素：`align-self:stretch` |
| 多子组件无法均分空间 | 根元素未设置 flex 比例 | 每个子组件根元素：`flex:1` |

---

### 二、高度 / 宽度 / 溢出继承

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 子组件 `height:100%` 无效 | 根元素无确定高度 | 根元素：`height:100%` 或 `flex:1` |
| 父 `overflow:hidden` 不生效 | overflow 不跨根元素传递 | 根元素加 `overflow:hidden` |
| 内容溢出父容器、不裁剪 | 根元素无 overflow 限制 | 根元素：`overflow:hidden` |
| 宽度不继承父级 100% | 根元素默认可收缩 | 根元素：`width:100%` |
| `min-height:100%` 无效 | 根元素未传递高度 | 逐层给根元素设置 `min-height:100%` |

---

### 三、滚动布局（最容易踩坑）

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 内容超长不滚动、直接撑破页面 | 滚动层被根元素隔断 | 根元素：`flex:1; min-height:0; overflow:auto` |
| 滚动条不出现 | 根元素无高度限制 | 根元素必须有 `flex:1` 或固定高度 |
| 下拉刷新/上拉加载失效 | 滚动容器不是根元素 | 把滚动属性写在**根元素**上 |
| 滚动穿透/无法阻止滚动 | 根元素独立滚动层 | 根元素加 `@touchmove.prevent` |

---

### 四、CSS 样式 / 选择器

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 父组件样式无法影响子组件内部 | scoped 隔离 + 根元素隔断 | 使用深度选择器 `:deep(.child)` |
| class / style 不传递到内部 | 样式只挂载在根元素 | 内部元素手动继承，或用 CSS 变量 |
| `:hover` 只影响根元素不影响内部 | 选择器无法穿透 | `:deep(.inner):hover` |
| 全局样式不生效 | 组件 scoped 隔离 | 去掉 scoped 或用 `:global()` |
| 优先级混乱、样式覆盖失败 | 根元素增加一层选择器权重 | 提高内部样式权重或使用 deep |

---

### 五、定位（position）

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 子组件内 `absolute` 定位跑偏 | 最近非 static 父级是**根元素** | 根元素加 `position:relative` |
| `fixed` 定位异常 | 根元素有 transform / filter | 移除根元素 transform，或改用其他布局 |
| `sticky` 不吸顶 | 根元素无高度/overflow | 确保根元素不设置 `overflow:hidden` |

---

### 六、Vue3 多根组件专属问题

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 给子组件设置 class/style 报错/无效 | Vue3 多根组件**无统一根元素** | 改为单根组件，或用 `<div>` 包裹 |
| 父 flex 布局作用异常 | 多节点直接作为 flex 子项，行为不可控 | 统一包一层根元素 |
| ref 获取 DOM 异常 | 多个根节点无统一引用 | 改为单根，或用多个 ref |

---

### 七、事件 / DOM 获取

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 父组件 ref 拿到的不是内部元素 | ref 指向**根元素** | 在子组件暴露方法，或用 `defineExpose` |
| 获取 `offsetHeight` 高度不对 | 获取的是根元素高度 | 在子组件内部获取真实 DOM 高度 |
| 外部点击判断（clickOutside）失效 | 根元素被判定为外部节点 | 把子组件根元素加入白名单 |

---

### 八、兼容性 / 渲染

| 失效现象 | 根本原因 | 最快修复方案 |
|---------|---------|-------------|
| 小程序/uni-app flex 布局错乱 | 组件根节点默认样式干扰 | 根节点：`box-sizing:border-box` |
| 文字/内容被挤压 | 根元素无 `min-width:0`/`min-height:0` | 根元素加 `min-width:0; min-height:0` |
| 渲染层级错乱、z-index 无效 | 根元素形成独立层叠上下文 | 调整根元素 z-index 或移除 transform |

---

## 万能一句话口诀（背会解决 99% 问题）

**组件多一层，布局断一层；
flex 看根节点，样式要 deep；
高度要继承，滚动看根元素；
定位要相对，样式穿不透。**
