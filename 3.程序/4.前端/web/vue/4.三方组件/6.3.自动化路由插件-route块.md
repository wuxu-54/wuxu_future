# `<route>` 路由块全属性详解

下面把 **uni-app（@uni-helper/vite-plugin-uni-pages）** 和 **Vue 通用（unplugin-vue-router）** 两套体系里 `<route>` 支持的**所有字段、用途、写法、注意事项**全部整合，一次性讲全、讲透，不遗漏任何常用/冷门属性，同时尽量通俗。

---

## 一、`<route>` 块是什么？

就是写在 `.vue` 文件最顶部的一个**自定义块**，用来给当前页面**配置路由信息**，不用再去外面改路由表。

```vue
<route lang="json5">
{
  // 所有路由配置都写在这里
}
</route>

<template>...</template>
<script setup>...</script>
```

支持三种语法：

- `json`（标准，不能写注释）
- `json5`（推荐，支持注释、尾逗号）
- `yaml`（缩进风格）

---

## 二、通用基础属性（两套插件都支持）

### 1. `path`

自定义路由路径，会覆盖自动生成的路径。

```json5
path: "/user/info"
```

### 2. `name`

给路由起名字，方便跳转时用 name（命名路由） 而不是 path。

```json5
name: "UserInfo"
```

### 3. `meta`

路由元信息，随便放自定义内容：标题、权限、是否缓存、布局等。

```json5
meta: {
  title: "个人中心",
  requiresAuth: true,
  keepAlive: true,
  roles: ["admin", "user"]
}
```

### 4. `alias`

路由别名，多个地址访问同一个页面。

```json5
alias: "/me"
// 或多个
alias: ["/me", "/profile"]
```

### 5. `redirect`

访问此页面时自动重定向到别处。

```json5
redirect: "/login"
redirect: { name: "Login" }
```

### 6. `props`

把路由参数自动传给组件 props，更规范。

```json5
props: true          // 全部传递
props: { id: true }  // 只传 id
```

### 7. `beforeEnter`

进入页面之前的路由守卫，做权限判断。

```json5
beforeEnter: (to, from) => {
  if (!token) return { name: "Login" }
}
```

## 三、uni-app 专属完整属性（重点：type 在这里）

uni-app 的 `<route>` 完全对应 `pages.json` 配置，**功能非常多**。

### 1. `type`（你问的关键属性）

标记页面类型，**只有 uni-app 有**。

```json5
type: "home"
```

可选值：

- `home`：标记为**首页**
- `tabBar`：属于底部 tab 页面
- `page`：普通页面（默认）

### 2. `home`

快捷标记是否为首页，等价 `type: 'home'`

```json5
home: true
```

### 3. `subPackage`

指定页面属于哪个分包。

```json5
subPackage: "user"
```

### 4. `needLogin`

页面是否需要登录才能访问（业务自定义）。

```json5
needLogin: true
```

### 5. `style`（超级常用，完整子字段）

页面样式配置，全部都在这里：

```json5
style: {
  // 导航栏
  navigationBarTitleText: "页面标题",
  navigationBarBackgroundColor: "##fff",
  navigationBarTextStyle: "black|white",
  navigationBarHidden: true | false,
  navigationStyle: "default|custom", // 自定义导航栏

  // 背景
  backgroundColor: "##f5f5f5",
  backgroundTextStyle: "dark|light",

  // 下拉刷新
  enablePullDownRefresh: true,
  onReachBottomDistance: 50,

  // 屏幕方向
  pageOrientation: "portrait|landscape|auto",

  // 各平台单独配置
  "mp-weixin": { /* 微信小程序 */ },
  "mp-baidu": {},
  "mp-qq": {},
  "mp-alipay": {},
  "mp-toutiao": {},
  "app-plus": { /* App 专属 */ }
}
```

### 6. `children`

嵌套路由（极少用，uni-app 路由体系不推荐）

## 四、unplugin-vue-router 专属属性（Vue Web 项目用）

### 1. `sensitive`

路径是否区分大小写

```json5
sensitive: true
```

### 2. `strict`

是否严格匹配末尾斜杠

```json5
strict: true
```

### 3. `children`

嵌套子路由

```json5
children: [
  { path: "info", name: "UserInfo" }
]
```

### 4. `components`

命名视图（一个路由多个 router-view）

```json5
components: {
  default: UserPage,
  sidebar: Sidebar
}
```

### 5. `layout`

指定使用哪个布局（配合布局系统）

```json5
layout: "admin"
layout: false // 不用布局
```

### 6. `middleware`

使用哪些中间件

```json5
middleware: ["auth", "logger"]
```

### 7. `importMode`

当前路由是否懒加载

```json5
importMode: "sync"   // 不懒加载
importMode: "async"  // 懒加载（默认）
```

## 五、一个超全示例（你复制就能用）

### uni-app 完整版

```vue
<route lang="json5" type="page">
{
  "type": "page",
  "home": false,
  "subPackage": "user",
  "needLogin": true,
  "path": "pages/user/info",
  "alias": "/me",
  "meta": {
    "title": "个人中心",
    "keepAlive": true
  },
  "style": {
    "navigationBarTitleText": "我的",
    "enablePullDownRefresh": true,
    "navigationBarHidden": false,
    "mp-weixin": {
      "navigationStyle": "default"
    }
  }
}
</route>
```

### Vue Web（unplugin-vue-router）完整版

```vue
<route lang="json5">
{
  "name": "UserInfo",
  "path": "/user/info",
  "alias": "/me",
  "redirect": "/login",
  "props": true,
  "sensitive": false,
  "strict": false,
  "layout": "admin",
  "middleware": ["auth"],
  "importMode": "async",
  "meta": {
    "title": "个人中心",
    "requiresAuth": true
  },
  "beforeEnter": (to) => {
    if (!token) return { name: "Login" }
  }
}
</route>
```

## 六、最简单记忆总结（一看就懂）

- **uni-app**：`<route>` 主要配置 `type`、`home`、`subPackage`、`style`
- **Vue Web**：`<route>` 主要配置 `name`、`meta`、`layout`、`middleware`
- 两套通用：`path`、`alias`、`meta`、`beforeEnter`、`redirect`、`props`
