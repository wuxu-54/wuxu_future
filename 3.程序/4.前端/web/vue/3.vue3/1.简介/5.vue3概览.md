# vue3 概览

## 一、Vue3 核心概述

### 1.1 版本背景

Vue3 于 2020 年 9 月正式发布（代号 One Piece），是 Vue 框架的重大重构版本，解决了 Vue2 在大型项目中暴露的「逻辑复用困难、TypeScript 支持差、性能瓶颈」等问题。

### 1.2 核心改进（严格准确版）

| 改进点                | 具体说明                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| 性能提升              | 渲染速度提升 55%+，内存占用减少 50%；通过**静态提升、PatchFlag、缓存事件处理函数** 优化虚拟 DOM |
| 组合式 API（Composition API） | 替代 Options API 的碎片化逻辑组织方式，支持逻辑复用和维护                 |
| 完善的 TypeScript 支持 | 源码重写为 TypeScript，提供完整的类型推导，告别 Vue2 需手动声明类型的痛点 |
| 更小的打包体积        | 支持 Tree-Shaking（摇树优化），未使用的 API 不会被打包，体积减少约 40%    |
| 重构核心模块          | 编译器、响应式系统、虚拟 DOM 完全重构，扩展性更强                         |

### 1.3 包结构说明

Vue3 拆分了核心包，避免冗余依赖：

- `vue`：核心运行时 + 编译器（开发环境）
- `@vue/runtime-dom`：运行时 DOM 适配（浏览器环境）
- `@vue/compiler-sfc`：单文件组件（.vue）编译器
- `@vue/reactivity`：独立的响应式模块（可单独使用）

## 二、Vue3 环境搭建（精准步骤）

### 2.1 方式 1：Vite（官方推荐，极速构建）

Vite 是 Vue 团队推出的前端构建工具，针对 Vue3 做了深度优化，冷启动速度远快于 Webpack。

```bash

# 或带 TypeScript：--template vue-ts

# 2. 进入项目目录
cd my-vue3-project

# 3. 安装依赖
npm install

# 4. 启动开发服务器（默认端口 5173）

# 5. 打包生产环境
npm run build
```

## 三、Vue3 基础语法（严格区分 Options/Composition API）

### 3.1 根组件创建（Vue3 核心变更）

Vue3 废弃了 `new Vue()`，改用 `createApp` 创建应用实例，避免全局污染：

```html
<!-- HTML 容器 -->
<div id="app"></div>

<script>
// 1. 引入 createApp（CDN 方式已全局挂载 Vue.createApp）
import { createApp } from 'vue'

// 2. 定义根组件
const App = {
  template: `<h1>Hello Vue3</h1>`,
  // Vue3 中 data 必须是函数（和 Vue2 一致，避免组件复用数据污染）
  data() {
    return {
      msg: 'Vue3 基础示例'
    }
  }
}

// 3. 创建应用实例并挂载
const app = createApp(App)
// 全局配置（如全局指令、组件）需在挂载前执行
app.config.errorHandler = (err) => console.error('全局错误：', err)
// 挂载到 DOM 节点
app.mount('#app')
</script>
```

### 3.2 模板语法（与 Vue2 兼容 + 新增特性）

#### 3.2.1 插值与指令（核心无变更，细节优化）

| 语法                | 说明                                                                 |
|---------------------|----------------------------------------------------------------------|
| `{{ msg }}`         | 文本插值（自动转义 HTML，避免 XSS）                                  |
| `v-html="htmlStr"`  | 渲染原始 HTML（谨慎使用，仅可信内容）                                |
| `v-bind:title="msg"`| 绑定属性（缩写 `:title="msg"`）                                      |
| `v-on:click="handleClick"` | 绑定事件（缩写 `@click="handleClick"`）                     |
| `v-if/v-else-if/v-else` | 条件渲染（与 Vue2 一致）                                      |
| `v-for="item in list"` | 列表渲染（必须加 key，推荐使用唯一值而非索引）               |
| `v-show`            | 显示隐藏（CSS 控制，DOM 不销毁）                                     |
| `v-model`           | 双向绑定（Vue3 重大调整，见下文）                                    |

#### 3.2.2 Vue3 中 v-model 的核心变更（关键准确点）

Vue3 废弃了 `v-model` 的 `.sync` 修饰符，统一了组件双向绑定规则：

- 默认绑定属性从 `value` 改为 `modelValue`
- 默认触发事件从 `input` 改为 `update:modelValue`
- 支持**多个 v-model** 绑定（解决 Vue2 需自定义.sync 的问题）

示例：

```vue
<!-- 父组件 -->
<template>
  <!-- 基础 v-model -->
  <Child v-model="name" />
  <!-- 多个 v-model（自定义属性名） -->
  <Child v-model:age="age" v-model:email="email" />
</template>

<script setup>
import { ref } from 'vue'
import Child from './Child.vue'
const name = ref('张三')
const age = ref(20)
const email = ref('zhangsan@test.com')
</script>

<!-- 子组件 Child.vue -->
<template>
  <!-- 绑定 modelValue，触发 update:modelValue -->
  <input 
    :value="modelValue" 
    @input="$emit('update:modelValue', $event.target.value)"
  />
  <!-- 绑定 age，触发 update:age -->
  <input 
    :value="age" 
    @input="$emit('update:age', $event.target.value)"
  />
</template>

<script setup>
// 声明接收的 props
defineProps(['modelValue', 'age', 'email'])
// 声明可触发的事件（可选，TypeScript 推荐）
defineEmits(['update:modelValue', 'update:age', 'update:email'])
</script>
```

### 3.3 选项式 API（Options API）

Vue3 完全兼容 Vue2 的 Options API，适合新手入门，核心选项如下（无错误版）：

```vue
<template>
  <div>
    <p>计数：{{ count }}</p>
    <p>双倍计数：{{ doubleCount }}</p>
    <button @click="increment">+1</button>
  </div>
</template>

<script>
export default {
  // 1. 组件名（推荐 PascalCase）
  name: 'Counter',

  // 2. 响应式数据（必须是函数）
  data() {
    return {
      count: 0
    }
  },

  // 3. 计算属性（缓存，依赖变化才重新计算）
  computed: {
    doubleCount() {
      return this.count * 2
    }
  },

  // 4. 方法
  methods: {
    increment() {
      this.count++
    }
  },

  // 5. 监听器
  watch: {
    // 监听 count 变化
    count(newVal, oldVal) {
      console.log(`count 从 ${oldVal} 变为 ${newVal}`)
    },
    // 深度监听（如对象）
    'user.info': {
      handler(newVal) {
        console.log('用户信息变化：', newVal)
      },
      deep: true,
      immediate: true // 立即执行一次
    }
  },

  // 6. 生命周期（Vue3 兼容，钩子名不变）
  created() {
    console.log('组件已创建')
  },
  mounted() {
    console.log('组件已挂载')
  }
}
</script>
```

## 四、组合式 API（Composition API）—— Vue3 核心

### 4.1 核心动机

Options API 将代码按「选项」拆分（data/methods/computed），复杂组件中相关逻辑被分散到不同选项，维护困难；Composition API 按「逻辑功能」聚合代码，支持逻辑复用。

### 4.2 setup 函数（入口）

setup 是 Composition API 的核心入口，执行时机和参数如下（关键准确点）：

- **执行时机**：组件创建前（beforeCreate 之后、created 之前），此时组件实例未创建，`this === undefined`（核心易错点）
- **参数**：
  - `props`：组件接收的属性（响应式，不可解构）
  - `context`：上下文对象，包含 `attrs`/`slots`/`emit`/`expose`（非响应式）
- **返回值**：
  - 对象：属性和方法可在模板中直接使用
  - 函数：自定义渲染函数（替代 template）

示例：

```vue
<template>
  <p>名称：{{ name }}</p>
  <button @click="handleClick">点击</button>
</template>

<script>
export default {
  props: {
    title: {
      type: String,
      required: true
    }
  },
  setup(props, context) {
    // 1. 访问 props（响应式）
    console.log(props.title)

    // 2. 访问 context 中的属性
    const { attrs, slots, emit, expose } = context
    // emit：触发父组件事件
    // expose：暴露组件内部属性给父组件（父组件通过 ref 访问）

    // 3. 定义响应式数据（需用 ref/reactive）
    const name = '张三' // 非响应式！
    const count = ref(0) // 响应式基本类型

    // 4. 定义方法
    const handleClick = () => {
      count.value++ // ref 需通过 .value 访问（核心点）
      emit('change', count.value)
    }

    // 5. 暴露给模板
    return {
      name,
      handleClick,
      count
    }
  }
}
</script>
```

### 4.3 `<script setup>` 语法糖（推荐）

`<script setup>` 是 Vue3.2+ 推出的语法糖，简化 setup 写法，无需手动返回变量/方法，是生产环境的首选：

```vue
<template>
  <p>计数：{{ count }}</p>
  <button @click="increment">+1</button>
</template>

<!-- 语法糖核心：无需 export default，无需 return -->
<script setup>
// 1. 引入响应式 API
import { ref } from 'vue'

// 2. 定义响应式数据（自动暴露给模板）
const count = ref(0)

// 3. 定义方法（自动暴露）
const increment = () => {
  count.value++
}

// 4. 声明 props（替代 defineProps）
const props = defineProps({
  title: String
})

// 5. 声明 emit（替代 defineEmits）
const emit = defineEmits(['change'])
</script>
```

### 4.4 响应式 API（全且准）

Vue3 提供了一套完整的响应式 API，替代 Vue2 的 `Object.defineProperty`，基于 `Proxy` 实现：

| API                | 作用                                                                 | 使用场景                     | 注意点                                  |
|--------------------|----------------------------------------------------------------------|------------------------------|-----------------------------------------|
| `ref()`            | 创建基本类型/引用类型的响应式数据（包装为 Ref 对象）                 | 基本类型（string/number/boolean） | JS 中需 `.value` 访问，模板中自动解包    |
| `reactive()`       | 创建对象/数组的响应式代理（深层响应式）                             | 复杂类型（对象/数组）        | 不能解构（解构后失去响应式）            |
| `readonly()`       | 创建只读的响应式代理（深层只读）                                     | 保护数据不被修改             | 原数据变化，只读代理也会更新            |
| `shallowRef()`     | 浅层 ref（仅顶层响应式）                                             | 大型对象，仅需监听引用变化   | 修改内部属性需用 `triggerRef()` 触发更新 |
| `shallowReactive()`| 浅层 reactive（仅顶层属性响应式）                                   | 大型对象，避免深层监听性能问题 | 内部嵌套对象非响应式                    |
| `toRef()`          | 从响应式对象中提取单个属性，保留响应式                               | 解构 props/响应式对象        | 原对象属性不存在也会创建（不会报错）    |
| `toRefs()`         | 将响应式对象转换为普通对象，每个属性都是 ref                         | 解构 reactive 对象           | 原对象属性不存在则忽略                  |
| `isRef()`          | 判断是否为 Ref 对象                                                 | 类型校验                     | -                                       |
| `unref()`          | 快捷访问 ref 的值（`unref(x)` 等价于 `isRef(x) ? x.value : x`）      | 通用工具函数                 | -                                       |
| `isReactive()`     | 判断是否为 reactive 创建的响应式对象                                 | 类型校验                     | -                                       |

示例（关键 API 用法）：

```vue
<script setup>
import { ref, reactive, toRefs, readonly } from 'vue'

// 1. ref 基本类型
const num = ref(10)
num.value = 20 // 必须用 .value 修改

// 2. reactive 对象
const user = reactive({
  name: '张三',
  age: 20
})
user.age = 21 // 直接修改，无需 .value

// 3. toRefs 解构 reactive（保留响应式）
const { name, age } = toRefs(user)
name.value = '李四' // 会同步更新 user.name

// 4. readonly 只读代理
const readOnlyUser = readonly(user)
// readOnlyUser.name = '王五' → 警告：只读属性不能修改

// 5. shallowRef 浅层响应式
const bigObj = shallowRef({
  a: { b: 1 }
})
bigObj.value.a.b = 2 // 不会触发更新
bigObj.value = { a: { b: 2 } } // 触发更新（引用变化）
</script>
```

### 4.5 计算属性与监听器（精准区分）

#### 4.5.1 `computed()`

创建响应式计算属性，支持「只读」和「可写」两种模式：

```vue
<script setup>
import { ref, computed } from 'vue'

const count = ref(0)

// 1. 只读计算属性（常用）
const doubleCount = computed(() => {
  return count.value * 2
})

// 2. 可写计算属性（需定义 get/set）
const fullName = computed({
  get() {
    return `${firstName.value} ${lastName.value}`
  },
  set(newVal) {
    const [first, last] = newVal.split(' ')
    firstName.value = first
    lastName.value = last
  }
})

// 赋值触发 set
fullName.value = '李四 李'
</script>
```

#### 4.5.2 `watch()` vs `watchEffect()`

| 特性                | `watch()`                          | `watchEffect()`                    |
|---------------------|------------------------------------|------------------------------------|
| 依赖指定            | 需显式指定监听的响应式数据         | 自动收集依赖（函数内用到的响应式数据） |
| 执行时机            | 首次不执行（除非设置 immediate）   | 立即执行一次，后续依赖变化再执行   |
| 能获取新旧值        | 可以（newVal, oldVal）             | 不可以                             |
| 适用场景            | 需监听特定数据，关注新旧值         | 需监听多个数据，执行副作用（如请求） |

示例：

```vue
<script setup>
import { ref, watch, watchEffect } from 'vue'

const count = ref(0)
const user = ref({ name: '张三' })

// 1. watch 监听单个 ref
watch(count, (newVal, oldVal) => {
  console.log(`count 从 ${oldVal} 变为 ${newVal}`)
}, {
  immediate: true, // 立即执行
  deep: false // 无需深层（基本类型）
})

// 2. watch 监听对象（需 deep: true）
watch(user, (newVal) => {
  console.log('user 变化：', newVal)
}, { deep: true })

// 3. watchEffect 自动收集依赖
const stop = watchEffect(() => {
  console.log('count 或 user.name 变化：', count.value, user.value.name)
})

// 停止监听（如组件卸载前）
// stop()
</script>
```

### 4.6 生命周期钩子（Composition API 版本）

Vue3 中 Composition API 的生命周期钩子需手动导入，且**无 beforeCreate/created**（这两个钩子的逻辑直接写在 setup 中即可）：

| Options API 钩子    | Composition API 钩子 | 执行时机                     |
|--------------------|----------------------|------------------------------|
| beforeCreate       | -（直接写 setup 中） | 组件实例创建前               |
| created            | -（直接写 setup 中） | 组件实例创建后               |
| beforeMount        | onBeforeMount        | 组件挂载到 DOM 前           |
| mounted            | onMounted            | 组件挂载到 DOM 后           |
| beforeUpdate       | onBeforeUpdate       | 组件更新（DOM 重新渲染）前   |
| updated            | onUpdated            | 组件更新后                   |
| beforeUnmount      | onBeforeUnmount      | 组件卸载前                   |
| unmounted          | onUnmounted          | 组件卸载后                   |
| errorCaptured      | onErrorCaptured      | 捕获子组件错误时             |
| renderTracked      | onRenderTracked      | 虚拟 DOM 追踪到依赖时（开发环境） |
| renderTriggered    | onRenderTriggered    | 虚拟 DOM 重新渲染触发时（开发环境） |

示例：

```vue
<script setup>
import { onMounted, onUnmounted } from 'vue'

// 替代 created
console.log('组件创建')

// 挂载后执行
onMounted(() => {
  console.log('组件挂载完成')
})

// 卸载前执行
onUnmounted(() => {
  console.log('组件即将卸载，清理定时器/事件监听')
})
</script>
```

## 五、组件系统（Vue3 精准细节）

### 5.1 组件定义（`<script setup>` 方式）

```vue
<!-- 子组件：HelloWorld.vue -->
<template>
  <h1>{{ msg }}</h1>
</template>

<script setup>
// 声明 props（支持类型校验）
const props = defineProps({
  msg: {
    type: String,
    required: true,
    default: '默认值'
  }
})

// 声明 emit 事件
const emit = defineEmits(['click', 'change'])

// 暴露组件内部方法（父组件通过 ref 访问）
defineExpose({
  innerMethod() {
    console.log('子组件内部方法')
  }
})
</script>

<!-- 父组件：App.vue -->
<template>
  <HelloWorld 
    ref="helloRef"
    msg="Hello Vue3" 
    @click="handleClick"
  />
</template>

<script setup>
import { ref, onMounted } from 'vue'
import HelloWorld from './HelloWorld.vue'

const helloRef = ref(null)

// 调用子组件暴露的方法
onMounted(() => {
  helloRef.value.innerMethod()
})

const handleClick = () => {
  console.log('子组件触发点击事件')
}
</script>
```

### 5.2 组件通信（全且准的 6 种方式）

| 通信方式       | 适用场景               | 核心 API/语法                     |
|----------------|------------------------|-----------------------------------|
| Props          | 父 → 子                | defineProps                       |
| Emit           | 子 → 父                | defineEmits                       |
| v-model        | 父子双向绑定           | v-model:xxx / update:xxx         |
| provide/inject | 跨层级（父 → 孙/深层） | provide(key, value) / inject(key) |
| attrs/listeners | 透传属性（无需声明） | $attrs / $listeners（Vue3 中 attrs 包含 listeners） |
| Pinia          | 全局状态共享           | defineStore / useStore            |

#### 关键示例：provide/inject（跨层级通信）

```vue
<!-- 顶层组件 -->
<script setup>
import { provide, ref } from 'vue'

// 提供响应式数据
const theme = ref('light')
provide('theme', theme)

// 提供方法
provide('changeTheme', () => {
  theme.value = theme.value === 'light' ? 'dark' : 'light'
})
</script>

<!-- 深层子组件 -->
<script setup>
import { inject } from 'vue'

// 注入数据
const theme = inject('theme', 'light') // 第二个参数是默认值

// 注入方法
const changeTheme = inject('changeTheme')
</script>
```

### 5.3 插槽（Vue3 语法优化）

Vue3 统一了插槽语法，废弃了 `slot` 标签，仅保留 `v-slot`（缩写 `#`）：

```vue
<!-- 父组件 -->
<template>
  <Child>
    <!-- 1. 默认插槽 -->
    <p>默认插槽内容</p>

    <!-- 2. 具名插槽（缩写 #header） -->
    <template v-slot:header>
      <h1>头部插槽</h1>
    </template>

    <!-- 3. 作用域插槽（接收子组件传值） -->
    <template #item="slotProps">
      <li>{{ slotProps.data }}</li>
    </template>
  </Child>
</template>

<!-- 子组件 Child.vue -->
<template>
  <div>
    <!-- 默认插槽 -->
    <slot />

    <!-- 具名插槽 -->
    <slot name="header" />

    <!-- 作用域插槽（传递数据） -->
    <ul>
      <slot name="item" v-for="item in list" :data="item" />
    </ul>
  </div>
</template>

<script setup>
const list = ref(['苹果', '香蕉', '橙子'])
</script>
```

### 5.4 异步组件（Vue3 新写法）

用于懒加载组件，优化首屏加载速度：


## 六、响应式原理（Vue3 核心底层）

### 6.1 Vue2 vs Vue3 响应式对比（精准）

| 特性                | Vue2（Object.defineProperty） | Vue3（Proxy + Reflect）          |
|---------------------|-------------------------------|----------------------------------|
| 监听目标            | 对象属性                      | 整个对象/数组                    |
| 数组支持            | 仅监听 7 个变异方法（push/pop 等），下标/长度修改无响应 | 原生支持数组下标/长度修改        |
| 对象新增属性        | 需手动 $set(obj, key, value)  | 自动监听新增属性                 |
| 对象删除属性        | 需手动 $delete(obj, key)      | 自动监听删除属性（delete obj.key） |
| 深层监听            | 初始化时递归遍历所有属性      | 懒监听（访问时才递归），性能更好 |
| 兼容性              | 支持 IE9+                     | 不支持 IE（Proxy 无 polyfill）   |

### 6.2 Vue3 响应式核心逻辑（简化版实现）

```javascript
// 1. 依赖收集容器（存储 effect 函数）
const targetMap = new WeakMap()

// 2. 依赖收集函数
function track(target, key) {
  const effect = activeEffect
  if (effect) {
    let depsMap = targetMap.get(target)
    if (!depsMap) targetMap.set(target, (depsMap = new Map()))
    let dep = depsMap.get(key)
    if (!dep) depsMap.set(key, (dep = new Set()))
    dep.add(effect)
    effect.deps.push(dep)
  }
}

// 3. 触发更新函数
function trigger(target, key) {
  const depsMap = targetMap.get(target)
  if (!depsMap) return
  const dep = depsMap.get(key)
  if (dep) dep.forEach(effect => effect())
}

// 4. 响应式代理（核心）
function reactive(target) {
  return new Proxy(target, {
    get(target, key, receiver) {
      const res = Reflect.get(target, key, receiver)
      track(target, key) // 收集依赖
      return typeof res === 'object' ? reactive(res) : res
    },
    set(target, key, value, receiver) {
      const oldVal = Reflect.get(target, key, receiver)
      const res = Reflect.set(target, key, value, receiver)
      if (oldVal !== value) trigger(target, key) // 触发更新
      return res
    },
    deleteProperty(target, key) {
      const hadKey = Reflect.has(target, key)
      const res = Reflect.deleteProperty(target, key)
      if (hadKey) trigger(target, key) // 触发更新
      return res
    }
  })
}

// 5. 副作用函数（effect）
let activeEffect
function effect(fn) {
  const effectFn = () => {
    cleanup(effectFn)
    activeEffect = effectFn
    fn()
  }
  effectFn.deps = []
  effectFn()
  return effectFn
}

// 清理依赖
function cleanup(effectFn) {
  effectFn.deps.forEach(dep => dep.delete(effectFn))
  effectFn.deps.length = 0
}

// 测试
const obj = reactive({ count: 0 })
effect(() => {
  console.log('count:', obj.count)
})
obj.count = 1 // 触发更新，打印 count: 1
delete obj.count // 触发更新，打印 count: undefined
```

```javascript
// 定义并导出 store（id 必须唯一）
export const useCounterStore = defineStore('counter', {
  // 状态（替代 Vuex 的 state）
  state: () => ({
    count: 0
  }),

  // 计算属性（替代 Vuex 的 getters）

    }
  }
})
```

## 十、最佳实践与常见错误（精准避坑）

### 10.1 最佳实践

1. 优先使用 `<script setup>` 语法糖，简化代码
2. 逻辑复用使用「组合式函数（Composables）」：将通用逻辑抽离为函数（如 `useFetch`、`useLocalStorage`）
3. 避免直接修改 props，通过 emit 通知父组件修改
4. 响应式数据：基本类型用 `ref`，复杂类型用 `reactive`，解构 `reactive` 用 `toRefs`
5. 组件拆分：按功能拆分小型组件，避免单组件过大
6. 异步操作：在 `onMounted` 中执行（而非 setup 顶层），避免服务端渲染问题
7. 清理副作用：在 `onUnmounted` 中清理定时器、事件监听、`watchEffect` 等

### 10.2 常见错误（精准避坑）

1. `setup` 中使用 `this`：`this` 为 `undefined`，需通过 `props`/`context` 访问
2. `ref` 数据未加 `.value`：JS 中必须用 `.value`，模板中自动解包
3. 解构 `reactive` 对象：解构后失去响应式，需用 `toRefs`
4. `watch` 监听对象未加 `deep: true`：需深层监听才触发更新
5. 全局 API 调用时机错误：`app.use()`/`app.component()` 需在 `app.mount()` 前执行

## 总结

### 核心关键点回顾

1. Vue3 核心改进：性能提升、Composition API、完善的 TS 支持、Tree-Shaking 优化
2. 组合式 API 是 Vue3 核心：`setup` 为入口，`ref`/`reactive` 实现响应式，`watch`/`computed` 处理逻辑，生命周期钩子加 `on` 前缀
3. 状态管理首选 Pinia：替代 Vuex，无 mutations，支持同步/异步 actions，TS 友好
4. 响应式原理：基于 `Proxy + Reflect`，解决 Vue2 无法监听数组下标/对象新增属性的问题
5. 最佳实践：优先用 `<script setup>`，逻辑抽离为组合式函数，及时清理副作用

### 版本兼容性

- Vue3 完全兼容 Options API，可渐进式迁移
- Vue Router 4、Pinia 是 Vue3 配套生态，Vuex 已废弃
- Vue3 不支持 IE 浏览器（Proxy 无 polyfill），需兼容 IE 则使用 Vue2
