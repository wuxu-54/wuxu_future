# vue3 插槽

vue3插槽同vue2原理相同，在使用上与vue2（2.6.0以下版本）有些差异。

## 与vue2（2.6.0以下版本）写法区别

### 具名插槽

* Vue2使用`slot`属性来定义具名插槽，并可以在任意标签中使用。
* Vue3则使用`v-slot`指令来定义具名插槽，并且必须将其写在`template`标签中。

### 作用域插槽

* 在Vue2中，作用域插槽通过`slot-scope`属性来获取子组件的数据。
* 在Vue3中，作用域插槽的使用方式得到了简化，直接使用`v-slot`指令来获取子组件的数据，无需再使用`slot-scope`。

---

## 一、插槽的核心定义

插槽（Slots）是 Vue 组件间通信的重要方式，核心作用是**让父组件可以向子组件的指定位置插入自定义内容**，实现组件的灵活复用。

### Vue3 插槽的核心变更

Vue3 完全废弃了 Vue2 中的 `slot` 标签（作为插槽内容）和 `slot-scope` 属性（作用域插槽），统一使用：

* `<template v-slot:插槽名>` 定义插槽内容（父组件）
* `<slot>` 标签作为插槽出口（子组件）
* 作用域插槽通过 `<slot :属性="值">` 传递数据，父组件通过 `v-slot` 接收

### 核心优势

1. 组件结构解耦：子组件定义布局框架，父组件填充具体内容
2. 内容定制化：同一子组件可根据不同场景渲染不同内容
3. 逻辑复用：子组件处理通用逻辑，父组件专注内容展示

## 二、插槽的基础用法

### 2.1 默认插槽（Default Slot）

最基础的插槽类型，子组件未命名的插槽出口，父组件直接传递内容即可。

#### 子组件（Child.vue）- 定义插槽出口

```vue
<template>
  <div class="card">
    <!-- 插槽出口：无名称，即默认插槽 -->
    <slot />
    <!-- 插槽默认内容：父组件未传递内容时显示 -->
    <slot>这是默认内容</slot>
  </div>
</template>

<style scoped>
.card {
  border: 1px solid #ccc;
  padding: 20px;
  width: 300px;
}
</style>
```

#### 父组件（Parent.vue）- 传递插槽内容

```vue
<template>
  <!-- 用法1：直接传递内容 -->
  <Child>
    <h2>自定义标题</h2>
    <p>这是父组件传递的默认插槽内容</p>
  </Child>

  <!-- 用法2：无内容，显示子组件默认内容 -->
  <Child />
</template>

<script setup>
import Child from './Child.vue'
</script>
```

#### 关键细节：

* 默认插槽的出口 `<slot>` 可以有**默认内容**，父组件未传递内容时生效

* 父组件传递的内容会**替换**子组件的 `<slot>` 标签（包括默认内容）
* 父组件传递的内容可以是任意模板内容（文本、标签、组件）

### 2.2 具名插槽（Named Slots）

当子组件需要多个插槽出口时，使用具名插槽区分不同位置的内容。

#### 子组件（Layout.vue）- 定义多个具名插槽

```vue
<template>
  <div class="layout">
    <!-- 头部插槽：name="header" -->
    <slot name="header" />
    
    <!-- 主体插槽：默认插槽（name 可省略） -->
    <slot />
    
    <!-- 底部插槽：name="footer" -->
    <slot name="footer" />
  </div>
</template>

<style scoped>
.layout {
  display: flex;
  flex-direction: column;
  min-height: 300px;
}
</style>
```

#### 父组件 - 传递具名插槽内容

```vue
<template>
  <Layout>
    <!-- 方式1：完整语法 v-slot:插槽名 -->
    <template v-slot:header>
      <h1>网站头部</h1>
    </template>

    <!-- 方式2：缩写语法 #插槽名（推荐） -->
    <template #footer>
      <footer>网站底部 ©2026</footer>
    </template>

    <!-- 默认插槽：无需 template 包裹（简单内容） -->
    <main>
      <p>网站主体内容</p>
      <p>更多内容...</p>
    </main>
  </Layout>
</template>

<script setup>
import Layout from './Layout.vue'
</script>
```

#### 关键规则：

1. 具名插槽必须通过 `<template v-slot:name>` 或 `<template #name>` 包裹内容
2. 插槽名遵循 **kebab-case（短横线命名）** 规范（如 `header-title` 而非 `headerTitle`）
3. 默认插槽和具名插槽可以混合使用
4. 父组件传递的插槽内容顺序不影响渲染（渲染顺序由子组件 `<slot>` 位置决定）

## 三、作用域插槽（Scoped Slots）

核心场景：**子组件向父组件的插槽内容传递数据**（子 → 父），让父组件可以基于子组件的数据定制插槽内容。

### 3.1 基础用法

#### 子组件（List.vue）- 传递数据到插槽

```vue
<template>
  <ul class="list">
    <!-- 遍历列表，将 item 和 index 传递给插槽 -->
    <li v-for="(item, index) in list" :key="item.id">
      <!-- 插槽出口：通过属性传递数据 -->
      <slot 
        name="item" 
        :data="item"    <!-- 传递单个数据 -->
        :index="index"  <!-- 传递索引 -->
        :is-last="index === list.length - 1" <!-- 传递计算属性 -->
      />
    </li>
  </ul>
</template>

<script setup>
import { reactive } from 'vue'

// 子组件内部数据
const list = reactive([
  { id: 1, name: 'Vue3 插槽', type: '基础' },
  { id: 2, name: '作用域插槽', type: '高级' },
  { id: 3, name: '动态插槽', type: '进阶' }
])
</script>
```

#### 父组件 - 接收并使用插槽数据

```vue
<template>
  <List>
    <!-- 方式1：完整语法接收所有数据 -->
    <template v-slot:item="slotProps">
      <div>
        <span>【{{ slotProps.index + 1 }}】</span>
        <span>{{ slotProps.data.name }}</span>
        <span v-if="slotProps.isLast">（最后一项）</span>
      </div>
    </template>

    <!-- 方式2：解构赋值（推荐，简化代码） -->
    <template #item="{ data, index, isLast }">
      <div>
        <span>【{{ index + 1 }}】</span>
        <span class="type">{{ data.type }}</span>
        <span>{{ data.name }}</span>
        <span v-if="isLast">（最后一项）</span>
      </div>
    </template>

    <!-- 方式3：解构 + 默认值（防止数据不存在） -->
    <template #item="{ data = { name: '默认名称' }, index = 0 }">
      <div>{{ index }} - {{ data.name }}</div>
    </template>
  </List>
</template>

<script setup>
import List from './List.vue'
</script>

<style scoped>
.type {
  color: #42b983;
  margin-right: 8px;
}
</style>
```

### 3.2 默认插槽的作用域插槽

默认插槽也可以传递数据，父组件通过 `v-slot="slotProps"` 接收：

#### 子组件（UserCard.vue）

```vue
<template>
  <div class="card">
    <!-- 默认插槽传递数据 -->
    <slot :user="userInfo" />
  </div>
</template>

<script setup>
import { reactive } from 'vue'
const userInfo = reactive({
  name: '张三',
  age: 25,
  email: 'zhangsan@test.com'
})
</script>
```

#### 父组件

```vue
<template>
  <!-- 方式1：完整语法 -->
  <UserCard v-slot="slotProps">
    <p>姓名：{{ slotProps.user.name }}</p>
    <p>年龄：{{ slotProps.user.age }}</p>
  </UserCard>

  <!-- 方式2：解构赋值 -->
  <UserCard v-slot="{ user }">
    <p>邮箱：{{ user.email }}</p>
  </UserCard>

  <!-- 方式3：缩写 + 解构（推荐） -->
  <UserCard #default="{ user }">
    <div>
      <h3>{{ user.name }}</h3>
      <p>年龄：{{ user.age }}</p>
    </div>
  </UserCard>
</template>
```

### 3.3 作用域插槽的典型场景：自定义列表渲染

作用域插槽最常用的场景是「通用列表组件」，让父组件自定义列表项的渲染方式：

```vue
<!-- 通用列表组件 ListItem.vue -->
<template>
  <div class="list-container">
    <div 
      v-for="(item, index) in items" 
      :key="item.id"
      class="list-item"
    >
      <!-- 作用域插槽：传递当前项和索引 -->
      <slot :item="item" :index="index" />
    </div>
  </div>
</template>

<script setup>
// 接收父组件传递的列表数据
defineProps({
  items: {
    type: Array,
    required: true,
    default: () => []
  }
})
</script>
```

```vue
<!-- 父组件使用 -->
<template>
  <!-- 场景1：渲染文本列表 -->
  <ListItem :items="userList">
    <template #default="{ item }">
      <span>{{ item.name }}</span>
    </template>
  </ListItem>

  <!-- 场景2：渲染带操作按钮的列表 -->
  <ListItem :items="userList">
    <template #default="{ item, index }">
      <div class="flex">
        <span>{{ index }} - {{ item.name }}</span>
        <button @click="deleteItem(item.id)">删除</button>
      </div>
    </template>
  </ListItem>
</template>

<script setup>
import { reactive } from 'vue'
import ListItem from './ListItem.vue'

const userList = reactive([
  { id: 1, name: '张三' },
  { id: 2, name: '李四' },
  { id: 3, name: '王五' }
])

const deleteItem = (id) => {
  const index = userList.findIndex(item => item.id === id)
  if (index > -1) userList.splice(index, 1)
}
</script>
```

## 四、高级用法

### 4.1 动态插槽名

通过变量动态指定插槽名，实现灵活的插槽内容渲染：

```vue
<template>
  <div>
    <!-- 切换要渲染的插槽 -->
    <button @click="currentSlot = 'header'">显示头部</button>
    <button @click="currentSlot = 'content'">显示内容</button>
    
    <DynamicSlot>
      <!-- 动态插槽名：v-slot:[变量名] 或 #[变量名] -->
      <template #[currentSlot]>
        <div v-if="currentSlot === 'header'">动态头部内容</div>
        <div v-else>动态主体内容</div>
      </template>
    </DynamicSlot>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import DynamicSlot from './DynamicSlot.vue'

// 动态插槽名变量
const currentSlot = ref('header')
</script>
```

```vue
<!-- DynamicSlot.vue -->
<template>
  <div class="dynamic-slot">
    <slot name="header" />
    <slot name="content" />
  </div>
</template>
```

### 4.2 插槽的透传（Slot Forwarding）

当组件嵌套层级较深时，可将父组件的插槽透传给子组件的子组件，避免多层传递：

```vue
<!-- 顶层组件 Parent.vue -->
<template>
  <MiddleComponent>
    <!-- 传递给 MiddleComponent 的插槽 -->
    <template #item="{ data }">
      <p>透传的内容：{{ data.name }}</p>
    </template>
  </MiddleComponent>
</template>

<script setup>
import MiddleComponent from './MiddleComponent.vue'
</script>
```

```vue
<!-- 中间组件 MiddleComponent.vue -->
<template>
  <div class="middle">
    <!-- 透传插槽给底层组件 -->
    <BottomComponent>
      <!-- 将当前组件的 #item 插槽透传给 BottomComponent -->
      <template #item="slotProps">
        <slot name="item" v-bind="slotProps" />
      </template>
    </BottomComponent>
  </div>
</template>

<script setup>
import BottomComponent from './BottomComponent.vue'
</script>
```

```vue
<!-- 底层组件 BottomComponent.vue -->
<template>
  <div class="bottom">
    <slot name="item" :data="itemData" />
  </div>
</template>

<script setup>
import { reactive } from 'vue'
const itemData = reactive({ name: '插槽透传测试' })
</script>
```

### 4.3 具名插槽的默认内容

具名插槽也可以设置默认内容，父组件未传递该插槽时生效：

```vue
<!-- 子组件 -->
<template>
  <div>
    <slot name="sidebar">
      <p>默认侧边栏内容</p>
    </slot>
  </div>
</template>

<!-- 父组件：未传递 #sidebar，显示默认内容 -->
<template>
  <Child />
</template>
```

## 五、插槽的编译与性能优化

### 5.1 插槽的编译规则

Vue3 对插槽的编译做了优化，核心规则：

1. 插槽内容的作用域是**父组件**的作用域（而非子组件），即：
   * 插槽内容可以访问父组件的所有数据和方法
   * 插槽内容无法直接访问子组件的数据（除非通过作用域插槽传递）
2. 作用域插槽的编译会生成独立的函数，避免不必要的重新渲染

### 5.2 性能优化建议

1. **避免插槽内容频繁重渲染**：
   * 如果插槽内容包含复杂逻辑，提取为组件或 `computed`
   * 避免在插槽内容中直接定义函数（每次渲染都会创建新函数）：

     ```vue
     <!-- 错误：每次渲染创建新函数 -->
     <template #item="{ item }">
       <button @click="() => handleClick(item.id)">点击</button>
     </template>

     <!-- 正确：使用已定义的方法 -->
     <template #item="{ item }">
       <button @click="() => handleClick(item.id)">点击</button>
     </template>
     <script setup>
     const handleClick = (id) => { /* 逻辑 */ }
     </script>
     ```

2. **静态插槽内容复用**：
   静态的插槽内容（无动态绑定）会被 Vue3 静态提升，无需额外优化；
   动态插槽内容尽量减少响应式依赖。

3. **避免过度使用作用域插槽**：
   作用域插槽会增加组件通信成本，简单场景优先使用 Props + 事件。

## 六、常见错误与避坑指南

### 6.1 常见错误

1. **混淆插槽作用域**：
   ❌ 错误：在插槽内容中直接访问子组件数据
   ✅ 正确：通过作用域插槽接收子组件数据

2. **具名插槽未用 template 包裹**：
   ❌ 错误：

   ```vue
   <Child>
     <div #header>头部内容</div> <!-- 无效 -->
   </Child>
   ```

   ✅ 正确：

   ```vue
   <Child>
     <template #header>
       <div>头部内容</div>
     </template>
   </Child>
   ```

3. **作用域插槽解构未加默认值**：
   ❌ 错误：`#item="{ data }"`（data 不存在时报错）
   ✅ 正确：`#item="{ data = {} }"`

4. **v-slot 缩写使用错误**：
   ❌ 错误：`v-slot#header`（缩写只能用 `#header`）
   ✅ 正确：`#header` 或 `v-slot:header`

### 6.2 避坑要点

1. 插槽名统一使用 kebab-case（如 `header-title`），避免大小写问题
2. 作用域插槽传递的数据尽量扁平化，减少嵌套解构
3. 复杂插槽内容提取为独立组件，提升可维护性
4. 多插槽场景优先使用具名插槽，避免默认插槽嵌套

## 总结

### 核心关键点回顾

1. **插槽分类**：默认插槽（无名称）、具名插槽（name 属性）、作用域插槽（子传父数据）。
2. **核心语法**：
   * 子组件：`<slot name="xxx" :数据="值">` 定义插槽出口
   * 父组件：`<template v-slot:xxx="插槽数据">` 或 `<template #xxx="插槽数据">` 传递内容
3. **作用域规则**：插槽内容作用域属于父组件，需通过作用域插槽接收子组件数据。
4. **高级特性**：动态插槽名（`#[变量]`）、插槽透传（嵌套组件传递插槽）、默认内容（未传内容时显示）。
5. **性能优化**：避免插槽内容中定义新函数、静态内容复用、减少不必要的作用域插槽使用。
