# vue3中的template标签

## 一、`<template>` 核心定义

`<template>` 是 Vue3 中用于编写组件模板的核心标签，作用是**声明组件的 DOM 结构**，它有以下关键特性：

1. **虚拟容器**：`<template>` 本身不会被渲染到最终的 DOM 中，仅作为 Vue 编译器的「语法容器」，最终会被解析为虚拟 DOM 节点。
2. **单一根节点**：Vue3 中 `<template>` 支持**多根节点**（Fragment 特性），无需像 Vue2 那样必须包裹一个根 div（这是 Vue3 重要优化）。
3. **编译时处理**：`<template>` 内的语法（如插值、指令）会被 Vue 编译器编译为渲染函数，运行时执行并生成真实 DOM。

### 基础示例（对比 Vue2/Vue3）

```vue
<!-- Vue2：必须单根节点 -->
<template>
  <div>
    <h1>标题</h1>
    <p>内容</p>
  </div>
</template>

<!-- Vue3：支持多根节点（Fragment） -->
<template>
  <h1>标题</h1>
  <p>内容</p>
</template>
```

## 二、`<template>` 核心语法（精准无错）

### 2.1 文本插值（最基础用法）

使用 `{{ }}`（Mustache 语法）插入响应式数据，Vue 会自动处理数据更新并重新渲染：

```vue
<template>
  <!-- 基础插值 -->
  <p>{{ message }}</p>
  
  <!-- 表达式插值（仅支持单个表达式，不支持语句） -->
  <p>{{ count + 1 }}</p>
  <p>{{ isActive ? '激活' : '未激活' }}</p>
  <p>{{ message.split('').reverse().join('') }}</p>
  
  <!-- 错误示例：不支持 if 语句、循环、赋值 -->
  <!-- <p>{{ if (count > 0) { return '正数' } }}</p> -->
</template>

<script setup>
import { ref } from 'vue'
const message = ref('Hello Vue3')
const count = ref(0)
const isActive = ref(true)
</script>
```

#### 关键细节：

- `{{ }}` 会自动转义 HTML（防止 XSS 攻击），如 `<span>{{ '<h1>危险HTML</h1>' }}</span>` 会渲染为纯文本，而非真实 h1 标签。
- 插值内不能使用异步操作（如 `await`）、全局变量（如 `window`）（除非通过组件数据暴露）。

### 2.2 指令（Directives）

指令是 `<template>` 中最核心的语法，Vue3 保留了 Vue2 大部分指令，仅调整了部分细节：

| 指令                | 作用                                                                 | Vue3 变更点                          |
|---------------------|----------------------------------------------------------------------|--------------------------------------|
| `v-text`            | 文本绑定（等价于 `{{ }}`）                                           | 无变更                               |
| `v-html`            | 渲染原始 HTML（谨慎使用）                                             | 无变更                               |
| `v-bind` (`:`)      | 属性绑定                                                             | 无变更，支持动态属性名 `:[key]="value"` |
| `v-on` (`@`)        | 事件绑定                                                             | 新增 `@click.stop.prevent` 链式修饰符 |
| `v-if`/`v-else-if`/`v-else` | 条件渲染                                                           | 无变更，支持 `<template v-if>`（不渲染容器） |
| `v-for`             | 列表渲染                                                             | 必须加 `key`，且 `key` 不能为 `index`（推荐唯一值） |
| `v-show`            | 基于 CSS 显示/隐藏                                                   | 无变更                               |
| `v-model`           | 双向绑定                                                             | 核心重构（见下文）                   |
| `v-pre`             | 跳过编译（显示原始 `{{ }}`）                                         | 无变更                               |
| `v-cloak`           | 隐藏未编译的模板（解决闪烁）                                         | 无变更，需配合 CSS `[v-cloak] { display: none }` |
| `v-once`            | 只渲染一次（后续数据变化不更新）                                     | 无变更                               |

#### 关键指令示例：

##### （1）v-bind 高级用法

```vue
<template>
  <!-- 动态属性名 -->
  <button :[attrName]="btnValue">动态属性</button>
  
  <!-- 绑定多个属性 -->
  <div v-bind="attrsObj">多属性绑定</div>
  
  <!-- 布尔属性（值为 false 时移除属性） -->
  <button :disabled="isDisabled">禁用按钮</button>
</template>

<script setup>
import { ref, reactive } from 'vue'
const attrName = ref('title')
const btnValue = ref('按钮标题')
const attrsObj = reactive({
  id: 'box',
  class: 'container',
  style: 'color: red'
})
const isDisabled = ref(true)
</script>
```

##### （2）v-for 核心规则（Vue3 严格要求）

```vue
<template>
  <!-- 遍历数组（推荐 key 为唯一 ID） -->
  <ul>
    <li v-for="item in list" :key="item.id">
      {{ item.name }}
    </li>
  </ul>
  
  <!-- 遍历对象 -->
  <div v-for="(value, key, index) in user" :key="key">
    {{ key }}: {{ value }}
  </div>
  
  <!-- 遍历数字 -->
  <span v-for="n in 5" :key="n">{{ n }}</span>
  
  <!-- 配合 template（不渲染容器） -->
  <template v-for="item in list" :key="item.id">
    <p>{{ item.name }}</p>
    <p>{{ item.age }}</p>
  </template>
</template>

<script setup>
import { reactive } from 'vue'
const list = reactive([
  { id: 1, name: '张三' },
  { id: 2, name: '李四' }
])
const user = reactive({ name: '王五', age: 20 })
</script>
```

##### （3）v-model 重构（Vue3 核心变更）

```vue
<template>
  <!-- 基础用法（输入框） -->
  <input v-model="username" />
  
  <!-- 修饰符 -->
  <input v-model.trim="username" /> <!-- 去除首尾空格 -->
  <input v-model.number="age" /> <!-- 转为数字 -->
  <input v-model.lazy="content" /> <!-- 失去焦点才更新 -->
  
  <!-- 组件双向绑定（核心变更） -->
  <CustomInput v-model="msg" />
  <!-- 多个 v-model -->
  <CustomInput v-model:name="name" v-model:age="age" />
</template>

<script setup>
import { ref } from 'vue'
import CustomInput from './CustomInput.vue'
const username = ref('')
const age = ref(0)
const content = ref('')
const msg = ref('')
const name = ref('')
</script>
```

### 2.3 插槽（Slots）

`<template>` 是定义插槽的核心容器，Vue3 废弃了 `slot` 标签，统一使用 `<template v-slot>`（缩写 `#`）：

#### （1）默认插槽

```vue
<!-- 父组件 -->
<template>
  <Child>
    <!-- 默认插槽内容 -->
    <p>这是默认插槽</p>
  </Child>
</template>

<!-- 子组件 Child.vue -->
<template>
  <div>
    <!-- 插槽出口 -->
    <slot />
  </div>
</template>
```

#### （2）具名插槽

```vue
<!-- 父组件 -->
<template>
  <Child>
    <template #header>
      <h1>头部插槽</h1>
    </template>
    <template #footer>
      <footer>底部插槽</footer>
    </template>
  </Child>
</template>

<!-- 子组件 Child.vue -->
<template>
  <div>
    <slot name="header" />
    <main>主体内容</main>
    <slot name="footer" />
  </div>
</template>
```

#### （3）作用域插槽（子传父）

```vue
<!-- 父组件 -->
<template>
  <Child>
    <!-- 接收子组件传递的参数 -->
    <template #item="slotProps">
      <li>{{ slotProps.data }} - {{ slotProps.index }}</li>
    </template>
  </Child>
</template>

<!-- 子组件 Child.vue -->
<template>
  <ul>
    <slot 
      v-for="(item, index) in list" 
      name="item" 
      :data="item" 
      :index="index"
    />
  </ul>
</template>

<script setup>
import { reactive } from 'vue'
const list = reactive(['苹果', '香蕉', '橙子'])
</script>
```

## 三、`<template>` 特殊特性

### 3.1 多根节点（Fragment）

Vue3 允许 `<template>` 有多个根节点，无需包裹外层容器，这是对 Vue2 的重要优化：

```vue
<template>
  <!-- 合法：多根节点 -->
  <header>头部</header>
  <main>主体</main>
  <footer>底部</footer>
</template>
```

#### 注意点：

- 如果需要给多根节点绑定 `class`/`style`，需通过 `$attrs` 透传（或指定根节点接收）：

  ```vue
  <template>
    <header :class="$attrs.class">头部</header>
    <main>主体</main>
  </template>
  ```

### 3.2 `<template>` 作为逻辑容器

`<template>` 可作为 `v-if`/`v-for`/`v-slot` 的逻辑容器，本身不会渲染为真实 DOM 节点：

```vue
<template>
  <!-- v-if 逻辑容器 -->
  <template v-if="isShow">
    <p>段落1</p>
    <p>段落2</p>
  </template>
  
  <!-- v-for 逻辑容器 -->
  <template v-for="item in list" :key="item.id">
    <div>{{ item.name }}</div>
    <div>{{ item.age }}</div>
  </template>
</template>
```

### 3.3 模板引用（Template Refs）

通过 `ref` 获取 `<template>` 内的 DOM 元素或组件实例：

```vue
<template>
  <!-- DOM 元素引用 -->
  <input ref="inputRef" />
  
  <!-- 组件引用 -->
  <Child ref="childRef" />
  
  <!-- v-for 中的引用（需用数组） -->
  <div v-for="item in list" :key="item.id" :ref="setItemRef">
    {{ item.name }}
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import Child from './Child.vue'

// 单个引用
const inputRef = ref(null)
const childRef = ref(null)

// v-for 中的引用
const itemRefs = ref([])
const setItemRef = (el) => {
  if (el) itemRefs.value.push(el)
}

onMounted(() => {
  // 访问 DOM 元素
  inputRef.value.focus()
  // 访问组件实例（需子组件用 defineExpose 暴露）
  console.log(childRef.value.innerMethod())
  // 访问 v-for 中的 DOM 数组
  console.log(itemRefs.value)
})

const list = ref([{ id: 1, name: '张三' }, { id: 2, name: '李四' }])
</script>
```

## 四、`<template>` 高级用法

### 4.1 内置组件结合 `<template>`

#### （1）Teleport 配合 `<template>`

```vue
<template>
  <Teleport to="body">
    <template v-if="showModal">
      <div class="modal">弹窗内容</div>
    </template>
  </Teleport>
</template>
```

#### （2）Suspense 配合 `<template>`

```vue
<template>
  <Suspense>
    <template #default>
      <AsyncComponent />
    </template>
    <template #fallback>
      <div>加载中...</div>
    </template>
  </Suspense>
</template>
```

#### （3）Transition 配合 `<template>`

```vue
<template>
  <TransitionGroup name="list">
    <template v-for="item in list" :key="item.id">
      <div>{{ item.name }}</div>
    </template>
  </TransitionGroup>
</template>
```

### 4.2 动态模板（动态组件）

通过 `<component :is>` 结合 `<template>` 实现动态组件渲染：

```vue
<template>
  <button @click="currentComponent = 'A'">组件A</button>
  <button @click="currentComponent = 'B'">组件B</button>
  
  <component :is="currentComponent">
    <!-- 插槽内容传递给动态组件 -->
    <template #header>
      <h1>动态组件头部</h1>
    </template>
  </component>
</template>

<script setup>
import { ref } from 'vue'
import ComponentA from './ComponentA.vue'
import ComponentB from './ComponentB.vue'

const currentComponent = ref('A')
</script>
```

### 4.3 模板编译优化（Vue3 底层）

Vue3 对 `<template>` 编译做了重大优化，核心是 **PatchFlag（补丁标记）** 和 **静态提升**：

1. **PatchFlag**：编译时标记动态节点（如 `{{ msg }}`、`:class`），运行时仅更新标记的节点，避免全量对比虚拟 DOM。
2. **静态提升**：将静态节点（无动态绑定）提升到渲染函数外部，避免每次渲染重新创建。

示例：

```vue
<template>
  <!-- 静态节点（提升） -->
  <h1>静态标题</h1>
  <!-- 动态节点（标记 PatchFlag） -->
  <p :class="cls">{{ msg }}</p>
</template>
```

编译后（简化）：

```javascript
// 静态节点提升到外部
const _hoisted_1 = /*#__PURE__*/createVNode("h1", null, "静态标题")

function render(_ctx, _cache) {
  return (_openBlock(), _createBlock(_Fragment, null, [
    _hoisted_1, // 复用静态节点
    _createVNode("p", {
      class: _ctx.cls
    }, _ctx.msg, 1 /* CLASS + TEXT */) // PatchFlag 标记
  ]))
}
```

## 五、常见错误与注意事项

### 5.1 常见错误

1. **v-for 和 v-if 同节点使用**：Vue3 中 v-for 优先级高于 v-if，会导致性能问题（遍历所有项后再判断），正确做法是用 `<template>` 包裹：

   ```vue
   <!-- 错误 -->
   <li v-for="item in list" v-if="item.active" :key="item.id">{{ item.name }}</li>
   
   <!-- 正确 -->
   <template v-for="item in list" :key="item.id">
     <li v-if="item.active">{{ item.name }}</li>
   </template>
   ```

2. **key 重复或使用 index**：`key` 必须唯一，使用 `index` 会导致列表更新时 DOM 复用错误（如删除项后索引变化）。

3. **模板中使用未声明的变量**：Vue3 会抛出警告，且变量不会渲染（显示为空）。

4. **多根节点绑定 ref**：多根节点无法直接绑定 ref，需指定单个根节点或使用 `$refs` 遍历。

### 5.2 性能优化建议

1. 避免在模板中使用复杂表达式（如 `{{ list.filter(item => item.active).length }}`），建议用 `computed` 替代。
2. 静态内容尽量提取为组件，利用 Vue3 的静态提升优化。
3. 减少 `v-for` 中的动态绑定，优先在数据层面处理。
4. 使用 `v-once` 标记静态内容，避免重复渲染。

## 总结

### 核心关键点回顾

1. `<template>` 是 Vue3 组件的 DOM 结构声明容器，本身不渲染为真实 DOM，支持多根节点（Fragment）。
2. 核心语法包括：插值 `{{ }}`（自动转义 HTML）、指令（v-bind/v-on/v-for/v-model 等）、插槽（v-slot/#）。
3. `<template>` 可作为逻辑容器（v-if/v-for），配合内置组件（Teleport/Suspense/Transition）实现高级功能。
4. Vue3 对 `<template>` 编译做了 PatchFlag 和静态提升优化，显著提升渲染性能。
5. 避坑要点：v-for 和 v-if 不共用节点、key 用唯一值、模板中避免复杂表达式。
