# 项目结构

## 一、Vue2 项目（Vue CLI 构建）

Vue2的工程化项目主要通过`@vue/cli`创建，以下是**标准且符合行业最佳实践**的目录结构和代码格式：

### 1. 完整目录结构

```
vue2-project/
├── node_modules/          # 项目依赖（npm install 生成）
├── public/                # 静态资源（不会被webpack编译）
│   ├── favicon.ico        # 网站图标
│   └── index.html         # 应用入口HTML（唯一的HTML文件）
├── src/                   # 项目核心源码
│   ├── api/               # 接口请求封装（统一管理接口）
│   │   └── user.js        # 示例：用户相关接口
│   ├── assets/            # 静态资源（会被webpack编译，如图片/样式）
│   │   ├── css/           # 全局样式
│   │   └── img/           # 图片资源
│   ├── components/        # 通用公共组件（非页面级）
│   │   ├── Button/        # 组件按文件夹组织（推荐）
│   │   │   ├── index.vue  # Button组件
│   │   │   └── style.css  # 组件专属样式
│   │   └── Layout/        # 布局组件
│   ├── router/            # 路由配置（vue-router 3.x）
│   │   └── index.js       # 路由核心配置
│   ├── store/             # 状态管理（Vuex 3.x）
│   │   ├── index.js       # Store入口
│   │   ├── state.js       # 全局状态
│   │   ├── mutations.js   # 同步修改状态
│   │   ├── actions.js     # 异步逻辑
│   │   └── modules/       # 模块化Store（复杂项目）
│   │       └── user.js    # 用户模块
│   ├── utils/             # 工具函数（如时间格式化、请求封装）
│   │   └── request.js     # axios封装
│   ├── views/             # 页面级组件（路由对应的组件）
│   │   ├── Home/          # 首页（按页面分文件夹）
│   │   │   └── index.vue
│   │   └── Login/
│   │       └── index.vue
│   ├── App.vue            # 根组件
│   └── main.js            # 项目入口文件
├── .babelrc               # Babel配置（ES6+转ES5）
├── .eslintrc.js           # ESLint代码规范配置
├── .gitignore             # Git忽略文件
├── package.json           # 项目依赖/脚本配置
└── vue.config.js          # Vue CLI自定义配置（如代理、打包）
```

### 2. 核心文件代码格式

#### （1）入口文件：src/main.js

```javascript
// Vue2 核心：通过new Vue()创建根实例
import Vue from 'vue'
import App from './App.vue'
import router from './router'
import store from './store'

// 关闭生产环境提示
Vue.config.productionTip = false

// 全局注册组件/指令（示例）
import Button from './components/Button'
Vue.component('MyButton', Button)

// 创建根实例，注入路由和Store
new Vue({
  el: '#app', // 挂载到public/index.html的#app
  router,
  store,
  render: h => h(App) // 渲染根组件（Runtime+Compiler版本也可写template）
})
```

#### （2）根组件：src/App.vue

```vue
<template>
  <!-- Vue2 模板支持所有Vue2语法（如v-for、v-bind、过滤器） -->
  <div id="app">
    <!-- 路由出口 -->
    <router-view />
  </div>
</template>

<script>
// Vue2 选项式API（Options API）
export default {
  name: 'App', // 组件名
  components: {}, // 局部注册组件
  data() { // 响应式数据（必须是函数）
    return {
      msg: 'Vue2 App'
    }
  },
  methods: {}, // 方法
  computed: {}, // 计算属性
  watch: {}, // 监听器
  created() {} // 生命周期钩子
}
</script>

<style scoped>
/* 样式（scoped表示仅作用于当前组件） */
#app {
  font-family: Avenir, Helvetica, Arial, sans-serif;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  text-align: center;
  color: #2c3e50;
  margin-top: 60px;
}
</style>
```

#### （3）路由配置：src/router/index.js

```javascript
import Vue from 'vue'
import VueRouter from 'vue-router'
import Home from '../views/Home'
import Login from '../views/Login'

// 安装路由插件
Vue.use(VueRouter)

// 路由规则
const routes = [
  {
    path: '/',
    name: 'Home',
    component: Home
  },
  {
    path: '/login',
    name: 'Login',
    component: Login
  }
]

// 创建路由实例
const router = new VueRouter({
  mode: 'history', // 路由模式
  base: process.env.BASE_URL,
  routes
})

export default router
```

#### （4）Vuex配置：src/store/index.js

```javascript
import Vue from 'vue'
import Vuex from 'vuex'
import user from './modules/user'

// 安装Vuex插件
Vue.use(Vuex)

export default new Vuex.Store({
  state: { // 全局状态
    appName: 'Vue2 Project'
  },
  mutations: { // 同步修改状态
    SET_APP_NAME(state, name) {
      state.appName = name
    }
  },
  actions: { // 异步逻辑
    updateAppName({ commit }, name) {
      setTimeout(() => {
        commit('SET_APP_NAME', name)
      }, 1000)
    }
  },
  getters: { // 派生状态
    appNameUpperCase: state => state.appName.toUpperCase()
  },
  modules: { // 模块化
    user
  }
})
```

## 二、Vue3 项目（Vite 构建）

Vue3的工程化项目推荐用`Vite`创建（替代Vue CLI），目录结构更简洁，核心差异在**代码语法（组合式API）** 和**工具链（Vite替代Webpack）**：

### 1. 完整目录结构

```
vue3-project/
├── node_modules/          # 项目依赖
├── public/                # 静态资源（不会被Vite处理）
│   └── favicon.ico        # 网站图标
├── src/                   # 核心源码
│   ├── api/               # 接口请求（和Vue2一致）
│   ├── assets/            # 静态资源（Vite编译）
│   ├── components/        # 通用组件（和Vue2一致）
│   ├── router/            # 路由配置（vue-router 4.x）
│   │   └── index.js       # 路由配置
│   ├── store/             # 状态管理（Pinia，替代Vuex）
│   │   └── index.js       # Pinia Store配置
│   ├── utils/             # 工具函数（和Vue2一致）
│   ├── views/             # 页面组件（和Vue2一致）
│   ├── App.vue            # 根组件
│   ├── main.js            # 入口文件
│   └── style.css          # 全局样式（Vite默认生成）
├── .eslintrc.js           # ESLint配置
├── .gitignore             # Git忽略文件
├── index.html             # 入口HTML（Vite特有：根目录，非public）
├── package.json           # 依赖/脚本
└── vite.config.js         # Vite配置（替代vue.config.js）
```

### 2. 核心文件代码格式

#### （1）入口文件：src/main.js

```javascript
// Vue3 核心：创建应用实例（createApp）
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import { createPinia } from 'pinia' // Pinia替代Vuex
import './style.css' // 全局样式

// 创建App实例（链式调用，无全局Vue对象）
const app = createApp(App)

// 安装插件（路由、Pinia）
app.use(router)
app.use(createPinia())

// 全局注册组件（示例）
import Button from './components/Button'
app.component('MyButton', Button)

// 挂载到#app（index.html在根目录）
app.mount('#app')
```

#### （2）根组件：src/App.vue

```vue
<template>
  <!-- Vue3 模板支持更多语法（如多根节点、v-model新用法） -->
  <router-view />
</template>

<script setup>
// Vue3 组合式API（Script Setup，推荐写法）
// 无需export default，自动暴露变量/方法
import { ref, computed, watch, onMounted } from 'vue'

// 响应式数据
const msg = ref('Vue3 App')

// 计算属性
const msgUpperCase = computed(() => msg.value.toUpperCase())

// 方法
const updateMsg = () => {
  msg.value = 'Vue3 Script Setup'
}

// 监听器
watch(msg, (newVal) => {
  console.log('msg变化：', newVal)
})

// 生命周期钩子
onMounted(() => {
  console.log('App挂载完成')
})
</script>

<style scoped>
/* 支持CSS变量、PostCSS等（Vite内置） */
#app {
  color: var(--primary-color, #2c3e50);
  margin-top: 60px;
}
</style>
```

#### （3）路由配置：src/router/index.js

```javascript
import { createRouter, createWebHistory } from 'vue-router'
import Home from '../views/Home.vue'
import Login from '../views/Login.vue'

// 路由规则（结构和Vue2类似，创建方式不同）
const routes = [
  {
    path: '/',
    name: 'Home',
    component: Home
  },
  {
    path: '/login',
    name: 'Login',
    component: Login
  }
]

// 创建路由实例（Vue3的createRouter替代new VueRouter）
const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL), // Vite的环境变量
  routes
})

export default router
```

#### （4）Pinia配置：src/store/index.js

```javascript
// Pinia（Vue3官方推荐，替代Vuex）
import { defineStore } from 'pinia'

// 定义Store（模块化，无需手动注册）
export const useAppStore = defineStore('app', {
  // 状态（替代Vuex的state，直接返回对象）
  state: () => ({
    appName: 'Vue3 Project'
  }),
  // 计算属性（替代Vuex的getters）
  getters: {
    appNameUpperCase: (state) => state.appName.toUpperCase()
  },
  // 方法（替代Vuex的mutations+actions，支持同步/异步）
  actions: {
    updateAppName(name) {
      // 直接修改状态（无需commit，Pinia支持）
      this.appName = name
      // 异步逻辑也可直接写
      setTimeout(() => {
        this.appName = 'Updated ' + name
      }, 1000)
    }
  }
})

// 用户模块Store（示例）
export const useUserStore = defineStore('user', {
  state: () => ({
    username: ''
  }),
  actions: {
    login(username) {
      this.username = username
    }
  }
})
```

#### （5）Vite配置：vite.config.js

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import path from 'path'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [vue()], // 安装Vue插件
  resolve: {
    // 路径别名（替代Webpack的alias）
    alias: {
      '@': path.resolve(__dirname, 'src')
    }
  },
  server: {
    port: 3000, // 开发服务器端口
    proxy: {
      // 接口代理（替代Vue CLI的devServer.proxy）
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  }
})
```

## 三、Vue2 vs Vue3 项目核心差异对比

### 1. 目录结构差异

| 特性                | Vue2（Vue CLI）                | Vue3（Vite）                    |
|---------------------|--------------------------------|---------------------------------|
| 入口HTML            | public/index.html              | 根目录index.html（Vite特有）    |
| 配置文件            | vue.config.js（Webpack配置）   | vite.config.js（Vite配置）      |
| 状态管理            | Vuex 3.x（modules/全局注册）   | Pinia（无需全局注册，更简洁）   |
| 全局样式            | 手动创建                      | 默认生成src/style.css           |
| 环境变量            | .env文件（VUE_APP_前缀）       | .env文件（VITE_前缀）           |

### 2. 代码格式核心差异

| 特性                | Vue2 写法                      | Vue3 写法                      |
|---------------------|--------------------------------|--------------------------------|
| 应用创建            | `new Vue({ el: '#app' })`      | `createApp(App).mount('#app')` |
| 组件API             | 选项式API（data/methods等）    | 组合式API（script setup）      |
| 响应式数据          | `data() { return {} }`         | `ref()`/`reactive()`           |
| 路由创建            | `new VueRouter()`              | `createRouter()`               |
| 状态管理            | Vuex（mutations/actions分离）  | Pinia（actions支持同步/异步）   |
| 生命周期钩子        | created/mounted（选项式）      | onMounted/onCreated（组合式）   |
| 全局API             | Vue.component()/Vue.directive()| app.component()/app.directive()|

### 3. 工具链差异

| 工具                | Vue2                          | Vue3                          |
|---------------------|-------------------------------|-------------------------------|
| 构建工具            | Webpack（Vue CLI）            | Vite（更快的热更新/打包）     |
| 包管理器            | npm/yarn（默认）              | npm/yarn/pnpm（推荐pnpm）     |
| 路由版本            | vue-router 3.x                | vue-router 4.x                |
| 状态管理            | Vuex 3.x                      | Pinia（替代Vuex）             |

## 总结

### 关键点回顾

1. **目录结构**：Vue2和Vue3的核心目录（src/api/components/views）基本一致，差异在**入口HTML位置**、**配置文件**（vue.config.js vs vite.config.js）、**状态管理**（Vuex vs Pinia）；
2. **代码格式**：
   - Vue2：选项式API（Options API）、`new Vue()`创建实例、Vuex需区分mutations/actions；
   - Vue3：组合式API（Script Setup）、`createApp()`创建实例、Pinia简化状态管理（无需commit）；
3. **工具链**：Vue2用Vue CLI+Webpack，Vue3用Vite（构建更快），路由/状态管理库版本升级且用法简化。

### 核心原则

- Vue2项目的核心是「全局Vue对象 + 选项式API」，所有插件通过`Vue.use()`安装；
- Vue3项目的核心是「应用实例 + 组合式API」，插件通过`app.use()`安装，无全局Vue对象，更符合模块化；
- 无论Vue2还是Vue3，目录结构都遵循「高内聚、低耦合」原则：公共组件/工具函数抽离，页面/模块按功能划分。
