# SpringBoot整合MyBatis

## 一、SpringBoot整合MyBatis基础（快速上手）

先通过最简示例掌握整合流程，为理解自动配置打基础。

### 1.1 核心依赖引入

SpringBoot整合MyBatis的核心是引入`mybatis-spring-boot-starter`（官方starter），它已封装所有依赖和自动配置逻辑，无需手动引入`mybatis`、`mybatis-spring`等依赖：

```xml
<dependencies>
    <!-- SpringBoot核心依赖 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter</artifactId>
    </dependency>
    
    <!-- MyBatis整合SpringBoot的核心starter -->
    <dependency>
        <groupId>org.mybatis.spring.boot</groupId>
        <artifactId>mybatis-spring-boot-starter</artifactId>
        <version>2.3.2</version> <!-- 适配SpringBoot 2.7.x，推荐稳定版 -->
    </dependency>
    
    <!-- MySQL驱动 -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <scope>runtime</scope>
    </dependency>
    
    <!-- 测试依赖 -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-test</artifactId>
        <scope>test</scope>
    </dependency>
</dependencies>
```

### 1.2 核心配置（application.yml）

只需配置数据库连接和MyBatis基础规则，**无需手动配置SqlSessionFactory、SqlSessionTemplate等核心对象**（自动配置会完成）：

```yaml
spring:
  # 数据库连接配置（SpringBoot自动配置数据源，默认HikariCP）
  datasource:
    url: jdbc:mysql://localhost:3306/test_db?useSSL=false&serverTimezone=UTC
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver

# MyBatis基础配置（对应自动配置类的属性）
mybatis:
  # Mapper XML文件路径（默认：classpath:mybatis/mapper/**/*.xml）
  mapper-locations: classpath:mapper/*.xml
  # 实体类别名包（简化XML中resultType写法）
  type-aliases-package: com.example.pojo
  # 全局配置
  configuration:
    map-underscore-to-camel-case: true # 驼峰命名自动映射
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl # 打印SQL日志
```

### 1.3 基础代码实现

#### 1.3.1 实体类（Pojo）

```java
package com.example.pojo;

public class User {
    private Integer id;
    private String userName; // 对应数据库user_name（驼峰映射）
    private Integer age;
    
    // getter/setter/toString 省略
}
```

#### 1.3.2 Mapper接口

```java
package com.example.mapper;

import com.example.pojo.User;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Param;

import java.util.List;

// 标记为MyBatis Mapper（或在启动类加@MapperScan）
@Mapper
public interface UserMapper {
    List<User> findAll();
    User findById(@Param("id") Integer id);
}
```

#### 1.3.3 Mapper XML文件

在`resources/mapper`下创建`UserMapper.xml`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.UserMapper">
    <select id="findAll" resultType="User">
        SELECT id, user_name, age FROM user
    </select>
    
    <select id="findById" resultType="User">
        SELECT id, user_name, age FROM user WHERE id = #{id}
    </select>
</mapper>
```

#### 1.3.4 启动类

```java
package com.example;

import org.mybatis.spring.annotation.MapperScan;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
// 扫描Mapper接口（替代每个Mapper加@Mapper，二选一）
@MapperScan("com.example.mapper")
public class MyBatisAutoConfigDemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(MyBatisAutoConfigDemoApplication.class, args);
    }
}
```

#### 1.3.5 测试验证

```java
package com.example;

import com.example.mapper.UserMapper;
import com.example.pojo.User;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;

import java.util.List;

@SpringBootTest
public class MyBatisTest {
    @Autowired
    private UserMapper userMapper;

    @Test
    public void testFindAll() {
        List<User> users = userMapper.findAll();
        users.forEach(System.out::println);
    }
}
```

运行测试，控制台打印SQL和结果，说明整合成功——这一切的核心是**SpringBoot的自动配置**帮我们省去了手动配置SqlSessionFactory、SqlSession等繁琐步骤。

## 二、SpringBoot对MyBatis的自动配置核心原理

SpringBoot的自动配置核心是「约定大于配置」，MyBatis的自动配置通过`mybatis-spring-boot-starter`中的`MyBatisAutoConfiguration`类实现，以下是底层逻辑拆解。

### 2.1 自动配置的触发条件

MyBatis自动配置生效需满足3个条件：

1. 项目中引入了`mybatis-spring-boot-starter`（核心）；
2. 容器中存在`DataSource` Bean（SpringBoot自动配置数据源，默认HikariCP）；
3. 未手动配置`SqlSessionFactory`（若手动配置，自动配置会失效）。

**底层触发逻辑**：
`mybatis-spring-boot-starter`的META-INF目录下有`spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`文件，里面声明了`MyBatisAutoConfiguration`，SpringBoot启动时会扫描这个文件，加载自动配置类。

### 2.2 核心自动配置类：MyBatisAutoConfiguration

这是MyBatis自动配置的核心类（位于`org.mybatis.spring.boot.autoconfigure`包），核心作用是**自动创建MyBatis的核心Bean**，关键代码简化如下：

```java
// 自动配置类注解：满足条件才生效
@Configuration
@ConditionalOnClass({ SqlSessionFactory.class, SqlSessionFactoryBean.class }) // 存在MyBatis核心类
@ConditionalOnSingleCandidate(DataSource.class) // 容器中有且仅有一个DataSource
@EnableConfigurationProperties(MyBatisProperties.class) // 绑定mybatis配置项
@AutoConfigureAfter({ DataSourceAutoConfiguration.class }) // 数据源自动配置完成后再执行
public class MyBatisAutoConfiguration {

    // 注入MyBatis配置属性（对应application.yml中的mybatis.*）
    @Autowired
    private MyBatisProperties properties;

    // 注入数据源（SpringBoot自动配置的HikariCP）
    @Autowired
    private DataSource dataSource;

    // 自动创建SqlSessionFactory Bean（MyBatis核心）
    @Bean
    @ConditionalOnMissingBean // 若手动配置了SqlSessionFactory，此Bean不生效
    public SqlSessionFactory sqlSessionFactory() throws Exception {
        SqlSessionFactoryBean factoryBean = new SqlSessionFactoryBean();
        // 设置数据源
        factoryBean.setDataSource(dataSource);
        // 设置Mapper XML文件路径（对应mybatis.mapper-locations）
        factoryBean.setMapperLocations(this.properties.resolveMapperLocations());
        // 设置实体类别名包（对应mybatis.type-aliases-package）
        factoryBean.setTypeAliasesPackage(this.properties.getTypeAliasesPackage());
        // 设置MyBatis全局配置（如驼峰映射、日志等）
        org.apache.ibatis.session.Configuration configuration = this.properties.getConfiguration();
        if (configuration != null) {
            factoryBean.setConfiguration(configuration);
        }
        // 其他配置（插件、类型处理器等）
        return factoryBean.getObject();
    }

    // 自动创建SqlSessionTemplate Bean（线程安全的SqlSession，替代原生SqlSession）
    @Bean
    @ConditionalOnMissingBean
    public SqlSessionTemplate sqlSessionTemplate(SqlSessionFactory sqlSessionFactory) {
        ExecutorType executorType = this.properties.getExecutorType();
        return executorType != null ? new SqlSessionTemplate(sqlSessionFactory, executorType)
                : new SqlSessionTemplate(sqlSessionFactory);
    }

    // Mapper接口扫描自动配置（对应@MapperScan或@Mapper）
    @Configuration
    @Import({ MyBatisMapperAutoConfigurer.class })
    @ConditionalOnMissingBean(MapperFactoryBean.class)
    public static class MapperScannerConfigurerConfiguration {
        // 自动扫描Mapper接口，生成代理对象
    }
}
```

### 2.3 自动配置的核心内容（关键Bean）

SpringBoot通过`MyBatisAutoConfiguration`自动创建以下核心Bean，无需手动定义：

| Bean名称 | 作用 | 自动配置规则 |
|----------|------|--------------|
| `SqlSessionFactory` | MyBatis核心工厂，创建SqlSession | 1. 绑定SpringBoot自动配置的数据源<br>2. 加载`mybatis.mapper-locations`指定的XML<br>3. 应用`mybatis.configuration`中的全局配置 |
| `SqlSessionTemplate` | 线程安全的SqlSession（Spring整合MyBatis的核心） | 基于`SqlSessionFactory`创建，注入到Mapper代理对象中 |
| `Mapper代理对象` | Mapper接口的实现类（动态代理） | 1. 扫描`@Mapper`注解的接口<br>2. 或扫描`@MapperScan`指定的包<br>3. 自动注入`SqlSessionTemplate` |

### 2.4 自动配置的属性映射：MyBatisProperties

`MyBatisProperties`类是MyBatis配置项的载体，**application.yml中的`mybatis.*`配置会自动绑定到这个类的属性**，核心属性对应关系：

| YAML配置项 | MyBatisProperties属性 | 作用 |
|------------|-----------------------|------|
| `mybatis.mapper-locations` | `mapperLocations` | 指定Mapper XML文件路径 |
| `mybatis.type-aliases-package` | `typeAliasesPackage` | 实体类别名包 |
| `mybatis.configuration.map-underscore-to-camel-case` | `configuration.mapUnderscoreToCamelCase` | 驼峰命名映射 |
| `mybatis.configuration.log-impl` | `configuration.logImpl` | SQL日志实现 |
| `mybatis.type-handlers-package` | `typeHandlersPackage` | 类型处理器包 |
| `mybatis.executor-type` | `executorType` | 执行器类型（SIMPLE/REUSE/BATCH） |

### 2.5 自动配置的默认规则（约定）

若不配置`mybatis.*`，SpringBoot会使用以下默认值：

1. Mapper XML文件默认路径：`classpath:mybatis/mapper/**/*.xml`；
2. 无默认实体类别名包（需手动配置）；
3. 驼峰命名映射默认关闭（需手动开启）；
4. Mapper扫描默认需加`@Mapper`注解（或手动加`@MapperScan`）；
5. 数据源默认使用HikariCP（SpringBoot默认数据源）。

## 三、自定义配置：覆盖/扩展自动配置

自动配置是“默认行为”，实际开发中常需自定义配置覆盖默认规则，以下是高频场景。

### 3.1 场景1：自定义SqlSessionFactory（添加分页插件）

若需添加MyBatis插件（如PageHelper），需手动创建`SqlSessionFactory`，覆盖自动配置：

```java
package com.example.config;

import com.github.pagehelper.PageInterceptor;
import org.apache.ibatis.session.SqlSessionFactory;
import org.mybatis.spring.SqlSessionFactoryBean;
import org.mybatis.spring.annotation.MapperScan;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.io.support.PathMatchingResourcePatternResolver;

import javax.annotation.Resource;
import javax.sql.DataSource;
import java.util.Properties;

@Configuration
@MapperScan("com.example.mapper") // 扫描Mapper包
public class MyBatisConfig {

    @Resource
    private DataSource dataSource;

    // 手动创建SqlSessionFactory，覆盖自动配置
    @Bean
    public SqlSessionFactory sqlSessionFactory() throws Exception {
        SqlSessionFactoryBean factoryBean = new SqlSessionFactoryBean();
        factoryBean.setDataSource(dataSource);
        
        // 1. 设置Mapper XML路径
        factoryBean.setMapperLocations(new PathMatchingResourcePatternResolver()
                .getResources("classpath:mapper/*.xml"));
        
        // 2. 添加分页插件PageHelper
        PageInterceptor pageInterceptor = new PageInterceptor();
        Properties properties = new Properties();
        properties.setProperty("helperDialect", "mysql"); // 指定数据库方言
        properties.setProperty("reasonable", "true"); // 分页参数合理化
        pageInterceptor.setProperties(properties);
        factoryBean.addPlugins(pageInterceptor);
        
        // 3. 开启驼峰映射
        org.apache.ibatis.session.Configuration configuration = new org.apache.ibatis.session.Configuration();
        configuration.setMapUnderscoreToCamelCase(true);
        factoryBean.setConfiguration(configuration);
        
        return factoryBean.getObject();
    }
}
```

### 3.2 场景2：自定义Mapper扫描范围

有两种方式（二选一）：

#### 方式1：启动类加`@MapperScan`（推荐）

```java
@SpringBootApplication
// 扫描多个包用逗号分隔，支持通配符
@MapperScan(basePackages = {"com.example.mapper", "com.example.dao"})
public class MyBatisAutoConfigDemoApplication { ... }
```

#### 方式2：配置类加`MapperScannerConfigurer`

```java
@Configuration
public class MyBatisConfig {
    @Bean
    public MapperScannerConfigurer mapperScannerConfigurer() {
        MapperScannerConfigurer configurer = new MapperScannerConfigurer();
        configurer.setBasePackage("com.example.mapper"); // 扫描包
        configurer.setSqlSessionTemplateBeanName("sqlSessionTemplate"); // 绑定SqlSessionTemplate
        return configurer;
    }
}
```

### 3.3 场景3：自定义TypeHandler（类型处理器）

若需自定义数据库类型与Java类型的映射（如JSON字符串→List），步骤如下：

#### 3.3.1 编写TypeHandler

```java
package com.example.handler;

import org.apache.ibatis.type.BaseTypeHandler;
import org.apache.ibatis.type.JdbcType;
import com.alibaba.fastjson.JSON;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.List;

// 处理数据库VARCHAR → Java List<String>
public class ListTypeHandler extends BaseTypeHandler<List<String>> {
    @Override
    public void setNonNullParameter(PreparedStatement ps, int i, List<String> parameter, JdbcType jdbcType) throws SQLException {
        ps.setString(i, JSON.toJSONString(parameter));
    }

    @Override
    public List<String> getNullableResult(ResultSet rs, String columnName) throws SQLException {
        return JSON.parseArray(rs.getString(columnName), String.class);
    }

    @Override
    public List<String> getNullableResult(ResultSet rs, int columnIndex) throws SQLException {
        return JSON.parseArray(rs.getString(columnIndex), String.class);
    }

    @Override
    public List<String> getNullableResult(java.sql.CallableStatement cs, int columnIndex) throws SQLException {
        return JSON.parseArray(cs.getString(columnIndex), String.class);
    }
}
```

#### 3.3.2 配置TypeHandler（两种方式）

- 方式1：XML中指定（局部生效）

  ```xml
  <resultMap id="UserResultMap" type="User">
      <result column="hobbies" property="hobbies" typeHandler="com.example.handler.ListTypeHandler"/>
  </resultMap>
  ```

- 方式2：全局配置（所有映射生效）

  ```yaml
  mybatis:
    type-handlers-package: com.example.handler # 扫描自定义TypeHandler包
  ```

### 3.4 场景4：自定义MyBatis配置文件

若需用传统的`mybatis-config.xml`（而非YAML配置），只需在YAML中指定路径：

```yaml
mybatis:
  config-location: classpath:mybatis-config.xml # 自定义MyBatis全局配置文件
  mapper-locations: classpath:mapper/*.xml
```

`mybatis-config.xml`示例：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE configuration
        PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
        "https://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
    <settings>
        <setting name="mapUnderscoreToCamelCase" value="true"/>
        <setting name="logImpl" value="STDOUT_LOGGING"/>
    </settings>
    <typeAliases>
        <package name="com.example.pojo"/>
    </typeAliases>
</configuration>
```

## 四、自动配置常见问题与解决方案

### 4.1 问题1：Mapper接口注入失败（报NoSuchBeanDefinitionException）

**原因**：

- 未加`@Mapper`注解，且未加`@MapperScan`；
- `@MapperScan`扫描包路径错误；
- Mapper接口不在启动类的子包下（SpringBoot默认扫描启动类所在包）。

**解决方案**：

- 确保`@MapperScan`路径正确：`@MapperScan("com.example.mapper")`；
- 或在每个Mapper接口加`@Mapper`注解。

### 4.2 问题2：Invalid bound statement (not found)（XML映射语句找不到）

**原因**：

- Mapper XML的`namespace`与Mapper接口全类名不一致；
- XML文件路径与`mybatis.mapper-locations`配置不一致；
- 打包时XML文件未被复制到target目录（Maven资源扫描问题）。

**解决方案**：

1. 检查`namespace`是否等于Mapper接口全类名；
2. 在pom.xml中添加资源扫描配置：

   ```xml
   <build>
       <resources>
           <resource>
               <directory>src/main/resources</directory>
               <includes>
                   <include>**/*.xml</include>
                   <include>**/*.yml</include>
               </includes>
           </resource>
       </resources>
   </build>
   ```

### 4.3 问题3：自动配置的SqlSessionFactory不生效

**原因**：手动配置了`SqlSessionFactory`，`@ConditionalOnMissingBean`导致自动配置的Bean失效。

**解决方案**：

- 若需自定义`SqlSessionFactory`，确保配置完整（包含数据源、Mapper路径等）；
- 若无需自定义，删除手动配置的`SqlSessionFactory` Bean。

### 4.4 问题4：驼峰映射不生效

**原因**：

- 未开启`map-underscore-to-camel-case`；
- 同时配置了YAML和`mybatis-config.xml`，配置冲突。

**解决方案**：

- 确保仅在一个地方开启（推荐YAML）：

  ```yaml
  mybatis:
    configuration:
      map-underscore-to-camel-case: true
  ```

## 总结

1. **自动配置核心**：SpringBoot通过`MyBatisAutoConfiguration`自动创建`SqlSessionFactory`、`SqlSessionTemplate`等核心Bean，无需手动配置，核心触发条件是引入`mybatis-spring-boot-starter`且存在`DataSource`；
2. **配置映射**：`application.yml`中的`mybatis.*`配置绑定到`MyBatisProperties`，由自动配置类读取并应用；
3. **自定义规则**：若需扩展（如添加插件、自定义TypeHandler），可通过手动创建`SqlSessionFactory`、`MapperScannerConfigurer`等Bean覆盖自动配置，遵循`@ConditionalOnMissingBean`规则（手动配置优先）；
4. **关键约定**：默认Mapper XML路径为`classpath:mybatis/mapper/**/*.xml`，Mapper扫描需`@Mapper`或`@MapperScan`，驼峰映射默认关闭。

掌握自动配置原理后，既能快速使用默认配置开发，也能灵活自定义扩展，这是SpringBoot整合MyBatis的核心能力。若需进一步讲解MyBatis的高级特性（如动态SQL、关联查询）结合SpringBoot的使用，可告诉我。
