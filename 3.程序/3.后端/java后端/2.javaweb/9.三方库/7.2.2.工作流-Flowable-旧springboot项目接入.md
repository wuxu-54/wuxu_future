# springboot项目接入Flowable

## 一、整体接入思路

在已有SpringBoot项目中接入Flowable的核心逻辑是：**复用现有数据源** → 引入Flowable依赖 → 设计BPMN审批流程 → 改造现有业务实体（增加审批相关字段） → 编写Flowable核心服务 → 联动现有增删改查接口（创建业务数据时启动流程，处理审批任务时更新业务状态）。

以下以「订单审批流程」为例（已有订单增删改查功能），给出完整接入步骤和代码。

## 二、环境准备（基于已有SpringBoot项目）

## 1. 新增Flowable核心依赖（pom.xml）

已有项目通常包含`spring-boot-starter-web`、`mybatis-plus-boot-starter`、`mysql-connector-j`等，只需新增Flowable依赖：

```xml
<!-- Flowable Spring Boot 核心启动器（复用现有数据源） -->
<dependency>
    <groupId>org.flowable</groupId>
    <artifactId>flowable-spring-boot-starter</artifactId>
    <version>6.8.0</version> <!-- 稳定版本，兼容SpringBoot 2.x/3.x -->
</dependency>

<!-- （可选）Flowable UI 控制台（开发环境调试用） -->
<dependency>
    <groupId>org.flowable</groupId>
    <artifactId>flowable-ui-modeler-spring-boot-starter</artifactId>
    <version>6.8.0</version>
</dependency>
```

## 2. 配置Flowable（application.yml）

复用现有项目的数据源，仅新增Flowable专属配置（核心是禁用自动表更新、设置历史级别）：

```yaml
spring:
  # 已有数据源配置（无需修改，Flowable会复用）
  datasource:
    url: jdbc:mysql://localhost:3306/your_existing_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&nullCatalogMeansCurrent=true
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver
  # 事务管理（已有配置，Flowable依赖事务）
  transaction:
    rollback-on-commit-failure: true

# Flowable 核心配置
flowable:
  # 生产环境必须设为false，手动执行SQL初始化表；开发环境可设为true（自动创建/更新表）
  database-schema-update: false
  # 历史级别：full（最全，记录所有操作）、audit（审计级）、activity（仅活动）、none（无）
  history-level: full
  # 异步执行器（生产环境开启，处理异步任务）
  async-executor-activate: true
  # 禁用Flowable内置的用户/组表（复用现有项目的用户体系）
  identity:
    db-enabled: false
  # 流程文件扫描路径（默认resources/processes，无需修改）
  process-definition-location-prefix: classpath:/processes/
```

## 3. 初始化Flowable数据库表（生产环境）

Flowable需要约60张表，开发环境`database-schema-update=true`会自动创建；生产环境需手动执行SQL：

- 下载对应版本SQL：<https://github.com/flowable/flowable-engine/tree/flowable-6.8.0/modules/flowable-db/src/main/resources/org/flowable/db/migration/mysql>
- 执行顺序：先执行`flowable.mysql.create.engine.sql` → `flowable.mysql.create.history.sql` → `flowable.mysql.create.idm.sql`（禁用IDM可跳过）。

## 三、业务层改造（订单业务+审批流程联动）

## 1. 改造现有订单实体（增加审批相关字段）

已有订单实体`Order`需新增3个字段，关联Flowable流程实例：

```java
import com.baomidou.mybatisplus.annotation.IdType;
import com.baomidou.mybatisplus.annotation.TableId;
import com.baomidou.mybatisplus.annotation.TableName;
import lombok.Data;
import java.math.BigDecimal;
import java.time.LocalDateTime;

/**
 * 已有订单实体 + 审批流程关联字段
 */
@Data
@TableName("t_order") // 已有订单表名
public class Order {
    // 已有字段
    @TableId(type = IdType.AUTO)
    private Long id; // 订单ID
    private String orderNo; // 订单编号
    private BigDecimal amount; // 订单金额
    private String createUser; // 创建人
    private LocalDateTime createTime; // 创建时间
    private String status; // 原有状态（比如：DRAFT-草稿、SUBMITTED-已提交）

    // 新增审批关联字段
    private String processInstanceId; // Flowable流程实例ID
    private String approvalStatus; // 审批状态：PENDING-待审批、APPROVED-已通过、REJECTED-已驳回
    private String currentApprover; // 当前审批人
}
```

## 2. 编写BPMN审批流程文件

在`resources/processes`目录下创建`order_approval.bpmn`（订单审批流程：创建订单→提交审批→部门经理审批→财务审批→结束）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<definitions
        xmlns="http://www.omg.org/spec/BPMN/20100524/MODEL"
        xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xmlns:flowable="http://flowable.org/bpmn"
        xsi:schemaLocation="http://www.omg.org/spec/BPMN/20100524/MODEL http://www.omg.org/spec/BPMN/2.0/20100501/BPMN20.xsd"
        targetNamespace="http://flowable.org/processdef"
        id="definitions">

    <!-- 订单审批流程：ID是流程标识，需全局唯一 -->
    <process id="orderApprovalProcess" name="订单审批流程" isExecutable="true">
        <!-- 流程变量定义（与订单字段关联） -->
        <extensionElements>
            <flowable:processVariables>
                <flowable:processVariable name="orderId" type="long" /> <!-- 订单ID -->
                <flowable:processVariable name="amount" type="double" /> <!-- 订单金额 -->
                <flowable:processVariable name="createUser" type="string" /> <!-- 创建人 -->
                <flowable:processVariable name="deptManager" type="string" /> <!-- 部门经理 -->
                <flowable:processVariable name="financeUser" type="string" /> <!-- 财务 -->
                <flowable:processVariable name="approvalResult" type="string" /> <!-- 审批结果：approve/reject -->
            </flowable:processVariables>
        </extensionElements>

        <!-- 开始事件 -->
        <startEvent id="startEvent" name="开始审批" />

        <!-- 排他网关：按金额判断审批节点 -->
        <exclusiveGateway id="amountGateway" name="金额判断网关" />

        <!-- 部门经理审批任务（金额≤5000） -->
        <userTask id="deptManagerTask" name="部门经理审批">
            <potentialOwner>
                <resourceAssignmentExpression>
                    <formalExpression>${deptManager}</formalExpression>
                </resourceAssignmentExpression>
            </potentialOwner>
        </userTask>

        <!-- 财务审批任务（金额>5000）：先部门经理→再财务 -->
        <userTask id="financeTask" name="财务审批">
            <potentialOwner>
                <resourceAssignmentExpression>
                    <formalExpression>${financeUser}</formalExpression>
                </resourceAssignmentExpression>
            </potentialOwner>
        </userTask>

        <!-- 审批结果网关：通过/驳回 -->
        <exclusiveGateway id="resultGateway" name="审批结果网关" />

        <!-- 结束事件：审批通过 -->
        <endEvent id="approvedEndEvent" name="审批通过" />
        <!-- 结束事件：审批驳回 -->
        <endEvent id="rejectedEndEvent" name="审批驳回" />

        <!-- 流程连线 -->
        <sequenceFlow id="start_to_gateway" sourceRef="startEvent" targetRef="amountGateway" />

        <!-- 金额≤5000 → 部门经理审批 -->
        <sequenceFlow id="gateway_to_dept" sourceRef="amountGateway" targetRef="deptManagerTask">
            <conditionExpression xsi:type="tFormalExpression">${amount &lt;= 5000}</conditionExpression>
        </sequenceFlow>

        <!-- 金额>5000 → 部门经理审批 → 财务审批 -->
        <sequenceFlow id="gateway_to_finance_pre" sourceRef="amountGateway" targetRef="deptManagerTask">
            <conditionExpression xsi:type="tFormalExpression">${amount > 5000}</conditionExpression>
        </sequenceFlow>
        <sequenceFlow id="dept_to_finance" sourceRef="deptManagerTask" targetRef="financeTask" />

        <!-- 财务审批 → 结果网关 -->
        <sequenceFlow id="finance_to_result" sourceRef="financeTask" targetRef="resultGateway" />
        <!-- 部门经理审批（≤5000）→ 结果网关 -->
        <sequenceFlow id="dept_to_result" sourceRef="deptManagerTask" targetRef="resultGateway">
            <conditionExpression xsi:type="tFormalExpression">${amount &lt;= 5000}</conditionExpression>
        </sequenceFlow>

        <!-- 审批结果：通过 → 结束 -->
        <sequenceFlow id="result_to_approved" sourceRef="resultGateway" targetRef="approvedEndEvent">
            <conditionExpression xsi:type="tFormalExpression">${approvalResult == 'approve'}</conditionExpression>
        </sequenceFlow>

        <!-- 审批结果：驳回 → 结束 -->
        <sequenceFlow id="result_to_rejected" sourceRef="resultGateway" targetRef="rejectedEndEvent">
            <conditionExpression xsi:type="tFormalExpression">${approvalResult == 'reject'}</conditionExpression>
        </sequenceFlow>
    </process>
</definitions>
```

## 3. 编写Flowable核心服务（流程部署、启动、任务处理）

创建`FlowableService`，封装Flowable核心操作，与订单业务联动：

```java
import org.flowable.engine.*;
import org.flowable.engine.repository.Deployment;
import org.flowable.engine.runtime.ProcessInstance;
import org.flowable.task.api.Task;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * Flowable核心服务：流程部署、启动、任务查询/处理
 */
@Service
public class FlowableService {

    // Flowable核心服务（自动注入）
    @Autowired
    private RepositoryService repositoryService; // 流程定义部署
    @Autowired
    private RuntimeService runtimeService;       // 流程实例管理
    @Autowired
    private TaskService taskService;             // 任务管理
    @Autowired
    private HistoryService historyService;       // 历史数据查询

    /**
     * 部署订单审批流程（项目启动时执行一次即可）
     */
    @Transactional
    public void deployOrderApprovalProcess() {
        // 检查流程是否已部署，避免重复部署
        long count = repositoryService.createProcessDefinitionQuery()
                .processDefinitionKey("orderApprovalProcess")
                .count();
        if (count > 0) {
            System.out.println("订单审批流程已部署，无需重复操作");
            return;
        }

        // 部署流程
        Deployment deployment = repositoryService.createDeployment()
                .name("订单审批流程V1.0")
                .addClasspathResource("processes/order_approval.bpmn")
                .deploy();
        System.out.println("流程部署成功，部署ID：" + deployment.getId());
    }

    /**
     * 启动订单审批流程实例
     * @param order 订单实体（包含金额、创建人、审批人等）
     * @return 流程实例ID
     */
    @Transactional
    public String startOrderApprovalProcess(Order order) {
        // 封装流程变量（与BPMN中的变量对应）
        Map<String, Object> variables = new HashMap<>();
        variables.put("orderId", order.getId());
        variables.put("amount", order.getAmount().doubleValue());
        variables.put("createUser", order.getCreateUser());
        variables.put("deptManager", "zhangsan"); // 模拟部门经理账号
        variables.put("financeUser", "lisi");     // 模拟财务账号

        // 启动流程实例（processDefinitionKey对应BPMN中的process id）
        ProcessInstance processInstance = runtimeService.startProcessInstanceByKey(
                "orderApprovalProcess", // 流程定义Key
                "ORDER_" + order.getId(), // 业务标识（建议关联订单ID，便于追踪）
                variables
        );

        // 返回流程实例ID，关联到订单表
        return processInstance.getId();
    }

    /**
     * 查询指定用户的待审批任务
     * @param assignee 审批人账号
     * @return 待办任务列表
     */
    public List<Task> getTodoApprovalTasks(String assignee) {
        return taskService.createTaskQuery()
                .taskAssignee(assignee) // 审批人
                .active() // 仅查询活跃任务
                .orderByTaskCreateTime().desc() // 按创建时间倒序
                .list();
    }

    /**
     * 处理审批任务（通过/驳回）
     * @param taskId 任务ID
     * @param approvalResult 审批结果：approve（通过）/reject（驳回）
     * @return 审批后的流程状态
     */
    @Transactional
    public String completeApprovalTask(String taskId, String approvalResult) {
        // 封装审批结果为流程变量
        Map<String, Object> variables = new HashMap<>();
        variables.put("approvalResult", approvalResult);

        // 完成任务（触发流程流转）
        taskService.complete(taskId, variables);

        // 查询任务对应的流程实例状态
        Task task = taskService.createTaskQuery().taskId(taskId).singleResult();
        String processInstanceId = task.getProcessInstanceId();
        boolean isEnded = runtimeService.createProcessInstanceQuery()
                .processInstanceId(processInstanceId)
                .finished()
                .count() > 0;

        return isEnded ? (approvalResult.equals("approve") ? "APPROVED" : "REJECTED") : "PENDING";
    }

    /**
     * 根据订单ID查询流程实例状态
     * @param orderId 订单ID
     * @return 流程状态
     */
    public String getProcessStatusByOrderId(Long orderId) {
        // 通过业务标识查询流程实例（业务标识格式：ORDER_${orderId}）
        ProcessInstance instance = runtimeService.createProcessInstanceQuery()
                .processInstanceBusinessKey("ORDER_" + orderId)
                .singleResult();

        if (instance == null) {
            // 流程已结束，查询历史
            long count = historyService.createHistoricProcessInstanceQuery()
                    .processInstanceBusinessKey("ORDER_" + orderId)
                    .finished()
                    .count();
            return count > 0 ? "FINISHED" : "NOT_STARTED";
        }
        return "RUNNING";
    }
}
```

## 4. 改造订单业务Service（联动审批流程）

已有`OrderService`需新增“提交审批”方法，并在创建订单后支持启动流程：

```java
import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

/**
 * 已有订单Service + 审批流程联动
 */
@Service
public class OrderService extends ServiceImpl<OrderMapper, Order> {

    @Autowired
    private FlowableService flowableService;

    /**
     * 创建订单（原有方法）+ 可选启动审批流程
     * @param order 订单实体
     * @param startApproval 是否立即启动审批
     * @return 创建后的订单
     */
    @Transactional
    public Order createOrder(Order order, boolean startApproval) {
        // 原有创建逻辑
        order.setStatus("DRAFT");
        order.setApprovalStatus("PENDING");
        this.save(order);

        // 启动审批流程（如果需要）
        if (startApproval) {
            String processInstanceId = flowableService.startOrderApprovalProcess(order);
            // 更新订单的流程实例ID和审批状态
            order.setProcessInstanceId(processInstanceId);
            order.setApprovalStatus("PENDING");
            this.updateById(order);
        }

        return order;
    }

    /**
     * 提交订单审批（原有草稿订单→启动流程）
     * @param orderId 订单ID
     * @return 提交后的订单
     */
    @Transactional
    public Order submitApproval(Long orderId) {
        Order order = this.getById(orderId);
        if (order == null) {
            throw new RuntimeException("订单不存在");
        }
        if (!"DRAFT".equals(order.getStatus())) {
            throw new RuntimeException("非草稿订单无法提交审批");
        }

        // 启动审批流程
        String processInstanceId = flowableService.startOrderApprovalProcess(order);

        // 更新订单状态
        order.setStatus("SUBMITTED");
        order.setProcessInstanceId(processInstanceId);
        order.setApprovalStatus("PENDING");
        this.updateById(order);

        return order;
    }

    /**
     * 更新订单审批状态（审批完成后调用）
     * @param orderId 订单ID
     * @param approvalStatus 审批状态：APPROVED/REJECTED
     */
    @Transactional
    public void updateOrderApprovalStatus(Long orderId, String approvalStatus) {
        Order order = this.getById(orderId);
        if (order == null) {
            throw new RuntimeException("订单不存在");
        }
        order.setApprovalStatus(approvalStatus);
        // 审批通过/驳回后更新订单最终状态
        if ("APPROVED".equals(approvalStatus)) {
            order.setStatus("COMPLETED");
        } else if ("REJECTED".equals(approvalStatus)) {
            order.setStatus("REJECTED");
        }
        this.updateById(order);
    }
}
```

## 5. 编写Controller（暴露审批相关接口）

在已有订单Controller基础上，新增审批流程相关接口：

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

import java.util.List;

/**
 * 订单Controller + 审批流程接口
 */
@RestController
@RequestMapping("/api/order")
public class OrderController {

    @Autowired
    private OrderService orderService;
    @Autowired
    private FlowableService flowableService;

    // 原有接口：创建订单
    @PostMapping("/create")
    public Order createOrder(@RequestBody Order order, @RequestParam(defaultValue = "true") boolean startApproval) {
        return orderService.createOrder(order, startApproval);
    }

    // 原有接口：查询订单
    @GetMapping("/{id}")
    public Order getOrder(@PathVariable Long id) {
        return orderService.getById(id);
    }

    // 新增接口：提交订单审批
    @PostMapping("/{id}/submit")
    public Order submitApproval(@PathVariable Long id) {
        return orderService.submitApproval(id);
    }

    // 新增接口：查询待审批任务
    @GetMapping("/approval/todo")
    public List<Task> getTodoTasks(@RequestParam String assignee) {
        return flowableService.getTodoApprovalTasks(assignee);
    }

    // 新增接口：处理审批任务
    @PostMapping("/approval/complete")
    public String completeApproval(
            @RequestParam String taskId,
            @RequestParam String approvalResult,
            @RequestParam Long orderId) {
        // 完成审批任务
        String approvalStatus = flowableService.completeApprovalTask(taskId, approvalResult);
        // 更新订单审批状态
        orderService.updateOrderApprovalStatus(orderId, approvalStatus);
        return "审批完成，订单状态：" + approvalStatus;
    }

    // 新增接口：查询订单审批状态
    @GetMapping("/{id}/approval/status")
    public String getApprovalStatus(@PathVariable Long id) {
        Order order = orderService.getById(id);
        return order.getApprovalStatus() + "（流程状态：" + flowableService.getProcessStatusByOrderId(id) + "）";
    }

    // 初始化接口：部署流程（项目启动后调用一次）
    @PostMapping("/approval/deploy")
    public String deployProcess() {
        flowableService.deployOrderApprovalProcess();
        return "流程部署成功";
    }
}
```

## 五、关键注意事项

## 1. 数据源与事务

- Flowable必须复用现有项目的数据源，避免多数据源导致事务不一致；
- 所有Flowable操作（部署、启动流程、完成任务）必须加`@Transactional`，确保与业务操作在同一事务中；
- 生产环境建议使用连接池（如HikariCP），并调大连接数（Flowable异步任务会占用连接）。

## 2. 流程设计规范

- BPMN文件中`process id`必须全局唯一，修改流程后需重新部署（Flowable会生成新版本）；
- 流程变量名必须与代码中一致，避免表达式解析错误（如`${amount}`拼写错误）；
- 网关条件需覆盖所有场景（如金额判断需包含`<=`和`>`，避免流程卡死）；
- XML中特殊字符需转义（如`<`转义为`&lt;`，`&`转义为`&amp;`）。

## 3. 性能优化

- 定期清理Flowable历史表（`ACT_HI_*`），可通过`historyService`批量删除过期数据；
- 非必要场景降低历史级别（如`audit`而非`full`），减少数据写入量；
- 异步任务（如耗时的服务任务）需配置`flowable:async="true"`，避免阻塞主线程；
- 对`ACT_RU_TASK`（待办任务表）、`ACT_RU_EXECUTION`（流程实例表）的常用查询字段建立索引。

## 4. 业务联动一致性

- 流程实例必须关联业务ID（通过`processInstanceBusinessKey`），便于追踪流程与业务数据的对应关系；
- 审批状态需同步更新到业务表（如订单的`approvalStatus`），避免流程状态与业务状态不一致；
- 流程终止/删除时，需同步更新业务表状态（如流程驳回后，订单状态改为`REJECTED`）。

## 5. 版本管理

- 流程定义修改后，部署时会生成新版本，旧流程实例仍按旧版本执行；
- 如需强制旧实例使用新版本，需通过`runtimeService`迁移流程实例（谨慎操作）；
- 生产环境建议给流程定义添加版本号（如`orderApprovalProcess_v1`），便于管理。

## 总结

1. Flowable接入现有SpringBoot项目的核心是**复用数据源+联动业务实体**，关键是给业务表增加流程实例ID、审批状态等关联字段；
2. 流程与业务的联动需通过`@Transactional`保证事务一致性，流程变量需与BPMN文件中的定义严格匹配；
3. 核心操作包括流程部署（仅一次）、启动流程实例（关联业务ID）、查询待办任务、完成审批任务（同步更新业务状态），需遵循“流程驱动业务”的逻辑。

以上代码可直接复制到现有项目中，只需调整包名、数据库表名、用户体系等个性化配置，即可快速实现“增删改查+审批流程”的联动。
