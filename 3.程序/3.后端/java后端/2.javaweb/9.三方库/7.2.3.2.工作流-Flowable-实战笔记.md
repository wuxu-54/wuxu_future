## 坑

### 全局变量的获取

问题：flowable 工作量，获取实例的全局变量，明明ACT_RU_VARIABLE 表有数据，但是实际上是取不到的

```java
/ 先尝试从运行时查询流程实例（多租户模式下需要指定租户 ID）
  ProcessInstance processInstance = runtimeService.createProcessInstanceQuery()
          .processInstanceId(plan.getProcessInstanceId())
          .processInstanceTenantId(String.valueOf(plan.getTenantId()))
          .singleResult();


  Map<String, Object> processVariables;
  boolean isProcessRunning;
  if(processInstance!=null && !processInstance.isEnded()){
      //实例存在
      processVariables  = processInstance.getProcessVariables();  // 问题语句！！！！！
      log.info("========== 流程变量开始（运行中）==========");
      isProcessRunning = true;
  }else{
      // 流程已结束，从历史表获取变量
      log.info("流程已结束，从历史表查询数据，planId: {}, processInstanceId: {}",
              planId, plan.getProcessInstanceId());
      processVariables = getHistoricProcessVariables(plan.getProcessInstanceId(), plan.getTenantId());
      //查询历史记录数据
      log.info("========== 流程变量开始（历史记录中）==========");
      isProcessRunning= false;
  }
```

原因：这是 Flowable 的一个常见 “坑”——ProcessInstance对象默认不会主动加载所有流程变量，即使数据库表中有数据，直接调用getProcessVariables()也可能返回空或不完整的变量。

解决方法：

```java
runtimeService.getVariables(plan.getProcessInstanceId());  //直接通过这种方式，会查询数据库中数据
```
