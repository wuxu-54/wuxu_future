# MapStruct

MapStruct是一款基于注解处理器的Java对象映射工具，核心优势是**编译期生成转换代码**（性能接近手写）、**类型安全**（编译期校验字段映射）、**可定制化强**，是SpringBoot项目中对象转换的行业最佳实践。

## 一、MapStruct 核心价值（为什么不用BeanUtils/手动转换）

| 方式 | 性能 | 类型安全 | 可定制化 | 空值处理 | 复杂映射 |
|------|------|----------|----------|----------|----------|
| 手动转换 | 最优 | 完全安全 | 完全可控 | 自定义 | 支持 |
| MapStruct | 接近手动 | 完全安全 | 高度可控 | 自定义 | 支持 |
| BeanUtils（Spring/Commons） | 较差 | 无（运行时报错） | 弱 | 易出问题 | 不支持 |
| 反射工具（如Orika） | 较差 | 弱 | 中等 | 中等 | 支持 |

## 二、基础环境配置（必看）

### 1. Maven 配置（最常用）

```xml
<!-- 核心依赖 -->
<dependency>
    <groupId>org.mapstruct</groupId>
    <artifactId>mapstruct</artifactId>
    <version>1.5.5.Final</version> <!-- 稳定版，推荐1.5+ -->
</dependency>

<!-- 注解处理器（编译期生成代码，必须） -->
<dependency>
    <groupId>org.mapstruct</groupId>
    <artifactId>mapstruct-processor</artifactId>
    <version>1.5.5.Final</version>
    <scope>provided</scope>
</dependency>

<!-- 编译插件配置（关键，避免注解处理器失效） -->
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.8.1</version>
            <configuration>
                <source>1.8</source> <!-- 对应项目JDK版本（8/11/17） -->
                <target>1.8</target>
                <annotationProcessorPaths>
                    <!-- MapStruct处理器 -->
                    <path>
                        <groupId>org.mapstruct</groupId>
                        <artifactId>mapstruct-processor</artifactId>
                        <version>1.5.5.Final</version>
                    </path>
                    <!-- 若用Lombok，必须加此配置（解决冲突） -->
                    <path>
                        <groupId>org.projectlombok</groupId>
                        <artifactId>lombok</artifactId>
                        <version>1.18.30</version> <!-- 你的Lombok版本 -->
                    </path>
                     <!-- 若用Lombok，必须加此配置，避免绑定问题：只生成转换器类，但具体方法没有映射 -->
                    <path>
							<groupId>org.projectlombok</groupId>
							<artifactId>lombok-mapstruct-binding</artifactId>
							<version>0.2.0</version>
						</path>
                </annotationProcessorPaths>
            </configuration>
        </plugin>
    </plugins>
</build>
```

### 2. Gradle 配置

```groovy
plugins {
    id 'java'
    id 'org.springframework.boot' version '2.7.0'
}

dependencies {
    // MapStruct核心
    implementation 'org.mapstruct:mapstruct:1.5.5.Final'
    // 注解处理器

    implementation 'org.projectlombok:lombok:1.18.30'

```

### 3. IDE 配置（IDEA）

确保注解处理器开启，否则无法生成实现类：

1. 打开 `File > Settings > Build, Execution, Deployment > Compiler > Annotation Processors`
2. 勾选 `Enable annotation processing`
3. 重启IDEA，执行 `mvn clean compile` 验证

## 三、核心注解与基础用法

### 1. 核心注解速查表

| 注解 | 作用位置 | 核心作用 |
|------|----------|----------|
| `@Mapper` | 接口 | 标记为MapStruct转换器接口，核心注解 |
| `@Mapping` | 方法/接口 | 配置单个字段的映射规则（如不同名、类型转换） |
| `@Mappings` | 方法 | 包裹多个`@Mapping`注解（Java8+可省略，直接写多个@Mapping） |
| `@MappingTarget` | 方法参数 | 标记“更新已有对象”的目标参数 |
| `@AfterMapping` | 方法 | 映射后执行的自定义逻辑 |
| `@BeforeMapping` | 方法 | 映射前执行的自定义逻辑 |
| `@Named` | 方法 | 命名自定义转换方法，供`@Mapping`引用 |

### 2. 基础用法：简单对象转换

#### 步骤1：定义源对象（Entity）和目标对象（DTO）

```java
// 数据库实体（源对象）
@Data
@NoArgsConstructor
@AllArgsConstructor
public class UserEntity {
    private Long id;
    private String userName; // 用户名
    private Integer age;     // 年龄
    private LocalDateTime createTime; // 创建时间
}

// 前端响应DTO（目标对象）
@Data
@NoArgsConstructor
@AllArgsConstructor
public class UserResponseDTO {
    private String name; // 对应Entity的userName（字段名不同）
    private Integer age;
    private String createTimeStr; // 对应Entity的createTime（类型不同，转字符串）
}
```

#### 步骤2：定义转换器接口

```java
import org.mapstruct.Mapper;
import org.mapstruct.Mapping;
import org.mapstruct.Named;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

// componentModel = "spring"：生成的实现类带@Component，可被Spring注入
@Mapper(componentModel = "spring")
public interface UserConverter {
    // 单例实例（非Spring环境可用）
    UserConverter INSTANCE = org.mapstruct.factory.Mappers.getMapper(UserConverter.class);

    // 基础映射：配置字段映射规则
    @Mapping(source = "userName", target = "name") // 字段名不同
    @Mapping(source = "createTime", target = "createTimeStr", qualifiedByName = "localDateTimeToString") // 类型不同，用自定义转换
    UserResponseDTO entityToResponseDTO(UserEntity entity);

    // 自定义字段转换方法（@Named标记，供@Mapping引用）
    @Named("localDateTimeToString")
    default String localDateTimeToString(LocalDateTime time) {
        if (time == null) {
            return null;
        }
        return time.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
    }
}
```

#### 步骤3：使用转换器（Spring环境）

```java
@RestController
@RequestMapping("/user")
public class UserController {
    // Spring自动注入转换器（因componentModel = "spring"）
    @Autowired
    private UserConverter userConverter;

    @GetMapping("/test")
    public UserResponseDTO test() {
        // 模拟数据库查询的Entity
        UserEntity entity = new UserEntity(1L, "张三", 25, LocalDateTime.now());
        // 转换为DTO
        UserResponseDTO dto = userConverter.entityToResponseDTO(entity);
        return dto;
    }
}
```

#### 编译后自动生成的实现类（核心）

MapStruct会在`target/generated-sources/annotations`下生成`UserConverterImpl`，核心代码如下：

```java
@Component
public class UserConverterImpl implements UserConverter {
    @Override
    public UserResponseDTO entityToResponseDTO(UserEntity entity) {
        if (entity == null) {
            return null;
        }
        UserResponseDTO userResponseDTO = new UserResponseDTO();
        userResponseDTO.setName(entity.getUserName()); // 映射不同名字段
        userResponseDTO.setAge(entity.getAge());
        // 调用自定义转换方法
        userResponseDTO.setCreateTimeStr(localDateTimeToString(entity.getCreateTime()));
        return userResponseDTO;
    }

    // 自动复制自定义的localDateTimeToString方法
    @Override
    public String localDateTimeToString(LocalDateTime time) {
        // 自定义逻辑
    }
}
```

## 四、进阶用法（覆盖90%实际场景）

### 1. 集合转换（List/Set/数组）

MapStruct支持集合自动转换，只需在转换器接口中添加集合转换方法：

```java
@Mapper(componentModel = "spring")
public interface UserConverter {
    // 单个对象转换（基础）
    @Mapping(source = "userName", target = "name")
    UserResponseDTO entityToResponseDTO(UserEntity entity);

    // 集合转换（无需额外配置，自动复用单个转换逻辑）
    List<UserResponseDTO> entityListToResponseDTOList(List<UserEntity> entityList);
    
    // Set/数组转换同理
    Set<UserResponseDTO> entitySetToResponseDTOSet(Set<UserEntity> entitySet);
    UserResponseDTO[] entityArrayToResponseDTOArray(UserEntity[] entityArray);
}
```

### 2. 多源对象转换

实际开发中常需将多个对象的数据合并为一个DTO，MapStruct完美支持：

```java
// 新增一个订单Entity
@Data
public class OrderEntity {
    private Long orderId;
    private String orderNo;
}

// 合并后的DTO：用户+订单信息
@Data
public class UserOrderDTO {
    private String userName;
    private Integer age;
    private String orderNo;
}

// 转换器中添加多源转换方法
@Mapper(componentModel = "spring")
public interface UserConverter {
    // 多源映射：source指定第几个参数的字段
    @Mapping(source = "user.userName", target = "userName")
    @Mapping(source = "user.age", target = "age")
    @Mapping(source = "order.orderNo", target = "orderNo")
    UserOrderDTO userAndOrderToUserOrderDTO(UserEntity user, OrderEntity order);
}

// 使用示例
UserEntity user = new UserEntity(1L, "张三", 25, LocalDateTime.now());
OrderEntity order = new OrderEntity(1001L, "ORDER_1001");
UserOrderDTO dto = userConverter.userAndOrderToUserOrderDTO(user, order);
```

### 3. 更新已有对象（非新建）

有时需要用源对象的数据更新已有目标对象（而非创建新对象），用`@MappingTarget`：

```java
@Mapper(componentModel = "spring")
public interface UserConverter {
    // 更新已有DTO：@MappingTarget标记目标对象
    @Mapping(source = "userName", target = "name")
    void updateUserDTO(UserEntity entity, @MappingTarget UserResponseDTO existingDTO);
}

// 使用示例
UserResponseDTO existingDTO = new UserResponseDTO();
existingDTO.setName("旧名字");
userConverter.updateUserDTO(entity, existingDTO);
// existingDTO的name会被更新为entity的userName，其他字段保留
```

### 4. 忽略字段/默认值

- **忽略字段**：目标对象中无需映射的字段，用`ignore = true`；
- **默认值**：源字段为null时，给目标字段设置默认值。

```java
@Mapper(componentModel = "spring")
public interface UserConverter {
    @Mapping(source = "userName", target = "name")
    @Mapping(target = "age", ignore = true) // 忽略age字段，不映射
    @Mapping(source = "createTime", target = "createTimeStr", defaultValue = "未创建") // 源为null时设默认值
    UserResponseDTO entityToResponseDTO(UserEntity entity);
}
```

### 5. 枚举转换

枚举类型转换是常见场景，MapStruct支持自定义枚举映射规则：

```java
// 源枚举（数据库存储）
public enum StatusEntityEnum {
    NORMAL(0, "正常"),
    DISABLED(1, "禁用");
    private Integer code;
    private String desc;
    // getter/setter
}

// 目标枚举（前端展示）
public enum StatusDTONameEnum {
    NORMAL("正常"),
    DISABLED("禁用");
    private String desc;
    // getter/setter
}

// 转换器
@Mapper(componentModel = "spring")
public interface StatusConverter {
    @Mapping(source = "desc", target = "desc") // 按desc字段映射
    StatusDTONameEnum entityEnumToDTOEnum(StatusEntityEnum entityEnum);
    
    // 集合转换
    List<StatusDTONameEnum> entityEnumListToDTOEnumList(List<StatusEntityEnum> list);
}
```

### 6. 依赖其他转换器

若转换逻辑依赖另一个MapStruct转换器，可通过`uses`属性引入：

```java
// 订单转换器
@Mapper(componentModel = "spring")
public interface OrderConverter {
    OrderDTO entityToDTO(OrderEntity entity);
}

// 用户转换器依赖订单转换器
@Mapper(componentModel = "spring", uses = OrderConverter.class)
public interface UserConverter {
    // 自动复用OrderConverter的转换逻辑
    UserOrderDTO userAndOrderToUserOrderDTO(UserEntity user, OrderEntity order);
}
```

## 五、高级特性与最佳实践

### 1. 空值处理

MapStruct默认**不会覆盖目标对象的非空字段**（更新场景），可通过`nullValuePropertyMappingStrategy`配置：

```java
// 源字段为null时，忽略目标字段（默认）
@Mapper(
    componentModel = "spring",
    nullValuePropertyMappingStrategy = NullValuePropertyMappingStrategy.IGNORE
)
// 源字段为null时，设置目标字段为null
@Mapper(
    componentModel = "spring",
    nullValuePropertyMappingStrategy = NullValuePropertyMappingStrategy.SET_TO_NULL
)
```

### 2. 格式化转换（日期/数字）

内置格式化注解支持常见类型转换，无需自定义方法：

```java
@Mapping(source = "createTime", target = "createTimeStr", dateFormat = "yyyy-MM-dd")
@Mapping(source = "amount", target = "amountStr", numberFormat = "#,##0.00") // 数字格式化
UserResponseDTO entityToResponseDTO(UserEntity entity);
```

### 3. 异常处理

MapStruct生成的代码是编译期确定的，可在自定义转换方法中捕获异常：

```java
@Named("stringToInteger")
default Integer stringToInteger(String str) {
    try {
        return Integer.parseInt(str);
    } catch (NumberFormatException e) {
        throw new IllegalArgumentException("数字格式错误：" + str, e);
    }
}
```

### 4. 最佳实践

1. **单一职责**：一个转换器对应一个业务模块（如`UserConverter`、`OrderConverter`），避免超大转换器；
2. **复用自定义方法**：将通用转换逻辑（如日期格式化）抽成公共接口，通过`uses`引入；
3. **编译期校验**：开发时执行`mvn compile`，提前发现字段映射错误（如字段名写错）；
4. **避免过度映射**：只映射前端需要的字段，减少数据传输量；
5. **Spring环境优先用componentModel = "spring"**：避免手动创建实例，符合Spring生态。

## 六、常见问题与避坑指南

| 问题现象 | 根本原因 | 解决方案 |
|----------|----------|----------|
| `componentModel = "spring"` 报错 | 依赖缺失/编译插件未配置/导入错误@Mapper | 1. 检查MapStruct依赖和processor版本一致 <br> 2. 配置maven-compiler-plugin的annotationProcessorPaths <br> 3. 确保导入`org.mapstruct.Mapper`（非MyBatis的） |
| 字段映射后为null | 1. 字段名大小写/拼写不一致 <br> 2. Lombok和MapStruct冲突 | 1. 检查`@Mapping`的source/target拼写 <br> 2. Maven中把Lombok加入annotationProcessorPaths |
| 集合转换报空指针 | 源集合为null时，MapStruct返回null | 自定义集合转换方法，处理null值：<br>`default List<UserResponseDTO> entityListToDTOList(List<UserEntity> list) {`<br> `if (list == null) return Collections.emptyList();`<br> `return list.stream().map(this::entityToResponseDTO).collect(Collectors.toList());`<br> `}` |
| 自定义方法不生效 | 1. 自定义方法未加`default`（接口中） <br> 2. `@Named`注解拼写错误 | 1. 接口中自定义方法必须加`default` <br> 2. 检查`qualifiedByName`的值和`@Named`一致 |

## 总结

1. **核心优势**：MapStruct通过编译期生成代码实现高性能、类型安全的对象转换，是SpringBoot项目替代BeanUtils的最佳选择；
2. **配置关键**：必须保证核心依赖和processor版本一致，Maven需配置编译插件指定注解处理器，IDE开启注解处理；
3. **核心用法**：
   - 基础映射用`@Mapping`配置字段规则，集合转换自动复用单对象逻辑；
   - 复杂转换（类型/多源）通过自定义方法+`@Named`/`uses`实现；
   - Spring环境用`componentModel = "spring"`实现依赖注入；
4. **避坑重点**：注意字段名拼写、Lombok冲突、null值处理，编译期校验提前发现问题。

掌握以上内容，你可以高效处理SpringBoot项目中99%的对象转换场景，大幅提升开发效率和代码可维护性。
