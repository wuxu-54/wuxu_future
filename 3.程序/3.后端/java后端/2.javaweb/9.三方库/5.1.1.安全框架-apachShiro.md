# 🛡️ Apache Shiro 完整使用指南

Apache Shiro 是一个轻量级、易用的 Java 安全框架，提供**认证（Authentication）、授权（Authorization）、会话管理（Session Management）、加密（Cryptography）**等核心功能，相比 Spring Security 更简洁、灵活，尤其适合中小项目和需要快速集成安全功能的场景。

---

## 🔍 一、核心概念与架构

### 1. 核心组件（三大核心）

| 组件 | 作用 | 理解 |
|------|------|------|
| **Subject** | 代表当前用户（可以是用户、程序、爬虫等），是与安全交互的入口 | 你可以把它看作“当前操作的主体”，所有安全操作都通过 Subject 触发 |
| **SecurityManager** | Shiro 的核心管理器，负责协调所有安全组件 | 相当于 Shiro 的“中央处理器”，管理认证、授权、会话等所有安全逻辑 |
| **Realm** | 数据源连接器，负责从数据库/缓存/LDAP 等获取用户、角色、权限数据 | 是 Shiro 和业务系统之间的“桥梁”，自定义 Realm 是开发的核心 |

### 2. 核心流程

```
用户请求 → Subject.login(token) → SecurityManager → Realm → 验证身份/权限 → 返回结果
```

## 🚀 二、Spring Boot 集成 Shiro（基础配置）

### 1. 引入依赖

在 `pom.xml` 中添加 Shiro 与 Spring Boot 的集成依赖：

```xml
<!-- Shiro Spring Boot Starter -->
<dependency>
    <groupId>org.apache.shiro</groupId>
    <artifactId>shiro-spring-boot-web-starter</artifactId>
    <version>1.12.0</version>
</dependency>
<!-- 可选：Lombok 简化代码 -->
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>
```

### 2. 自定义 Realm（核心！必须实现）

Realm 是 Shiro 与业务系统的交互层，需要实现 `AuthorizingRealm` 接口，重写**认证**和**授权**方法：

```java
import org.apache.shiro.authc.*;
import org.apache.shiro.authz.AuthorizationInfo;
import org.apache.shiro.authz.SimpleAuthorizationInfo;
import org.apache.shiro.realm.AuthorizingRealm;
import org.apache.shiro.subject.PrincipalCollection;
import org.springframework.beans.factory.annotation.Autowired;

/**
 * 自定义 Realm：处理认证和授权逻辑
 */
public class CustomRealm extends AuthorizingRealm {

    @Autowired
    private UserService userService; // 业务层，用于查询用户数据

    // -------------------------- 授权（验证权限/角色） --------------------------
    @Override
    protected AuthorizationInfo doGetAuthorizationInfo(PrincipalCollection principals) {
        // 1. 从 principals 中获取当前用户（认证时存入的用户信息）
        User user = (User) principals.getPrimaryPrincipal();

        // 2. 构建授权信息（角色 + 权限）
        SimpleAuthorizationInfo info = new SimpleAuthorizationInfo();

        // 3. 添加角色（示例：从数据库查询用户角色）
        info.addRoles(userService.getUserRoles(user.getId()));

        // 4. 添加权限（示例：从数据库查询用户权限）
        info.addStringPermissions(userService.getUserPermissions(user.getId()));

        return info;
    }

    // -------------------------- 认证（验证身份） --------------------------
    @Override
    protected AuthenticationInfo doGetAuthenticationInfo(AuthenticationToken token) throws AuthenticationException {
        // 1. 从 token 中获取用户名（登录时传入的账号）
        String username = (String) token.getPrincipal();

        // 2. 从数据库查询用户（不存在则抛出异常）
        User user = userService.getUserByUsername(username);
        if (user == null) {
            throw new UnknownAccountException("用户不存在");
        }

        // 3. 验证密码（Shiro 会自动对比 token 中的密码和此处传入的加密密码）
        // 参数：用户信息（存入 Subject 中，后续可全局获取）、加密后的密码、Realm 名称
        return new SimpleAuthenticationInfo(
                user,          // 存入 Subject 的用户信息（全局可通过 Subject.getPrincipal() 获取）
                user.getPassword(), // 数据库中存储的加密密码
                getName()      // Realm 名称（默认是类名）
        );
    }
}
```

### 3. Shiro 核心配置类

配置 `SecurityManager`、`ShiroFilterFactoryBean` 等核心 Bean，定义安全规则：

```java
import org.apache.shiro.mgt.DefaultSecurityManager;
import org.apache.shiro.spring.web.ShiroFilterFactoryBean;
import org.apache.shiro.web.mgt.DefaultWebSecurityManager;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import java.util.LinkedHashMap;
import java.util.Map;

/**
 * Shiro 核心配置类
 */
@Configuration
public class ShiroConfig {

    // 1. 自定义 Realm Bean
    @Bean
    public CustomRealm customRealm() {
        return new CustomRealm();
    }

    // 2. 安全管理器（SecurityManager）
    @Bean
    public DefaultWebSecurityManager securityManager() {
        DefaultWebSecurityManager securityManager = new DefaultWebSecurityManager();
        // 关联自定义 Realm
        securityManager.setRealm(customRealm());
        // 可选：配置会话管理器、缓存管理器等
        return securityManager;
    }

    // 3. Shiro 过滤器工厂（定义 URL 拦截规则）
    @Bean
    public ShiroFilterFactoryBean shiroFilterFactoryBean(DefaultWebSecurityManager securityManager) {
        ShiroFilterFactoryBean factoryBean = new ShiroFilterFactoryBean();
        factoryBean.setSecurityManager(securityManager);

        // 配置登录页面（前后端分离场景可配置为接口）
        factoryBean.setLoginUrl("/api/auth/login");
        // 配置未授权页面（无权限时跳转）
        factoryBean.setUnauthorizedUrl("/api/auth/unauthorized");

        // -------------------------- 定义过滤器链（顺序重要！） --------------------------
        // key: URL 路径，value: 过滤器名称（Shiro 内置过滤器）
        Map<String, String> filterChainDefinitionMap = new LinkedHashMap<>();

        // 放行：登录接口、静态资源、swagger 等
        filterChainDefinitionMap.put("/api/auth/login", "anon");
        filterChainDefinitionMap.put("/static/**", "anon");
        filterChainDefinitionMap.put("/swagger-ui/**", "anon");

        // 认证：需要登录才能访问的接口
        filterChainDefinitionMap.put("/api/user/**", "authc");

        // 角色验证：需要拥有 ADMIN 角色才能访问
        filterChainDefinitionMap.put("/api/admin/**", "roles[ADMIN]");

        // 权限验证：需要拥有 user:edit 权限才能访问
        filterChainDefinitionMap.put("/api/user/edit", "perms[user:edit]");

        // 所有其他路径需要认证
        filterChainDefinitionMap.put("/**", "authc");

        factoryBean.setFilterChainDefinitionMap(filterChainDefinitionMap);
        return factoryBean;
    }
}
```

## 🔐 三、核心功能实战

### 1. 认证（登录/退出）

#### 登录接口实现

```java
import org.apache.shiro.SecurityUtils;
import org.apache.shiro.authc.UsernamePasswordToken;
import org.apache.shiro.subject.Subject;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/auth")
public class AuthController {

    @PostMapping("/login")
    public String login(@RequestBody LoginRequest request) {
        // 1. 获取当前 Subject
        Subject subject = SecurityUtils.getSubject();

        // 2. 构建登录 Token（用户名 + 密码）
        UsernamePasswordToken token = new UsernamePasswordToken(
                request.getUsername(),
                request.getPassword()
        );

        // 3. 执行登录（失败会抛出异常，如 UnknownAccountException、IncorrectCredentialsException 等）
        try {
            subject.login(token);
            // 登录成功：返回用户信息或令牌
            User user = (User) subject.getPrincipal();
            return "登录成功，当前用户：" + user.getUsername();
        } catch (Exception e) {
            return "登录失败：" + e.getMessage();
        }
    }

    @PostMapping("/logout")
    public String logout() {
        // 执行退出登录
        SecurityUtils.getSubject().logout();
        return "退出成功";
    }

    // 登录请求参数
    public static class LoginRequest {
        private String username;
        private String password;
        // getter/setter
    }
}
```

#### 常见认证异常

| 异常类 | 含义 |
|--------|------|
| `UnknownAccountException` | 用户不存在 |
| `IncorrectCredentialsException` | 密码错误 |
| `LockedAccountException` | 账户被锁定 |
| `DisabledAccountException` | 账户被禁用 |

### 2. 授权（验证角色/权限）

#### 方式 1：注解式授权（推荐）

在 Controller/Service 方法上添加注解，细粒度控制权限：

```java
import org.apache.shiro.authz.annotation.RequiresPermissions;
import org.apache.shiro.authz.annotation.RequiresRoles;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/user")
public class UserController {

    // 需要 ADMIN 角色才能访问
    @RequiresRoles("ADMIN")
    @GetMapping("/list")
    public String getUserList() {
        return "用户列表（仅管理员可见）";
    }

    // 需要 user:edit 权限才能访问
    @RequiresPermissions("user:edit")
    @GetMapping("/edit")
    public String editUser() {
        return "编辑用户（需 user:edit 权限）";
    }
}
```

#### 方式 2：编程式授权

在代码中手动验证权限，灵活度更高：

```java
Subject subject = SecurityUtils.getSubject();
// 验证角色
if (subject.hasRole("ADMIN")) {
    // 执行管理员操作
}
// 验证权限
if (subject.isPermitted("user:edit")) {
    // 执行编辑操作
}
```

```java
// 获取当前用户信息（认证时存入的 User 对象）
User currentUser = (User) SecurityUtils.getSubject().getPrincipal();

// 获取用户ID
```

### 4. 记住我功能（Remember Me）

配置“记住我”，让用户下次访问时自动登录：

```java
// 在 ShiroConfig 中添加记住我配置
@Bean
public RememberMeManager rememberMeManager() {
    CookieRememberMeManager rememberMeManager = new CookieRememberMeManager();
    // 配置加密密钥（生产环境需加密存储）
    rememberMeManager.setCipherKey(Base64.decode("4AvVhmFLUs0KTA3Kprsdag=="));
    // 配置 Cookie
    SimpleCookie cookie = new SimpleCookie("rememberMe");
    cookie.setMaxAge(7 * 24 * 60 * 60); // 7天有效期
    rememberMeManager.setCookie(cookie);
    return rememberMeManager;
}

// 在 securityManager 中关联 rememberMeManager
@Bean
public DefaultWebSecurityManager securityManager() {
    DefaultWebSecurityManager securityManager = new DefaultWebSecurityManager();
    securityManager.setRealm(customRealm());
    securityManager.setRememberMeManager(rememberMeManager()); // 开启记住我
    return securityManager;
}
```

登录时携带 `rememberMe` 参数：

```java
UsernamePasswordToken token = new UsernamePasswordToken(username, password);
token.setRememberMe(true); // 开启记住我
subject.login(token);
```

## ⚡ 四、高级特性

### 1. 缓存集成（Redis）

用 Redis 缓存角色和权限，减少数据库查询：

```xml
<!-- 引入 Shiro Redis 缓存依赖 -->
<dependency>
    <groupId>org.crazycake</groupId>
    <artifactId>shiro-redis</artifactId>
    <version>3.3.1</version>
</dependency>
```

```java
// 在 ShiroConfig 中配置 Redis 缓存管理器
@Bean
public RedisCacheManager redisCacheManager(RedisManager redisManager) {
    RedisCacheManager cacheManager = new RedisCacheManager();
    cacheManager.setRedisManager(redisManager);
    return cacheManager;
}

// 在 securityManager 中关联缓存管理器
@Bean
public DefaultWebSecurityManager securityManager() {
    DefaultWebSecurityManager securityManager = new DefaultWebSecurityManager();
    securityManager.setRealm(customRealm());
    securityManager.setCacheManager(redisCacheManager(redisManager())); // 开启缓存
    return securityManager;
}
```

### 2. 密码加密

Shiro 提供多种加密算法（如 MD5、SHA-256），推荐用 `Md5Hash` 加盐加密：

```java
// 加密密码（用户名作为盐，避免相同密码加密后结果一致）
String password = "123456";
String salt = "admin"; // 用户名或随机字符串
String encryptedPassword = new Md5Hash(password, salt, 1024).toString(); // 1024次迭代
```

### 3. 多 Realm 配置

支持同时配置多个 Realm（如数据库 Realm + LDAP Realm），通过 `ModularRealmAuthenticator` 配置认证策略：

```java
@Bean
public ModularRealmAuthenticator authenticator() {
    ModularRealmAuthenticator authenticator = new ModularRealmAuthenticator();
    // 配置认证策略：AtLeastOneSuccessfulStrategy（至少一个 Realm 认证成功）
    authenticator.setAuthenticationStrategy(new AtLeastOneSuccessfulStrategy());
    return authenticator;
}

// 在 securityManager 中关联多 Realm
@Bean
public DefaultWebSecurityManager securityManager() {
    DefaultWebSecurityManager securityManager = new DefaultWebSecurityManager();
    securityManager.setAuthenticator(authenticator());
    securityManager.setRealms(List.of(customRealm(), ldapRealm())); // 多个 Realm
    return securityManager;
}
```

## 🛠️ 五、常见问题与最佳实践

### 1. 前后端分离场景适配

- 登录接口返回 JWT 令牌，前端后续请求携带令牌；
- 自定义 `JwtFilter` 拦截请求，解析令牌并自动登录；
- 异常统一处理，返回 JSON 格式的错误信息（如 401 未登录、403 无权限）。

### 2. 权限动态更新

当用户角色/权限变化时，需要清理缓存并重新加载授权信息：

```java
Subject subject = SecurityUtils.getSubject();
// 清理当前用户的授权缓存
subject.getSession().removeAttribute(DefaultSubjectContext.AUTHORIZATION_SESSION_KEY);
// 重新加载授权信息
subject.isPermitted("user:edit"); // 触发授权缓存更新
```

### 3. 跨域问题

在 Shiro 过滤器前添加 CORS 过滤器，解决跨域请求被拦截的问题：

```java
@Bean
public CorsFilter corsFilter() {
    CorsConfiguration config = new CorsConfiguration();
    config.addAllowedOrigin("*");
    config.addAllowedHeader("*");
    config.addAllowedMethod("*");
    UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/**", config);
    return new CorsFilter(source);
}
```

## 📌 总结

Shiro 的核心优势是**轻量、灵活、易于扩展**，适合中小项目和需要快速集成安全功能的场景。核心开发流程是：

1. **自定义 Realm**：实现认证和授权逻辑；
2. **配置 Shiro**：定义安全规则和核心 Bean；
3. **业务集成**：在接口中使用注解/编程式授权，全局获取用户信息。

如果你的项目是 Jeecg Boot，它本身已经集成了 Shiro，你可以直接基于现有配置扩展自定义 Realm 和权限规则。
