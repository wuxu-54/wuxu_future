# Lombok 使用详解

## 一、Lombok 概述

### 1.1 什么是 Lombok

Lombok 是一个 Java 库，通过注解的方式自动生成 Java 代码（如 getter、setter、构造器等），减少样板代码的编写。

### 1.2 工作原理

编译时使用注解处理器（Annotation Processor）在 AST（抽象语法树）层面修改字节码，不会影响运行时性能。

## 三、核心注解详解

### 3.1 `@Getter` / `@Setter`

```java
import lombok.Getter;
import lombok.Setter;
import lombok.AccessLevel;

// 类级别注解
@Getter
@Setter
public class User {
    private Long id;
    private String name;
    
    // 字段级别注解
    @Getter(AccessLevel.PROTECTED)
    @Setter(AccessLevel.PRIVATE)
    private String password;
    
    // 静态字段
    @Getter
    @Setter
    private static int count = 0;
    
    // 指定默认值
    @Getter(lazy = true)
    private final Map<String, String> cache = initCache();
    
    private Map<String, String> initCache() {
        return new HashMap<>();
    }
}

// 等价于生成的代码
/*
public Long getId() { return this.id; }
public void setId(Long id) { this.id = id; }
public String getName() { return this.name; }
public void setName(String name) { this.name = name; }
protected String getPassword() { return this.password; }
private void setPassword(String password) { this.password = password; }
*/
```

### 3.2 `@ToString`

```java
import lombok.ToString;

// 基本用法
@ToString
public class User {
    private Long id;
    private String name;
    private String email;
    
    // 排除字段
    @ToString.Exclude
    private String password;
    
    // 包含父类的toString
    @ToString(callSuper = true)
    static class Admin extends User {
        private String role;
    }
    
    // 只包含指定字段
    @ToString(onlyExplicitlyIncluded = true)
    static class Product {
        @ToString.Include
        private Long id;
        
        @ToString.Include(name = "产品名称")
        private String productName;
        
        private Double price; // 不会被包含
    }
    
    // 格式化输出
    @ToString(doNotUseGetters = true) // 不使用getter方法
    static class Order {
        private Long id;
        
        @ToString.Include(rank = 1) // 排名，数字越大越靠前
        private String orderNo;
    }
}
```

### 3.3 `@EqualsAndHashCode`

```java
import lombok.EqualsAndHashCode;

@EqualsAndHashCode
public class User {
    private Long id;
    private String name;

    @EqualsAndHashCode.Exclude

    }

@Getter
@Setter
```

### 3.4 构造器注解

```java
import lombok.*;

// 无参构造
@NoArgsConstructor
// 全参构造
@AllArgsConstructor
// 必需参数构造（final和@NonNull字段）
@RequiredArgsConstructor
// 建造者模式
@Builder
@Data
public class User {
    private Long id;
    
    @NonNull
    private String username;
    
    private final String type = "USER";
    
    // 自定义构造器
    public User(String username, String email) {
        this.username = username;
        this.email = email;
    }
}

// Builder的高级用法
@Builder(builderClassName = "UserBuilder", builderMethodName = "userBuilder", 
         buildMethodName = "create", toBuilder = true)
@Data
class Product {
    private Long id;
    private String name;
    
    @Builder.Default
    private int stock = 0;
    
    // 自定义构建方法
    public static class UserBuilder {
        public Product create() {
            if (name == null) {
                name = "默认产品";
            }
            return new Product(id, name, stock);
        }
    }
```

### 3.5 `@Data`

```java
import lombok.Data;

// @Data = @Getter + @Setter + @ToString + @EqualsAndHashCode + @RequiredArgsConstructor
@Data
public class User {
    private Long id;
    private String name;
    private String email;
    
    // 注意：@Data不会生成无参构造器
    // 如果需要无参构造器，需要显式添加@NoArgsConstructor
    
    // 静态工厂方法
    public static User of(String name, String email) {
        User user = new User();
        user.setName(name);
        user.setEmail(email);
        return user;
    }
}

// @Value 不可变版本
@Value // = final class + @Getter + @ToString + @EqualsAndHashCode + @AllArgsConstructor
public class ImmutableUser {
    Long id;
    String name;
    String email;
    
    // @Builder也可以用在@Value上
    @Builder
    public ImmutableUser(Long id, String name) {
        this.id = id;
        this.name = name;
        this.email = name + "@example.com";
    }
}
```

### 3.7 `@Cleanup`

```java
import lombok.Cleanup;
import java.io.*;

public class FileUtil {
    
    public void copyFile(String source, String target) throws IOException {
        // 自动关闭资源
        @Cleanup InputStream in = new FileInputStream(source);
        @Cleanup OutputStream out = new FileOutputStream(target);
        
        byte[] buffer = new byte[1024];
        int length;
        while ((length = in.read(buffer)) != -1) {
            out.write(buffer, 0, length);
        }
        
        // 等价于
        /*
        try (InputStream in = new FileInputStream(source);
             OutputStream out = new FileOutputStream(target)) {
            // ...
        }
        */
    }
    
    // 自定义清理方法
    public void customCleanup() {
        @Cleanup("dispose") // 调用dispose方法而不是close
        CustomResource resource = new CustomResource();
        // 使用资源
    }
    
    static class CustomResource {
        void dispose() {
            System.out.println("资源已释放");
        }
    }
}
```

### 5.1 实体类中的使用

```java
import javax.persistence.*;

@Entity
@Table(name = "user")
@Getter
@Setter
@ToString(exclude = {"password", "orders"}) // 排除敏感字段和关联字段

    private LocalDateTime updateTime;

    @PrePersist
    protected void onCreate() {
        createTime = LocalDateTime.now();
        updateTime = LocalDateTime.now();
    }
    
    @PreUpdate
    protected void onUpdate() {
        updateTime = LocalDateTime.now();
    }
}
```

### 5.3 避免的陷阱

```java
// 1. 避免循环引用
@Data
class Department {
    private Long id;
    private String name;
    
    // 错误：会导致StackOverflowError
    private List<Employee> employees;
}

@Data
class Employee {
    private Long id;
    private String name;
    
    // 错误：会导致StackOverflowError
    private Department department;
}

// 正确做法
@Data
class Department {
    private Long id;
    private String name;
    
    @ToString.Exclude
    @EqualsAndHashCode.Exclude
    private List<Employee> employees;
}

// 2. 避免在JPA实体中使用@Data
// @Data包含了@EqualsAndHashCode，可能导致意外行为

// 3. 注意final字段的初始化顺序
@Data
@AllArgsConstructor
class Problem {
    private final String name = "default";
    private final int age;
    
    // 问题：AllArgsConstructor会先设置age，再设置name
    // 但name有默认值，实际上name不会被构造器设置
}

// 4. Builder与继承的问题
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
class Parent {
    private Long id;
    private String name;
}

// 子类需要重新定义Builder
@Data
@Builder(builderMethodName = "childBuilder")
@NoArgsConstructor
@AllArgsConstructor
class Child extends Parent {
    private String childField;
}

// 使用
Child child = Child.childBuilder()
    .id(1L)
    .name("parent")
    .childField("child")
    .build();
```

### 6.1 与 Spring Boot

```java
// Spring Bean
@Component
@Slf4j
@RequiredArgsConstructor
public class UserService {
    
    private final UserRepository userRepository;
    private final PasswordEncoder passwordEncoder;
    
    // 不需要@Autowired，通过构造器注入
    
    public UserVO createUser(UserCreateReq req) {
        log.info("创建用户: {}", req.getUsername());
        
        UserEntity entity = UserEntity.builder()
            .username(req.getUsername())
            .password(passwordEncoder.encode(req.getPassword()))
            .email(req.getEmail())
            .build();
        
        UserEntity saved = userRepository.save(entity);
        
        return UserVO.builder()
            .id(saved.getId())
            .username(saved.getUsername())
            .email(saved.getEmail())
            .createTime(saved.getCreateTime())
            .build();
    }
}
```

### 7.2 常见问题解决

```java
// 1. Lombok注解不生效
// 解决方案：
// - 检查IDE是否安装Lombok插件
// - 检查Maven/Gradle配置
// - 清理并重新编译项目

// 2. 编译错误：找不到符号

// 3. 序列化问题
@Data
public class SerializationIssue {
    // @Data生成的equals/hashCode可能包含transient字段
    private transient String tempData;
    
    // 解决方法：使用@EqualsAndHashCode(exclude = "tempData")
}

// 4. 与Javac版本兼容性问题
// 使用与JDK版本匹配的Lombok版本
```

## 总结

### Lombok 的优缺点

**优点：**

1. 显著减少样板代码，提高开发效率
2. 代码更简洁，易于阅读和维护
3. 编译时生成代码，不影响运行时性能
4. 丰富的注解满足各种需求
5. 良好的IDE支持和社区生态

**缺点：**

1. 隐藏了代码生成细节，可能给调试带来困难
2. 需要IDE插件支持
3. 可能与其他注解处理器冲突
4. 过度使用可能导致代码可读性下降
5. 版本兼容性问题

### 使用建议

1. **团队统一规范**：制定团队统一的Lombok使用规范
2. **适度使用**：不要过度依赖，适当保留必要的样板代码
3. **注意版本兼容**：保持Lombok与JDK、框架版本的兼容性
4. **实体类谨慎使用**：在JPA实体中谨慎使用@Data和@EqualsAndHashCode
5. **结合其他工具**：与MapStruct、Jackson等框架良好集成

### 推荐配置

```properties
# lombok.config
# 全局配置
config.stopBubbling = true

# 链式调用
lombok.accessors.chain = true

# 日志配置
lombok.log.fieldName = LOG

# 排除实验性特性警告
lombok.experimental.flagUsage = WARNING
```

通过合理使用Lombok，可以显著提升Java开发效率和代码质量，但同时需要注意其潜在问题，做好团队规范和代码审查。
