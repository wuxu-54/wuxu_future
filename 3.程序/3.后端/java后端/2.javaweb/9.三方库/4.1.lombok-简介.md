# Lombok 使用详解

Lombok 是一个通过注解减少 Java 样板代码的工具，主要作用于编译阶段。下面是 **Lombok 所有注解的详细说明**（基于最新版本 1.18.30）。

## 一、核心数据注解

### 1. **@Data** - 全能数据类注解

**作用**：组合注解，生成所有字段的 getter、setter、toString、equals 和 hashCode 方法

```java
@Data
public class User {
    private Long id;
    private String username;
    private String email;
    private final String status = "ACTIVE"; // final字段没有setter
}
```

**等效于**：`@Getter` + `@Setter` + `@ToString` + `@EqualsAndHashCode` + `@RequiredArgsConstructor`

### 2. **@Getter 和 @Setter** - Getter/Setter 方法

**作用**：为字段生成 getter 和 setter 方法

```java
public class User {
    @Getter @Setter
    private String name;
    
    @Getter(AccessLevel.PROTECTED)
    @Setter(AccessLevel.PRIVATE)
    private String password;
    
    @Getter(lazy = true) // 懒加载
    private final Map<String, String> cache = expensiveInit();
    
    private Map<String, String> expensiveInit() {
        // 昂贵的初始化操作
        return new ConcurrentHashMap<>();
    }
}

// 类级别应用
@Getter
@Setter
public class Product {
    private Long id;
    private String name;
}
```

### 3. **@ToString** - toString() 方法

**作用**：生成 toString() 方法

```java
@ToString(
    exclude = {"password", "salt"},          // 排除字段
    includeFieldNames = true,                // 包含字段名
    callSuper = true,                        // 包含父类
    onlyExplicitlyIncluded = false,          // 仅包含显式标记的字段
    doNotUseGetters = false                  // 直接访问字段而非getter
)
public class User extends BaseEntity {
    @ToString.Include(name = "用户名", rank = 1)  // 自定义显示名和排序
    private String username;
    
    @ToString.Exclude                         // 排除该字段
    private String password;
    
    @ToString.Include(rank = 2)               // 高优先级（先显示）
    private String email;
}
```

### 4. **@EqualsAndHashCode** - equals() 和 hashCode()

**作用**：生成 equals() 和 hashCode() 方法

```java
@EqualsAndHashCode(
    exclude = {"id", "createdAt"},           // 排除字段
    callSuper = true,                        // 包含父类字段
    onlyExplicitlyIncluded = false,          // 仅包含显式标记的字段
    of = {"username", "email"}               // 只使用指定字段（与exclude互斥）
)
public class User extends BaseEntity {
    private Long id;                         // 被排除
    private String username;                 // 被包含
    private String email;                    // 被包含
    private Date createdAt;                  // 被排除
}
```

### 5. **@Value** - 不可变数据类

**作用**：生成不可变类（final类 + final字段）

```java
@Value                                    // 生成final类
@Builder                                 // 允许建造者模式
@With                                    // 生成with方法
public class ImmutableUser {
    Long id;                             // 自动变为private final
    String username;                     // 自动变为private final
    List<String> roles;                  // 自动变为private final
    
    // 不会生成setter，生成全参构造器
    // 生成getter，但不带"get"前缀
}

// 使用
ImmutableUser user = new ImmutableUser(1L, "john", List.of("ADMIN"));
ImmutableUser updated = user.withUsername("john.doe");
```

### 6. **@Builder** - 建造者模式

**作用**：生成建造者模式代码

```java
@Builder(
    builderClassName = "UserBuilder",     // 建造者类名
    buildMethodName = "create",           // 构建方法名
    builderMethodName = "builder",        // 获取建造者方法名
    toBuilder = true,                     // 生成toBuilder()方法
    access = AccessLevel.PUBLIC,          // 建造者访问级别
    setterPrefix = "set"                  // setter前缀
)
@ToString
public class User {
    @Builder.Default                      // 设置默认值
    private Long id = 0L;
    
    @NonNull                              // 非null检查
    private String username;
    
    @Singular                             // 处理集合字段
    private List<String> roles;
    
    @Singular("item")                     // 指定单数形式方法名
    private Map<String, String> attributes;
}

// 使用
User user = User.builder()
    .username("john")
    .role("ADMIN")                        // Singular方法（单数）
    .role("USER")                         // Singular方法（单数）
    .item("key", "value")                 // Map的Singular方法
    .build();

User copy = user.toBuilder()
    .username("jane")
    .build();
```

### 7. **@AllArgsConstructor** - 全参构造器

**作用**：生成包含所有字段的构造器

```java
@AllArgsConstructor(
    access = AccessLevel.PRIVATE,         // 构造器访问级别
    staticName = "of",                    // 静态工厂方法名
    onConstructor = @__(@Deprecated)      // 在构造器上添加注解
)
public class User {
    private Long id;
    private String username;
    
    // 生成：private User(Long id, String username)
    // 生成：public static User of(Long id, String username)
}
```

### 8. **@NoArgsConstructor** - 无参构造器

**作用**：生成无参构造器

```java
@NoArgsConstructor(
    access = AccessLevel.PROTECTED,       // 访问级别
    force = true                          // final字段初始化为0/false/null
)
public class User {
    private final Long id;                // 由于force=true，初始化为null
    private String username;
}
```

### 9. **@RequiredArgsConstructor** - 必需参数构造器

**作用**：生成包含 final 字段和 @NonNull 字段的构造器

```java
@RequiredArgsConstructor(
    staticName = "create",                // 静态工厂方法名
    onConstructor = @__(@Autowired)       // 添加Spring的@Autowired
)
public class UserService {
    private final UserRepository repository;  // final字段
    @NonNull
    private final CacheManager cache;         // @NonNull字段
    private String name;                      // 不会包含
    
    // 生成：public UserService(UserRepository repository, CacheManager cache)
}
```

## 二、实用工具注解

### 10. **@NonNull** - 非空检查

**作用**：在方法或构造器参数上生成非空检查

```java
public class UserService {
    public void createUser(@NonNull String username, @NonNull String email) {
        // Lombok生成：if (username == null) throw new NullPointerException("username");
        // Lombok生成：if (email == null) throw new NullPointerException("email");
    }
    
    @Setter
    @NonNull
    private String name;  // setter中也会生成非空检查
}
```

### 11. **@Cleanup** - 自动资源管理

**作用**：自动调用资源的 close() 方法

```java
public void readFile(String path) throws IOException {
    @Cleanup                             // 自动调用close()
    InputStream in = new FileInputStream(path);
    
    @Cleanup("dispose")                  // 指定清理方法名
    Graphics2D g = image.createGraphics();
    
    @Cleanup(value = "shutdown", onNormal = false)  // 仅在异常时清理
    ExecutorService executor = Executors.newCachedThreadPool();
    
    // 作用域结束时自动：in.close(); g.dispose();
}
```

### 12. **@SneakyThrows** - 偷偷抛出异常

**作用**：将检查异常转换为运行时异常

```java
public class FileUtil {
    @SneakyThrows                         // 抛IOException但不用声明
    public String readFile(String path) {
        return Files.readString(Paths.get(path));
    }
    
    @SneakyThrows(InterruptedException.class)  // 指定异常类型
    public void sleep(long millis) {
        Thread.sleep(millis);
    }
}
```

### 13. **@Synchronized** - 同步方法

**作用**：生成同步代码块，比 synchronized 关键字更安全

```java
public class Counter {
    private final Object lock = new Object();
    
    @Synchronized                        // 使用私有锁对象
    public void increment() {
        count++;
    }
    
    @Synchronized("lock")                // 指定锁对象
    public void decrement() {
        count--;
    }
}
```

### 14. **@With** - 不可变对象的修改

**作用**：为不可变对象生成 withXxx() 方法

```java
@Value
@With
@AllArgsConstructor
public class User {
    Long id;
    String username;
    String email;
}

// 使用
User user = new User(1L, "john", "john@example.com");
User updated = user.withUsername("john.doe")  // 返回新对象
                   .withEmail("new@example.com");
```

### 15. **@Accessors** - Getter/Setter 自定义

**作用**：自定义 getter/setter 的行为

```java
@Getter
@Setter
@Accessors(
    chain = true,        // 链式调用：setter返回this
    fluent = true,       // 流式调用：getter/setter不带get/set前缀
    prefix = {"f", "_"}  // 忽略字段前缀
)
public class User {
    private String fName;     // 生成：name() 和 name(String)
    private String _age;      // 生成：age() 和 age(String)
    
    // 链式调用：user.name("John").age(30)
    // 流式调用：user.name() 而不是 getName()
}
```

## 三、集合处理注解

### 16. **@Singular** - 集合字段的特殊处理

**作用**：为集合字段生成便捷的添加方法（与 @Builder 配合）

```java
@Builder
@Data
public class Order {
    @Singular                     // 生成：item(String) 和 items(List<String>)
    private List<String> items;
    
    @Singular("tag")              // 指定单数方法名：tag(String)
    private Set<String> tags;
    
    @Singular("entry")            // Map的Singular处理
    private Map<String, Integer> quantities;
}

// 使用
Order order = Order.builder()
    .item("Book")                 // 单个添加
    .item("Pen")
    .items(Arrays.asList("Ruler", "Eraser"))  // 批量添加
    .tag("urgent")
    .tag("priority")
    .entry("Book", 2)
    .entry("Pen", 5)
    .build();
```

## 四、日志注解

### 17. **日志框架支持** - 自动生成日志对象

```java
// SLF4J（最常用）
@Slf4j
public class UserService {
    public void process() {
        log.info("Processing user...");
        log.error("Error occurred", exception);
    }
}

// Log4j2
@Log4j2
public class UserService {
    public void process() {
        log.info("Processing...");
    }
}

// Java Util Logging
@Log
public class UserService {
    public void process() {
        log.info("Processing...");
    }
}

// Apache Commons Logging
@CommonsLog
public class UserService {
    // 生成：private static final org.apache.commons.logging.Log log = ...
}

// Log4j 1.x
@Log4j
public class UserService {
    // 生成：private static final org.apache.log4j.Logger log = ...
}

// JBoss Logging
@JBossLog
public class UserService {
    // 生成：private static final org.jboss.logging.Logger log = ...
}

// FluentLogger (Google)
@Flogger
public class UserService {
    public void process() {
        log.atInfo().log("Processing...");
    }
}

// XSlf4j (扩展SLF4J)
@XSlf4j
public class UserService {
    // 生成：private static final org.slf4j.ext.XLogger log = ...
}
```

## 六、实验性注解（Experimental）

### 19. **@SuperBuilder** - 支持继承的建造者

**作用**：生成支持父类字段的建造者模式

```java
@SuperBuilder
@Data
public class Animal {
    private String name;
    private int age;
}

@SuperBuilder
@Data
public class Dog extends Animal {
    private String breed;
}

// 使用
Dog dog = Dog.builder()
    .name("Buddy")      // 父类字段
    .age(3)             // 父类字段
    .breed("Golden Retriever")  // 子类字段
    .build();
```

### 20. **@FieldNameConstants** - 字段名常量

**作用**：为字段生成常量（用于反射、JSON序列化等）

```java
@FieldNameConstants
public class User {
    private String username;
    private String email;
    
    // 生成：
    // public static final class Fields {
    //     public static final String username = "username";
    //     public static final String email = "email";
    // }
}

// 使用
String fieldName = User.Fields.username;  // "username"
```

### 21. **@UtilityClass** - 工具类

**作用**：生成私有构造器的工具类

```java
@UtilityClass
public class StringUtils {
    public boolean isEmpty(String str) {
        return str == null || str.isEmpty();
    }
    
    // 自动生成：
    // 1. 私有构造器
    // 2. 添加@Generated注解
    // 3. 所有方法变为static
}

// 相当于
public final class StringUtils {
    private StringUtils() {
        throw new UnsupportedOperationException();
    }
    
    public static boolean isEmpty(String str) {
        return str == null || str.isEmpty();
    }
}
```

### 22. **@StandardException** - 标准异常类

**作用**：为异常类生成标准构造器

```java
@StandardException
public class BusinessException extends RuntimeException {
    // 自动生成4个标准构造器：
    // 1. public BusinessException()
    // 2. public BusinessException(String message)
    // 3. public BusinessException(String message, Throwable cause)
    // 4. public BusinessException(Throwable cause)
}
```

### 23. **@Tolerate** - 容忍冲突方法

**作用**：让 Lombok 忽略特定的方法

```java
@Data
public class User {
    private String name;
    
    @Tolerate  // Lombok会忽略此构造器，不报冲突
    public User(String name) {
        this.name = name.toUpperCase();
    }
    
    @Tolerate  // Lombok会忽略此setter
    public void setName(String name, boolean uppercase) {
        this.name = uppercase ? name.toUpperCase() : name;
    }
}
```

### 24. **@Delegate** - 委托模式

**作用**：将字段的方法委托给当前类

```java
public interface Nameable {
    String getName();
    void setName(String name);
}

@Data
public class User implements Nameable {
    @Delegate(types = Nameable.class)  // 委托给name字段
    private final Nameable nameable = new SimpleNameable();
    
    // 不需要实现Nameable接口的方法
    // Lombok会自动生成：getName()和setName()委托给nameable
}
```

### 25. **@Jacksonized** - Jackson友好建造者

**作用**：使 @Builder 类支持 Jackson 反序列化

```java
@Jacksonized
@Builder
@JsonIgnoreProperties(ignoreUnknown = true)
public class User {
    private String name;
    private String email;
}

// Jackson可以反序列化：
// ObjectMapper mapper = new ObjectMapper();
// User user = mapper.readValue(json, User.class);
```

### 26. **@Value.Immutable** - 深度不可变

```java
@Value.Immutable
@Value.Style(
    typeImmutable = "*",            // 生成ImmutableUser类
    allParameters = true,           // 全参构造器
    visibility = Value.Style.ImplementationVisibility.PUBLIC
)
public abstract class User {
    abstract String name();
    abstract List<String> roles();
    
    // 生成：ImmutableUser implements User
    // 使用：ImmutableUser.of("John", List.of("ADMIN"))
}
```

## 七、配置和元注解

### 27. **配置文件支持** - lombok.config


### 28. **@lombok.Generated** - 生成标记

**作用**：Lombok 自动添加的注解，标记生成的代码

```java
// Lombok生成的方法会自动添加此注解
@java.lang.Generated("lombok")
public String getName() {
    return this.name;
}
```

## 八、Lombok 注解处理流程

### 编译时处理顺序：

1. **解析阶段**：Lombok 读取源代码中的注解
2. **AST操作**：修改抽象语法树（AST）
3. **代码生成**：根据注解生成字节码
4. **编译输出**：生成最终的 .class 文件

## 九、最佳实践和注意事项

### 1. **实体类推荐配置**

```java
@Entity
@Table(name = "users")
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@EqualsAndHashCode(callSuper = true, onlyExplicitlyIncluded = true)
@ToString(callSuper = true, exclude = {"password"})
public class User extends BaseEntity {
    @Id
    @EqualsAndHashCode.Include
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(unique = true, nullable = false)
    private String username;
    
    @ToString.Exclude
    private String password;
    
    @ManyToOne(fetch = FetchType.LAZY)
    @ToString.Exclude
    @EqualsAndHashCode.Exclude
    private Department department;
}
```

### 2. **DTO推荐配置**

```java
@Jacksonized
@Builder
@Data
@AllArgsConstructor
@NoArgsConstructor
@FieldNameConstants
public class UserDTO {
    @NotNull
    @Size(min = 3, max = 20)
    @JsonProperty(Fields.username)  // 使用字段名常量
    private String username;
    
    @Email
    private String email;
    
    @Builder.Default
    private UserStatus status = UserStatus.ACTIVE;
}
```

### 3. **避免的问题**

```java
// 避免循环依赖
@Data
public class Department {
    private List<Employee> employees;  // 循环引用
}

@Data
public class Employee {
    private Department department;     // 循环引用
}

// 解决方案
@Data
@ToString(exclude = "employees")
@EqualsAndHashCode(exclude = "employees")
public class Department {
    private List<Employee> employees;
}

@Data
@ToString(exclude = "department")
@EqualsAndHashCode(exclude = "department")
public class Employee {
    private Department department;
}
```

### 4. **性能考虑**

```java
// 避免在大型集合上使用 @ToString 和 @EqualsAndHashCode
@Data
public class BigData {
    @ToString.Exclude
    @EqualsAndHashCode.Exclude
    private List<Detail> details;  // 可能包含大量数据
    
    private String summary;
}
```

## 注意事项

1. **IDE 必须安装插件**（IntelliJ IDEA、Eclipse、VS Code）
2. **编译时需要注解处理器**
3. **避免过度使用**，特别是在复杂继承结构中
4. **注意循环依赖**问题
5. **测试覆盖**：生成的代码也需要测试
6. **团队规范**：统一 Lombok 使用风格

Lombok 通过注解极大简化了 Java 开发，但需要根据项目实际情况合理选择使用哪些注解，避免过度依赖导致代码可读性下降。
