# 一、Redis 从零安装与配置

## 场景1：Windows系统（开发环境）

## 步骤1：下载Redis

1. 访问Redis官方Windows版下载地址（微软维护版）：<https://github.com/microsoftarchive/redis/releases>
2. 选择稳定版本（如`Redis-x64-3.2.100.zip`）下载，解压到指定目录（如`D:\redis`）。

## 步骤2：配置Redis

1. 打开解压目录下的`redis.windows.conf`文件（建议用Notepad++编辑），修改核心配置：

   ```ini
   # 绑定IP，允许所有机器访问（开发环境）
   bind 0.0.0.0
   # 关闭保护模式（否则远程无法连接）
   protected-mode no
   # 设置Redis密码（必填，否则不安全）
   requirepass 123456
   # 端口号（默认6379，可自定义）
   port 6379
   # 开启持久化（RDB模式，默认开启，可选）
   save 900 1
   save 300 10
   save 60 10000
   ```

2. 保存配置文件。

## 步骤3：启动Redis

1. 以**管理员身份**打开CMD，切换到Redis解压目录：

   ```bash
   cd D:\redis
   ```

2. 临时启动（关闭CMD则Redis停止）：

   ```bash
   redis-server.exe redis.windows.conf
   ```

3. （可选）注册为Windows服务（开机自启）：

   ```bash
   # 注册服务
   redis-server --service-install redis.windows.conf --loglevel verbose
   # 启动服务
   redis-server --service-start
   # 停止服务（如需）
   redis-server --service-stop
   # 删除服务（如需）
   redis-server --service-uninstall
   ```

## 步骤4：验证Redis启动成功

1. 新开一个CMD窗口，切换到Redis目录，执行：

   ```bash
   redis-cli.exe
   ```

2. 输入密码验证：

   ```redis
   AUTH 123456
   ```

3. 执行测试命令，返回`PONG`则成功：

   ```redis
   PING
   ```

## 场景2：Linux系统（CentOS 7/8，生产环境）

## 步骤1：安装Redis依赖

```bash
# 安装编译依赖
yum install -y gcc gcc-c++ make
```

## 步骤2：下载并编译Redis

```bash
# 下载Redis（选择稳定版，如7.0.12）
wget https://download.redis.io/releases/redis-7.0.12.tar.gz
# 解压
tar -zxvf redis-7.0.12.tar.gz
# 进入目录
cd redis-7.0.12
# 编译
make
# 安装（指定安装目录）
make install PREFIX=/usr/local/redis
```

## 步骤3：配置Redis

1. 复制配置文件到安装目录：

   ```bash
   cp redis.conf /usr/local/redis/
   ```

2. 编辑配置文件：

   ```bash
   vi /usr/local/redis/redis.conf
   ```

3. 修改核心配置（按`i`进入编辑模式）：

   ```ini
   bind 0.0.0.0
   protected-mode no
   port 6379
   requirepass 123456
   # 以守护进程运行（后台运行）
   daemonize yes
   # 日志文件路径
   logfile "/var/log/redis/redis.log"
   # 持久化文件目录
   dir /usr/local/redis/data
   ```

4. 保存退出（按`Esc`，输入`:wq`）。
5. 创建日志和数据目录：

   ```bash
   mkdir -p /var/log/redis
   mkdir -p /usr/local/redis/data
   ```

## 步骤4：启动Redis

```bash
# 启动
/usr/local/redis/bin/redis-server /usr/local/redis/redis.conf
# 查看进程，确认启动成功
ps -ef | grep redis
```

## 步骤5：验证Redis

```bash
# 连接Redis
/usr/local/redis/bin/redis-cli
# 验证密码
AUTH 123456
# 测试
PING
```

# 二、SpringBoot 连接Redis（完整步骤）

## 步骤1：创建SpringBoot项目

1. 打开IDEA，选择「New Project」→「Spring Initializr」：
   - Project SDK：选择JDK 8+/11（推荐11）
   - Group：自定义（如`com.example`）
   - Artifact：自定义（如`redis-demo`）
   - 依赖：勾选「Spring Data Redis」（核心依赖）。

## 步骤2：引入核心依赖

如果是手动创建`pom.xml`，添加以下依赖（SpringBoot 2.7+/3.x通用）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>2.7.15</version> <!-- 稳定版本，可替换为3.x -->
        <relativePath/>
    </parent>
    <groupId>com.example</groupId>
    <artifactId>redis-demo</artifactId>
    <version>0.0.1-SNAPSHOT</version>
    <name>redis-demo</name>
    
    <dependencies>
        <!-- SpringBoot Redis核心依赖 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-redis</artifactId>
        </dependency>
        <!-- 连接池（可选，但推荐，提升性能） -->
        <dependency>
            <groupId>org.apache.commons</groupId>
            <artifactId>commons-pool2</artifactId>
        </dependency>
        <!-- SpringBoot测试依赖（用于测试） -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>
```

## 步骤3：配置Redis连接信息

在`src/main/resources`目录下创建/修改`application.yml`（推荐），添加Redis配置：

```yaml
spring:
  # Redis配置
  redis:
    # Redis服务器地址（本地填127.0.0.1，远程填服务器IP）
    host: 127.0.0.1
    # Redis端口
    port: 6379
    # Redis密码（对应前面配置的123456）
    password: 123456
    # 连接超时时间（毫秒）
    timeout: 10000
    # 数据库索引（Redis默认有16个库，编号0-15）
    database: 0
    # 连接池配置（commons-pool2）
    lettuce:
      pool:
        # 最大活跃连接数
        max-active: 8
        # 最大空闲连接数
        max-idle: 8
        # 最小空闲连接数
        min-idle: 0
        # 最大等待时间（毫秒）
        max-wait: -1
```

## 步骤4：配置RedisTemplate（解决序列化问题）

SpringBoot默认的`RedisTemplate`使用JDK序列化，存储的数据是乱码，需自定义配置类优化：

```java
package com.example.redisdemo.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

@Configuration
public class RedisConfig {

    /**
     * 自定义RedisTemplate，解决序列化问题
     */
    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        // 设置连接工厂
        template.setConnectionFactory(factory);
        
        // 字符串序列化器（key和hash的key用）
        StringRedisSerializer stringSerializer = new StringRedisSerializer();
        // JSON序列化器（value和hash的value用）
        GenericJackson2JsonRedisSerializer jsonSerializer = new GenericJackson2JsonRedisSerializer();
        
        // 配置key序列化
        template.setKeySerializer(stringSerializer);
        template.setHashKeySerializer(stringSerializer);
        // 配置value序列化
        template.setValueSerializer(jsonSerializer);
        template.setHashValueSerializer(jsonSerializer);
        
        // 初始化模板
        template.afterPropertiesSet();
        return template;
    }
}
```

## 步骤5：编写测试代码，验证连接

创建测试类`RedisDemoApplicationTests`，测试Redis的增删改查：

```java
package com.example.redisdemo;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.data.redis.core.RedisTemplate;

@SpringBootTest
class RedisDemoApplicationTests {

    // 注入自定义的RedisTemplate
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Test
    void testRedisConnection() {
        // 1. 存储字符串
        redisTemplate.opsForValue().set("name", "张三");
        // 2. 获取字符串
        String name = (String) redisTemplate.opsForValue().get("name");
        System.out.println("获取到的name：" + name); // 输出：张三

        // 3. 存储对象（自动序列化为JSON）
        User user = new User(1L, "李四", 25);
        redisTemplate.opsForValue().set("user:1", user);
        // 4. 获取对象
        User getUser = (User) redisTemplate.opsForValue().get("user:1");
        System.out.println("获取到的用户：" + getUser); // 输出：User(id=1, name=李四, age=25)

        // 5. 删除数据
        redisTemplate.delete("name");
        Boolean exists = redisTemplate.hasKey("name");
        System.out.println("name是否存在：" + exists); // 输出：false
    }

    // 测试用的User实体类（需序列化，Lombok可选）
    static class User {
        private Long id;
        private String name;
        private Integer age;

        // 无参构造（JSON反序列化必须）
        public User() {}

        public User(Long id, String name, Integer age) {
            this.id = id;
            this.name = name;
            this.age = age;
        }

        // getter/setter（省略，IDEA可自动生成）
        @Override
        public String toString() {
            return "User{" +
                    "id=" + id +
                    ", name='" + name + '\'' +
                    ", age=" + age +
                    '}';
        }
    }
}
```

## 步骤6：运行测试

执行测试方法`testRedisConnection`，控制台输出正常则说明SpringBoot已成功连接Redis。

## 总结

1. **Redis核心配置**：必须修改`bind 0.0.0.0`、关闭保护模式、设置密码，否则无法远程连接或存在安全风险。
2. **SpringBoot连接关键**：引入`spring-boot-starter-data-redis`依赖，配置`application.yml`中的Redis地址/端口/密码，自定义`RedisTemplate`解决序列化乱码问题。
3. **验证方式**：通过`redis-cli`验证Redis服务是否启动，通过SpringBoot测试类验证连接和数据操作是否正常。

如果遇到连接失败，优先检查：Redis服务是否启动、防火墙是否放行6379端口、密码是否匹配、`bind`配置是否允许当前IP访问。
