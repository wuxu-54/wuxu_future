# 一、Mac系统下Redis 从零安装与配置

## 方式1：Homebrew安装（推荐，最简单）

Mac自带的Homebrew是包管理器，能一键安装Redis，无需手动编译，适合开发环境。

## 步骤1：安装Homebrew（如已安装可跳过）

打开Mac的「终端」（Terminal），执行以下命令安装Homebrew：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

安装完成后，执行`brew -v`验证，输出版本号则安装成功。

## 步骤2：安装Redis

```bash
# 安装最新稳定版Redis
brew install redis
```

安装完成后，执行`redis-server -v`验证版本（如输出`Redis server v=7.2.4 sha=00000000:0 malloc=libc bits=64 build=xxx`则成功）。

## 步骤3：找到并修改Redis配置文件

Mac通过brew安装的Redis配置文件默认路径：`/opt/homebrew/etc/redis.conf`（M1/M2/M3芯片Mac）或`/usr/local/etc/redis.conf`（Intel芯片Mac）。

1. 先确认配置文件路径（通用命令）：

   ```bash
   brew info redis
   ```

   输出中会显示`Configuration file:`后的路径，复制该路径。

2. 编辑配置文件（以M1芯片为例，替换为你的实际路径）：

   ```bash
   # 用vim编辑（新手也可以用文本编辑器打开该路径文件）
   vim /opt/homebrew/etc/redis.conf
   ```

3. 修改核心配置（按`i`进入编辑模式）：

   ```ini
   # 1. 允许所有IP访问（开发环境）
   bind 0.0.0.0
   # 2. 关闭保护模式（否则远程无法连接）
   protected-mode no
   # 3. 设置Redis密码（必填，安全）
   requirepass 123456
   # 4. 端口保持默认6379（可自定义）
   port 6379
   # 5. （可选）设置后台运行（brew启动默认已后台，可忽略）
   daemonize yes
   # 6. 开启持久化（默认已开启，可选）
   save 900 1
   save 300 10
   save 60 10000
   ```

4. 保存退出：按`Esc`键，输入`:wq`回车。

## 步骤4：启动/停止/重启Redis（brew方式）

```bash
# 启动Redis（开机自启）
brew services start redis
# 停止Redis
brew services stop redis
# 重启Redis（修改配置后需重启）
brew services restart redis
# 查看Redis状态
brew services list | grep redis
```

状态显示`started`则说明Redis已后台运行。

## 步骤5：验证Redis启动成功

```bash
# 连接Redis客户端
redis-cli
# 输入密码验证
AUTH 123456
# 测试连接，返回PONG则成功
PING
```

## 方式2：源码编译安装（备用，brew安装失败时用）

如果brew安装有问题，可手动编译源码：

```bash
# 1. 安装依赖
brew install gcc make
# 2. 下载Redis源码（以7.2.4为例）
wget https://download.redis.io/releases/redis-7.2.4.tar.gz
# 3. 解压
tar -zxvf redis-7.2.4.tar.gz
# 4. 进入目录编译
cd redis-7.2.4
make
# 5. 安装到指定目录
make install PREFIX=/usr/local/redis
# 6. 复制配置文件
cp redis.conf /usr/local/redis/
# 7. 编辑配置文件（同方式1的核心配置）
vim /usr/local/redis/redis.conf
# 8. 启动Redis
/usr/local/redis/bin/redis-server /usr/local/redis/redis.conf
# 9. 验证（同方式1）
/usr/local/redis/bin/redis-cli
```

# 二、SpringBoot 连接Redis（Mac适配说明）

Mac系统下的SpringBoot连接Redis逻辑和Windows/Linux**完全一致**，仅需确认以下点：

## 步骤1：复用之前的SpringBoot项目依赖

`pom.xml`依赖无需修改，保持原内容即可（包含`spring-boot-starter-data-redis`和连接池依赖）。

## 步骤2：确认application.yml配置

只需保证Redis地址为本地（Mac本地Redis填`127.0.0.1`），密码和Redis配置一致：

```yaml
spring:
  redis:
    host: 127.0.0.1  # Mac本地Redis，无需改IP
    port: 6379
    password: 123456  # 和你配置的Redis密码一致
    timeout: 10000
    database: 0
    lettuce:
      pool:
        max-active: 8
        max-idle: 8
        min-idle: 0
        max-wait: -1
```

## 步骤3：复用之前的Redis配置类和测试代码

1. `RedisConfig`配置类（解决序列化）无需修改；
2. 测试类`RedisDemoApplicationTests`无需修改，直接运行测试方法：
   - 控制台输出`获取到的name：张三`、`获取到的用户：User{id=1, name='李四', age=25}`等内容，说明连接成功。

## 常见问题（Mac专属）

1. **Redis启动失败**：检查Mac防火墙是否放行6379端口（开发环境可临时关闭防火墙：`sudo pfctl -d`）；
2. **brew命令找不到**：重启终端，或执行`source ~/.zshrc`（Mac默认shell是zsh）；
3. **配置文件修改不生效**：修改后必须执行`brew services restart redis`重启Redis。

---

## 总结

1. **Mac安装Redis优先用brew**：命令简单（`brew install redis`），配置文件路径记住M1/M2芯片是`/opt/homebrew/etc/redis.conf`，Intel芯片是`/usr/local/etc/redis.conf`；
2. **Redis核心配置不变**：必须修改`bind 0.0.0.0`、关闭保护模式、设置密码，这是连接成功的关键；
3. **SpringBoot适配无成本**：仅需保证配置文件中Redis地址为`127.0.0.1`、密码匹配，代码和Windows/Linux完全通用。
