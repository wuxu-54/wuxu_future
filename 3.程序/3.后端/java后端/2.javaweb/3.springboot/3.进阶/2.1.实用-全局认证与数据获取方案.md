# 全局配置与获取

你希望我详细讲解 Spring Boot 中**全局认证**（所有接口统一身份验证）的配置方法，以及如何在应用的任意层（Controller/Service/工具类等）**全局获取当前登录用户的信息**，包括完整的配置步骤、核心代码实现和最佳实践。

接下来我会基于 **Spring Security + JWT**（行业主流无状态认证方案）来实现，这是 Spring Boot 中全局认证的标准做法，同时提供通用的用户数据全局获取方案，确保代码可直接复用。

---

## 一、核心思路梳理

### 全局认证核心逻辑

1. **认证流程**：用户登录 → 生成 JWT 令牌 → 客户端请求时携带令牌 → 服务端全局拦截器/过滤器验证令牌 → 验证通过则放行，失败则返回认证错误。
2. **核心组件**：
   - JWT 工具类：生成/解析令牌，存储用户核心信息（ID/用户名/角色）；
   - Spring Security 配置：定义全局认证规则（哪些接口放行、哪些需要认证）；
   - JWT 认证过滤器：拦截所有请求，验证令牌有效性，将用户信息存入 `SecurityContext`；
   - 用户详情服务：加载数据库/内存中的用户数据，供认证使用。

### 全局用户数据获取逻辑

Spring Security 内置的 `SecurityContextHolder` 基于 `ThreadLocal` 实现（线程隔离），认证通过后会将用户信息存入其中，可在任意层通过工具类封装获取，无需手动传递用户参数。

### 2. JWT 工具类（生成/解析令牌）

封装 JWT 核心操作，用于生成令牌、解析令牌中的用户信息：

```java
import io.jsonwebtoken.*;
import io.jsonwebtoken.security.Keys;
import lombok.extern.slf4j.Slf4j;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.stereotype.Component;

import javax.crypto.SecretKey;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

/**
 * JWT 工具类
 */
@Slf4j
@Component
public class JwtTokenUtil {

    // 生成签名密钥（基于自定义密钥）
    private static final SecretKey SECRET_KEY = Keys.hmacShaKeyFor(JwtConstants.SECRET_KEY.getBytes());

    /**
     * 生成 JWT 令牌（基于用户信息）
     * @param userDetails Spring Security 用户详情
     * @return JWT 令牌
     */
    public String generateToken(UserDetails userDetails) {
        // 1. 构建令牌的自定义声明（存储用户核心信息，如ID/用户名）
        Map<String, Object> claims = new HashMap<>();
        claims.put("username", userDetails.getUsername());
        // 如需存储用户ID，可扩展 UserDetails，此处先简化

        // 2. 生成令牌
        return Jwts.builder()
                // 设置自定义声明
                .setClaims(claims)
                // 设置主题（用户名）
                .setSubject(userDetails.getUsername())
                // 设置签发时间
                .setIssuedAt(new Date())
                // 设置过期时间
                .setExpiration(new Date(System.currentTimeMillis() + JwtConstants.EXPIRATION_TIME))
                // 设置签名算法和密钥
                .signWith(SECRET_KEY, SignatureAlgorithm.HS256)
                // 构建令牌
                .compact();
    }

    /**
     * 解析令牌，获取用户名
     * @param token JWT 令牌
     * @return 用户名
     */
    public String getUsernameFromToken(String token) {
        return getClaimsFromToken(token).getSubject();
    }

    /**
     * 验证令牌有效性
     * @param token JWT 令牌
     * @param userDetails 用户详情
     * @return true=有效，false=无效
     */
    public boolean validateToken(String token, UserDetails userDetails) {
        String username = getUsernameFromToken(token);
        // 验证用户名匹配 + 令牌未过期
        return username.equals(userDetails.getUsername()) && !isTokenExpired(token);
    }

    /**
     * 解析令牌，获取所有声明
     */
    private Claims getClaimsFromToken(String token) {
        try {
            return Jwts.parserBuilder()
                    .setSigningKey(SECRET_KEY)
                    .build()
                    .parseClaimsJws(token)
                    .getBody();
        } catch (ExpiredJwtException e) {
            log.error("JWT 令牌已过期: {}", e.getMessage());
            throw new RuntimeException("令牌已过期");
        } catch (UnsupportedJwtException e) {
            log.error("不支持的 JWT 令牌: {}", e.getMessage());
            throw new RuntimeException("不支持的令牌格式");
        } catch (MalformedJwtException e) {
            log.error("JWT 令牌格式错误: {}", e.getMessage());
            throw new RuntimeException("令牌格式错误");
        } catch (SignatureException e) {
            log.error("JWT 签名验证失败: {}", e.getMessage());
            throw new RuntimeException("签名验证失败");
        } catch (IllegalArgumentException e) {
            log.error("JWT 令牌为空或格式非法: {}", e.getMessage());
            throw new RuntimeException("令牌非法");
        }
    }

    /**
     * 判断令牌是否过期
     */
    private boolean isTokenExpired(String token) {
        Date expiration = getClaimsFromToken(token).getExpiration();
        return expiration.before(new Date());
    }
}
```

### 4. 用户详情服务（加载用户数据）

```java
import java.util.Collections;

/**
 * 用户详情服务（加载用户数据）

    /**
     * 根据用户名加载用户数据（生产环境替换为数据库查询）

    public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {

            throw new UsernameNotFoundException("用户不存在");

                "系统管理员", // 昵称
```

### 5. JWT 认证过滤器（全局拦截认证）

自定义过滤器，拦截所有请求，验证 JWT 令牌，将用户信息存入 `SecurityContext`：

```java
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.web.authentication.WebAuthenticationDetailsSource;
import org.springframework.stereotype.Component;
import org.springframework.util.StringUtils;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;

/**
 * JWT 认证过滤器（全局拦截所有请求，验证令牌）
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtTokenUtil jwtTokenUtil;
    private final CustomUserDetailsService userDetailsService;

    /**
     * 核心过滤逻辑
     */
    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {
        try {
            // 1. 从请求头中获取 JWT 令牌
            String token = getTokenFromRequest(request);
            if (StringUtils.hasText(token)) {
                // 2. 解析令牌，获取用户名
                String username = jwtTokenUtil.getUsernameFromToken(token);

                // 3. 如果用户名存在，且 SecurityContext 中无认证信息（未登录）
                if (StringUtils.hasText(username) && SecurityContextHolder.getContext().getAuthentication() == null) {
                    // 4. 加载用户详情
                    UserDetails userDetails = userDetailsService.loadUserByUsername(username);

                    // 5. 验证令牌有效性
                    if (jwtTokenUtil.validateToken(token, userDetails)) {
                        // 6. 创建认证令牌，存入 SecurityContext（全局可获取）
                        UsernamePasswordAuthenticationToken authenticationToken =
                                new UsernamePasswordAuthenticationToken(userDetails, null, userDetails.getAuthorities());
                        // 设置请求详情（IP/会话等）
                        authenticationToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
                        // 存入 SecurityContext（核心：ThreadLocal 存储，全局可获取）
                        SecurityContextHolder.getContext().setAuthentication(authenticationToken);
                    }
                }
            }
        } catch (Exception e) {
            log.error("JWT 认证失败: {}", e.getMessage());
            // 认证失败不抛出异常，交给后续异常处理器处理
            SecurityContextHolder.clearContext();
        }

        // 7. 放行请求（无论认证是否成功，后续 Security 会处理未认证的请求）
        filterChain.doFilter(request, response);
    }

    /**
     * 从请求头中提取 JWT 令牌（格式：Bearer <token>）
     */
    private String getTokenFromRequest(HttpServletRequest request) {
        String header = request.getHeader(JwtConstants.TOKEN_HEADER);
        if (StringUtils.hasText(header) && header.startsWith(JwtConstants.TOKEN_PREFIX)) {
            // 去掉前缀 "Bearer "，返回纯令牌
            return header.substring(JwtConstants.TOKEN_PREFIX.length());
        }
        return null;
    }
}
```

### 6. Spring Security 全局配置

配置全局认证规则、放行接口、添加 JWT 过滤器：

```java
import lombok.RequiredArgsConstructor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.dao.DaoAuthenticationProvider;
import org.springframework.security.config.annotation.authentication.configuration.AuthenticationConfiguration;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

/**
 * Spring Security 全局配置
 */
@Configuration
@EnableWebSecurity // 启用 Web 安全
@EnableMethodSecurity // 启用方法级权限控制（可选）
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtAuthenticationFilter;
    private final CustomUserDetailsService userDetailsService;

    /**
     * 配置全局认证规则
     */
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                // 1. 关闭 CSRF（无状态 JWT 不需要）
                .csrf(csrf -> csrf.disable())
                // 2. 关闭 Session（无状态认证）
                .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                // 3. 配置请求授权规则（全局认证规则）
                .authorizeHttpRequests(auth -> auth
                        // 放行登录接口（无需认证）
                        .requestMatchers("/api/auth/login").permitAll()
                        // 放行静态资源（可选）
                        .requestMatchers("/static/**").permitAll()
                        // 所有其他请求都需要认证
                        .anyRequest().authenticated()
                )
                // 4. 添加 JWT 过滤器（在 UsernamePasswordAuthenticationFilter 之前执行）
                .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }

    /**
     * 配置认证提供者（关联用户详情服务和密码编码器）
     */
    @Bean
    public DaoAuthenticationProvider authenticationProvider() {
        DaoAuthenticationProvider provider = new DaoAuthenticationProvider();
        provider.setUserDetailsService(userDetailsService);
        provider.setPasswordEncoder(passwordEncoder());
        return provider;
    }

    /**
     * 密码编码器（BCrypt 加密）
     */
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    /**
     * 认证管理器（用于登录接口手动认证）
     */
    @Bean
    public AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }
}
```

### 7. 全局用户上下文工具类（核心：全局获取用户数据）

封装 `SecurityContextHolder` 操作，提供全局获取当前用户的方法，简化代码：

```java
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;

/**
 * 全局用户上下文工具类（任意层可调用）
 */
@Component
public class UserContextHolder {

    /**
     * 获取当前登录用户的完整信息
     * @return 自定义用户详情（null=未登录）
     */
    public static CustomUserDetails getCurrentUser() {
        // 从 SecurityContext 中获取认证信息
        Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
        if (authentication == null || !authentication.isAuthenticated()) {
            return null;
        }

        // 获取用户详情（需强转为自定义类型）
        Object principal = authentication.getPrincipal();
        if (principal instanceof CustomUserDetails) {
            return (CustomUserDetails) principal;
        }
        return null;
    }

    /**
     * 获取当前登录用户ID
     * @return 用户ID（null=未登录）
     */
    public static Long getCurrentUserId() {
        CustomUserDetails user = getCurrentUser();
        return user != null ? user.getUserId() : null;
    }

    /**
     * 获取当前登录用户名
     * @return 用户名（null=未登录）
     */
    public static String getCurrentUsername() {
        CustomUserDetails user = getCurrentUser();
        return user != null ? user.getUsername() : null;
    }

    /**
     * 获取当前登录用户昵称
     * @return 昵称（null=未登录）
     */
    public static String getCurrentNickname() {
        CustomUserDetails user = getCurrentUser();
        return user != null ? user.getNickname() : null;
    }
}
```

### 8. 全局认证异常处理（可选）

统一处理认证失败的异常，返回友好的 JSON 响应：

```java
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.HttpStatus;
import org.springframework.http.MediaType;
import org.springframework.security.access.AccessDeniedException;
import org.springframework.security.authentication.AuthenticationCredentialsNotFoundException;
import org.springframework.security.core.AuthenticationException;
import org.springframework.security.web.AuthenticationEntryPoint;
import org.springframework.security.web.access.AccessDeniedHandler;
import org.springframework.stereotype.Component;

import java.io.IOException;
import java.nio.charset.StandardCharsets;

/**
 * 全局认证/授权异常处理器
 */
@Slf4j
@Component
public class CustomAuthExceptionHandler implements AuthenticationEntryPoint, AccessDeniedHandler {

    /**
     * 处理未认证异常（访问需要认证的接口但未携带令牌）
     */
    @Override
    public void commence(HttpServletRequest request,
                         HttpServletResponse response,
                         AuthenticationException authException) throws IOException {
        log.error("未认证异常: {}", authException.getMessage());
        // 返回 JSON 响应
        response.setStatus(HttpStatus.UNAUTHORIZED.value());
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding(StandardCharsets.UTF_8.name());
        response.getWriter().write("{\"code\":401,\"msg\":\"请先登录\",\"data\":null}");
    }

    /**
     * 处理权限不足异常（已认证但无权限）
     */
    @Override
    public void handle(HttpServletRequest request,
                       HttpServletResponse response,
                       AccessDeniedException accessDeniedException) throws IOException {
        log.error("权限不足异常: {}", accessDeniedException.getMessage());
        response.setStatus(HttpStatus.FORBIDDEN.value());
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding(StandardCharsets.UTF_8.name());
        response.getWriter().write("{\"code\":403,\"msg\":\"权限不足\",\"data\":null}");
    }
}
```

> .exceptionHandling(ex -> ex
>         .authenticationEntryPoint(customAuthExceptionHandler) // 未认证异常
>         .accessDeniedHandler(customAuthExceptionHandler) // 权限不足异常
> )
> ```

## 四、业务层实现（测试验证）

### 1. 登录接口（生成 JWT 令牌）

```java
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

/**
 * 认证接口
 */
@Slf4j
@RestController
@RequestMapping("/api/auth")
@RequiredArgsConstructor
public class AuthController {

    private final AuthenticationManager authenticationManager;
    private final JwtTokenUtil jwtTokenUtil;
    private final CustomUserDetailsService userDetailsService;

    /**
     * 登录接口（无需认证）
     */
    @PostMapping("/login")
    public String login(@RequestBody LoginRequest request) {
        // 1. 手动认证（用户名+密码）
        Authentication authentication = authenticationManager.authenticate(
                new UsernamePasswordAuthenticationToken(request.getUsername(), request.getPassword())
        );

        // 2. 加载用户详情
        UserDetails userDetails = userDetailsService.loadUserByUsername(request.getUsername());

        // 3. 生成 JWT 令牌
        String token = jwtTokenUtil.generateToken(userDetails);

        // 4. 返回令牌（客户端需存储，后续请求携带）
        return JwtConstants.TOKEN_PREFIX + token;
    }

    // 登录请求参数
    public static class LoginRequest {
        private String username;
        private String password;

        // getter/setter
        public String getUsername() {
            return username;
        }

        public void setUsername(String username) {
            this.username = username;
        }

        public String getPassword() {
            return password;
        }

        public void setPassword(String password) {
            this.password = password;
        }
    }
}
```

## 六、关键扩展与最佳实践

### 1. 扩展用户数据

如果需要存储更多用户信息（如手机号、部门ID），只需：

1. 在 `CustomUserDetails` 中添加对应字段；
2. 在 `CustomUserDetailsService` 中加载这些字段；
3. 在 `UserContextHolder` 中添加获取方法。

### 2. 令牌刷新（可选）

生产环境需实现令牌刷新逻辑：

- 客户端检测令牌即将过期时，调用刷新接口；
- 服务端验证旧令牌有效性，生成新令牌返回。

### 3. 多线程场景获取用户

如果在异步线程中获取用户信息，需手动传递 `SecurityContext`：

```java
// 主线程获取 SecurityContext
SecurityContext context = SecurityContextHolder.getContext();

// 异步线程中设置
CompletableFuture.runAsync(() -> {
    SecurityContextHolder.setContext(context);
    // 异步线程中获取用户信息
    Long userId = UserContextHolder.getCurrentUserId();
    log.info("异步线程获取用户ID：{}", userId);
});
```

### 4. 生产环境注意事项

- JWT 密钥需配置在环境变量/配置中心，避免硬编码；
- 令牌过期时间不宜过长，建议 1-2 小时；
- 敏感接口需结合 HTTPS 传输；
- 可添加令牌黑名单（如用户登出时，将令牌加入黑名单）。

### 总结

1. **全局认证核心**：
   - 基于 Spring Security + JWT 实现无状态全局认证，通过 `JwtAuthenticationFilter` 拦截所有请求验证令牌；
   - 配置 `SecurityConfig` 定义全局认证规则（放行登录接口，其余需认证）；
   - 认证通过后，用户信息存入 `SecurityContextHolder`（ThreadLocal 存储，线程隔离）。

2. **全局用户数据获取**：
   - 封装 `UserContextHolder` 工具类，基于 `SecurityContextHolder` 提供统一的用户信息获取方法；
   - 可在 Controller、Service、工具类等任意层调用，无需手动传递用户参数；
   - 扩展 `CustomUserDetails` 可存储更多用户自定义字段。

3. **关键特性**：
   - 无状态认证：无需 Session，支持分布式部署；
   - 可扩展：轻松添加用户字段、调整认证规则；
   - 安全性：密码加密存储，令牌签名验证，异常统一处理。

这套方案是 Spring Boot 中全局认证和用户数据管理的标准实现，适配绝大多数业务场景，兼具安全性和易用性。
