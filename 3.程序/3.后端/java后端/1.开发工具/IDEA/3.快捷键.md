# IDEA 快捷键 + 代码模板大全（精简版）

## 一、基础编辑快捷键（通用高频）

| 快捷键（Win/Linux） | 功能 |
|---------------------|------|
| Ctrl+C/V/X/Z/Y      | 复制/粘贴/剪切/撤销/重做 |
| Ctrl+D              | 复制当前行/选中内容到下一行 |
| Ctrl+Y              | 删除当前行（Mac用Cmd+Backspace） |
| Ctrl+/              | 单行注释（//），再次按取消 |
| Ctrl+Shift+/        | 块注释（/**/），再次按取消 |
| Ctrl+Alt+L          | 格式化代码（全局/选中部分） |
| Ctrl+Alt+O          | 优化导入（删除无用包、排序） |
| Alt+Enter           | 万能修复键（导包/改语法/修错误） |
| Tab/Shift+Tab       | 缩进/反缩进当前行/选中内容 |

## 二、代码模板（Live Template）快捷键（核心补充）

所有模板均为「输入缩写 + Tab」触发，以下是开发高频模板：

### Java 专属模板

| 缩写 | 触发后生成代码 | 适用场景 |
|------|----------------|----------|
| sout | System.out.println(); | 快速打印内容（光标定位括号内） |
| soutv | System.out.println("变量名 = " + 变量); | 打印变量名+值（自动识别当前变量） |
| soutp | System.out.println("参数名 = " + 参数); | 打印方法参数名+值 |
| soutm | System.out.println("类名.方法名()"); | 打印当前方法名（调试定位） |
| psvm | public static void main(String[] args) {} | 快速生成main方法 |
| main | 同psvm（别名） | 兼容不同输入习惯 |
| fori | for (int i = 0; i < 长度; i++) {} | 普通for循环（自动补全长度变量） |
| iter | for (元素类型 变量 : 集合) {} | 增强for循环（遍历集合/数组） |
| ifn | if (对象 == null) {} | 判断对象为空 |
| inn | if (对象 != null) {} | 判断对象非空 |
| tryc | try {<br>  // 代码<br>} catch (Exception e) {<br>  e.printStackTrace();<br>} | 快速生成try-catch块 |
| psf | public static final | 快速定义公共静态常量 |
| prsf | private static final | 快速定义私有静态常量 |
| thr | throw new RuntimeException(); | 快速抛出运行时异常 |

### 通用/跨语言模板

| 缩写 | 触发后生成代码 | 适用场景 |
|------|----------------|----------|
| todo | // TODO: 待办事项 | 标记待办（支持全局搜索TODO） |
| fixme | // FIXME: 需要修复 | 标记需修复的问题 |
| null | null | 快速输入null（避免手动拼写） |
| true/false | true/false | 快速输入布尔值 |

## 三、查找替换 & 代码导航快捷键

| 快捷键（Win/Linux） | 功能 |
|---------------------|------|
| Ctrl+F/R            | 本文件查找/替换 |
| Ctrl+Shift+F/R      | 全局查找/全局替换 |
| Double Shift        | 全局万能搜索（文件/类/方法/功能） |
| Ctrl+N              | 快速查找类（模糊匹配） |
| Ctrl+Shift+N        | 快速查找任意文件（xml/yml等） |
| Ctrl+左键点击       | 跳转到符号（类/方法/变量）定义处 |
| Alt+Left/Right      | 回退/前进到上一/下一光标位置 |
| Alt+7               | 打开文件结构（查看类的方法/变量） |
| Alt+F7              | 查找当前符号的所有用法 |

## 四、代码生成 & 重构快捷键

| 快捷键（Win/Linux） | 功能 |
|---------------------|------|
| Alt+Insert          | 代码生成菜单（get/set/构造器/toString等） |
| Ctrl+Alt+T          | 环绕代码（if/for/try-catch/同步块等） |
| Shift+F6            | 重命名（类/方法/变量，全局同步） |
| Ctrl+Alt+M          | 提取方法（封装选中代码为方法） |
| Ctrl+Alt+V          | 提取变量（将表达式赋值给新变量） |
| Ctrl+O/I            | 重写父类方法/实现接口方法 |

## 五、运行调试快捷键

| 快捷键（Win/Linux） | 功能 |
|---------------------|------|
| Shift+F10           | 运行当前类/最近运行的程序 |
| Shift+F9            | 调试当前类/方法 |
| F8                  | 调试步过（不进入子方法） |
| F7                  | 调试步入（进入子方法） |
| F9                  | 调试继续执行（跳转到下一个断点） |
| Ctrl+F8             | 切换当前行断点（添加/删除） |
| Alt+4               | 快速切换到控制台（查看打印输出） |

## 六、窗口 & 版本控制快捷键

| 快捷键（Win/Linux） | 功能 |
|---------------------|------|
| Alt+1-9             | 切换对应数字的侧边栏（1=项目结构） |
| Ctrl+Tab            | 循环切换打开的标签页 |
| Ctrl+Alt+S          | 打开IDEA全局设置 |
| Ctrl+K              | Git提交代码到本地仓库 |
| Ctrl+T              | Git从远程拉取代码 |
| Ctrl+Shift+K        | Git推送代码到远程仓库 |

### 总结

1. 代码模板核心用法：输入缩写（如`sout`/`psvm`）+ `Tab`，是生成重复代码最高效的方式；
2. 万能快捷键：`Alt+Enter`（修复问题）、`Double Shift`（全局搜索）、`Ctrl+Alt+L`（格式化）；
3. 调试/打印核心：`Shift+F10`（运行）、`sout+Tab`（生成打印语句）、`Alt+4`（查看控制台输出）。
