# 实战

1. 时间字段格式的自动转换配置

```java
@JsonFormat(timezone = "GMT+8", pattern = "yyyy-MM-dd HH:mm:ss")  //在 RESTful API 接口中，处理 JSON 格式的数据传输
@DateTimeFormat(pattern = "yyyy-MM-dd HH:mm:ss") //在处理表单提交、URL 参数等非 JSON 格式的日期时间参数
private LocalDateTime visitTime;
```
