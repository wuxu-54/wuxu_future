# 常用功能记录

## web

### 本地配置选择组件

在BasicForm的 data数据 中配置, 实现本地的选择器：

```ts
{
    label: '随访形式',
    field: 'followUpForm',
    component: 'Select',
    defaultValue: '院内随访', // 提交给后端的值
    componentProps: {
      options: [
        { label: '院内随访', value: '院内随访' },
        { label: '社区沙龙', value: '社区沙龙' },
        { label: '居民活动', value: '居民活动' },
        { label: '药店活动', value: '药店活动' },
        { label: '线上访谈', value: '线上访谈' },
        { label: '面对面访谈', value: '面对面访谈' },
      ],
      placeholder: '请选择解决方案',
    },
    dynamicRules: ({ model, schema }) => {
      return [
        { required: true, message: '请输入解决方案!' },
      ];
    },
  },
```

### 树状选择（加载远程数据）

解释：

`dict`：`prod_rel_product_info`  是数据库名，`product_name`是展示的字段，`id` 是上传的字段
`pidField`: 配置父级字段 `pid`
`hasChildField`: 判断是否有子节点

```ts
 {
    label: '我司产品',
    field: 'ourProduct',
    component: 'JTreeSelect',
    componentProps: {
      treeCheckable:true,
      dict: "prod_rel_product_info,product_name,id",
      pidField: "pid",
      pidValue: "0",
      hasChildField: "has_child",
      multiple: true,
      maxTagCount: 'responsive',
      checkStrictly: false,      
      showCheckedStrategy: 2,
      showSearch: true,              // 开启搜索框
      treeNodeFilterProp: 'title',   // 搜索时匹配节点的 title 属性（JTreeSelect 会将 dict 中的 text 字段映射为 title）
      placeholder: '请输入产品名称搜索', // 搜索框占位符
    },
    dynamicRules: ({model,schema}) => {
          return [
                 { required: true, message: '请输入目标产品!'},
          ];
     },
},
```

### 两种图片上传方式

方式一： 文件上传，增加fileType限制为图片

```ts
  {
    label: '现场照片',
    field: 'photoUrl',
    component: 'JUpload',
    componentProps: {
      // 配置上传参数
      fileMaxSize: 10, // 文件最大10MB
      maxNumber: 5,    // 最多上传5张图片
      fileType: 'image', // 限制只上传图片
      imageWidth: 800,  // 图片预览宽度
      imageHeight: 600, // 图片预览高度
    },
  },
```

方式二：JImageUpload 图片上传组件

```ts
  {
    label: '患者签名',
    field: 'patientSignature',
    component: 'JImageUpload',
    componentProps: {
      fileMax: 0
    },
  },
```
