# 开发实记

- 可以使用online建数据库表，并快速生成前后端代码。但注意，使用时需要在菜单配置为本地路径，同时需要修改`sys_permission`表对应的component字段改为正确views下的路径。 还有个特别的点，子菜单，必须将  `是否为路由开关` 打开，否则不会在前端注册进入路由地址，访问不到。
- 自己配置数据字典时，别忘了在字段上添加注解，比如：`@Dict(dicCode = "product_type")`，否则不会返回字典code对应的名称
- 前端配置模糊查询，后端需要在查询接口处添加支持模糊匹配的查询配置：

    ```java
    查询接口：{
        // 自定义查询规则
        Map<String, QueryRuleEnum> customeRuleMap = new HashMap<>(); //主要是这个配置，支持两个参数可以模糊查询
        // 自定义多选的查询规则为：LIKE_WITH_OR
        customeRuleMap.put("partyA", QueryRuleEnum.LIKE_WITH_OR); 
        customeRuleMap.put("partyB", QueryRuleEnum.LIKE_WITH_OR);

        QueryWrapper<CoopAgreementInfo> queryWrapper = QueryGenerator.initQueryWrapper(coopAgreementInfo, req.getParameterMap(),customeRuleMap);
		Page<CoopAgreementInfo> page = new Page<CoopAgreementInfo>(pageNo, pageSize);
		IPage<CoopAgreementInfo> pageList = coopAgreementInfoService.page(page, queryWrapper);
		return Result.OK(pageList);
	}
	```
