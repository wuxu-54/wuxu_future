## 项目文件上传机制说明

根据代码分析，这个项目采用了**统一的多存储方式文件上传架构**，支持三种存储方式：

### 📋 **1. 支持的存储类型**

项目通过配置项 `jeecg.uploadType` 控制上传方式：

- **local** - 本地文件存储（你当前需要的）
- **minio** - MinIO对象存储
- **alioss** - 阿里云OSS存储

### 🎯 **2. 推荐使用的上传接口**

#### **主上传接口（推荐使用）**

```
POST /sys/common/upload
```

**位置**: `CommonController.java` (第66行)

**特点**：

- ✅ 统一的上传入口
- ✅ 自动根据配置选择存储方式
- ✅ 包含文件安全校验
- ✅ 支持自定义业务路径（biz参数）

**调用示例**：

```java
// 前端调用
POST /sys/common/upload?biz=images
Content-Type: multipart/form-data

file: [图片文件]
```

**返回结果**：

```json
{
  "success": true,
  "message": "images/filename_1234567890.jpg",
  "code": 200
}
```

### 🔧 **3. 核心实现逻辑**

#### **上传流程**（CommonController.upload方法）：

```java
@PostMapping(value = "/upload")
public Result<?> upload(HttpServletRequest request, HttpServletResponse response) {
    String bizPath = request.getParameter("biz"); // 获取业务路径
    MultipartFile file = multipartRequest.getFile("file");
    
    // 1. 文件安全校验（防止上传漏洞文件）
    SsrfFileTypeFilter.checkUploadFileType(file, bizPath);
    
    // 2. 根据配置选择上传方式
    if(CommonConstant.UPLOAD_TYPE_LOCAL.equals(uploadType)){
        savePath = this.uploadLocal(file, bizPath); // 本地存储
    } else {
        savePath = CommonUtils.upload(file, bizPath, uploadType); // MinIO或OSS
    }
    
    return result;
}
```

#### **本地存储实现**（uploadLocal方法，第108-144行）：

```java
private String uploadLocal(MultipartFile mf, String bizPath){
    String ctxPath = uploadpath; // 从配置文件读取
    
    // 1. 创建目录
    File file = new File(ctxPath + File.separator + bizPath);
    if (!file.exists()) {
        file.mkdirs();
    }
    
    // 2. 生成文件名（原文件名_时间戳.扩展名）
    String orgName = mf.getOriginalFilename();
    String fileName = orgName.substring(0, orgName.lastIndexOf(".")) 
                      + "_" + System.currentTimeMillis() 
                      + orgName.substring(orgName.lastIndexOf("."));
    
    // 3. 保存文件
    String savePath = file.getPath() + File.separator + fileName;
    FileCopyUtils.copy(mf.getBytes(), savefile);
    
    // 4. 返回相对路径（如：images/abc_1234567890.jpg）
    return dbpath;
}
```

### 📁 **4. 文件访问方式**

上传后的文件通过以下URL访问：

```
GET /sys/common/static/{相对路径}
```

**示例**：

```
上传返回: images/photo_1712345678901.jpg
访问地址: http://localhost:8080/sys/common/static/images/photo_1712345678901.jpg
```

**实现位置**: `CommonController.view()` 方法（第190-234行）

### ⚙️ **5. 配置项说明**

在 `application.yml` 中配置：

```yaml
jeecg:
  # 上传类型：local（本地）、minio、alioss
  uploadType: local
  
  path:
    # 本地上传根路径
    upload: /opt/jeecg-boot/upload
```

---

### 🛡️ **6. 安全特性**

项目内置了多重安全防护：

1. **文件类型校验** - `SsrfFileTypeFilter.checkUploadFileType()`
   - 检查文件扩展名
   - 检查文件魔数（Magic Number）
   - 防止上传恶意文件

2. **路径攻击防护** - `StrAttackFilter.filter()`
   - 过滤特殊字符
   - 防止目录穿越攻击

3. **文件名处理** - `CommonUtils.getFileName()`
   - 移除危险字符
   - 添加时间戳避免重名

### 📝 **8. 实际使用建议**

**对于你的图片上传需求**：

1. **直接使用主接口** `/sys/common/upload?biz=images`
2. **配置本地存储**：确保 `jeecg.uploadType=local`
3. **设置上传目录**：配置 `jeecg.path.upload`
4. **访问图片**：通过 `/sys/common/static/` + 返回的相对路径

**前端调用示例**：

```javascript
const formData = new FormData();
formData.append('file', imageFile);

fetch('/sys/common/upload?biz=activity_images', {
  method: 'POST',
  body: formData
})
.then(res => res.json())
.then(data => {
  if (data.success) {
    const imageUrl = '/sys/common/static/' + data.message;
    console.log('图片地址:', imageUrl);
  }
});
```

### 🔄 **9. 未来迁移到阿里云OSS**

当需要切换到阿里云OSS时，只需：

1. 修改配置：`jeecg.uploadType=alioss`
2. 配置OSS信息：

```yaml
jeecg:
  oss:
    endpoint: oss-cn-hangzhou.aliyuncs.com
    accessKeyId: xxx
    accessKeySecret: xxx
    bucketName: your-bucket
```

**无需修改任何业务代码**，系统会自动切换到OSS存储！
