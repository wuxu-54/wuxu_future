# MySQL命令大全

覆盖从基础连接到高级管理的各类核心操作，方便你查阅和实际使用。下面我会按**功能模块**整理，每个命令都包含**语法格式**、**示例**和**核心说明**，兼顾新手易懂性和实用性：

---

## 一、基础连接与退出命令

### 1. 连接MySQL服务器

```bash
# 基础格式（推荐，密码交互式输入更安全）
mysql -h [主机地址] -P [端口] -u [用户名] -p

# 示例1：连接本地MySQL（默认主机localhost，端口3306）
mysql -u root -p

# 示例2：连接远程MySQL（主机192.168.1.100，端口3307）
mysql -h 192.168.1.100 -P 3307 -u root -p

# 非交互式（密码直接写，不推荐生产环境）
mysql -h localhost -u root -p123456
```

**说明**：

- `-h`：指定MySQL服务器主机（本地可省略，默认`localhost`）
- `-P`：指定端口（默认3306，大写P区分小写p（密码））
- `-u`：指定登录用户名
- `-p`：后接密码（无空格），单独写`-p`会提示输入密码（更安全）

### 2. 退出MySQL客户端

```sql
# 方式1（推荐）
exit;

# 方式2
quit;

# 方式3
\q;
```

### 3. 执行外部SQL文件

```bash
# 终端执行（未登录时）
mysql -u root -p 数据库名 < /path/to/your/sql/file.sql

# MySQL客户端内执行
source /path/to/your/sql/file.sql;
# 等价写法
\. /path/to/your/sql/file.sql;
```

## 二、数据库（Database）操作

### 1. 查看所有数据库

```sql
SHOW DATABASES;
```

**说明**：列出MySQL中所有已创建的数据库（含系统库如`mysql`、`information_schema`）。

### 2. 创建数据库

```sql
# 基础格式
CREATE DATABASE [IF NOT EXISTS] 数据库名 [CHARACTER SET 字符集] [COLLATE 校对规则];

# 示例1：创建默认字符集的数据库
CREATE DATABASE test_db;

# 示例2：避免重复创建+指定UTF8字符集（推荐）
CREATE DATABASE IF NOT EXISTS test_db 
CHARACTER SET utf8mb4  # 支持emoji，比utf8更完整
COLLATE utf8mb4_unicode_ci;  # 不区分大小写的校对规则
```

**说明**：

- `IF NOT EXISTS`：避免数据库已存在时报错
- `utf8mb4`：MySQL中真正的UTF-8（原生`utf8`仅支持3字节，不兼容emoji）

### 3. 切换当前数据库

```sql
USE 数据库名;

# 示例：切换到test_db
USE test_db;
```

**说明**：后续操作默认针对该数据库，等价于连接时指定数据库名。

### 4. 查看当前数据库

```sql
SELECT DATABASE();
```

### 5. 修改数据库

```sql
# 修改字符集和校对规则
ALTER DATABASE 数据库名 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_general_ci;

# 示例：修改test_db的字符集
ALTER DATABASE test_db CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

### 6. 删除数据库

```sql
DROP DATABASE [IF EXISTS] 数据库名;

# 示例：删除test_db（避免不存在时报错）
DROP DATABASE IF EXISTS test_db;
```

**警告**：删除不可逆，生产环境务必谨慎！

## 三、数据表（Table）操作

### 1. 查看当前数据库的所有表

```sql
SHOW TABLES;
```

### 2. 查看表结构

```sql
# 方式1（简洁）
DESC 表名;
DESCRIBE 表名;

# 方式2（详细，含索引、注释等）
SHOW CREATE TABLE 表名;

# 示例：查看user表结构
DESC user;
SHOW CREATE TABLE user;
```

### 3. 创建数据表

```sql
# 基础格式
CREATE TABLE [IF NOT EXISTS] 表名 (
    字段名1 数据类型 [约束条件] [COMMENT '注释'],
    字段名2 数据类型 [约束条件] [COMMENT '注释'],
    ...
    [PRIMARY KEY (主键字段)],
    [UNIQUE KEY (唯一索引字段)],
    [FOREIGN KEY (外键字段) REFERENCES 关联表(关联字段)]
) [ENGINE=存储引擎] [CHARACTER SET 字符集] [COMMENT '表注释'];

# 示例：创建用户表
CREATE TABLE IF NOT EXISTS user (
    id INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID（主键）',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(100) NOT NULL COMMENT '密码（加密存储）',
    age TINYINT UNSIGNED DEFAULT 0 COMMENT '年龄',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户信息表';
```

**关键说明**：

- `INT UNSIGNED`：无符号整数（非负）
- `AUTO_INCREMENT`：自增（仅用于主键）
- `NOT NULL`：非空约束
- `DEFAULT`：默认值
- `ENGINE=InnoDB`：主流存储引擎（支持事务、外键）
- `CURRENT_TIMESTAMP`：默认当前时间

### 4. 修改数据表

#### （1）添加字段

```sql
ALTER TABLE 表名 ADD [COLUMN] 字段名 数据类型 [约束] [COMMENT '注释'] [AFTER 已有字段];

# 示例：给user表添加email字段（在username后）
ALTER TABLE user ADD COLUMN email VARCHAR(100) UNIQUE COMMENT '邮箱' AFTER username;
```

#### （2）修改字段

```sql
# 修改字段类型/约束
ALTER TABLE 表名 MODIFY [COLUMN] 字段名 新数据类型 [新约束];

# 修改字段名+类型
ALTER TABLE 表名 CHANGE [COLUMN] 旧字段名 新字段名 新数据类型 [约束];

# 示例1：修改age字段为允许空
ALTER TABLE user MODIFY age TINYINT UNSIGNED NULL;

# 示例2：将email改名为user_email，类型改为VARCHAR(120)
ALTER TABLE user CHANGE email user_email VARCHAR(120) UNIQUE COMMENT '用户邮箱';
```

#### （3）删除字段

```sql
ALTER TABLE 表名 DROP [COLUMN] 字段名;

# 示例：删除user表的age字段
ALTER TABLE user DROP COLUMN age;
```

#### （4）修改表名

```sql
ALTER TABLE 旧表名 RENAME TO 新表名;

# 示例：将user表改名为t_user
ALTER TABLE user RENAME TO t_user;
```

### 5. 删除数据表

```sql
DROP TABLE [IF EXISTS] 表名1, 表名2...;

# 示例：删除t_user表
DROP TABLE IF EXISTS t_user;
```

### 6. 复制数据表

```sql
# 复制表结构+数据
CREATE TABLE 新表名 LIKE 原表名;  # 仅复制结构
INSERT INTO 新表名 SELECT * FROM 原表名;  # 复制数据

# 简化版（复制结构+数据，不含索引/约束）
CREATE TABLE 新表名 AS SELECT * FROM 原表名;

# 示例：复制user表为user_backup
CREATE TABLE user_backup LIKE user;
INSERT INTO user_backup SELECT * FROM user;
```

## 四、数据操作（DML：增删改查）

### 1. 插入数据（INSERT）

```sql
# 方式1：指定字段插入
INSERT INTO 表名 (字段1, 字段2, ...) VALUES (值1, 值2, ...);

# 方式2：插入多条数据
INSERT INTO 表名 (字段1, 字段2) VALUES 
(值1, 值2),
(值3, 值4);

# 方式3：省略字段（按表字段顺序插入，不推荐）
INSERT INTO 表名 VALUES (值1, 值2, ...);

# 示例：插入一条用户数据
INSERT INTO user (username, password, email) 
VALUES ('zhangsan', 'e10adc3949ba59abbe56e057f20f883e', 'zhangsan@test.com');

# 示例：插入多条
INSERT INTO user (username, password) 
VALUES ('lisi', '123456'), ('wangwu', '654321');
```

### 2. 查询数据（SELECT，核心）

```sql
# 基础格式
SELECT [DISTINCT] 字段1, 字段2, ...  # DISTINCT去重
FROM 表名
[WHERE 条件]  # 行筛选
[GROUP BY 分组字段]  # 分组
[HAVING 分组后条件]  # 分组筛选（区别于WHERE）
[ORDER BY 排序字段 [ASC/DESC]]  # 排序
[LIMIT 偏移量, 条数];  # 分页

# 示例1：查询所有字段
SELECT * FROM user;

# 示例2：查询指定字段+去重
SELECT DISTINCT username FROM user;

# 示例3：带条件查询（年龄>18，用户名含'zhang'）
SELECT id, username FROM user WHERE age > 18 AND username LIKE '%zhang%';

# 示例4：分组统计（按年龄分组，统计每组人数）
SELECT age, COUNT(*) AS total FROM user GROUP BY age HAVING total > 5;

# 示例5：排序+分页（按创建时间降序，取第2页，每页10条）
SELECT * FROM user ORDER BY create_time DESC LIMIT 10, 10;

# 示例6：多表联查（INNER JOIN）
SELECT u.username, o.order_no 
FROM user u
INNER JOIN order o ON u.id = o.user_id
WHERE u.age > 20;
```

**常用条件运算符**：

- 比较：`=`、`!=`、`<`、`>`、`<=`、`>=`
- 模糊匹配：`LIKE`（`%`通配任意字符，`_`通配单个字符）
- 范围：`IN (值1,值2)`、`BETWEEN 最小值 AND 最大值`
- 空值：`IS NULL`、`IS NOT NULL`

### 3. 更新数据（UPDATE）

```sql
UPDATE 表名 SET 字段1=值1, 字段2=值2 [WHERE 条件];

# 示例：更新zhangsan的密码
UPDATE user SET password='888888' WHERE username='zhangsan';

# 示例：批量更新（年龄+1）
UPDATE user SET age=age+1 WHERE age < 30;
```

**警告**：无WHERE条件会更新全表数据，务必谨慎！

### 4. 删除数据（DELETE）

```sql
DELETE FROM 表名 [WHERE 条件];

# 示例：删除用户名是lisi的记录
DELETE FROM user WHERE username='lisi';

# 清空表（保留表结构，自增重置）
TRUNCATE TABLE 表名;  # 比DELETE更快，不可回滚
```

**区别**：

- `DELETE`：可带条件，支持事务回滚，自增不重置
- `TRUNCATE`：清空全表，不可回滚，自增重置为1

## 五、索引操作

### 1. 创建索引

```sql
# 主键索引（创建表时已指定，也可单独加）
ALTER TABLE 表名 ADD PRIMARY KEY (字段名);

# 唯一索引（值唯一，可含NULL）
CREATE UNIQUE INDEX 索引名 ON 表名(字段名);
ALTER TABLE 表名 ADD UNIQUE KEY 索引名(字段名);

# 普通索引（无唯一性约束）
CREATE INDEX 索引名 ON 表名(字段名);
ALTER TABLE 表名 ADD INDEX 索引名(字段名);

# 复合索引（多个字段）
CREATE INDEX idx_user_age_create ON user(age, create_time);

# 示例：给user表的email加唯一索引
CREATE UNIQUE INDEX idx_user_email ON user(email);
```

### 2. 查看索引

```sql
# 查看表的所有索引
SHOW INDEX FROM 表名;
SHOW KEYS FROM 表名;

# 示例：查看user表索引
SHOW INDEX FROM user;
```

### 3. 删除索引

```sql
# 删除普通/唯一索引
DROP INDEX 索引名 ON 表名;

# 删除主键索引
ALTER TABLE 表名 DROP PRIMARY KEY;

# 示例：删除idx_user_email索引
DROP INDEX idx_user_email ON user;
```

## 六、用户与权限管理

### 1. 创建用户

```sql
CREATE USER [IF NOT EXISTS] '用户名'@'主机' IDENTIFIED BY '密码';

# 示例1：创建本地用户（仅允许localhost登录）
CREATE USER 'test_user'@'localhost' IDENTIFIED BY '123456';

# 示例2：创建远程用户（允许任意主机登录，%通配）
CREATE USER 'test_user'@'%' IDENTIFIED BY '123456';
```

**主机说明**：

- `localhost`：仅本地登录
- `%`：任意远程主机
- `192.168.1.%`：指定网段

### 2. 授权

```sql
# 基础格式
GRANT 权限1,权限2 ON 数据库.表 TO '用户名'@'主机' [WITH GRANT OPTION];

# 示例1：授予test_user对test_db所有表的增删改查权限
GRANT SELECT, INSERT, UPDATE, DELETE ON test_db.* TO 'test_user'@'%';

# 示例2：授予所有权限（仅管理员）
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%';

# 示例3：授予仅查询指定表的权限
GRANT SELECT ON test_db.user TO 'test_user'@'localhost';

# 刷新权限（授权后必须执行）
FLUSH PRIVILEGES;
```

**常用权限**：

- `SELECT`：查询
- `INSERT`：插入
- `UPDATE`：更新
- `DELETE`：删除
- `CREATE`：创建库/表
- `DROP`：删除库/表
- `ALL PRIVILEGES`：所有权限

### 3. 查看用户权限

```sql
# 查看当前用户权限
SHOW GRANTS;

# 查看指定用户权限
SHOW GRANTS FOR '用户名'@'主机';

# 示例：查看test_user的权限
SHOW GRANTS FOR 'test_user'@'%';
```

### 4. 修改用户密码

```sql
# 方式1（MySQL 5.7+）
ALTER USER '用户名'@'主机' IDENTIFIED BY '新密码';

# 方式2（通用）
SET PASSWORD FOR '用户名'@'主机' = PASSWORD('新密码');

# 示例：修改test_user的密码为654321
ALTER USER 'test_user'@'%' IDENTIFIED BY '654321';
FLUSH PRIVILEGES;
```

### 5. 撤销权限

```sql
REVOKE 权限 ON 数据库.表 FROM '用户名'@'主机';

# 示例：撤销test_user的删除权限
REVOKE DELETE ON test_db.* FROM 'test_user'@'%';
FLUSH PRIVILEGES;
```

### 6. 删除用户

```sql
DROP USER [IF EXISTS] '用户名'@'主机';

# 示例：删除test_user
DROP USER IF EXISTS 'test_user'@'%';
```

## 七、备份与恢复

### 1. 备份（mysqldump，终端执行）

```bash
# 备份单个数据库
mysqldump -u root -p 数据库名 > 备份文件名.sql

# 备份多个数据库
mysqldump -u root -p --databases 库1 库2 > 备份文件名.sql

# 备份所有数据库
mysqldump -u root -p --all-databases > 全库备份.sql

# 备份指定表
mysqldump -u root -p 数据库名 表1 表2 > 表备份.sql

# 示例：备份test_db到test_db_20260116.sql
mysqldump -u root -p test_db > test_db_20260116.sql
```

### 2. 恢复（终端执行）

```bash
# 方式1：未登录时恢复
mysql -u root -p 数据库名 < 备份文件名.sql

# 方式2：登录后恢复
source /path/to/备份文件名.sql;

# 示例：恢复test_db
mysql -u root -p test_db < test_db_20260116.sql
```

## 八、系统信息与运维命令

### 1. 查看MySQL版本

```sql
SELECT VERSION();
# 终端执行
mysql --version
```

### 2. 查看当前用户

```sql
SELECT USER();
```

### 3. 查看数据库大小

```sql
# 查看所有数据库大小
SELECT 
    table_schema AS '数据库名',
    SUM(data_length + index_length) / 1024 / 1024 AS '大小(MB)'
FROM information_schema.TABLES 
GROUP BY table_schema;

# 查看指定数据库大小
SELECT 
    SUM(data_length + index_length) / 1024 / 1024 AS '大小(MB)'
FROM information_schema.TABLES 
WHERE table_schema = 'test_db';
```

### 4. 查看进程/杀死进程

```sql
# 查看所有连接进程
SHOW PROCESSLIST;

# 杀死指定进程（解决锁表/慢查询）
KILL 进程ID;

# 示例：杀死ID为123的进程
KILL 123;
```

### 5. 查看慢查询日志

```sql
# 查看慢查询配置
SHOW VARIABLES LIKE '%slow_query%';
SHOW VARIABLES LIKE 'long_query_time';  # 慢查询阈值（默认10秒）

# 开启慢查询日志（临时生效）
SET GLOBAL slow_query_log = ON;
SET GLOBAL long_query_time = 1;  # 阈值改为1秒
```

### 6. 优化表

```sql
# 优化表（整理碎片，仅InnoDB/MyISAM）
OPTIMIZE TABLE 表名;

# 示例：优化user表
OPTIMIZE TABLE user;
```

## 九、事务与锁

### 1. 事务操作

```sql
# 开启事务
START TRANSACTION;
# 等价
BEGIN;

# 提交事务
COMMIT;

# 回滚事务（撤销未提交的修改）
ROLLBACK;

# 示例：转账事务（保证原子性）
START TRANSACTION;
UPDATE account SET balance = balance - 100 WHERE id = 1;
UPDATE account SET balance = balance + 100 WHERE id = 2;
COMMIT;  # 成功则提交
# 失败则执行 ROLLBACK;
```

### 2. 锁表

```sql
# 读锁（共享锁，允许读，禁止写）
LOCK TABLES 表名 READ;

# 写锁（排他锁，禁止其他所有操作）
LOCK TABLES 表名 WRITE;

# 解锁
UNLOCK TABLES;
```

### 总结

1. **核心分类**：MySQL命令可分为「连接/退出」「库操作」「表操作」「数据操作（增删改查）」「索引」「权限」「备份恢复」「运维」「事务」9大类，覆盖从基础使用到高级管理。
2. **安全要点**：`DROP`（删库/表）、`UPDATE/DELETE`（无WHERE）、`TRUNCATE`等命令不可逆，生产环境务必先备份、加条件、测试验证。
3. **性能关键**：查询用`LIMIT`分页、给高频查询字段加索引、开启慢查询日志定位性能问题，是优化MySQL的核心手段。
4. **新手优先级**：先掌握「连接」「库/表创建」「SELECT/INSERT/UPDATE/DELETE」这4类基础命令，再逐步学习索引、事务、权限等进阶内容。
