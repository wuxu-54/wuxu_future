# 括号

在 Shell Script 中，括号（圆括号 `()`、方括号 `[]`、双括号 `[[]]`）和花括号 `{}` 的用法差异很大，分别用于**命令分组、条件判断、变量扩展、序列生成**等场景。以下是详细说明：

## 一、圆括号 `()` 的用法

圆括号在 Shell 中主要用于**创建子 Shell、分组命令、数组定义**等，核心特点是“隔离环境”（子 Shell 中的操作不影响当前 Shell）。

### 1. 子 Shell 中执行命令（分组）

- **作用**：将括号内的命令放入**子 Shell** 中执行，子 Shell 是当前 Shell 的副本，拥有独立的环境（变量、工作目录等），执行完毕后不影响当前 Shell。
- **语法**：`(命令1; 命令2; ...)`
- **示例**：

  ```bash
  # 子 Shell 中切换目录，不影响当前 Shell
  (cd /tmp; echo "子 Shell 目录: $(pwd)")
  echo "当前 Shell 目录: $(pwd)"  # 仍为原目录

  # 子 Shell 中定义变量，当前 Shell 不可见
  (name="子 Shell"; echo "子 Shell 变量: $name")
  echo "当前 Shell 变量: $name"  # 输出空（变量未定义）
  ```

### 2. 命令替换（`$()`）

- **作用**：将括号内的命令输出作为字符串替换到当前位置（等价于反引号 `` ` ` ``，但嵌套更方便）。
- **语法**：`$(` 命令 `)`
- **示例**：

  ```bash
  # 获取当前日期并赋值给变量
  today=$(date +%Y-%m-%d)
  echo "今天是: $today"

  # 嵌套使用（反引号难以实现）
  files_count=$(ls $(pwd) | wc -l)
  echo "当前目录文件数: $files_count"
  ```

### 3. 数组定义（Bash 支持）

- **作用**：在 Bash 中，用圆括号定义数组（元素用空格分隔）。
- **语法**：`数组名=(元素1 元素2 ...)`
- **示例**：

  ```bash
  fruits=(apple banana "cherry pie")
  echo "第一个元素: ${fruits[0]}"  # 输出 apple
  echo "所有元素: ${fruits[@]}"    # 输出 apple banana cherry pie
  ```

### 4. 算术扩展（配合 `$`）

- **作用**：在 `$((...))` 中执行算术运算（整数运算）。
- **语法**：`$(( 表达式 ))`
- **示例**：

  ```bash
  a=5
  b=3
  echo "和: $((a + b))"   # 输出 8
  echo "积: $((a * b))"   # 输出 15
  echo "自增: $((a++))"   # 输出 5（先使用后自增）
  ```

## 二、方括号 `[]` 的用法

方括号 `[]` 是 **`test` 命令的简写**，主要用于**条件测试**（判断文件属性、变量比较等），是 Shell 中最基础的条件判断工具。

### 核心特点：

- 本质是 `test` 命令的别名（`[ 条件 ]` 等价于 `test 条件`）。
- 语法严格：`[` 后和 `]` 前必须有**空格**，否则会报错。
- 支持的判断类型：文件测试、字符串测试、整数比较。
- 逻辑运算需用 `-a`（与）、`-o`（或），不能直接用 `&&`、`||`。

### 1. 文件测试

- 用于判断文件/目录的属性（存在性、类型、权限等）。

  ```bash
  file="test.txt"
  # 判断文件是否存在
  if [ -f "$file" ]; then
    echo "$file 是普通文件"
  fi

  # 判断目录是否存在
  if [ -d "/home" ]; then
    echo "/home 是目录"
  fi
  ```

  常用文件测试运算符：`-f`（普通文件）、`-d`（目录）、`-e`（存在）、`-r`（可读）、`-w`（可写）、`-x`（可执行）等。

### 2. 字符串测试

- 用于比较字符串是否相等、为空等。

  ```bash
  str1="hello"
  str2="world"

  # 字符串相等（=）和不等（!=）
  if [ "$str1" = "$str2" ]; then
    echo "相等"
  else
    echo "不等"  # 输出此结果
  fi

  # 字符串非空（-n）和空（-z）
  if [ -z "$empty_str" ]; then
    echo "字符串为空"
  fi
  ```

  注意：变量必须加引号（如 `"$str1"`），否则字符串含空格时会被解析为多个参数，导致错误。

### 3. 整数比较

- 用于比较整数大小（不能直接用 `>`、`<`，需用专用运算符）。

  ```bash
  num1=10
  num2=20

  # 等于（-eq）、不等于（-ne）、大于（-gt）、小于（-lt）、大于等于（-ge）、小于等于（-le）
  if [ $num1 -lt $num2 ]; then
    echo "$num1 小于 $num2"  # 输出此结果
  fi
  ```

### 4. 逻辑组合

- 用 `-a`（与）、`-o`（或）、`!`（非）组合多个条件。

  ```bash
  # 判断文件存在且可读
  if [ -f "test.txt" -a -r "test.txt" ]; then
    echo "文件存在且可读"
  fi

  # 判断变量非空且不等于 "no"
  if [ -n "$flag" -a "$flag" != "no" ]; then
    echo "条件满足"
  fi
  ```

## 三、双括号 `[[]]` 的用法

双括号 `[[]]` 是 **Bash 的扩展语法**（兼容 zsh、ksh 等），功能比 `[]` 更强大，主要用于**增强型条件测试**，语法更灵活。

### 核心优势：

- 支持 `&&`、`||` 等逻辑运算符（无需用 `-a`、`-o`）。
- 支持 `>`、`<` 等比较运算符（无需用 `-gt`、`-lt`）。
- 字符串比较时，变量可以不加引号（但建议加）。
- 支持正则匹配（`=~` 运算符）。
- 语法宽松：`[[` 后和 `]]` 前的空格要求不严格（但建议加）。

### 1. 整数比较（更简洁）

```bash
a=5
b=10
if [[ $a < $b ]]; then  # 直接用 < 代替 -lt
  echo "$a < $b"
fi
```

### 2. 逻辑组合（用 `&&`/`||`）

```bash
file="test.sh"
# 更直观的逻辑与（&&）
if [[ -f "$file" && -x "$file" ]]; then
  echo "$file 是可执行文件"
fi

# 逻辑或（||）
if [[ -z "$name" || "$name" = "default" ]]; then
  echo "使用默认名称"
fi
```

### 3. 正则匹配（`=~`）

```bash
email="user@example.com"
# 用正则判断邮箱格式（简化版）
if [[ $email =~ ^[a-zA-Z0-9]+@[a-zA-Z0-9]+\.[a-zA-Z]+$ ]]; then
  echo "邮箱格式正确"
fi
```

### 注意：

- `[[]]` 是 Bash 扩展，不兼容 POSIX 标准的 `sh` shell（如 `dash`），如果脚本开头是 `#!/bin/sh`，可能无法使用。
- 脚本中若需兼容所有 Shell，优先用 `[]`；若确定用 Bash（`#!/bin/bash`），推荐用 `[[]]` 更简洁。

## 四、花括号 `{}` 的用法

花括号在 Shell 中用途最广，主要用于**brace 展开、命令分组、变量扩展** 等，核心特点是“不创建子 Shell”（影响当前环境）。

### 1. Brace 展开（生成序列/字符串组合）

- **作用**：快速生成有规律的字符串序列（文件名、数字等），支持范围、列表、嵌套。
- **语法**：
  - 列表：`{字符串1,字符串2,...}`（生成多个字符串）
  - 范围：`{start..end}`（生成连续序列，数字/字母均可）
- **示例**：

  ```bash
  # 列表展开：生成多个文件名
  touch {a,b,c}.txt  # 创建 a.txt、b.txt、c.txt
  echo {hello,world}  # 输出 hello world

  # 范围展开：生成数字/字母序列
  echo {1..5}  # 输出 1 2 3 4 5
  echo {a..e}  # 输出 a b c d e
  echo {2023..2025}-{01..03}  # 输出 2023-01 2023-02 ... 2025-03

  # 嵌套展开
  echo {a{b,c},d}  # 输出 ab ac d
  ```

### 2. 命令分组（当前 Shell 中执行）

- **作用**：将多个命令视为一个整体执行，**在当前 Shell 中运行**（不创建子 Shell），会影响当前环境（如变量、目录）。
- **语法**：`{ 命令1; 命令2; ... }`（注意：`{` 后必须有空格，最后一个命令后必须加 `;`，`}` 前建议有空格）。
- **示例**：

  ```bash
  # 分组命令影响当前 Shell 的目录
  { cd /tmp; echo "分组内目录: $(pwd)"; }
  echo "当前目录: $(pwd)"  # 输出 /tmp（目录被改变）

  # 分组命令定义的变量在当前 Shell 可见
  { name="当前 Shell"; echo "分组内变量: $name"; }
  echo "当前 Shell 变量: $name"  # 输出 "当前 Shell"
  ```

  与 `()` 的区别：`()` 创建子 Shell（不影响当前环境），`{}` 在当前 Shell 执行（影响当前环境）。

### 3. 变量扩展（明确变量边界）

- **作用**：在变量名后接其他字符时，用 `{}` 明确变量边界，避免解析错误。
- **语法**：`${变量名}其他字符`
- **示例**：

  ```bash
  prefix="file"
  echo "${prefix}1.txt"  # 输出 file1.txt（正确）
  echo "$prefix1.txt"    # 输出 .txt（错误，因为变量 prefix1 未定义）
  ```

### 4. 参数扩展（高级变量操作）

Bash 中，`${}` 支持丰富的参数扩展，用于变量默认值、截取、替换等（核心功能）：

- `${var:-默认值}`：若 `var` 未定义或为空，返回默认值（不修改 `var`）。
- `${var:=默认值}`：若 `var` 未定义或为空，将 `var` 设为默认值并返回。
- `${var:?提示信息}`：若 `var` 未定义或为空，输出提示信息并退出脚本。
- `${var:+替代值}`：若 `var` 已定义且非空，返回替代值；否则返回空。
- 字符串截取：`${var:起始位置:长度}`（从 0 开始计数）。
- 字符串替换：`${var/旧字符串/新字符串}`（只替换第一个）、`${var//旧字符串/新字符串}`（替换所有）。

示例：

```bash
# 默认值
name=""
echo "${name:-Guest}"  # 输出 Guest（name 为空）

# 变量赋值
age=""
echo "${age:=18}"  # 输出 18（age 被设为 18）
echo $age          # 输出 18

# 字符串截取（取前 3 个字符）
str="hello world"
echo "${str:0:3}"  # 输出 hel

# 字符串替换（替换所有 "l" 为 "x"）
echo "${str//l/x}"  # 输出 hexxo worxd
```

## 五、总结：核心区别速查表

| 符号       | 主要用途                          | 环境影响               | 典型场景示例                          |
|------------|-----------------------------------|------------------------|---------------------------------------|
| `()`       | 子 Shell 分组、命令替换、数组定义 | 不影响当前 Shell       | `(cd /tmp; ls)`、`$(date)`、`arr=(1 2)` |
| `[]`       | 基础条件测试（`test` 别名）       | 无                     | `[ -f "file" ]`、`[ $a -lt $b ]`      |
| `[[]]`     | 增强型条件测试（Bash 扩展）       | 无                     | `[[ $str =~ ^[0-9]+$ ]]`、`[[ $a < $b ]]` |
| `{}`       | Brace 展开、当前 Shell 分组、变量扩展 | 影响当前 Shell         | `{1..5}`、`{ cd /tmp; ls; }`、`${var}` |

掌握这些括号和花括号的用法，能大幅提升 Shell 脚本的灵活性和可读性，尤其在条件判断、批量操作、变量处理等场景中非常实用。
