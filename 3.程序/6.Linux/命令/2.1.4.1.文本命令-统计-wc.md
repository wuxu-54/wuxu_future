# Linux `wc` 命令 完整权威手册（最细、最全、无错误）

`wc` (**Word Count**) 是 **POSIX 标准命令**，所有 Linux/Unix/macOS 系统原生支持，用于**统计文本流/文件的行数、单词数、字符数、字节数、最长行长度**，是系统最核心的文本统计工具。

本文覆盖：**完整语法、所有参数、标准输出格式、输入规则、返回值、多文件统计、管道用法、编码差异、边界场景、跨系统兼容**。

---

## 一、官方标准定义（POSIX）

`wc` 命令功能：
> 对输入文件/标准输入，统计 **行数 (lines)**、**单词数 (words)**、**字节数 (bytes)**，支持指定参数输出单一/多项统计值。

---

## 二、完整语法（标准 + GNU 扩展）

### 1. 基础语法

```bash
wc [OPTION]... [FILE]...
```

- `OPTION`：参数（零个/多个）
- `FILE`：文件路径（零个/多个，**无文件则读取标准输入**）

### 2. 支持两种参数格式

1. 短参数（推荐）：`-l` `-w` `-c`
2. 长参数（GNU）：`--lines` `--words` `--bytes`

---

## 三、**全部参数详解（100% 完整）**

### 核心必用参数

| 短参数 | 长参数 | 功能（精准定义） |
|--------|--------|------------------|
| `-l` | `--lines` | **统计换行符数量 = 行数** |
| `-w` | `--words` | **统计单词数**（空白字符分隔的非空白字符串） |
| `-c` | `--bytes` | **统计字节数**（文件原始字节大小） |
| `-m` | `--chars` | **统计字符数**（多字节编码：UTF-8 中文算 1 字符） |

### 扩展参数（GNU Linux 独有）

| 短参数 | 长参数 | 功能 |
|--------|--------|------|
| `-L` | `--max-line-length` | 输出**最长行的长度**（不含换行符） |
| 无 | `--files0-from=F` | 从文件 F 读取**以 \0 分隔**的文件列表（处理含空格文件名） |
| 无 | `--help` | 输出帮助 |
| 无 | `--version` | 输出版本 |

### 禁用默认输出参数

| 参数 | 功能 |
|------|------|
| 无任何参数 | 默认输出：**行数 单词数 字节数** |
| 任意组合参数 | 只输出指定项，顺序固定：`行 词 字节 字符 最长行` |

## 四、**统计规则（最关键，决定结果准确性）**

### 1. 行数 (`-l`)

- 计数标准：**`\n` 换行符的数量**
- 边界场景：
  - 文件最后一行**无换行符** → **不计入行数**
  - 空文件 → 行数 = 0

### 2. 单词数 (`-w`)

- 定义：**由空白字符（空格、制表符、换行）分隔的连续非空白字符串**
- 规则：
  - 连续空白 = 1 个分隔符
  - 标点和字母连在一起 = 1 个单词
  - 空文件 = 0

示例：

```
hello world! 123
```

单词数 = **3**

### 3. 字节数 (`-c`)

- 完全等于文件**原始字节大小**
- 英文：1 字符 = 1 字节
- UTF-8 中文：1 汉字 = **3 字节**
- 换行符：`\n` = 1 字节

### 4. 字符数 (`-m`)

- 按**Unicode 字符**计数
- 中文、英文、符号、 emoji 都 = **1 字符**
- 换行符 = 1 字符

### 5. 最长行长度 (`-L`)

- 计算一行中**字符数量**
- **不包含换行符 `\n`**

---

## 五、输出格式（标准固定）

### 1. 无参数（默认）

```
行数 单词数 字节数 文件名
```

### 2. 多参数组合（顺序固定不变）

输出顺序永远是：

```
行数(-l) 单词数(-w) 字节数(-c) 字符数(-m) 最长行(-L) 文件名
```

你指定哪些，就输出哪些，**顺序不会乱**。

示例：

```bash
wc -lwcL file.txt
```

输出：

```
行 词 字节 字符 最长行 file.txt
```

### 3. 无文件名（标准输入）

只输出数字，**不显示文件名**。

---

## 六、多文件统计规则

- 对每个文件单独输出一行
- 最后自动输出一行 **total 总计**
- 总计 = 所有文件对应数值相加

示例：

```bash
wc file1.txt file2.txt
```

输出：

```
  5  10  50 file1.txt
 10  20 100 file2.txt
 15  30 150 total
```

---

## 七、退出状态码（脚本必备）

`wc` 执行后会返回状态码，可通过 `$?` 获取：

- `0`：**成功**，所有文件正常读取
- `>0`：**失败**（文件不存在、权限不足、读取错误）

---

## 八、字节 vs 字符（必须分清）

| 内容 | 字节数 `-c` | 字符数 `-m` |
|------|-------------|-------------|
| `a` | 1 | 1 |
| `中` | 3 | 1 |
| `😀` | 4 | 1 |
| `\n` | 1 | 1 |

✅ **使用建议**

- 统计文件大小 → `-c`
- 统计文字数量（含中文）→ `-m`
- 统计代码行数 → `-l`
- 统计英文单词 → `-w`

---

## 九、标准输入 / 管道用法（最常用）

`wc` 支持**无文件参数**，从管道/键盘读取：

### 1. 统计命令输出行数

```bash
ls | wc -l
```

### 2. 统计匹配行数

```bash
grep "error" log.txt | wc -l
```

### 3. 统计总代码行数

```bash
find . -name "*.py" -exec cat {} \; | wc -l
```

### 4. 键盘输入统计（Ctrl+D 结束）

```bash
wc -l
```

## 十一、系统兼容性

| 系统 | 支持情况 |
|------|----------|
| Linux | 完整支持（所有参数） |
| macOS | 支持 `-l -w -c -m`，**不支持 `-L`** |
| BSD | 同 macOS |
| POSIX | 标准 `-l -w -c` 必支持 |

## 十二、高频实用速查（生产常用）

```bash
# 统计行数
wc -l file

# 统计单词数
wc -w file

# 统计字节大小
wc -c file

# 统计字符数（中文准确）
wc -m file

# 统计最长行长度
wc -L file

# 只输出数字（无文件名）
cat file | wc -l

# 多文件总行数
wc -l *.log
```

## 总结（权威版）

1. **`wc` 是 POSIX 标准命令，通用可靠**
2. **默认输出：行数 单词数 字节数**
3. **`-l` 行数、`-w` 单词、`-c` 字节、`-m` 字符、`-L` 最长行**
4. **字节≠字符：中文用 `-m`，大小用 `-c`**
5. **行数 = 换行符数量，最后一行无换行不计入**
6. **支持多文件 + 自动总计 + 管道 + 标准输入**
