# tr

`tr`（translate）是 Linux 中用于**字符转换、删除或压缩**的轻量级文本处理命令，它从标准输入读取数据，通过指定的规则处理后输出到标准输出，不直接处理文件（需配合管道或重定向）。`tr` 专注于单个字符的处理，语法简洁但功能强大，是文本清洗、格式转换的常用工具。

## 一、基本语法与核心概念

### 1. 语法格式

```bash
tr [选项] 字符集1 [字符集2]
```

- **核心逻辑**：用 `字符集2` 转换 `字符集1` 中的字符（转换模式）；或仅用 `字符集1` 进行删除/压缩（删除/压缩模式）。
- **输入输出**：`tr` 只能从标准输入（如管道 `|`、输入重定向 `<`）读取数据，处理后输出到标准输出（终端或重定向 `>`）。

### 2. 字符集的表示方法

`字符集1` 和 `字符集2` 用于定义转换/删除的规则，支持多种表示方式：

| 表示方式         | 说明                                  | 示例                          |
|------------------|---------------------------------------|-------------------------------|
| 单个字符         | 直接写字符（特殊字符需转义 `\`）      | `'a'`、`'1'`、`'\n'`（换行）  |
| 字符范围         | 用 `-` 表示连续字符（需按 ASCII 顺序）| `'a-z'`（所有小写字母）、`'0-9'`（数字） |
| POSIX 字符类     | 预定义的字符集合（更通用，跨字符集）  | `[:lower:]`（小写字母）、`[:digit:]`（数字） |
| 转义字符         | 特殊控制字符（需用 `\` 转义）         | `'\t'`（制表符）、`'\r'`（回车） |
| 重复次数（仅字符集2） | 用 `*` 表示重复前一字符（GNU 扩展）  | `'a*3'` 等价于 `'aaa'`        |

### 3. 常用 POSIX 字符类（推荐使用，兼容性更好）

| 字符类           | 含义                                  | 等价范围（ASCII 环境）        |
|------------------|---------------------------------------|-------------------------------|
| `[:lower:]`      | 所有小写字母                          | `a-z`                         |
| `[:upper:]`      | 所有大写字母                          | `A-Z`                         |
| `[:alpha:]`      | 所有字母（大小写）                    | `a-zA-Z`                      |
| `[:digit:]`      | 所有数字                              | `0-9`                         |
| `[:alnum:]`      | 所有字母和数字                        | `a-zA-Z0-9`                   |
| `[:space:]`      | 所有空白字符（空格、制表符、换行等）  | `\t\n\r\f\v`                 |
| `[:punct:]`      | 所有标点符号                          | `!\"#$%&'()*+,-./:;<=>?@[\]^_`{|}~` |
| `[:print:]`      | 所有可打印字符（含空格）              | 上述字符类的组合              |

## 二、核心功能与选项详解

`tr` 的功能主要分为 **转换（Translate）**、**删除（Delete）**、**压缩（Squeeze）** 三大类，通过选项控制行为。

### 1. 字符转换（默认模式，无需选项）

将 `字符集1` 中的每个字符，按位置对应转换为 `字符集2` 中的字符。  

- 若 `字符集1` 长度 > `字符集2` 长度：`字符集2` 中多余的字符用 `字符集2` 的最后一个字符填充。  
- 若 `字符集1` 长度 < `字符集2` 长度：`字符集2` 中多余的字符被忽略。  

**示例**：  

```bash
# 示例1：单个字符对应转换（a→x，b→y，c→z）
echo "abc" | tr 'abc' 'xyz'  # 输出：xyz

# 示例2：字符集1长于字符集2（d、e 用字符集2最后一个字符 z 转换）
echo "abcde" | tr 'abcde' 'xyz'  # 输出：xyzzz

# 示例3：大小写转换（经典用法）
echo "Hello World" | tr 'A-Z' 'a-z'  # 输出：hello world
echo "hello world" | tr '[:lower:]' '[:upper:]'  # 输出：HELLO WORLD（用POSIX字符类）

# 示例4：替换换行符为空格（将多行内容转为单行）
cat file.txt | tr '\n' ' '  # file.txt 中的换行全部变为空格

# 示例5：数字替换（0→a，1→b，…，9→j）
echo "12345" | tr '0123456789' 'abcdefghij'  # 输出：bcdef
```

### 2. 删除字符（`-d` 选项）

删除所有属于 `字符集1` 的字符（此时不需要 `字符集2`）。  

**示例**：  

```bash
# 示例1：删除所有小写字母
echo "Hello 123 World" | tr -d 'a-z'  # 输出：H 123 W

# 示例2：删除所有数字
echo "abc123def456" | tr -d '[:digit:]'  # 输出：abcdef

# 示例3：删除特定标点符号（删除逗号和感叹号）
echo "Hello, World! How are you?" | tr -d ',!'  # 输出：Hello World How are you?

# 示例4：删除空白字符（包括空格、制表符等）
echo "a b\tc\nd" | tr -d '[:space:]'  # 输出：abcd（\t是制表符，\n是换行）
```

### 3. 压缩重复字符（`-s` 选项）

将 `字符集1` 中**连续出现的重复字符**压缩为单个（仅保留一个）。  

**示例**：  

```bash
# 示例1：压缩连续的相同字母（aaa→a，bbb→b）
echo "aaabbbcccd" | tr -s 'abc'  # 输出：abcd

# 示例2：压缩多余空格（将多个连续空格转为单个）
echo "Hello   world    this   is  a test" | tr -s ' '  # 输出：Hello world this is a test

# 示例3：压缩换行符（将多个空行转为单个）
cat file.txt | tr -s '\n'  # file.txt 中的连续空行变为单个空行

# 示例4：结合POSIX字符类（压缩所有连续的空白字符）
echo "a  \t\tb\n\nc" | tr -s '[:space:]'  # 输出：a b c（多个空格/制表符/换行→单个空格）
```

### 4. 补集转换/删除（`-c` 选项）

`-c` 表示「字符集1的补集」（即所有**不在** `字符集1` 中的字符），通常与转换、删除或压缩结合使用。  

**示例**：  

```bash
# 示例1：补集转换（将非数字字符转为换行）
echo "abc123def456" | tr -c '[:digit:]' '\n'  # 输出：123\n456（非数字→换行）

# 示例2：补集删除（删除所有非字母字符）
echo "Hello123!@# World456" | tr -cd '[:alpha:]'  # 输出：HelloWorld（仅保留字母）

# 示例3：补集压缩（压缩所有非数字的连续重复字符）
echo "aa111bb222cc" | tr -cs '[:digit:]' ' '  # 输出： aa 111 bb 222 cc（非数字的连续重复→单个空格）
```

### 5. 组合选项（`-d`、`-s`、`-c` 结合使用）

多个选项可组合，执行顺序为：**先删除（-d），再压缩（-s）**（无论选项顺序如何）。  

**示例**：  

```bash
# 示例1：先删除数字，再压缩空格（-d 和 -s 组合）
echo "a 111 b 222 c" | tr -ds '[:digit:]' ' '  # 步骤：1. 删除数字→"a  b  c"；2. 压缩空格→"a b c"

# 示例2：先删除非字母，再压缩连续字母（-cd 和 -s 组合）
echo "11aa22bb33cc44" | tr -cds '[:alpha:]' ''  # 步骤：1. 删除非字母→"aabbcc"；2. 压缩连续字母→"abc"

# 示例3：补集删除+压缩（保留数字，压缩连续数字）
echo "aa111bb222cc333" | tr -cds '[:digit:]' ''  # 步骤：1. 删除非数字→"111222333"；2. 压缩→"123"
```

## 三、高级用法与实战场景

### 1. 提取字符串中的数字

```bash
echo "订单号：OD20230910001，金额：99.9元" | tr -cd '[:digit:]'  # 输出：20230910001999
```

### 2. 清除文件中的控制字符（如 ^M 回车符）

Windows 文本文件的换行符是 `\r\n`，Linux 是 `\n`，直接打开会显示 `^M`，可用 `tr` 清除：  

```bash
cat windows_file.txt | tr -d '\r' > linux_file.txt  # 删除所有 \r 字符（^M）
```

### 3. 生成随机密码（结合 `/dev/urandom`）

```bash
# 生成10位包含大小写字母、数字的随机密码
tr -dc 'A-Za-z0-9' < /dev/urandom | head -c 10 ; echo
# 解释：-dc 'A-Za-z0-9' 表示删除所有非字母数字字符；head -c 10 取前10个字符
```

### 4. 统计文件中不同字符的出现次数

```bash
# 统计 file.txt 中每个字符的出现次数（排序后展示）
cat file.txt | tr -c '[:print:]' '\n' | sort | uniq -c | sort -nr
# 解释：-c '[:print:]' '\n' 表示非打印字符转为换行，便于统计
```

### 5. 将多行文本按固定长度拆分

```bash
# 将文本按每行5个字符拆分（超出部分换行）
echo "abcdefghijklmnopqrstuvwxyz" | tr -s '' '\n' | fold -w5 | tr -d '\n' | fold -w5
# 输出：
# abcde
# fghij
# klmno
# pqrst
# uvwxy
# z
```

## 四、注意事项

1. **字符集顺序**：字符范围（如 `a-z`）必须按 ASCII 码顺序排列，不能写反（如 `z-a` 是错误的，需用 `-c` 补集实现反向）。  
2. **特殊字符转义**：对 `\`、`*`、`[`、`]` 等特殊字符，需用 `\` 转义（如 `tr '\*' 'x'` 替换 `*` 为 `x`）。  
3. **不支持字符串替换**：`tr` 只能处理单个字符，无法替换字符串（如将 `ab` 替换为 `cd` 无法直接实现，需用 `sed`）。  
4. **GNU 扩展差异**：部分选项（如 `*` 重复字符）是 GNU `tr` 的扩展，在 BSD 系统（如 macOS）可能不支持，需用标准写法替代。  
5. **无法直接处理文件**：`tr` 必须通过管道（`|`）或输入重定向（`<`）读取数据，如 `tr 'a' 'b' < input.txt > output.txt`。  

## 总结

`tr` 是字符级处理的轻量工具，核心优势在于**简单高效**，适合处理：  

- 字符转换（大小写、特定字符映射）；  
- 字符删除（过滤不需要的字符）；  
- 重复字符压缩（格式化空格、空行）。  

虽然功能不及 `sed` 或 `awk` 全面，但在简单字符处理场景中，`tr` 往往是最简洁的选择。
