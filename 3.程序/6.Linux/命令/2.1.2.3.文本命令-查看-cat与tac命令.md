# cat与tac

`cat`（concatenate）和 `tac`（反向cat）是 Linux 系统中用于**文件内容查看与处理**的基础命令。`cat` 主要用于连接文件并打印内容（正序），`tac` 则是 `cat` 的反向操作（按行倒序打印）。两者功能互补，是文本处理的常用工具。以下是详细解析：

## 一、`cat` 命令：连接与正序打印文件

`cat` 的核心功能是**读取文件内容并输出到标准输出**（终端），同时支持文件合并、创建文件、追加内容等扩展功能。其设计简洁但实用性极强，是查看小型文本文件的首选命令。

### 1. 基本语法

```bash
cat [选项] [文件1] [文件2] ...
```

- 若不指定文件，`cat` 从**标准输入**（键盘）读取内容，按 `Ctrl+D` 结束输入并输出。  
- 若指定多个文件，`cat` 会按顺序连接所有文件内容并一次性输出。  

### 2. 核心功能与选项详解

#### （1）基础功能：显示文件内容

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| 无选项 |  | 直接打印文件全部内容（正序，从第一行到最后一行）。 | `cat file.txt` → 输出 `file.txt` 的所有内容。 |
| `-n` | `number` | 显示所有行的行号（包括空行），行号从1开始。 | `cat -n file.txt` → 每行前加序号（如 `1  hello`、`2  world`）。 |
| `-b` | `number-nonblank` | 仅显示**非空行**的行号（空行不编号）。 | `cat -b file.txt` → 空行无序号，非空行从1编号。 |
| `-s` | `squeeze-blank` | 压缩连续的空行（多个空行合并为一个）。 | `cat -s file.txt` → 原文件中的3个连续空行变为1个。 |
| `-v` | `show-nonprinting` | 显示**非打印字符**（如制表符 `^I`、结束符 `^@` 等），除换行符 `\n` 和制表符 `\t` 外的控制字符用 `^` 前缀表示。 | `cat -v file.txt` → 制表符显示为 `^I`，退格符显示为 `^H`。 |
| `-t` |  | 等价于 `-vT`，显示制表符 `\t` 为 `^I`（结合 `-v` 显示其他非打印字符）。 | `cat -t file.txt` → 制表符显示为 `^I`，其他控制字符按 `-v` 规则显示。 |
| `-e` |  | 等价于 `-vE`，在每行末尾显示 `$` 符号（标识换行符位置），并按 `-v` 显示非打印字符。 | `cat -e file.txt` → 每行末尾加 `$`（如 `hello$`、`world$`）。 |
| `-E` | `show-ends` | 仅在每行末尾显示 `$` 符号（标识换行位置，不处理其他字符）。 | `cat -E file.txt` → 直观区分空行与换行（空行显示为 `$`）。 |
| `-T` | `show-tabs` | 仅将制表符 `\t` 显示为 `^I`（不处理其他非打印字符）。 | `cat -T file.txt` → 制表符显式化为 `^I`，便于观察格式。 |

#### （2）扩展功能：文件合并与创建

| 功能 | 命令示例 | 说明 |
|------|----------|------|
| 合并多个文件到新文件 | `cat file1.txt file2.txt > merged.txt` | 将 `file1.txt` 和 `file2.txt` 的内容按顺序合并到 `merged.txt`（覆盖原有内容）。 |
| 追加文件内容到已有文件 | `cat file3.txt >> merged.txt` | 将 `file3.txt` 的内容追加到 `merged.txt` 末尾（不覆盖原有内容）。 |
| 从键盘创建文件 | `cat > newfile.txt` | 从键盘输入内容（按 `Enter` 换行，`Ctrl+D` 结束），保存到 `newfile.txt`（覆盖已有文件）。 |
| 追加键盘输入到文件 | `cat >> newfile.txt` | 从键盘输入内容，追加到 `newfile.txt` 末尾（不覆盖）。 |
| 合并标准输入与文件 | `echo "header" \| cat - file.txt > with_header.txt` | 将 `echo` 输出的 "header" 作为首行，与 `file.txt` 合并到 `with_header.txt`（`-` 代表标准输入）。 |

### 3. 实战场景示例

#### （1）查看文件并显示行号

```bash
# 显示所有行的行号（包括空行）
cat -n poem.txt
# 输出示例：
# 1  床前明月光
# 2  
# 3  疑是地上霜

# 仅显示非空行的行号
cat -b poem.txt
# 输出示例：
# 1  床前明月光
#   
# 2  疑是地上霜
```

#### （2）处理空行与特殊字符

```bash
# 压缩连续空行（适合格式化杂乱的文本）
cat -s messy.txt  # 多个空行→1个空行

# 查看文件中的制表符和控制字符（排查格式问题）
cat -t data.txt  # 制表符显示为 ^I，便于区分空格与制表符

# 标识每行结束位置（确认是否有隐藏换行）
cat -E script.sh  # 每行末尾显示 $，空行显示为 $
```

#### （3）文件合并与创建

```bash
# 合并多个日志文件（按日期排序）
cat log_20230901.txt log_20230902.txt > log_202309.txt

# 创建包含多行内容的配置文件
cat > config.ini << EOF
[server]
port = 8080
host = localhost
EOF
# 输入结束后，config.ini 包含上述内容（EOF 是自定义终止符）

# 向现有文件追加内容
cat >> config.ini << EOF
[client]
timeout = 30
EOF
# config.ini 末尾新增 [client] 部分
```

## 二、`tac` 命令：反向打印文件内容

`tac` 是 `cat` 的反向操作，其核心功能是**按行倒序打印文件内容**（从最后一行到第一行），而非字符级反转。适合需要从结尾开始查看的场景（如日志文件从最新记录开始看）。

### 1. 基本语法

```bash
tac [选项] [文件1] [文件2] ...
```

- 若指定多个文件，`tac` 会先倒序打印每个文件的内容，再按文件顺序拼接（与 `cat` 正序拼接对应）。  
- 若不指定文件，`tac` 从标准输入读取内容，倒序输出（按 `Ctrl+D` 结束输入）。  

### 2. 核心选项详解

`tac` 选项较少，主要用于控制“行分隔符”（默认以换行符 `\n` 为分隔符）。

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| `-b` | `before` | 在分隔符**前**而非**后**打印分隔符（默认分隔符在每行后，反向后可能错位，`-b` 修正）。 | `tac -b file.txt` → 确保分隔符位置正确（多用于自定义分隔符时）。 |
| `-r` | `regex` | 将 `-s` 指定的分隔符视为**正则表达式**（默认视为普通字符串）。 | `tac -r -s '[,;]' data.txt` → 以 `,` 或 `;` 为分隔符拆分内容并反向。 |
| `-s 分隔符` | `separator` | 自定义行分隔符（默认是换行符 `\n`），按指定分隔符拆分内容并反向。 | `tac -s '---' report.txt` → 以 `---` 为分隔符拆分 `report.txt`，反向输出各部分。 |

### 3. 实战场景示例

#### （1）基础反向打印

```bash
# 倒序打印文件（最后一行先输出）
cat numbers.txt  # 原内容：1\n2\n3\n4
tac numbers.txt  # 输出：4\n3\n2\n1
```

#### （2）查看最新日志（从末尾开始）

日志文件通常最新记录在末尾，`tac` 可直接从最新内容开始查看：

```bash
tac /var/log/syslog  # 从最后一行（最新日志）开始显示系统日志
```

#### （3）自定义分隔符反向

```bash
# 以 ";" 为分隔符拆分内容并反向（默认按换行）
echo "a;b;c;d" > test.txt
tac -s ';' test.txt  # 输出：d;c;b;a

# 以正则表达式作为分隔符（匹配逗号或分号）
echo "x,y;z,w" | tac -r -s '[,;]'  # 输出：w,z;y,x
```

#### （4）处理多个文件

```bash
# 先倒序打印 file1.txt，再倒序打印 file2.txt
cat file1.txt  # 内容：a\nb
cat file2.txt  # 内容：c\nd
tac file1.txt file2.txt  # 输出：b\na\nd\nc
```

## 三、`cat` 与 `tac` 的对比与组合使用

### 1. 核心区别

| 命令 | 处理方式 | 典型用途 | 效率 |
|------|----------|----------|------|
| `cat` | 正序打印（第一行→最后一行） | 查看文件、合并文件、创建文件 | 高效（直接读取输出，适合大文件） |
| `tac` | 倒序打印（最后一行→第一行） | 反向查看日志、倒序处理文本 | 需先读取所有内容再反转，大文件可能稍慢 |

### 2. 组合使用示例

```bash
# 先正序合并文件，再倒序输出（整体反转）
cat file1.txt file2.txt | tac  # 合并后的内容整体倒序

# 查看文件的前3行和后3行（结合 head/tail）
echo "查看前3行："
cat file.txt | head -n 3
echo "查看后3行（倒序）："
tac file.txt | head -n 3 | tac  # 先倒序取前3行（即原文件后3行），再倒序恢复正常顺序
```

## 四、注意事项

1. **大文件处理**：  
   - `cat` 适合查看大文件（直接流式输出，内存占用低）；  
   - `tac` 需读取整个文件到内存再反转，大文件（如GB级）可能占用较多内存，建议用 `tail -r`（部分系统支持，功能类似 `tac`）。

2. **特殊字符处理**：  
   - 包含非打印字符（如 `\r`、`\0`）的文件，建议用 `cat -v` 显式化后查看，避免乱码。

3. **避免 `cat` 的无用使用**：  
   反模式：`cat file.txt | grep "keyword"`（多余的 `cat`），直接用 `grep "keyword" file.txt` 更高效。

4. **`tac` 与 `rev` 的区别**：  
   - `tac` 是**行级反转**（最后一行→第一行）；  
   - `rev` 是**字符级反转**（每行内的字符反转，如 "hello"→"olleh"）。  

## 总结

- `cat` 是文本处理的“瑞士军刀”，核心用于正序查看、合并、创建文件，选项 `-n`（行号）、`-s`（压缩空行）、`-v`（显示特殊字符）最常用。  
- `tac` 是行级反向工具，适合从结尾查看文件（如日志），支持自定义分隔符，与 `cat` 形成互补。  
- 灵活使用两者可高效处理文本查看、合并、格式检查等场景，是Linux基础操作的必备技能。
