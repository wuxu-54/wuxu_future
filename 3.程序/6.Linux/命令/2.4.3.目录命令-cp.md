# cp

`cp`（copy）是 Linux/Unix 系统中用于**复制文件或目录**的核心命令，支持文件复制、目录递归复制、权限保留、覆盖控制等多种功能。其用法灵活，选项丰富，掌握细节可大幅提升文件管理效率。以下是 `cp` 命令的全面解析，涵盖所有常用选项、场景示例及注意事项。

## 一、基础语法与核心概念

### 1. 基本语法

```bash
cp [选项] 源文件/目录... 目标文件/目录
```

- **核心逻辑**：将“源”（可以是1个或多个文件/目录）复制到“目标”位置。
- **关键区别**：  
  - 若复制**文件**：直接复制内容到目标（目标可以是新文件名或已有目录）。  
  - 若复制**目录**：必须加 `-r` 或 `-R` 选项（递归复制目录内所有内容），否则会报错 `cp: 略过目录'xxx'`。  

### 2. 核心行为规则

| 场景 | 源类型 | 目标状态 | 结果 |
|------|--------|----------|------|
| 1 | 单个文件 | 目标是**不存在的文件** | 创建目标文件，内容与源文件相同。 |
| 2 | 单个文件 | 目标是**已存在的文件** | 覆盖目标文件（默认不提示，可用 `-i` 开启确认）。 |
| 3 | 单个文件 | 目标是**已存在的目录** | 将源文件复制到该目录下，文件名不变。 |
| 4 | 多个文件 | 目标必须是**已存在的目录** | 所有源文件都被复制到该目录下，文件名不变。 |
| 5 | 目录（加 `-r`） | 目标是**不存在的目录** | 创建目标目录，将源目录内所有内容复制到目标目录中。 |
| 6 | 目录（加 `-r`） | 目标是**已存在的目录** | 在目标目录内创建与源目录同名的子目录，再复制内容（即 `目标/源目录/内容`）。 |

## 二、核心选项详解（按功能分类）

### 1. 目录复制（递归复制必备）

复制目录时必须使用以下选项之一，否则无法递归处理子目录和文件。

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| `-r` | `recursive` | 递归复制目录（包括所有子目录和文件），但不保留特殊文件（如设备文件）的属性。 | `cp -r dir1 dir2` → 复制 `dir1` 到 `dir2`（`dir2` 不存在则创建）。 |
| `-R` | `recursive` | 与 `-r` 功能基本一致，但会保留特殊文件（如 `/dev` 下的设备文件）的属性（更安全的递归复制）。 | `cp -R /dev/sda1_backup /tmp/` → 复制设备文件备份目录。 |
| `-a` | `archive` | 归档模式（最常用的目录复制选项），等价于 `-dR --preserve=all`：<br>1. 递归复制（`-R`）；<br>2. 保留符号链接（`-d`）；<br>3. 保留所有文件属性（权限、所有者、时间戳等）。 | `cp -a /etc /backup/etc` → 完整备份 `/etc` 目录（保留所有原始属性）。 |

### 2. 覆盖控制（避免误操作）

默认情况下，`cp` 会直接覆盖目标文件而不提示，以下选项可控制覆盖行为（防止误删重要文件）。

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| `-i` | `interactive` | 交互式覆盖：若目标文件已存在，会提示 `是否覆盖？`（输入 `y` 确认，`n` 跳过）。 | `cp -i file.txt /backup/` → 若 `/backup/file.txt` 存在，提示确认。 |
| `-f` | `force` | 强制覆盖：无论目标文件是否存在、是否有写权限，直接覆盖（优先级高于 `-i`，root 用户常用）。 | `cp -f file.txt /backup/` → 强制覆盖，无任何提示。 |
| `-n` | `no-clobber` | 不覆盖：若目标文件已存在，直接跳过（不复制，也不提示），适合批量复制时保留目标文件。 | `cp -n *.txt /backup/` → 复制所有 `.txt` 文件到 `/backup`，但不覆盖已有文件。 |
| `--backup[=CONTROL]` | `backup` | 覆盖前为目标文件创建备份（避免直接丢失原文件），`CONTROL` 可指定备份方式（如 `numbered` 加数字后缀）。 | `cp --backup=numbered file.txt /backup/` → 若目标存在，先创建 `file.txt.~1~` 备份，再覆盖。 |

### 3. 属性保留（复制时保持文件特性）

默认复制会丢失部分文件属性（如所有者、时间戳），以下选项可保留关键属性（备份场景必备）。

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| `-p` | `preserve` | 保留核心属性：包括文件权限（mode）、修改时间（mtime）、访问时间（atime）、所有者（owner）和所属组（group）。 | `cp -p file.txt /backup/` → 复制后 `file.txt` 的权限和时间戳与源文件一致。 |
| `-a` | `archive` | 保留所有属性（比 `-p` 更全面）：除 `-p` 的属性外，还保留符号链接、硬链接、设备文件特性等（等价于 `--preserve=all`）。 | `cp -a /home/user /backup/` → 完整复制用户目录，保留所有原始属性。 |
| `--preserve=属性列表` | `preserve` | 自定义保留的属性（用逗号分隔），可选属性：`mode`（权限）、`ownership`（所有者）、`timestamp`（时间戳）、`links`（链接）等。 | `cp --preserve=mode,timestamp file.txt /tmp/` → 仅保留权限和时间戳。 |
| `-d` | `no-dereference` | 复制符号链接本身（而非链接指向的原文件），并保留链接属性（通常与 `-R` 配合复制目录中的链接）。 | `cp -d link.txt /tmp/` → `/tmp/link.txt` 仍是符号链接，指向原目标。 |

### 4. 复制模式（控制复制内容）

根据需求选择复制“链接指向的文件”还是“链接本身”，或仅复制更新的文件。

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| `-L` | `dereference` | 跟随符号链接：复制符号链接指向的**原文件**（而非链接本身）。 | `cp -L link.txt /tmp/` → 若 `link.txt` 指向 `data.txt`，则复制 `data.txt` 内容到 `/tmp/link.txt`。 |
| `-P` | `no-dereference` | 不跟随符号链接：复制符号链接本身（与 `-d` 功能类似，优先级更高）。 | `cp -P link.txt /tmp/` → `/tmp/link.txt` 仍是指向原目标的链接。 |
| `-u` | `update` | 仅复制“更新的文件”：若源文件比目标文件**更新**（修改时间更新），或目标文件不存在，才复制（增量复制，节省时间）。 | `cp -ru /data/* /backup/` → 仅复制 `/data` 中比 `/backup` 新的文件。 |
| `-s` | `symbolic-link` | 创建符号链接而非复制文件内容（相当于 `ln -s`，但目标必须不存在）。 | `cp -s file.txt link.txt` → 创建 `link.txt` 指向 `file.txt`（而非复制内容）。 |
| `-l` | `link` | 创建硬链接而非复制文件内容（源和目标必须在同一文件系统）。 | `cp -l file.txt hardlink.txt` → `hardlink.txt` 是 `file.txt` 的硬链接（共享inode）。 |

### 5. 输出与进度（显示复制过程）

默认 `cp` 执行成功后无输出，以下选项可显示复制细节（便于调试或确认操作）。

| 选项 | 英文全称 | 功能描述 | 示例 |
|------|----------|----------|------|
| `-v` | `verbose` | 显示复制过程：输出每个文件的复制路径（`源' -> '目标'`）。 | `cp -v *.txt /backup/` → 输出：`'a.txt' -> '/backup/a.txt'`、`'b.txt' -> '/backup/b.txt'`。 |
| `-v -r` | （组合） | 递归复制时显示所有文件的复制过程（适合确认目录复制的完整性）。 | `cp -rv dir1 /backup/` → 输出目录内每个文件的复制路径。 |
| `--progress` | `progress` | 显示复制进度条（仅 GNU `cp` 支持，适合大文件复制）。 | `cp --progress largefile.iso /tmp/` → 显示：`largefile.iso  50%  1.5G / 3.0G  01:23 ETA`。 |

### 6. 路径与命名（控制目标路径和名称）

| 选项 | 功能描述 | 示例 |
|------|----------|------|
| `-t 目标目录` | 指定目标目录（适合复制多个源文件到同一目录，简化命令）。 | `cp -t /backup/ a.txt b.txt c.txt` → 等价于 `cp a.txt b.txt c.txt /backup/`。 |
| `-T` | 将目标视为**文件**（而非目录）：避免“当目标是目录时，将源文件复制到目录内”的默认行为。 | `cp -T file.txt /tmp/file.txt` → 强制将 `file.txt` 复制为 `/tmp/file.txt`（即使 `/tmp` 是目录）。 |
| `--parents` | 复制时保留源文件的完整路径结构（在目标目录中重建源文件的父目录）。 | `cp --parents a/b/c.txt /backup/` → 在 `/backup` 中创建 `a/b/` 目录，再复制 `c.txt` 到该目录（结果：`/backup/a/b/c.txt`）。 |

## 三、实战场景与示例

### 1. 基础文件复制

```bash
# 复制单个文件到目标文件（目标不存在则创建）
cp file.txt newfile.txt  # 复制 file.txt 为 newfile.txt

# 复制单个文件到目标目录（文件名不变）
cp document.pdf /home/user/docs/  # 复制到 docs 目录下，仍叫 document.pdf

# 复制多个文件到目标目录
cp report.txt data.csv image.jpg /backup/  # 三个文件都被复制到 /backup 目录
```

### 2. 目录复制（核心场景）

```bash
# 复制目录到新目录（目标不存在）
cp -r project/ project_backup/  # 创建 project_backup 并复制 project 内所有内容

# 复制目录到已有目录（在目标内创建同名子目录）
cp -r project/ /data/  # 结果：/data/project/（包含原 project 的所有内容）

# 复制目录内容到目标目录（不创建子目录）
cp -r project/* /data/  # 将 project 内的文件/子目录直接复制到 /data/ 下

# 备份目录（保留所有属性）
cp -av /etc /backup/etc_$(date +%F)  # -a 保留属性，-v 显示过程，目标名带日期（如 etc_2023-09-10）
```

### 3. 覆盖控制（安全操作）

```bash
# 交互式复制（覆盖前确认）
cp -i important.txt /backup/  # 若目标存在，提示：cp: 是否覆盖'/backup/important.txt'?

# 批量复制但不覆盖已有文件
cp -n /downloads/*.zip /archive/  # 仅复制 /archive 中没有的 .zip 文件

# 覆盖前创建备份（保留原文件）
cp --backup=numbered config.ini /etc/  # 若目标存在，先创建 config.ini.~1~ 备份，再覆盖
```

### 4. 增量复制（更新文件）

```bash
# 仅复制比目标新的文件（适合同步目录）
cp -ru /home/user/docs/ /backup/docs/  # 若源文件修改时间晚于目标，才复制

# 结合 -v 显示哪些文件被更新
cp -ruv /data/logs/ /backup/logs/  # 输出：'access.log' -> '/backup/logs/access.log'（仅新文件）
```

### 5. 处理特殊文件（链接、设备文件）

```bash
# 复制符号链接本身（而非指向的文件）
cp -d link_to_data /tmp/  # /tmp/link_to_data 仍是指向原数据的链接

# 跟随符号链接，复制实际文件内容
cp -L link_to_data /tmp/  # /tmp/link_to_data 是原数据的副本（非链接）

# 复制设备文件（保留设备特性，需 root 权限）
sudo cp -R /dev/sda1 /tmp/sda1_backup  # 复制磁盘设备文件（用于备份）
```

### 6. 高级路径控制

```bash
# 用 -t 简化多文件复制到同一目录
cp -t /var/www/html/ index.html style.css script.js  # 等价于复制三个文件到 html 目录

# 保留源文件的路径结构
cp --parents src/main.c src/include/head.h /backup/  # 结果：/backup/src/main.c 和 /backup/src/include/head.h

# 强制将源文件复制为目标文件（即使目标是目录）
cp -T app.conf /etc/app.conf  # 无论 /etc 是否为目录，都将 app.conf 复制为 /etc/app.conf
```

## 四、常见错误与解决

1. **复制目录时提示“略过目录”**  
   原因：未加 `-r`、`-R` 或 `-a` 选项（目录复制必须递归）。  
   解决：`cp -r 源目录 目标目录`。

2. **无法覆盖文件，提示“权限不够”**  
   原因：目标文件权限为只读（`-r--r--r--`），普通用户无法直接覆盖。  
   解决：用 `-f` 强制覆盖（`cp -f 源 目标`），或先修改目标文件权限（`chmod +w 目标`）。

3. **复制符号链接后内容不对**  
   原因：默认 `cp` 会复制链接本身，而非指向的文件（除非用 `-L`）。  
   解决：需要副本时用 `cp -L 链接 目标`；需要保留链接时用 `cp -d 链接 目标`。

4. **复制大量小文件速度慢**  
   优化：用 `cp -a` 结合 `tar`（先打包再解压，减少IO操作）：  

   ```bash
   tar cf - 源目录 | (cd 目标目录 && tar xf -)  # 比直接 cp -r 更快
   ```

## 五、常用选项组合

| 场景 | 选项组合 | 作用 |
|------|----------|------|
| 安全备份文件 | `cp -ip` | 交互式覆盖，保留属性。 |
| 完整备份目录 | `cp -av` | 递归复制，保留所有属性，显示过程。 |
| 批量增量复制 | `cp -ruv` | 仅复制更新的文件，显示过程。 |
| 强制覆盖文件 | `cp -f` | 忽略权限，直接覆盖（谨慎使用）。 |
| 复制链接本身 | `cp -d` | 保留符号链接（不跟随原文件）。 |

## 总结

`cp` 命令的核心是“复制”，但通过选项组合可实现**灵活的文件/目录管理**：  

- 基础操作：`cp 源 目标`（文件）、`cp -r 源 目标`（目录）；  
- 安全控制：`-i`（确认）、`-n`（不覆盖）、`--backup`（备份）；  
- 属性保留：`-p`（基础属性）、`-a`（完整属性，备份首选）；  
- 高效复制：`-u`（增量）、`-v`（显示过程）、`-t`（简化路径）。  

熟练掌握这些选项，能应对从简单文件复制到复杂目录备份的各种场景，是 Linux 日常操作的必备技能。
