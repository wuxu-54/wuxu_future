# 目录命令大全

Linux 目录管理是日常操作的核心，涉及目录的创建、删除、切换、查看、复制、移动、权限控制等。以下按功能分类整理了 **所有常用目录管理命令**，包含详细选项、示例及使用场景，确保覆盖日常及进阶需求。

## 一、目录导航（切换与查看当前目录）

### 1. `cd`：切换目录

**功能**：改变当前工作目录，是最常用的目录导航命令。  
**常用用法**：

| 命令               | 说明                                  | 示例场景                          |
|--------------------|---------------------------------------|-----------------------------------|
| `cd 目录路径`      | 切换到指定目录（绝对/相对路径均可）   | `cd /home/user`（绝对路径）       |
| `cd ~` 或 `cd`     | 切换到当前用户的家目录（`/home/用户名`） | `cd ~` 等价于 `cd /home/zhang`    |
| `cd ..`            | 切换到上一级目录                      | 从 `/home/user/doc` 到 `/home/user` |
| `cd -`             | 切换到上一次所在的目录（目录间快速切换） | 从 `/home` 到 `/tmp` 后，`cd -` 返回 `/home` |
| `cd ./目录`        | 切换到当前目录下的子目录（`./` 可省略） | `cd ./downloads` 等价于 `cd downloads` |

**注意**：路径中 `~` 代表家目录，`.` 代表当前目录，`..` 代表父目录。

### 2. `pwd`：显示当前目录路径

**功能**：打印当前工作目录的绝对路径，避免“迷路”。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| 无选项     | 显示当前目录路径（可能包含符号链接）  | `pwd` → `/home/user/link_dir`（若 `link_dir` 是符号链接） |
| `-P`       | 显示实际路径（解析符号链接为真实路径） | `pwd -P` → `/home/user/real_dir`（解析符号链接后的真实目录） |

**示例**：  
若 `~/docs` 是指向 `/data/documents` 的符号链接：  

```bash
cd ~/docs
pwd       # 输出：/home/user/docs（显示链接路径）
pwd -P    # 输出：/data/documents（显示真实路径）
```

## 二、目录创建与删除

### 1. `mkdir`：创建目录

**功能**：创建新目录，支持一次性创建单级或多级目录。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| 无选项     | 创建单级目录（父目录必须存在）        | `mkdir notes` → 创建 `notes` 目录 |
| `-p`       | 递归创建多级目录（父目录不存在则自动创建） | `mkdir -p a/b/c` → 一次性创建 `a`、`a/b`、`a/b/c` |
| `-m`       | 创建目录时直接设置权限（无需后续 `chmod`） | `mkdir -m 700 secret` → 创建 `secret` 目录并设置权限为 `rwx------`（仅所有者可访问） |
| `-v`       | 显示创建过程（verbose）               | `mkdir -v logs` → 输出：`mkdir: 已创建目录 'logs'` |

**示例**：  
创建一个带权限的多级目录：  

```bash
mkdir -p -m 755 project/{src,docs,bin}
# 等价于创建 project 目录，及其子目录 src、docs、bin，权限均为 755
```

### 2. `rmdir`：删除空目录

**功能**：仅删除 **空目录**（目录内无任何文件/子目录），非空目录无法删除（避免误删）。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| 无选项     | 删除指定空目录                        | `rmdir empty_dir` → 删除空目录 `empty_dir` |
| `-p`       | 递归删除空目录（从子到父，仅删除空的） | `rmdir -p a/b/c` → 若 `a/b/c`、`a/b`、`a` 均为空，则依次删除 |
| `-v`       | 显示删除过程                          | `rmdir -v temp` → 输出：`rmdir: 正在删除目录 'temp'` |

**限制**：若目录非空，会报错 `rmdir: 删除 'dir' 失败: 目录非空`，此时需用 `rm -r`。

### 3. `rm -r`：删除非空目录（强制删除）

**功能**：`rm` 是删除文件的命令，加 `-r`（递归）选项后可删除目录（包括目录内所有文件和子目录），**危险操作，谨慎使用**。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| `-r`       | 递归删除目录及内容（必须加，否则无法删除目录） | `rm -r old_dir` → 删除 `old_dir` 及其所有内容 |
| `-f`       | 强制删除（不提示确认，忽略不存在的文件） | `rm -rf bad_dir` → 强制删除 `bad_dir`，无任何提示 |
| `-i`       | 交互式删除（删除前逐一确认）          | `rm -ri test` → 每个文件/子目录删除前提示 `是否删除？` |
| `-v`       | 显示删除过程                          | `rm -rv logs` → 输出每个被删除的文件/目录名称 |

**警告**：`rm -rf /` 会删除系统所有文件（除非有保护机制），绝对禁止执行！日常使用建议优先用 `-i` 选项确认。

## 三、目录查看与列出（内容与属性）

### 1. `ls`：列出目录内容

**功能**：列出目录中的文件和子目录，是查看目录内容的核心命令，选项极其丰富。  
**常用选项（目录相关）**：

| 选项组合       | 说明                                  | 示例场景                          |
|----------------|---------------------------------------|-----------------------------------|
| `ls`           | 列出当前目录可见文件/目录（默认不显示隐藏项） | `ls` → 显示 `docs/ logs/ readme.txt` |
| `ls 目录路径`  | 列出指定目录内容                      | `ls /etc` → 列出 `/etc` 目录下的文件/目录 |
| `-l`           | 长格式显示（权限、所有者、大小、修改时间等） | `ls -l` → 显示详细信息，如 `drwxr-xr-x 2 user user 4096 9月 10 10:00 docs`（`d` 代表目录） |
| `-a`           | 显示所有内容（包括隐藏文件/目录，以 `.` 开头） | `ls -a` → 显示 `.bashrc/ .ssh/ docs/` |
| `-h`           | 以人类可读单位显示大小（K、M、G）     | `ls -lh` → 显示 `4.0K`（而非 `4096`） |
| `-t`           | 按修改时间排序（最新的在前）          | `ls -lt` → 最近修改的目录/文件排在前面 |
| `-r`           | 反向排序（配合 `-t` 则 oldest 在前）  | `ls -ltr` → 按修改时间从旧到新排列 |
| `-R`           | 递归列出所有子目录内容（目录树形式）  | `ls -R project` → 列出 `project` 及其所有子目录的内容 |
| `-d`           | 仅显示目录本身（而非目录内内容）      | `ls -ld docs` → 显示 `docs` 目录自身的详细信息（权限、大小等） |
| `-S`           | 按大小排序（从大到小）                | `ls -lS` → 目录/文件按大小降序排列 |

**示例**：  
查看当前目录下所有目录（包括隐藏目录）的详细信息，按大小排序：  

```bash
ls -ldh .*/ */  # .*/ 匹配隐藏目录，*/ 匹配普通目录，-ldh 显示目录自身的详细信息（人类可读）
```

### 2. `tree`：以树状结构显示目录

**功能**：递归列出目录内容，以树状结构展示（更直观），默认不预装，需手动安装。  
**安装**：  

- Ubuntu/Debian：`sudo apt install tree`  
- CentOS/RHEL：`sudo yum install tree`  
- macOS：`brew install tree`（需先安装 Homebrew）  

**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| 无选项     | 显示当前目录的树状结构（包含文件和目录） | `tree` → 以树状列出所有内容        |
| `-d`       | 仅显示目录（忽略文件）                | `tree -d` → 只展示目录的层级结构   |
| `-L n`     | 限制递归深度（n 为层数）              | `tree -L 2` → 只显示当前目录及下一级子目录 |
| `-a`       | 显示隐藏目录/文件                     | `tree -a` → 包含 `.git/ .config/` 等 |
| `-h`       | 显示目录/文件大小（人类可读）         | `tree -h` → 显示每个目录/文件的大小 |
| `-f`       | 显示完整路径（绝对路径）              | `tree -f` → 每个目录/文件前显示完整路径 |

**示例**：  
以树状显示 `project` 目录，只展示目录，深度为 2 层：  

```bash
tree -d -L 2 project
# 输出：
# project/
# ├── src/
# │   ├── main/
# │   └── test/
# └── docs/
#     └── api/
```

## 四、目录复制与移动

### 1. `cp -r`：复制目录

**功能**：`cp` 是复制文件的命令，加 `-r`（递归）选项后可复制目录（包括目录内所有文件和子目录）。  
**常用选项（目录相关）**：

| 选项组合       | 说明                                  | 示例                              |
|----------------|---------------------------------------|-----------------------------------|
| `-r` 或 `-R`   | 递归复制目录（必须加，否则无法复制目录） | `cp -r dir1 dir2` → 复制 `dir1` 到 `dir2`（若 `dir2` 不存在则创建，存在则复制到 `dir2/dir1`） |
| `-a`           | 归档复制（保留权限、所有者、时间戳等所有属性，等价于 `-dR --preserve=all`） | `cp -a /etc /backup/etc` → 复制 `/etc` 到 `/backup`，保留所有原始属性 |
| `-v`           | 显示复制过程                          | `cp -rv src/ dest/` → 输出每个被复制的文件/目录 |
| `-n`           | 不覆盖已存在的文件/目录（避免误覆盖） | `cp -rn old/ new/` → 若 `new` 中已有同名文件，不覆盖 |
| `-u`           | 仅复制源比目标新的文件/目录（增量复制） | `cp -ru updates/ target/` → 只复制 `updates` 中比 `target` 新的内容 |
| `-i`           | 覆盖前提示确认                        | `cp -ri doc/ backup/` → 若有同名文件，提示 `是否覆盖？` |

**示例**：  
将 `website` 目录完整复制到 `/var/www` 下，保留所有权限：  

```bash
cp -a website /var/www/
# 复制后路径为 /var/www/website
```

### 2. `mv`：移动或重命名目录

**功能**：移动目录到新位置，或对目录重命名（与文件操作一致，无需特殊选项）。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| 无选项     | 移动目录到目标路径                    | `mv docs/ /backup` → 将 `docs` 移动到 `/backup` 下 |
| 无选项     | 重命名目录（目标路径与源路径同目录）  | `mv old_dir new_dir` → 将 `old_dir` 改名为 `new_dir` |
| `-i`       | 移动/重命名前提示（若目标存在）       | `mv -i docs/ /backup` → 若 `/backup/docs` 存在，提示 `是否覆盖？` |
| `-v`       | 显示移动过程                          | `mv -v logs/ archive/` → 输出：`'logs/' -> 'archive/logs'` |
| `-u`       | 仅移动源比目标新的目录（较少用）      | `mv -u data/ backup/` → 若 `backup/data` 存在且更新，则不移动 |

**示例**：  
将当前目录的 `temp` 目录重命名为 `cache`，并显示过程：  

```bash
mv -v temp cache  # 输出：'temp' -> 'cache'
```

## 五、目录大小与磁盘使用

### 1. `du`：查看目录大小

**功能**：计算目录（或文件）所占用的磁盘空间大小。  
**常用选项**：

| 选项组合       | 说明                                  | 示例                              |
|----------------|---------------------------------------|-----------------------------------|
| `du 目录`      | 显示目录及其子目录的大小（默认单位：KB） | `du docs` → 显示 `docs` 及所有子目录的大小 |
| `-h`           | 以人类可读单位（K、M、G）显示         | `du -h downloads` → 输出：`2.5G downloads` |
| `-s`           | 仅显示目录总大小（不列出子目录）      | `du -sh project` → 输出：`10G project`（仅总大小） |
| `-a`           | 包含目录内文件的大小（默认只显示目录） | `du -ah docs` → 显示 `docs` 下每个文件和子目录的大小 |
| `--max-depth=n` | 限制递归深度（n=1 只显示当前目录的直接子目录） | `du -h --max-depth=1 /home` → 显示 `/home` 下每个直接子目录的大小 |
| `-c`           | 显示所有目录的总大小（最后一行加 `total`） | `du -hc dir1 dir2` → 分别显示 `dir1`、`dir2` 大小，最后显示总和 |

**示例**：  
查看 `/var` 目录下所有直接子目录的大小（按从大到小排序）：  

```bash
du -h --max-depth=1 /var | sort -hr
# 输出（示例）：
# 15G    /var/lib
# 5.2G   /var/log
# 1.3G   /var/cache
# ...
```

### 2. `df -h`：查看目录所在分区的磁盘使用

**功能**：`df` 用于查看磁盘分区的使用情况，结合目录路径可查看该目录所在分区的剩余空间。  
**用法**：  

```bash
df -h 目录路径  # 查看目录所在分区的总容量、已用、可用空间
```

**示例**：  
查看 `/home` 目录所在分区的使用情况：  

```bash
df -h /home
# 输出（示例）：
# 文件系统        容量  已用  可用 已用% 挂载点
# /dev/sda5       50G   20G   30G   40% /home
```

## 六、目录权限与属性管理

### 1. `chmod`：修改目录权限

**功能**：修改目录的访问权限（读 `r`、写 `w`、执行 `x`，对应数字 `4`、`2`、`1`），目录的 `x` 权限代表“能否进入该目录”。  
**常用选项与用法**：

| 权限形式       | 说明                                  | 示例                              |
|----------------|---------------------------------------|-----------------------------------|
| 数字权限       | `chmod [权限] 目录`（所有者/组/其他用户的权限和） | `chmod 755 docs` → 所有者 `rwx`，组和其他 `r-x`（7=4+2+1，5=4+1） |
| 符号权限       | `chmod [用户][操作][权限] 目录`（u=所有者，g=组，o=其他，a=所有） | `chmod u+rwx,g+rx,o+rx docs` → 等价于 755 |
| `-R`           | 递归修改目录及所有子目录/文件的权限    | `chmod -R 700 secret` → `secret` 及其内所有内容仅所有者可访问 |
| `-v`           | 显示权限修改过程                      | `chmod -v 755 logs` → 输出：`mode of 'logs' changed from 0700 (rwx------) to 0755 (rwxr-xr-x)` |

**关键说明**：  

- 目录必须有 `x` 权限才能 `cd` 进入；  
- 目录有 `r` 权限才能 `ls` 查看内容；  
- 目录有 `w` 权限才能在其中创建/删除文件/目录。  

### 2. `chown`：修改目录所有者

**功能**：修改目录的所有者（用户）和所属组。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| `chown 用户 目录` | 修改目录所有者为指定用户              | `chown zhang docs` → `docs` 所有者改为 `zhang` |
| `chown 用户:组 目录` | 同时修改所有者和所属组                | `chown zhang:dev team` → `team` 所有者为 `zhang`，所属组为 `dev` |
| `-R`       | 递归修改目录及所有子目录/文件的所有者  | `chown -R admin:staff /app` → `/app` 及其内容的所有者改为 `admin`，组改为 `staff` |
| `-v`       | 显示修改过程                          | `chown -v root:root /etc/config` → 输出修改信息 |

**注意**：普通用户需 `sudo` 权限才能修改所有者（如 `sudo chown root:root dir`）。

### 3. `chgrp`：修改目录所属组

**功能**：单独修改目录的所属组（`chown` 也可实现，但 `chgrp` 更直观）。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| `chgrp 组 目录` | 修改目录所属组为指定组                | `chgrp dev docs` → `docs` 所属组改为 `dev` |
| `-R`       | 递归修改目录及子目录的所属组          | `chgrp -R test /tmp/data` → `/tmp/data` 及其内容所属组改为 `test` |

**示例**：  
将 `project` 目录及其所有内容的所属组改为 `developers`：  

```bash
chgrp -R developers project
```

### 4. `lsattr`/`chattr`：查看/修改目录特殊属性

**功能**：Linux 支持一些特殊属性（如“不可删除”“只能追加”），通过这两个命令管理（主要用于保护重要目录）。  
**常用属性（目录相关）**：

| 属性       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| `i`        | 不可修改（无法删除、重命名、创建内容） | `chattr +i protected_dir` → 保护目录不被修改 |
| `a`        | 只能追加（可创建新内容，但不能删除/修改已有内容） | `chattr +a logs` → 日志目录只能新增文件，不能删除旧文件 |

**用法**：  

```bash
lsattr 目录  # 查看目录的特殊属性
chattr +i 目录  # 添加 i 属性（保护）
chattr -i 目录  # 移除 i 属性（取消保护）
```

**示例**：  
保护 `/etc/passwd` 所在目录（防止误删）：  

```bash
sudo chattr +i /etc
# 此时无法删除 /etc 下的文件，也不能新建文件，除非移除 i 属性
```

## 七、目录查找与比较

### 1. `find`：查找目录（按名称、属性等）

**功能**：在指定路径下递归查找符合条件的目录（或文件），支持多条件过滤。  
**常用查找条件（目录相关）**：

| 命令格式                          | 说明                                  | 示例                              |
|-----------------------------------|---------------------------------------|-----------------------------------|
| `find 路径 -type d -name "名称模式"` | 按名称查找目录（`-type d` 限定为目录） | `find /home -type d -name "docs"` → 在 `/home` 下找名为 `docs` 的目录 |
| `find 路径 -type d -iname "名称模式"` | 按名称查找（忽略大小写）              | `find / -type d -iname "log"` → 找名为 `log`、`Log`、`LOG` 的目录 |
| `find 路径 -type d -perm 权限`     | 按权限查找目录                        | `find / -type d -perm 777` → 找权限为 777（所有人可读写执行）的目录 |
| `find 路径 -type d -user 用户名`   | 按所有者查找目录                      | `find /var -type d -user root` → 找 `/var` 下所有者为 `root` 的目录 |
| `find 路径 -type d -mtime +n`      | 按修改时间查找（`+n` 表示 n 天前修改） | `find ./ -type d -mtime +30` → 找当前目录下 30 天前修改过的目录 |
| `find 路径 -type d -size +100M`    | 按大小查找（`+100M` 表示大于 100M）   | `find / -type d -size +1G` → 找大于 1G 的目录 |

**示例**：  
在 `/tmp` 下查找 7 天内修改过、名称包含 `cache` 的目录：  

```bash
find /tmp -type d -name "*cache*" -mtime -7
```

### 2. `diff -r`：比较两个目录的差异

**功能**：比较两个目录的内容差异（包括文件和子目录），递归检查每个文件。  
**常用选项**：

| 选项       | 说明                                  | 示例                              |
|------------|---------------------------------------|-----------------------------------|
| `-r`       | 递归比较子目录（必须加，否则只比较目录本身） | `diff -r dir1 dir2` → 比较 `dir1` 和 `dir2` 及其子目录的差异 |
| `-q`       | 仅显示“是否有差异”，不显示具体内容     | `diff -rq dir1 dir2` → 输出：`Only in dir1: file.txt` 或 `Files dir1/a and dir2/a differ` |
| `-u`       | 显示详细差异（类似补丁格式）          | `diff -ru dir1 dir2` → 详细显示不同文件的内容差异 |

**示例**：  
快速比较 `backup1` 和 `backup2` 两个目录的差异（只看哪些文件/目录不同）：  

```bash
diff -rq backup1 backup2
# 输出（示例）：
# Only in backup1: old.log
# Files backup1/report.txt and backup2/report.txt differ
```

## 八、其他实用命令

### 1. `pwdx`：查看进程的当前目录

**功能**：根据进程 ID（PID）查看该进程正在使用的当前工作目录（用于调试进程行为）。  
**用法**：  

```bash
pwdx 进程PID
```  

**示例**：  
查看 PID 为 1234 的进程的当前目录：  

```bash
pwdx 1234  # 输出：1234: /home/user/app
```

### 2. `cdargs`：目录快速跳转（需安装）

**功能**：为常用目录添加标签，快速跳转（无需输入完整路径），适合频繁切换目录的场景。  
**安装**：`sudo apt install cdargs`（Ubuntu/Debian）  
**用法**：  

```bash
ca -a work /home/user/project  # 为目录添加标签 work
ca work  # 快速跳转到标签为 work 的目录
ca -l    # 列出所有标签
```

## 总结

目录管理命令是 Linux 操作的基础，核心需掌握：  

- 导航：`cd`、`pwd`  
- 增删：`mkdir`、`rmdir`、`rm -r`  
- 查看：`ls`、`tree`  
- 复制移动：`cp -r`、`mv`  
- 权限：`chmod`、`chown`、`chgrp`  
- 查找比较：`find`、`diff -r`  

实际使用中，结合选项（如 `ls -l`、`cp -a`、`du -h`）可大幅提升效率，同时需注意 `rm -rf` 等危险命令的使用安全。
