# awk

`awk` 是一款强大的文本处理工具，主要用于**结构化文本分析**（如日志、CSV、配置文件等），其核心能力是**按行处理输入**，通过“模式匹配-动作执行”机制实现数据提取、转换、统计等操作。它支持正则表达式、条件判断、循环、数组等编程特性，是 Shell 脚本中处理文本的“瑞士军刀”。

## 一、基本概念与工作原理

### 1. 什么是 `awk`？

`awk` 得名于其三位开发者（Aho、Weinberger、Kernighan）的姓氏首字母，最初是 Unix 系统的文本处理工具，现主流版本为 GNU awk（`gawk`），兼容标准 `awk` 并扩展了更多功能。

### 2. 工作流程

`awk` 按**行**处理输入（文件或标准输入），核心流程：  

```txt
读取一行 → 分割为字段 → 检查是否匹配模式（pattern）→ 若匹配，执行动作（action）→ 重复直到所有行处理完毕
```

- **字段分割**：默认以**空格/制表符**为分隔符，可自定义（通过 `-F` 选项或 `FS` 变量）。  
- **模式（pattern）**：决定是否对当前行执行动作（如正则表达式、条件判断等）。  
- **动作（action）**：对匹配的行执行的操作（如打印、计算、替换等，用 `{}` 包裹）。  

## 二、基本语法

### 1. 命令格式

```bash
awk [选项] '模式 {动作}' [输入文件...]
```

- 若不指定输入文件，`awk` 从**标准输入**（如管道 `|` 传递的数据）读取内容。  
- 若省略“模式”，则对**所有行**执行动作；若省略“动作”，默认动作是 `print`（打印整行）。  

### 2. 核心示例

```bash
# 示例文件：test.txt（内容如下）
# name age score
# Alice 20 90
# Bob 21 85
# Charlie 19 95

# 1. 打印 test.txt 所有行（省略模式和动作，默认打印）
awk '' test.txt

# 2. 打印第2个字段（$2 表示第二个字段）
awk '{print $2}' test.txt  # 输出：age、20、21、19

# 3. 只打印 age > 20 的行的 name 和 score（模式：$2 > 20）
awk '$2 > 20 {print $1, $3}' test.txt  # 输出：Bob 85
```

## 三、核心概念：字段与变量

### 1. 字段引用

`awk` 将每行文本分割为多个“字段”，用 `$n` 表示第 `n` 个字段（`n` 为正整数）：  

- `$0`：表示**整行文本**（未分割的原始行）。  
- `$1`、`$2`...`$n`：表示第1、2...n个字段（字段编号从1开始）。  
- `$NF`：表示**最后一个字段**（`NF` 是内置变量，代表当前行的字段总数）。  
- `$(NF-1)`：表示倒数第二个字段，以此类推。  

示例：  

```bash
# 打印每行的最后一个字段
awk '{print $NF}' test.txt  # 输出：score、90、85、95

# 打印整行和字段数
awk '{print "行内容:", $0, "| 字段数:", NF}' test.txt
```

### 2. 内置变量（常用）

`awk` 提供了大量内置变量，用于控制处理逻辑和获取上下文信息：  

| 变量名   | 含义                                  | 示例（基于 test.txt）                  |
|----------|---------------------------------------|---------------------------------------|
| `FS`     | 输入字段分隔符（默认：空格/制表符）   | `awk 'BEGIN{FS=","} {print $1}'`  # 以逗号为分隔符 |
| `OFS`    | 输出字段分隔符（默认：空格）          | `awk 'BEGIN{OFS="|"} {print $1,$2}'`  # 用|分隔输出 |
| `NF`     | 当前行的字段总数（Number of Fields）  | `awk '{print NF}' test.txt`  # 输出：3、3、3、3（每行3个字段） |
| `NR`     | 当前处理的行号（全局，跨文件累计）    | `awk '{print NR, $0}' test.txt`  # 输出：1 name... 2 Alice... |
| `FNR`    | 当前文件的行号（仅对当前文件计数）    | `awk '{print FNR, $0}' a.txt b.txt`  # 分别对a.txt和b.txt从1计数 |
| `FILENAME` | 当前处理的文件名                      | `awk '{print FILENAME, $0}' test.txt`  # 输出：test.txt name... |
| `RS`     | 记录分隔符（默认：换行符 `\n`）       | `awk 'BEGIN{RS=";"} {print $0}'`  # 以;为行分隔符 |
| `ORS`    | 输出记录分隔符（默认：换行符 `\n`）   | `awk 'BEGIN{ORS=";"} {print $0}'`  # 输出行用;分隔 |

### 3. 自定义变量

可在命令行或脚本中定义变量，语法：  

- 命令行：`awk -v 变量名=值 '动作'`  
- 脚本内：直接赋值（`变量名=值`）  

示例：  

```bash
# 命令行传递变量（计算年龄+1）
awk -v add=1 '$1!="name" {print $1, $2+add}' test.txt  # 输出：Alice 21、Bob 22...

# 脚本内定义变量（统计总分）
awk 'BEGIN{total=0} $1!="name" {total+=$3} END{print "总分:", total}' test.txt  # 输出：总分: 270
```

## 四、模式（Pattern）：决定处理哪些行

模式用于筛选需要处理的行，支持多种类型：  

### 1. 正则表达式模式

格式：`/正则表达式/`，匹配**包含该正则**的行。  
示例：  

```bash
# 匹配包含 "Bob" 的行（整行任意位置）
awk '/Bob/ {print $0}' test.txt  # 输出：Bob 21 85

# 匹配第1个字段以 "A" 开头的行（用 ~ 表示匹配）
awk '$1 ~ /^A/ {print $0}' test.txt  # 输出：Alice 20 90

# 匹配第3个字段不以 "9" 开头的行（!~ 表示不匹配）
awk '$3 !~ /^9/ {print $0}' test.txt  # 输出：Bob 21 85
```

### 2. 比较表达式模式

格式：`字段/变量 运算符 值`，支持的运算符：`==`（等于）、`!=`（不等于）、`>`、`<`、`>=`、`<=`、`~`（匹配正则）、`!~`（不匹配正则）。  
示例：  

```bash
# 年龄大于20的行
awk '$2 > 20 {print $1}' test.txt  # 输出：Bob

# 分数等于90的行
awk '$3 == 90 {print $0}' test.txt  # 输出：Alice 20 90

# 名字不等于 "Alice" 的行
awk '$1 != "Alice" {print $1}' test.txt  # 输出：name、Bob、Charlie
```

### 3. 范围模式

格式：`模式1, 模式2`，匹配从“模式1首次成立”到“模式2首次成立”的**所有行**（包含首尾）。  
示例：  

```bash
# 从包含 "Alice" 的行到包含 "Bob" 的行（含两行）
awk '/Alice/, /Bob/ {print $0}' test.txt
# 输出：
# Alice 20 90
# Bob 21 85
```

### 4. 特殊模式：`BEGIN` 与 `END`

- `BEGIN`：在**处理任何输入行之前**执行（仅一次），常用于初始化变量、设置分隔符等。  
- `END`：在**所有输入行处理完毕后**执行（仅一次），常用于输出统计结果、汇总信息等。  

示例：  

```bash
# 打印标题，处理数据，最后输出统计
awk 'BEGIN {
    FS=" "               # 设置输入分隔符为空格
    OFS="\t"             # 设置输出分隔符为制表符
    print "姓名", "年龄", "成绩"  # 打印标题
}
$1 != "name" {          # 跳过首行（标题行）
    print $1, $2, $3     # 打印数据行
    total_score += $3    # 累计总分
}
END {
    print "-------------------------"
    print "平均分:", total_score/(NR-1)  # NR-1：减去标题行
}' test.txt
```

## 五、动作（Action）：对匹配行执行的操作

动作由 `{}` 包裹，支持赋值、打印、条件判断、循环、数组等，语句间用**分号**分隔。  

### 1. 打印操作（`print` 与 `printf`）

- `print`：简单打印，默认用 `OFS` 分隔字段，自动换行。  
  格式：`print 表达式1, 表达式2, ...`（逗号分隔字段）  
  示例：`print $1, "的年龄是", $2` → 输出：`Alice 的年龄是 20`  

- `printf`：格式化打印（同 Shell 的 `printf`），需显式指定换行符 `\n`。  
  格式：`printf "格式字符串", 表达式1, 表达式2, ...`  
  示例：`printf "姓名: %-10s 年龄: %d\n", $1, $2` → 左对齐姓名，输出：`姓名: Alice      年龄: 20`  

### 2. 条件判断（`if-else`）

格式：  

```awk
if (条件) {
    语句1
} else if (条件2) {
    语句2
} else {
    语句3
}
```

示例：  

```bash
# 根据分数评级
awk '$1 != "name" {
    if ($3 >= 90) {
        grade = "A"
    } else if ($3 >= 80) {
        grade = "B"
    } else {
        grade = "C"
    }
    print $1, "等级:", grade
}' test.txt
# 输出：
# Alice 等级: A
# Bob 等级: B
# Charlie 等级: A
```

### 3. 循环（`for`、`while`）

- `for` 循环：遍历数组或固定次数。  
  示例：遍历字段并打印（模拟 `print $0`）：  

  ```bash
  awk '{for(i=1; i<=NF; i++) {printf $i " "}; print ""}' test.txt
  ```

- `while` 循环：条件满足时重复执行。  
  示例：计算年龄的平方（直到计数器超过年龄）：  

  ```bash
  awk '$1 != "name" {
      i=1;
      while(i <= $2) {
          square = i*i;
          i++
      }
      print $1, "年龄平方:", square
  }' test.txt  # 输出：Alice 年龄平方: 400（20²）
  ```

### 4. 数组（关联数组）

`awk` 的数组是**关联数组**（哈希表），下标可以是**字符串或数字**，无需声明长度，直接赋值即可。  

示例：统计每个分数出现的次数：  

```bash
awk '$1 != "name" {
    score_count[$3]++  # 以分数为键，自增计数
}
END {
    for (s in score_count) {  # 遍历数组
        print "分数", s, "出现次数:", score_count[s]
    }
}' test.txt
# 输出：
# 分数 90 出现次数: 1
# 分数 85 出现次数: 1
# 分数 95 出现次数: 1
```

### 5. 内置函数（常用）

`awk` 提供丰富的内置函数，按功能分为：  

| 类别       | 函数示例                          | 功能描述                                  |
|------------|-----------------------------------|-------------------------------------------|
| 字符串函数 | `length(str)`                     | 返回字符串长度（无参则返回当前行长度）    |
|            | `sub(/正则/, 替换串, 目标串)`     | 替换目标串中第一个匹配正则的部分          |
|            | `gsub(/正则/, 替换串, 目标串)`    | 替换目标串中所有匹配正则的部分（全局替换）|
|            | `index(str, 子串)`                | 返回子串在str中的起始位置（未找到返回0）  |
|            | `split(str, 数组, 分隔符)`        | 按分隔符分割str到数组，返回字段数         |
| 数学函数   | `int(num)`                        | 取整数部分（截断小数）                    |
|            | `sqrt(num)`                       | 计算平方根                                |
|            | `rand()`                          | 生成0-1之间的随机数（需用srand()初始化）  |
| 其他       | `system(cmd)`                     | 执行Shell命令（返回退出码）               |
|            | `getline`                         | 读取下一行输入到$0                        |

示例：  

```bash
# 用 gsub 替换所有数字为 "NUM"
awk '{gsub(/[0-9]/, "NUM"); print $0}' test.txt
# 输出：name age score、Alice NUM NUM、Bob NUM NUM...

# 用 split 分割字符串到数组
awk 'BEGIN{
    str = "apple,banana,cherry"
    n = split(str, arr, ",")  # 按逗号分割
    for(i=1; i<=n; i++) print arr[i]
}'  # 输出：apple、banana、cherry
```

## 六、高级用法

### 1. 处理多个文件

`awk` 可同时处理多个文件，用 `FILENAME` 区分当前文件，`FNR` 记录当前文件行号：  

```bash
# 打印两个文件的内容，带文件名和行号
awk '{print FILENAME ":" FNR ": " $0}' a.txt b.txt
```

### 2. 从 Shell 传递变量

除了 `-v` 选项，还可在命令行末尾传递变量（需用 `'` 与 `"` 组合避免提前解析）：  

```bash
threshold=85
# 单引号内无法解析Shell变量，需拼接双引号
awk -v th=$threshold '$3 > th {print $1}' test.txt  # 输出：Alice、Charlie
```

### 3. 执行 Shell 命令（`system()`）

通过 `system()` 函数在 `awk` 中调用 Shell 命令：  

```bash
# 为每个用户创建目录（假设$1是用户名）
awk '$1 != "name" {system("mkdir -p user_" $1)}' test.txt
# 执行后会创建 user_Alice、user_Bob 等目录
```

### 4. 保存为脚本文件

将 `awk` 代码写入 `.awk` 文件，通过 `awk -f 脚本文件` 执行，便于复杂逻辑：  

```bash
# 脚本：score_analysis.awk
BEGIN {
    print "=== 成绩分析 ==="
    FS=" "
}
$1 == "name" {next}  # 跳过标题行
{
    names[NR-1] = $1  # 存储姓名（NR-1：跳过标题行）
    scores[NR-1] = $3
    total += $3
}
END {
    avg = total / (NR-1)
    print "平均分:", avg
    print "最高分获得者:"
    max_score = 0
    for(i=1; i<=NR-1; i++) {
        if (scores[i] > max_score) {
            max_score = scores[i]
            max_name = names[i]
        }
    }
    print max_name, "(", max_score, ")"
}

# 执行脚本
awk -f score_analysis.awk test.txt
```

## 七、常见示例

### 1. 统计日志中 404 错误的数量

```bash
awk '/404/ {count++} END {print "404错误数:", count}' access.log
```

### 2. 提取 CSV 文件中第 2 列大于 100 的行

```bash
awk -F ',' '$2 > 100 {print $0}' data.csv  # -F ',' 设逗号为分隔符
```

### 3. 计算某列的总和与平均值

```bash
# 计算 test.txt 中分数（第3列）的总和与平均值
awk '$1 != "name" {sum+=$3; count++} END {print "总和:", sum, "平均值:", sum/count}' test.txt
```

### 4. 替换文件中所有的 "old" 为 "new"

```bash
awk '{gsub(/old/, "new"); print $0}' input.txt > output.txt
```

## 八、总结

`awk` 是文本处理的强大工具，核心优势在于：  

- **按行处理**：适合结构化文本（日志、表格等）。  
- **模式匹配**：通过正则和条件筛选目标行。  
- **编程能力**：支持变量、数组、循环、函数，可实现复杂逻辑。  

掌握 `awk` 需重点理解“字段分割”“模式-动作”机制，以及内置变量和函数的用法，结合实际场景（如日志分析、数据统计、格式转换）练习可快速上手。
