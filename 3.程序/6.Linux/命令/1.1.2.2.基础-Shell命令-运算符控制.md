# 运算符依赖控制

在 Shell 中，多命令的执行依赖性主要通过**控制命令执行顺序的运算符**来实现，这些运算符基于前一个命令的**退出状态码**（0 表示成功，非 0 表示失败）或执行方式（如管道、后台运行等）来决定后续命令是否/如何执行。除了常见的 `||` 和 `&&`，还有其他多种运算符和组合方式，以下是详细说明：

## 一、基础执行控制运算符（基于退出状态）

这类运算符通过前一个命令的退出状态（`$?`）决定后续命令是否执行，核心是“短路逻辑”。

### 1. 分号 `;`：不依赖前命令结果，顺序执行

- **作用**：无论前一个命令成功（退出码 0）还是失败（退出码非 0），都会执行后面的命令，是“无条件顺序执行”。
- **语法**：`cmd1 ; cmd2 ; cmd3`
- **示例**：

  ```bash
  # 无论 ls 是否成功，都会执行 echo
  ls non_exist_file ; echo "执行完成"
  # 输出：ls: 无法访问 'non_exist_file': 没有那个文件或目录；执行完成
  ```

### 2. 逻辑与 `&&`：前命令成功才执行后命令

- **作用**：仅当前一个命令执行成功（退出码 0）时，才执行后面的命令（短路逻辑：前失败则后不执行）。
- **语法**：`cmd1 && cmd2 && cmd3`
- **示例**：

  ```bash
  # 仅当目录存在时，才进入目录并列出内容
  [ -d "/home" ] && cd /home && ls
  # 解释：[ -d "/home" ] 是判断目录存在的测试命令（成功返回 0），成功后才执行 cd 和 ls
  ```

### 3. 逻辑或 `||`：前命令失败才执行后命令

- **作用**：仅当前一个命令执行失败（退出码非 0）时，才执行后面的命令（短路逻辑：前成功则后不执行）。
- **语法**：`cmd1 || cmd2 || cmd3`
- **示例**：

  ```bash
  # 若文件不存在，则创建文件
  [ -f "test.txt" ] || touch test.txt
  # 解释：[ -f "test.txt" ] 测试文件是否存在（不存在返回非 0），失败后执行 touch 创建
  ```

### 4. 逻辑非 `!`：反转命令退出状态

- **作用**：不直接控制执行顺序，但会反转命令的退出状态（0 变非 0，非 0 变 0），常与 `&&`/`||` 配合使用。
- **语法**：`! cmd`
- **示例**：

  ```bash
  # 若文件不存在（! 反转了 [ -f ] 的结果），则输出提示
  ! [ -f "test.txt" ] && echo "文件不存在"
  # 等价于：[ ! -f "test.txt" ] && echo "文件不存在"
  ```

## 二、管道运算符 `|`：依赖前命令的输出

- **作用**：将前一个命令的**标准输出（stdout）** 作为后一个命令的**标准输入（stdin）**，实现命令间的数据传递。  
  注意：管道不直接依赖前命令的退出状态（默认情况下，只要最后一个命令成功，整个管道返回 0），但可通过 `set -o pipefail` 改变这一行为（管道中任何命令失败，整体返回非 0）。
- **语法**：`cmd1 | cmd2 | cmd3`
- **示例**：

  ```bash
  # 将 ls 的输出通过管道传给 grep，筛选含 .txt 的文件
  ls | grep ".txt"
  
  # 启用 pipefail：若管道中任一命令失败，整体返回非 0
  set -o pipefail
  ls non_exist_file | grep "a"  # ls 失败，整个管道返回非 0
  echo $?  # 输出非 0（默认情况下此处会返回 0，因为 grep 成功执行但无匹配）
  ```

## 三、后台执行 `&`：不等待前命令完成

- **作用**：将前一个命令放入**后台运行**，不阻塞当前 Shell，后续命令无需等待其完成即可立即执行（并行执行的依赖关系）。
- **语法**：`cmd1 & cmd2`
- **示例**：

  ```bash
  # 后台运行长时间任务（如备份），同时执行后续命令
  tar -czf backup.tar.gz /home & echo "备份已启动，可继续操作"
  # 输出：备份已启动，可继续操作（此时 tar 在后台运行）
  ```

## 四、命令分组：改变执行范围和环境

通过分组运算符将多个命令视为一个整体，控制它们的执行环境或依赖关系。

### 1. 子shell分组 `(...)`

- **作用**：括号内的命令在**子Shell**中执行（不影响当前Shell环境），整体作为一个命令单元，退出状态为最后一个命令的退出状态。
- **语法**：`(cmd1; cmd2; cmd3) && cmd4`（分组内命令执行完后，根据整体状态决定是否执行 cmd4）
- **示例**：

  ```bash
  # 分组内的 cd 不影响当前Shell的目录
  (cd /tmp; ls) && echo "分组执行成功"
  pwd  # 输出当前目录（未被 cd /tmp 改变）
  ```

### 2. 当前Shell分组 `{ ...; }`

- **作用**：括号内的命令在**当前Shell**中执行（影响当前环境），语法上要求最后一个命令后必须有分号 `;`，且 `{` 后和 `}` 前需有空格。
- **语法**：`{ cmd1; cmd2; cmd3; } || cmd4`（分组内命令执行完后，根据整体状态决定是否执行 cmd4）
- **示例**：

  ```bash
  # 分组内的 cd 会改变当前Shell的目录
  { cd /tmp; ls; } && echo "分组执行成功"
  pwd  # 输出 /tmp（当前目录被改变）
  ```

## 五、组合使用：模拟条件判断

通过 `&&`、`||` 等组合，可模拟简单的 `if-else` 逻辑，实现更复杂的依赖关系。

### 示例 1：`cmd1 && cmd2 || cmd3`（类似 if-else）

```bash
# 若文件存在，则输出“存在”，否则输出“不存在”
[ -f "test.txt" ] && echo "存在" || echo "不存在"
# 等价于：
# if [ -f "test.txt" ]; then echo "存在"; else echo "不存在"; fi
```

### 示例 2：结合分组和管道

```bash
# 若目录存在，压缩其中的 .log 文件并备份，否则提示错误
[ -d "/var/log" ] && (cd /var/log; tar -czf logs.tar.gz *.log) && echo "备份完成" || echo "目录不存在"
```

## 六、核心总结

| 运算符       | 作用描述                                  | 依赖逻辑                                  | 示例                                  |
|--------------|-------------------------------------------|-------------------------------------------|---------------------------------------|
| `;`          | 顺序执行，不依赖前命令结果                | 前命令无论成败，后命令必执行              | `ls; echo "done"`                     |
| `&&`         | 前命令成功（0），才执行后命令             | 前成功 → 后执行；前失败 → 后不执行        | `mkdir dir && cd dir`                 |
| `||`         | 前命令失败（非0），才执行后命令           | 前失败 → 后执行；前成功 → 后不执行        | `rm file || echo "文件不存在"`        |
| `!`          | 反转命令退出状态                          | 配合 `&&`/`||` 使用，改变判断条件         | `! [ -f file ] && echo "不存在"`      |
| `|`          | 前命令输出作为后命令输入                  | 依赖数据传递，默认不依赖退出状态          | `ps aux | grep "nginx"`               |
| `&`          | 前命令后台运行，后命令立即执行            | 不等待前命令完成，并行执行                | `long_task & echo "任务启动"`         |
| `(...)`      | 子Shell中执行分组命令，不影响当前环境     | 分组整体作为一个单元，按退出状态判断      | `(cd /tmp; ls) && echo "成功"`        |
| `{ ...; }`   | 当前Shell中执行分组命令，影响当前环境     | 分组整体作为一个单元，按退出状态判断      | `{ cd /tmp; ls; } && echo "成功"`     |

这些运算符是 Shell 脚本中控制命令执行流程的核心工具，通过组合使用可以实现复杂的条件依赖和流程控制，替代部分 `if-else` 语句的功能，让脚本更简洁高效。
