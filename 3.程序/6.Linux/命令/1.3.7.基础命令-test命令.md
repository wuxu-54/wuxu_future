# test命令

`test` 是 Shell 中用于**条件测试**的内置命令，主要用于判断文件属性、字符串特性、整数大小等条件是否成立，是脚本中实现分支逻辑（如 `if` 语句）的核心工具。其语法简洁，兼容性强，所有 POSIX 标准的 Shell（如 `bash`、`sh`、`zsh`）均支持。

## 一、基本语法

`test` 命令有两种等价的语法形式，功能完全一致：  

```bash
# 形式1：使用 test 关键字
test 条件表达式

# 形式2：使用方括号（更常用，注意 [ 后和 ] 前必须有空格）
[ 条件表达式 ]
```

- **核心作用**：判断“条件表达式”是否成立，通过**退出状态码**返回结果：  
  - 条件成立 → 退出状态码为 `0`（Shell 中“真”的表示）。  
  - 条件不成立 → 退出状态码为**非0**（通常是 `1`，表示“假”）。  

- **使用场景**：常与 `if`、`while` 等流程控制语句结合，例如：  

  ```bash
  # 判断文件是否存在
  if test -f "file.txt"; then
      echo "文件存在"
  fi

  # 等价于（用 [ ] 形式）
  if [ -f "file.txt" ]; then
      echo "文件存在"
  fi
  ```

## 二、文件测试（最常用）

`test` 可测试文件/目录的各种属性（存在性、类型、权限、时间等），核心语法：  

```bash
test [选项] 文件路径
# 或
[ 选项 文件路径 ]
```

常用文件测试选项：  

| 选项   | 含义描述（条件成立的情况）                          | 示例                                      |
|--------|---------------------------------------------------|-------------------------------------------|
| `-e`   | 文件或目录**存在**（exists）                       | `[ -e "/etc/passwd" ]` → 检查 `/etc/passwd` 是否存在 |
| `-f`   | 是**普通文件**（file，非目录/设备文件）             | `[ -f "test.sh" ]` → 检查是否为普通文件    |
| `-d`   | 是**目录**（directory）                            | `[ -d "/home" ]` → 检查是否为目录          |
| `-L`   | 是**符号链接**（link）                             | `[ -L "/usr/bin/python" ]` → 检查是否为符号链接 |
| `-s`   | 是**非空文件**（size > 0）                         | `[ -s "log.txt" ]` → 检查文件是否有内容    |
| `-r`   | 文件**可读**（readable，当前用户有读权限）          | `[ -r "secret.txt" ]` → 检查是否可读      |
| `-w`   | 文件**可写**（writable，当前用户有写权限）          | `[ -w "data.csv" ]` → 检查是否可写        |
| `-x`   | 文件**可执行**（executable，当前用户有执行权限）    | `[ -x "./script.sh" ]` → 检查是否可执行    |
| `-g`   | 文件设置了**set-group-id** 权限（sgid）             | `[ -g "shared.txt" ]` → 检查是否有sgid权限 |
| `-u`   | 文件设置了**set-user-id** 权限（suid）              | `[ -u "/usr/bin/passwd" ]` → 检查是否有suid权限 |
| `-k`   | 文件设置了**sticky bit** 权限（粘滞位）             | `[ -k "/tmp" ]` → 检查 `/tmp` 是否有粘滞位 |
| `-N`   | 文件**自上次读取后被修改过**（newer）               | `[ -N "notes.txt" ]` → 检查是否被修改过    |
| `file1 -nt file2` | file1 比 file2 **更新**（newer than，修改时间更新） | `[ "a.txt" -nt "b.txt" ]` → a比b新？      |
| `file1 -ot file2` | file1 比 file2 **更旧**（older than，修改时间更旧） | `[ "a.txt" -ot "b.txt" ]` → a比b旧？      |
| `file1 -ef file2` | file1 和 file2 是**硬链接**（same inode）           | `[ "link.txt" -ef "orig.txt" ]` → 是否为同一文件的硬链接 |

**示例解析**：  

```bash
# 检查文件是否存在且为普通文件
if [ -e "report.pdf" ] && [ -f "report.pdf" ]; then
    echo "report.pdf 是存在的普通文件"
fi

# 检查目录是否存在且可写
if [ -d "data" ] && [ -w "data" ]; then
    echo "data目录存在且可写"
else
    mkdir -p "data"  # 不存在则创建
fi

# 检查文件是否为空
if [ -s "log.txt" ]; then
    echo "log.txt 有内容"
else
    echo "log.txt 为空或不存在"
fi
```

## 三、字符串测试

用于判断字符串的空值、相等性、比较等，核心语法：  

```bash
test 字符串表达式
# 或
[ 字符串表达式 ]
```

常用字符串测试选项/运算符：  

| 表达式形式         | 含义描述（条件成立的情况）                          | 示例                                      |
|--------------------|---------------------------------------------------|-------------------------------------------|
| `-z "$str"`        | 字符串 `str` 长度为**0**（空字符串）               | `[ -z "$name" ]` → 变量 name 为空？       |
| `-n "$str"`        | 字符串 `str` 长度**不为0**（非空字符串）           | `[ -n "$name" ]` → 变量 name 非空？       |
| `"$str1" = "$str2"` | 字符串 `str1` 与 `str2` **相等**（= 前后需空格）   | `[ "$a" = "$b" ]` → a和b是否相等？        |
| `"$str1" != "$str2"`| 字符串 `str1` 与 `str2` **不相等**                 | `[ "$a" != "$b" ]` → a和b是否不等？       |
| `"$str1" \< "$str2"`| 字符串 `str1` 按字典序**小于** `str2`（需转义<）   | `[ "apple" \< "banana" ]` → apple在banana前？ |
| `"$str1" \> "$str2"`| 字符串 `str1` 按字典序**大于** `str2`（需转义>）   | `[ "cat" \> "bat" ]` → cat在bat后？       |

**关键注意事项**：  

1. 字符串变量必须用**双引号包裹**（如 `"$str"`），否则：  
   - 若变量为空，会被解析为无参数，导致语法错误。  
   - 若变量含空格，会被拆分为多个参数，导致判断错误。  
   示例：`[ -n $name ]` 错误（变量为空时等价于 `[ -n ]`，结果为真），正确写法是 `[ -n "$name" ]`。  

2. 比较运算符 `=`、`!=`、`<`、`>` 前后必须有**空格**，否则会被视为字符串的一部分。  
3. `<` 和 `>` 在 `[ ]` 中需要用反斜杠 `\` 转义（避免被Shell解析为重定向），在 `[[ ]]`（Bash扩展）中可直接使用。  

**示例解析**：  

```bash
name="Alice"
empty_str=""

# 测试非空字符串
if [ -n "$name" ]; then
    echo "name 是非空字符串：$name"  # 会执行
fi

# 测试空字符串
if [ -z "$empty_str" ]; then
    echo "empty_str 是空字符串"  # 会执行
fi

# 字符串相等比较
if [ "$name" = "Alice" ]; then
    echo "name 是 Alice"  # 会执行
fi

# 字符串字典序比较
if [ "apple" \< "banana" ]; then
    echo "apple 在字典序中小于 banana"  # 会执行
fi
```

## 四、整数测试

用于比较两个整数的大小关系（不支持浮点数），核心语法：  

```bash
test 整数1 运算符 整数2
# 或
[ 整数1 运算符 整数2 ]
```

常用整数比较运算符：  

| 运算符 | 含义描述（条件成立的情况）              | 示例                          |
|--------|---------------------------------------|-------------------------------|
| `-eq`  | 整数1 **等于** 整数2（equal）          | `[ 10 -eq 10 ]` → 10等于10？  |
| `-ne`  | 整数1 **不等于** 整数2（not equal）    | `[ 5 -ne 3 ]` → 5不等于3？    |
| `-gt`  | 整数1 **大于** 整数2（greater than）   | `[ 8 -gt 3 ]` → 8大于3？      |
| `-lt`  | 整数1 **小于** 整数2（less than）      | `[ 2 -lt 5 ]` → 2小于5？      |
| `-ge`  | 整数1 **大于等于** 整数2（greater or equal） | `[ 10 -ge 10 ]` → 10>=10？ |
| `-le`  | 整数1 **小于等于** 整数2（less or equal）    | `[ 3 -le 5 ]` → 3<=5？     |

**注意事项**：  

- 运算符必须是 `-eq`、`-gt` 等形式，**不能直接使用 `=`、`>`、`<`**（这些是字符串运算符，用于整数会导致错误）。  
- 比较对象必须是**整数**（如 `123`、变量值为整数的 `$num`），若为字符串或浮点数，会报语法错误。  

**示例解析**：  

```bash
age=25
limit=18

# 整数大于比较
if [ $age -gt $limit ]; then
    echo "年龄超过限制"  # 会执行（25>18）
fi

# 整数等于比较
count=0
if [ $count -eq 0 ]; then
    echo "计数为0"  # 会执行
fi

# 结合变量运算（先计算再比较）
a=5
b=3
if [ $((a + b)) -ge 7 ]; then  # $((a+b)) 计算5+3=8
    echo "和大于等于7"  # 会执行（8>=7）
fi
```

## 五、逻辑运算（组合条件）

`test` 支持通过逻辑运算符组合多个条件，实现复杂判断，常用逻辑运算符：  

| 运算符 | 含义       | 语法形式（以两个条件为例）               | 说明                                  |
|--------|------------|------------------------------------------|---------------------------------------|
| `!`    | 逻辑非     | `! 条件`                                 | 条件不成立时，结果为真                |
| `-a`   | 逻辑与     | `条件1 -a 条件2`                         | 两个条件都成立时，结果为真（单test内） |
| `-o`   | 逻辑或     | `条件1 -o 条件2`                         | 至少一个条件成立时，结果为真（单test内） |
| `&&`   | 逻辑与     | `[ 条件1 ] && [ 条件2 ]`                 | 前一个条件成立，才判断后一个（多test） |
| `||`   | 逻辑或     | `[ 条件1 ] || [ 条件2 ]`                 | 前一个条件不成立，才判断后一个（多test） |

**`-a`/`-o` 与 `&&`/`||` 的区别**：  

- `-a` 和 `-o` 是 `test` 命令**内部的逻辑运算符**，用于在一个 `[ ]` 中组合条件。  
- `&&` 和 `||` 是 **Shell 本身的逻辑运算符**，用于连接多个 `[ ]` 命令（或其他命令）。  

推荐使用 `&&`/`||`，因为可读性更好，且避免 `-a`/`-o` 可能的优先级混淆。  

**示例解析**：  

```bash
file="data.txt"
num=15

# 逻辑非（!）
if [ ! -f "$file" ]; then
    echo "$file 不是普通文件"  # 若文件不存在，会执行
fi

# 逻辑与（-a，单test内）
if [ -f "$file" -a $num -gt 10 ]; then
    echo "文件存在且数字大于10"
fi

# 逻辑与（&&，多test）（推荐）
if [ -f "$file" ] && [ $num -gt 10 ]; then
    echo "文件存在且数字大于10"  # 与上等价，更易读
fi

# 逻辑或（-o，单test内）
if [ -d "$file" -o -L "$file" ]; then
    echo "是目录或符号链接"
fi

# 逻辑或（||，多test）（推荐）
if [ -d "$file" ] || [ -L "$file" ]; then
    echo "是目录或符号链接"  # 与上等价，更易读
fi

# 复杂组合（优先级：! > -a > -o，建议用括号分组）
if [ \( -f "$file" -a -r "$file" \) -o $num -lt 5 ]; then
    echo "（文件存在且可读）或者（数字小于5）"
fi
```

- 注意：在 `[ ]` 中用 `()` 分组时，需用反斜杠转义 `\( \)`，否则会被Shell解析为子Shell。  

## 六、与 `[[ ]]`（Bash扩展）的区别

`[[ ]]` 是 Bash 对 `[ ]`（即 `test`）的扩展语法，功能更强大，两者的核心区别：  

| 特性                | `test`/`[ ]`（POSIX标准）              | `[[ ]]`（Bash扩展）                    |
|---------------------|----------------------------------------|----------------------------------------|
| 兼容性              | 所有Shell支持                           | 仅 Bash、zsh 等支持                     |
| 字符串比较          | `<`/`>` 需转义（`\<`/`\>`）              | 可直接用 `<`/`>`，无需转义              |
| 逻辑运算符          | 用 `-a`/`-o`（单命令内）                | 支持 `&&`/`||`（内部直接使用）          |
| 正则匹配            | 不支持                                  | 支持 `=~` 运算符（如 `[[ $str =~ ^[0-9]+$ ]]`） |
| 变量引用            | 必须用双引号包裹（避免空格问题）        | 变量可不用双引号（但建议保留）          |
| 分组                | 需用 `\( \)` 转义                       | 直接用 `()` 分组，无需转义              |

**示例**：  

```bash
# [[ ]] 中直接使用 && 和 <
if [[ "apple" < "banana" && -f "file.txt" ]]; then
    echo "条件成立"
fi

# [[ ]] 支持正则匹配
str="12345"
if [[ $str =~ ^[0-9]+$ ]]; then
    echo "str 是纯数字"  # 会执行
fi
```

## 七、退出状态码

`test` 命令的核心是通过退出状态码表示条件是否成立：  

- 条件成立 → 退出状态码 `0`（`$?` 为 `0`）。  
- 条件不成立 → 退出状态码 `1`（`$?` 为 `1`）。  
- 语法错误 → 退出状态码 `2`（如参数缺失、运算符错误）。  

示例：  

```bash
[ -f "non_exist.txt" ]
echo $?  # 输出 1（文件不存在，条件不成立）

[ -d "/home" ]
echo $?  # 输出 0（目录存在，条件成立）
```

## 八、综合示例

### 1. 检查文件是否存在且可执行，若否则提示并退出

```bash
script="./install.sh"
if [ ! -f "$script" ] || [ ! -x "$script" ]; then
    echo "错误：$script 不存在或不可执行"
    exit 1
fi
echo "执行安装脚本..."
$script
```

### 2. 验证用户输入是否为正整数

```bash
read -p "请输入年龄：" age
# 检查是否为空 + 是否为纯数字 + 是否大于0
if [ -z "$age" ] || [[ ! "$age" =~ ^[0-9]+$ ]] || [ $age -le 0 ]; then
    echo "输入错误：请输入正整数"
else
    echo "您输入的年龄是：$age"
fi
```

### 3. 比较两个文件的修改时间

```bash
file1="a.txt"
file2="b.txt"
if [ -e "$file1" ] && [ -e "$file2" ]; then
    if [ "$file1" -nt "$file2" ]; then
        echo "$file1 比 $file2 新"
    elif [ "$file1" -ot "$file2" ]; then
        echo "$file1 比 $file2 旧"
    else
        echo "$file1 和 $file2 修改时间相同"
    fi
else
    echo "文件不存在"
fi
```

## 总结

`test` 命令（及等价的 `[ ]`）是 Shell 脚本中条件判断的基础，主要用于：  

- 检查文件/目录的属性（存在性、类型、权限等）。  
- 判断字符串的空值、相等性和字典序。  
- 比较整数的大小关系。  
- 通过逻辑运算符组合多个条件。  

掌握 `test` 的用法，能帮助你实现脚本中的分支逻辑和流程控制。对于 Bash 环境，可结合 `[[ ]]` 的扩展功能（如正则匹配）提升效率，但需注意兼容性；若需跨 Shell 兼容，优先使用 POSIX 标准的 `[ ]`。
