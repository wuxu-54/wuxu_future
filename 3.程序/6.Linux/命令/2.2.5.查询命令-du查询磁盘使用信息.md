# du

`du`（disk usage）是 Linux 中用于查看文件和目录磁盘占用空间的命令，可精确统计指定路径下的存储使用情况，是系统管理和磁盘清理的常用工具。以下是其详细说明：

## 一、基本语法

```bash
du [选项] [文件/目录...]
```

- **默认行为**：若不指定`[文件/目录]`，默认统计当前目录（`.`）下所有子目录的磁盘使用情况（递归），输出结果以**块（block）** 为单位（默认 1 块 = 512 字节，不同系统可能有差异）。  
- **核心功能**：统计文件/目录实际占用的磁盘空间（按文件系统的块分配计算，非文件的“表观大小”）。

## 二、常用选项（基础篇）

### 1. 单位转换（可读性优化）

- `-h`（--human-readable）：以人类可读的格式显示（自动转换为 K、M、G 等单位，1K=1024字节）。  
  示例：`du -h /home` → 显示 `/home` 目录下各子项的大小（如 `4.0K  ./docs`、`2.5G  ./videos`）。

- `-H`（--si）：与 `-h` 类似，但采用国际单位制（1K=1000字节，而非1024），适合需要十进制单位的场景。  
  示例：`du -H file.txt` → 若文件为 1024 字节，`-h` 显示 `1.0K`，`-H` 显示 `1.0K`（但 1000 字节时两者均为 `1.0K`）。

- `-k`：强制以 KB（1024字节）为单位（等价于 `--block-size=1K`）。  
- `-m`：强制以 MB（1024KB）为单位（等价于 `--block-size=1M`）。  
- `-g`：强制以 GB（1024MB）为单位（等价于 `--block-size=1G`）。  
- `-b`（--bytes）：以字节（byte）为单位，精确显示实际占用的字节数。  

### 2. 统计范围控制

- `-a`（--all）：不仅显示目录大小，还显示**所有文件**的大小（默认只显示目录）。  
  示例：`du -ah ~/Downloads` → 列出 `Downloads` 下所有文件和子目录的大小。

- `-s`（--summarize）：只显示指定路径的**总大小**（不展开子目录/文件）。  
  示例：`du -sh /var` → 仅输出 `/var` 目录的总大小（如 `8.3G  /var`）。

- `--max-depth=N`：限制统计的目录深度（`N` 为非负整数，`0` 表示只统计自身）。  
  示例：`du -h --max-depth=1 /etc` → 只显示 `/etc` 下一级目录/文件的大小（不深入子目录）。  
  （注：部分系统可用 `-d N` 替代，如 `du -hd 1 /etc`，效果相同）。

- `-x`（--one-file-system）：只统计与当前目录所在**同一文件系统**的文件/目录（不跨越挂载点，如避免统计 `/mnt` 下挂载的其他分区）。  
  示例：`du -xh /` → 统计根目录大小，但不包含其他分区（如 `/boot` 若为独立分区则会被排除）。

### 3. 输出细节调整

- `-c`（--total）：在最后一行显示所有统计项的**总和**（总计）。  
  示例：`du -hc /home /var` → 分别显示 `/home` 和 `/var` 的大小，最后一行显示 `total: 10.8G`。

- `-L`（--dereference）：跟随符号链接（默认不跟随，符号链接本身大小通常为 0 或指向路径的长度）。  
  示例：`du -hL /usr/local/bin` → 若 `bin` 是符号链接，会统计其指向的实际目录大小。

- `-S`（--separate-dirs）：只显示目录自身的大小，**不包含子目录**的大小（默认显示目录+所有子目录的总大小）。  
  示例：`du -hS docs` → 仅显示 `docs` 目录中直接包含的文件大小，不包括其下子目录的内容。

## 三、高级选项（进阶篇）

### 1. 特殊统计方式

- `--apparent-size`：显示文件的**表观大小**（即文件内容的实际字节数，而非磁盘占用的块大小）。  
  说明：磁盘存储按“块”分配（如 4KB/块），一个 100 字节的文件也会占用 4KB 磁盘空间（`du` 默认显示 4KB），而 `--apparent-size` 显示 100 字节。  
  示例：`du -h --apparent-size smallfile.txt` → 输出 `100B  smallfile.txt`。

- `-D`（--dereference-args）：仅跟随作为命令参数的符号链接（不跟随子目录中的链接）。  
  示例：`du -hD /usr/bin/python` → 若 `python` 是符号链接，统计其指向的实际文件大小，而子目录中的链接不处理。

### 2. 过滤与排除

- `--exclude=PATTERN`：排除匹配 `PATTERN`（通配符模式）的文件/目录。  
  示例：`du -h --exclude="*.log" /var/log` → 统计 `/var/log` 大小，但排除所有 `.log` 文件。

- `--exclude-from=FILE`：从 `FILE` 中读取多个排除模式（每行一个模式）。  
  示例：`du -h --exclude-from=exclude.txt /data` → 排除 `exclude.txt` 中列出的所有模式。

### 3. 时间与权限相关

- `--time`：显示每个目录的**最后修改时间**（等价于 `ls -l` 中的修改时间）。  
  示例：`du -h --time /home/user` → 输出目录大小的同时，显示最后修改时间（如 `2024-09-11 14:30`）。

- `--time=WORD`：指定显示的时间类型（`atime` 访问时间、`ctime` 状态时间，默认 `mtime` 修改时间）。  
  示例：`du -h --time=atime /tmp` → 显示 `/tmp` 下目录的最后访问时间。

### 4. 其他实用选项

- `-0`（--null）：输出的文件名以 `null` 字符分隔（解决文件名含空格/换行的问题，常与 `xargs -0` 配合）。  
  示例：`du -0h --max-depth=1 | xargs -0 echo` → 安全处理含特殊字符的目录名。

- `--block-size=SIZE`：自定义块大小（如 `1K`、`2M`、`512` 等），覆盖默认的 512 字节块。  
  示例：`du --block-size=4K /boot` → 以 4KB 块为单位统计 `/boot` 大小。

## 四、典型示例

1. **查看当前目录总大小**  

   ```bash
   du -sh    # 等价于 du --summarize --human-readable .
   ```

2. **列出当前目录下所有文件和子目录的大小（含隐藏文件）**  

   ```bash
   du -ah    # -a 显示所有文件，-h 人类可读
   ```

3. **查看当前目录下一级目录的大小（不深入子目录）**  

   ```bash
   du -hd 1  # -d 1 限制深度为1，-h 人类可读
   ```

4. **统计多个目录的大小并显示总计**  

   ```bash
   du -hc /home /var /tmp  # -c 显示总计
   ```

5. **查找大于1GB的目录（结合排序）**  

   ```bash
   du -h --max-depth=1 / | grep -E 'G' | sort -hr
   # 解释：统计/下一级目录，筛选含"G"的项，按大小倒序排列
   ```

6. **排除特定类型文件后统计大小**  

   ```bash
   du -h --exclude="*.tmp" --exclude="*.bak" /data
   ```

7. **对比文件的磁盘占用与表观大小**  

   ```bash
   du -h file.txt           # 磁盘占用（如 4.0K）
   du -h --apparent-size file.txt  # 表观大小（如 100B）
   ```

## 五、注意事项

1. **`du` 与 `df` 的区别**：  
   - `du` 统计**文件/目录实际占用的磁盘空间**（按文件系统块分配计算）。  
   - `df` 统计**文件系统的整体使用情况**（包括已分配但未使用的块、预留空间等）。  
   例如：删除大文件后，`du` 会立即反映变化，但 `df` 可能需等待进程释放文件句柄后才更新。

2. **权限问题**：访问无权限的目录时会报错，可加 `2>/dev/null` 忽略错误：  

   ```bash
   du -h /root 2>/dev/null  # 忽略无权限的错误信息
   ```

3. **符号链接处理**：默认不跟随符号链接（统计为 0 或路径长度），需显式加 `-L` 或 `-D` 跟随。

4. **性能影响**：递归统计大目录（如 `/`）时可能耗时较长，建议结合 `--max-depth` 限制范围，或使用 `nohup` 后台执行。

通过灵活组合上述选项，`du` 可满足从简单的目录大小查询到复杂的磁盘使用分析等多种需求，是 Linux 系统中管理磁盘空间的核心工具。
