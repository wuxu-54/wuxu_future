# printf

`printf` 是 Shell 中用于**格式化输出**的命令，功能类似 C 语言中的 `printf` 函数，相比 `echo` 具有更强的格式化能力（支持自定义宽度、对齐方式、精度等），是脚本中精确控制输出格式的核心工具。

## 一、基本语法

```bash
printf "格式字符串" [参数1 参数2 ...]
```

- **格式字符串**：包含普通字符（直接输出）和**转换说明符**（以 `%` 开头，用于指定参数的输出格式，如 `%s`、`%d` 等）。  
- **参数**：需按格式字符串中转换说明符的顺序提供，用于填充格式中的占位符。  

## 二、核心特性（与 `echo` 的区别）

1. **无自动换行**：`printf` 不会像 `echo` 那样自动在输出末尾添加换行符（`\n`），需显式指定。  
2. **严格的格式匹配**：转换说明符的数量与参数数量需对应（不匹配时会重复使用格式或用空值填充）。  
3. **丰富的格式化选项**：支持控制字段宽度、对齐方式、数字精度、填充字符等。  

## 三、常用转换说明符（格式占位符）

转换说明符用于指定参数的类型和输出格式，基本格式为：`%[修饰符]转换字符`，常用转换字符如下：

| 转换字符 | 含义                                  | 示例（参数值）          | 输出结果          |
|----------|---------------------------------------|-------------------------|-------------------|
| `%s`     | 输出字符串（默认原样输出）            | `printf "%s" "hello"`   | `hello`           |
| `%d`/`%i`| 输出十进制整数（参数需为整数）        | `printf "%d" 123`       | `123`             |
| `%o`     | 输出八进制整数（无前缀）              | `printf "%o" 10`        | `12`              |
| `%x`/`%X`| 输出十六进制整数（`%x` 小写，`%X` 大写）| `printf "%x %X" 255 255`| `ff FF`           |
| `%f`     | 输出浮点数（默认6位小数）             | `printf "%f" 3.14`      | `3.140000`        |
| `%e`/`%E`| 科学计数法输出浮点数（`%e` 小写e，`%E` 大写E）| `printf "%e" 123.45`| `1.234500e+02`    |
| `%g`/`%G`| 自动选择 `%f` 或 `%e`（取更简洁的格式）| `printf "%g" 0.0000123` | `1.23e-05`        |
| `%c`     | 输出单个字符（参数为ASCII码或字符）    | `printf "%c" 65`        | `A`               |
| `%%`     | 输出百分号本身（转义）                | `printf "%%"`           | `%`               |

## 四、格式修饰符（控制输出样式）

修饰符用于调整字段宽度、对齐方式、精度等，可组合使用，基本格式：  
`%[标志][宽度][.精度]转换字符`  

### 1. 标志（控制对齐与符号）

| 标志 | 含义                                  | 示例（格式字符串）          | 参数       | 输出结果          |
|------|---------------------------------------|-----------------------------|------------|-------------------|
| `-`  | 左对齐（默认右对齐）                  | `printf "%-10s" "hello"`    | `"hello"`  | `hello`（后补5个空格） |
| `+`  | 强制显示正负号（正数带`+`，负数带`-`）| `printf "%+d" 10`           | `10`       | `+10`             |
| ` `（空格） | 正数前加空格，负数前加`-`（替代`+`） | `printf "% d" 10`           | `10`       | `10`（前有1个空格） |
| `0`  | 用0填充字段（仅对数字有效，宽度需指定）| `printf "%05d" 123`         | `123`      | `00123`           |

### 2. 宽度（控制字段长度）

- 用数字指定输出字段的最小宽度（不足则补空格或0，超出则按实际长度输出）。  
- 示例：  

  ```bash
  # 宽度为10，默认右对齐（补前导空格）
  printf "Name: %10s\n" "Alice"  # 输出：Name:      Alice（Alice前有6个空格）
  
  # 宽度为5，数字用0填充
  printf "Num: %05d\n" 42        # 输出：Num: 00042
  ```

### 3. 精度（控制小数/字符串长度）

- 格式：`.数字`，含义随转换字符变化：  
  - 对字符串（`%s`）：指定最大输出长度（超出则截断）。  
  - 对浮点数（`%f`/`%e`）：指定小数位数（不足补0，超出四舍五入）。  
  - 对整数（`%d`等）：指定最小输出位数（不足补0，超出不截断）。  

- 示例：  

  ```bash
  # 字符串最大长度为5（截断超出部分）
  printf "Str: %.5s\n" "helloworld"  # 输出：Str: hello
  
  # 浮点数保留2位小数
  printf "Float: %.2f\n" 3.14159     # 输出：Float: 3.14
  
  # 整数至少3位（不足补0）
  printf "Int: %.3d\n" 5             # 输出：Int: 005
  ```

## 五、特殊字符（转义序列）

`printf` 支持通过转义字符输出特殊格式，常用转义序列：

| 转义字符 | 含义          | 示例                          | 输出结果          |
|----------|---------------|-------------------------------|-------------------|
| `\n`     | 换行          | `printf "line1\nline2"`       | `line1`（换行）`line2` |
| `\t`     | 水平制表符（Tab） | `printf "col1\tcol2"`         | `col1    col2`（Tab分隔） |
| `\r`     | 回车（回到行首） | `printf "abc\r12"`            | `12c`（覆盖行首） |
| `\b`     | 退格（删除前一个字符） | `printf "hello\bworld"`      | `hellworld`（删除最后一个o） |
| `\f`     | 换页          | `printf "page1\fpage2"`       | 分页输出          |
| `\v`     | 垂直制表符    | `printf "row1\vrow2"`         | 垂直分隔          |
| `\\`     | 输出反斜杠    | `printf "a\\b"`               | `a\b`             |

## 六、参数与格式的匹配规则

`printf` 按**顺序匹配**格式字符串中的转换说明符和参数，规则如下：  

1. 若参数数量 **等于** 转换说明符数量：一一对应输出。  
2. 若参数数量 **多于** 转换说明符数量：重复使用格式字符串，直到参数用完。  
3. 若参数数量 **少于** 转换说明符数量：剩余的转换说明符用空值（字符串为空，数字为0）填充。  

### 示例：

```bash
# 1. 参数与格式数量相等
printf "Name: %s, Age: %d\n" "Bob" 25  # 输出：Name: Bob, Age: 25

# 2. 参数多于格式（重复使用格式）
printf "Num: %d\n" 1 2 3  # 等价于执行3次：printf "Num: %d\n" 1; ... 3
# 输出：
# Num: 1
# Num: 2
# Num: 3

# 3. 参数少于格式（剩余用空值填充）
printf "A: %s, B: %d\n" "test"  # 第二个参数缺失，%d用0填充
# 输出：A: test, B: 0
```

## 七、高级用法示例

### 1. 格式化表格输出（对齐列）

```bash
# 左对齐字符串（10宽），右对齐数字（5宽），带标题
printf "%-10s %5s %5s\n" "Name" "Math" "English"
printf "%-10s %5d %5d\n" "Alice" 90 85
printf "%-10s %5d %5d\n" "Bob" 78 92
# 输出（列对齐整齐）：
# Name           Math English
# Alice           90      85
# Bob             78      92
```

### 2. 控制浮点数显示精度

```bash
# 显示不同精度的圆周率
pi=3.1415926535
printf "默认: %.f\n" $pi       # 整数（四舍五入）→ 3
printf "1位小数: %.1f\n" $pi   # 3.1
printf "4位小数: %.4f\n" $pi   # 3.1416
printf "科学计数: %.2e\n" $pi  # 3.14e+00
```

### 3. 结合变量和循环输出

```bash
# 批量输出文件大小（假设files数组存文件名）
files=("file1.txt" "image.jpg" "data.csv")
sizes=(1024 2048000 5120)
printf "%-15s %8s\n" "文件名" "大小(KB)"
for i in "${!files[@]}"; do
  # 转换为KB（除以1024），保留1位小数
  printf "%-15s %8.1f\n" "${files[$i]}" "$((sizes[$i]/1024)).$(( (sizes[$i]%1024)*10/1024 ))"
done
# 输出：
# 文件名             大小(KB)
# file1.txt           1.0
# image.jpg        2000.0
# data.csv            5.0
```

### 4. 输出ASCII字符（用%c）

```bash
# 输出A-Z（ASCII码65-90）
printf "%c " {65..90}  # 输出：A B C ... Z
```

## 八、注意事项

1. **引号问题**：格式字符串建议用双引号 `"` 包裹（单引号中`\n`等转义字符不会被解析）。  

   ```bash
   printf 'Hello\nWorld'  # 错误：单引号中\n不解析，输出Hello\nWorld
   printf "Hello\nWorld"  # 正确：输出Hello（换行）World
   ```

2. **变量解析**：格式字符串中的变量会被解析，若包含`%`需转义（用`%%`）。  

   ```bash
   rate=90
   printf "完成率: %d%%\n" $rate  # 输出：完成率: 90%（%%转义为%）
   ```

3. **兼容性**：不同 Shell（如 Bash、zsh、dash）的 `printf` 实现略有差异（主要在浮点数和扩展功能），脚本中建议用 `#!/bin/bash` 保证兼容性。

4. **性能**：批量输出时，`printf` 比 `echo` 更高效（尤其在循环中）。

## 九、总结

`printf` 是 Shell 中功能最强大的格式化输出工具，通过**转换说明符**和**格式修饰符**可精确控制输出的类型、宽度、对齐方式和精度，尤其适合脚本中生成表格、报告等结构化输出。相比 `echo`，它的语法稍复杂，但灵活性和可控性显著提升，是 Shell 脚本开发的必备技能。
