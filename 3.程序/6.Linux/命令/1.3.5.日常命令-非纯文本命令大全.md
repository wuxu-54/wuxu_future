# 非纯文本命令大全

Linux系统中，除了处理纯文本的命令，还有大量用于操作**二进制文件、媒体文件、压缩包、磁盘/设备、网络数据包**等非文本内容的命令。以下按功能分类整理，涵盖核心命令的详细用法、选项及实战场景，力求全面且实用。

## 一、压缩与归档命令（处理压缩包/归档文件）

用于创建、解压、查看压缩文件（如`.tar`、`.zip`、`.gz`等），非文本文件的打包与压缩核心工具。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `tar` | 归档工具（可结合压缩算法，处理`.tar`系列文件） | `-c`（创建归档）、`-x`（解压归档）、`-v`（显示过程）、`-f 文件名`（指定归档文件）、`-z`（用gzip压缩/解压）、`-j`（用bzip2）、`-J`（用xz）、`-t`（查看归档内容） | `tar -czvf data.tar.gz dir/`（将dir压缩为data.tar.gz）、`tar -xzvf data.tar.gz`（解压并显示过程）、`tar -tf data.tar`（查看归档内容） |
| `gzip`/`gunzip` | 用gzip算法压缩/解压（`.gz`文件，仅压缩单个文件） | `-k`（保留原文件）、`-d`（解压，等价于gunzip）、`-v`（显示压缩率） | `gzip -k file.txt`（压缩为file.txt.gz，保留原文件）、`gunzip file.txt.gz`（解压为file.txt） |
| `bzip2`/`bunzip2` | 用bzip2算法压缩/解压（`.bz2`文件，压缩率高于gzip） | `-k`（保留原文件）、`-d`（解压，等价于bunzip2） | `bzip2 -k largefile`（压缩为largefile.bz2）、`bunzip2 file.bz2`（解压） |
| `xz`/`unxz` | 用xz算法压缩/解压（`.xz`文件，压缩率最高，速度较慢） | `-k`（保留原文件）、`-d`（解压）、`-0`~`-9`（压缩级别，9级最高） | `xz -k -9 data.bin`（最高压缩级别处理二进制文件）、`unxz data.xz`（解压） |
| `zip`/`unzip` | 处理ZIP格式压缩包（跨平台，支持多文件） | `zip -r`（递归压缩目录）、`-q`（安静模式）；`unzip -l`（查看内容）、`-d 目录`（指定解压目录） | `zip -r docs.zip docs/`（压缩目录为docs.zip）、`unzip -d extract/ docs.zip`（解压到extract目录） |
| `7z` | 处理7z、ZIP、RAR等多种格式（高压缩率，功能丰富） | `a`（创建压缩包）、`x`（解压）、`l`（查看内容）、`-t格式`（指定格式，如-tzip） | `7z a -t7z archive.7z folder/`（创建7z格式压缩包）、`7z x archive.rar -o./extract`（解压RAR到extract目录） |

## 二、磁盘与分区管理命令（处理块设备/文件系统）

用于管理磁盘分区、查看磁盘使用情况、挂载文件系统等，直接操作磁盘设备（非文本）。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `fdisk` | 磁盘分区工具（MBR分区表，支持传统分区） | `-l`（列出所有磁盘及分区）、`/dev/sdX`（指定磁盘，如/dev/sda） | `sudo fdisk -l`（查看所有磁盘分区）、`sudo fdisk /dev/sdb`（进入交互式分区界面，操作/dev/sdb） |
| `parted` | 高级分区工具（支持GPT分区表、大磁盘>2TB） | `mklabel gpt`（创建GPT分区表）、`mkpart`（创建分区）、`print`（显示分区信息） | `sudo parted /dev/sdc`（交互式操作/dev/sdc）、`sudo parted -l`（列出所有磁盘详细分区） |
| `df` | 查看文件系统磁盘使用情况（已用/可用空间） | `-h`（人类可读单位，如G/M）、`-T`（显示文件系统类型）、`-i`（显示inode使用情况） | `df -h`（查看所有挂载点的空间使用）、`df -Th /home`（查看/home的文件系统类型和空间） |
| `du` | 查看目录/文件的磁盘占用大小（与df的区别：du看具体文件，df看文件系统） | `-h`（人类可读）、`-s`（仅显示总计）、`-d 1`（显示一级子目录占用） | `du -sh dir/`（查看dir的总占用）、`du -hd 2 /var`（查看/var下两级目录的占用） |
| `mount`/`umount` | 挂载/卸载文件系统（将设备关联到目录） | `mount -t 类型`（指定文件系统类型，如ext4、ntfs）、`-o 选项`（如ro只读、rw读写）；`umount 设备/目录`（卸载） | `sudo mount /dev/sdb1 /mnt/usb`（挂载U盘到/mnt/usb）、`sudo umount /mnt/usb`（卸载U盘） |
| `mkfs` | 格式化分区（创建文件系统，如ext4、xfs） | `mkfs.ext4`（格式化为ext4）、`mkfs.xfs`（xfs格式）、`-L 标签`（给分区加标签） | `sudo mkfs.ext4 /dev/sdb1`（将/dev/sdb1格式化为ext4）、`sudo mkfs.ntfs -L DATA /dev/sdc1`（NTFS格式并加标签DATA） |
| `e2fsck`/`fsck` | 检查并修复文件系统错误（ext系列用e2fsck，通用用fsck） | `-f`（强制检查，即使系统认为正常）、`-y`（自动修复所有错误） | `sudo e2fsck -f /dev/sda1`（强制检查ext4分区）、`sudo fsck -t ntfs /dev/sdc1`（检查NTFS分区） |
| `lsblk` | 列出块设备（磁盘、分区、loop设备等）的树形结构 | `-f`（显示文件系统类型和UUID）、`-l`（线性列表显示，非树形） | `lsblk`（查看所有块设备）、`lsblk -f`（查看设备的UUID和文件系统） |

## 三、二进制文件分析命令（处理二进制/可执行文件）

用于查看二进制文件的结构、内容、元信息，分析可执行文件、库文件等。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `file` | 判断文件类型（文本、二进制、压缩包、设备文件等） | `-b`（仅显示类型，不显示文件名）、`-L`（跟随符号链接） | `file /bin/ls`（显示ls是ELF可执行文件）、`file -b image.jpg`（显示JPEG图像文件） |
| `hexdump`/`xxd` | 以十六进制/ASCII码显示二进制文件内容 | `hexdump -C`（带ASCII注释的十六进制）、`xxd -l 100`（仅显示前100字节） | `hexdump -C binary.bin`（十六进制+ASCII查看二进制文件）、`xxd image.png | head`（查看PNG文件头） |
| `objdump` | 分析目标文件/可执行文件（反汇编、查看符号表等） | `-d`（反汇编代码段）、`-t`（显示符号表）、`-h`（显示段头信息） | `objdump -d /bin/ls`（反汇编ls的执行代码）、`objdump -t libc.so`（查看libc库的符号表） |
| `readelf` | 分析ELF格式文件（Linux下可执行文件、库文件的标准格式） | `-h`（显示ELF头信息）、`-S`（显示段表）、`-l`（显示程序头表） | `readelf -h /bin/bash`（查看bash的ELF头）、`readelf -S libm.so`（查看数学库的段信息） |
| `strings` | 从二进制文件中提取可打印字符串（如路径、常量、版本信息） | `-n 8`（提取至少8个字符的字符串）、`-a`（扫描整个文件，包括数据段） | `strings -n 10 /usr/bin/ssh`（从ssh二进制中提取长字符串）、`strings firmware.bin | grep "version"`（查找固件版本信息） |
| `nm` | 列出二进制文件中的符号（函数名、变量名等） | `-g`（仅显示全局符号）、`-u`（仅显示未定义符号） | `nm -g /usr/lib/libssl.so`（查看ssl库的全局符号）、`nm -u a.out`（查看可执行文件中未定义的符号） |

## 四、媒体文件处理命令（图像/音视频/文档）

用于处理图像、音视频、PDF等媒体文件（非文本，二进制格式）。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `ffmpeg` | 音视频处理（转换格式、剪辑、转码、提取音频等） | `-i 输入`（指定输入文件）、`-c:v 编码器`（视频编码器，如libx264）、`-c:a 编码器`（音频编码器，如aac）、`-ss 时间`（开始时间）、`-t 时长`（截取时长） | `ffmpeg -i input.mp4 -c:v libx265 output.mkv`（MP4转MKV，用H.265编码）、`ffmpeg -i video.mp4 -vn audio.mp3`（从视频中提取音频） |
| `ffprobe` | 查看音视频文件的元信息（分辨率、码率、时长等） | `-show_streams`（显示流信息）、`-print_format json`（JSON格式输出） | `ffprobe -i video.mp4`（查看视频基本信息）、`ffprobe -show_streams -print_format json input.mkv`（JSON格式显示流详情） |
| `convert`（ImageMagick） | 图像处理（格式转换、缩放、裁剪、加水印等） | `-resize 50%`（缩放为50%）、`-crop 100x100+0+0`（裁剪100x100区域）、`-format png`（转换为PNG格式） | `convert image.jpg -resize 800x600 resized.png`（缩放JPG为PNG）、`convert pic.png -fill red -pointsize 20 -draw "text 10,10 'watermark'" watermarked.png`（加水印） |
| `identify`（ImageMagick） | 查看图像文件元信息（尺寸、格式、颜色深度等） | `-verbose`（详细信息）、`-format "%wx%h"`（仅输出宽x高） | `identify image.png`（显示图像基本信息）、`identify -format "%wx%h" photo.jpg`（输出照片尺寸，如1920x1080） |
| `exiftool` | 查看/修改图像的EXIF信息（拍摄时间、相机型号、GPS等） | `-DateTimeOriginal`（仅显示拍摄时间）、`-GPSLatitude -GPSLongitude`（显示GPS坐标）、`-overwrite_original`（修改后覆盖原文件） | `exiftool photo.jpg`（查看所有EXIF信息）、`exiftool -DateTimeOriginal="2023:09:10 15:30:00" photo.jpg`（修改拍摄时间） |
| `pdftk` | PDF文件处理（合并、拆分、加密、提取页面等） | `cat`（合并PDF）、`burst`（拆分每页为单独文件）、`encrypt 密码`（加密PDF） | `pdftk file1.pdf file2.pdf cat output merged.pdf`（合并两个PDF）、`pdftk input.pdf burst`（拆分PDF为单页） |
| `pdfinfo` | 查看PDF文件元信息（页数、标题、作者、大小等） | 无核心选项，直接指定文件 | `pdfinfo report.pdf`（显示PDF的页数、创建时间等） |

## 五、设备管理命令（硬件设备/系统设备）

用于查看和管理硬件设备（如网卡、显卡、USB设备等），操作设备文件（非文本）。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `lspci` | 列出PCI总线设备（显卡、网卡、SSD控制器等） | `-v`（详细信息）、`-k`（显示驱动程序）、`-nn`（显示设备ID和厂商ID） | `lspci`（列出所有PCI设备）、`lspci -v -s 01:00.0`（显示指定PCI设备的详细信息，如显卡） |
| `lsusb` | 列出USB设备（U盘、鼠标、摄像头等） | `-v`（详细信息）、`-t`（树形显示USB总线结构） | `lsusb`（列出所有USB设备）、`lsusb -t`（查看USB设备的连接树） |
| `lsmod` | 列出当前加载的内核模块（驱动程序） | 无核心选项，配合`grep`过滤 | `lsmod | grep nvidia`（查看是否加载NVIDIA显卡驱动） |
| `modprobe` | 加载/卸载内核模块（管理驱动） | `-r`（卸载模块）、`-v`（显示过程） | `sudo modprobe nvidia`（加载NVIDIA驱动模块）、`sudo modprobe -r usb_storage`（卸载USB存储驱动） |
| `udevadm` | 管理udev设备（系统设备事件、设备信息） | `info -q property -n /dev/sda`（查看设备属性）、`trigger`（触发设备事件） | `udevadm info -n /dev/video0`（查看摄像头设备信息）、`udevadm trigger`（重新加载设备规则） |
| `dmidecode` | 查看硬件BIOS/固件信息（内存、主板、CPU等） | `-t memory`（仅显示内存信息）、`-t processor`（仅显示CPU信息） | `sudo dmidecode -t processor`（查看CPU型号、核心数等）、`sudo dmidecode -t memory`（查看内存容量、类型） |
| `sensors` | 查看硬件传感器数据（CPU温度、风扇转速等） | `-f`（ Fahrenheit温度单位） | `sensors`（显示CPU温度、主板电压等） |

## 六、网络非文本命令（网络数据包/设备配置）

用于处理网络数据包（二进制）、配置网络设备（非文本交互）。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `tcpdump` | 网络数据包捕获与分析（抓包工具，处理二进制数据包） | `-i 网卡`（指定网卡，如eth0）、`-w 文件`（保存数据包到文件）、`-r 文件`（读取保存的数据包）、`'port 80'`（过滤80端口的包） | `sudo tcpdump -i eth0 port 443`（捕获eth0上443端口的HTTPS包）、`sudo tcpdump -w capture.pcap host 192.168.1.1`（保存与192.168.1.1的通信包到文件） |
| `wireshark` | 图形化数据包分析工具（基于tcpdump，可视化二进制包） | `-r 文件`（打开保存的数据包文件） | `wireshark capture.pcap`（用图形界面分析之前保存的包） |
| `ethtool` | 配置以太网设备（网卡速率、双工模式等） | `-s 网卡 speed 1000 duplex full`（设置网卡为1000M全双工）、`-i 网卡`（查看网卡驱动信息） | `ethtool eth0`（查看eth0的当前配置）、`sudo ethtool -s eth0 speed 100 duplex half`（设置网卡为100M半双工） |
| `iwconfig` | 配置无线网卡（WiFi）参数（SSID、信道、加密等） | `wlan0 essid "MyWiFi"`（连接到MyWiFi）、`wlan0 channel 6`（设置信道6） | `iwconfig`（查看所有无线网卡状态）、`sudo iwconfig wlan0 power off`（关闭无线网卡节能模式） |
| `ip` | 网络设备配置（替代ifconfig，管理IP、路由、隧道等） | `ip addr`（查看IP地址）、`ip link set eth0 up`（启用网卡）、`ip route add 10.0.0.0/24 via 192.168.1.1`（添加路由） | `ip addr show eth0`（查看eth0的IP信息）、`sudo ip link set wlan0 down`（禁用无线网卡） |

## 七、其他非文本命令（哈希、低级复制、加密等）

处理数据校验、低级设备复制、加密等非文本操作。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `md5sum`/`sha256sum` | 计算文件的哈希值（校验数据完整性，非文本校验） | `-c`（验证哈希值是否匹配） | `md5sum file.iso`（计算ISO文件的MD5）、`sha256sum -c checksum.sha256`（验证文件与校验和是否一致） |
| `dd` | 低级数据复制（按块复制，处理磁盘/分区/二进制文件） | `if=输入`（源，如/dev/sda）、`of=输出`（目标，如image.iso）、`bs=块大小`（如4M）、`count=块数`（复制的块数） | `sudo dd if=/dev/sdb of=usb_image.iso bs=4M`（制作U盘镜像）、`dd if=image.iso of=/dev/sdc bs=4M`（将镜像写入U盘） |
| `losetup` | 管理循环设备（将文件模拟为块设备，如挂载ISO镜像） | `-f`（自动分配空闲循环设备）、`-P`（自动创建分区映射） | `sudo losetup -fP image.iso`（将ISO镜像关联到循环设备，如/dev/loop0）、`sudo losetup -d /dev/loop0`（解除关联） |
| `gpg` | 加密/解密文件（处理加密的二进制数据） | `-c`（对称加密）、`-d`（解密）、`--verify`（验证签名） | `gpg -c secret.txt`（对称加密secret.txt为secret.txt.gpg）、`gpg -d secret.txt.gpg`（解密为secret.txt） |
| `openssl` | 密码学工具（加密、签名、SSL/TLS测试等） | `enc -aes-256-cbc -in file -out file.enc`（AES加密）、`dgst -sha1 file`（计算SHA1哈希） | `openssl enc -aes-256-cbc -salt -in data.bin -out data.enc`（AES加密二进制文件）、`openssl s_client -connect example.com:443`（测试HTTPS连接） |

## 总结

非文本命令覆盖了Linux系统中**压缩归档、磁盘管理、二进制分析、媒体处理、设备控制、网络数据包**等核心场景，其特点是：  

- 直接操作二进制数据或硬件设备，而非文本字符；  
- 多与系统底层交互（如磁盘分区、设备驱动）；  
- 功能专一但参数复杂（如`tar`的压缩算法组合、`ffmpeg`的编解码选项）。  

掌握这些命令是系统管理、数据恢复、媒体处理、网络分析的基础，实际使用中需注意权限（多数命令需`sudo`）和操作风险（如`dd`误操作可能损坏磁盘）。
