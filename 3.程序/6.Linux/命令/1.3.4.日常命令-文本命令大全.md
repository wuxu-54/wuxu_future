# 文本命令大全

Linux/Unix 系统中用于文本处理的命令极其丰富，涵盖**查看、编辑、搜索、分析、转换、统计**等多个场景。以下按功能分类整理，包含核心命令的功能、常用选项及实战示例，力求全面且细致。

## 一、文本查看命令（查看内容）

用于读取文本文件内容，支持分页、部分查看、行号显示等。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `cat` | 正序连接并打印文件内容（适合小文件） | `-n`（显示所有行号）、`-b`（仅非空行号）、`-s`（压缩空行）、`-v`（显示非打印字符） | `cat -n file.txt`（带行号显示）、`cat file1.txt file2.txt > merged.txt`（合并文件） |
| `tac` | 倒序打印文件内容（行级反转，最后一行先输出） | `-s 分隔符`（自定义行分隔符）、`-b`（修正分隔符位置） | `tac /var/log/syslog`（从最新日志开始查看）、`tac -s ';' data.txt`（按分号拆分并倒序） |
| `more` | 分页查看文本（只能向前翻页，空格翻页，q退出） | `-num`（指定每页行数）、`+n`（从第n行开始） | `more -10 largefile.txt`（每页显示10行）、`more +50 log.txt`（从第50行开始） |
| `less` | 增强版分页查看（支持前后翻页、搜索，更常用） | `-N`（显示行号）、`-i`（搜索忽略大小写）、`/pattern`（向下搜索）、`?pattern`（向上搜索） | `less -N file.txt`（带行号分页）、`less +/error log.txt`（直接定位到含error的行） |
| `head` | 查看文件开头部分（默认前10行） | `-n num`（指定行数，`-n -5` 排除最后5行）、`-c num`（指定字节数） | `head -n 5 file.txt`（前5行）、`head -c 100 data.bin`（前100字节） |
| `tail` | 查看文件结尾部分（默认后10行，适合日志实时监控） | `-n num`（指定行数）、`-f`（实时跟踪新增内容）、`-F`（跟踪时自动重连文件） | `tail -n 3 log.txt`（后3行）、`tail -f /var/log/nginx/access.log`（实时监控nginx日志） |
| `nl` | 显示文件内容并添加行号（比`cat -n`更灵活） | `-ba`（所有行编号，包括空行）、`-bt`（仅非空行编号）、`-w 5`（行号占5位宽度） | `nl -ba -w 3 file.txt`（所有行编号，行号占3位） |

## 二、文本编辑命令（创建/修改内容）

用于直接编辑文本文件，从简单编辑器到复杂编辑器均有覆盖。

| 命令 | 核心功能 | 特点与常用操作 | 适用场景 |
|------|----------|----------------|----------|
| `nano` | 轻量交互式编辑器（新手友好，纯键盘操作） | `Ctrl+O`（保存）、`Ctrl+X`（退出）、`Ctrl+W`（搜索） | 快速编辑小型文件（如配置文件） |
| `vim` | 强大的模态编辑器（分命令模式/插入模式） | `i`（进入插入模式）、`Esc`（返回命令模式）、`:wq`（保存退出）、`:q!`（强制退出不保存）、`/pattern`（搜索） | 编程、复杂文本编辑（功能丰富，支持语法高亮） |
| `vi` | `vim`的前身（功能简化，兼容性强） | 基本操作同`vim`（无高级功能如语法高亮） | 老旧系统或极简环境 |
| `emacs` | 全能编辑器（可扩展为IDE，操作复杂） | `Ctrl+X Ctrl+S`（保存）、`Ctrl+X Ctrl+C`（退出）、`Ctrl+S`（搜索） | 高级用户、定制化编辑需求 |
| `ed` | 最古老的行编辑器（纯命令行，无交互界面） | `1,5p`（打印1-5行）、`d`（删除当前行）、`w`（保存）、`q`（退出） | 脚本中自动编辑文本（极少手动使用） |
| `ex` | `vi`的行编辑模式（可批量执行编辑命令） | `:%s/old/new/g`（全局替换）、`:10,20d`（删除10-20行） | 批量文本处理（常嵌入脚本） |

## 三、文本搜索命令（查找内容）

用于在文本中搜索匹配的字符串或模式（正则表达式）。

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `grep` | 按模式搜索文本（支持正则表达式） | `-i`（忽略大小写）、`-n`（显示匹配行号）、`-v`（反向匹配，显示不包含模式的行）、`-r`（递归搜索目录）、`-E`（支持扩展正则） | `grep -in "error" log.txt`（忽略大小写找含error的行并显示行号）、`grep -rv "debug" /var/log/`（递归排除含debug的行） |
| `egrep` | 等价于`grep -E`（支持扩展正则表达式，如`|`表示或） | 同`grep -E` | `egrep -n "error|warn" log.txt`（找含error或warn的行） |
| `fgrep` | 等价于`grep -F`（仅匹配固定字符串，不解析正则） | 速度比`grep`快（无需处理正则） | `fgrep "hello world" file.txt`（精确匹配字符串，包含空格也无需转义） |
| `ack` | 替代`grep`的高级搜索工具（默认递归，忽略版本控制文件） | `-i`（忽略大小写）、`--python`（仅搜索Python文件）、`-l`（仅显示含匹配的文件名） | `ack -i "def func" src/`（在src目录递归搜索含def func的Python代码） |
| `ag`（the silver searcher） | 比`ack`更快的搜索工具（专注代码搜索） | `-G "\.js$"`（仅搜索.js文件）、`--ignore-dir=node_modules`（忽略指定目录） | `ag "const" --js`（在.js文件中搜索const） |
| `rg`（ripgrep） | 基于Rust的超高速搜索工具（支持多线程） | `-g "!*.log"`（排除.log文件）、`-o`（仅显示匹配的部分） | `rg -o "user=\w+" access.log`（在日志中提取所有user=xxx的部分） |

## 四、文本处理命令（分析/转换内容）

用于对文本进行分割、排序、去重、替换、格式化等处理（核心为管道组合工具）。

### （1）行处理（排序、去重、过滤）

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `sort` | 对文本行排序（默认按ASCII码） | `-n`（按数字排序）、`-r`（倒序）、`-k 2`（按第2列排序）、`-u`（去重，保留唯一行）、`-t ','`（指定分隔符为逗号） | `sort -n -k 3 data.txt`（按第3列数字升序）、`sort -t ',' -k 2r csvfile.csv`（按CSV第2列倒序） |
| `uniq` | 移除连续重复行（需先排序，与`sort -u`的区别：`uniq`只去连续重复） | `-c`（统计每行出现次数）、`-d`（仅显示重复行）、`-u`（仅显示不重复行） | `sort file.txt | uniq -c`（统计每行出现次数）、`sort file.txt | uniq -d`（显示所有重复行） |
| `wc` | 统计文本行数、单词数、字节数 | `-l`（仅行数）、`-w`（仅单词数）、`-c`（仅字节数）、`-m`（字符数，含多字节字符） | `wc -l file.txt`（统计行数）、`cat file.txt | wc -w`（统计单词数） |
| `fmt` | 格式化文本（自动折行，使每行长度一致） | `-w 80`（指定每行80字符）、`-s`（仅拆分长行，不合并短行） | `fmt -w 50 longline.txt`（将长行折为50字符/行） |

### （2）列处理（分割、拼接、提取）

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `cut` | 从文本中提取列（按分隔符或字节位置） | `-d ','`（指定分隔符为逗号）、`-f 1,3`（提取第1和第3列）、`-c 1-5`（提取前5个字符） | `cut -d ':' -f 1,7 /etc/passwd`（从passwd提取用户名和shell）、`cut -c 3-7 file.txt`（提取每行第3-7字符） |
| `paste` | 按列拼接多个文件（横向合并） | `-d ','`（指定列分隔符）、`-s`（将单行转为多列，纵向转横向） | `paste file1.txt file2.txt -d ','`（用逗号拼接file1和file2的列）、`paste -s numbers.txt`（将多行转为一行，用制表符分隔） |
| `join` | 按共同字段（列）连接两个文件（类似SQL的JOIN） | `-t ','`（指定分隔符）、`-1 2 -2 1`（用第一个文件的第2列和第二个文件的第1列连接） | `join -t ',' -1 1 -2 1 data1.csv data2.csv`（按第1列连接两个CSV文件） |
| `column` | 将文本按列对齐（格式化表格） | `-t`（自动识别分隔符并对齐）、`-s ','`（指定分隔符为逗号） | `column -t -s ',' data.csv`（将CSV文件格式化为对齐的表格） |

### （3）替换与转换（字符/格式转换）

| 命令 | 核心功能 | 常用选项 | 示例 |
|------|----------|----------|------|
| `tr` | 字符转换/删除/压缩（单个字符级处理） | `-d`（删除指定字符）、`-s`（压缩连续重复字符）、`-c`（处理补集） | `tr 'a-z' 'A-Z' file.txt`（小写转大写）、`tr -d '0-9' file.txt`（删除所有数字） |
| `sed` | 流编辑器（批量文本替换、删除、插入等） | `-i`（原地修改文件）、`'s/old/new/g'`（全局替换）、`'/pattern/d'`（删除含pattern的行）、`'1i header'`（在第1行前插入header） | `sed -i 's/hello/hi/g' file.txt`（原地全局替换hello为hi）、`sed '/^#/d' config.txt`（删除所有注释行） |
| `awk` | 文本分析工具（按行处理，支持条件、循环、函数） | `-F ','`（指定分隔符）、`'{print $1, $3}'`（打印第1和第3列）、`'$2 > 100 {print $0}'`（第2列>100的行） | `awk -F ':' '{print $1 "的shell是" $7}' /etc/passwd`（格式化输出用户名和shell）、`awk 'NR%2==0 {print $0}' file.txt`（打印偶数行） |
| `iconv` | 文本编码转换（如UTF-8转GBK） | `-f 原编码`、`-t 目标编码` | `iconv -f GBK -t UTF-8 old.txt -o new.txt`（GBK转UTF-8） |
| `dos2unix`/`unix2dos` | 换行符转换（DOS的CRLF→Unix的LF，反之） | `-n 输入 输出`（不覆盖原文件） | `dos2unix -n win.txt unix.txt`（将Windows格式文本转为Unix格式） |
| `rev` | 反转每行的字符顺序（字符级反转） | 无核心选项 | `echo "hello" | rev`（输出"olleh"）、`rev file.txt`（反转文件每行的字符） |

## 五、其他实用文本命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `pr` | 格式化文本为打印格式（添加页眉、页脚、分页） | `pr -h "报告标题" -l 60 file.txt`（每页60行，页眉为报告标题） |
| `fold` | 按指定宽度折行（不考虑单词完整性，与`fmt`区别） | `fold -w 20 longtext.txt`（强制每行不超过20字符） |
| `spell`/`aspell` | 拼写检查（`aspell`功能更强） | `aspell check essay.txt`（交互式检查并修正拼写错误） |
| `pastebin` | 将文本上传到在线pastebin（需安装，适合分享） | `cat code.py | pastebin`（上传代码并返回分享链接） |
| `comm` | 比较两个已排序文件的差异（显示仅在第一个、仅在第二个、两者共有的行） | `comm -12 sorted1.txt sorted2.txt`（显示两个文件共有的行） |
| `diff` | 比较两个文件的差异（显示具体修改内容） | `diff -u old.txt new.txt`（以统一格式显示差异，适合补丁） |
| `patch` | 应用`diff`生成的补丁文件（更新旧文件） | `patch old.txt < patch.diff`（用补丁更新old.txt为new.txt） |

## 六、命令组合与实战场景

文本命令的强大之处在于**管道（`|`）组合**，以下是典型场景：

1. **统计日志中出现最多的IP**：  

   ```bash
   grep -oE '([0-9]+\.){3}[0-9]+' access.log | sort | uniq -c | sort -nr | head -n 5
   ```

   （提取IP→排序→统计次数→按次数倒序→取前5）

2. **处理CSV文件，提取第2列大于100的行并按第3列排序**：  

   ```bash
   awk -F ',' '$2 > 100 {print $0}' data.csv | sort -t ',' -k 3n
   ```

3. **批量替换目录下所有文件中的字符串**：  

   ```bash
   find ./src -type f -name "*.js" -exec sed -i 's/oldVar/newVar/g' {} +
   ```

   （查找所有.js文件→批量替换oldVar为newVar）

4. **查看大文件中含“error”的行及其前后5行上下文**：  

   ```bash
   grep -C 5 "error" large.log | less
   ```

   （`-C 5`显示匹配行前后5行）

## 总结

Linux文本命令覆盖了从简单查看（`cat`/`less`）到复杂分析（`awk`/`sed`）的全场景，核心特点是：  

- **单一职责**：每个命令专注于一件事（如`sort`仅排序，`grep`仅搜索）；  
- **管道组合**：通过`|`串联多个命令，实现复杂功能；  
- **脚本友好**：可嵌入Shell脚本，实现自动化文本处理。  

熟练掌握这些命令，能极大提升文本处理效率，是Linux运维、开发的必备技能。
