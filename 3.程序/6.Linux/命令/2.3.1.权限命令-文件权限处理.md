# 权限配置

在 Linux/Unix 系统中，`chmod` 命令用于修改文件或目录的访问权限，权限分为 **用户（Owner）、组（Group）、其他用户（Others）** 三类三个维度，每个维度可设置 **读（Read）、写（Write）、执行（Execute）** 三种权限。

文件权限格式：`[d或-][rwx][rwx][rwx]` 第一个字符：`d`指目录、`-`指文件， 后面的三个分别是owner、group、others的读、写、执行（如果是目录文件，表示进入该目录的权限）三种权限，没有权限用`-`替代，例如无可写权限：[r-x]。

示例：

1. `-rwxr-xr--` 表示：一个非目录普通文件，root权限为可读可写可执行，group权限为可读不可写可执行，others权限为只读。
2. `xrwxr-xr--` 表示：一个目录文件夹，root权限为可读可写可进入，group权限为可读不可写可进入，others权限为只读。

## 权限修改

- `chgrp`：改变文件所属群组。
- `chown`：改变文件拥有者。
- `chmod`：改变文件的权限，SUID，SGID，SBIT等等的特性。

## 权限修改详细说明

以下是 `chgrp`、`chown`、`chmod` 三个命令的详细说明，包含功能、语法、选项、示例及特殊说明，并通过表格汇总核心信息：

### 一、命令详细说明

#### 1. `chgrp`：改变文件/目录的所属群组

**功能**：修改文件或目录的所属群组（Group），仅影响群组属性，不改变所有者（Owner）。

| 项目                | 详情                                                                 |
|---------------------|----------------------------------------------------------------------|
| **基本语法**        | `chgrp [选项] 目标群组 文件名/目录名`                                |
| **权限要求**        | 必须是文件的所有者，或拥有 `root` 权限                               |
| **常用选项**        | - `-R`：递归处理，改变目录下所有文件和子目录的群组<br>- `-v`：显示操作过程（详细模式）<br>- `-h`：仅修改符号链接本身的群组（不跟随链接指向的文件）<br>- `--reference=参考文件`：以参考文件的群组为标准，设置目标文件的群组 |
| **示例**            | 1. 改变单个文件的群组：`chgrp users test.txt`（将 `test.txt` 所属群组改为 `users`）<br>2. 递归改变目录及内容的群组：`chgrp -R admin /data`（将 `/data` 目录及所有子文件/目录的群组改为 `admin`）<br>3. 参考其他文件的群组：`chgrp --reference=file1.txt file2.txt`（让 `file2.txt` 的群组与 `file1.txt` 一致） |
| **特殊说明**        | - 群组名必须是系统中已存在的（可通过 `/etc/group` 查看所有群组）<br>- 符号链接的群组默认跟随其指向的文件，`-h` 选项可单独修改链接本身的群组 |

#### 2. `chown`：改变文件/目录的所有者（及群组）

**功能**：修改文件或目录的所有者（Owner），也可同时修改所属群组（Group）。

| 项目                | 详情                                                                 |
|---------------------|----------------------------------------------------------------------|
| **基本语法**        | `chown [选项] 目标所有者[:目标群组] 文件名/目录名`（`:` 可替换为 `.`，部分系统支持） |
| **权限要求**        | 必须拥有 `root` 权限（普通用户无法修改文件所有者）                     |
| **常用选项**        | - `-R`：递归处理，改变目录下所有文件和子目录的所有者（及群组）<br>- `-v`：显示操作过程（详细模式）<br>- `-h`：仅修改符号链接本身的所有者（不跟随链接指向的文件）<br>- `--reference=参考文件`：以参考文件的所有者和群组为标准，设置目标文件的属性 |
| **示例**            | 1. 仅改变所有者：`chown alice test.txt`（将 `test.txt` 的所有者改为 `alice`）<br>2. 同时改变所有者和群组：`chown bob:users data/`（将 `data/` 的所有者改为 `bob`，群组改为 `users`）<br>3. 递归修改目录：`chown -R root:admin /etc/nginx`（将 `/etc/nginx` 及子内容的所有者改为 `root`，群组改为 `admin`）<br>4. 参考其他文件：`chown --reference=file1.txt file2.txt`（让 `file2.txt` 的所有者和群组与 `file1.txt` 一致） |
| **特殊说明**        | - 用户名必须是系统中已存在的（可通过 `/etc/passwd` 查看所有用户）<br>- 若仅需改群组，建议用 `chgrp`（更直观）<br>- `root` 可强制修改任何文件的所有者，普通用户即使是文件所有者，也不能将所有权转让给其他用户 |

#### 3. `chmod`：改变文件/目录的权限（含特殊权限）

**功能**：修改文件或目录的访问权限（读、写、执行），以及特殊权限（SUID、SGID、SBIT）。

##### （1）权限基础

- **权限对象**：`u`（所有者）、`g`（所属群组）、`o`（其他用户）、`a`（所有用户，默认）。
- **权限类型**：`r`（读，4）、`w`（写，2）、`x`（执行，1）。
- **表示方法**：
  - **符号法**：`[对象][操作符][权限]`（如 `u+r` 给所有者加读权限）。
  - **数字法**：用3位数字表示 `u/g/o` 的权限（如 `755` 表示 `u=rwx`、`g=rx`、`o=rx`）。

##### （2）特殊权限

| 特殊权限 | 符号 | 数字值 | 作用（文件/目录）                                                                 |
|----------|------|--------|----------------------------------------------------------------------------------|
| SUID     | s    | 4000   | **文件**：执行文件时，以文件所有者权限运行（如 `passwd` 命令需修改 `/etc/shadow`）<br>**目录**：无意义 |
| SGID     | s    | 2000   | **文件**：执行文件时，以文件所属群组权限运行<br>**目录**：新创建的文件/目录自动继承该目录的群组（而非创建者的主群组） |
| SBIT     | t    | 1000   | **文件**：无意义<br>**目录**：用户只能删除自己创建的文件（如 `/tmp` 目录，防止他人删除自己的文件） |

##### （3）命令详情

数字法，数字代表的权限对照：

- r:4
- w:2
- x:1

例如：`rwx` 数字是 4+2+1 = 7

| 项目                | 详情                                                                 |
|---------------------|----------------------------------------------------------------------|
| **基本语法**        | - 符号法：`chmod [选项] [对象][±=][权限] 文件名/目录名`<br>- 数字法：`chmod [选项] 权限数字 文件名/目录名` |
| **权限要求**        | 必须是文件的所有者，或拥有 `root` 权限                               |
| **常用选项**        | - `-R`：递归处理，改变目录下所有文件和子目录的权限<br>- `-v`：显示操作过程（详细模式）<br>- `-c`：仅显示权限有变化的文件<br>- `--reference=参考文件`：以参考文件的权限为标准，设置目标文件的权限 |
| **示例**            | 1. 符号法：<br>   - `chmod u+x file.sh`（给所有者加执行权限）<br>   - `chmod g-w,o-r file.txt`（取消群组的写权限，取消其他用户的读权限）<br>   - `chmod a=rwx dir/`（给所有用户读、写、执行目录的权限）<br>2. 数字法：<br>   - `chmod 644 document.txt`（`u=rw`、`g=r`、`o=r`，普通文件常用）<br>   - `chmod 755 script.sh`（`u=rwx`、`g=rx`、`o=rx`，可执行文件常用）<br>3. 特殊权限：<br>   - `chmod 4755 program`（设置 SUID，数字为 `4000+755=4755`）<br>   - `chmod 2770 shared_dir`（设置 SGID，数字为 `2000+770=2770`）<br>   - `chmod 1777 /tmp/test`（设置 SBIT，数字为 `1000+777=1777`）<br>4. 递归修改目录：`chmod -R 750 /data`（将 `/data` 及子内容权限设为 `750`） |
| **特殊说明**        | - 目录的 `x` 权限表示“可进入”（`cd`），无 `x` 权限时即使有 `r` 权限也无法查看内容<br>- 特殊权限 `s` 或 `t` 若显示为大写 `S` 或 `T`，表示对应的基本执行权限（`x`）未设置（如 `rwSr--r--` 表示 SUID 已设置，但所有者无 `x` 权限） |

### 二、命令对比总表

| 命令    | 核心功能                | 可修改的属性               | 权限要求                     | 特殊场景                     |
|---------|-------------------------|----------------------------|------------------------------|------------------------------|
| `chgrp` | 改变所属群组            | 仅群组（Group）            | 所有者或 `root`              | 批量调整文件的群组归属       |
| `chown` | 改变所有者（及群组）    | 所有者（Owner）+ 可选群组  | 必须 `root`                  | 转移文件所有权，批量改属主   |
| `chmod` | 改变访问权限及特殊权限  | 读/写/执行权限 + SUID/SGID/SBIT | 所有者或 `root`              | 控制文件访问权限，设置特殊权限（如 `passwd` 的 SUID） |

通过以上内容，可以全面掌握这三个命令的用法及区别。实际使用时，根据需求选择：改群组用 `chgrp`，改所有者用 `chown`，改权限（含特殊权限）用 `chmod`。
