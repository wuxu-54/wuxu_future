# nano

`nano` 是一款轻量、易用的命令行文本编辑器，以简单直观著称，特别适合 Linux 初学者。它默认在大多数 Linux 发行版中预装，底部会显示常用快捷键提示，无需记忆复杂命令即可快速上手。以下是 `nano` 的详细说明：

## **一、安装 nano**

如果系统未预装 `nano`，可通过包管理器安装：

- **Debian/Ubuntu 系列**：`sudo apt install nano`
- **CentOS/RHEL 系列**：`sudo yum install nano`（CentOS 8+ 用 `dnf`）
- **Fedora**：`sudo dnf install nano`
- **Arch Linux**：`sudo pacman -S nano`

## **二、基本用法**

### 1. 打开/创建文件

```bash
nano [选项] 文件名
```

- 若文件已存在，直接打开编辑；若不存在，保存时会创建该文件。
- 示例：`nano test.txt`（打开或创建 `test.txt`）。

### 2. 界面组成

打开 `nano` 后，界面分为 4 个部分：

- **顶部标题栏**：显示当前编辑的文件名、是否为新文件（`New File`）、是否已修改（`Modified`）。
- **中间编辑区**：文本内容编辑区域，光标闪烁处为当前编辑位置。
- **底部提示栏**：显示常用快捷键（`^` 代表 `Ctrl` 键，`M-` 代表 `Alt` 键，部分系统用 `Esc` 代替 `Alt`）。
- **底部状态栏**：执行操作时显示提示（如保存时显示文件名输入框）。

## **三、核心操作**

### 1. 光标移动

- **方向键**：上下左右移动光标（最常用）。
- `Ctrl+A`：跳到行首（同 `Home` 键）。
- `Ctrl+E`：跳到行尾（同 `End` 键）。
- `Ctrl+Y`：向上滚动一页（同 `Page Up`）。
- `Ctrl+V`：向下滚动一页（同 `Page Down`）。
- `Ctrl+_`（下划线，需按 `Shift+-`）：输入行号后回车，直接跳到指定行（如输入 `5` 跳到第 5 行）。

### 2. 文本编辑

- **插入文本**：直接按键盘输入（默认进入插入模式，无需切换）。
- **删除字符**：
  - `Backspace`：删除光标左侧字符。
  - `Delete`：删除光标右侧字符。
- **换行**：按 `Enter` 键（自动换行需配置，见下文）。
- **撤销/重做**：
  - `Alt+U`（或 `Esc+U`）：撤销上一步操作（需 nano 2.3.5+ 版本支持）。
  - `Alt+E`（或 `Esc+E`）：重做（部分版本支持）。

### 3. 保存与退出

- `Ctrl+O`（Write Out）：保存文件。
  - 按后会在底部提示“File Name to Write: 文件名”，直接回车确认保存；若需另存为其他文件名，输入新名称后回车。
- `Ctrl+X`（Exit）：退出 `nano`。
  - 若文件未保存，会提示“Save modified buffer? (Y/N/O)”：
    - 按 `Y` 保存后退出；
    - 按 `N` 不保存直接退出；
    - 按 `O` 保存为其他文件后退出。

### 4. 搜索与替换

- **搜索文本**：
  - `Ctrl+W`（Where Is）：输入要搜索的关键词，回车开始查找。
  - `Alt+W`（或 `Esc+W`）：查找下一个匹配项。
- **替换文本**：
  - `Ctrl+\`（Replace）：输入“要替换的词”和“替换后的词”，按提示选择：
    - `Y`：替换当前匹配项；
    - `A`：替换所有匹配项；
    - `N`：跳过当前匹配项；
    - `Ctrl+C`：取消替换。

### 5. 文本选择、剪切、复制、粘贴

`nano` 通过“标记”功能选择文本：

- `Ctrl+6`（Set Mark）：标记选择的起始位置（光标处会显示 `Mark Set`）。
- 移动光标：选中从标记位置到当前光标位置的文本（选中区域会高亮）。
- 操作选中的文本：
  - `Ctrl+K`（Cut Text）：剪切选中的文本（放入缓冲区）。
  - `Alt+6`（或 `Esc+6`，Copy Text）：复制选中的文本（放入缓冲区）。
  - `Ctrl+U`（Uncut Text）：粘贴缓冲区中的文本（可多次粘贴）。
- **全选文本**：`Ctrl+6`（标记开始） → `Ctrl+V`（跳到末尾），即可选中全部内容。

### 6. 行操作

- `Ctrl+K`（无选中时）：剪切当前行（整行删除并放入缓冲区）。
- `Alt+Shift+3`（或 `Esc+Shift+3`）：注释当前行（需配置语法高亮时生效，如脚本文件）。
- `Alt+#`（或 `Esc+#`）：临时显示行号（仅当前会话有效）。

### 7. 其他实用功能

- `Ctrl+G`（Get Help）：打开帮助手册，显示所有快捷键（按 `Q` 退出帮助）。
- `Ctrl+C`（Cancel）：显示当前光标位置（行号、列号）。
- `Ctrl+R`（Read File）：读取其他文件内容到当前编辑区（输入文件名后回车，内容会插入到光标位置）。
- `Ctrl+T`（To Files）：打开文件浏览器，可选择文件打开（按 `Enter` 选中，`Q` 退出浏览器）。
- `Alt+S`（或 `Esc+S`）：拼写检查（需提前安装 `spell` 或 `aspell` 工具）。

## **四、配置 nano（自定义功能）**

`nano` 的配置文件为 **`~/.nanorc`**（用户级）或 **`/etc/nanorc`**（系统级），通过添加配置项可自定义功能。常用配置：

1. **显示行号**：`set linenumbers`（打开后左侧显示行号）。
2. **自动缩进**：`set autoindent`（换行时自动跟随上一行缩进）。
3. **语法高亮**：`include /usr/share/nano/*.nanorc`（启用所有预设的语法高亮，如代码、配置文件）。
4. **自动换行**：`set wrap`（超出屏幕宽度时自动换行）；`set nowrap`（禁用自动换行）。
5. **Tab 键替换为空格**：`set tabsize 4`（Tab 键宽度为 4 空格）；`set expandtab`（按 Tab 时插入空格而非制表符）。
6. **保存时自动备份**：`set backup`（保存时生成 `.文件名~` 备份文件）。

配置示例（`~/.nanorc`）：

```bash
set linenumbers       # 显示行号
set autoindent        # 自动缩进
set tabsize 4         # Tab 宽度为 4 空格
set expandtab         # Tab 替换为空格
include /usr/share/nano/*.nanorc  # 启用语法高亮
```

## **五、进阶技巧**

1. **同时编辑多个文件**：`nano file1 file2 file3`，用 `Ctrl+^`（切换文件）循环切换打开的文件。
2. **强制退出不保存**：`Ctrl+X` → 按 `N`（忽略提示直接退出）。
3. **临时禁用配置**：`nano -N 文件名`（`-N` 禁用 `~/.nanorc` 配置，用默认设置打开）。
4. **编辑二进制文件**：`nano -v 文件名`（`-v` 启用查看模式，可编辑二进制内容）。

## **六、注意事项**

- 不同版本的 `nano` 功能可能略有差异（通过 `nano --version` 查看版本）。
- 部分终端中 `Alt` 键可能需用 `Esc` 代替（如 `Alt+U` 变为 `Esc+U`）。
- `nano` 适合轻量编辑，处理超大文件（GB 级）时性能不如 `vim` 或 `emacs`。

通过上述功能，`nano` 可满足日常文本编辑、脚本编写、配置文件修改等需求，是命令行环境中高效且友好的工具。
