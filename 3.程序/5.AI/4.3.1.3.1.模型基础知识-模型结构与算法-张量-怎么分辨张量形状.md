# 如何读懂一个张量形状的含义

张量形状是一串整数，比如 `(3, 224, 224)` 或 `(32, 10, 768)`。读懂它的关键是：**形状只告诉你每个轴有多少个元素，但不告诉你每个轴代表什么物理意义**。物理意义需要根据上下文（模型类型、数据来源）来推断。

下面我会教你一套“三步推断法”，并给出常见领域的形状解读模板。

---

## 第一步：看维度数量（阶数）

先数一下有几个数字，就知道张量是几维的。

| 阶数 | 可能含义 |
|------|----------|
| 0阶 | 单个数值（标量），如 loss、准确率 |
| 1阶 | 一个特征向量 / 一个样本的嵌入 / 一个时间序列 |
| 2阶 | 一批样本的特征矩阵 / 一张灰度图 / 一个注意力矩阵 |
| 3阶 | 单张彩色图 / 一段文本序列 / 一批向量 |
| 4阶 | 一批彩色图 / 一段视频的一帧序列 / 一批文本序列 |
| 5阶 | 一批视频片段 / 3D医学图像 |

**口诀**：维度数 = 你需要几个索引才能定位到一个具体数值。

---

## 第二步：根据领域猜测每个轴的物理意义

### 图像领域（最常用）

| 形状 | 格式 | 含义 |
|------|------|------|
| `(H, W)` | 2D 单通道 | 一张灰度图，高 H 像素，宽 W 像素 |
| `(H, W, C)` | TensorFlow 风格 | 一张彩色图，C 通常为 3（RGB）或 1（灰度） |
| `(C, H, W)` | PyTorch 风格 | 同上，通道在第一维 |
| `(B, H, W, C)` | TF 批量 | B 张彩色图，每张 H×W×C |
| `(B, C, H, W)` | PyTorch 批量 | 同上 |
| `(B, T, C, H, W)` | 视频批量 | B 个视频片段，每个片段 T 帧，每帧 C×H×W |

**例子**：  

- `(1, 224, 224, 3)` → 1 张 224×224 的 RGB 图像（TF 格式）  
- `(32, 3, 256, 256)` → 32 张 256×256 的 RGB 图像（PyTorch 格式）

### 文本 / NLP 领域

| 形状 | 含义 |
|------|------|
| `(V,)` | 词汇表大小为 V 的 one-hot 向量 |
| `(D,)` | 一个词/句的嵌入向量（D 为嵌入维度） |
| `(S, D)` | 一个句子，有 S 个 token，每个 token 用 D 维向量表示 |
| `(B, S)` | 一个 batch 的 token ID 序列（未经嵌入） |
| `(B, S, D)` | 一个 batch 的句子，每个 token 已嵌入为 D 维 |
| `(B, H, S, S)` | Transformer 中多头注意力的分数矩阵（H 头数，S 序列长） |

**例子**：  

- `(128, 512)` → 128 个 token，每个 token 的嵌入维度是 512（单个句子）  
- `(8, 64, 768)` → 8 个句子，每个句子 64 个 token，每个 token 嵌入 768 维（BERT 常见中间状态）

### 音频领域

| 形状 | 含义 |
|------|------|
| `(T,)` | 单通道音频波形，T 个采样点 |
| `(T, 2)` | 双通道音频 |
| `(B, T)` | 批量音频 |
| `(F, T)` | 频谱图（F 频率 bins，T 时间帧） |
| `(B, 1, F, T)` | 批量单通道频谱图（类似图像） |

### 通用/其他

| 形状 | 含义 |
|------|------|
| `(N, D)` | N 个样本，每个样本 D 维特征（如 PCA 降维后） |
| `(K, M, N)` | K 个矩阵，每个 M×N（如协方差矩阵批量） |
| `(B, ...)` | 几乎总是表示“批量大小”，即一次处理多少个独立样本 |

---

## 第三步：结合数值范围、dtype 和操作验证

形状只是骨架，要真正读懂，还需结合：

- **dtype**：`uint8` 通常是图像像素（0~255）；`float32` 是归一化特征或模型输出。
- **数值范围**：看到 0~1 可能是概率或归一化像素；看到 logits（有正有负）则是未经过 softmax。
- **后续操作**：如果张量后面要过 softmax，通常最后一维是类别数；如果要过 conv2d，则形状必须为 `(B, C, H, W)` 或 `(B, H, W, C)`。

**例子验证**：  
形状 `(10, 1000)` + 数值范围 `[-10, 10]` + 后面接了 `softmax(dim=-1)` → 推断：10 个样本，每个样本是 1000 个类别的 logits。

## 实战练习：给你一些形状，你来解读

1. `(1, 640, 640, 3)`  
   → 1 张 640×640 的 RGB 图像（TF 格式），常用于 YOLO 输入。

2. `(1, 84, 84, 4)`  
   → 1 个样本，84×84 像素，4 个通道。可能是 Atari 游戏中的帧堆叠（4 帧历史）。

3. `(16, 150, 300)`  
   → 16 个样本，每个样本是一个 150×300 的矩阵。可能是 16 张灰度图（150×300），或者 16 个句子（每个 150 token，每个 token 300 维嵌入）。

4. `(2, 3, 320, 320)`  
   → PyTorch 格式：2 张彩色图（3 通道），320×320。可能是 batch=2 的输入。

5. `(50, 10, 10)`  
   → 50 个 10×10 的矩阵。常见于批量协方差矩阵或小批图像块。

---

## 最容易混淆的点

- **单张彩色图在不同框架的形状差异**：  
  PyTorch: `(3, 224, 224)`；TensorFlow: `(224, 224, 3)`。面试常问。

- **批次维度位置**：在绝大多数框架中，**批次维度永远在第一维**（`B, ...`）。所以看到形状第一个数字很大的时候（如 32, 64, 128），优先怀疑是 batch size。

- **序列长度 vs 嵌入维度**：在 `(B, S, D)` 中，S 通常比 D 小（S 是 token 数，D 是嵌入维度，如 768、1024）。如果 S 很大（如 4096）而 D 很小（如 128），那可能是某种编码器输出或时间序列。

## 你的下一步练习

1. 随便找一个预训练模型（比如 ResNet50），打印它的输入和输出形状，自己解读。
2. 手写一个简单的神经网络，故意打乱维度顺序，观察报错信息，加深理解。
3. 面试前准备：能解释 `[batch, seq_len, hidden]` 和 `[batch, channels, height, width]` 这两个模板即可覆盖 90% 的问题。

如果你能流畅地回答：“给定一个形状，请说出它可能对应什么数据以及为什么”，你就真正掌握了。
