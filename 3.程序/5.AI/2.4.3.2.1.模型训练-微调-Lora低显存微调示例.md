## 一、LoRA 到底是什么？（极简人话版）

**LoRA = Low-Rank Adaptation（低秩适配）**

它的核心作用：

- **不训练完整大模型**（几十GB）
- **只训练很小的“小参数”**（几MB～几百MB）
- 效果 ≈ 全量微调
- **速度快 10 倍、显存占用降低 80%**
- 8GB 显存也能轻松微调 LLaMA、Qwen、GLM、Stable Diffusion 等模型

### 工作原理（一句话）

在 Transformer 的 **Attention 层（Q/K/V）** 插入两个极小矩阵，只训练这两个矩阵，冻结原模型不动。

---

## 二、8GB 显存微调的关键技术（必须开）

要让 8GB 能跑，必须同时开 4 个优化：

1. **4/8 bit 量化加载模型**（bitsandbytes）
2. **LoRA 小参数训练**
3. **梯度检查点（Gradient Checkpointing）**
4. **混合精度训练 + 小 batch size**

满足这 4 条，**8GB 显存稳稳跑大模型微调**。

### 完整训练代码（直接复制运行）

```python
import torch
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,
    TrainingArguments,
    DataCollatorForLanguageModeling,
)
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training
from datasets import load_dataset

# ======================
# 1. 基础配置（8GB 专用）
# ======================
MODEL_NAME = "Qwen/Qwen-1.8B-Chat"  # 1.8B 模型 8GB 稳稳跑
# 也可以用：
# MODEL_NAME = "lmsys/vicuna-7b-v1.5" （7B模型4bit也能跑）
# MODEL_NAME = "THUDM/chatglm3-6b"
# MODEL_NAME = "internlm/internlm2-chat-1_8b"

DATA_PATH = "your_data.json"  # 你自己的微调数据
LORA_RANK = 8  # 越小显存越少
BATCH_SIZE = 2
GRADIENT_ACCUMULATION = 4
MAX_SEQ_LEN = 512

# ======================
# 2. LoRA 配置（核心）
# ======================
lora_config = LoraConfig(
    r=LORA_RANK,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],  # 主流模型通用
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)

# ======================
# 3. 4bit 加载模型（8GB 必备）
# ======================
model = AutoModelForCausalLM.from_pretrained(
    MODEL_NAME,
    load_in_4bit=True,  # 4bit 量化
    torch_dtype=torch.bfloat16,
    device_map="auto",
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME, trust_remote_code=True)

# 开启训练支持
model = prepare_model_for_kbit_training(model)
model = get_peft_model(model, lora_config)

# 开启梯度检查点（省显存神器）
model.gradient_checkpointing_enable()

# 看看训练参数比例
model.print_trainable_parameters()

# ======================
# 4. 加载数据（JSON 格式）
# ======================
dataset = load_dataset("json", data_files=DATA_PATH)

def tokenize_fn(examples):
    return tokenizer(
        examples["text"],
        truncation=True,
        max_length=MAX_SEQ_LEN,
        padding="max_length",
    )

tokenized_data = dataset.map(tokenize_fn, batched=True)
data_collator = DataCollatorForLanguageModeling(tokenizer=tokenizer, mlm=False)

# ======================
# 5. 训练参数（8GB 最优配置）
# ======================
training_args = TrainingArguments(
    output_dir="./lora-finetune-result",
    per_device_train_batch_size=BATCH_SIZE,
    gradient_accumulation_steps=GRADIENT_ACCUMULATION,
    learning_rate=2e-4,
    num_train_epochs=3,
    logging_steps=10,
    save_strategy="epoch",
    optim="paged_adamw_8bit",  # 8bit 优化器（省显存）
    fp16=True,  # 混合精度
    report_to="none",
)

# ======================
# 6. 开始训练
# ======================
from transformers import Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_data["train"],
    data_collator=data_collator,
)

trainer.train()

# 保存 LoRA 权重（只有几MB～几十MB）
model.save_pretrained("lora-final-model")
```

## 六、训练后怎么用 LoRA？（推理代码）

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen-1.8B-Chat",
    load_in_4bit=True,
    device_map="auto",
    trust_remote_code=True
)
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen-1.8B-Chat", trust_remote_code=True)

# 加载 LoRA
model = PeftModel.from_pretrained(model, "lora-final-model")

# 推理
prompt = "用户：你好"
inputs = tokenizer(prompt, return_tensors="pt").to("cuda")
outputs = model.generate(**inputs, max_new_tokens=200)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

## 七、关键注意事项（8GB 必看）

1. **必须用 4bit/8bit 加载**
2. **batch size 不要超过 2~4**
3. **开启 gradient_checkpointing**
4. **优化器用 paged_adamw_8bit**
5. **序列长度不要超过 512~1024**

满足这些，**8GB 显存训练大模型 LoRA 完全没问题**。

## Demo遇到问题记录

实际开发中，不同模型、框架版本 会有兼容性问题，我们需要找到python运行中所有库合适的版本。

1. `ERROR: Could not find a version that satisfies the requirement torch (from versions: none)`

    - 原因：我的Mac 是 Intel x86_64，cpu架构不同可能导致此问题
    - 解决：指定安装版本（兼容当前cpu架构）与路径：`python3.10 -m pip install torch==2.2.0 --index-url https://download.pytorch.org/whl/cpu`

2. `我本地的Deepseek-R1-1.5B  是怎么识别到的，传入了MODEL_ID = "deepseek-ai/DeepSeek-R1-1.5B"就行了？`

    原代码：

    ```python
    from transformers import AutoModelForCausalLM, AutoTokenizer
    MODEL_ID = "deepseek-ai/DeepSeek-R1-1.5B"
    base_model = AutoModelForCausalLM.from_pretrained(
        MODEL_ID,
        torch_dtype=torch.float16,
        device_map="cpu",
        trust_remote_code=True
    )
    ```

    - 配置方式一：直接写模型仓库 ID,框架自动查找本地文件的优先级顺序。运行逻辑：

        ```python
        MODEL_ID = "deepseek-ai/DeepSeek-R1-1.5B"
        model = AutoModelForCausalLM.from_pretrained(MODEL_ID, ...)
        ```

        - 检查`~/.cache/huggingface/hub/` 有没有对应缓存文件夹、完整权重；
        - 齐全 → 纯本地加载，0 流量；
        - 不全 / 不存在 → 后台自动调用 huggingface 下载工具，分片下载全部文件到缓存目录，下次运行就本地读取。
    - 配置方式二：指定你手动存放的本地文件夹路径。  比如你手动把模型解压放在 `./local_model/DeepSeek-R1-1.5B`

        ```python
        #运行
        MODEL_PATH = "./local_model/DeepSeek-R1-1.5B"
        model = AutoModelForCausalLM.from_pretrained(MODEL_PATH, ...)
        ```

        逻辑：直接读取这个文件夹内全部文件，完全绕过缓存目录，不会联网。

    - 担心重复下载怎么禁止联网？答：加参数 local_files_only=True，强制只读取本地，找不到直接报错、绝不联网

        ```python
        model = AutoModelForCausalLM.from_pretrained(
        MODEL_ID,
        local_files_only=True,  # 强制纯本地
        torch_dtype=torch.float16,
        trust_remote_code=True
        )
        ```
