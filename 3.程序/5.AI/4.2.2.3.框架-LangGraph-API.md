# LangGraph API 详细说明（2026 最新稳定版）

LangGraph 是 LangChain 推出的**有状态、可循环、支持多轮与人工干预**的编排框架，核心是用“状态图（StateGraph）”把 LLM、工具、记忆、RAG 串成可靠的智能体流程，解决传统链（Chain）无法循环、状态不可控的问题。

---

## 一、核心概念（先懂再用）

### 1. State（状态）

- 全局共享数据，全图节点读写同一份状态，驱动流程流转。
- 常用结构：`TypedDict`（推荐）、`dataclass`、`Pydantic`。
- 内置便捷状态：`MessagesState`（消息列表）、`AgentState`（消息+工具+记忆）。

### 2. Node（节点）

- 图的执行单元，函数/方法，接收 `state` → 处理 → 返回**状态更新（partial）**。
- 三类节点：LLM 节点、工具节点、决策/路由节点。

### 3. Edge（边）

- 定义节点流转关系：
  - **普通边**：A → B，固定流转。
  - **条件边**：根据 `state` 动态选下一个节点（循环、分支核心）。
  - **START/END**：图的入口/出口（内置常量）。

### 4. Checkpointer（检查点/持久化）

- 状态持久化，支持**中断后恢复、时间旅行、多轮会话记忆**。
- 常用：`MemorySaver`（内存，调试）、`SqliteSaver`、`RedisSaver`（生产）。

### 5. Runnable 兼容

- 编译后的图完全实现 LangChain `Runnable` 协议，支持 `invoke/stream/ainvoke` 等统一调用方式。

## 三、StateGraph 核心 API（图构建）

### 1. 定义状态（State）

```python
from typing import TypedDict, Annotated, Sequence
import operator

# 方式1：基础 TypedDict（最常用）
class AgentState(TypedDict):
    messages: Sequence[HumanMessage | AIMessage | ToolMessage]  # 对话消息
    tool_outputs: list[str]  # 工具返回结果
    step: int  # 步骤计数

# 方式2：带 Reducer（多节点并发更新时合并）
class State(TypedDict):
    count: Annotated[int, operator.add]  # 多个节点返回值相加
    messages: Annotated[list, operator.concat]  # 消息列表追加
```

### 2. 创建图实例

```python
# 绑定状态
graph_builder = StateGraph(AgentState)
```

### 3. 添加节点（add_node）

```python
# 节点函数：接收 state，返回状态更新（dict）
def llm_node(state: AgentState) -> dict:
    # 调用模型
    response = model.invoke(state["messages"])
    return {"messages": [response]}  # 返回更新（追加消息）

def tool_node(state: AgentState) -> dict:
    # 执行工具
    tool_call = state["messages"][-1].tool_calls[0]
    result = my_tool.invoke(tool_call["args"])
    return {"tool_outputs": [result], "step": state["step"] + 1}

# 注册节点（name + function）
graph_builder.add_node("llm", llm_node)
graph_builder.add_node("tool", tool_node)
```

### 4. 添加边（add_edge / add_conditional_edges）

#### 普通边（固定流转）

```python
# 入口 → llm
graph_builder.add_edge(START, "llm")
# tool → 出口
graph_builder.add_edge("tool", END)
```

#### 条件边（动态路由，核心）

```python
# 路由函数：接收 state，返回下一个节点名称（str）
def router(state: AgentState) -> str:
    last_msg = state["messages"][-1]
    # 判断是否需要调用工具
    if last_msg.tool_calls:
        return "tool"  # 去工具节点
    else:
        return END  # 结束

# 添加条件边：llm → router → 分支
graph_builder.add_conditional_edges(
    source="llm",
    path=router,
    path_map={"tool": "tool", END: END}  # 映射（可选，更安全）
)
```

### 5. 编译图（compile）

```python
# 持久化（可选，生产必加）
checkpointer = MemorySaver()

# 编译为可执行 Runnable
graph = graph_builder.compile(
    checkpointer=checkpointer,  # 状态持久化
    interrupt_before=["tool"]   # 执行 tool 前中断（人工干预）
)
```

## 四、图执行 API（调用与流式）

编译后的 `graph` 是 `Runnable`，支持 5 种标准调用：

### 1. 同步调用（invoke）

```python
# 输入：与 State 结构匹配的 dict
inputs = {
    "messages": [HumanMessage(content="3+5等于多少？")],
    "step": 0
}

# 配置：thread_id 用于会话隔离、持久化
config = {"configurable": {"thread_id": "user_001"}}

# 执行
result = graph.invoke(inputs, config=config)
print(result["messages"][-1].content)
```

### 2. 流式输出（stream，最常用）

逐块返回节点输出/模型 token，适合实时对话：

```python
for event in graph.stream(inputs, config=config, stream_mode="values"):
    if "messages" in event:
        print(event["messages"][-1].content, end="", flush=True)
```

- `stream_mode="values"`：返回完整状态更新
- `stream_mode="debug"`：返回每一步详细事件（调试）

### 3. 异步调用（ainvoke / astream）

```python
import asyncio

async def run_graph():
    result = await graph.ainvoke(inputs, config=config)
    return result

asyncio.run(run_graph())
```

### 4. 批量调用（batch）

```python
inputs_list = [
    {"messages": [HumanMessage(content="你好")], "step": 0},
    {"messages": [HumanMessage(content="今天天气？")], "step": 0}
]
results = graph.batch(inputs_list, config=config)
```

## 五、高级核心 API

### 1. 内置工具节点（ToolNode）

无需手写工具执行逻辑，直接用内置 `ToolNode`：

```python
from langgraph.prebuilt import ToolNode

# 定义工具
@tool
def add(a: int, b: int) -> int:
    return a + b

# 注册工具节点
graph_builder.add_node("tools", ToolNode([add]))

# 条件边：llm → tools（当有工具调用时）
graph_builder.add_conditional_edges("llm", tools_condition)
```

### 2. 状态管理（get_state / update_state）

运行中读取/修改状态，支持**人工干预**：

```python
# 读取当前状态
state = graph.get_state(config)
print(state.values["messages"])

# 修改状态（人工介入）
graph.update_state(config, {"step": 10})
```

### 3. 时间旅行（状态回滚）

结合 `checkpointer`，回到任意历史状态重新执行：

```python
# 查看历史状态
for state in graph.get_state_history(config):
    print(f"Step: {state.metadata['step']}")

# 回滚到指定状态
graph.invoke(inputs, config={"configurable": {"thread_id": "user_001", "checkpoint_id": "xxx"}})
```

### 4. Send API（动态生成节点调用，Map-Reduce）

无需预定义边，节点可动态发送状态到任意节点（适合并行处理）：

```python
from langgraph.graph import Send

def map_node(state: AgentState) -> list[Send]:
    # 拆分任务，动态发送到 process 节点
    return [Send("process", {"data": item}) for item in state["items"]]

graph_builder.add_node("map", map_node)
graph_builder.add_node("process", process_node)
```

## 六、预构建智能体 API（create_react_agent）

LangGraph 1.0+ 提供**开箱即用的 ReAct 智能体**，无需手动建图：

```python
from langgraph.prebuilt import create_react_agent

# 模型 + 工具
model = ChatOpenAI(model="gpt-4o")
tools = [add, multiply]

# 创建智能体（内置 StateGraph、循环、工具调用、记忆）
agent = create_react_agent(
    model=model,
    tools=tools,
    checkpointer=MemorySaver(),
    interrupt_before=["tools"]  # 工具调用前中断
)

# 直接调用
result = agent.invoke({"messages": [("human", "3+5*2等于多少？")]}, config=config)
```

## 七、常用模式（直接套用）

### 1. 基础 ReAct（循环：思考→工具→思考）

```
START → llm → (条件) → tools → llm → ... → END
```

### 2. 分支路由（多工具选择）

```
START → llm → router → {工具A, 工具B, END}
```

### 3. 人机交互（中断→人工输入→恢复）

```
START → llm → interrupt → 人工修改state → 继续执行
```

### 4. 多智能体（Agent A → Agent B → Agent C）

```
START → agent_a → agent_b → agent_c → END
```

## 九、常见问题与最佳实践

### 1. 状态设计原则

- 尽量**扁平化**，避免嵌套过深
- 用 `Annotated + reducer` 处理多节点并发更新
- 消息列表统一用 `messages` 字段，兼容 LangChain 生态

### 2. 循环控制

- 必须有**终止条件**（如 `step > 5`、无工具调用），避免死循环
- 用 `interrupt_before` 防止无限执行

### 3. 生产必备

- 必加 `checkpointer`（Redis/SQLite），保证会话不丢失
- 用 `stream` 而非 `invoke`，提升用户体验
- 结合 LangSmith 监控节点耗时、错误率、token 消耗

## 十、总结

LangGraph API 核心是**“状态驱动的图编排”**：

- **State**：数据核心，全图共享
- **Node**：执行单元，处理状态
- **Edge**：流转规则，支持循环/分支
- **Checkpointer**：持久化，支持中断恢复
- **Runnable 兼容**：无缝融入 LangChain 生态

一句话：**LangGraph = 可控循环 + 状态持久化 + 灵活编排**，是工业级智能体的核心框架。
