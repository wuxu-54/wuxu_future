# MCP接入

AI工具：trea
接入方式：MCP server配置

## MCP 接入简述

- trea需要安装配置mcp服务（MCP 分为server与client两部分，trea等同于客户端，配置的目标mcs server就是服务端）
- 不走Figma api方式的mcp插件，Figma 客户端同样需要安装插件（注意：有的mcp走Figma API方式，因此不需要Figma安装插件）。 要保证两个端插件都是同一个，如果插件不一致无法使用的。（不是同一家，当然无法使用了）
- 需要从figma获取AccessToken，配置在trea mcp的配置文件中
- 使用及测试：figma 网页端 右侧可以点击快速拷贝获取url，在ai工具输入框粘贴并提问“获取设计数据”。如果大模型正常回答表示功能正常。

### 方式一：trea 插件平台接入

1. trea 的 mcp市场可以看到mcp插件，安装使用即可。
2. 如果插件是figma api方式，figma不需要需要安装插件，否则需要安装同一款插件。（我就在这里遇到了坑，trea中有的插件，figma插件平台没有，这时需要本地进行安装配置，很麻烦）

### 方式二：本地插件接入

- 从github下载mcp插件，在trea mcp 采用本地配置，本地运行mcp server服务。
- 非API方式获取Figma 数据，Figma 客户端也需要本地安装此mcp插件（一个mcp插件库，会提供figma用的和AI工具用的两种插件）。

## 我的实战记录

我采用Figma API方式+本地插件接入，也能获取到数据，并且Figma 不需要安装插件。（说明：API方式可能不如插件方式获取的信息全面，但够用就行了）

1. 从github下载`figma-coder-mcp` (这是通过Figma API方式获取数据)
2. trea ai工具配置mcp服务

  ```json
    {
    "mcpServers": {
      "figma": {
        "command": "npx",
        "args": [
          "-y",
          "figma-coder-mcp"
        ],
        "env": {
          "FIGMA_PAT": "这里放入Figma的AccessToken"
        }
      }
    }
  }
  ```

3. 使用测试
   - 从Figma网页端右侧拷贝地址数据：<https://www.figma.com/design/5IxYLCQykQJk4J6XpSRQtC/>
   - trea输入：“读取这个设计稿中「Dialog对话框-通用」这个 Frame 的布局和样式信息<https://www.figma.com/design/5IxYLCQykQJk4J6XpSRQtC/>
   - 大模型正常回复表示功能正常
