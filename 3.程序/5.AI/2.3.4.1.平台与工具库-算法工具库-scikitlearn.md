## 一句话总结

**scikit-learn（简称 sklearn）是 Python 里最流行、最通用的机器学习库！**
专门用来做**传统机器学习**（不是深度学习），比如：

- 分类
- 回归
- 聚类
- 降维
- 特征工程
- 模型评估

它是**数据科学、机器学习入门必学工具**。

## 它到底是干嘛的？

你可以把它理解成：
**一个装满了现成机器学习算法的工具箱**

你不用自己写数学公式、不用自己实现梯度下降、不用自己写KNN、SVM、决策树……
你只需要：

1. 准备数据
2. 调 sklearn 的函数
3. 训练模型
4. 预测

**5行代码就能训练一个机器学习模型！**

## 为什么大家都用 scikit-learn？

### ✅ 简单到爆炸

API 统一，所有模型用法几乎一样：

```python
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier()
model.fit(X_train, y_train)   ## 训练
model.predict(X_test)         ## 预测
```

### ✅ 不用懂复杂数学也能用

它把所有复杂算法都封装好了。

### ✅ 速度快

底层用 C 写的，运行效率高。

### ✅ 文档超级全

遇到问题查官方文档马上解决。

### ✅ 配合 Python 生态无敌

- numpy
- pandas
- matplotlib
- 甚至后面你学 LangChain、RAG 也会用到它！

## scikit-learn 不能干嘛？

**不能做深度学习！**
不能做：

- 大模型（LLM）
- 深度学习
- CNN / RNN / Transformer

深度学习用：

- TensorFlow / Keras
- PyTorch

## 最简单示例代码（5 行训练模型）

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

## 加载数据
data = load_iris()
X, y = data.data, data.target

## 划分训练集测试集
X_train, X_test, y_train, y_test = train_test_split(X, y)

## 训练模型
model = LogisticRegression()
model.fit(X_train, y_train)

## 测试准确率
print(model.score(X_test, y_test))
```
