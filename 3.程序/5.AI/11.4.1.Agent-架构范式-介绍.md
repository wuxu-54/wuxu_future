# Agent架构范式介绍

这些范式定义了Agent处理任务的逻辑，相当于它的“工作方法”。

* **ReAct (Reasoning + Acting)**：最经典的范式，让Agent在“思考”（推理下一步）和“行动”（调用工具）之间交替进行。它像一个边想边做的工匠，每一步都基于上一步的反馈。
* **Plan-and-Execute**：先制定完整计划，再按计划执行。像一个建筑师，先画好图纸再施工，适合步骤明确、可预测的复杂任务。
* **Chain-of-Thought (CoT)**：通过引导模型展示一步步的推理过程来解决问题。像一个解数学题的学生，写下每一步推导，主要用于提升推理的准确性。
* **多智能体协作 (Multi-Agent)**：由多个专业Agent分工协作，共同完成复杂目标。像一个专业的团队，每个成员各司其职、协同工作。
