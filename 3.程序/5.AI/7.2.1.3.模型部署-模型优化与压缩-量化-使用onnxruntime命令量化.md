# onnxruntime 命令量化

不同于微调时使用Pytorch微调时进行的量化，这个是专门进行量化处理的。

## 命令

- 下载optimum `pip install optimum[onnxruntime]>=1.17.0`内置命令行量化工具，注意必须是HuggeFace支持的模型。本次我使用的是`mobilenet_v2_1.4_224-ONNX`模型,是可以用的。
    >optimum-cli onnxruntime quantize 是在 Optimum >= 1.8.0 ,如果你的版本低于该版本，onnxruntime 子命令不会注册，因此会报错 invalid choice。

    命令解释：
        ```txt
        [onnxruntime] —— 附加依赖（Extras）
        这是核心关键点。Python 的 pip 允许包定义“附加依赖组”。如果你只执行 pip install optimum，你只能获得基础功能，没有 ONNX 量化的命令行工具。加上 [onnxruntime]，pip 会自动帮你把 ONNX 量化所需的所有依赖库一次性装好，包括：

        onnx（模型解析器）
        onnxruntime 或 onnxruntime-gpu（推理后端）
        onnxconverter-common（模型转换工具）
        onnxruntime-tools 等辅助库

        特别注意：[onnxruntime] 默认会安装 CPU 版本的 onnxruntime。因为你之前已经手动安装了 onnxruntime-gpu，这里如果不加处理，pip 可能会把 GPU 版本覆盖成 CPU 版本。
        ```

- 下载安装：
  - CPU 版本： `pip install onnxruntime`
  - GPU (CUDA) 版本：`pip install onnxruntime-gpu`
- 命令(windows 不支持\换行，直接写成一行)：

      ```sh
      optimum-cli onnxruntime quantize --onnx_model mobilenetv2-onnx/onnx -o mobilenet_v2_1.4_224_gpu --avx2 --per_channel
      # mobilenetv2-onnx/onnx 是原始目录.onnx文件
      ```

- optimum 量化命令参数查询网站：`https://huggingface.co/docs/optimum-onnx/en/onnxruntime/usage_guides/quantization`
