# 用 Netron 查看 ONNX 模型结构

很简单。下面是几种方法：

---

## 🔧 方法一：命令行直接启动（最快）

```powershell
# 安装 Netron（如果还没装）
pip install netron

# 启动 Netron，打开你的 ONNX 文件
netron ./onnx_model/model.onnx
```

执行后，Netron 会自动在浏览器中打开一个可视化界面。

---

## 🐍 方法二：Python 脚本启动

```python
import netron

# 启动 Netron 查看 ONNX 模型
netron.start("./onnx_model/model.onnx")
```

运行这个脚本，同样会在浏览器中打开。

---

## 🌐 方法三：在线查看（无需安装）

如果不想安装，可以直接用 Netron 的在线版本：

1. 打开浏览器访问：**<https://netron.app>**
2. 点击 "Open Model" 按钮
3. 选择你本地的 `model.onnx` 文件
4. 直接在网页上查看模型结构

---

## 📊 Netron 界面说明

打开后，你会看到：

| 区域 | 内容 |
|---|---|
| **左侧面板** | 模型元信息（版本、opset、输入输出格式） |
| **中间画布** | 网络结构图，显示每一层和连接关系 |
| **右侧面板** | 点击任意节点后，显示该节点的详细信息（输入输出形状、参数等） |

### 关键信息查看：

1. **输入/输出节点**：点击模型入口或出口节点，查看 `input_ids`、`logits` 等张量的形状
2. **层结构**：展开节点查看内部操作（如 `MatMul`、`Add`、`Softmax` 等）
3. **参数统计**：查看各层权重张量的维度

## 📁 查看前确认 ONNX 文件存在

```powershell
# 确认模型已生成
ls ./onnx_model/

# 应该看到 model.onnx 文件
```

如果还没生成 ONNX，先运行转换命令：

```powershell
optimum-cli export onnx --model ./merged_model --task text-generation-with-past ./onnx_model
```

---

## 💡 常用查看技巧

1. **检查输入输出形状**：点击输入节点（通常叫 `input_ids`），看 `shape` 字段是否支持动态维度（`batch_size`、`sequence_length`）

2. **检查模型是否完整**：看最后是否有 `Softmax` 或 `Logits` 输出节点

3. **检查 KV Cache 结构**：如果指定了 `text-generation-with-past`，应该能看到 `past_key_values` 相关节点，这是加速推理的关键
