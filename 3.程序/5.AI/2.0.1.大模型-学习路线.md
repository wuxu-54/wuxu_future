# 大模型学习路线

我们重点是能力增强层知识的学习。

## AI基础知识

1. 认识大模型：类似大脑，核心是：通过训练记录数据，通过向量进行找到最相似内容
    - 大模型基础原理
    - 大模型与AI关系
    - 提示词工程
2. 底层基座：
    - TOKEN
    - 上下文
    - 大模型微调
    - Embedding（向量）
3. 使用外部工具：
    - 函数调用
    - skills：转义技能，底层依赖函数调用实现，更适用上层使用，减少Token消耗，适配MCP协议
    - mcp协议：函数调用的进阶，统一的标准化协议，用于抹平不同大模型 Function Calling 格式差异，提供一套通用、跨平台的工具调用规范。
4. 知识外挂
    - 向量数据库
    - RAG
5. 框架
    - Lanchain：开发者可以通过此功能，让大模型具备使用更多接口、工具等外部能力
    - LangGraph：基于Lanchain，更好的设定Agent流程
    - Harness：智能体的标准化运行时环境和执行引擎，它像一个 "智能体操作系统"，为所有 Agent 提供统一的底层运行支撑，屏蔽了模型差异、工具差异和基础设施差异，让开发者只需要关注业务逻辑，而不需要重复构建 Agent 的基础能力。
5. 顶层能力
    - Agent：Agent = LLM + Harness
        - 入门知识
        - 进阶知识
        - A2A协议：多Agent标准通信协议
        - ACP：单Agent标准通信协议
6. AI项目实战
    - 智能助手开发
    - 个人Agent成长助手，知识库体系构建。
