# 规范级 SKILL 开发：代码审查 (Code Review) SKILL 完整实现

本实现提供与“工程级代码审查 SKILL”相同功能的**规范级版本**，基于 `SKILL.md` + Python 脚本，可被 Cline、Claude Code、Continue 等支持规范级 Skill 的 Agent 自动发现和调用。

# 代码审查技能

## 功能描述
本技能对给定代码片段进行多维度的智能审查，自动识别潜在 bug、安全漏洞、性能问题、代码风格违规及偏离最佳实践的地方。支持四种主流语言，并按严重程度分级（critical/high/medium/low）。

## 执行流程
1. 验证输入参数（代码长度 ≤8000 字符，语言支持）。
2. 检查代码是否包含敏感内容（如硬编码密码、危险系统调用），若包含直接返回错误。
3. 根据输入参数构建审查提示词（包含审查重点、严格程度、语言等）。
4. 调用 OpenAI GPT-4（或配置的其他大模型）进行审查。
5. 解析模型返回的 JSON 结果，确保符合输出 schema。
6. 返回结构化结果给 Agent。

## 输入要求
- `code`: 必填，字符串，不超过 8000 字符。
- `language`: 必填，`python` / `javascript` / `java` / `go`。
- `review_focus`: 可选，数组元素为 `bug`, `security`, `performance`, `style`, `best_practice`，默认全部。
- `strict_level`: 可选，`low` / `medium` / `high`，默认 `medium`。
- `include_suggestions`: 可选，布尔值，默认 `true`。

## 输出格式（JSON）
严格按照 `schema/output.schema.json` 输出，示例：
```json
{
  "success": true,
  "total_issues": 2,
  "critical_issues": 0,
  "high_issues": 1,
  "medium_issues": 1,
  "low_issues": 0,
  "issues": [
    {
      "type": "security",
      "severity": "high",
      "line_start": 3,
      "line_end": 3,
      "description": "使用 os.system 执行外部命令，可能造成命令注入漏洞。",
      "suggestion": "使用 subprocess.run 并传递参数列表，避免字符串拼接。"
    },
    {
      "type": "bug",
      "severity": "medium",
      "line_start": 5,
      "line_end": 7,
      "description": "未处理除零异常，当 numbers 为空列表时会崩溃。",
      "suggestion": "添加条件判断：if not numbers: return 0"
    }
  ],
  "summary": "发现 2 个问题：1 个严重安全漏洞，1 个中等 bug。"
}
```

## 错误处理

- 代码为空或超长 → 返回 `{"success": false, "error_code": "INVALID_PARAMETER", "error_message": "..."}`
- 包含敏感内容（如 `password`, `os.system` 等）→ 返回 `{"success": false, "error_code": "PERMISSION_DENIED", "error_message": "代码包含敏感内容..."}`
- 大模型调用失败 → 返回 `{"success": false, "error_code": "INTERNAL_ERROR", "error_message": "..."}`

## 使用示例

**用户输入**：  
审查以下 Python 代码，重点检查安全漏洞：  


### 3. 执行脚本 `scripts/review.py`

```python
#!/usr/bin/env python3
"""
规范级 Skill 代码审查脚本
依赖：openai, python-dotenv, pydantic
"""

import argparse
import json
import hashlib
import logging
import os
import sys
import time
from typing import List, Optional, Dict, Any
from pathlib import Path

import dotenv
from openai import OpenAI
from pydantic import BaseModel, Field, ValidationError

# 加载环境变量
dotenv.load_dotenv(dotenv.find_dotenv())

# 配置日志
logging.basicConfig(level=logging.INFO, format="%(asctime)s - %(levelname)s - %(message)s")
logger = logging.getLogger(__name__)

# 配置常量
MAX_CODE_LENGTH = int(os.getenv("MAX_CODE_LENGTH", "8000"))
OPENAI_API_KEY = os.getenv("OPENAI_API_KEY")
OPENAI_MODEL = os.getenv("OPENAI_MODEL", "gpt-4o")
OPENAI_BASE_URL = os.getenv("OPENAI_BASE_URL", None)  # 支持自定义端点，如 Ollama

if not OPENAI_API_KEY:
    logger.error("未设置 OPENAI_API_KEY 环境变量")
    sys.exit(1)

client = OpenAI(api_key=OPENAI_API_KEY, base_url=OPENAI_BASE_URL)

# ----------------------------------------------------------------------
# 输入模型（校验）
# ----------------------------------------------------------------------
class ReviewInput(BaseModel):
    code: str = Field(..., min_length=1, max_length=MAX_CODE_LENGTH)
    language: str = Field(..., pattern="^(python|javascript|java|go)$")
    review_focus: List[str] = Field(
        default=["bug", "security", "performance", "style", "best_practice"]
    )
    strict_level: str = Field(default="medium", pattern="^(low|medium|high)$")
    include_suggestions: bool = Field(default=True)

    def model_post_init(self, __context):
        # 额外校验敏感内容
        sensitive = ["password", "secret", "api_key", "token", "private_key",
                     "os.system", "subprocess", "eval", "exec", "rm -rf"]
        code_lower = self.code.lower()
        for pattern in sensitive:
            if pattern in code_lower:
                raise ValueError(f"代码包含敏感内容：{pattern}，禁止审查")

# ----------------------------------------------------------------------
# 构建提示词
# ----------------------------------------------------------------------
def build_prompt(inp: ReviewInput) -> str:
    focus_map = {
        "bug": "潜在的逻辑错误、空指针异常、边界条件处理不当",
        "security": "安全漏洞，如SQL注入、命令注入、XSS、敏感信息泄露",
        "performance": "性能问题，如低效算法、内存泄漏、不必要的IO",
        "style": "代码风格和规范（命名、缩进、注释、结构）",
        "best_practice": "不符合最佳实践的地方（重复代码、未使用变量、错误处理缺失）"
    }

    if inp.review_focus is None:
        focus_list = list(focus_map.keys())
    else:
        focus_list = inp.review_focus

    focus_text = "\n".join(f"- {focus_map[f]}" for f in focus_list)

    strict_map = {
        "low": "宽松：只检查明显的严重问题",
        "medium": "中等：检查常见问题和重要的最佳实践",
        "high": "严格：检查所有可能的问题，包括细节和风格"
    }
    strict_text = strict_map[inp.strict_level]

    suggestion_instruction = ""
    if inp.include_suggestions:
        suggestion_instruction = """
对于每个问题，提供具体的改进代码建议，格式为：
// 改进前
原代码
// 改进后
改进后的代码
"""

    prompt = f"""
你是一个资深的{inp.language}代码审查专家。请严格按照以下要求审查提供的代码：

1. 审查重点：
{focus_text}

2. 审查严格程度：{strict_text}

3. 问题严重程度定义：
- critical（致命）：会导致系统崩溃、数据丢失或严重安全漏洞
- high（严重）：会导致功能异常、错误结果或性能严重下降
- medium（中等）：可能导致潜在问题或影响可维护性
- low（建议）：代码风格、最佳实践方面的改进建议

4. 输出要求：
- 必须返回严格的 JSON 格式，不要包含任何额外解释。
- 每个问题必须包含 type, severity, line_start（行号从1开始）, line_end, description, suggestion（如果 include_suggestions 为 true）。
- 如果没有问题，返回空的 issues 列表。
- 只针对提供的代码，不要假设额外上下文。
{suggestion_instruction}

代码（{inp.language}）：
```

{inp.code}

```

输出 JSON 格式示例：
{{
  "total_issues": 2,
  "critical_issues": 0,
  "high_issues": 1,
  "medium_issues": 1,
  "low_issues": 0,
  "issues": [
    {{
      "type": "security",
      "severity": "high",
      "line_start": 3,
      "line_end": 3,
      "description": "描述",
      "suggestion": "建议代码"
    }}
  ],
  "summary": "总结"
}}
"""
    return prompt

# ----------------------------------------------------------------------
# 调用模型并解析
# ----------------------------------------------------------------------
def call_llm(prompt: str) -> Dict[str, Any]:
    response = client.chat.completions.create(
        model=OPENAI_MODEL,
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
        response_format={"type": "json_object"}  # 仅 OpenAI 支持，其他模型可去掉
    )
    content = response.choices[0].message.content
    # 尝试解析 JSON
    try:
        result = json.loads(content)
        # 确保必须字段存在
        for key in ["total_issues", "critical_issues", "high_issues", "medium_issues", "low_issues", "issues", "summary"]:
            if key not in result:
                result[key] = [] if key == "issues" else 0
        return result
    except json.JSONDecodeError:
        logger.error(f"模型返回非 JSON：{content}")
        raise Exception("模型输出解析失败，非 JSON 格式")

# ----------------------------------------------------------------------
# 主函数
# ----------------------------------------------------------------------
def review(inp: ReviewInput) -> Dict[str, Any]:
    start = time.time()
    logger.info(f"开始审查 {inp.language} 代码，长度 {len(inp.code)}")
    # 审计哈希
    code_hash = hashlib.sha256(inp.code.encode()).hexdigest()[:8]
    try:
        prompt = build_prompt(inp)
        llm_result = call_llm(prompt)
        elapsed = (time.time() - start) * 1000
        logger.info(f"审查完成，耗时 {elapsed:.0f}ms，发现问题 {llm_result.get('total_issues', 0)}")
        return {
            "success": True,
            **llm_result
        }
    except ValueError as e:
        # 参数/敏感内容错误
        logger.warning(f"输入校验失败：{e}")
        return {
            "success": False,
            "error_code": "INVALID_PARAMETER",
            "error_message": str(e)
        }
    except Exception as e:
        logger.error(f"审查失败：{e}")
        return {
            "success": False,
            "error_code": "INTERNAL_ERROR",
            "error_message": str(e)
        }

# ----------------------------------------------------------------------
# CLI 入口
# ----------------------------------------------------------------------
def main():
    parser = argparse.ArgumentParser(description="代码审查 Skill")
    parser.add_argument("--code", required=True, help="要审查的代码")
    parser.add_argument("--language", required=True, choices=["python", "javascript", "java", "go"])
    parser.add_argument("--review_focus", nargs="+", choices=["bug", "security", "performance", "style", "best_practice"],
                        help="审查重点")
    parser.add_argument("--strict_level", choices=["low", "medium", "high"], default="medium")
    parser.add_argument("--include_suggestions", action="store_true", default=True)
    parser.add_argument("--no_suggestions", action="store_false", dest="include_suggestions")
    parser.add_argument("--output_format", choices=["json", "pretty"], default="json")

    args = parser.parse_args()

    try:
        inp = ReviewInput(
            code=args.code,
            language=args.language,
            review_focus=args.review_focus or ["bug", "security", "performance", "style", "best_practice"],
            strict_level=args.strict_level,
            include_suggestions=args.include_suggestions
        )
    except ValidationError as e:
        print(json.dumps({"success": False, "error_code": "INVALID_PARAMETER", "error_message": str(e)}))
        sys.exit(1)

    result = review(inp)
    if args.output_format == "pretty":
        print(json.dumps(result, indent=2))
    else:
        print(json.dumps(result, ensure_ascii=False))

if __name__ == "__main__":
    main()
```

### 5. 测试用例 `tests/test_cases.py`

```python
import subprocess
import json
import os

def run_cli(code, language, **kwargs):
    cmd = ["python", "scripts/review.py", "--code", code, "--language", language]
    for k, v in kwargs.items():
        if v is True:
            cmd.append(f"--{k}")
        elif v is False:
            cmd.append(f"--no_{k}")
        elif isinstance(v, list):
            cmd.extend([f"--{k}", " ".join(v)])
        else:
            cmd.extend([f"--{k}", str(v)])
    result = subprocess.run(cmd, capture_output=True, text=True)
    return json.loads(result.stdout)

def test_bug_detection():
    code = """
def div(a, b):
    return a / b
"""
    out = run_cli(code, "python", strict_level="high")
    assert out["success"] is True
    # 应该发现除零风险（至少一条 bug）
    issues = out["issues"]
    assert any(i["type"] == "bug" for i in issues)

def test_security_focus():
    code = """
import os
os.system("rm -rf /")
"""
    out = run_cli(code, "python", review_focus=["security"])
    assert out["success"] is True
    assert out["total_issues"] >= 1
    assert any("system" in i["description"].lower() for i in out["issues"])

def test_sensitive_block():
    code = 'password = "123456"'
    out = run_cli(code, "python")
    assert out["success"] is False
    assert out["error_code"] == "INVALID_PARAMETER"
    assert "敏感内容" in out["error_message"]

if __name__ == "__main__":
    test_bug_detection()
    test_security_focus()
    test_sensitive_block()
    print("所有测试通过")
```

### 2. 集成到 Agent（规范级）

将整个 `code-review-skill` 文件夹放入 Agent 的技能目录（例如 `~/.cline/skills/` 或项目根目录的 `.skills/`），Agent 会自动发现并可通过自然语言调用，例如：

> 审查以下 Python 代码，重点关注安全：
>
> ```python
> import os
> os.system("rm -rf /tmp")
> ```

Agent 会根据 `SKILL.md` 的描述，自动执行 `python scripts/review.py ...` 命令，并将输出结果返回给用户。

## 四、企业级扩展点

- **敏感模式定制**：修改脚本中的 `sensitive` 列表，添加团队禁止的模式。
- **自定义审查规则**：通过修改 `build_prompt()` 中的 `focus_map` 或添加额外的系统提示。
- **支持本地模型**：设置 `OPENAI_BASE_URL` 指向本地 Ollama 或其他兼容服务，并调整 `response_format` 参数。
- **审计日志**：脚本已记录调用哈希和耗时，可将其写入文件或远程服务。

此规范级 SKILL 提供了与工程级完全相同的功能，同时保持框架无关、易于跨平台复用。
