# SKILL 两种写法

>我在做SKILL 的Demo学习时，AI给的都是代码级的实现，但我疑惑为什么我整理的SKILL介绍文档里却又很多复杂结构？如果你也有类似困惑那看这篇文章可以解惑。

1. 代码级 Skill（@tool）：将普通函数通过装饰器注册为 Agent 可直接调用的工具对象，运行在 Agent 同一进程内，依赖特定框架（如 LangChain）。
2. 规范级 Skill（SKILL.md）：通过文件夹 + SKILL.md 元数据文件声明技能的用途、输入输出及执行方式。Agent 扫描发现技能，按描述启动子进程或外部调用执行，与 Agent 框架解耦、跨平台复用。

核心区别：前者是函数直接嵌入，后者是文件声明 + 独立执行。两者可共存，规范级 Skill 可调用代码级 Skill。
