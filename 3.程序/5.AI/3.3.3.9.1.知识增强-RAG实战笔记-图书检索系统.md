# RAG 实战笔记-图书检索系统

视频：<https://www.bilibili.com/video/BV1tU5M6kEcn?spm_id_from=333.788.player.switch&vd_source=3509947f569e04aa5c144447e22d0ceb&p=21>

技术栈：

- 中文NLP处理：TF-IDF + Scikit-learn
- 中文分词：jieba
- 缓存机制：plckle序列化

## 实现流程记录

### 文档内容获取

1. 获取本地文档数据，通过glob匹配全部 '*.txt','*.md' 文件
2. 通过 with open() 读取文件内容
3. 将文件内容全部存放在变量 documents 集合中

### 数据处理

1. 清洗
2. 分块

## 运行问题记录

1. `AttributeError: 'str' object has no attribute 'glob'`  解决： Path(docs_dir)，  必须是Path对象，不能String直接调用文件匹配方法
