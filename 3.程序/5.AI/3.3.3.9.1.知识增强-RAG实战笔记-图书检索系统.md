# RAG 实战笔记-图书检索系统

视频：<https://www.bilibili.com/video/BV1tU5M6kEcn?spm_id_from=333.788.player.switch&vd_source=3509947f569e04aa5c144447e22d0ceb&p=21>

技术栈：

- 中文NLP处理： Scikit-learn+TF-IDF
- 中文分词：jieba
- 缓存机制：plckle序列化

## 实现流程记录

### 文档内容获取

1. 获取本地文档数据，通过glob匹配全部 '*.txt','*.md' 文件
2. 通过 with open() 读取文件内容
3. 将文件内容全部存放在变量 documents 集合中

### 数据处理

1. 清洗
2. 分块
3. 向量化：使用Scikit-learn库的 `TF-IDF` 算法API进行文本向量化计算

中文文本特征判断分类:

- 评论 推文
- 新闻文章 产品的描述
- 学术论文 技术文档 文学作品

依据特征分类可以修改`TfidfVectorizer`向量器参数，如：`max_features` 最大特征的值，找到合适的参数。避免过大导致噪声、过小导致过渡拟合

4. 缓存处理

### 问答逻辑

1. 获取用户输入
2. 向量化输入内容
3. 计算相似度：Scikit-learn 余弦相似度计算。  0 - 1 越大越相似，使用numpy 工具进行筛选。

    ```py
    similarities = cosine_similarity(question_vector,self.doc_vectors).flatten()  # 注意必须要使用flatten()将多维数组转换为一维数组
    ```

4. 引入大模型（我使用本地部署的Deepseek轻量模型）. 本地引入 api_key 随便写，base_url特别注意，openai的接口规范是`curl http://192.168.x.x:11434/api/tags`，接口得有tag,可默认写`/v1`，不写会报404错误。

    ```py
     self.client = OpenAI(
            api_key=api_key,
            base_url="http://localhost:11434/v1"  # 注意这里base_url 必须有/v1，否则
            )
    ```

## 运行问题记录

1. `AttributeError: 'str' object has no attribute 'glob'`  解决： Path(docs_dir)，  必须是Path对象，不能String直接调用文件匹配方法
