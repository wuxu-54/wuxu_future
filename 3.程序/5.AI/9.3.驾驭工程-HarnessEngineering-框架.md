# 现成Harness系统框架与API调用完全指南（2026年5月最新）

Harness Engineering概念自2026年2月正式提出以来，生态系统发展极为迅速。目前已经形成了**"官方原生框架+开源社区实现+托管服务"**的完整格局，你完全不需要从零开始构建Harness系统。

## 一、官方原生框架（推荐优先使用）

### 1.1 OpenAI Agents SDK（⭐⭐⭐⭐⭐ 首选）

**发布时间**：2026年5月16日（最新）  
**核心优势**：OpenAI官方出品，内置模型原生Harness，沙箱执行，零编排代码

OpenAI Agents SDK是目前最成熟的Harness实现，它将Harness直接内置到SDK中，你不需要自己编写while循环、工具调度和状态管理代码。

#### 核心特性

- 模型原生Harness：自动处理工具调用、多步骤执行和状态持久化
- 内置沙箱执行：基于Firecracker微VM的隔离环境，支持文件系统、Shell命令和Git
- 多Agent协作：原生支持Agent之间的任务移交（Handoff）
- 完整可观测性：内置追踪和调试功能
- 模型无关：支持任何OpenAI兼容端点

#### 安装与API示例

```bash
pip install openai-agents
export OPENAI_API_KEY="sk-..."
```

**基础Harness使用**：

```python
from agents import Agent, Runner, function_tool
import asyncio

# 1. 定义工具（Harness自动处理权限和调用）
@function_tool
def calculate(a: int, b: int, operation: str) -> int:
    """执行数学计算"""
    if operation == "add":
        return a + b
    elif operation == "multiply":
        return a * b
    else:
        raise ValueError("不支持的操作")

# 2. 创建Agent（Harness自动配置）
agent = Agent(
    name="Calculator Agent",
    instructions="你是一个计算器助手，使用提供的工具进行计算",
    tools=[calculate],
    # Harness配置
    max_turns=10,  # 最大迭代次数
    temperature=0,
)

# 3. 运行（Harness自动执行循环）
async def main():
    result = await Runner.run(agent, input="计算 123 * 456 + 789")
    print(result.final_output)
    # 输出：123 * 456 + 789 = 56088 + 789 = 56877

if __name__ == "__main__":
    asyncio.run(main())
```

**沙箱执行Harness**（代码生成必备）：

```python
from agents import Agent, Runner
from agents.sandbox import Sandbox

async def main():
    # 创建沙箱Harness
    sandbox = Sandbox(
        image="python:3.11",
        mount_dir="./my-project",  # 挂载本地目录
        allowed_commands=["python", "pytest", "git"],  # 白名单命令
    )
    
    agent = Agent(
        name="Coding Agent",
        instructions="编写Python代码并运行测试",
        tools=[sandbox.get_tools()],
    )
    
    result = await Runner.run(
        agent,
        input="编写一个快速排序函数并测试它"
    )
    print(result.final_output)
```

### 1.2 Anthropic Managed Agents

**发布时间**：2026年4月  
**核心优势**："脑手分离"架构，Harness与Sandbox完全解耦，企业级安全

Anthropic提出了业界最先进的Harness架构，将Agent拆分为**Session（会话）、Harness（大脑）、Sandbox（手）**三个独立组件。

#### 核心特性

- 脑手分离：Harness运行在安全控制面，Sandbox运行在不可信执行面
- 凭证代理：Sandbox永远无法直接访问API密钥
- 会话持久化：任务可以暂停和恢复，不受容器重启影响
- 多Agent协作：原生支持规划器、生成器、评审器三代理架构

#### API示例

```python
from anthropic import Anthropic
from anthropic.agents import ManagedAgent, Session

client = Anthropic(api_key="sk-ant-...")

# 创建Harness配置
harness_config = {
    "model": "claude-3-5-sonnet-20260410",
    "max_tokens": 100000,
    "tools": ["filesystem", "shell", "git"],
    "permissions": {
        "read": ["./src", "./tests"],
        "write": ["./src", "./tests"],
        "execute": ["pytest", "ruff"]
    }
}

# 创建托管Agent
agent = ManagedAgent.create(
    client=client,
    name="Code Assistant",
    instructions="你是一个代码助手，帮助用户修改和测试代码",
    harness_config=harness_config
)

# 创建会话并运行
session = Session.create(client=client, agent_id=agent.id)
result = session.run("修复tests/test_utils.py中的失败测试")
print(result.output)
```

## 二、开源Harness框架

### 2.1 OpenHarness（港大HKUDS）⭐⭐⭐⭐

**GitHub**：<https://github.com/HKUDS/OpenHarness>  
**Stars**：12.2k+（2026年5月）  
**核心优势**：轻量、可组合、提供商无关，内置个人代理Ohmo

OpenHarness是目前最受欢迎的开源Harness实现，被称为"Claude Code的Python开源版"。

#### 安装与使用

```bash
# 一键安装
curl -fsSL https://raw.githubusercontent.com/HKUDS/OpenHarness/main/scripts/install.sh | bash

# 配置API密钥
oh setup
```

**命令行使用**：

```bash
# 检查当前仓库并给出重构建议
oh -p "检查这个仓库并列出前3项重构建议"

# 修复bug并运行测试
oh -p "修复src/main.py中的除以零错误，然后运行pytest"

# JSON格式输出
oh -p "列出项目中的所有Python函数" --output-format json
```

**Python API调用**：

```python
from openharness import Harness, Agent

# 创建Harness
harness = Harness(
    provider="anthropic",
    model="claude-3-5-sonnet-20260410",
    api_key="sk-ant-..."
)

# 注册工具
harness.register_tool("filesystem", allowed_paths=["./"])
harness.register_tool("shell", allowed_commands=["ls", "cat", "python"])

# 创建Agent并运行
agent = Agent(harness=harness)
result = agent.run("列出当前目录下的所有文件")
print(result)
```

**插件开发**：

```typescript
// 自定义Harness插件
export default {
  name: "my-plugin",
  hooks: {
    beforeCallLLM: async (messages, tools) => {
      // 在调用模型前修改消息
      console.log("即将调用模型，消息数：", messages.length);
      return { messages, tools };
    },
    afterToolCall: async (toolCall, result) => {
      // 在工具调用后处理结果
      console.log("工具调用结果：", result);
      return result;
    }
  }
};
```

## 四、Harness生态核心：MCP协议工具

所有现代Harness框架都原生支持**Model Context Protocol（MCP）**，这是AI时代的"USB-C接口"，让你可以一次开发工具，在所有Harness系统中使用。

### 4.1 常用MCP服务器

| 工具 | 用途 | 安装命令 |
|------|------|----------|
| filesystem | 文件系统访问 | `npx @modelcontextprotocol/server-filesystem ./` |
| git | Git操作 | `npx @modelcontextprotocol/server-git ./` |
| postgresql | PostgreSQL数据库 | `npx @modelcontextprotocol/server-postgresql` |
| browser | 浏览器自动化 | `npx @modelcontextprotocol/server-browserbase` |
| github | GitHub API | `npx @modelcontextprotocol/server-github` |

### 4.2 在Harness中使用MCP工具

**OpenAI Agents SDK示例**：

```python
from agents import Agent, Runner
from agents.mcp import MCPServer

async def main():
    # 启动MCP服务器
    mcp_server = MCPServer(
        command="npx",
        args=["@modelcontextprotocol/server-filesystem", "./my-project"]
    )
    
    async with mcp_server as server:
        tools = await server.get_tools()
        
        agent = Agent(
            name="File Agent",
            instructions="读取和分析项目文件",
            tools=tools
        )
        
        result = await Runner.run(agent, input="总结README.md的内容")
        print(result.final_output)
```
