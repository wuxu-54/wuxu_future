# LangChain 1.3 API 完整指南（2026年最新稳定版）

**一句话定义**：LangChain是一个**基于Runnable协议的模块化AI应用开发框架**，提供了统一的接口来连接大模型、工具、知识库和记忆系统。截至2026年5月，最新稳定版为**v1.3.0**，已全面重构为以LCEL为核心、LangGraph为编排层的生产级架构。

## 一、整体架构与核心包结构

LangChain采用**三层模块化架构**，严格分离抽象、核心实现和社区集成：

| 包名 | 职责 | 包含内容 |
|------|------|----------|
| `langchain-core` | 基础抽象层 | 定义所有核心接口（Runnable、ChatModel、Tool等）、LCEL实现、通用工具 |
| `langchain` | 核心实现层 | 提供开箱即用的链、代理、记忆和工具实现 |
| `langchain-{provider}` | 独立集成包 | 针对特定服务商的集成（如`langchain-openai`、`langchain-anthropic`） |
| `langchain-community` | 社区贡献层 | 第三方贡献的集成和工具（逐渐迁移至独立包） |

**安装命令**：

```bash
# 核心包
pip install langchain langchain-core

# 常用集成
pip install langchain-openai langchain-community
```

## 二、核心基础：Runnable协议

所有LangChain组件都实现了**Runnable协议**，这是LangChain的灵魂。它定义了统一的调用接口，让任何组件都可以通过`|`管道符自由组合。

### 2.1 标准调用方法

所有Runnable对象都支持以下5种标准调用方式：

| 方法 | 功能 | 返回值 |
|------|------|--------|
| `invoke(input, config=None)` | 同步调用 | 单个结果 |
| `ainvoke(input, config=None)` | 异步调用 | 单个结果（协程） |
| `stream(input, config=None)` | 同步流式输出 | 结果生成器 |
| `astream(input, config=None)` | 异步流式输出 | 结果异步生成器 |
| `batch(inputs, config=None)` | 批量调用 | 结果列表 |

**示例**：

```python
from langchain_core.runnables import RunnableLambda

# 定义一个简单的Runnable
add_one = RunnableLambda(lambda x: x + 1)

# 各种调用方式
print(add_one.invoke(1))  # 输出: 2
print(add_one.batch([1, 2, 3]))  # 输出: [2, 3, 4]

for token in add_one.stream(5):
    print(token)  # 输出: 6
```

### 2.2 LCEL（LangChain Expression Language）

LCEL是基于Runnable协议的声明式语法，使用`|`管道符连接组件，数据从左到右自动流转。

**基础语法**：

```python
chain = component1 | component2 | component3
result = chain.invoke(input_data)
```

**核心组合原语**：

- **RunnableSequence**：顺序执行（`|`）
- **RunnableParallel**：并行执行（`{}`）
- **RunnableAssign**：向字典中添加新字段
- **RunnableBranch**：条件分支执行

**示例：并行执行**

```python
from langchain_core.runnables import RunnableParallel

chain = RunnableParallel({
    "a": lambda x: x["num"] + 1,
    "b": lambda x: x["num"] * 2
})

print(chain.invoke({"num": 5}))
# 输出: {"a": 6, "b": 10}
```

## 三、模型API

LangChain提供了统一的接口来调用不同厂商的大模型，分为**LLM（文本补全模型）**和**ChatModel（聊天模型）**两大类，目前ChatModel是主流。

### 3.1 ChatModel（聊天模型）

这是最常用的模型接口，支持多轮对话和工具调用。

**核心类**：

- `ChatOpenAI`：OpenAI GPT系列
- `ChatAnthropic`：Anthropic Claude系列
- `ChatGoogleGenerativeAI`：Google Gemini系列
- `init_chat_model()`：通用模型构造器（推荐）

**初始化与基本调用**：

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage

# 初始化模型
model = ChatOpenAI(
    model="gpt-4o",
    temperature=0,
    max_tokens=1024,
    api_key="your-api-key"
)

# 基本调用
messages = [
    SystemMessage(content="你是一个有用的助手"),
    HumanMessage(content="你好，介绍一下你自己")
]

response = model.invoke(messages)
print(response.content)
```

**流式输出**：

```python
for chunk in model.stream(messages):
    print(chunk.content, end="", flush=True)
```

### 3.2 工具调用API

所有支持工具调用的ChatModel都实现了`bind_tools()`方法，这是构建智能体的基础。

**定义工具**：

```python
from langchain_core.tools import tool
from pydantic import BaseModel, Field

# 方法1：使用@tool装饰器（推荐）
@tool
def add(a: int, b: int) -> int:
    """将两个整数相加"""
    return a + b

# 方法2：使用Pydantic模型定义
class MultiplyInput(BaseModel):
    """乘法输入参数"""
    a: int = Field(..., description="第一个整数")
    b: int = Field(..., description="第二个整数")

@tool(args_schema=MultiplyInput)
def multiply(a: int, b: int) -> int:
    """将两个整数相乘"""
    return a * b
```

**绑定与调用工具**：

```python
# 绑定工具到模型
model_with_tools = model.bind_tools([add, multiply])

# 调用模型，模型会自动决定是否使用工具
response = model_with_tools.invoke("3加5等于多少？再乘以2是多少？")

# 检查工具调用
if response.tool_calls:
    print("工具调用：", response.tool_calls)
    # 执行工具
    from langgraph.prebuilt import ToolNode
    tool_node = ToolNode([add, multiply])
    tool_results = tool_node.invoke({"messages": [response]})
    print("工具结果：", tool_results)
```

**强制调用特定工具**：

```python
# 强制模型调用multiply工具
model_force_multiply = model.bind_tools(
    [multiply],
    tool_choice={"type": "function", "function": {"name": "multiply"}}
)
```

### 3.3 MCP (Model Context Protocol) 集成

根据 AI Agent 开发架构规范，**MCP (Model Context Protocol)** 正在成为工具调用的行业标准：

- **标准化接口**：为不同框架和服务之间的工具互操作提供统一协议
- **上下文感知**：工具调用时自动携带相关上下文信息
- **安全传输**：内置认证和授权机制，确保工具调用的安全性
- **跨平台兼容**：支持 LangChain、LlamaIndex、AutoGen 等主流框架

```python
# MCP 工具注册示例
from langchain_mcp import register_mcp_tool

@register_mcp_tool
def mcp_search(query: str) -> str:
    """MCP 标准化的搜索工具"""
    # 实现 MCP 兼容的搜索逻辑
    return f"MCP搜索结果: {query}"
```

## 四、提示词API

提示词模板用于将用户输入和系统指令格式化为模型可以理解的消息格式。

### 4.1 ChatPromptTemplate（聊天提示词模板）

这是最常用的提示词模板，支持多角色消息和占位符。

**基本用法**：

```python
from langchain_core.prompts import ChatPromptTemplate

# 创建聊天提示词模板
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个{role}，请用{language}回答问题"),
    ("human", "{question}")
])

# 格式化提示词
formatted_prompt = prompt.format_messages(
    role="数学老师",
    language="中文",
    question="什么是勾股定理？"
)

# 与模型组合成链
chain = prompt | model
response = chain.invoke({
    "role": "数学老师",
    "language": "中文",
    "question": "什么是勾股定理？"
})
```

**高级用法：MessagesPlaceholder**

```python
from langchain_core.prompts import MessagesPlaceholder

# 支持动态消息历史的提示词模板
prompt_with_history = ChatPromptTemplate.from_messages([
    ("system", "你是一个有用的助手"),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{question}")
])
```

## 五、输出解析器API

输出解析器用于将模型的原始输出转换为结构化数据（如字符串、JSON、Pydantic对象）。

### 5.1 常用解析器

| 解析器 | 功能 | 返回值 |
|--------|------|--------|
| `StrOutputParser` | 提取模型输出的文本内容 | 字符串 |
| `JsonOutputParser` | 解析JSON格式的输出 | 字典 |
| `PydanticOutputParser` | 解析为Pydantic模型对象 | Pydantic实例 |

**示例：PydanticOutputParser**

```python
from langchain_core.output_parsers import PydanticOutputParser
from pydantic import BaseModel, Field

class Person(BaseModel):
    name: str = Field(description="人的姓名")
    age: int = Field(description="人的年龄")
    occupation: str = Field(description="人的职业")

parser = PydanticOutputParser(pydantic_object=Person)

prompt = ChatPromptTemplate.from_messages([
    ("system", "请根据用户描述生成一个人物信息，使用以下格式：\n{format_instructions}"),
    ("human", "{description}")
]).partial(format_instructions=parser.get_format_instructions())

chain = prompt | model | parser
person = chain.invoke({"description": "一个30岁的软件工程师，名叫张三"})
print(person.name)  # 输出: 张三
```

### 5.2 结构化输出API（推荐）

对于支持结构化输出的模型（如GPT-4o、Claude 3），推荐使用更简洁的`with_structured_output()`方法：

```python
# 直接让模型输出Pydantic对象
structured_model = model.with_structured_output(Person)
person = structured_model.invoke("一个30岁的软件工程师，名叫张三")
```

## 六、RAG相关API

LangChain提供了完整的检索增强生成（RAG）工具链，覆盖从文档加载到检索生成的全流程。

### 6.1 核心组件

| 组件 | 功能 | 常用实现 |
|------|------|----------|
| `DocumentLoader` | 加载各种格式的文档 | `PyPDFLoader`、`TextLoader`、`WebBaseLoader` |
| `TextSplitter` | 将文档分割为小块 | `RecursiveCharacterTextSplitter` |
| `Embeddings` | 将文本转换为向量 | `OpenAIEmbeddings`、`HuggingFaceEmbeddings` |
| `VectorStore` | 存储和检索向量 | `Chroma`、`FAISS`、`Pinecone` |
| `Retriever` | 根据查询检索相关文档 | `VectorStoreRetriever` |

**完整RAG流程示例**：

```python
from langchain_community.document_loaders import WebBaseLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import Chroma

# 1. 加载文档
loader = WebBaseLoader("https://python.langchain.com/docs/concepts/lcel/")
documents = loader.load()

# 2. 分割文档
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200
)
splits = text_splitter.split_documents(documents)

# 3. 创建向量存储
embeddings = OpenAIEmbeddings()
vectorstore = Chroma.from_documents(documents=splits, embedding=embeddings)

# 4. 创建检索器
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
```

### 6.2 构建RAG链

使用LCEL构建完整的RAG问答链：

```python
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

# 定义RAG提示词
rag_prompt = ChatPromptTemplate.from_template("""
根据以下上下文回答问题：
上下文：{context}
问题：{question}
如果上下文没有相关信息，请回答"我不知道"。
""")

# 构建RAG链
rag_chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | rag_prompt
    | model
    | StrOutputParser()
)

# 调用RAG链
response = rag_chain.invoke("什么是LCEL？")
print(response)
```

## 七、记忆API

记忆系统用于存储和检索对话历史，让AI能够记住之前的对话内容。

### 7.1 核心类

| 类 | 功能 | 适用场景 |
|----|------|----------|
| `InMemoryChatMessageHistory` | 内存存储对话历史 | 开发调试、短会话 |
| `RedisChatMessageHistory` | Redis存储对话历史 | 生产环境、长会话 |
| `RunnableWithMessageHistory` | 将记忆集成到链中 | 所有需要记忆的场景 |

**示例：带记忆的对话链**

```python
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

# 定义聊天历史存储
store = {}

def get_session_history(session_id: str):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

# 构建基础链
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个有用的助手"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{question}")
])

chain = prompt | model | StrOutputParser()

# 集成记忆
chain_with_history = RunnableWithMessageHistory(
    chain,
    get_session_history,
    input_messages_key="question",
    history_messages_key="history"
)

# 调用带记忆的链
config = {"configurable": {"session_id": "user_123"}}
print(chain_with_history.invoke({"question": "我叫张三"}, config=config))
print(chain_with_history.invoke({"question": "我叫什么名字？"}, config=config))
```

## 八、代理API（LangGraph集成）

从LangChain 1.0开始，代理功能已全面迁移至**LangGraph**，使用统一的`create_agent()`函数构建生产级智能体。

### 8.1 基本ReAct代理

```python
from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.memory import MemorySaver

# 定义工具
tools = [add, multiply]

# 创建记忆
memory = MemorySaver()

# 创建ReAct代理
agent = create_react_agent(
    model,
    tools,
    checkpointer=memory
)

# 运行代理
config = {"configurable": {"thread_id": "1"}}
result = agent.invoke(
    {"messages": [("human", "3加5等于多少？再乘以2是多少？")]},
    config=config
)

# 输出最终结果
print(result["messages"][-1].content)
```

### 8.2 流式输出代理执行过程

```python
# 流式输出代理的所有事件
for event in agent.stream_events(
    {"messages": [("human", "3加5等于多少？再乘以2是多少？")]},
    config=config,
    version="v3"
):
    if event["event"] == "on_chat_model_stream":
        print(event["data"]["chunk"].content, end="", flush=True)
    elif event["event"] == "on_tool_start":
        print(f"\n调用工具：{event['name']}，参数：{event['data']['input']}")
    elif event["event"] == "on_tool_end":
        print(f"工具结果：{event['data']['output']}")
```

## 九、生产级安全最佳实践

根据 AI Agent 开发架构规范，必须实施以下安全措施：

### 9.1 沙箱机制

- **文件系统隔离**：限制对本地文件系统的访问权限
- **网络访问控制**：仅允许访问预定义的白名单域名和API
- **系统调用限制**：禁止执行危险的系统命令（如 rm、exec 等）

### 9.2 输入输出过滤

- **Prompt 注入防护**：对用户输入进行严格验证和清理
- **敏感信息审查**：防止泄露隐私数据或机密信息
- **输出内容过滤**：确保生成内容符合安全和合规要求

### 9.3 资源控制

- **工具调用成本限制**：设置每日/每小时的API调用配额
- **调用深度限制**：防止循环依赖和上下文爆炸
- **执行时间限制**：设置单次任务的最大执行时间

**安全工具示例**：

```python
@tool
def safe_calculate(expression: str) -> str:
    """安全的计算器工具，仅支持基本数学运算"""
    import re
    # 严格的输入验证
    if not re.match(r'^[\d+\-*/().\s]+$', expression):
        return "表达式包含非法字符"
    
    try:
        # 在受限环境中执行计算
        result = eval(expression, {"__builtins__": {}}, {})
        return str(result)
    except Exception as e:
        return f"计算错误：{str(e)}"
```
