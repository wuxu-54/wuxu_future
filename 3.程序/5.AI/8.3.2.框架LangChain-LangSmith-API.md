# LangSmith API 详细说明（2026 最新）

LangSmith API 分为两部分：  
1）**Python/TS SDK**（日常开发用，封装好、易集成）；  
2）**REST API**（控平台、批量操作、自动化流程）。  
核心用途：**追踪上报、查询 trace、管理数据集/评估、人工反馈、监控告警**。

---

## 一、基础信息与认证

### 1. 端点与版本

- 基础 URL：`https://api.smith.langchain.com`
- 版本：`/api/v1/`（当前稳定）
- 文档：<https://api.smith.langchain.com/docs（OpenAPI> 3.1）

### 2. 认证（必须）

所有请求带 Header：

```http
X-Api-Key: ls__your_api_key_here
```

获取方式：LangSmith 控制台 → Settings → API Keys。

### 3. 安装 SDK

```bash
pip install langsmith
# TS: npm install langsmith
```

## 二、Python SDK 核心 API（日常开发首选）

### 2.1 初始化 Client

```python
from langsmith import Client

client = Client(
    api_key="ls__xxx",  # 或用环境变量 LANGCHAIN_API_KEY
    api_url="https://api.smith.langchain.com"
)
```

### 2.2 追踪（Tracing）相关

#### （1）自动追踪（最常用）

直接设置环境变量，**无需改业务代码**：

```python
import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_PROJECT"] = "my-agent-project"
```

- 自动捕获：LLM 调用、工具调用、LangGraph 节点、RAG 检索。

#### （2）手动创建 Run（自定义 span）

```python
# 根 Run
with client.create_run(
    name="my-custom-run",
    run_type="chain",
    inputs={"query": "xxx"}
) as run:
    # 子 Run（嵌套）
    with client.create_run(
        name="sub-step",
        run_type="tool",
        parent_run_id=run.id
    ) as sub_run:
        sub_run.end(outputs={"result": "yyy"})
    run.end(outputs={"final": "zzz"})
```

#### （3）查询 Runs（查 Trace）

```python
# 简单过滤
runs = client.list_runs(
    project_name="my-agent-project",
    run_type="llm",
    limit=10
)

# 高级过滤（查询语法）
runs = client.list_runs(
    project_name="my-agent-project",
    filter='search("用户问题") AND metadata.user_id="123"'
)
```

- 支持：**全文搜索、metadata 过滤、时间范围、状态、token 数**。

### 2.3 数据集与评估（Evaluation）

#### （1）数据集管理

```python
# 创建数据集
dataset = client.create_dataset(
    dataset_name="rag-test-set",
    description="RAG 问答测试集"
)

# 添加示例（输入-输出对）
client.create_examples(
    inputs=[{"question": "什么是 LangSmith?"}],
    outputs=[{"answer": "LangSmith 是可观测性平台"}],
    dataset_id=dataset.id
)
```

#### （2）运行评估

```python
from langsmith.evaluation import evaluate

# 目标函数（你的 Agent/Chain）
def target_fn(inputs):
    return {"output": my_agent.invoke(inputs["question"])}

# 运行评估
results = evaluate(
    target_fn,
    data="rag-test-set",  # 数据集名
    evaluators=["correctness", "hallucination"]  # 内置评估器
)
```

- 内置评估器：**正确性、幻觉、相关性、有害性、流畅度**。

### 2.4 人工反馈（Human Feedback）

```python
# 给某个 Run 打分
client.create_feedback(
    run_id="run-uuid",
    key="user_rating",
    score=4.5,
    comment="回答很准确"
)

# 获取反馈
feedbacks = client.list_feedbacks(run_id="run-uuid")
```

### 2.5 项目与会话管理

```python
# 列出项目
projects = client.list_projects()

# 创建项目（等价于 Session）
session = client.create_session(
    name="experiment-v2",
    description="新提示词实验"
)
```

## 三、REST API 核心端点（自动化/批量）

### 3.1 追踪（Runs）

#### 创建 Run

```http
POST /api/v1/runs
Content-Type: application/json
X-Api-Key: ls__xxx

{
  "name": "api-test-run",
  "run_type": "llm",
  "project_name": "my-project",
  "inputs": {"prompt": "Hello"},
  "start_time": "2026-05-19T12:00:00Z"
}
```

#### 查询 Runs

```http
GET /api/v1/runs/query?project_name=my-project&run_type=llm
```

### 3.2 数据集（Datasets）

```http
# 创建数据集
POST /api/v1/datasets
{
  "name": "api-dataset",
  "description": "API 创建的数据集"
}

# 添加示例
POST /api/v1/datasets/{dataset_id}/examples
{
  "inputs": [{"q": "xxx"}],
  "outputs": [{"a": "yyy"}]
}
```

### 3.3 评估（Evaluations）

```http
# 创建实验（评估任务）
POST /api/v1/sessions
{
  "name": "eval-experiment",
  "reference_dataset_id": "dataset-uuid",
  "start_time": "2026-05-19T12:00:00Z"
}
```

### 3.4 反馈（Feedbacks）

```http
POST /api/v1/feedbacks
{
  "run_id": "run-uuid",
  "key": "quality",
  "score": 0.8,
  "comment": "Good"
}
```

## 四、LangGraph / LangChain 集成（重点）

### 4.1 自动追踪 LangGraph

```python
from langgraph.graph import StateGraph, START, END
from langsmith import Client

# 无需额外代码，只要开启追踪
os.environ["LANGCHAIN_TRACING_V2"] = "true"

# 定义图
builder = StateGraph(dict)
builder.add_node("llm", lambda state: state)
builder.add_edge(START, "llm")
graph = builder.compile()

# 执行时自动上报所有节点、状态、工具调用
graph.invoke({})
```

### 4.2 追踪 LCEL 链

```python
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI

prompt = PromptTemplate.from_template("Q: {q}")
llm = ChatOpenAI()
chain = prompt | llm

# 自动追踪整个链的执行
chain.invoke({"q": "LangSmith 是什么？"})
```

## 五、常用场景示例

### 场景1：调试 LangGraph 智能体

- 开启追踪 → 运行智能体 → 在 LangSmith 看**完整执行树、状态变化、工具入参/出参、耗时、token 数**。

### 场景2：批量评估 RAG 系统

- 创建测试数据集 → 调用 `evaluate` → 自动计算**准确率、幻觉率、相关性** → 对比不同版本效果。

### 场景3：生产环境监控

- 自动上报所有用户请求 → 用 API 查**错误率、延迟、成本、用户满意度** → 设置告警。

## 六、速率限制与安全

### 1. 速率限制（2026）

- 免费版：**100 次/分钟**，每月 5000 次追踪
- 团队版：**1000 次/分钟**
- 企业版：定制。

### 2. 安全

- 所有通信 **TLS 加密**
- 支持**敏感数据脱敏**（关闭上报字段）
- 自托管部署（企业版）满足数据驻留要求。

## 七、与 LangChain/LangGraph 关系

- **LangChain**：组件库（模型、工具、提示词）
- **LangGraph**：编排框架（状态、循环、多智能体）
- **LangSmith**：**可观测性+评估+监控平台**（为前两者提供“黑盒变白盒”能力）

一句话：**LangSmith = AI 应用的可观测性与质量控制中枢**。
