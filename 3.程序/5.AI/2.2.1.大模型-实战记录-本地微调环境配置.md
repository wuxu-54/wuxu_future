# 本地微调环境配置（windows）

## 我的电脑主要配置（微调相关）

| 部件 | 型号/规格 | 对微调的影响 |
|------|----------|-------------|
| **显卡** | NVIDIA GTX 1660 SUPER · **6GB 显存** | 核心算力，6GB 够用但不大 |
| **内存** | **16GB** | 训练前需关掉其他软件释放空间 |
| **CPU** | i5-10400F · 6核12线程 | 够用，数据预处理很快 |
| **硬盘** | SSD | 加载模型快，没问题 |

能微调的模型

| 模型大小 | 能否跑 LoRA |
|----------|:---:|
| **1.5B**（DeepSeek-R1 / Qwen） | ✅ **最佳选择**，流畅 |
| **3B**（Qwen2.5-3B） | ✅ 可以，batch 调低 |
| **7B**（Qwen/Llama） | ⚠️ 勉强，需 QLoRA + batch=1 |
| **全参数微调任何模型** | ❌ 显存不足，跑不了 |

## 大模型下载、运行

1. ollama 官网下载windows版本，安装、运行
2. 通过ollama下载 `DeepSeek-R1-1.5B` 大语言模型
3. conda 运行问题

    ```txt

    无法加载文件 C:\Users\Administrator\Documents\WindowsPowerShell\profile.ps1，因为在此系统上禁止运行脚本。有关详细信
    息，请参阅 https:/go.microsoft.com/fwlink/?LinkID=135170 中的 about_Execution_Policies。
    所在位置 行:1 字符: 3
    ```

    解决：使用`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force` 放行本地脚本执行。
4. torch安装命令（支持GPU版本的torch）：

    ```python
     conda create -n deepseek-lora python=3.10 -y # 创建虚拟环境，指定python为3.10.0  这个很重要，避免版本兼容问题。
     conda activate deepseek-lora #进入虚拟环境

    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121 #不指定版本安装

    python -c "import torch; print(f'CUDA可用: {torch.cuda.is_available()}'); print(f'CUDA版本: {torch.version.cuda}')" # 验证是否成功安装
    ```

5. 其他库安装命令：

    ```
    pip install transformers peft datasets accelerate bitsandbytes huggingface_hub sentencepiece tensorboard
    ```

库作用：

- transformers：深度学习库，里面包括文本处理工具、模型配置参数、训练数据加载工具
- peft：LoRA微调时使用
- dataset: 加载json
- accelerate：PyTorch 的分布式训练后端（Transformers 依赖它）
- bitsandbytes：用来做 4-bit 量化节省显存（脚本里 USE_4BIT=True 时需要）
- huggingface_hub：下载模型时用到（代码里 snapshot_download 需要）
- sentencepiece：部分 Tokenizer 需要（DeepSeek 用的是自己的，一般不缺）
- tensorboard：看训练 Loss 曲线（装了你就能 tensorboard --logdir ./ 看图表）
- scipy：某些评估指标会用到
