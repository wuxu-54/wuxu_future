# ollama

官网：<https://ollama.com/>

Ollama 是一款开源轻量级的本地大语言模型运行框架，支持一键部署 Llama、Qwen、Gemma 等数百种主流大模型，无需复杂配置即可通过命令行或 API 快速调用，所有计算完全在本地完成，能有效保护数据隐私安全。

## Ollama 常用命令速查表（可打印版）

**提示**：任何命令后加 `-h` 可查看详细帮助，如 `ollama run -h`

### 🚀 核心命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `ollama run <model>` | 运行模型并进入交互模式 | `ollama run llama3.2` |
| `ollama run <model> "<prompt>"` | 单次查询后退出 | `ollama run qwen3 "解释什么是AI"` |
| `ollama pull <model>` | 下载/更新模型 | `ollama pull gemma3:7b` |
| `ollama list` | 列出本地所有模型 | `ollama list` |
| `ollama ps` | 查看正在运行的模型 | `ollama ps` |
| `ollama stop <model>` | 停止模型释放内存 | `ollama stop llama3.2` |
| `ollama rm <model>` | 删除本地模型文件 | `ollama rm old-model` |

### ⚙️ 服务管理

| 命令 | 功能 |
|------|------|
| `ollama serve` | 手动启动Ollama服务 |
| `OLLAMA_HOST=0.0.0.0:11434 ollama serve` | 允许外部网络访问 |
| `OLLAMA_KEEP_ALIVE=-1 ollama serve` | 模型永久驻留内存 |

### 🛠️ 模型管理

| 命令 | 功能 |
|------|------|
| `ollama show <model> --modelfile` | 导出模型的Modelfile |
| `ollama show <model> --parameters` | 查看模型默认参数 |
| `ollama cp <old> <new>` | 复制模型创建新标签 |
| `ollama create <name> -f Modelfile` | 从Modelfile创建自定义模型 |

### 💬 交互模式快捷键

| 命令 | 功能 |
|------|------|
| `/bye` 或 `Ctrl+D` | 退出交互模式 |
| `/?` | 显示交互模式帮助 |
| `/clear` | 清除对话上下文 |
| `/load <model>` | 快速切换模型 |
| `/set system "<prompt>"` | 临时设置系统提示词 |
| `"""` | 开始多行输入（以`"""`结束） |

### ✨ 实用技巧

```bash
# 管道输入处理文本
cat document.txt | ollama run llama3.2 "总结这段文字"

# 强制JSON格式输出
ollama run gemma3 "列出3个水果" --format json

# 多模态模型分析图片
ollama run llava "这张图里有什么？ /path/to/photo.jpg"

# 生成文本嵌入向量
ollama run nomic-embed-text "Hello World"
```

### 📍 常用模型速记

- `llama3.2`：Meta最新通用模型（3B/7B/70B）
- `qwen3`：阿里通义千问（中文最佳）
- `gemma3`：谷歌轻量高效模型
- `llava`：多模态图像理解
- `nomic-embed-text`：文本嵌入模型
