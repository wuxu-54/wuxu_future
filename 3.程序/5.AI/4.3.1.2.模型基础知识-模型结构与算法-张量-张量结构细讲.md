# 张量完全指南

---

## 第一部分：张量是什么？（一句话 + 结构拆解）

**一句话定义**：  
张量是一个**带有多维结构、可硬件加速、支持自动微分**的数组。它把标量、向量、矩阵统一到一个框架里。

### 1.1 张量的六大组成部分

无论在 PyTorch、TensorFlow 还是 JAX 中，一个张量对象都包含以下 **6 个核心组成部分**：

| 组成部分 | 含义 | 查看方式 (PyTorch) | 为什么重要 |
|----------|------|--------------------|--------------|
| **数据存储** | 实际数值所占的连续内存块 | `tensor.data_ptr()` | 决定是否共享内存（视图 vs 拷贝） |
| **形状 (shape)** | 每个维度的大小（整数元组） | `tensor.shape` 或 `tensor.size()` | 定义数据结构，是索引和变形的依据 |
| **数据类型 (dtype)** | 每个元素的精度，如 float32, int64 | `tensor.dtype` | 影响显存和计算速度 |
| **设备 (device)** | 存储在 CPU / GPU / NPU | `tensor.device` | 不同设备无法直接运算 |
| **梯度信息** | `requires_grad` 和 `grad` | `tensor.requires_grad`, `tensor.grad` | 自动微分的核心 |
| **存储布局 (layout)** | 元素在内存中的排列方式 | `tensor.is_contiguous()`, `tensor.stride()` | 影响性能与是否可 view |

**分辨两个张量**：  

- 共享存储：`a.data_ptr() == b.data_ptr()`（修改一个另一个会变）  
- 视图关系：共享存储但 shape 或 stride 不同（如转置）  
- 独立拷贝：`.clone()` 或 `.to()` 会产生新内存

## 第二部分：张量的“维度”有三个不同含义（重点区分）

在日常交流中，“维度”一词经常混用，必须分清以下三种情况：

| 术语 | 英文 | 含义 | 代码示例 | 生活比喻 |
|------|------|------|-----------|------------|
| **阶数 (rank)** | rank / ndim | 张量有几个轴（几维） | `tensor.ndim` → 3 | 一张表格是 2 维，一本书是 3 维 |
| **轴的大小 (size)** | size / dimension | 某个具体轴上的元素个数 | `tensor.shape[1]` → 224 | 表格有多少行？书有多少页？ |
| **嵌入维度 (embedding dimension)** | embedding dim | 一个 token 的向量长度 | `d_model = 768` | 每个学生考了几门课？ |

**最容易混淆的例子**：  
> “文本向量化后的维度是 768”  

- 这里的“维度”指的是 **嵌入维度**，本质上就是 **轴的大小**（因为向量只有一轴，该轴长度=768）  
- **不是阶数**（向量的阶数是 1）

**快速判断技巧**：  

- 问“几维”→ 回答阶数  
- 问“这个维度大小是多少”→ 回答轴的大小  
- 说“embedding 维度”→ 专指向量长度（也是轴大小的一种）

## 第三部分：从标量到高维张量——每升一阶增加一种“组织关系”

| 阶数 | 名称 | 形状示例 | 新增的组织能力 | 大模型 / RAG 中的例子 |
|------|------|----------|----------------|------------------------|
| 0 | 标量 | `()` | 单个数字 | loss 值，准确率 |
| 1 | 向量 | `(D,)` | 将多个属性组合成一个样本 | 一个文本的 embedding，形状 `(768,)` |
| 2 | 矩阵 | `(N, D)` | 将多个样本堆叠成数据集 | 一个 batch 的文本向量，形状 `(32, 768)` |
| 3 | 三阶张量 | `(T, N, D)` | 引入时间 / 序列维度 | 一个句子中多个 token 的 embedding：`(10, 32, 768)` 即序列长度×批次×嵌入维 |
| 4 | 四阶张量 | `(B, C, H, W)` | 引入通道和空间结构 | 图像 batch：`(32, 3, 224, 224)` |

**直观记忆**：  

- 向量 = 一行数字  
- 矩阵 = 一页表格  
- 三阶张量 = 一本书（页 × 行 × 列）  
- 四阶张量 = 一排书（书架位置 × 页 × 行 × 列）

**注意**：向量是 1 阶张量，矩阵是 2 阶张量，标量是 0 阶张量。**向量是张量的子集，张量是向量的超集。**

## 第四部分：张量在计算机中的表示（内存布局与步长）

### 4.1 连续内存 + 元数据

张量数据存储在**一块连续的内存**中。为了支持高效切片、转置等操作，每个张量还记录了 **步长 (stride)**。

- **步长**：跳到下一个维度所需的元素个数。  
  对于形状为 `(D0, D1, D2)` 的行主序张量，默认步长为 `(D1*D2, D2, 1)`。

**示例**：一个 `(2, 3)` 矩阵的逻辑与内存布局

```python
import torch
x = torch.arange(6).reshape(2, 3)
# x = [[0,1,2],
#      [3,4,5]]
print(x.stride())   # (3, 1)  跳到下一行需3个元素，跳到下一列需1个元素
```

### 4.2 连续 vs 非连续

- **连续 (contiguous)**：内存中元素的排列顺序与逻辑索引顺序一致。  
  判断：`tensor.is_contiguous()`

- **非连续**：经过 `transpose`、`permute` 等操作后，步长改变，但内存数据未移动。  
  后果：`view()` 会报错（因为 view 要求连续），需要用 `reshape()` 或 `.contiguous()` 先拷贝再变形。

```python
x = torch.randn(3, 4)
y = x.transpose(0, 1)   # 转置，y 不连续
print(y.is_contiguous()) # False
# y.view(2, 6)          # 报错！
y.reshape(2, 6)         # 正确（内部会拷贝）
y.contiguous().view(2,6)# 显式连续化后再 view
```

### 4.3 视图 vs 拷贝

| 操作类型 | 是否拷贝 | 例子 |
|----------|----------|------|
| 切片 | 否（视图） | `x[0, :]` |
| `view` / `reshape` (兼容时) | 否 | `x.view(-1)` |
| `transpose` / `permute` | 否 | `x.t()` |
| `clone` | 是 | `x.clone()` |
| `.to(device)` | 是 | `x.to('cuda')` |
| `.numpy()` (若数据已共享) | 否（但注意） | `torch.from_numpy(ndarray)` 是共享的 |

**修改视图会影响原张量**，务必小心。

## 第五部分：张量的核心操作（实战必备）

### 5.1 创建张量

| 方式 | 特点 | 示例 |
|------|------|------|
| 从列表 | 拷贝数据 | `torch.tensor([1,2,3])` |
| 零/一/随机 | 分配新内存 | `torch.zeros(2,3)`, `torch.randn(2,3)` |
| 从 NumPy | 默认共享内存 | `torch.as_tensor(ndarray)` 或 `torch.from_numpy(ndarray)` |
| 全等 / 等差 | 方便测试 | `torch.full((2,3), 5)`, `torch.arange(0,10,2)` |

**注意**：`torch.tensor()` 总是拷贝；`torch.as_tensor()` 尽量共享，效率高但可能意外修改原数据。

### 5.2 形状操作

| 操作 | 是否拷贝 | 要求 | 推荐用法 |
|------|----------|------|-----------|
| `view` | 否 | 必须连续 | 已知连续时用 |
| `reshape` | 尽量不拷贝 | 自动处理非连续 | 通用推荐 |
| `permute` / `transpose` | 否 | 任意 | 交换维度，返回非连续 |
| `unsqueeze` / `squeeze` | 否 | 增删大小为1的维度 | 调整维度对齐 |
| `flatten` | 通常拷贝 | 拍平 | `x.flatten()` |
| `contiguous` | 若非连续则拷贝 | 返回连续版本 | 调用 `view` 前若不确定连续，先 `contiguous()` |

**最佳实践**：不确定时用 `reshape` 代替 `view`，牺牲少量性能避免出错。

### 5.3 数学运算

- **逐元素**：`+`, `-`, `*`, `/`, `**`（支持广播）  
- **归约**：`.sum(dim=1)`, `.mean(dim=0)`, `.max(dim=2)`  
- **矩阵乘法**：`@`, `torch.matmul`, `torch.mm` (2D only)  
- **广播规则**：从尾部维度对齐，每个维度要么相等，要么其中一个是1，要么缺失。

```python
a = torch.randn(2, 3, 1)
b = torch.randn(3, 5)
c = a + b   # shape (2, 3, 5) 自动广播
```

**注意**：广播不分配新内存，是虚拟的，但可能导致难以发现的形状错误。

### 5.4 自动微分相关操作

```python
x = torch.randn(3, requires_grad=True)  # 需要梯度
y = x * 2
z = y.sum()
z.backward()          # 反向传播
print(x.grad)         # 梯度 = 2
```

- **推理时**：用 `with torch.no_grad():` 禁用梯度计算，节省显存。
- **梯度清零**：`optimizer.zero_grad()`（梯度默认累积）
- **就地修改**：避免对 `requires_grad=True` 的叶子张量使用 `x.add_(...)`，会破坏计算图。

## 第六部分：大模型中的张量——典型形状与分布

### 6.1 常见张量形状（以 Transformer 为例）

| 组件 | 形状 | 含义 |
|------|------|------|
| 输入嵌入 | `[B, S, D]` | B=batch_size, S=sequence_length, D=d_model |
| 注意力 Q/K/V | `[B, H, S, D_head]` | H=num_heads, D_head = D/H |
| 注意力分数 | `[B, H, S, S]` | 自注意力矩阵 |
| FFN 中间层 | `[B, S, 4D]` | 前馈网络扩维 |
| 输出 logits | `[B, S, V]` | V=vocab_size |

### 6.2 分布式训练中的张量并行（TP）

将一个大张量切分到多个 GPU：

- **列并行**：切最后维度，例如 `[B, S, D]` → 每个 GPU 得到 `[B, S, D/tp_size]`  
- **行并行**：切第一个维度，例如 `[D, 4D]` 权重矩阵 → 按行切分

切分后的张量叫**分片张量**，通过 `all-reduce` 通信同步。

## 第七部分：RAG 中文本向量化——张量视角

### 7.1 向量化过程

1. **输入**：一段文本（字符串）  
2. **嵌入模型**（如 BGE、OpenAI Ada）  
3. **输出**：一个 1 阶张量，形状 `(D,)`，即**向量**。  
   - `D` = 嵌入维度（例如 768、1536）

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('BAAI/bge-base-zh')
query = "如何学习张量？"
vec = model.encode(query)          # shape: (768,)  → 1阶张量
```

### 7.2 批量处理

```python
docs = ["文本1", "文本2", ...]
vecs = model.encode(docs)          # shape: (N, 768) → 2阶张量（矩阵）
```

- 每行是一个文本的向量  
- 批量编码提高吞吐量

### 7.3 相似度计算

```python
# query_vec: (768,), doc_vecs: (N, 768)
scores = doc_vecs @ query_vec       # shape: (N,) 余弦相似度（若已归一化）
best_idx = scores.argmax()          # 0阶张量（标量）
```

### 7.4 存储与检索

向量数据库（如 Milvus, Faiss）内部存储的就是 1 阶或 2 阶张量（float32），并建立索引加速近似最近邻搜索。

## 第八部分：开发中的常见错误与速查

| 错误现象 | 原因 | 解决方法 |
|----------|------|----------|
| `shape mismatch` | 广播规则不满足 | 打印 `.shape`，用 `unsqueeze` 或 `reshape` |
| `expected device cuda:0 but got cpu` | 不同设备张量运算 | 统一 `.to(device)` |
| `view size is not compatible` | 非连续张量调用 view | 改用 `reshape` 或 `.contiguous().view` |
| `CUDA out of memory` | 显存不足 | 减小 batch，用混合精度，清空缓存 |
| `RuntimeError: element 0 of tensors does not require grad` | 混合需要梯度和不需要梯度的张量 | 不需要梯度的用 `.detach()` |
| 修改视图导致原数据变化 | 视图共享内存 | 若需独立，显式 `.clone()` |

## 总结：一张脑图记住张量

```
张量
├── 元数据
│   ├── shape（形状）
│   ├── stride（步长）
│   ├── dtype（类型）
│   ├── device（设备）
│   ├── requires_grad/grad（梯度）
│   └── layout（布局）
├── 存储
│   └── 一块连续内存
├── 阶数（rank） = len(shape)
│   ├── 0 标量
│   ├── 1 向量
│   ├── 2 矩阵
│   └── ≥3 高维张量
└── 核心操作
    ├── 创建（工厂函数）
    ├── 变形（reshape/view/permute）
    ├── 数学（逐元素/矩阵乘/广播）
    └── 自动微分（backward）
```

**最终记住三句话**：  

1. 张量是带元数据的多维数组，是深度学习的数据通货。  
2. 向量是 1 阶张量，RAG 中一个文本的 embedding 就是向量。  
3. “维度”要看上下文：分清阶数、轴的大小、嵌入维度。
