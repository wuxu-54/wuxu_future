#

## 问

```txt
auto x = _Input({1, 3, 224, 224}, NC4HW4);
auto y = _Conv2D(x, 64, {3,3}, VALID);
auto z = _MaxPool(y, {2,2});
```

## 解释

这段代码使用了 MNN 的 **Express (动态构图) API**，一行一行地搭建一个简单的卷积神经网络片段。我们来逐行解释：

```cpp
auto x = _Input({1, 3, 224, 224}, NC4HW4);
```

- **`_Input`**：创建一个**输入节点**，代表模型的输入张量。
- **`{1, 3, 224, 224}`**：输入张量的形状，含义是：
  - `1` —— batch size（一次处理 1 张图片）
  - `3` —— 通道数（如 RGB 3 通道）
  - `224` —— 高度
  - `224` —— 宽度
- **`NC4HW4`**：MNN 内部使用的内存布局格式。这是一种为移动端 CPU 优化的数据排布方式，将通道按 4 对齐后交错存储，可以提高 SIMD 指令的利用率。`N` 代表 batch，`C4` 代表通道按 4 分块，`H` 和 `W` 代表空间维度。

```cpp
auto y = _Conv2D(x, 64, {3,3}, VALID);
```

- **`_Conv2D`**：添加一个**二维卷积层**。
- **`x`**：输入节点（即上一行定义的 `x`）。
- **`64`**：输出通道数，即使用 64 个卷积核，输出特征图将有 64 个通道。
- **`{3,3}`**：卷积核的大小，3×3 的滤波器。
- **`VALID`**：padding 模式，表示**不使用填充**（no padding）。这意味着输出空间尺寸会比输入小（对于 224×224 输入，3×3 卷积 stride=1 时输出为 222×222）。另一种常见模式是 `SAME`，会自动补零使输出尺寸与输入相同。

```cpp
auto z = _MaxPool(y, {2,2});
```

- **`_MaxPool`**：添加一个**最大池化层**。
- **`y`**：输入节点（上一行卷积的输出）。
- **`{2,2}`**：池化窗口大小，2×2 的区域取最大值。默认步长等于窗口大小，所以输出空间尺寸会减半（111×111）。

> 池化层（Pooling Layer）是卷积神经网络（CNN）中非常常见的一层，核心作用就是下采样，通俗地说就是把特征图“浓缩”一下，尺寸变小，但保留最重要的信息。具体可以看CNN章节有介绍。

---

### 整体效果

这段代码构建了这样一个操作序列：

```
输入(1×3×224×224)  →  卷积(64个3×3核,无填充)  →  最大池化(2×2)
```

最终 `z` 就是这段子图的输出节点。之后可以继续添加更多层，或者直接 `auto output = z->readMap<float>()` 来获取推理结果。这就是 **MNN 动态构图** 的方式：像搭积木一样即时创建计算图，兼具灵活性和高效性。
