# PyTorch 全维度详解：核心API、模块、使用注意事项

PyTorch 是**Facebook AI 研究院（FAIR）** 开源的**深度学习框架**，以**动态计算图、Pythonic 语法、易用性强、调试方便**为核心优势，是学术界和工业界最主流的深度学习框架之一。

- 中文网站：<https://docs.pytorch.ac.cn/docs/stable/index.html>

它的核心定位：**面向张量计算、自动微分、神经网络搭建、训练部署的全流程工具**，支持 CPU/GPU/TPU 加速，无缝衔接 Python 生态。

## 一、PyTorch 核心架构与核心API总览

PyTorch API 分为**核心底层API**和**高层封装API**，整体分层：

1. **底层核心**：张量操作、自动微分、设备管理
2. **中层组件**：神经网络层、优化器、数据加载、损失函数
3. **高层工具**：模型保存加载、分布式训练、部署工具

### 核心API分类总表

| 分类 | 核心模块/API | 核心作用 |
|------|-------------|----------|
| 张量基础 | `torch` | 张量创建、数学运算、设备操作 |
| 自动微分 | `torch.autograd` | 自动求导、梯度计算、反向传播 |
| 神经网络 | `torch.nn` | 搭建网络层、模型容器、损失函数 |
| 优化器 | `torch.optim` | 梯度更新（SGD/Adam等） |
| 数据处理 | `torch.utils.data` | 数据集加载、批处理、多线程加载 |
| 模型工具 | `torch.save/load` | 模型保存/加载、断点续训 |
| 视觉专用 | `torchvision` | 图像数据集、预训练模型、图像增强 |
| 分布式 | `torch.distributed` | 多卡/多机分布式训练 |
| 部署 | `torch.onnx/torchscript` | 模型导出、生产环境部署 |

## 二、分模块精细化API详解

### 1. 核心底层模块：`torch`

**定位**：PyTorch 的**基础核心**，对标 NumPy，是所有操作的基石，提供张量（Tensor）定义和基础运算。

#### 核心API

1. **张量创建**

   ```python
   import torch
   # 创建张量
   a = torch.tensor([1,2,3])  # 从列表创建
   b = torch.zeros(2,3)       # 全0张量
   c = torch.ones(2,3)        # 全1张量
   d = torch.rand(2,3)        # 0~1随机张量
   e = torch.arange(0,10,2)   # 序列张量
   ```

2. **张量属性/操作**
   - 形状：`tensor.shape` / `tensor.size()`
   - 数据类型：`tensor.dtype`
   - 设备：`tensor.device` (CPU/GPU)
   - 变形：`tensor.reshape()`, `tensor.view()`
   - 拼接/切分：`torch.cat()`, `torch.split()`
3. **数学运算**
   加减乘除、矩阵乘法（`torch.matmul`）、指数、对数、统计运算（均值/方差）。
4. **设备管理**

   ```python
   # 判断GPU是否可用
   torch.cuda.is_available()
   # 张量迁移到GPU
   tensor = tensor.to('cuda')
   ```

#### 核心特性

- 张量 = **数据 + 梯度 + 设备信息**，是 PyTorch 最基本的数据结构
- 完全兼容 NumPy，可互转：`tensor.numpy()` / `torch.from_numpy()`

---

### 2. 自动微分模块：`torch.autograd`

**定位**：PyTorch 的核心引擎，实现**自动反向传播、梯度计算**，无需手动推导公式。

#### 核心API

1. **梯度开启**：`requires_grad=True`

   ```python
   x = torch.tensor([1.0], requires_grad=True)
   ```

2. **反向传播**：`loss.backward()`
   自动计算所有叶子节点的梯度，存储在 `.grad` 属性中。
3. **梯度禁用**：`torch.no_grad()`
   推理阶段使用，关闭梯度计算，**节省内存+加速**。
4. **高阶API**：`torch.autograd.grad()` 手动计算梯度。

#### 关键机制

- **动态计算图**：运行时构建，每一步都可调试，区别于 TensorFlow 静态图
- 梯度会**累加**，训练时必须用 `optimizer.zero_grad()` 清空梯度

---

### 3. 神经网络核心模块：`torch.nn`

**定位**：搭建深度学习模型的**核心模块**，封装了所有常用网络层、模型容器、损失函数。

这是 PyTorch 最常用的模块，分为 4 大类：

#### ① 模型容器（搭建网络骨架）

- `nn.Module`：**所有模型/层的基类**，自定义模型必须继承
- `nn.Sequential`：顺序容器，快速搭建简单网络

  ```python
  model = nn.Sequential(
      nn.Linear(10, 20),
      nn.ReLU(),
      nn.Linear(20, 1)
  )
  ```

#### ② 网络层（预定义层，直接调用）

| API | 用途 |
|-----|------|
| `nn.Linear` | 全连接层 |
| `nn.Conv2d` | 二维卷积层（图像） |
| `nn.LSTM/GRU` | 循环神经网络层 |
| `nn.Transformer` | Transformer 架构 |
| `nn.BatchNorm2d` | 批归一化 |
| `nn.Dropout` | 随机失活（防止过拟合） |

#### ③ 激活函数

`nn.ReLU()`、`nn.Sigmoid()`、`nn.Softmax()`、`nn.GELU()`

#### ④ 损失函数

- 分类任务：`nn.CrossEntropyLoss`（交叉熵）、`nn.BCELoss`
- 回归任务：`nn.MSELoss`（均方误差）
- 对比学习：`nn.CosineEmbeddingLoss`

---

### 4. 优化器模块：`torch.optim`

**定位**：实现**梯度更新算法**，自动更新模型参数。

#### 常用API

```python
# 定义优化器
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
```

- 基础优化器：`SGD`、`Adam`、`AdamW`（最常用）、`RMSprop`
- 核心方法：
  1. `optimizer.zero_grad()`：**清空梯度**（必须写）
  2. `loss.backward()`：计算梯度
  3. `optimizer.step()`：更新参数

---

### 5. 数据处理模块：`torch.utils.data`

**定位**：标准化处理**数据集加载、批处理、打乱、多线程加速**，解决数据瓶颈。

#### 核心API

1. `Dataset`：抽象类，**自定义数据集**必须继承
2. `DataLoader`：数据加载器，自动批处理、打乱、多进程加载

   ```python
   from torch.utils.data import DataLoader, TensorDataset
   dataset = TensorDataset(x, y)
   dataloader = DataLoader(dataset, batch_size=32, shuffle=True, num_workers=2)
   ```

3. `random_split`：数据集划分（训练集/验证集）

---

### 6. 扩展模块：`torchvision`（视觉专用）

**定位**：PyTorch 官方视觉工具库，独立安装，专为**计算机视觉**任务设计。

#### 核心API

1. **数据集**：`MNIST`、`CIFAR10`、`ImageNet` 等内置数据集
2. **预训练模型**：`resnet50`、`vit_b_16`、`yolo` 等，一键加载
3. **图像变换**：`transforms`（缩放、裁剪、归一化、数据增强）

   ```python
   from torchvision import transforms
   transform = transforms.Compose([
       transforms.Resize(256),
       transforms.CenterCrop(224),
       transforms.ToTensor()
   ])
   ```

---

### 7. 模型保存与部署模块

1. **模型保存/加载**
   - 保存整个模型：`torch.save(model, 'model.pth')`
   - 仅保存参数（推荐）：`torch.save(model.state_dict(), 'params.pth')`
2. **部署工具**
   - `TorchScript`：生产环境部署
   - `ONNX`：跨平台部署（支持 C++/Java/移动端）

---

### 8. 分布式训练模块：`torch.distributed`

**定位**：多GPU/多服务器训练加速，工业界必备。
核心API：`init_process_group`、`DistributedDataParallel(DDP)`

## 三、PyTorch 使用核心注意事项（避坑指南）

这是新手最容易出错的点，**必须牢记**：

### 1. 设备统一（CPU/GPU）

- 模型、数据、损失函数必须在**同一设备**上
- 错误写法：数据在CPU，模型在GPU → 直接报错
- 标准写法：

  ```python
  device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
  model = model.to(device)
  x, y = x.to(device), y.to(device)
  ```

### 2. 梯度管理（训练/推理模式）

- **训练模式**：默认开启梯度，启用 Dropout/BatchNorm
- **推理模式**：必须加 `model.eval()` + `torch.no_grad()`

  ```python
  model.eval()
  with torch.no_grad():
      output = model(x)
  ```

### 3. 梯度清零

- 梯度默认**累加**，每次迭代必须 `optimizer.zero_grad()`，否则梯度爆炸

### 4. 数据类型匹配

- 模型参数默认 `float32`，输入数据必须是浮点型，不能用整数张量输入网络

### 5. 原地操作禁止

- 自动微分不支持原地操作（如 `tensor += 1`），会破坏计算图
- 正确写法：`tensor = tensor + 1`

### 6. 模型保存规范

- 优先保存**参数（state_dict）**，不保存整个模型
- 跨版本/跨设备兼容性更好

### 7. BatchNorm/Dropout 陷阱

- 训练和推理行为不同：推理时必须 `model.eval()`，否则结果错误

### 8. 内存优化

- 不用的张量及时释放：`del tensor` + `torch.cuda.empty_cache()`
- 大模型用混合精度训练（`torch.cuda.amp`）

## 四、PyTorch 核心工作流（标准模板）

所有任务通用流程，串联所有API：

```python
# 1. 导入模块
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

# 2. 定义设备
device = torch.device('cuda')

# 3. 数据加载
dataloader = DataLoader(...)

# 4. 定义模型、损失、优化器
model = nn.Sequential(...).to(device)
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

# 5. 训练循环
model.train()
for x, y in dataloader:
    x, y = x.to(device), y.to(device)
    pred = model(x)
    loss = criterion(pred, y)
    
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# 6. 推理
model.eval()
with torch.no_grad():
    output = model(x)
```

### 总结

1. **核心分层**：`torch`（张量）→ `autograd`（微分）→ `nn`（网络）→ `optim`（优化）→ `data`（数据）
2. **最常用模块**：`torch`、`torch.nn`、`torch.optim`、`torch.utils.data`、`torchvision`
3. **避坑核心**：设备统一、梯度清零、训练/推理模式区分、禁用原地操作
4. **优势**：动态图、易调试、Python原生、生态完善，适合入门与工业落地
