# LLM + MNN 完整链路（极简版）

## 总流程一句话

**用户文字 → 编码（转token id整数）→ MNN推理 → 拿到概率 → argmax取token id → 解码（转回文字），循环生成直到结束符。**

---

## 1、输入侧：编码（Encode）【文字 → token id】

输入：用户文本，例如：`你好`

1. 交给sentencepiece分词器
2. 分词，得到一串子词，转成**整数token id**>

> 例子：`你好` → token_ids = [1280, 2561]

3. 把这组整数，放进MNN的int32类型Tensor，shape `[1, seq_len]`
4. MNN resizeSession调整输入形状
5. 执行 runSession 推理

>
> ✅ 记住：**MNN只认数字，不认汉字**

## 2、MNN推理输出

推理跑完，输出Tensor shape `[1,1,vocab_size]`
里面一大堆float数字，代表：**下一个位置，每个token的预测概率**

## 3、取token id：argmax

遍历所有概率，找到**最大概率对应的下标**
这个下标 = `next_token_id`（整数）

## 4、输出侧：解码（Decode）【token id → 文字】

把`next_token_id`丢给sentencepiece
转成对应的子词/汉字，追加到回答。

## 5、循环！LLM是一字一字生成（核心！）

1. 把刚拿到的`next_token_id`追加到输入token_ids数组末尾
2. 重新resize MNN输入tensor
3. 再次runSession，预测**再下一个token**
4. 一直循环，直到：
   - 遇到EOS结束token（`sp.eos_id()`）→ 停止生成
   - 或者达到设置的最大长度，强制停止

# 流程图（一眼看懂）

```
用户输入文字
    ↓
【Encode编码】sentencepiece → token id整数数组
    ↓
写入MNN输入Tensor(int32)
    ↓
MNN runSession 推理
    ↓
输出：一大堆概率float [1,1,vocab_size]
    ↓
argmax 取最大概率下标 → next_token_id
    ↓
【Decode解码】sentencepiece → 单个文字，加到回答
    ↓
判断：是不是EOS结束符？
├─是 → 结束，返回完整回答
└─否 → next_token_id追加到输入，回到上面继续循环
```

# 精简代码骨架（C++，对应上面流程）

```
// 1. 输入文本编码
std::string prompt = "你好";
std::vector<int32_t> token_ids = sp.Encode(prompt);

// 循环生成
while(true){
    // 放进MNN tensor，resize，推理
    fill_tensor_and_run(token_ids);

    // argmax拿到下一个token id
    int next_token = get_argmax_token();

    // 碰到结束符，退出
    if(next_token == sp.eos_id()) break;

    // 解码成文字，输出
    std::string word = sp.Decode({next_token});
    printf("%s", word.c_str());

    // 把新token追加输入，继续预测下一个
    token_ids.push_back(next_token);
}
```

## 容易混淆的两个关键点

1. **编码Encode：文字 → 数字（送入模型前）**
2. **解码Decode：数字 → 文字（模型输出之后）**
3. argmax不是编解码！只是从模型输出概率里挑出token id
