# 大模型核心采样参数「提示工程怎么设」通俗易懂完整版

直接告诉你：**每个参数是什么、调大调小什么效果、不同场景固定设多少、Prompt里怎么写进去**，拿来就能用。

## 一、先搞懂3个核心参数

### 1. Temperature 温度（最常用）

**作用**：控制**随机性、创造力、发散程度**

- 越低：越老实、越确定、重复少、严谨、不走偏
- 越高：越脑洞、越自由、爱即兴、容易瞎编幻觉

**通用档位**

- 0.1～0.3：**事实问答、考试解题、代码、专业严谨内容**
- 0.4～0.6：**日常对话、普通文案、通用办公**（中庸默认）
- 0.7～1.2：**写诗、故事、营销文案、创意脑洞**

---

### 2. Top-P 核采样

**作用**：按**累计概率**圈定可选词汇池，和温度配合控稳定度

- 越小：只选最确定的几个词，输出更死板
- 越大：可选范围更广，更灵活

**工程固定推荐**
绝大多数场景直接 **Top-P = 0.9** 不用改，万能黄金值。

---

### 3. Top-K

**作用**：只从**概率最高前K个词**里选

- 越小：越保守、套路化
- 越大：越灵活、容易乱

**工程固定推荐**
默认 **Top-K = 40** 即可，一般不用手动调。

---

## 三、提示工程里「两种设定方式」

### 方式1：在Prompt文字里直接要求（通用所有模型都生效）

不用后台调参数，**直接写在提示词里**，模型会遵守：

```
本次回答要求：
语言严谨、逻辑准确，不要过度发挥、不要编造无关内容，保持低随机性，只基于事实作答。
```

- 这句话 = 等效把温度压低到 0.2～0.3
- 创意写作就反过来写：

```
本次回答要求：
风格富有创意、文笔生动、允许适度艺术化表达，语言自然有感染力。
```

等效拉高温度。

### 方式2：平台/API 后台直接填参数（专业提示工程用法）

在调用大模型时，接口参数直接固定写死，示例：

```json
{
  "temperature": 0.2,
  "top_p": 0.9,
  "top_k": 40
}
```

做RAG、知识库、企业问答、智能客服**必须固定低温度**，防止幻觉。

---

## 四、调参口诀（记住这几句就够用）

1. **做题写代码，温度往低拉**（0.1–0.3）
2. **文案搞创作，温度往上加**（0.7–1.0）
3. **Top-P 常年 0.9，基本不用动它**
4. **想要严谨就收敛，想要创意就放开**

---

## 五、常见踩坑提醒

1. 温度**不要设0**：太死板、句子重复、没语感
2. 创意场景别用低温：写出来干巴巴像机器人
3. 专业问答别用高温：容易编造数据、产生幻觉
