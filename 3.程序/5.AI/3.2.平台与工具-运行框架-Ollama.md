# Ollama

官网：<https://ollama.com/>

Ollama是**目前全球最流行的开源本地大模型运行框架**，它彻底解决了本地部署大模型的"环境地狱"问题，让任何人都能在自己的电脑上用**一行命令**运行Llama、Qwen、Gemma等几乎所有主流开源大模型。截至2026年5月，Ollama在GitHub上已获得超过16万颗星，成为本地AI开发的事实标准工具。

## 一、什么是Ollama？

### 1. 核心定义

Ollama是一个**轻量级、跨平台的大模型运行时**，它将大模型的权重、配置文件和运行环境打包成单一的`Modelfile`格式，自动处理GPU加速、依赖安装、内存管理等所有底层细节。用户不需要懂CUDA、PyTorch或任何深度学习知识，就能在几分钟内搭建起自己的本地AI助手。

**最形象的类比**：Ollama就是大模型界的"Docker"。Docker让应用可以"一次构建，到处运行"；Ollama让大模型可以"一次打包，到处运行"。

### 2. 解决的核心痛点

在Ollama出现之前，本地部署大模型是一件极其痛苦的事情：

- 需要手动安装CUDA、cuDNN、PyTorch等复杂依赖
- 经常遇到版本冲突、环境不兼容问题
- 需要自己下载模型文件并转换格式
- 手动配置GPU显存、线程数等参数
- 不同模型的运行方式各不相同

Ollama把所有这些复杂步骤都自动化了，真正实现了"开箱即用"。

## 二、Ollama的核心优势

### 1. 极简部署，一行命令搞定

这是Ollama最大的优势。安装Ollama只需要双击安装包，运行大模型只需要一行命令：

```bash
ollama run qwen3.5:7b
```

这行命令会自动：

- 从官方仓库下载Qwen3.5-7B模型
- 自动检测并启用GPU加速
- 配置最优的运行参数
- 直接进入对话界面

### 2. 丰富的模型库

Ollama官方模型库包含了超过1700种开源模型，覆盖了几乎所有主流模型和各种尺寸：

- **通用大模型**：Llama 3.2、Qwen 3.5、Gemma 3、Mistral
- **代码模型**：DeepSeek-Coder、CodeLlama、StarCoder
- **多模态模型**：Llava、Qwen-VL、Gemma 3 Vision
- **嵌入模型**：bge-m3、m3e、gte
- **小模型**：Qwen 0.5B、Llama 3.2 1B（可以在手机上运行）

### 3. 全平台支持

Ollama原生支持所有主流操作系统：

- **macOS**：完美支持Apple Silicon芯片（M1/M2/M3），自动利用Metal加速
- **Windows**：支持WSL2和原生Windows运行
- **Linux**：支持所有主流发行版，支持NVIDIA CUDA和AMD ROCm加速

### 4. 自动硬件加速

Ollama会自动检测你的硬件配置，启用最优的加速方案：

- **NVIDIA GPU**：自动启用CUDA加速
- **Apple Silicon**：自动启用Metal加速
- **AMD GPU**：自动启用ROCm加速
- **CPU**：如果没有GPU，自动使用CPU运行

### 5. 原生OpenAI兼容API

Ollama提供了与OpenAI完全兼容的REST API，运行在默认端口`11434`上。这意味着：

- 所有基于OpenAI API开发的应用都可以无缝切换到本地模型
- 只需要修改`base_url`为`http://localhost:11434/v1`
- 不需要修改任何其他代码

### 6. 强大的模型管理能力

Ollama提供了完整的模型管理命令，可以轻松管理本地的多个模型：

- 查看已安装的模型：`ollama list`
- 删除模型：`ollama rm qwen3.5:7b`
- 查看运行中的模型：`ollama ps`
- 停止运行中的模型：`ollama stop qwen3.5:7b`

### 7. 支持自定义模型

你可以通过`Modelfile`轻松创建自己的自定义模型：

```dockerfile
# Modelfile示例
FROM qwen3.5:7b

# 设置系统提示词
SYSTEM "你是一个专业的代码审查助手，擅长发现代码中的错误和优化点。"

# 设置参数
PARAMETER temperature 0.2
PARAMETER top_p 0.9
```

然后用以下命令构建自定义模型：

```bash
ollama create code-reviewer -f Modelfile
```

## 三、Ollama安装与快速上手

### 1. 安装Ollama

#### macOS/Linux（一键脚本）

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

#### Windows

访问[Ollama官网](https://ollama.com/download)下载`OllamaSetup.exe`，双击安装即可。

#### 验证安装

打开终端或命令提示符，输入：

```bash
ollama --version
# 输出示例：ollama version is 0.23.0
```

### 2. 运行你的第一个大模型

```bash
# 运行Qwen3.5-7B模型（中文效果最好的开源模型之一）
ollama run qwen3.5:7b
```

第一次运行会自动下载模型文件（约4GB），下载完成后直接进入对话界面：

```
>>> 你好
你好！我是Qwen，一个由阿里云开发的人工智能助手。有什么我可以帮助你的吗？

>>> 用Python写一个快速排序算法
好的，这是一个Python实现的快速排序算法：

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

# 测试
print(quicksort([3,6,8,10,1,2,1]))
```

## 五、Ollama生态与集成

Ollama拥有极其丰富的生态系统，几乎所有主流AI工具和框架都原生支持Ollama。

### 1. 与LangChain集成（Python）

这是最常用的集成方式，可以用Ollama构建本地RAG、Agent等复杂应用：

```python
# 安装依赖
pip install langchain-ollama

from langchain_ollama import ChatOllama
from langchain_core.messages import HumanMessage

# 初始化模型
llm = ChatOllama(
    model="qwen3.5:7b",
    temperature=0,
    base_url="http://localhost:11434"
)

# 调用模型
response = llm.invoke([
    HumanMessage(content="解释什么是RAG技术")
])

print(response.content)
```

### 2. 调用OpenAI兼容API

你可以像调用OpenAI API一样调用本地Ollama模型：

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama"  # 随便填一个即可
)

response = client.chat.completions.create(
    model="qwen3.5:7b",
    messages=[{"role": "user", "content": "你好"}]
)

print(response.choices[0].message.content)
```

### 3. 热门第三方工具

- **Open WebUI**：最受欢迎的Ollama Web界面，功能媲美ChatGPT
- **Continue**：VS Code插件，用本地模型实现代码补全和审查
- **AnythingLLM**：一键搭建本地RAG系统
- **Cursor**：AI代码编辑器，原生支持Ollama
- **Claude Desktop**：从v0.23.0版本开始原生支持Ollama模型

## 七、Ollama的应用场景

### 1. 本地开发测试

- 开发和调试AI应用，不需要调用云端API
- 测试不同模型的效果，选择最适合的模型
- 避免云端API的成本和延迟问题

### 2. 隐私敏感数据处理

- 处理企业内部文档、客户数据等敏感信息
- 所有数据都在本地处理，不会上传到云端
- 符合数据安全和合规要求

### 3. 离线使用

- 在没有网络的环境下使用AI能力
- 适合出差、偏远地区等网络不佳的场景

### 4. 教育学习

- 学习大模型的原理和应用
- 搭建自己的AI学习环境
- 进行AI实验和研究

### 5. 企业内部部署

- 搭建企业内部的AI助手和知识库
- 为员工提供统一的AI服务
- 控制成本和数据安全

## 八、局限性与注意事项

### 1. 硬件限制

- 大模型（34B以上）需要较高的硬件配置
- 消费级显卡（如RTX 4090）最多只能流畅运行13B-34B模型
- CPU运行速度较慢，只适合小模型

### 2. 性能差距

- 本地开源模型的整体性能仍然落后于GPT-4o、Claude 3等云端模型
- 复杂推理、数学计算、代码生成等能力差距较为明显

### 3. 多轮对话能力

- 本地模型的上下文窗口通常较小（一般为8K-128K）
- 长对话容易出现上下文丢失和遗忘问题

### 4. 更新速度

- 新模型发布后，通常需要几天到几周时间才能在Ollama上可用
- 部分小众模型可能没有官方支持

## 总结

Ollama是本地大模型部署的"杀手级"工具，它将原本只有专家才能完成的复杂工作变得简单到任何人都能上手。它不仅是个人学习和实验的好工具，也是企业构建私有化AI应用的首选方案。

随着开源大模型性能的不断提升和硬件成本的持续下降，Ollama将在未来的AI生态中扮演越来越重要的角色，让AI真正走进每个人的电脑。

## Ollama 常用命令速查表（可打印版）

**提示**：任何命令后加 `-h` 可查看详细帮助，如 `ollama run -h`

### 🚀 核心命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `ollama run <model>` | 运行模型并进入交互模式 | `ollama run llama3.2` |
| `ollama run <model> "<prompt>"` | 单次查询后退出 | `ollama run qwen3 "解释什么是AI"` |
| `ollama pull <model>` | 下载/更新模型 | `ollama pull gemma3:7b` |
| `ollama list` | 列出本地所有模型 | `ollama list` |
| `ollama ps` | 查看正在运行的模型 | `ollama ps` |
| `ollama stop <model>` | 停止模型释放内存 | `ollama stop llama3.2` |
| `ollama rm <model>` | 删除本地模型文件 | `ollama rm old-model` |

### ⚙️ 服务管理

| 命令 | 功能 |
|------|------|
| `ollama serve` | 手动启动Ollama服务 |
| `OLLAMA_HOST=0.0.0.0:11434 ollama serve` | 允许外部网络访问 |
| `OLLAMA_KEEP_ALIVE=-1 ollama serve` | 模型永久驻留内存 |

### 🛠️ 模型管理

| 命令 | 功能 |
|------|------|
| `ollama show <model> --modelfile` | 导出模型的Modelfile |
| `ollama show <model> --parameters` | 查看模型默认参数 |
| `ollama cp <old> <new>` | 复制模型创建新标签 |
| `ollama create <name> -f Modelfile` | 从Modelfile创建自定义模型 |

### 💬 交互模式快捷键

| 命令 | 功能 |
|------|------|
| `/bye` 或 `Ctrl+D` | 退出交互模式 |
| `/?` | 显示交互模式帮助 |
| `/clear` | 清除对话上下文 |
| `/load <model>` | 快速切换模型 |
| `/set system "<prompt>"` | 临时设置系统提示词 |
| `"""` | 开始多行输入（以`"""`结束） |

### ✨ 实用技巧

```bash
# 管道输入处理文本
cat document.txt | ollama run llama3.2 "总结这段文字"

# 强制JSON格式输出
ollama run gemma3 "列出3个水果" --format json

# 多模态模型分析图片
ollama run llava "这张图里有什么？ /path/to/photo.jpg"

# 生成文本嵌入向量
ollama run nomic-embed-text "Hello World"
```
