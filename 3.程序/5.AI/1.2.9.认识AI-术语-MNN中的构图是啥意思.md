# 构图

在 MNN 框架中，**“构图”** 指的是**构建计算图（Computation Graph）**，也就是把你想要执行的深度学习模型（结构 + 权重）解析成 MNN 内部能够理解、调度和执行的数据结构。

---

## 简单理解

- **图**：就是一系列运算节点（卷积、池化、加法等）按依赖关系连成的有向无环图。
- **构图**：把这个图从模型文件（`.mnn`、`.onnx`、`.tflite` 等）读出来，或通过代码动态创建出来，生成可供推理的引擎对象。

## 在 MNN 里，“构图”一般指以下流程

1. **创建解释器**：`MNN::Interpreter` 负责加载模型。
2. **解析模型**：把文件里的模型描述转成内部计算图。
3. **配置并创建会话**：`createSession(config)` 触发真正的图优化（算子融合、内存规划等），得到可直接运行的 `Session`。

用 C++ 代码示意：

```cpp
// 1. 加载模型并“构图”
auto interpreter = MNN::Interpreter::createFromFile("model.mnn");

// 2. 配置（后端、线程数等）
MNN::ScheduleConfig config;
config.type = MNN_FORWARD_CPU;

// 3. 创建会话——这一步会完成真正的图构建和优化
auto session = interpreter->createSession(config);

// 4. 输入输出张量，运行推理…
```

## 另一种“构图”：动态构图（Expr API）

MNN 还提供了类似 PyTorch 的动态构图能力，可以直接用 C++ 代码搭网络：

```cpp
using namespace MNN::Express;
auto x = _Input({1, 3, 224, 224}, NC4HW4);
auto y = _Conv2D(x, 64, {3,3}, VALID);
auto z = _MaxPool(y, {2,2});
```

这里的每一行都在即时地往计算图中添加节点，最终得到一个可执行的变量。

---

## 总结

- **构图 ≈ 让 MNN 知道你要算什么、怎么算。**
- 对于你看到的“MNN 后端，构图”这个说法，很可能是在讲：**切换到 MNN 后端时，如何把网络结构交给 MNN 去构建计算图**，以便后续在该后端上高效执行推理。
