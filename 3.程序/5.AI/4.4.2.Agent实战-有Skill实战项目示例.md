# Agent 调用规范级 Skill 完整实现

本示例在前文 Agent 规范实现的基础上，增加 **自动发现和调用规范级 Skill** 的能力。规范级 Skill 是指遵循 `SKILL.md` 文件声明的技能，Agent 可以读取其元数据并动态将其作为工具使用。

---

## 一、规范级 Skill 示例（复用之前的代码审查 Skill）

假设我们有一个已完成规范级 Skill：`code-review-skill`，其目录结构如下：

```
skills/
└── code-review-skill/
    ├── SKILL.md
    ├── scripts/
    │   └── review.py
    └── schema/
        ├── input.schema.json
        └── output.schema.json
```

`SKILL.md` 的 YAML 头部包含：

```yaml
name: code-review-skill
description: 智能代码审查，检查 bug、安全漏洞、性能、风格，返回结构化问题列表。
inputs:
  - name: code
    type: string
    required: true
  - name: language
    type: string
    enum: [python, javascript, java, go]
```

Agent 要做的就是：扫描 `skills/` 目录，解析每个 Skill 的元数据，将其注册为可用工具；当 LLM 需要调用时，执行对应的脚本并返回结果。

## 二、Agent 扩展实现

在原有 Agent 的基础上，增加 **Skill 发现与调用** 模块。

### 2.1 新增文件：`skill_discovery.py`

负责扫描目录，解析 `SKILL.md` 文件，提取工具定义。

```python
import os
import re
import json
import yaml
from typing import List, Dict, Any

def discover_skills(skills_dir: str = "skills") -> List[Dict[str, Any]]:
    """
    扫描 skills 目录，读取每个 SKILL.md 的 YAML frontmatter，
    返回符合 OpenAI function calling 格式的工具列表。
    """
    tools = []
    if not os.path.exists(skills_dir):
        return tools

    for skill_name in os.listdir(skills_dir):
        skill_path = os.path.join(skills_dir, skill_name)
        skill_md = os.path.join(skill_path, "SKILL.md")
        if not os.path.isfile(skill_md):
            continue

        with open(skill_md, "r", encoding="utf-8") as f:
            content = f.read()

        # 解析 YAML frontmatter (--- ... ---)
        frontmatter = {}
        if content.startswith("---"):
            parts = content.split("---", 2)
            if len(parts) >= 2:
                try:
                    frontmatter = yaml.safe_load(parts[1])
                except yaml.YAMLError:
                    continue

        name = frontmatter.get("name", skill_name)
        description = frontmatter.get("description", "")
        inputs = frontmatter.get("inputs", [])

        # 构造 JSON Schema for parameters
        properties = {}
        required = []
        for inp in inputs:
            prop = {
                "type": inp.get("type", "string"),
                "description": inp.get("description", "")
            }
            if "enum" in inp:
                prop["enum"] = inp["enum"]
            properties[inp["name"]] = prop
            if inp.get("required", False):
                required.append(inp["name"])

        tool_def = {
            "type": "function",
            "function": {
                "name": name,
                "description": description,
                "parameters": {
                    "type": "object",
                    "properties": properties,
                    "required": required
                }
            }
        }
        # 额外存储脚本路径，用于执行
        tool_def["_skill_path"] = skill_path
        tools.append(tool_def)

    return tools

def execute_skill(tool_name: str, arguments: Dict[str, Any], tools_meta: List[Dict]) -> str:
    """
    根据工具名找到对应的 skill 路径，执行入口脚本，返回结果。
    假设每个 skill 的入口脚本为 scripts/run.py，接受 --参数名 参数。
    """
    import subprocess
    for tool in tools_meta:
        if tool["function"]["name"] == tool_name:
            skill_path = tool["_skill_path"]
            script_path = os.path.join(skill_path, "scripts", "review.py")
            if not os.path.exists(script_path):
                return f"错误：Skill {tool_name} 的脚本不存在"

            # 构建命令行参数
            cmd = ["python", script_path]
            for k, v in arguments.items():
                cmd.append(f"--{k}")
                cmd.append(str(v))
            try:
                result = subprocess.run(cmd, capture_output=True, text=True, timeout=30)
                if result.returncode != 0:
                    return f"Skill 执行失败 (code {result.returncode}): {result.stderr}"
                return result.stdout.strip()
            except subprocess.TimeoutExpired:
                return f"Skill {tool_name} 执行超时"
            except Exception as e:
                return f"执行 Skill 异常: {e}"
    return f"未知 Skill: {tool_name}"
```

### 2.2 修改 Agent 核心类 `agent.py`

在原有 Agent 基础上集成 Skill 发现和调用。

```python
import json
from openai import OpenAI
from config import Config
from logger_config import setup_logger
from memory import ShortTermMemory, LongTermMemory
from skill_discovery import discover_skills, execute_skill

logger = setup_logger("Agent")

class Agent:
    def __init__(self, skills_dir: str = "skills"):
        self.client = OpenAI(api_key=Config.OPENAI_API_KEY)
        self.model = Config.OPENAI_MODEL
        self.max_steps = Config.MAX_STEPS

        # 记忆组件
        self.short_term = ShortTermMemory()
        self.long_term = LongTermMemory()

        # 发现规范级 Skill 并构建工具列表
        self.skills_meta = discover_skills(skills_dir)
        self.tools = self.skills_meta  # 直接作为 OpenAI tools

        logger.info(f"已加载 {len(self.tools)} 个 Skill 工具: {[t['function']['name'] for t in self.tools]}")

        # 系统提示
        self.system_prompt = (
            "你是一个自主的智能体（Agent）。你可以使用以下 Skill 工具来完成任务：\n" +
            "\n".join([f"- {t['function']['name']}: {t['function']['description']}" for t in self.tools]) +
            "\n\n请按照 Thought -> Action -> Observation 循环工作。需要调用工具时直接使用工具调用格式。"
        )
        self.short_term.add("system", self.system_prompt)

    def _call_llm(self, messages: list):
        # 同前文，使用 self.tools
        return self.client.chat.completions.create(
            model=self.model,
            messages=messages,
            tools=self.tools,
            tool_choice="auto",
            temperature=0
        )

    def run(self, user_input: str) -> str:
        logger.info(f"用户输入: {user_input}")

        # 长期记忆检索（可选）
        memories = self.long_term.search(user_input, top_k=2)
        if memories:
            context = "相关历史经验：\n" + "\n".join(memories)
            self.short_term.add("system", context)

        messages = self._build_messages(user_input)
        step = 0

        while step < self.max_steps:
            step += 1
            logger.info(f"步骤 {step}")

            try:
                response = self._call_llm(messages)
            except Exception as e:
                return f"Agent 内部错误：{e}"

            message = response.choices[0].message
            self.short_term.add("assistant", message.content or "")
            messages.append(message)

            # 处理工具调用（包括 Skill 工具）
            if hasattr(message, 'tool_calls') and message.tool_calls:
                for tool_call in message.tool_calls:
                    tool_name = tool_call.function.name
                    arguments = json.loads(tool_call.function.arguments)

                    logger.info(f"调用 Skill: {tool_name}, 参数: {arguments}")
                    # 执行 Skill（规范级调用）
                    observation = execute_skill(tool_name, arguments, self.skills_meta)
                    logger.info(f"Skill 返回: {observation}")

                    # 将工具结果加入消息
                    tool_msg = {
                        "role": "tool",
                        "tool_call_id": tool_call.id,
                        "content": observation
                    }
                    messages.append(tool_msg)
                    self.short_term.add("tool", observation)
                continue

            # 如果没有工具调用，说明 LLM 给出了最终答案
            if message.content:
                answer = message.content
                logger.info(f"最终答案: {answer}")
                self.long_term.add(
                    text=f"用户问: {user_input} | 回答: {answer}",
                    metadata={"step": step, "success": True}
                )
                return answer

            # 没有工具调用也没有内容，视为错误
            return "Agent 无法生成有效回答。"

        return "任务未完成，已达到最大执行步数。"

    # _build_messages, reset 等方法同前文
```

### 2.3 注意事项

- **脚本参数传递**：上述 `execute_skill` 假设 skill 入口脚本支持 `--参数名 值` 的命令行格式。实际使用时可根据需要调整，例如支持 JSON 字符串参数。
- **输入输出校验**：生产环境应在执行前根据 `input.schema.json` 校验参数，执行后校验输出格式。
- **错误处理**：Skill 脚本可能崩溃或超时，Agent 需捕获并优雅降级（例如告知用户，或尝试其他 Skill）。

## 三、运行示例

假设已有 `code-review-skill` 放在 `skills/` 目录下。启动 Agent：

```python
from agent import Agent

agent = Agent(skills_dir="skills")
response = agent.run("请审查以下 Python 代码：\nimport os\nos.system('rm -rf /')")
print(response)
```

**Agent 执行流程**：

1. 发现 `code-review-skill`，将其加入工具列表。
2. 用户请求 → LLM 推理决定调用 `code-review-skill`，参数 `code` 和 `language`。
3. Agent 执行 `python skills/code-review-skill/scripts/review.py --code "..." --language python`。
4. 脚本返回 JSON 结果，Agent 将其作为 Observation 传回 LLM。
5. LLM 根据结果生成最终答案（例如：“发现致命安全漏洞，建议使用 subprocess.run”）。

## 四、总结

通过 **自动发现规范级 Skill** 和 **动态调用执行**，Agent 获得了无限扩展的能力，且每个 Skill 独立开发、跨平台复用。此模式将 Agent 的决策能力与 Skill 的执行能力彻底分离，是构建大规模智能应用的最佳实践。
