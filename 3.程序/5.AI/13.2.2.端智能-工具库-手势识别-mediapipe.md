## 一、MediaPipe 整体介绍

### 1. 是什么

MediaPipe 是 **Google 开源**的跨平台实时计算机视觉框架，基于 C++ 底层封装，提供 Python/JS/Android/iOS 多语言接口，专门解决**人体姿态、手部、人脸、物体识别**等实时视觉任务，低延迟、轻量化，支持 CPU 实时运行，无需高性能显卡。

### 2. 核心优势

1. 开箱即用：内置预训练模型，无需自己训练
2. 轻量化：移动端/笔记本 CPU 流畅跑
3. 模块化：每个任务是独立解决方案（人脸、手、姿态、虹膜等）
4. 跨平台：Python、网页、手机、嵌入式设备通用
5. 输出标准化关键点：2D/3D 坐标、置信度、包围盒

### 3. 内置核心解决方案（模块）

| 模块名称 | 功能 | 输出关键点数量 |
|--------|------|--------------|
| Hands | 手部检测+21个手关节关键点 | 单只手21点，左右手分开 |
| Pose | 全身人体姿态检测 | 33个人体骨骼关键点 |
| FaceMesh | 人脸468个精细面部关键点 | 468点（眼、嘴、眉、轮廓） |
| FaceDetection | 人脸粗检测（只输出框，无精细点） | 人脸矩形、置信度 |
| Holistic | 全身姿态+双手+人脸三合一 | 33+21*2+468 |
| Iris | 虹膜/眼球追踪 | 眼内精细点位 |
| SelfieSegmentation | 人像背景分割 | 前景掩码 |
| ObjectDetection | 通用物体检测 | 80类物体框+置信度 |

### 4. 底层工作流程（Pipeline）

图像输入 → 检测器（人脸/手掌/人体） → ROI 裁剪 → 关键点回归模型 → 后处理平滑滤波 → 输出关键点坐标
自带**平滑滤波**，解决摄像头抖动导致关键点闪烁问题。

## 三、MediaPipe 顶层通用 API 结构详解

### 1. 顶层导入固定模板

所有模块都基于两套核心工具：

```python
import mediapipe as mp

# 绘图工具：绘制关键点、连接线
mp_drawing = mp.solutions.drawing_utils
# 绘图样式工具：自定义点、线颜色粗细
mp_drawing_styles = mp.solutions.drawing_styles

# 各个解决方案单独导入，示例：手部
mp_hands = mp.solutions.hands
# 姿态模块 mp_pose = mp.solutions.pose
# 人脸网格 mp_face_mesh = mp.solutions.face_mesh
# 综合全身 mp_holistic = mp.solutions.holistic
```

### 2. 每个解决方案通用两类类

#### （1）处理类（核心推理类）

如 `mp_hands.Hands()`、`mp_pose.Pose()`
作用：接收图像，返回检测结果（landmarks 关键点）
通用构造参数（几乎所有模块通用）：

1. `static_image_mode=False`
   - False：视频流模式（默认，持续帧优化，速度快）
   - True：静态图片模式，每一帧独立检测，适合单张图片
2. `max_num_xxx` 最大检测数量
   - Hands：`max_num_hands=2` 最多两只手
   - Pose：`max_num_poses=1` 单人检测
3. `min_detection_confidence=0.5`
   初始检测置信度阈值（0~1），低于该值认为无目标
4. `min_tracking_confidence=0.5`
   跟踪置信度阈值，视频流中跟踪失败会重新检测

#### （2）绘图工具 API `mp_drawing`

##### 核心函数

```python
# 在图像上绘制关键点与骨架连线
mp_drawing.draw_landmarks(
    image,                # 原图（BGR）
    landmark_list,        # 检测结果的关键点 landmarks
    connections,          # 骨架连接规则（如 mp_hands.HAND_CONNECTIONS）
    landmark_drawing_spec,# 关键点绘制样式（颜色、大小）
    connection_drawing_spec # 连线样式
)
```

##### 样式工具 `mp_drawing_styles` 预设

```python
# 手部默认点样式
mp_drawing_styles.get_default_hand_landmarks_style()
# 手部默认连线样式
mp_drawing_styles.get_default_hand_connections_style()
# 姿态、人脸同理
```

### 3. 图像格式关键坑（必看）

OpenCV 读取图像是 **BGR**，MediaPipe 要求输入 **RGB**，必须转换：

```python
# 正确流程
image = cv2.imread("test.jpg") # BGR
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB) # 转RGB
image_rgb.flags.writeable = False # 提升推理速度，只读模式

# 推理处理
results = hands.process(image_rgb)

# 绘图前转回BGR
image.flags.writeable = True
image = cv2.cvtColor(image_rgb, cv2.COLOR_RGB2BGR)
```

### 4. 统一返回结果对象 `results` 结构

以 Hands 举例，所有模块结构逻辑一致：

```python
results = hands.process(rgb_image)

# 1. 是否检测到手
if results.multi_hand_landmarks:
    # 遍历每一只手
    for hand_landmarks in results.multi_hand_landmarks:
        # hand_landmarks：单只手21个关键点对象列表
        # 获取第0号关键点（手腕）3D坐标
        wrist = hand_landmarks.landmark[0]
        x = wrist.x  # 归一化坐标 0~1（相对图像宽）
        y = wrist.y  # 归一化坐标 0~1（相对图像高）
        z = wrist.z  # 深度坐标，相机平面为0，靠近相机为负

        # 转换为图像实际像素坐标
        img_h, img_w = image.shape[:2]
        px = int(wrist.x * img_w)
        py = int(wrist.y * img_h)
```

通用字段总结：

- `multi_xxx_landmarks`：多个目标关键点（手/人脸/人体）
- `multi_xxx_world_landmarks`：真实3D世界坐标（米单位，不受图像尺寸影响）
- `multi_handedness`：左右手分类，置信度

## 四、分模块分步实战教程（完整可运行代码）

### 实战1：MediaPipe Hands 手部识别（最常用）

#### 完整分步代码

```python
import mediapipe as mp
import cv2
import numpy as np

# 1. 初始化工具
mp_drawing = mp.solutions.drawing_utils
mp_drawing_styles = mp.solutions.drawing_styles
mp_hands = mp.solutions.hands

# 2. 开启摄像头
cap = cv2.VideoCapture(0)

# 3. 初始化手部检测器（视频模式）
with mp_hands.Hands(
    static_image_mode=False, # 视频流
    max_num_hands=2,        # 最多检测2只手
    min_detection_confidence=0.5,
    min_tracking_confidence=0.5
) as hands:
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret:
            break
        
        # 4. 图像预处理 BGR -> RGB
        frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        frame_rgb.flags.writeable = False
        
        # 5. 推理检测手部
        results = hands.process(frame_rgb)
        
        # 6. 转回BGR用于绘图
        frame_rgb.flags.writeable = True
        frame = cv2.cvtColor(frame_rgb, cv2.COLOR_RGB2BGR)

        # 7. 判断是否检测到手，绘制关键点
        if results.multi_hand_landmarks:
            # 遍历每一只手
            for idx, hand_landmarks in enumerate(results.multi_hand_landmarks):
                # 绘制手骨架
                mp_drawing.draw_landmarks(
                    frame,
                    hand_landmarks,
                    mp_hands.HAND_CONNECTIONS,
                    mp_drawing_styles.get_default_hand_landmarks_style(),
                    mp_drawing_styles.get_default_hand_connections_style()
                )
                
                # 读取左右手信息
                handedness = results.multi_handedness[idx]
                hand_label = handedness.classification[0].label # Left / Right
                score = handedness.classification[0].score       # 置信度
                
                # 打印手腕像素坐标
                h, w = frame.shape[:2]
                wrist = hand_landmarks.landmark[0]
                x_pix, y_pix = int(wrist.x * w), int(wrist.y * h)
                print(f"{hand_label} 手腕坐标：({x_pix}, {y_pix}), 置信度：{score:.2f}")
        
        # 窗口展示
        cv2.imshow("MediaPipe Hands", frame)
        # 按q退出
        if cv2.waitKey(5) & 0xFF == ord('q'):
            break

# 释放资源
cap.release()
cv2.destroyAllWindows()
```

#### Hands 关键API补充

1. 21个手部关键点索引含义
0:手腕；1-4:大拇指；5-8:食指；9-12:中指；13-16:无名指；17-20:小指
2. `results.multi_hand_world_landmarks`：真实3D坐标，用于手势距离计算
3. 静态图片使用：`static_image_mode=True`，无需循环读取摄像头

## 五、高级API & 常用工具函数

### 1. 归一化坐标转像素坐标通用函数

```python
def landmark2pixel(landmark, img_shape):
    h, w = img_shape[:2]
    x = int(landmark.x * w)
    y = int(landmark.y * h)
    z = landmark.z
    return (x, y, z)
```

### 2. 两点欧式距离计算（手势/动作判断）

```python
def calc_distance(p1, p2, img_shape):
    x1,y1,_ = landmark2pixel(p1, img_shape)
    x2,y2,_ = landmark2pixel(p2, img_shape)
    dist = np.sqrt((x1-x2)**2 + (y1-y2)**2)
    return dist
```

### 3. 置信度过滤（过滤低质量检测结果）

遍历时判断置信度，丢弃模糊检测：

```python
if handedness.classification[0].score < 0.6:
    continue
```

### 4. 图像镜像翻转（摄像头左右反转，更符合人眼习惯）

```python
frame = cv2.flip(frame, 1) # 水平翻转
```

### 5. 模型性能优化技巧

1. `image_rgb.flags.writeable = False`：关闭写入，加速推理
2. 降低摄像头分辨率：`cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)`
3. 调低 `max_num_hands/max_num_faces`，减少计算量
4. 不绘制关键点时关闭 draw_landmarks，大幅提升帧率

## 六、常见报错与解决方案

1. **ImportError: No module named mediapipe**
   解决：确认虚拟环境激活，重新 `pip install mediapipe`

2. **摄像头打不开 cap.read() 返回 False**
   - 关闭其他占用摄像头软件
   - 修改设备编号：`cv2.VideoCapture(1)`

3. **关键点不显示、检测不到手/人脸**
   - 光线不足，增加环境亮度
   - 提高 `min_detection_confidence` 阈值
   - 画面中目标完整露出，不要截断

4. **z坐标负数是什么意思**
   z是相对相机平面深度，数值越小代表物体离镜头越近。

5. 画面卡顿、帧率低
   - 缩小摄像头分辨率
   - 注释绘图代码，只做推理
   - 使用静态图片模式代替实时视频

### 十、通用流程固定API调用顺序（所有模块统一模板）

1. 导入包：`import mediapipe as mp, cv2, numpy as np`
2. 初始化绘图工具：`mp_drawing = mp.solutions.drawing_utils`
3. 初始化对应解决方案类（Hands/Pose/FaceMesh等）
4. 摄像头/图片读取图像 → BGR转RGB
5. `rgb_img.flags.writeable = False`
6. `results = model.process(rgb_img)` 推理
7. 恢复图像可写，转回BGR绘图展示
8. `cv2.imshow()` + 释放资源 `cap.release()` `cv2.destroyAllWindows()`
