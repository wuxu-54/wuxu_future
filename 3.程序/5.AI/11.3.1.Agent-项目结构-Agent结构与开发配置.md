# Agent 项目结构与开发配置

>本文是我自己在学习Agent标准结构章节后总结出来的。大体分为依据描述文件自动执行（需要部署各大平台使用时）和手动扫描两种方式

- Agent 有自动扫描配置与手动扫描两种方式
- Agent由skill组成，各家大模型或商城有不同的规范来引入Agent，所以开发者需要根据不同的厂家要求进行配置（这里各家是自动化引入Agent）
- 当我们要自己建一个可识别使用SKILL的Agent时，需要进行手动配置，手写代码进行SKILL识别引入。

基于以上，我按自动化和手动两种方式产生Agent的目录结构与配置

## 一、自动扫描（标准配置）

这里是标准化结构（2026年提出的规范性结构）
>注意标准配置里，无需任何单独代码编写，所有功能执行都在对应的skill中，只需要开发者写好AGENTS.md说明即可

```
your-project/
├── AGENTS.md                      # 跨工具通用项目级 AI 指令（总纲）
├── .agents/                       # Agentic AI Foundation 通用标准目录
│   ├── AGENTS.md                  # 可选的补充指令
│   └── skills/                    # 跨工具通用技能存放处
│       └── skill-name/
│           ├── SKILL.md
│           ├── scripts/           # 技能关联的可执行脚本
│           └── references/        # 技能关联的参考文档
├── .claude/                       # Claude Code 专用目录
│   ├── CLAUDE.md                  # Claude 专属项目指令
│   ├── settings.json              # Claude 项目设置
│   └── skills/                    # Claude 专用技能
└── .cursor/                       # Cursor 专用目录（类似结构）
    ├── CURSOR.md
    └── rules/
```

- `AGENTS.md` 是一个专门为 AI 智能体设计的 Markdown 文件，提供**项目级别的工作指南**。它是所有支持标准的 Agent 工具都会自动读取的第一个文件。它应该告诉 Agent：
  - 项目的安装、构建、测试和运行命令
  - 代码风格与命名规范
  - PR 流程与 commit 信息格式
  - 特殊依赖或安全注意事项
  - 项目的整体架构和核心模块说明

- `.agents/` – 跨工具通用标准目录。`.agents/` 目录是 Agentic AI Foundation 推动的核心标准，旨在成为 AI Agent 世界的".editorconfig"。任何支持该标准的工具都会自动读取此目录下的配置。
  - **位置**：支持项目级（`./.agents/`）和用户级（`~/.agents/`）两种
  - **内容**：可以包含 `AGENTS.md`、`skills/` 子目录等
  - **核心优势**：一次配置，多工具共享。例如，你在 `.agents/skills/pdf-parser/SKILL.md` 中定义了一个 PDF 解析技能，那么 Claude Code、Cursor、Continue 等所有支持标准的工具都可以直接使用，无需重复编写

- 工具专用目录：不同的 AI 开发工具会提供自己的专用目录，用于存放只有该工具才能识别的高级配置,下面是示例：
  - **`.claude/` 目录**：由 Anthropic 为 Claude Code 定义。`CLAUDE.md` 是 Claude 专属的项目指令文件，优先级高于通用的 `AGENTS.md`。`settings.json` 用于配置项目级的 Claude 设置，`skills/` 目录存放只能在 Claude Code 中使用的专用技能。
  - **`.cursor/` 目录**：由 Cursor 编辑器定义。`CURSOR.md` 是 Cursor 专属指令，`rules/` 目录存放 Cursor 的自定义规则。

## 二、手动扫描

我们手动实现扫描SKILL相关文件以及运行其功能，需要手写代码，项目结构无特别要求。一般如下：

```python
your-project/
├── AGENTS.md                  # 跨工具通用项目级 AI 指令（总纲）
├── src/                      
│   ├── __init__.py
│   ├── agent_loader.py            # 关键：标准目录加载器（我们自己实现）
│   ├── main.py                    # Agent 入口
│   └── tools/                     # 自定义工具（可选）
│       └── my_custom_tool.py
├── skills/                    # 跨工具通用技能存放处
│       └── skill-name/
│           ├── SKILL.md
│           ├── scripts/           # 技能关联的可执行脚本
│           └── references/        # 技能关联的参考文档
├── requirements.txt             # 技能依赖包说明
├── .env                         # 环境变量
└── readme.md
```

1. 我们将SKILL放在对应目录下
2. src中编写SKILL加载器、Agent入口
3. 最后在CLI或Server接口方式触发Agent运行即可
