# 模型知识蒸馏

知识蒸馏（Knowledge Distillation, KD）的核心思想，是**让一个轻量级的“学生模型”去模仿一个复杂且性能优异的“教师模型”的行为**。它不仅仅是压缩模型，更是一种“迁移智慧”的过程。

与直接移除参数的剪枝和量化不同，蒸馏是通过改变训练目标来“创造”一个更高效的新模型。

## 一、核心原理：不只学答案，更要学“思考方式”

传统的模型训练只关注**硬目标（Hard Targets）** ，即真实标签（如“这是一只猫”）。而蒸馏引入了**软目标（Soft Targets）** 。

- **软目标**：教师模型输出的概率分布（经温度系数 $T$ 软化后）。它不仅告诉学生“答案是什么”，还揭示了**类别间的相似性**（如“猫”和“老虎”的概率接近，而和“汽车”相差甚远）。这种暗知识（Dark Knowledge）是蒸馏成功的关键。

**经典蒸馏 Loss 公式**：
总损失 = $\alpha \cdot \text{Soft Loss} + (1 - \alpha) \cdot \text{Hard Loss}$

- **Soft Loss（蒸馏损失）**：学生输出（$T$温度）与教师输出（$T$温度）的 KL 散度，乘以 $T^2$（用于补偿梯度缩放）。
- **Hard Loss（学生损失）**：学生输出与真实标签的交叉熵损失。

## 二、三大主流蒸馏策略

| 策略类型 | 教师提供的信息 | 适用场景 | 代表作 |
| :--- | :--- | :--- | :--- |
| **响应蒸馏**<br>(基于Logits) | 教师**最后一层**的输出概率 | 通用性强，实现最简单 | Hinton 经典 KD |
| **特征蒸馏**<br>(基于中间层) | 教师**隐藏层**的特征图 | 学生结构差异大时效果好 | FitNet, AT |
| **关系蒸馏** | 样本间的**距离/角度**关系 | 保持特征空间的结构一致性 | RKD, CC |

## 三、知识蒸馏完整实践示例

这里以 **CIFAR-10 图像分类**为例，用 **PyTorch** 演示如何将 ResNet-34（教师）的知识蒸馏给 ResNet-18（学生）。

### 1. 定义模型与温度缩放

首先，我们需要一个带温度参数 $T$ 的 `softmax` 函数。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def softmax_with_temperature(logits, temperature):
    """温度缩放，T越大，概率分布越平滑（软标签）"""
    return F.softmax(logits / temperature, dim=1)
```

### 2. 定义蒸馏损失函数

这是核心部分，结合了 KL 散度（衡量两个概率分布差异）和交叉熵。

```python
class DistillationLoss(nn.Module):
    def __init__(self, temperature=4.0, alpha=0.7):
        """
        Args:
            temperature: 温度系数，建议 3~10
            alpha: 软标签损失的权重
        """
        super().__init__()
        self.temperature = temperature
        self.alpha = alpha
        self.kl_loss = nn.KLDivLoss(reduction="batchmean")
        self.ce_loss = nn.CrossEntropyLoss()
        
    def forward(self, student_logits, teacher_logits, true_labels):
        # 1. 软标签损失 (蒸馏)
        # 用温度软化两者的 logits
        soft_student = F.log_softmax(student_logits / self.temperature, dim=1)
        soft_teacher = F.softmax(teacher_logits / self.temperature, dim=1)
        
        # 计算 KL 散度，并乘以 T^2 以保持梯度量级不变
        soft_loss = self.kl_loss(soft_student, soft_teacher) * (self.temperature ** 2)
        
        # 2. 硬标签损失 (与真实标签对比)
        hard_loss = self.ce_loss(student_logits, true_labels)
        
        # 总损失 = alpha * 软损失 + (1 - alpha) * 硬损失
        total_loss = self.alpha * soft_loss + (1 - self.alpha) * hard_loss
        return total_loss
```

### 3. 完整的训练流程（关键代码段）

在实际训练中，教师模型**保持冻结（不更新权重）**，只更新学生模型。

```python
def train_kd_epoch(student, teacher, train_loader, optimizer, criterion, device):
    student.train()
    teacher.eval()  # 冻结教师
    
    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)
        
        # 1. 前向传播
        student_logits = student(images)
        with torch.no_grad():  # 不计算教师梯度，节省显存
            teacher_logits = teacher(images)
        
        # 2. 计算蒸馏损失
        loss = criterion(student_logits, teacher_logits, labels)
        
        # 3. 反向传播 (只更新学生)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return loss.item()
```

### 4. 教师模型准备与训练脚本

为了方便你直接运行，这里给出完整的可执行脚本框架：

```python
import torchvision
import torchvision.transforms as transforms
from torchvision.models import resnet34, resnet18

if __name__ == "__main__":
    device = "cuda" if torch.cuda.is_available() else "cpu"
    
    # --- 加载数据 ---
    transform = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.5,), (0.5,))])
    train_set = torchvision.datasets.CIFAR10(root='./data', train=True, download=True, transform=transform)
    train_loader = torch.utils.data.DataLoader(train_set, batch_size=128, shuffle=True)

    # --- 准备教师和学生 ---
    teacher = resnet34(pretrained=True).to(device)  # 加载预训练教师
    student = resnet18(pretrained=False).to(device) # 从头训练学生
    
    # --- 冻结教师 ---
    for param in teacher.parameters():
        param.requires_grad = False

    # --- 初始化蒸馏损失和优化器 ---
    criterion = DistillationLoss(temperature=5.0, alpha=0.7)
    optimizer = torch.optim.Adam(student.parameters(), lr=0.001)

    # --- 开始训练 ---
    for epoch in range(50):
        loss = train_kd_epoch(student, teacher, train_loader, optimizer, criterion, device)
        print(f"Epoch {epoch}, Loss: {loss:.4f}")
```

**关于代码的补充说明**：

- **教师模型的选择**：如果已有训练好的大模型，直接加载即可；如果没有，可以先粗训练一个作为教师。
- **温度T的选择**：通常越大，概率分布越“软”，蕴含的信息越丰富，但也可能淹没小概率类别信息。建议从 3~10 开始尝试。
- **损失权重的调优**：`alpha` 控制在 0.5~0.9 之间，通常软目标提供更多信息时，`alpha` 可以取大一些。

## 四、蒸馏进阶：特征蒸馏（中间层对齐）

如果学生网络层数较浅，仅靠最后的 Logits 可能学不到精髓。特征蒸馏让学生不仅模仿“结论”，还要模仿“思考过程”，即教师网络的**中间层特征图**。

**核心思想**：计算学生和教师在相同尺寸特征图之间的 L2 损失。

```python
# 伪代码示例
class FeatureLoss(nn.Module):
    def __init__(self, layer_weights):
        super().__init__()
        self.layer_weights = layer_weights  # 例如 {'layer1':0.5, 'layer2':0.3}

    def forward(self, student_feats, teacher_feats):
        loss = 0
        for key, weight in self.layer_weights.items():
            # 假设学生和教师的特征图空间大小不同，需要用适配器(adapter)对齐
            s_feat = student_feats[key]
            t_feat = teacher_feats[key].detach()
            loss += weight * F.mse_loss(s_feat, t_feat)
        return loss
```

**实战建议**：特征蒸馏需要解决“维度不匹配”问题，通常会在学生网络对应层后添加一个 1×1 卷积（适配器）将通道数对齐到教师。

## 五、工程实践要点总结

| 关键要点 | 说明与建议 |
| :--- | :--- |
| **教师模型选择** | 并非越大越好，需保证师生模型属于**同一任务领域**，且教师推理速度快。 |
| **温度系数 T** | 通常 **3~20** 之间。T 越大，软标签越平滑，能暴露更多类别间关系。 |
| **损失权重 α** | 通常 **0.5~0.9** 之间。如果教师精度很高，软标签更可靠，α 可调大。 |
| **学生初始化** | 用预训练权重初始化学生通常比随机初始化效果更好。 |
| **轻量级蒸馏库** | 生产环境可借助 **HuggingFace `transformers`**（针对 NLP）或 **TextBrewer** 等工具。 |

## 💎 总结

知识蒸馏的本质是**函数逼近**——用更少的参数去拟合大模型的复杂决策边界。它特别适合**推理延迟敏感**且**GPU显存严格受限**的场景。

需要注意，蒸馏通常不适合从零构建轻量模型，因为你仍需要一个强大的教师模型作为基础。如果缺少大模型作为教师，可以考虑**自蒸馏**或**在线蒸馏**（多个学生互教互学）作为替代方案。如果你对这两种方案感兴趣，我们也可以继续探讨。
